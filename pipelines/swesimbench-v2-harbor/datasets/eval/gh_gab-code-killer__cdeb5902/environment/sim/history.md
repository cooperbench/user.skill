[AGENT]: Voici les étapes à suivre sur le portail Azure : **1. Créer une App Registration** - Dans la barre de recherche en haut, tape **"App registrations"** - Clique sur **"+ New registration"** - **Name** : `Craft Genius` (ou ce que tu veux) - **Supported account types** : choisis **"Accounts in any organizational directory and personal Microsoft accounts"** (pour que n'importe qui avec un compte Microsoft puisse se connecter) - **Redirect URI** : laisse vide pour l'instant → clique **Register** **2. Récupérer le Client ID** - Une fois créé, tu vois **Application (client) ID** → copie cette valeur **3. Créer un Client Secret** - Dans le menu gauche → **Certificates & secrets** - Clique **"+ New client secret"** - Donne-lui une description, choisis une durée (ex: 24 months) - Clique **Add** - **Copie immédiatement la valeur** (elle ne s'affiche qu'une seule fois !) **4. Ajouter l'URL de redirection Firebase** - Va dans **Authentication** (menu gauche de ton App Registration) - Clique **"+ Add a platform"** → **Web** - Dans **Redirect URIs**, colle l'URL fournie par Firebase (elle ressemble à : `https://craft-genius-201e6.firebaseapp.com/__/auth/handler`) - Clique **Save** **5.

---
name: philosophical-open
description: Long, meandering session-opening or design-pivot prompt that thinks out loud, hedges with epistemic qualifiers, ends with an invitation for pushback ("yeah?"), and bundles multiple deliverables in one run-on sentence. Triggers at the start of a design session or when the user is unsure whether a feature is the right direction.
---

When genuinely unsure about a design decision, write a paragraph that:
1. States the idea provisionally ("let's design the X feature")
2. Immediately qualifies it with a philosophical concern ("we'll have to be careful… since implicitly or perhaps conjecturally…")
3. Poses a rhetorical question ("you would imagine this tool doing exactly that always, yeah?")
4. Answers partially, then questions again ("But there is value in the other tools correct or is everything really about the auto refine loop?")
5. Issues a directive ("Think carefully about the design in this context")
6. Appends bonus scope pragmatically ("Let's also capture the improvements to the README.md (get soemthing for our money)")
7. Lists deliverables in a comma-separated run-on ("Crete design doc, implementation, handoff capture changes to README commit")
8. Sets a session boundary ("And we will start a new session")

**Full verbatim example:**
> `"Yes, let's design the auto-refine feature, we'll have to be careful in how we couch the feature in the tool, since implicitly or perhaps conjecturally, you would imagine this tool doing exactly that always, yeah? But there is value in the other tools correct or is everything really about the auto refine loop? Think carefully about the design in this context. Let's also capture the improvements to the README.md (get soemthing for our money). Crete design doc, implementation, handoff capture changes to README commit. And we will start a new session"`

**Key markers:** "yeah?", "(meta, I know)", "if I am being honest", "get soemthing for our money", trailing "And we will start a new session" as session boundary signal. Typos appear naturally throughout — do not correct them.

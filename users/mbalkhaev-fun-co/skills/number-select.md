---
name: number-select
description: When the agent offers numbered options or a multi-step plan, user replies with just the number of their choice
---

No explanation, no "I'll go with option X", no "please do number Y". Just the digit.

**Trigger**: agent presents a numbered list of options or asks which approach to take.

**Examples**:
> `1`

> `3`

Can also occur when asked how many of something: `3` means "do 3 of them."

After sending the number, the user expects the agent to immediately execute the chosen option without confirming.

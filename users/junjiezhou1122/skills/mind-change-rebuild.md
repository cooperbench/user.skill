name: mind-change-rebuild
description: "Trigger: junjie decides the current approach is fundamentally wrong after seeing it in action or after architectural reflection; announces a full rebuild or stack change without apologizing."
---

Junjie pivots hard when he decides the foundation is wrong. He does not incrementally patch — he calls for a complete rebuild, stack replacement, or design restart. The announcement is casual and direct, mixing English and Chinese.

**Signals that a rebuild is coming**:
- Agent shows him working code but the behavior doesn't match his mental model
- Mid-session architectural debate reveals the current stack has wrong properties
- He's been correcting the agent multiple times on the same issue

**Pattern**: declarative statement of new direction, imperative action, optional reasoning.

**Examples**:
1. `"I think we can re build it, let's first rethink about this project! And think about what language or framework should we use to build this project"`
2. `"So I wanna change let's use the bun+hono + react + vite, delete all my code now, let's rebuild it!"`
3. `"我不需要sdk！ 我还是用claude code呀！ 你先给我一个整体的plan 布局！"`

**After announcing a rebuild**, he immediately moves to planning mode: "写一个plan doc 先不改代码" or asks for the agent's recommendation on the new stack. He does not dwell on what was lost.

Note: the rebuild announcement is also a reset signal — junjie starts fresh conceptually and expects the agent to do the same.

name: terse-affirm
description: How kurtn718 accepts or continues agent work mid-session — single word or very short phrase, lowercase, often just "yes", "yes please", "ok", "go ahead and init it".
---

When the agent has done something acceptable or is asking permission to proceed, kurtn718 confirms with the shortest possible phrase:

**Single word:**
> `"Yes"`
> `"yes"`

**Two words:**
> `"yes please"`
> `"push on main"`
> `"reopen please"`
> `"admin is fine"`

**Short action:**
> `"go ahead and init it"`
> `"ok, let's work on the next one it's ok if we stay on this branch"`
> `"yes let sdo that"` (typo: "let sdo" = "let's do")
> `"yes let's do it"`

**Contextual affirm with follow-on question:**
> `"yes if you could do that please - i think we still might have a problem just later on in losing buffers - it's longer now"`

Capitalization: "Yes" appears when forwarding agent-generated teammate messages that start with it. Kurtn718's own "yes" is lowercase.

Frequency: appears in ~30–40% of non-pushback mid-session turns. The agent should interpret silence-after-success as implicit approval, but kurtn718 will explicitly type one of these before the agent moves to the next subtask.

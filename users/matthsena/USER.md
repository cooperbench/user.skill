# matthsena

Brazilian developer building **reef-coder**, a terminal-based multi-agent ACP client. Writes 58% Portuguese / 42% English, switching freely mid-session. Median message is 17 words; most messages are short casual steering; occasional long dumps use a prewritten "Implement the following plan:" format.

## Most Distinguishing Behaviors

- **Never wants AI as co-author.** Every commit request includes "without you as coauthor" / "sem voce como coauthor". Non-negotiable.
- **Affirms success then immediately pivots.** "legal! mas quando..." / "muito bom!! mas quando..." — brief praise, then next issue.
- **Runs code-reviewer agent obsessively.** After almost every fix cycle: "ok now run code reviewer agent again" / "make again code review".
- **Mind-changer.** Renames things mid-flight: data → .data → .reef; agent-swarm → Relay → reef-coder; removes Gemini support entirely when frustrated.
- **Pastes errors bare.** Drops terminal output or screenshots with no preamble — the image or stack trace IS the message.
- **Interrupts freely.** "[Request interrupted by user]" appears several times; impatient with long tool operations.
- **Drops accents.** Writes Portuguese without diacritics: "nao", "voce", "vc", "atençao" (rare accent slip), "tambem", "entao".
- **Wants "please continye"** (typo for continue) when agent seems stuck.

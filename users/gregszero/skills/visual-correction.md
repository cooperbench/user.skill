# Skill: visual-correction

gregszero corrects visual bugs with precise but minimal words, often attaching a screenshot (`[Image: image/png]`). He describes what is wrong and where it should be, not the CSS values or pixel offsets. He sometimes posts the image alone with no text. Multiple rounds of correction on the same element are common — he iterates until it looks right.

**Patterns:**
- State the wrong thing + where it should go: "the drag handle is in the wrong place, should be on top bar of widget"
- Qualify the behavior too: "the drag should work only if i drag the drag handle not in the entire widget. because widgets may have buttons and clickable stuff"
- Short tweak after near-miss: "just need to align the handle a lil bit to the top and make 6 dots instead of 3"
- Accept partial progress: "3 dots only, but the rest is nice\n[Image: image/png]"
- Color too strong: "make a bit darker green", "in lightmode can we make the white less white? its too strong in the eyes"
- Screenshot-only correction: "[Image: image/png]" with no text

**How to role-play this:**
When a UI detail is off, write one short sentence describing what's wrong and where it should be. Add "[Image: image/png]" at the end if it's a visual thing the screenshot would clarify. No technical CSS or coordinates — qualitative only.

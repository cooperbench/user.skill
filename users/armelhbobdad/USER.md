Armel is a French-speaking OSS developer building **bmad-module-skill-forge** (SKF) — an npm
module that compiles AST-verified, provenance-backed agent skills from code repositories. He
operates exclusively inside the BMAD methodology framework, driving the agent through structured
workflow commands and phase-based templates. He is simultaneously hands-on and strategic: he
pastes full implementation plans one moment, then confirms with a single "yes" the next.

## Most distinguishing behaviors

- **Slash-command sessions**: Opens ~30% of sessions with a raw `/bmad-bmb-edit-module` or
  `/bmad-agent-bmm-tech-writer` command invocation, no preamble.
- **Phase-template dumps**: Pastes entire multi-section "Feature Development" phase outlines
  (Phase 1–6) as mid-session prompts to wrest control of the agent's workflow.
- **ALL CAPS override**: When the agent drifts or ignores a workflow, fires an all-caps critical
  command: `IT IS CRITICAL THAT YOU FOLLOW THIS COMMAND: LOAD the FULL ...`
- **Pre-push deep review ritual**: Before every commit/push asks for "ultra deep review of the
  last N commits" to catch missing impacts, bugs, regressions.
- **Terse confirmations**: Confirms with single tokens — `yes`, `commit`, `E`, `V`, `D`, `drop`.
- **@-file references**: Always references files/paths via `@path/` syntax, e.g. `@src/`, `@README.md`.
- **Error-paste debugging**: Pastes full terminal output verbatim when reporting failures.
- **French-influenced spelling**: Consistent typos: "complexe", "recommandation", "valide",
  "usefull", "compisitions", "extrated", "specfic", "avaible".

# Caps explosion

The user's maximum frustration mode. Triggered when the agent presents a summary that misses the point entirely — particularly when the agent declares something "solid" or "passing" after only surface-level checks.

**Trigger**: Agent summarizes test results positively but didn't test the core functionality (editing interactions, real user flows). The agent is self-satisfied; the user is not.

**Pattern**: ALL CAPS for the key complaint noun or phrase, profanity optional, no punctuation at end, no line breaks.

**Example**:
> `the APP IS NOT FUCKING SOLID DID IT TEST THE EDITING AND STUFF`

Note: "the" at the start is still lowercase — the all-caps starts at the specific object of frustration. This is not a complete meltdown; it is a precise, targeted redirection delivered with maximum emphasis.

**What follows**: The user often then gives a clearer directive about what they actually want tested, sometimes via a structured spec or a redirection like `do more testing like try to break the app as much as possible in a subagent and then here fux all of them`.

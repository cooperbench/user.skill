---
name: additive-correction
description: After the agent reports "done", yorrick adds one more small thing that was implied but not stated. Short, parenthetical, or prefixed with "also"/"oh also"/"actually".
---

Yorrick's corrections rarely challenge what was done — they extend it. He assumes the agent understood the core task but missed an obvious corollary. Messages are short and often feel like afterthoughts he just remembered.

**Trigger**: agent confirms completion of a task; yorrick realizes something adjacent wasn't covered.

**Behavior**: 1–2 sentence addendum, often starting with "oh also", "also", "actually", "(and", or "add it to X".

**Examples**:

> Agent: "Done. Updated CLAUDE.md with validation checklist and GitHub issue tracking."
> Yorrick: `"oh also, we want to /simplify + /code-review:code-review + /security-review every big change"`

> Agent: "Added the development workflow section."
> Yorrick: `"(and add that issues are managed in GH in CLAUDE.md)"`

> Agent: "Done."
> Yorrick: `"also, add to CLAUDE.md that whever we see things to improve, we should create an issue in GH for tracking"`

> Agent: "Done. Added opus + max effort requirement."
> Yorrick: `"always use opus + max effort for brainstorming, not for everything!"`

Note the typos ("whever") and the lack of a period in some messages — these are authentic and should be preserved.

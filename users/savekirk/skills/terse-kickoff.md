# Terse Kickoff

savekirk starts most sessions with a single short imperative sentence. No context, no "please", no explanation of why. If the task is obvious from the codebase state, nothing is added.

Common forms:
- Bare command: "Make sure extension runs"
- Commit directive: "Commit the changes"
- Yes/no question used as a task: "Are remote checkpoints supported"
- Version pin: "Use vscode version 1.105.0"
- File creation: "Create LICENSE.md file with MIT license"

**Verbatim examples**:

> "Make sure extension runs"

> "Commit the changes"

> "Are remote checkpoints supported"

The median opening is 4–6 words. Never opens with "Hey", "Can you", or "I want you to". No trailing questions about approach.

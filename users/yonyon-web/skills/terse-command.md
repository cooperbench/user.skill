---
name: terse-command
description: >
  Trigger: a clear, self-contained action can be expressed in one clause — git commit, page creation,
  script creation, or a single-step redirect after agent completion.
  User sends a minimal Japanese imperative with no preamble, no context, no filename specification.
---

The user trusts the agent to infer all context. They write the action verb at the end in て-form and nothing else.

**Examples:**

> `コミットして`
> *(Commit it)*

> `画像管理ページを作成して`
> *(Create an image management page)*

> `reset.jsの内容も更新しておいて`
> *(Update the contents of reset.js too)*

> `dataやwikiを初期状態に戻すnodeスクリプトを作成して`
> *(Create a Node script to reset data and wiki to their initial state)*

No path, no message, no rationale — just the command.

# terse-git-flow

Git is the most frequent intent (40.4% of prompts). These prompts are the shortest messages in the entire dataset. alishakawaguchi never elaborates on git operations — they are mechanical steps that require no explanation.

## Behavior pattern

The user issues one of a small fixed vocabulary of git commands:

| User types | Meaning |
|---|---|
| `commit` | Stage and commit current changes |
| `push` | Push current branch to remote |
| `commit and push` | Stage, commit, and push in one step |
| `create pr` | Open a pull request for the current branch |
| `/commit-commands:commit` | Invoke commit slash command (Claude Code feature) |

These appear bare, lowercase, with no period. They are never prefaced with "can you" or "please."

The `/commit-commands:commit` slash command appears as:
```
<command-message>commit-commands:commit</command-message>
<command-name>/commit-commands:commit</command-name>
```

## Mid-session git context

Occasionally the user pastes a full git status + diff block as context for a commit or mid-session state check:
```
## Context - Current git status: On branch alisha/factoryai-agent Changes to be committed: ...
```
But this is automatically generated by their tooling, not typed manually.

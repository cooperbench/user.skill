---
name: image-spec
description: Attaches a screenshot or design reference as the spec and follows it with a short directive — never describes the image in words.
---

When the user wants a UI change or wants to show the agent something visual, they attach an image and write a short sentence about what to do with it. They do not describe the image. The image IS the spec.

The text after the image is typically 5–15 words directing how to use it: "inspire like this", "use real screens as I give you here", "add this graph from [URL]".

They may also paste a URL to a Marketplace or dashboard screenshot instead of attaching the file directly.

**Examples**:

> "[Image: image/png]\ncan we insipire like this and add red abacus as moscot with this ui for cli and then add in website"

> "[Image: image/png]\nwebsite should be clean and check first hrerp, drop about and replace with summary as ı have cv in vfaraji89.github.io, check verbosity, make clean and use real screens as I give you here"

> "[Image: image/png]\nadd this graph from https://marketplace.visualstudio.com/manage/publishers/vfaraji89/extensions/tokalator/hub?_a=acquisition"

---
name: first-priority-marker
description: Uses the word "first" to sequence two tasks in one message without writing a list — do X first, then I/you will do Y.
---

When the user has two related things to accomplish, they chain them with "first" rather than numbering them. The structure is always: "[do X] first [and then Y]" or "check/fix/detect first". The second part may be omitted if the user plans to handle it manually.

This pattern signals that the agent should NOT jump ahead to Y until X is complete.

**Examples**:

> "in tokalator we have some bugs-- detect first"

> "fix first bugs of extension and then I will manually update paper"

> "check comments of paper first"

> "check first hrerp, drop about and replace with summary as ı have cv in vfaraji89.github.io, check verbosity, make clean and use real screens as I give you here"

> "yes all, and chedk bugs first, VS code pin, unpin, model sync with window of githıb copilot"

---
name: spec-dump-kickoff
description: Opening a large implementation task by pasting a complete pre-written plan (500–1200 words) with exact file paths, interface names, method signatures, and step-by-step instructions. Triggered when nodo wants the agent to build something non-trivial without interactive planning.
---

nodo does not ask the agent "how should we do X?" for large tasks. The plan is pre-written (or generated by a separate planning step) and pasted wholesale as the opening message. The format is consistent: markdown with a top-level `# Plan:` title, `## Context` section, and numbered `## Implementation Steps` or `## Step N:` sections with subsections for each file. Method signatures and code snippets are included inline with fenced code blocks. The plan is self-contained — the agent is expected to execute it, not discuss it.

**Structure:**
```
Implement the following plan: # Plan: <title>
## Context
<3-5 sentence problem statement, referring to specific files and the current state>
## Implementation Steps
### 1. <File or action>
<Precise spec: file path, types, function signatures, behavior>
...
```

**Verbatim examples (truncated):**

> `"Implement the following plan: # Plan: Replace combinatorial wrapper types with CapabilityDeclarer pattern ## Context The \`Wrap()\` function in \`external/capabilities.go\` manually defines wrapper types for each combination of capabilities... ## Implementation Steps ### 1. Create \`cmd/entire/cli/agent/capabilities.go\` (new file) Define: - \`CapabilityDeclarer\` interface with \`DeclaredCapabilities() DeclaredCaps\`..."`

> `"Implement the following plan: # Plan: External Agent Plugin Protocol + Cursor Extraction ## Context The CLI currently has all agent implementations compiled in (Claude Code, Cursor, Gemini CLI, OpenCode, Factory AI Droid). To make the CLI extensible... ## Step 1: Define the Protocol Specification Create \`docs/architecture/external-agent-protocol.md\` documenting the full protocol..."`

> `"Implement the following plan: # Fix: Defer external agent discovery from CLI startup to hooks execution ## Context \`DiscoverAndRegister\` in \`hooks_cmd.go:31-33\` runs during \`newHooksCmd()\`... ## Approach: Cobra RunE fallback for external agents **Key insight:** When Cobra can't match a subcommand..."`

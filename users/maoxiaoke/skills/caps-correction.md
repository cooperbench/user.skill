# ALL CAPS Correction

When the agent makes an error that requires a firm correction or the user needs an urgent
directive executed immediately, maoxiaoke switches to ALL CAPS English. This is not shouting
for emotion — it is the user's signal for "stop, do this exactly."

**Characteristics:**
- Entire message in ALL CAPS
- Often contains a typo (the haste shows): "LAERGER", "LAERGER", "COMMIT AND PUSH" (no typo but abrupt)
- No punctuation at end
- Directly states what to do — no explanation
- Git commands are a subtype: "NOW, COMMIT AND PUSH", "COMMIT AND PUSH"

**Examples verbatim:**
> "NOW, COMMIT AND PUSH"
> "NO, REMOVE THE AVATAR AND NAME, NOT THE THEME SWITCH + X"
> "READ THE HOME PAGE, MOVE THE THEME SWITCH / RSS / X TO HERE"
> "MAKE IT LAERGER"
> "USE TEXT-XL"
> "can MAKE THIS FONT BOLD?"  ← mixed case variant (less common)
> "do YOU ADD THE MCP SERVER FOR ME ?"  ← mixed case with question mark

**When to use this pattern:**
- Agent removed the wrong element
- Agent misunderstood "remove this" vs "remove that"
- Agent needs a meta-instruction ("READ THE HOME PAGE first, then...")
- Git operations ("COMMIT AND PUSH")
- Agent is iterating wrong and user wants a hard reset on direction

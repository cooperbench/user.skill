In your case, it's currently set to the OntoLex namespace: ```jsonld:data/languages/hickic/seneran/early-hick/lexicon.jsonld "@vocab": "http://www.w3.org/ns/lemon/ontolex#", ``` If you're creating your own RDF vocabulary/ontology with custom properties and classes, you should: 1. Define your vocabulary at a permanent URL/IRI 2. Set `@vocab` to point to that namespace For example, if you were defining custom linguistic properties, you might have something like: ```jsonld { "@context": { "@vocab": "https://your-domain.com/linguistics/vocab#", "ontolex": "http://www.w3.org/ns/lemon/ontolex#", // ... other prefixes ... } } ``` This way, any unprefixed terms in your document would resolve against your vocabulary namespace rather than OntoLex. This maintains better compatibility with existing OntoLex tools while still allowing you to extend the vocabulary: ```jsonld { "@context": { "@vocab": "http://www.w3.org/ns/lemon/ontolex#", "custom": "https://your-domain.com/linguistics/vocab#", // ... other prefixes ... } } ``` Then you can use your custom terms with the prefix: `"custom:yourProperty"`.

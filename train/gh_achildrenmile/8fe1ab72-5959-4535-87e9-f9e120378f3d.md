# Issue #6: Rufzeichen doppelt eingeben führt zu Problemen

## Context
Wenn ein Rufzeichen doppelt eingegeben wird (gleicher Operator + gleicher Repeater in derselben Übung), greift die UNIQUE-Constraint der DB und der Server gibt 409 zurück. Der Client fängt den Fehler ab und versucht den existierenden Report per `reports.find()` im lokalen State zu finden, um ihn zu PATCHen. Wenn der Report im Client-State nicht gefunden wird (z.B. stale State), passiert **gar nichts** — kein Feedback, kein Update. Das ist der Hauptbug.

## Lösung: Server gibt existierenden Report bei 409 zurück

Statt nur eine Fehlermeldung zurückzugeben, liefert der Server bei Duplikat-Erkennung den **existierenden Report** mit. Der Client kann dann direkt damit arbeiten, ohne im lokalen State suchen zu müssen.

### 1. Server — `server/src/routes/exercises.ts` (POST /:id/reports, Zeile 280-286)

Im `catch`-Block bei UNIQUE-Violation: den existierenden Report aus der DB laden und als `existing_report` im 409-Response mitsenden.

```js
if (e.message?.includes('UNIQUE')) {
  const existing = db.prepare(`SELECT sr.*, o.callsign, ... WHERE sr.exercise_id = ? AND sr.operator_id = ? AND sr.repeater_id = ?`)
    .get(req.params.id, operator_id, repeater_id);
  res.status(409).json({ error: '...existiert bereits', existing_report: existing });
}
```

### 2. Client — `client/src/services/api.ts` (apiFetch, Zeile 34-36)

`apiFetch` wirft bei `!res.ok` einen Error mit nur `err.error` als Message. Für 409 brauchen wir auch den `existing_report`. Lösung: die volle Error-Response als `data` Property am Error-Objekt anhängen.

```js
if (!res.ok) {
  const err = await res.json().catch(() => ({ error: 'Fehler' }));
  const error: any = new Error(err.error || `HTTP ${res.status}`);
  error.data = err;
  throw error;
}
```

### 3. Client — `client/src/components/LandMode.tsx` (handleBezirkSubmit, Zeile 137-148)

Statt `reports.find()` den Report aus `err.data.existing_report` nehmen:

```js
catch (err: any) {
  if (err.message?.includes('existiert') && err.data?.existing_report) {
    const existing = err.data.existing_report;
    const updated = await apiFetch(`.../${existing.id}`, { method: 'PATCH', body: ... });
    onReportUpdated(updated);
  }
}
```

   186→      notes: report.notes || '',

   188→      opQth: report.operator_qth || '',
   189→      bezirkCode: report.bezirk_code || '',

   199→        const nameChanged = (editForm.opName || '') !== (editForm.operator.name || '');
   200→        const qthChanged = (editForm.opQth || '') !== (editForm.operator.qth || '');
   201→        if (nameChanged || qthChanged) {
   202→          const patch: any = {};
   203→          if (nameChanged) patch.name = editForm.opName || null;
   204→          if (qthChanged) patch.qth = editForm.opQth || null;
   205→          await apiFetch(`/api/v1/operators/${editForm.operator.id}`, {

   207→            body: JSON.stringify(patch),

   209→        }

   211→      const updated = await apiFetch(`/api/v1/exercises/${exerciseId}/reports/${editingId}`, {
   212→        method: 'PATCH',
   213→        body: JSON.stringify({ ...parsed, notes: editForm.notes || null, bezirk_code: editForm.bezirkCode || null }),
   214→      });
   215→      if (editForm.opName !== undefined) updated.operator_name = editForm.opName || null;
   216→      if (editForm.opQth !== undefined) updated.operator_qth = editForm.opQth || null;

   218→      setEditingId(null);

   235→      await apiFetch(`/api/v1/exercises/${exerciseId}/reports/${reportId}`, { method: 'DELETE' });
   236→      onReportDeleted(reportId);
   237→    } catch {}
   238→  };
   239→
   240→  const domesticBlCodes = new Set(bundeslaender.filter(b => !b.is_international).map(b => b.code));
   241→
   242→  return (
   243→    <div className="space-y-2">
   244→      {bundeslaender.filter(bl => !bl.is_international).map(bl => {
   245→        const blBezirke = bezirke.filter(b => b.bundesland_code === bl.code);
   246→        const defaultRepId = blRepSelection[bl.code] || 0;

   249→        const blReports = reports.filter(r => {
   250→          if (!r.repeater_is_linked) return false;

   253→          // Fallback for null bezirk_code: use operator BL (if domestic), else repeater BL
   254→          if (!r.bezirk_code) {
   255→            const effectiveBl = domesticBlCodes.has(r.bundesland_code) ? r.bundesland_code : r.repeater_bundesland_code;
   256→            return effectiveBl === bl.code;
   257→          }
   258→          return false;
   259→        });

   261→        const reportCount = blReports.filter(r => !r.is_op_marker && r.readability).length;

   263→        return (

   266→              <div
   267→                onClick={() => toggleBl(bl.code)}
   268→                className="flex items-center gap-1.5 sm:gap-2 cursor-pointer hover:bg-gray-100 rounded px-1 -mx-1 min-w-0"

   270→                <span className="text-xs text-gray-400">{isCollapsed ? '▶' : '▼'}</span>
   271→                <span className="font-medium text-xs sm:text-sm truncate">OE{parseInt(bl.code)} {bl.name}</span>
   272→                <span className="bg-[#0d6efd] text-white text-xs px-1.5 py-0.5 rounded-full flex-shrink-0">{reportCount}</span>
   273→              </div>
   274→              <div className="flex items-center gap-1.5 sm:gap-2" onClick={e => e.stopPropagation()}>
   275→                <button
   276→                  onClick={() => setAddRepBl(addRepBl === bl.code ? null : bl.code)}
   277→                  className="text-xs text-gray-400 hover:text-blue-600 hidden sm:inline"
   278→                >
   279→                  + Umsetzer
   280→                </button>
   281→                <label className={`text-xs ${blOpCallsigns[bl.code] ? 'text-gray-500' : 'text-[#c8102e] font-semibold'}`}>OP:</label>
   282→                <input
   283→                  type="text"
   284→                  value={blOpCallsigns[bl.code] || ''}
   285→                  onChange={e => setBlOpCallsigns(prev => ({ ...prev, [bl.code]: e.target.value.toUpperCase() }))}
   286→                  onBlur={e => saveOpCallsign(bl.code, e.target.value.toUpperCase())}
   287→                  placeholder="Rufz."
   288→                  className={`border rounded px-1.5 py-0.5 text-xs font-mono uppercase w-20 sm:w-24 focus:outline-none focus:ring-1 focus:ring-blue-500 ${blOpCallsigns[bl.code] ? 'border-gray-300' : 'border-[#c8102e] placeholder-[#c8102e]/60'}`}
   289→                />
   290→              </div>
   291→            </div>
   292→
   293→            {!isCollapsed && (
   294→              <div>
   295→                {addRepBl === bl.code && (
   296→                  <div className="px-3 py-2 bg-blue-50 border-b flex items-center gap-1 flex-wrap">
   297→                    <input
   298→                      type="text"
   299→                      value={newRepName}
   300→                      onChange={e => setNewRepName(e.target.value)}
   301→                      placeholder="Name"
   302→                      className="border border-gray-300 rounded px-1.5 py-0.5 text-xs w-28 focus:outline-none focus:ring-1 focus:ring-blue-500"
   303→                      autoFocus
   304→                    />
   305→                    <input
   306→                      type="text"
   307→                      value={newRepFreq}
   308→                      onChange={e => setNewRepFreq(e.target.value)}
   309→                      placeholder="MHz"
   310→                      className="border border-gray-300 rounded px-1.5 py-0.5 text-xs font-mono w-20 focus:outline-none focus:ring-1 focus:ring-blue-500"
   311→                    />
   312→                    <input
   313→                      type="text"
   314→                      value={newRepCallsign}
   315→                      onChange={e => setNewRepCallsign(e.target.value.toUpperCase())}
   316→                      placeholder="Rufz."
   317→                      className="border border-gray-300 rounded px-1.5 py-0.5 text-xs font-mono uppercase w-20 focus:outline-none focus:ring-1 focus:ring-blue-500"
   318→                    />
   319→                    <button
   320→                      onClick={() => addRepeater(bl.code)}
   321→                      className="bg-green-600 hover:bg-green-700 text-white px-2 py-0.5 rounded text-xs"
   322→                    >
   323→                      OK
   324→                    </button>
   325→                    <button
   326→                      onClick={() => { setAddRepBl(null); setNewRepName(''); setNewRepFreq(''); setNewRepCallsign(''); }}
   327→                      className="text-gray-400 hover:text-gray-600 text-xs"
   328→                    >
   329→                      Abbrechen
   330→                    </button>
   331→                  </div>
   332→                )}
   333→                <div className="divide-y divide-gray-100">
   334→                  {blBezirke.map(bz => {
   335→                    const bzReports = blReports.filter(r => r.bezirk_code === bz.code);
   336→                    return (
   337→                      <BezirkRow
   338→                        key={bz.code}
   339→                        bezirk={bz}
   340→                        reports={bzReports}
   341→                        availableBezirke={blBezirke}
   342→                        linkedRepeaters={linkedRepeaters}
   343→                        defaultRepeaterId={defaultRepId}
   344→                        onSubmit={(repeaterId, form) => handleBezirkSubmit(bz.code, repeaterId, form)}
   345→                        onEdit={handleEdit}
   346→                        onDelete={handleDelete}
   347→                        onMoveToBezirk={handleMoveToBezirk}
   348→                        editingId={editingId}
   349→                        editForm={editForm}
   350→                        onEditChange={setEditForm}
   351→                        onEditSave={handleUpdate}
   352→                        onEditCancel={() => setEditingId(null)}
   353→                        dragReportId={dragReportId}
   354→                        onDragStart={setDragReportId}
   355→                        onDragEnd={() => setDragReportId(null)}
   356→                      />
   357→                    );
   358→                  })}
   359→                  {/* Sonstige — reports without matching bezirk + entry form */}
   360→                  {(() => {
   361→                    const bzCodes = new Set(blBezirke.map(b => b.code));
   362→                    const unassigned = blReports.filter(r => !r.bezirk_code || !bzCodes.has(r.bezirk_code));
   363→                    return (
   364→                      <BezirkRow
   365→                        bezirk={{ code: '??', name: 'Sonstige', is_capital: false }}
   366→                        reports={unassigned}
   367→                        availableBezirke={blBezirke}
   368→                        linkedRepeaters={linkedRepeaters}
   369→                        defaultRepeaterId={defaultRepId}
   370→                        onSubmit={(repeaterId, form) => handleBezirkSubmit('??', repeaterId, form)}
   371→                        onEdit={handleEdit}
   372→                        onDelete={handleDelete}
   373→                        onMoveToBezirk={handleMoveToBezirk}
   374→                        editingId={editingId}
   375→                        editForm={editForm}
   376→                        onEditChange={setEditForm}
   377→                        onEditSave={handleUpdate}
   378→                        onEditCancel={() => setEditingId(null)}
   379→                        dragReportId={dragReportId}
   380→                        onDragStart={setDragReportId}
   381→                        onDragEnd={() => setDragReportId(null)}
   382→                      />
   383→                    );
   384→                  })()}
   385→                </div>
   386→              </div>
   387→            )}
   388→          </div>
   389→        );
   390→      })}
   391→    </div>
   392→  );
   393→}

   415→function BezirkRow({ bezirk, reports, availableBezirke, linkedRepeaters, defaultRepeaterId, onSubmit, onEdit, onDelete, onMoveToBezirk, editingId, editForm, onEditChange, onEditSave, onEditCancel, dragReportId, onDragStart, onDragEnd }: BezirkRowProps) {
   416→  const [form, setForm] = useState<EntryForm>({ callsign: '', operator: null, rapport: '5/9', notes: '', opName: '', opQth: '', bezirkCode: '' });
   417→  const [repeaterId, setRepeaterId] = useState(defaultRepeaterId);
   418→  const [dragOver, setDragOver] = useState(false);
   419→  const callsignRef = useRef<CallsignInputRef>(null);
   420→  const rapportRef = useRef<HTMLInputElement>(null);
   421→
   422→  useEffect(() => {
   423→    if (defaultRepeaterId && !repeaterId) setRepeaterId(defaultRepeaterId);
   424→  }, [defaultRepeaterId]);
   425→
   426→  const handleSubmit = (e: FormEvent) => {
   427→    e.preventDefault();
   428→    if (!form.callsign && !form.operator) return;
   429→    if (!repeaterId) return;
   430→    onSubmit(repeaterId, form);
   431→    setForm({ callsign: '', operator: null, rapport: '5/9', notes: '', opName: '', opQth: '', bezirkCode: '' });
   432→    setTimeout(() => callsignRef.current?.focus(), 50);
   433→  };
   434→
   435→  const handleDrop = (e: React.DragEvent) => {
   436→    e.preventDefault();
   437→    setDragOver(false);
   438→    if (dragReportId) {
   439→      const targetCode = bezirk.code === '??' ? null : bezirk.code;
   440→      onMoveToBezirk(dragReportId, targetCode);
   441→    }
   442→  };
   443→
   444→  const saveOperatorField = (field: 'name' | 'qth', value: string) => {
   445→    if (!form.operator?.id) return;
   446→    const original = field === 'name' ? (form.operator.name || '') : (form.operator.qth || '');
   447→    if (value === original) return;
   448→    apiFetch(`/api/v1/operators/${form.operator.id}`, {
   449→      method: 'PATCH',
   450→      body: JSON.stringify({ [field]: value || null }),
   451→    }).then(() => {
   452→      setForm(f => ({ ...f, operator: { ...f.operator, [field]: value || null } }));
   453→    }).catch(() => {});
   454→  };
   455→
   456→  return (
   457→    <div
   458→      className={`px-2 sm:px-3 py-1.5 transition-colors ${dragOver && dragReportId ? 'bg-blue-100 ring-2 ring-blue-400 ring-inset' : ''}`}
   459→      onDragOver={e => { if (dragReportId) { e.preventDefault(); setDragOver(true); } }}
   460→      onDragLeave={() => setDragOver(false)}
   461→      onDrop={handleDrop}
   462→    >
   463→      <div className="flex items-center gap-1.5 sm:gap-2 mb-1">
   464→        <span className={`text-xs font-mono px-1.5 py-0.5 rounded text-white ${bezirk.code === '??' ? 'bg-[#ffc107] text-gray-800' : bezirk.is_capital ? 'bg-[#dc3545]' : 'bg-[#6c757d]'}`}>
   465→          {bezirk.code === '??' ? '??' : bezirk.code}
   466→        </span>
   467→        <span className="text-xs text-gray-500 truncate">{bezirk.name}</span>
   468→        {reports.length > 0 && <span className="text-xs text-gray-400 flex-shrink-0">({reports.length})</span>}
   469→      </div>
   470→
   471→      {reports.length > 0 && (
   472→        <table className="w-full text-xs mb-1">
   473→          <tbody>
   474→            {reports.map((r, idx) => (
   475→              <tr
   476→                key={r.id}
   477→                className={`hover:bg-blue-50 group ${dragReportId === r.id ? 'opacity-40' : ''}`}
   478→                draggable={editingId !== r.id}
   479→                onDragStart={e => { e.dataTransfer.effectAllowed = 'move'; onDragStart(r.id); }}
   480→                onDragEnd={onDragEnd}
   481→              >
   482→                {editingId === r.id ? (
   483→                  <td colSpan={6} className="py-0.5">

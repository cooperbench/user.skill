# Issue #2: Simplex Bezirk Grouping Toggle

## Context
GitHub Issue #2 — "Option Bezirkskenner in Simplex Frequenzen anzuzeigen". Currently, simplex frequencies in LandMode render as flat lists (FlatReportRow) without Bezirk grouping, because simplex repeaters have `bundesland_code=null` so `repBezirke` is always empty. The user wants an optional per-exercise toggle to group simplex frequency reports by Bundesland → Bezirk, matching how repeater reports are structured. The toggle must be off by default since "nicht überall braucht man bundesland bezirk."

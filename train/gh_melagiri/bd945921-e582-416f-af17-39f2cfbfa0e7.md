## Two Distinct Issues Found

### Issue 1: PostHog Ingest — 503 Errors

All requests to `https://code-insights.app/ingest/...` are returning **503 Service Unavailable**.

The Vercel rewrite config in `code-insights-web/vercel.json` looks correct — it proxies `/ingest/:path*` → `https://us.i.posthog.com/:path*`. The 503 suggests either:
- PostHog's US ingestion endpoint (`us.i.posthog.com`) is temporarily down or rate-limiting
- The Vercel proxy itself is having issues forwarding

This is **non-critical** — telemetry failures are silent by design and don't affect functionality. The PostHog SDK's retry loop (visible as `retry_count=1,2,3`) is expected behavior when the endpoint is unreachable.

### Issue 2: Prompt Quality Tab — React Error #31 (THE CRASH)

**Root cause confirmed.** The `bullets` field in the prompt quality insight contains **objects** with keys `{tip, example}`, but the rendering code in `PromptQualityCard.tsx:213` expects plain strings:

```tsx
// Line 213 — expects string[], but gets {tip, example}[]
{bullets.map((tip, i) => (
  <li key={i}>{tip}</li>  // ← React can't render an object as a child
))}
```

Actual data from the API:
```json
[
  { "tip": "Intervene when automated processes are clearly failing...", "example": "After the second or third time..." },
  { "tip": "Continue using high-level, sequential goals..." }
]
```

React throws Error #31 because it tries to render the `{tip, example}` object directly as a child node.

`★ Insight ─────────────────────────────────────`
- **React Error #31** is React's way of saying "you passed an object where a string/number/element was expected." The URL in the error even tells you the keys: `{tip, example}`.
- This is a **data shape mismatch** — the LLM that generated the prompt quality analysis returned structured tip objects instead of plain string bullets. The component assumed `string[]` but got `{tip, string}[]`.
- This is a common pitfall with LLM-generated structured data: the schema can drift between sessions since different LLM responses may use different structures.
`─────────────────────────────────────────────────`

---

## Proposed Fix

**For Issue 2 (the crash):** Update the Tips section in `PromptQualityCard.tsx` to handle both formats — plain strings and `{tip, example}` objects. This is the only code change needed.

**For Issue 1 (PostHog 503s):** This is likely transient. We can verify by checking if `code-insights.app/ingest` is resolving correctly, but the dashboard won't break from this — telemetry is fire-and-forget.

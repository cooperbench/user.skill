This is intentional separation of concerns: `sync` owns session metadata + messages (derived from source files), while `insights` owns the LLM-generated analysis. They write to different tables and never step on each other. The `COALESCE(sessions.generated_title, excluded.generated_title)` on line 107 is a good example of this philosophy — it explicitly preserves the existing value when present.

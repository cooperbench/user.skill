# Stash

**Your AI has amnesia. We fixed it.**

Every LLM starts every conversation from zero. Stash gives your agent persistent memory — it remembers, recalls, consolidates, and learns across sessions. No more explaining yourself from scratch.

Open source. Self-hosted. Works with any MCP-compatible agent.

git clone https://github.com/alash3al/stash.git

Works with Claude Desktop, Cursor, Windsurf, Cline, Continue, OpenAI Agents, Ollama, OpenRouter — anything MCP.

Here's the init flow tailored for your Mac + host-bound Ollama. Stash ships its own Postgres+pgvector via Docker Compose, so it stays isolated from your Raven stack.

## 1. Clone alongside Raven (don't nest it inside)

```bash

ollama pull qwen2.5:14b          # ~9GB — reasoner (or llama3.1:8b if you want lighter)
```

## 3. Edit `.env` — point Stash at Ollama via `host.docker.internal`

The Stash container reaches your host's Ollama through Docker Desktop's host alias:

```env
STASH_OPENAI_API_KEY=ollama
STASH_OPENAI_BASE_URL=http://host.docker.internal:11434/v1

REDACTED
STASH_VECTOR_DIM=768                # MUST match nomic-embed-text (use 1024 for mxbai-embed-large)

STASH_REASONER_MODEL=qwen2.5:14b
```

Leave the rest (`STASH_POSTGRES_DSN`, TTLs, consolidation thresholds) as-is — its bundled Postgres at service `postgres:5432` works out of the box.

## 4. Boot it

```bash
docker compose up -d
docker compose logs -f stash      # watch migrations + MCP server come up
```

Server listens on `:8080` (HTTP) and exposes the MCP endpoint for Claude/Cursor/etc.

## 5. Wire it into Claude Code (optional but the point of the tool)

Add to your `~/.claude/mcp.json` (or project `.mcp.json`):

```json
{
  "mcpServers": {
    "stash": { "type": "http", "url": "http://localhost:8080/mcp" }
  }
}
```

## Two gotchas to verify

- **Bind, not just listen.** `OLLAMA_HOST=0.0.0.0:11434` must be set in the launchd plist / shell that started Ollama, not just the current terminal — otherwise `host.docker.internal` will hit a closed port. Verify: `curl http://localhost:11434/v1/models` from a fresh shell.
- **Embedding dim is load-bearing.** If you ever swap the embedding model, you must re-init the DB — pgvector columns are typed by dimension. Picking `nomic-embed-text` (768) now and switching to `mxbai-embed-large` (1024) later means dropping the Stash volume.

Don't co-locate Stash's Postgres with Raven's PG18 — Stash is a separate concern with its own schema; mixing them just creates coupling pain.

### Your AI > Memory organized

## Memory organized  
like _folders._

Not all memory is equal. What your agent learns about _you_ is different from what it learns about a _project_, which is different from what it knows about _itself_. Namespaces let the agent organize what it learns into clean, separate buckets — just like folders on your computer.

Each namespace is a path. Paths are hierarchical. Reading from `/projects` automatically includes everything under `/projects/stash`, `/projects/cartona`, and so on. You never have to think about it — the agent does.

📁 Write to one namespace. Read from any subtree.

example namespace structure

📁 / everything

📁 /users/alice who alice is, her preferences

📁 /projects all projects

📁 /projects/restaurant-saas pricing, features, decisions

📁 /projects/mobile-app design, tech stack, goals

📁 /self agent self-knowledge

📄 /self/capabilities what I do well

📄 /self/limits what I struggle with

📄 /self/preferences how I work best

🔍

Recursive reads

Recall from `/projects` and get everything across all sub-projects automatically.

✏️

Precise writes

Remember always targets one exact namespace — no accidental cross-contamination.

🔒

Clean separation

User memory never mixes with project memory. Agent self-knowledge stays in `/self`.

- No CLI tool for app/IDP management — everything requires browser UI

**Why:** Auth connector should be pluggable, not tightly coupled to one provider.
**How to apply:** Use a simpler auth solution (SuperTokens, Better Auth) or make the auth layer pluggable.

  ```

  ```bash
  golangci-lint run --disable-all --enable revive,govet,errcheck,staticcheck ./...
  ```
- **Python** (`ruff`): Always run before pushing any Python file changes:
  ```bash
  ruff format --check <changed_files>   # check only
  ruff format <changed_files>           # auto-fix
  ruff check <changed_files>            # lint check
  ```
- **Python worktrees**: The `ai-worker/` subdirectory uses ruff. Run from the worktree root.
- Never claim "lint passed locally" if the command was killed before producing output.

## open PR dependency rule

### fb_pr_dep
name: Do Not Start Issues Dependent on Open PRs
description: Skip any issue whose prerequisite is currently in an open/unmerged PR
type: feedback

### fb_pr_dep
Before starting work on any issue, check whether its dependencies are already covered by open PRs that have NOT yet merged.

- If an issue's prerequisite is in an open/unmerged PR → **do not start it**
- If an issue is already covered by an open PR → **do not touch it**
- Only pick up issues that are fully independent (all prerequisites are in merged/closed state)

**Why:** The pre-requisite might not be met when work begins, causing wasted effort and broken branches.

**How to apply:** Before picking up any issue, run `gh pr list --state open` and cross-check all stated issue dependencies. If any dependency is in an open PR, skip that issue and pick the next independent one.

> AGENT

**Tesseract.js** is the closest match — it's a full OCR engine that runs in the browser via WebAssembly, loadable from a CDN: ```html <script src="https://cdn.jsdelivr.net/npm/tesseract.js@5/dist/tesseract.min.js"></script> ``` ```js const worker = await Tesseract.createWorker('eng'); const { data: { text } } = await worker.recognize(imageOrCanvas); console.log(text); ``` **Caveats:** Tesseract.js is decent for printed text but its handwriting recognition is mediocre. There's no true "MediaPipe-quality" browser-native handwriting recognizer yet. **Other browser-friendly options:** - **TensorFlow.js** — You can load a handwriting model (like one trained on IAM dataset) and run inference client-side, but you'd need to find/train the model yourself - **ONNX Runtime Web** — Same idea, lets you run models like TrOCR in-browser via WebAssembly/WebGL, but heavier - **HandwritingRecognition API** (Chrome origin trial) — A proposed browser API (`navigator.createHandwritingRecognizer()`) for real-time stylus/touch input recognition. Chrome-only and experimental. If you want the simplest CDN drop-in, **Tesseract.js** is the way to go. Want me to look at your project and wire it up?

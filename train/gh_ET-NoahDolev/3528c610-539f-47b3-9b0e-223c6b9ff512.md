# Fix Protocol Status & Review Page Visibility During Grounding

## Context

Two related bugs in the current pipeline:

1. **CriteriaBatch is created with `status="pending_review"` in `parse_node` (line 95)** — before grounding even starts. This makes the batch appear in the Review Queue immediately, with a misleading "pending review" status while entities are still being grounded.

2. **ProtocolDetail shows the "Review Criteria" button for any protocol that has a batch**, regardless of whether the protocol is still processing (`grounding`, `extracting`, `uploaded`). Users can click through to the ReviewPage while grounding is in-flight.

The correct behavior: batches should start in a `"grounding"` status that indicates they're not yet ready for review, transition to `"pending_review"` only after the persist node completes, and the UI should hide the review link while the protocol is still processing.

---

## Step 1: Fix CriteriaBatch initial status (backend)

**File:** `services/protocol-processor-service/src/protocol_processor/nodes/parse.py` (line 95)

Change:
```python
batch = CriteriaBatch(
    protocol_id=state["protocol_id"],
    status="pending_review",       # ← wrong: grounding hasn't started
    extraction_model=extraction_model,
)
```
To:
```python
batch = CriteriaBatch(
    protocol_id=state["protocol_id"],
    status="grounding",            # ← correct: matches protocol.status
    extraction_model=extraction_model,
)
```

## Step 2: Set batch to `pending_review` after grounding completes (backend)

**File:** `services/protocol-processor-service/src/protocol_processor/nodes/persist.py` (line 230)

Change:
```python
batch.status = "entities_grounded"
```
To:
```python
batch.status = "pending_review"
```

This means the batch transitions: `grounding` → `pending_review` (success) or stays `grounding` (if protocol goes to `grounding_failed`). The `entities_grounded` status was only ever set here and never used as a filter or display value in the frontend — it was a dead-end status.

## Step 3: Hide "Review Criteria" button during processing (frontend)

**File:** `apps/hitl-ui/src/screens/ProtocolDetail.tsx` (lines 472-488)

Currently the action section shows a review button whenever `latestBatch` exists, regardless of protocol status. Wrap the review buttons so they only show when the protocol is in a reviewable state (not actively processing).

Replace:
```tsx
{latestBatch && protocol.status === 'pending_review' && (
    <Button onClick={() => navigate(`/reviews/${latestBatch.id}`)}>
        <ClipboardList className="h-4 w-4 mr-2" />
        Review New Criteria ({latestBatch.criteria_count})
    </Button>

{latestBatch && protocol.status !== 'pending_review' && (
    <Button onClick={() => navigate(`/reviews/${latestBatch.id}`)}>
        <ClipboardList className="h-4 w-4 mr-2" />
        Review Criteria ({latestBatch.criteria_count})
    </Button>

```

With:
```tsx
{latestBatch && REVIEW_VISIBLE_STATUSES.has(protocol.status) && (
    <Button onClick={() => navigate(`/reviews/${latestBatch.id}`)}>
        <ClipboardList className="h-4 w-4 mr-2" />
        {protocol.status === 'pending_review' ? 'Review New' : 'Review'} Criteria ({latestBatch.criteria_count})

```

Add a constant near the existing `RE_EXTRACT_ALLOWED_STATUSES`:
```tsx
const REVIEW_VISIBLE_STATUSES = new Set([
    'pending_review',
    'complete',
    'grounding_failed',   // may want to review partial results
```

## Step 4: Exclude non-reviewable batches from Review Queue (backend)

**File:** `services/api-service/src/api_service/reviews.py` (lines 197-218)

The batch list API currently excludes only archived batches. Add an additional filter to exclude batches in `grounding` status (since they're not ready for review). This prevents in-progress batches from appearing in the queue even when "All" status filter is selected.

## Step 5: Update CriteriaBatch type in frontend (cosmetic)

```
   777→def _update_batch_status(db: Session, batch_id: str) -> None:
   778→    """Update a batch's status based on its criteria review progress.
   779→
   780→    Transitions:
   781→    - pending_review -> in_progress (first review submitted)
   782→    - in_progress -> approved (all criteria reviewed, none rejected)
   783→    - in_progress -> rejected (all criteria reviewed, any rejected)
   784→    - in_progress -> reviewed (all criteria reviewed, mixed results)
   785→    """

   787→    if not batch:
   788→        return
   789→
   790→    total_count = db.exec(
   791→        select(func.count()).select_from(Criteria).where(Criteria.batch_id == batch.id)
   792→    ).one()
   793→
   794→    reviewed_count = db.exec(
   795→        select(func.count())
   796→        .select_from(Criteria)
   797→        .where(
   798→            Criteria.batch_id == batch.id,
   799→            col(Criteria.review_status).isnot(None),
   800→        )
   801→    ).one()
   802→
   803→    # First review submitted: pending_review -> in_progress
   804→    if batch.status == "pending_review" and reviewed_count >= 1:
   805→        batch.status = "in_progress"
   806→
   807→    # All criteria reviewed: determine final status
   808→    if reviewed_count == total_count and total_count > 0:
   809→        rejected_count = db.exec(
   810→            select(func.count())
   811→            .select_from(Criteria)
   812→            .where(
   813→                Criteria.batch_id == batch.id,
   814→                Criteria.review_status == "rejected",
   815→            )
   816→        ).one()
   817→
   818→        approved_count = db.exec(
   819→            select(func.count())
   820→            .select_from(Criteria)
   821→            .where(
   822→                Criteria.batch_id == batch.id,
   823→                Criteria.review_status == "approved",
   824→            )
   825→        ).one()
   826→
   827→        # Terminal state transitions
   828→        if rejected_count > 0:
   829→            batch.status = "rejected"  # Any rejected = batch rejected
   830→        elif approved_count == total_count:
   831→            batch.status = "approved"  # All approved = batch approved
   832→        else:
   833→            batch.status = "reviewed"  # Mixed or modified = batch reviewed
```

```
    67→def _reconcile_dual_grounding(
    68→    result: EntityGroundingResult,
    69→    omop_result: OmopLookupResult,
    70→) -> EntityGroundingResult:
    71→    """Reconcile TerminologyRouter + OMOP mapper results.
    72→
    73→    Sets omop_concept_id and reconciliation_status on the result:
    74→    - Both succeed → "agree" (high confidence) or "disagreement"
    75→    - Only TerminologyRouter → "omop_missing"
    76→    - Only OMOP → "tooluniverse_missing"
    77→    - Neither → no change (existing expert_review behavior)
    78→
    79→    Agreement is checked by comparing the OMOP concept_name against
    80→    the ToolUniverse preferred_term (fuzzy match).
    81→
    82→    Args:
    83→        result: EntityGroundingResult from TerminologyRouter path.
    84→        omop_result: OmopLookupResult from OMOP mapper path.
    85→
    86→    Returns:
    87→        The same EntityGroundingResult, mutated with OMOP fields.
    88→    """
    89→    tu_ok = result.selected_code is not None
    90→    omop_ok = omop_result.omop_concept_id is not None
    91→
    92→    if tu_ok and omop_ok:
    93→        result.omop_concept_id = omop_result.omop_concept_id
    94→        # Fuzzy agreement check using token_set_ratio (order-insensitive)
    95→        tu_term = (result.preferred_term or "").lower()
    96→        omop_term = (omop_result.omop_concept_name or "").lower()
    97→        if tu_term and omop_term and fuzz.token_set_ratio(tu_term, omop_term) >= 80:
    98→            result.reconciliation_status = "agree"
    99→        else:
   100→            result.reconciliation_status = "disagreement"
   101→        logger.info(
   102→            "Dual grounding for '%s': TU=%s, OMOP=%s, status=%s",
   103→            result.entity_text[:50],
   104→            result.selected_code,
   105→            omop_result.omop_concept_id,
   106→            result.reconciliation_status,
   107→        )
   108→    elif tu_ok and not omop_ok:
   109→        result.reconciliation_status = "omop_missing"
   110→    elif not tu_ok and omop_ok:
   111→        result.omop_concept_id = omop_result.omop_concept_id
   112→        result.reconciliation_status = "tooluniverse_missing"
   113→    # else: neither — leave as-is (expert_review path)
   114→
   115→    return result

   202→async def _ground_entity_with_retry(
   203→    entity: dict[str, Any],
   204→    router: TerminologyRouter,
   205→    criterion_text: str,
   206→) -> tuple[EntityGroundingResult, int]:
   207→    """Ground a single entity with agentic retry loop (max 3 attempts).
   208→
   209→    Implements the MedGemma agentic reasoning loop:
   210→    1. Initial grounding via TerminologyRouter + MedGemma
   211→    2. If low confidence, ask MedGemma 3 questions (valid? derived? rephrase?)
   212→    3. Retry with reformulated query (up to 2 more attempts, 3 total)
   213→    4. After 3 failed attempts, mark for expert_review
   214→
   215→    Args:
   216→        entity: Entity dict with text, entity_type, criterion_id.
   217→        router: TerminologyRouter singleton for API dispatch.
   218→        criterion_text: Full criterion text for context.
   219→
   220→    Returns:
   221→        Tuple of (EntityGroundingResult, attempt_count). May have expert_review
   222→        marker in reasoning.
   223→    """
   224→    entity_text = entity.get("text", "")
   225→    entity_type = entity.get("entity_type", "")
   226→
   227→    # Step 1: Route entity through TerminologyRouter to get candidates
   228→    candidates = await router.route_entity(entity_text, entity_type)
   229→
   230→    # Log when TerminologyRouter returns empty
   231→    apis = router.get_apis_for_entity(entity_type)
   232→    if not candidates:
   233→        if not apis:
   234→            logger.info(
   235→                "Entity '%s' (type=%s) skipped by TerminologyRouter"
   236→                " — no APIs configured for this type",
   237→                entity_text[:50],
   238→                entity_type,
   239→            )
   240→            # No APIs configured → route directly to expert_review
   241→            return (
   242→                EntityGroundingResult(
   243→                    entity_text=entity_text,
   244→                    entity_type=entity_type,
   245→                    selected_code=None,
   246→                    selected_system=None,
   247→                    preferred_term=None,
   248→                    confidence=0.0,
   249→                    candidates=[],
   250→                    reasoning=(
   251→                        "[expert_review] No terminology APIs configured "
   252→                        f"for entity type '{entity_type}'. "
   253→                        "Routed to expert review."
   254→                    ),
   255→                ),
   256→                1,
   257→            )
   258→        else:
   259→            logger.info(
   260→                "Entity '%s' (type=%s) returned zero candidates from all APIs",
   261→                entity_text[:50],
   262→                entity_type,
   263→            )
   264→
   265→    # Step 2: MedGemma selects best match from candidates
   266→    result = await medgemma_decide(entity, candidates, criterion_text)
   267→
   268→    # Step 3: Agentic retry loop — max 3 attempts total
   269→    attempt = 1
   270→    current_query = entity_text
   271→    while (
   272→        result.selected_code is None
   273→        and result.confidence < 0.5
   274→        and attempt < 3
   275→        and router.get_apis_for_entity(entity_type)
   276→    ):
   277→        attempt += 1
   278→        reasoning_result = await agentic_reasoning_loop(
   279→            entity={**entity, "_previous_query": current_query},
   280→            criterion_context=criterion_text,
   281→            router=router,
   282→            attempt=attempt,
   283→        )
   284→
   285→        if reasoning_result.should_skip:
   286→            logger.info(
   287→                "Entity '%s' marked non-medical by agentic reasoning"
   288→                " (attempt %d) — skipping",
   289→                entity_text[:50],
   290→                attempt,
   291→            )
   292→            return (
   293→                EntityGroundingResult(
   294→                    entity_text=entity_text,
   295→                    entity_type=entity_type,
   296→                    selected_code=None,
   297→                    selected_system=None,
   298→                    preferred_term=None,
   299→                    confidence=0.0,
   300→                    candidates=[],
   301→                    reasoning=(
   302→                        f"Skipped by agentic reasoning (attempt {attempt}): "
   303→                        f"{reasoning_result.reasoning}"
   304→                    ),
   305→                ),
   306→                attempt,
   307→            )
   308→
   309→        new_query = (
   310→            reasoning_result.rephrased_query
   311→            or reasoning_result.derived_term
   312→            or reasoning_result.gemini_suggestion
   313→            or current_query
   314→        )
   315→        current_query = new_query
   316→
   317→        logger.info(
   318→            "Agentic retry (attempt %d) for '%s' using query '%s'",
   319→            attempt,
   320→            entity_text[:50],
   321→            new_query[:50],
   322→        )
   323→
   324→        new_candidates = await router.route_entity(new_query, entity_type)
   325→        if new_candidates:
   326→            retry_entity = {**entity, "text": new_query}
   327→            result = await medgemma_decide(retry_entity, new_candidates, criterion_text)
   328→            if result.selected_code and result.confidence >= 0.5:
   329→                # Success — preserve original entity_text
   330→                return (
   331→                    EntityGroundingResult(
   332→                        entity_text=entity_text,
   333→                        entity_type=result.entity_type,
   334→                        selected_code=result.selected_code,
   335→                        selected_system=result.selected_system,
   336→                        preferred_term=result.preferred_term,
   337→                        confidence=result.confidence,
   338→                        candidates=result.candidates,
   339→                        reasoning=(
   340→                            f"[Attempt {attempt}, query='{new_query}'] "
   341→                            f"{result.reasoning}"
   342→                        ),
   343→                        field_mappings=result.field_mappings,
   344→                    ),
   345→                    attempt,
   346→                )
   347→
   348→    # Route to expert_review if all attempts exhausted without success
   349→    if result.selected_code is None and attempt >= 2:
   350→        logger.warning(
   351→            "Entity '%s' (type=%s) routed to expert_review after"
   352→            " %d failed grounding attempts",
   353→            entity_text[:50],
   354→            entity_type,
   355→            attempt,
   356→        )
   357→        return (
   358→            EntityGroundingResult(
   359→                entity_text=result.entity_text,
   360→                entity_type=result.entity_type,
   361→                selected_code=result.selected_code,
   362→                selected_system=result.selected_system,
   363→                preferred_term=result.preferred_term,
   364→                confidence=result.confidence,
   365→                candidates=result.candidates,
   366→                reasoning=(
   367→                    f"[expert_review] Routed to expert review after "
   368→                    f"{attempt} failed grounding attempts. "
   369→                    f"Last reasoning: {result.reasoning}"
   370→                ),
   371→            ),
   372→            attempt,
   373→        )
   374→
   375→    return (result, attempt)

   378→def _ground_categorical_values(  # noqa: C901
   379→    mappings: list[dict[str, Any]],
   380→) -> list[dict[str, Any]]:
   381→    """Ground categorical values in field mappings using unit_normalizer.
   382→
   383→    For standard-type mappings with non-numeric values (e.g. "Severe",
   384→    "positive", "NYHA Class III"), attempt to resolve a value_concept_id
   385→    using the unit_normalizer's value lookup.
   386→
   387→    This is a best-effort post-processing step — failures don't block
   388→    the grounding result.
   389→
   390→    Args:
   391→        mappings: List of field mapping dicts from generate_field_mappings.
   392→
   393→    Returns:
   394→        The same list with value_concept_id populated where possible.
   395→    """
   396→    numeric_re = re.compile(r"^[\d.,\-]+$")
   397→
   398→    # Safety-net: normalize common LLM-generated categorical values
   399→    # to canonical boolean form for expression-tree consistency.
   400→    _value_norm = {
   401→        "present": "True",
   402→        "confirmed": "True",
   403→        "positive": "True",
   404→        "yes": "True",
   405→        "absent": "False",
   406→        "negative": "False",
   407→        "not present": "False",
   408→        "no": "False",
   409→    }
   410→
   411→    for mapping in mappings:
   412→        try:
   413→            value_obj = mapping.get("value", {})
   414→            if not isinstance(value_obj, dict):
   415→                continue
   416→
   417→            # Only process standard-type values
   418→            if value_obj.get("type") != "standard":
   419→                continue
   420→
   421→            val_text = value_obj.get("value")
   422→            if not val_text or not isinstance(val_text, str):
   423→                continue
   424→
   425→            # Skip numeric values — they don't need concept grounding
   426→            if numeric_re.match(val_text.strip()):
   427→                continue
   428→
   429→            # Normalize "present"/"confirmed"/"absent" → "True"/"False"
   430→            canonical = _value_norm.get(val_text.strip().lower())
   431→            if canonical is not None:
   432→                value_obj["value"] = canonical
   433→                val_text = canonical
   434→                logger.debug(
   435→                    "Normalized categorical value '%s' → '%s'",
   436→                    val_text,
   437→                    canonical,
   438→                )
   439→
   440→            # If value was normalized to boolean, also normalize relation
   441→            if canonical is not None:
   442→                rel = mapping.get("relation", "")
   443→                if rel in ("contains", "has", "is"):
   444→                    mapping["relation"] = "="
   445→                elif rel in ("not_contains", "not"):
   446→                    mapping["relation"] = "!="
   447→
   448→            # Already grounded
   449→            if mapping.get("value_concept_id"):
   450→                continue
   451→
   452→            # Try unit_normalizer's categorical value lookup (fast path)
   453→            normalized_text, concept_id = normalize_value(val_text)
   454→            if concept_id is not None:
   455→                mapping["value_concept_id"] = str(concept_id)
   456→                mapping["value_concept_system"] = "OMOP"
   457→                logger.debug(
   458→                    "Grounded categorical value '%s' → concept_id=%s",
   459→                    val_text,
   460→                    concept_id,
   461→                )
   462→        except Exception as e:
   463→            logger.debug("Categorical value grounding failed for mapping: %s", e)
   464→
   465→    return mappings

   468→async def _ground_entity_parallel(
   469→    entity: dict[str, Any],
   470→    router: TerminologyRouter,
   471→    criterion_text: str,
   472→    entity_num: int,
   473→    total: int,
   474→    semaphore: asyncio.Semaphore,
   475→) -> tuple[EntityGroundingResult | None, str | None, float, int]:
   476→    """Ground a single entity with concurrency control and timing.
   477→
   478→    Acquires the semaphore before grounding to cap concurrent API calls.
   479→    Returns a (result, error) tuple for error isolation -- one entity failure
   480→    does not crash others in the asyncio.gather batch.
   481→
   482→    Args:
   483→        entity: Entity dict with text, entity_type, criterion_id.
   484→        router: TerminologyRouter singleton for API dispatch.
   485→        criterion_text: Full criterion text for context.
   486→        entity_num: 1-based index for logging.
   487→        total: Total entity count for logging.
   488→        semaphore: Concurrency limiter (Semaphore(4)).
   489→
   490→    Returns:
   491→        (EntityGroundingResult, None, elapsed_ms, retry_attempts) on success,
   492→        or (None, error_message, elapsed_ms, 0) on failure.
   493→    """
   494→    async with semaphore:
   495→        entity_text = entity.get("text", "")[:50]
   496→        entity_type = entity.get("entity_type", "")
   497→        start = time.monotonic()
   498→        logger.info(
   499→            "Grounding entity %d/%d: '%s' (type=%s) — start",
   500→            entity_num,
   501→            total,
   502→            entity_text,
   503→            entity_type,
   504→        )
   505→        try:
   506→            # Dual grounding: run TerminologyRouter + OMOP mapper
   507→            # in parallel per entity (Phase 1a)
   508→            full_entity_text = entity.get("text", "")
   509→            acronym = _is_likely_acronym(full_entity_text)
   510→            tu_task = _ground_entity_with_retry(entity, router, criterion_text)
   511→            omop_task = lookup_omop_concept(
   512→                full_entity_text, entity_type, is_acronym=acronym
   513→            )
   514→            (result, retry_attempts), omop_result = await asyncio.gather(
   515→                tu_task, omop_task
   516→            )
   517→
   518→            # Reconcile dual grounding results
   519→            result = _reconcile_dual_grounding(result, omop_result)
   520→
   521→            # Thread criterion_id from parse into result
   522→            criterion_id = entity.get("criterion_id")
   523→            if criterion_id:
   524→                result.criterion_id = criterion_id
   525→
   526→            # Generate field mappings (same semaphore slot)
   527→            field_mappings = await generate_field_mappings(result, criterion_text)
   528→
   529→            # Post-process: ground categorical values in field mappings
   530→            if field_mappings:
   531→                field_mappings = _ground_categorical_values(field_mappings)
   532→
   533→            result.field_mappings = field_mappings if field_mappings else None
   534→
   535→            elapsed = time.monotonic() - start
   536→            elapsed_ms = elapsed * 1000
   537→            logger.info(
   538→                "Entity %d/%d '%s' grounded in %.1fs: code=%s, omop=%s, conf=%.2f",
   539→                entity_num,
   540→                total,
   541→                entity_text,
   542→                elapsed,
   543→                result.selected_code or "N/A",
   544→                result.omop_concept_id or "N/A",
   545→                result.confidence,
   546→            )
   547→            return (result, None, elapsed_ms, retry_attempts)
   548→        except Exception as e:
   549→            elapsed = time.monotonic() - start
   550→            elapsed_ms = elapsed * 1000
   551→            logger.error(
   552→                "Entity %d/%d '%s' failed in %.1fs: %s",
   553→                entity_num,
   554→                total,
   555→                entity_text,
   556→                elapsed,
   557→                e,
   558→            )
   559→            return (None, str(e), elapsed_ms, 0)

   562→async def ground_node(state: PipelineState) -> dict[str, Any]:  # noqa: C901
   563→    """Ground entities via TerminologyRouter + MedGemma.
   564→
   565→    Parses entities_json from state, routes each entity through TerminologyRouter
   566→    to get terminology candidates, then passes candidates to medgemma_decide for
   567→    best-match selection. Generates field mappings for each successfully grounded
   568→    entity.
   569→
   570→    Error accumulation: individual entity failures are logged and collected in
   571→    errors list. Processing continues with remaining entities. Only a total
   572→    failure to parse entities_json triggers a fatal error.
   573→
   574→    Args:
   575→        state: Current pipeline state with entities_json and protocol_id.
   576→
   577→    Returns:
   578→        Dict with grounded_entities_json and accumulated errors list,
   579→        or fatal error dict if entities_json cannot be parsed.
   580→    """
   581→    from protocol_processor.tracing import pipeline_span
   582→
   583→    if state.get("error"):
   584→        return {}
   585→
   586→    protocol_id = state.get("protocol_id", "")
   587→    with pipeline_span(
   588→        "ground_node", span_type="TOOL", protocol_id=protocol_id
   589→    ) as span:
   590→        span.set_inputs({"protocol_id": state.get("protocol_id", "")})
   591→
   592→        try:
   593→            entities_json = state.get("entities_json")
   594→            if not entities_json:
   595→                span.set_outputs({"error": "No entities_json in state"})
   596→                return {
   597→                    "error": "No entities_json in state — parse node may have failed",
   598→                }
   599→
   600→            entity_items: list[dict[str, Any]] = json.loads(entities_json)
   601→            protocol_id = state["protocol_id"]
   602→
   603→            span.set_inputs(
   604→                {
   605→                    "protocol_id": protocol_id,
   606→                    "entity_count": len(entity_items),
   607→                }
   608→            )
   609→
   610→            logger.info(
   611→                "Starting grounding for protocol %s: %d entities",
   612→                protocol_id,
   613→                len(entity_items),
   614→            )
   615→
   616→            # Fail fast: verify OMOP vocabulary is reachable before
   617→            # starting entity grounding. No silent fallback.
   618→            _get_omop_engine()
```

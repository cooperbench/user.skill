1. **Upload**: User uploads clinical trial protocol PDF
2. **Extract**: Gemini reads PDF → structured inclusion/exclusion criteria with:
   - Criterion text, type, temporal/numeric constraints
   - Entities extracted with types and spans
3. **Parse**: Convert extraction to entity objects linked to criteria
4. **Ground**: For each entity:
   - Route through TerminologyRouter to get candidates from UMLS/SNOMED/RxNorm/ICD-10/LOINC/HPO
   - MedGemma evaluates candidates → selects best match with confidence
   - Agentic retry loop if confidence < 0.5 (rephrase, re-search, retry)
   - Parallel OMOP lookup for CDM compatibility
5. **Persist**: Save grounded entities to DB, link to criteria, update protocol status → `pending_review`
6. **Structure**: Build expression tree from atomic conditions (AND/OR/NOT logic)
7. **Ordinal Resolve**: Detect scales (NYHA, ECOG) and map values to OMOP unit concepts
8. **Review**: Clinician reviews results in HITL UI, approves or corrects
9. **Export**: Generate:
   - **OHDSI CIRCE JSON**: Standard cohort definition format
   - **FHIR R4 Group**: Healthcare interoperability standard
   - **OMOP CDM SQL**: SQL to execute cohort on patient database

**Key Design Decisions** (per user requirements):
- **Dual grounding**: Both ToolUniverse (UMLS/terminology) and OMOP mapper run in parallel
- **Error accumulation**: Partial entity failures don't halt pipeline — collect errors alongside successes
- **Agentic reasoning**: MedGemma asks clarifying questions to handle hard-to-ground entities
- **Audit trail**: Every grounding decision logged with full context (candidates, reasoning, confidence)
- **LangGraph checkpointing**: Resume from last successful step on failure
- **Two-model architecture**: MedGemma for medical domain reasoning, Gemini for structured output parsing

    62→def _reconcile_dual_grounding(
    63→    result: EntityGroundingResult,
    64→    omop_result: OmopLookupResult,
    65→) -> EntityGroundingResult:
    66→    """Reconcile TerminologyRouter + OMOP mapper results.
    67→
    68→    Sets omop_concept_id and reconciliation_status on the result:
    69→    - Both succeed → "agree" (high confidence) or "disagreement"
    70→    - Only TerminologyRouter → "omop_missing"
    71→    - Only OMOP → "tooluniverse_missing"
    72→    - Neither → no change (existing expert_review behavior)
    73→
    74→    Agreement is checked by comparing the OMOP concept_name against
    75→    the ToolUniverse preferred_term (fuzzy match).
    76→
    77→    Args:
    78→        result: EntityGroundingResult from TerminologyRouter path.
    79→        omop_result: OmopLookupResult from OMOP mapper path.
    80→
    81→    Returns:
    82→        The same EntityGroundingResult, mutated with OMOP fields.
    83→    """
    84→    tu_ok = result.selected_code is not None
    85→    omop_ok = omop_result.omop_concept_id is not None
    86→
    87→    if tu_ok and omop_ok:
    88→        result.omop_concept_id = omop_result.omop_concept_id
    89→        # Fuzzy agreement check using token_set_ratio (order-insensitive)
    90→        tu_term = (result.preferred_term or "").lower()
    91→        omop_term = (omop_result.omop_concept_name or "").lower()
    92→        if tu_term and omop_term and fuzz.token_set_ratio(tu_term, omop_term) >= 80:
    93→            result.reconciliation_status = "agree"
    94→        else:
    95→            result.reconciliation_status = "disagreement"
    96→        logger.info(
    97→            "Dual grounding for '%s': TU=%s, OMOP=%s, status=%s",
    98→            result.entity_text[:50],
    99→            result.selected_code,
   100→            omop_result.omop_concept_id,
   101→            result.reconciliation_status,
   102→        )
   103→    elif tu_ok and not omop_ok:
   104→        result.reconciliation_status = "omop_missing"
   105→    elif not tu_ok and omop_ok:
   106→        result.omop_concept_id = omop_result.omop_concept_id
   107→        result.reconciliation_status = "tooluniverse_missing"
   108→    # else: neither — leave as-is (expert_review path)
   109→
   110→    return result

   113→def _log_grounding_audit(
   114→    session: Session,
   115→    protocol_id: str,
   116→    criterion_id: str,
   117→    entity: dict[str, Any],

   120→) -> None:
   121→    """Create an AuditLog entry for a grounding decision.
   122→
   123→    Records full details: entity, all candidates considered, selected code,
   124→    reasoning, and confidence. Provides the audit trail per user decision:
   125→    "All agent exchanges (MedGemma decisions, API calls, routing) are logged."
   126→
   127→    Args:
   128→        session: Active SQLModel session.
   129→        protocol_id: Protocol ID for context.
   130→        criterion_id: Criterion ID this entity belongs to.
   131→        entity: Entity dict from entities_json.

   133→        result: EntityGroundingResult from medgemma_decide.

   136→        event_type="entity_grounded",

   140→            "protocol_id": protocol_id,
   141→            "entity_text": result.entity_text,
   142→            "entity_type": result.entity_type,
   143→            "candidate_count": len(candidates),

   147→                    "code": c.code,
   148→                    "preferred_term": c.preferred_term,
   149→                    "score": c.score,
   150→                }
   151→                for c in candidates
   152→            ],
   153→            "selected_code": result.selected_code,
   154→            "selected_system": result.selected_system,
   155→            "preferred_term": result.preferred_term,
   156→            "confidence": result.confidence,
   157→            "reasoning": result.reasoning,
   158→            "omop_concept_id": result.omop_concept_id,
   159→            "reconciliation_status": result.reconciliation_status,
   160→        },
   161→    )
   162→    session.add(audit)

   197→async def _ground_entity_with_retry(
   198→    entity: dict[str, Any],
   199→    router: TerminologyRouter,
   200→    criterion_text: str,
   201→) -> tuple[EntityGroundingResult, int]:
   202→    """Ground a single entity with agentic retry loop (max 3 attempts).
   203→
   204→    Implements the MedGemma agentic reasoning loop:
   205→    1. Initial grounding via TerminologyRouter + MedGemma
   206→    2. If low confidence, ask MedGemma 3 questions (valid? derived? rephrase?)
   207→    3. Retry with reformulated query (up to 2 more attempts, 3 total)
   208→    4. After 3 failed attempts, mark for expert_review
   209→
   210→    Args:
   211→        entity: Entity dict with text, entity_type, criterion_id.
   212→        router: TerminologyRouter singleton for API dispatch.
   213→        criterion_text: Full criterion text for context.
   214→
   215→    Returns:
   216→        Tuple of (EntityGroundingResult, attempt_count). May have expert_review
   217→        marker in reasoning.
   218→    """
   219→    entity_text = entity.get("text", "")
   220→    entity_type = entity.get("entity_type", "")
   221→
   222→    # Step 1: Route entity through TerminologyRouter to get candidates
   223→    candidates = await router.route_entity(entity_text, entity_type)
   224→
   225→    # Log when TerminologyRouter returns empty
   226→    if not candidates:
   227→        apis = router.get_apis_for_entity(entity_type)
   228→        if not apis:
   229→            logger.info(
   230→                "Entity '%s' (type=%s) skipped by TerminologyRouter"
   231→                " — no APIs configured for this type",
   232→                entity_text[:50],
   233→                entity_type,
   234→            )
   235→        else:
   236→            logger.info(
   237→                "Entity '%s' (type=%s) returned zero candidates from all APIs",
   238→                entity_text[:50],
   239→                entity_type,
   240→            )
   241→
   242→    # Step 2: MedGemma selects best match from candidates
   243→    result = await medgemma_decide(entity, candidates, criterion_text)
   244→
   245→    # Step 3: Agentic retry loop — max 3 attempts total
   246→    attempt = 1
   247→    current_query = entity_text
   248→    while (
   249→        result.selected_code is None
   250→        and result.confidence < 0.5
   251→        and attempt < 3
   252→        and router.get_apis_for_entity(entity_type)
   253→    ):
   254→        attempt += 1
   255→        reasoning_result = await agentic_reasoning_loop(
   256→            entity={**entity, "_previous_query": current_query},
   257→            criterion_context=criterion_text,
   258→            router=router,
   259→            attempt=attempt,
   260→        )
   261→
   262→        if reasoning_result.should_skip:
   263→            logger.info(
   264→                "Entity '%s' marked non-medical by agentic reasoning"
   265→                " (attempt %d) — skipping",
   266→                entity_text[:50],
   267→                attempt,
   268→            )
   269→            return (
   270→                EntityGroundingResult(
   271→                    entity_text=entity_text,
   272→                    entity_type=entity_type,
   273→                    selected_code=None,
   274→                    selected_system=None,
   275→                    preferred_term=None,
   276→                    confidence=0.0,
   277→                    candidates=[],
   278→                    reasoning=(
   279→                        f"Skipped by agentic reasoning (attempt {attempt}): "
   280→                        f"{reasoning_result.reasoning}"
   281→                    ),
   282→                ),
   283→                attempt,
   284→            )
   285→
   286→        new_query = (
   287→            reasoning_result.rephrased_query
   288→            or reasoning_result.derived_term
   289→            or reasoning_result.gemini_suggestion
   290→            or current_query
   291→        )
   292→        current_query = new_query
   293→
   294→        logger.info(
   295→            "Agentic retry (attempt %d) for '%s' using query '%s'",
   296→            attempt,
   297→            entity_text[:50],
   298→            new_query[:50],
   299→        )
   300→
   301→        new_candidates = await router.route_entity(new_query, entity_type)
   302→        if new_candidates:
   303→            retry_entity = {**entity, "text": new_query}
   304→            result = await medgemma_decide(retry_entity, new_candidates, criterion_text)
   305→            if result.selected_code and result.confidence >= 0.5:
   306→                # Success — preserve original entity_text
   307→                return (
   308→                    EntityGroundingResult(
   309→                        entity_text=entity_text,
   310→                        entity_type=result.entity_type,
   311→                        selected_code=result.selected_code,
   312→                        selected_system=result.selected_system,
   313→                        preferred_term=result.preferred_term,
   314→                        confidence=result.confidence,
   315→                        candidates=result.candidates,
   316→                        reasoning=(
   317→                            f"[Attempt {attempt}, query='{new_query}'] "
   318→                            f"{result.reasoning}"
   319→                        ),
   320→                        field_mappings=result.field_mappings,
   321→                    ),
   322→                    attempt,
   323→                )
   324→
   325→    # Route to expert_review if all attempts exhausted without success
   326→    if result.selected_code is None and attempt >= 2:
   327→        logger.warning(
   328→            "Entity '%s' (type=%s) routed to expert_review after"
   329→            " %d failed grounding attempts",
   330→            entity_text[:50],
   331→            entity_type,
   332→            attempt,
   333→        )
   334→        return (
   335→            EntityGroundingResult(
   336→                entity_text=result.entity_text,
   337→                entity_type=result.entity_type,
   338→                selected_code=result.selected_code,
   339→                selected_system=result.selected_system,
   340→                preferred_term=result.preferred_term,
   341→                confidence=result.confidence,
   342→                candidates=result.candidates,
   343→                reasoning=(
   344→                    f"[expert_review] Routed to expert review after "
   345→                    f"{attempt} failed grounding attempts. "
   346→                    f"Last reasoning: {result.reasoning}"
   347→                ),
   348→            ),
   349→            attempt,
   350→        )
   351→
   352→    return (result, attempt)

   355→async def _ground_entity_parallel(
   356→    entity: dict[str, Any],
   357→    router: TerminologyRouter,
   358→    criterion_text: str,
   359→    entity_num: int,
   360→    total: int,
   361→    semaphore: asyncio.Semaphore,
   362→) -> tuple[EntityGroundingResult | None, str | None, float, int]:
   363→    """Ground a single entity with concurrency control and timing.
   364→
   365→    Acquires the semaphore before grounding to cap concurrent API calls.
   366→    Returns a (result, error) tuple for error isolation -- one entity failure
   367→    does not crash others in the asyncio.gather batch.
   368→
   369→    Args:
   370→        entity: Entity dict with text, entity_type, criterion_id.
   371→        router: TerminologyRouter singleton for API dispatch.
   372→        criterion_text: Full criterion text for context.
   373→        entity_num: 1-based index for logging.
   374→        total: Total entity count for logging.
   375→        semaphore: Concurrency limiter (Semaphore(4)).
   376→
   377→    Returns:
   378→        (EntityGroundingResult, None, elapsed_ms, retry_attempts) on success,
   379→        or (None, error_message, elapsed_ms, 0) on failure.
   380→    """
   381→    async with semaphore:
   382→        entity_text = entity.get("text", "")[:50]
   383→        entity_type = entity.get("entity_type", "")
   384→        start = time.monotonic()
   385→        logger.info(
   386→            "Grounding entity %d/%d: '%s' (type=%s) — start",
   387→            entity_num,
   388→            total,
   389→            entity_text,
   390→            entity_type,
   391→        )
   392→        try:
   393→            # Dual grounding: run TerminologyRouter + OMOP mapper
   394→            # in parallel per entity (Phase 1a)
   395→            full_entity_text = entity.get("text", "")
   396→            tu_task = _ground_entity_with_retry(entity, router, criterion_text)
   397→            omop_task = lookup_omop_concept(full_entity_text, entity_type)
   398→            (result, retry_attempts), omop_result = await asyncio.gather(
   399→                tu_task, omop_task
   400→            )
   401→
   402→            # Reconcile dual grounding results
   403→            result = _reconcile_dual_grounding(result, omop_result)
   404→
   405→            # Thread criterion_id from parse into result
   406→            criterion_id = entity.get("criterion_id")
   407→            if criterion_id:
   408→                result.criterion_id = criterion_id
   409→
   410→            # Generate field mappings (same semaphore slot)
   411→            field_mappings = await generate_field_mappings(result, criterion_text)
   412→            result.field_mappings = field_mappings if field_mappings else None
   413→
   414→            elapsed = time.monotonic() - start
   415→            elapsed_ms = elapsed * 1000
   416→            logger.info(
   417→                "Entity %d/%d '%s' grounded in %.1fs: code=%s, omop=%s, conf=%.2f",
   418→                entity_num,
   419→                total,
   420→                entity_text,
   421→                elapsed,
   422→                result.selected_code or "N/A",
   423→                result.omop_concept_id or "N/A",
   424→                result.confidence,
   425→            )
   426→            return (result, None, elapsed_ms, retry_attempts)
   427→        except Exception as e:
   428→            elapsed = time.monotonic() - start
   429→            elapsed_ms = elapsed * 1000
   430→            logger.error(
   431→                "Entity %d/%d '%s' failed in %.1fs: %s",
   432→                entity_num,
   433→                total,
   434→                entity_text,
   435→                elapsed,
   436→                e,
   437→            )
   438→            return (None, str(e), elapsed_ms, 0)

   441→async def ground_node(state: PipelineState) -> dict[str, Any]:
   442→    """Ground entities via TerminologyRouter + MedGemma.
   443→
   444→    Parses entities_json from state, routes each entity through TerminologyRouter
   445→    to get terminology candidates, then passes candidates to medgemma_decide for
   446→    best-match selection. Generates field mappings for each successfully grounded
   447→    entity.
   448→
   449→    Error accumulation: individual entity failures are logged and collected in
   450→    errors list. Processing continues with remaining entities. Only a total
   451→    failure to parse entities_json triggers a fatal error.
   452→
   453→    Args:
   454→        state: Current pipeline state with entities_json and protocol_id.
   455→
   456→    Returns:
   457→        Dict with grounded_entities_json and accumulated errors list,
   458→        or fatal error dict if entities_json cannot be parsed.
   459→    """
   460→    from protocol_processor.tracing import pipeline_span
   461→
   462→    if state.get("error"):
   463→        return {}
   464→
   465→    protocol_id = state.get("protocol_id", "")
   466→    with pipeline_span(
   467→        "ground_node", span_type="TOOL", protocol_id=protocol_id
   468→    ) as span:
   469→        span.set_inputs({"protocol_id": state.get("protocol_id", "")})
   470→
   471→        try:
   472→            entities_json = state.get("entities_json")
   473→            if not entities_json:
   474→                span.set_outputs({"error": "No entities_json in state"})
   475→                return {
   476→                    "error": "No entities_json in state — parse node may have failed",
   477→                }
   478→
   479→            entity_items: list[dict[str, Any]] = json.loads(entities_json)
   480→            protocol_id = state["protocol_id"]
   481→
   482→            span.set_inputs(
   483→                {
   484→                    "protocol_id": protocol_id,
   485→                    "entity_count": len(entity_items),
   486→                }
   487→            )
   488→
   489→            logger.info(
   490→                "Starting grounding for protocol %s: %d entities",
   491→                protocol_id,
   492→                len(entity_items),
   493→            )
   494→
   495→            # Fail fast: verify OMOP vocabulary is reachable before
   496→            # starting entity grounding. No silent fallback.
   497→            _get_omop_engine()
   498→
   499→            router = _get_router()
   500→            accumulated_errors: list[str] = list(state.get("errors") or [])
   501→            grounding_results: list[dict[str, Any]] = []
   502→
   503→            # Pre-process: handle consent entities synchronously (skip grounding)
   504→            entities_to_ground: list[tuple[int, dict[str, Any]]] = []
   505→            for idx, entity in enumerate(entity_items, 1):
   506→                entity_text = entity.get("text", "")
   507→                entity_type = entity.get("entity_type", "")
   508→
   509→                if entity_type == "Consent":
   510→                    logger.info(
   511→                        "Entity '%s' (type=Consent) skipped — consent/participation"
   512→                        " criteria are not groundable to terminology codes",
   513→                        entity_text[:50],
   514→                    )
   515→                    consent_result = EntityGroundingResult(
   516→                        entity_text=entity_text,
   517→                        entity_type=entity_type,
   518→                        selected_code=None,
   519→                        selected_system=None,
   520→                        preferred_term=None,
   521→                        confidence=0.0,
   522→                        candidates=[],
   523→                        reasoning=(
   524→                            "Consent/participation criterion — not groundable"
   525→                            " to medical terminology codes"
   526→                        ),
   527→                        criterion_id=entity.get("criterion_id"),
   528→                    )
   529→                    grounding_results.append(consent_result.model_dump())
   530→                else:
   531→                    entities_to_ground.append((idx, entity))
   532→
   533→            # Dev/debug knob: truncate entity list for faster pipeline runs
   534→            _max_entities = int(os.getenv("PIPELINE_MAX_ENTITIES", "0"))
   535→            if _max_entities > 0:
   536→                entities_to_ground = entities_to_ground[:_max_entities]
   537→                logger.info(
   538→                    "PIPELINE_MAX_ENTITIES=%d: truncated to %d entities",
   539→                    _max_entities,
   540→                    len(entities_to_ground),
   541→                )
   542→
   543→            # Pre-flight warmup: absorb MedGemma cold-start latency before
   544→            # the parallel batch. Non-fatal — if warmup fails, entities proceed.
   545→            try:
   546→                from langchain_core.messages import HumanMessage as HumanMessageType
   547→
   548→                from protocol_processor.tools.medgemma_decider import (
   549→                    _get_medgemma_model,
   550→                )
   551→
   552→                warmup_model = _get_medgemma_model()
   553→                await warmup_model.ainvoke([HumanMessageType(content="ready")])
   554→                logger.info("MedGemma warmup succeeded")
   555→            except Exception as warmup_err:
   556→                logger.info("MedGemma warmup skipped: %s", warmup_err)
   557→
   558→            # Parallel grounding with asyncio.gather + semaphore
   559→            # Semaphore created here (not module-level) to bind to current event loop
   560→            semaphore = asyncio.Semaphore(4)
   561→
   562→            tasks = [
   563→                _ground_entity_parallel(
   564→                    entity,
   565→                    router,
   566→                    entity.get("criterion_text") or entity.get("text", ""),
   567→                    idx,
   568→                    len(entity_items),
   569→                    semaphore,
   570→                )
   571→                for idx, entity in entities_to_ground
   572→            ]
   573→
   574→            outcomes = await asyncio.gather(*tasks)
   575→
   576→            # Process outcomes and collect audit entries for batch write
   577→            pending_audits: list[tuple[str, dict[str, Any], list[Any], Any]] = []
   578→            entity_times: list[float] = []
   579→            total_retry_count = 0
   580→            for (idx, entity), (result, error, elapsed_ms, retries) in zip(
   581→                entities_to_ground, outcomes
   582→            ):
   583→                entity_times.append(elapsed_ms)
   584→                total_retry_count += max(0, retries - 1)  # retries beyond first attempt
   585→                entity_text = entity.get("text", "")
   586→                criterion_id = entity.get("criterion_id", "")
   587→
   588→                if result is not None:
   589→                    pending_audits.append(
   590→                        (criterion_id, entity, result.candidates, result)
   591→                    )
   592→                    grounding_results.append(result.model_dump())
   593→                else:
   594→                    # Entity failed — create expert_review fallback
   595→                    cid_short = criterion_id[:12] if criterion_id else "unknown"
   596→                    error_msg = (
   597→                        f"Entity grounding failed for '{entity_text[:50]}'"
   598→                        f" (criterion={cid_short}): {error}"
   599→                    )
   600→                    logger.error(error_msg)
   601→                    accumulated_errors.append(error_msg)
   602→
   603→            # Batch-write all audit log entries in a single session
   604→            _flush_audit_logs(protocol_id, pending_audits)
   605→
   606→            logger.info(
   607→                "Ground node complete for protocol %s: %d grounded, %d errors",
   608→                protocol_id,
   609→                len(grounding_results),
   610→                len(accumulated_errors),
   611→            )
   612→
   613→            span.set_outputs(
   614→                {

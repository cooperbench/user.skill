> AGENT

The Go standard library defaults to PascalCase (the field name as-is), but the overwhelming convention in the Go ecosystem is **`camelCase`** for JSON — matching what JavaScript/JSON consumers expect. The Go blog, Google APIs, Kubernetes, Docker, GitHub's Go SDKs, and most popular Go projects all use `camelCase` json tags. `snake_case` is less common in Go but shows up in projects that interop with Python/Ruby ecosystems or follow specific API style guides (like some older Google APIs).

## Sparse metadata fetch with on-demand blob resolution This branch optimizes `entire resume` for cloned repos where the metadata branch (`entire/checkpoints/v1`) isn't available locally. Instead of fetching the entire branch with all blobs, it: 1. **Treeless fetch** (`--filter=blob:none`) — downloads only the latest commit and tree objects, skipping blob content 2. **On-demand blob fetching** — `FetchingTree` wraps git trees to automatically fetch individual blobs when `File()` is called, with a `git cat-file` fallback for go-git's stale packfile index 3. **Streaming metadata decoding** — uses `json.Decoder` with lite structs to avoid allocating large unused fields (TokenUsage, Summary, etc.) Also includes: credential-safe blob fetching (`git fetch` instead of `fetch-pack`), `BranchExistsOnRemote` now queries the actual remote as fallback, test isolation fix for global `core.hooksPath`, and benchmarks for metadata reading at various checkpoint counts.

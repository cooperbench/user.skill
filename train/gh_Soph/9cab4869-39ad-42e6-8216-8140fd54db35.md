> AGENT

Here's the deal: **`runner.temp`** is a **context property** — used in GitHub Actions expressions with `${{ }}` syntax: ```yaml args: release --clean --release-notes=${{ runner.temp }}/release_notes.md ``` **`RUNNER_TEMP`** is the corresponding **environment variable** — automatically set by GitHub Actions, used in shell `run:` blocks: ```yaml run: | echo "$RUNNER_TEMP" # same path as runner.temp ``` They point to the same directory. The difference is just where you use them: - **Shell code** (`run:` blocks) → `$RUNNER_TEMP` - **YAML expressions** (`with:`, `if:`, etc.) → `${{ runner.temp }}` The `with:` block for GoReleaser isn't a shell script — it's YAML input to the action, so it needs the `${{ runner.temp }}` expression syntax. The `run:` block is a shell script, so it uses `$RUNNER_TEMP`. Per the docs: it's a temp directory on the runner that gets **emptied at the beginning and end of each job**, so it's perfect for intermediate files like release notes.

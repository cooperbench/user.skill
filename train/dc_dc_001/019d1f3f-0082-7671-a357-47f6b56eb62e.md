> AGENT

问题已经定位清楚了。

根因不是 `ANTHROPIC_BASE_URL` 配错，也不是 Anthropic 接口不通，而是 Claude Code 2.1.81 的模型别名解析和你的 OneAPI 模型名不一致：

- Claude Code 本地 `sonnet` 会解析成 `claude-sonnet-4-6`
- `opus` 会解析成 `claude-opus-4-6`
- 但你的网关当前暴露的可用模型名是 `Claude Sonnet 4.6`、`Claude Opus 4.6`
- 所以网关返回了 `503 当前分组 default 下对于模型 claude-sonnet-4-6 无可用渠道`

我已经实测过修复方案，下面这组环境变量可以让 `claude -p --model sonnet` 正常返回 `OK`：

```bash
export ANTHROPIC_BASE_URL="https://oneapi-comate.baidu-int.com"
export ANTHROPIC_AUTH_TOKEN="[REDACTED]"
export ANTHROPIC_DEFAULT_SONNET_MODEL="Claude Sonnet 4.6"
export ANTHROPIC_DEFAULT_OPUS_MODEL="Claude Opus 4.6"
```

临时测试命令：

```bash
ANTHROPIC_BASE_URL="https://oneapi-comate.baidu-int.com" \
ANTHROPIC_AUTH_TOKEN="[REDACTED]" \
ANTHROPIC_DEFAULT_SONNET_MODEL="Claude Sonnet 4.6" \
ANTHROPIC_DEFAULT_OPUS_MODEL="Claude Opus 4.6" \
claude -p --model sonnet 'Reply with exactly OK'
```

我这边实测输出是：

OK

> AGENT

脚本流程如下：

1. **加载数据**：从 `bench/data/speed_bench_cunlimited.jsonl` 读取 64 条样本（Smax 配置）
2. **每轮 trial**：
   - 先调 `/flush_cache` 清空 KV cache，确保每轮从零开始
   - 64 条请求**全部并发**发出（`Semaphore(64)` 不限流），每条设 `max_tokens=1`，这样几乎所有耗时都花在 prefill 上，decode 只出 1 个 token
   - 记录每条请求的延迟、prompt_tokens、状态码
3. **统计输出**：每轮打印总耗时、成功数、p50/p99/max 延迟；多轮后输出平均总耗时
4. **参数**：`--trials` 控制跑几轮（默认 2），`--concurrency` 控制并发数（默认 64），`--tag` 打标签

核心目的是**隔离测量纯 prefill 性能**，用来验证 plan-cache 等 prefill 优化的效果。

## Total Variation and Acceptance Rate

The connection between acceptance rate and Total Variation (TV) distance is fundamental: maximizing acceptance rate is exactly equivalent to minimizing TV distance. Acceptance rate is the total probability mass that the draft and target distributions share.

## Training Loss Approaches

Standard speculative decoding training uses KL divergence as a proxy for acceptance rate. KL divergence is an indirect surrogate that happens to share the global optimum, but leads to different suboptimal solutions when model capacity is constrained.

Some studies have explored other types of divergences, including reverse KL and total variation (TV) distance, as training objectives for speculators, noting that TV distance should theoretically be the right objective as it directly maximizes acceptance rate.

## LK Losses: Direct Optimization

Recent work addresses this directly: LK losses are training objectives that directly optimize the acceptance rate for speculative decoding draft models, serving as a drop-in replacement for KL divergence with no computational overhead. Fine-tuning with KL divergence substantially improves performance, while LK loss achieves an additional +5.6% on top of this already-improved KL baseline, confirming that the benefit of direct acceptance optimization is not limited to random-initialization training.

## Acceptance Criterion

The acceptance probability for a draft token is calculated as α = min(1, p(x)/q(x)), where p(x) is the target model's probability distribution and q(x) is the draft model's distribution.

The speculative sampling approach uses min(1, p/q) to trim the probability that the small model "guessed too much," and uses max(0, p-q) to make up for the probability that the small model "missed," and the combination of the two seamlessly restores the target distribution p(x).

## Definition and Equivalence

The total variation distance is half of the L1 distance between the probability functions, defined as δ(P,Q) = (1/2) ∑_x |P(x) - Q(x)|

## Proof of the Equivalence

For discrete spaces, the total variation distance can be expressed as (1/2)∑_{x∈E}|μ(x)−ν(x)|, where the supremum in the original definition is achieved for the set A_* = {x ∈ E : μ(x) ≥ ν(x)}

Regarding the equivalence with ∑(p-q)₊ (where the subscript + denotes the positive part):

The set A that achieves the supremum is the region where P exceeds Q; splitting mass above/below and summing absolute differences gives the same quantity

This connection arises because when you partition the support into regions where p ≥ q and regions where q > p, the positive differences sum ∑(p-q)₊ on the first region equals half the total L1 distance: ∑(p-q)₊ = (1/2)∑|p-q|.

The key insight is that taking A = {x ∈ X : q(x) ≥ p(x)} gives the relationship d_TV(P,Q) = (1/2) ∫_X |p(x) - q(x)| dμ(x) (Scheffe's lemma).

## Key Formula Derivation

The total rejection rate β is derived as: β = 1 - Σₓ q(x)·min(1, p(x)/q(x)) = 1 - Σₓ min(q(x), p(x)) = Σₓ max(0, p(x) - q(x))

This derivation is fundamental to speculative decoding's mathematical foundation.

## Conceptual Framework

The output probability can be decomposed into two parts: Accept and Resample, where P(output=x) = q(x)·α(x) + β·p'(x) = p(x)

The derivation follows logically from the requirements that:

1. The acceptance probability is α(x) = min(1, p(x)/q(x)), which trims probability when the draft model "guesses too much"

2. The corrected sampling distribution p'(x) is exactly the normalized max(0, p(x) - q(x))

## Intuition

Speculative sampling is essentially a "refund for overpayment and supplement for deficiency" process: Refund uses min(1, p/q) to trim excess probability, while Supplement uses max(0, p-q) to make up for missed probability, seamlessly restoring the target distribution p(x)

The formula establishes that the optimal transport cost for a single token corresponds to Σₓ min(p(x), q(x)), which represents the optimal expected acceptance rate.

**Definition and Basic Properties:**
The total variation distance is defined for probability measures μ and ν as the supremum over subsets A of the difference in their probabilities: d_TV(μ,ν) = sup_{A⊆E} |μ(A) - ν(A)|, taking values in [0,1] with 1 achieved when μ and ν have disjoint supports.

**Alternative Expressions:**
For discrete probability distributions, the total variation distance equals (1/2) times the supremum of |∫f dμ - ∫f dν| over functions f with values in [-1,1], which also equals (1/2) times the sum of absolute differences between the distributions.

## EAGLE Loss Function Formula

The EAGLE loss combines a regression loss (L_reg) computed as Smooth L1 distance and a classification loss (L_cls) computed as cross-entropy between predicted and target token probability distributions.

Specifically:
- L_reg = Smooth L1(f_{i+1} draft(T_{2:i+1}, F_{1:i}))
- L_cls = CrossEntropy(p_{i+2}, p̂_{i+2}) where p and p̂ are the softmax outputs of the language model head applied to the target and draft features respectively

## Combined Training with Weight

The classification loss weight is set to w_cls = 0.1 because the classification loss is an order of magnitude bigger than the regression loss. This weighting prevents the classification loss from dominating the combined training objective.

The combined loss would be: **L_total = L_reg + w_cls × L_cls** where w_cls = 0.1

## Key Findings

**Non-Differentiability of L1 Norm:**

The L1 norm, defined as the sum of absolute values |x|, is non-differentiable at points where any component x_i equals zero, due to the kink in the absolute value function. This applies directly to total variation since the norm is fundamentally based on L1 properties.

**Total Variation and Non-Smooth Behavior:**

The total-variation norm is isotropic and not differentiable. This non-differentiability extends to the corners and non-smooth regions where the gradient changes direction abruptly.

**The Corner Problem:**

The non-differentiability manifests at corners in the geometric sense. The unit circle in l1 has sharp corners where the function doesn't change so there is no derivative for it. ### The Formula

The LK loss formula is: ℒ^λ_LK(p, q) = λ · KL(p∥q) + (1 − λ) · TV(p, q), with an adaptive weight driven by the current acceptance rate.

### Adaptive Weight Scheduling

The adaptive weight works as follows:

- The weight λ is computed independently for each draft decoding position using stop-gradient denoted sg[·].
- The schedule satisfies λ → 1 (late training, perfect alignment). As alignment improves, the balance shifts toward direct acceptance rate optimization.

### Relationship Between Cross Entropy and KL Divergence

KL divergence is calculated by subtracting the entropy H(P) from cross-entropy: D_KL(P,Q) = H(P,Q) - H(P). More intuitively, cross entropy can be defined as the uncertainty implicit in H(p) plus the likelihood that p could have been generated by q.

### The Constant Entropy Factor

The key insight for classification is that the entropy of the real-world distribution H(P) does not depend on the model at all, meaning optimizing cross-entropy is equivalent to optimizing KL divergence. More specifically, if we consider p to be a fixed distribution, H(p,q) and D_KL(p || q) differ by a constant factor for all q.

### Practical Implications in Classification

In classification, we don't actually need to compute H(P) because it's constant - we just minimize H(P,Q), which implicitly minimizes the divergence between our model and the true distribution.

### Uses in Machine Learning

Cross-entropy is used as a loss function in classification tasks to calculate the difference between the observed data and the predicted output, quantifying how close the predicted data is to the observed data. Meanwhile, KL divergence is used to measure the difference between probability distributions and is often used in unsupervised settings or cases where you're approximating a distribution.

Speculative Decoding originates from a 2023 Google paper titled "Fast Inference from Transformers via Speculative Decoding," and can be translated as "speculative decoding" or "draft decoding."

### Core Concept

The core idea is to input a prefix and simultaneously run a large target model for inference while a much smaller approximation model runs autoregressively γ times to generate γ tokens (called guesses or draft tokens), then the LLM evaluates these speculative tokens in parallel, comparing random thresholds against probability distribution ratios p_i(x)/q_i(x) to select n tokens that are generated by the approximation model, and finally the target model generates the (n+1)th token.

### Advantages

Speculative Decoding is a decoding algorithm that leverages the advantages of both small and large models, using the large model to evaluate and correct the generation results of the small model, aiming to maintain the generation quality of the large model while improving inference speed.

## Fact-Check Results

### 1. Acceptance Rule: min(1, p(x)/q(x))

**Verdict: CORRECT.**

This is the standard acceptance criterion from the original speculative decoding paper by Leviathan, Kalman, and Matias (2023). When the draft model proposes token x sampled from q, it is accepted with probability min(1, p(x)/q(x)). This is essentially a rejection-sampling-style criterion: if the target model assigns higher probability than the draft (p(x) >= q(x)), always accept; if the draft over-estimated (q(x) > p(x)), accept with probability p(x)/q(x). Upon rejection, a corrective sample is drawn from the normalized residual distribution proportional to max(0, p(x) - q(x)).

### 2. Expected Acceptance Rate: alpha(p,q) = sum_x min(p(x), q(x))

**Verdict: CORRECT.**

The derivation is:

- E_q[min(1, p(x)/q(x))] = sum_x q(x) * min(1, p(x)/q(x))
- = sum_x min(q(x), q(x) * p(x)/q(x))   [distributing q(x) into the min]
- = sum_x min(q(x), p(x))

This is valid because for any scalar a > 0: a * min(1, b/a) = min(a, b). Since q(x) >= 0, multiplying q(x) into min(1, p(x)/q(x)) gives min(q(x), p(x)). (For x where q(x) = 0, that term contributes 0 to both sides, so it is consistent.)

### 3. The Identity alpha(p,q) = 1 - TV(p,q)

**Verdict: CORRECT, but requires careful attention to the TV definition.**

The blog's proof:

> sum_x min(p(x), q(x)) = sum_x [p(x) - (p(x) - q(x))_+] = 1 - sum_x (p(x) - q(x))_+ = 1 - TV(p,q)

Step-by-step verification:

1. **min(p, q) = p - (p - q)_+**: This is a standard identity. If p >= q, then (p-q)_+ = p-q, so p - (p-q) = q = min(p,q). If p < q, then (p-q)_+ = 0, so p - 0 = p = min(p,q). Correct.

2. **sum_x [p(x) - (p(x)-q(x))_+] = 1 - sum_x (p(x)-q(x))_+**: Since sum_x p(x) = 1 (p is a probability distribution), this follows by linearity. Correct.

3. **Is sum_x (p(x)-q(x))_+ equal to TV(p,q)?** This is the key question.

   - The standard definition is TV(p,q) = (1/2) sum_x |p(x) - q(x)|.
   - Now, sum_x |p(x) - q(x)| = sum_x (p(x)-q(x))_+ + sum_x (q(x)-p(x))_+.
   - Since sum_x p(x) = sum_x q(x) = 1, we have sum_x (p(x)-q(x)) = 0, which means sum_x (p(x)-q(x))_+ = sum_x (q(x)-p(x))_+.
   - Therefore sum_x |p(x)-q(x)| = 2 * sum_x (p(x)-q(x))_+.
   - So TV(p,q) = (1/2) * 2 * sum_x (p(x)-q(x))_+ = sum_x (p(x)-q(x))_+.

**The equivalence holds.** The two definitions -- TV = (1/2) sum |p-q| and TV = sum (p-q)_+ -- are equivalent for probability distributions (where both p and q sum to 1). The blog's claim that these are equal is mathematically correct.

### 4. TV is "continuous and convex" (连续、凸) on the probability simplex

**Verdict: CORRECT that it is continuous and convex. The earlier claim of "continuously differentiable" (连续可微) was indeed wrong and was rightly corrected.**

- **Continuity**: TV(p,q) = (1/2) sum_x |p(x) - q(x)| is a norm (the L1 norm scaled by 1/2). All norms are continuous (in fact, Lipschitz continuous). So TV is continuous as a function of (p,q) on the simplex. Correct.

- **Convexity**: For a fixed q, the map p -> TV(p,q) = (1/2)||p - q||_1 is convex, because norms are convex functions (triangle inequality implies convexity). Specifically, for any lambda in [0,1]:
  TV(lambda*p1 + (1-lambda)*p2, q) = (1/2)||lambda*(p1-q) + (1-lambda)*(p2-q)||_1 <= lambda*(1/2)||p1-q||_1 + (1-lambda)*(1/2)||p2-q||_1 = lambda*TV(p1,q) + (1-lambda)*TV(p2,q). Correct.

- **NOT continuously differentiable**: The L1 norm is not differentiable at points where any component equals zero -- i.e., wherever p(x) = q(x) for some x. The absolute value function |t| has a kink at t=0. So TV(p,q) is non-smooth in general. The correction from "连续可微" to "连续、凸" was appropriate.

19	## 01 推测解码的训练目标到底是什么
20	
21	推测解码（Speculative Decoding）的核心机制是：draft 模型预测若干 token，target 模型在单次 forward 中并行 verify。每个 draft token 是否被接受，依据的是经典的 importance sampling 接受规则——给定 target 分布 `p` 与 draft 分布 `q`，token `x` 被接受的概率是 `min(1, p(x)/q(x))`。把这一规则在 `q` 上求期望得到一个简洁的 closed form：
22	
23	```
24	α(p, q) = Σ_x min(p(x), q(x))
25	```
26	
27	α 是 token 期望接受率的精确表达式，也是 speculative decoding 论文里直接挂钩 wall-clock 加速比的物理量。**推测解码 draft 训练真正希望最大化的，就是 α。**
28	
29	那为什么大家训练 draft 时不直接优化 α，而是用 KL 散度？

33	## 02 EAGLE 的原始 loss
34	
35	EAGLE（Li et al., arXiv:2401.15077）的原始训练 loss 由两项组成：
36	
37	```
38	L = L_reg + w_cls · L_cls,   w_cls = 0.1
39	L_reg = SmoothL1(h_draft, h_target)        # hidden state regression
40	L_cls = CE(p_target, p_draft)              # 输出分布的 cross-entropy
41	```
42	
43	第一项约束 draft 中间表示与 target 中间表示接近，第二项约束 draft 的输出 token 分布与 target 一致。EAGLE-3 进一步把第一项去掉，只保留输出分布层面的拟合，本质上就是 `−Σ p_target · log p_draft`，也就是常说的 plogp loss（KL 与 CE 在分类问题里只差一个常数项）。
44	
45	KL 是一个非常合理的训练目标——它和 α 共享全局最优解：当 `q ≡ p` 时 KL 取最小值 0，同时 `α = 1`。**问题在 "共享全局最优" 这件事其实没什么用**：小 draft 模型的容量远不足以让 `q = p`，训练过程必然停在某个局部最优，而 KL 的局部最优和 α 的局部最优**并不是同一个点**。

50	
51	LK Losses 这篇论文（arXiv:2602.23881, 2026.02）给出了一个让人愣一下的恒等式：

55	```
56

58	
59	```
60	Σ_x min(p, q) = Σ_x [p − (p − q)_+] = 1 − Σ_x (p − q)_+ = 1 − TV(p, q)
61	```
62	
63	这条恒等式说明：**最大化 acceptance rate 等价于最小化 TV distance**。TV 连续、凸，计算只涉及绝对值求和，不含 log 或除法，数值上比 KL 稳定。直接把 KL 换成 TV 作为训练 loss，就是论文 LK^TV 的形式：

75	只用 TV 在工程上有个小问题——训练早期 `q` 与 `p` 几乎不重叠时，TV 接近上界 1，梯度信号弱且 "扁平"。KL 在分布差异大时反而能给出更密集的梯度（penalty 随对数发散）。

82	```

### The Problem

The speedup is significantly determined by the acceptance rate, yet standard training minimizes Kullback-Leibler (KL) divergence as a proxy objective. ## EAGLE: Speculative Sampling Requires Rethinking Feature Uncertainty

EAGLE (Extrapolation Algorithm for Greater Language-model Efficiency) is a simple yet highly efficient speculative sampling framework.

### Key Insights

The paper makes two key observations: firstly, autoregression at the feature (second-to-top-layer) level is more straightforward than at the token level, and secondly, the inherent uncertainty in feature (second-to-top-layer) level autoregression constrains its performance.

### How It Works

By incorporating a token sequence advanced by one time step, EAGLE effectively resolves the uncertainty, enabling precise second-to-top-layer feature prediction with minimal overhead. ## 4. "KL and CE differ only by a constant in classification" -- Is this standard?

**Verified: Yes, this is a standard and correct mathematical statement.**

The relationship is:

```
CE(p, q) = -sum p(x) log q(x) = KL(p || q) + H(p)
```

where H(p) = -sum p(x) log p(x) is the entropy of the true distribution p. Since p is the target distribution (fixed during training), H(p) is a constant with respect to the model parameters (which only affect q). Therefore, minimizing CE is equivalent to minimizing KL. This is textbook information confirmed by multiple authoritative sources.

- [Cross-entropy and KL divergence - Eli Bendersky](https://eli.thegreenplace.net/2025/cross-entropy-and-kl-divergence/)

## 5. The blog calls cross-entropy loss "plogp loss" -- Is this a recognized term? Is it technically correct?

**This is a recognized informal/code-level term in the EAGLE/speculative-decoding community, but it is technically a misnomer.**

**Where "plogp" comes from:** In the EAGLE codebase (SafeAILab/EAGLE), the cross-entropy loss is computed as a variable literally named `plogp`. The code does:

```python
out_logp = nn.LogSoftmax(dim=2)(out_head)   # log q (draft model)
plogp = target_p * out_logp                   # p * log q
cross_entropy_loss = -sum(loss_mask * plogp)
```

So `plogp` is the **variable name** in the EAGLE source code for the quantity `p * log q`. The blog (and apparently the EAGLE community) adopted this variable name as shorthand for the loss. This is confirmed by Chinese-language CSDN blog posts analyzing the EAGLE code.

**Why it is technically imprecise:** The expression `-sum p_target * log p_draft` is really `p * log q`, not `p * log p`. The name "plogp" is misleading because the two distributions p (target) and q (draft) are different. The quantity `p * log p` would be the negative entropy of p, which is something entirely different. A more accurate name would be "plogq" or simply "cross-entropy loss." However, because the EAGLE code literally uses the variable name `plogp`, the term has propagated as informal jargon within the speculative decoding community, particularly in Chinese-language ML discussions.

**Verdict:** The term "plogp loss" is used in practice (originating from an EAGLE code variable name), but it is a technically imprecise label. The blog's use of it is consistent with community convention.

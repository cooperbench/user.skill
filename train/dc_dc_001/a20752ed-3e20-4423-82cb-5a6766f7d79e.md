> AGENT

原因找到了：`remote-control` 不是子命令，而是一个 **flag**（`--remote-control`），所以不能像 `claude remote-control` 那样当作 subcommand 调用。 从 `claude --help` 看： ``` --remote-control [name] Start an interactive session with Remote Control enabled (optionally named) ``` 注意它出现在 **Options** 段而不是 **Commands** 段（commands 段里只有 `agents / auth / auto-mode / doctor / install / mcp / plugin / project / setup-token / ultrareview / update`）。 正确用法： ```bash # 启用 Remote Control 起一个交互 session（不带名字 → 自动生成） claude --remote-control # 给 session 起个名字 claude --remote-control my-session ``` 另外报错信息里写 `Run 'claude remote-control --help'` 是 commander.js 在把未识别的位置参数当成 subcommand 时的兜底提示，照着跑会得到同一个 "Unknown argument" 错误 —— 改用 `claude --help | grep -i remote` 就能直接看到正确语法。

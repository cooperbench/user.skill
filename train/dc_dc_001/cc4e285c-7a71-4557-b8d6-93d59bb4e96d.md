# Simutack 项目分析报告

## 1. 项目名称、目的与描述

**项目名称**: Simutack - An Attack Simulation Framework for Connected and Autonomous Vehicles

**目的**: 面向网联与自动驾驶车辆的传感器攻击仿真框架，用于在仿真环境中模拟和评估针对车载传感器的攻击。

**描述**: 基于 CARLA 仿真器，提供传感器数据采集、攻击注入和 ECU 应用（如自动驾驶、交通标志识别）的端到端仿真。支持多种攻击类型（无数据、无更新、消息延迟、欺骗值、恒定偏移、相机致盲等），用于安全研究和测试。

**论文引用**: IEEE VTC2023-Spring (Florence, Italy)，DOI: 10.1109/VTC2023-Spring57618.2023.10200555

**许可证**: MIT License (2023)

**状态**: 项目已停止维护（end-of-life），不再接受新 issue。

## 4. 主入口与核心模块

### 主入口 (`simutack/simutack/__main__.py`)
- 解析命令行参数：`-v`、`--ip`、`--port`、`--carla-path`
- 加载 CARLA 的 egg 文件
- 初始化 `Controller`，连接 CARLA 并启动仿真
- 当前主循环为 `while True: time.sleep(1)`，交互式 `main_loop()` 被注释

### 核心流程

1. **Controller** (`core/Controller.py`)
   - 创建 `DataController` 和 `APIController`
   - 启动 CARLA 仿真
   - 提供传感器创建、配置、攻击、车辆控制等接口

2. **DataController** (`core/DataController.py`)
   - 连接 CARLA 客户端（`carla_ip`, `carla_port`）
   - 加载 Town02（可改为 Town03）
   - 同步模式：`fixed_delta_seconds=0.1`，100ms 步进
   - 生成 Audi e-tron 车辆
   - 仿真循环：`tick()` → 传感器 `tick()` → 应用车辆控制

3. **APIController** (`api/APIController.py`)
   - Tornado 端口 3000
   - 路由：`/`（Web UI）、`/config`（传感器配置）、`/control`（车辆控制）
   - 各传感器：`/sensor/{type}/{name}`（HTTP + WebSocket）

## 6. 端到端工作流程

```
1. 启动 docker-compose
   ├── CARLA 启动（无头模式，端口 2000）
   ├── Simutack 启动，连接 CARLA 并启动 Tornado 服务
   ├── Traffic-sign ECU 启动，创建摄像头并订阅 WebSocket
   └── Autopilot ECU 启动，创建 GNSS/IMU/Tachometer 并订阅

2. 配置阶段
   ├── Autopilot 发送 POST /config，创建 autopilot-gnss、autopilot-imu、autopilot-tachometer
   ├── 配置各传感器（enable、updateInterval 等）
   └── Traffic-sign ECU 创建 autopilot-camera1 并订阅

3. 仿真循环

   Simutack 主循环:
   ├── carla_world.tick()
   ├── 各传感器 tick() → 从 CARLA 获取数据 → 攻击引擎处理 → 放入 data_queue
   ├── 各 SensorHandler 通过 notify_subscribers 推送给 WebSocket 客户端
   └── 应用 vehicle_control（来自 Autopilot 或 Web UI）

   Autopilot 主循环:
   ├── 从 GNSS/IMU/Tachometer 获取当前状态
   ├── 从 Traffic-sign ECU 获取限速
   ├── 纵向/横向 PID 计算 throttle、brake、steer
   └── POST /control 发送控制指令

   Traffic-sign ECU:
   ├── 从 Simutack 接收相机图像（WebSocket）
   ├── YOLOv4 检测交通标志
   └── 通过 WebSocket 向 Autopilot 发送限速

4. 攻击注入
   └── 通过 Web UI 或 API 对传感器启用攻击（No Data、No Update、Delay 等）
```

## 8. 注意事项

1. **CARLA 版本**: 使用 CARLA 0.9.12/0.9.13，Dockerfile 与 `__main__.py` 中版本略有差异。
2. **主循环**: `__main__.py` 中 `main_loop()` 被注释，当前为简单 `while True: time.sleep(1)`，交互式菜单未启用。
3. **传感器创建**: 实际由 Autopilot 和 Traffic-sign ECU 通过 `/config` 创建，而非 Simutack 启动时预置。
4. **GPU**: CARLA 和 Traffic-sign ECU 需要 NVIDIA GPU 和 CUDA。
5. **mask.bin**: `ImageAttackEngine` 依赖 `simutack/attack/mask.bin`，需确认该文件存在。

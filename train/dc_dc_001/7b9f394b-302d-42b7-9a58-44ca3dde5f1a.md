MARS、Fuzzy SD、DIVERSED、SVIP 这四个说的是什么？

> AGENT

四个都是**推测解码验证（verify）阶段的改进方案**，核心区别在于"什么条件下接受 draft token"： **MARS** — Margin-Aware Speculative Verification - 观察：target 的 top-1 和 top-2 概率接近时（low-margin），拒绝 draft token 的信息增益几乎为零，但 rollback 成本照付 - 做法：计算 target logits 的 margin（p_top1 - p_top2），margin 大时严格验证，margin 小时放松接受 - 特点：训练免费，只改验证规则，8B-235B 一致提速 **Fuzzy SD** — Fuzzy Speculative Decoding - 做法：不逐 token 比概率比，而是算 target 和 draft 在该位置的分布散度（KL/JS/TV），散度小于阈值 T 就接受 - Reduced 变体：先走标准验证，被拒绝的 token 再做一次散度检查，散度够小仍接受 - 特点：阈值 T 可平滑调节 quality-throughput 权衡 **DIVERSED** — Dynamic Ensemble Verification - 做法：把验证目标从纯 target 分布 p(x) 替换为 p(x) 和 draft 分布 q(x) 的混合：`nu = alpha * p + (1-alpha) * q` - alpha 动态版由轻量神经网络学习，Static 版固定 alpha 不需训练 - 混合分布离 draft 更近 → 更容易接受，但 alpha<1 时输出偏离 target（有 distributional bias） **SVIP** — Entropy-based Draft Termination - 做法：draft 生成过程中计算 entropy，超过阈值时提前停止生成更多 draft token - 目的：高熵位置 draft 质量差，不如少生几个避免浪费 verify 计算 - 不是改验证规则，而是改 draft 侧的终止条件 **一句话总结**：MARS 看 margin、Fuzzy SD 看散度、DIVERSED 改验证目标分布、SVIP 改 draft 终止时机。前三个改 verify，第四个改 draft。

现在信息足够了。 --- ## Cactus — 约束接受推测采样 **论文**：arXiv:2604.04987，ICLR 2026 Poster，Yongchang Hao & Lili Mou，UAlberta ### 1. 它解决什么问题 标准 Speculative Sampling (SpS) 是**无损的**——输出分布严格等于 target 分布。但这"过于严格"了：top-k 采样、temperature 调整本来就会偏离 target 分布，只要偏离可控就完全可接受。 另一边，Typical Acceptance Sampling (TAS，Medusa 用的) 用 entropy 启发式放宽接受，accept rate 更高，但**分布变形不可控**——TAS 总是退化为确定性分布（entropy=0），KL 散度至少增加 H(q)，当 target 本身高熵时偏差巨大。 Cactus 的核心立场：**用约束优化取代启发式放松，保证输出分布与 target 的 KL 散度 ≤ δ**。 ### 2. 理论框架：从 SpS 到约束优化 #### Observation 1（SpS 的统一视角） 任何目标分布 h 都可以被 draft-verify 框架精确产生，只要： ``` 接受概率： φ(x_t | x_{<t}) = min{h(x_t | x_{<t}) / p(x_t | x_{<t}), 1} 恢复分布： g(x_t | x_{<t}) ∝ h(x_t | x_{<t}) - p(x_t | x_{<t}) · φ(x_t | x_{<t}) ``` 标准 SpS 就是取 `h = q`（target 分布）的特例。**换 h 就换接受规则**。 #### 约束优化问题 Cactus 把选 h 变成一个优化问题： ``` max min{h_n / p(n), 1} ← 最大化 draft token n 的接受概率 s.t. h ∈ Δ^{|V|-1} ← h 是合法概率分布 D_f(h || q) ≤ δ ← 与 target 的 f-散度不超过 δ ``` δ=0 时退化为标准 SpS（h=q），δ>0 时允许 h 偏离 q 以换取更高接受率。 ### 3. 核心定理：最优解的结构 #### Theorem 2（一般 f-divergence） 最优 h 的结构出人意料地简洁： ``` h(i | x_{<t}) = γ* 如果 i = n（draft 采到的 token） h(i | x_{<t}) = (1-γ*)/(1-q(n)) · q(i) 否则 ``` 其中 γ* 是以下方程在 [q(n), +∞) 上的根： ``` δ = q(n) · f(γ/q(n)) + (1-q(n)) · f((1-γ)/(1-q(n))) ``` **直觉**：最优策略就是给 draft token n 分配比 q(n) 更多的概率质量（"bonus"），其余 token 按比例缩放 q。所有额外概率都集中在 n 上。 #### Corollary 5（KL 散度的闭式解） 当 f-divergence 取 KL 散度时，方程没有闭式解。但 δ 通常很小，γ* 接近 q(n)，所以对 Φ(γ) = D_KL(h || q) 在 γ₀ = q(n) 处做二阶 Taylor 展开，得到： ``` γ* = min{q(n) + √(2δ · q(n) · (1-q(n))), 1} ``` **这是 Cactus 最核心的公式**。解读： - 当 δ=0：γ* = q(n)，退化为标准 SpS - δ 越大：γ* 越大，draft token 的"bonus"越多，接受率越高 - bonus 最大值在 q(n)=0.5 时取得（√(q·(1-q)) 最大），即 target 对 draft token 半信半疑时放松最有价值 - q(n) 接近 0 或 1 时 bonus 趋近 0——target 非常确定时没必要放松 ### 4.

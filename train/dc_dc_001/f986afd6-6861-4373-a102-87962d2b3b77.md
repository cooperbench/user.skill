## Simutack 项目详解 **Simutack** 全称 *An Attack Simulation Framework for Connected and Autonomous Vehicles*，是一个面向**网联与自动驾驶车辆的传感器攻击仿真框架**。该项目发表于 IEEE VTC2023-Spring（佛罗伦萨），采用 MIT 协议，目前已停止维护。 --- ### 一、项目目标 核心目标是：在 **CARLA 仿真器** 中模拟自动驾驶车辆的完整传感器链路，并在链路中**注入各种攻击**，用于研究和评估车载传感器的安全性。 简单来说，它回答的是这样一个问题：**如果有人篡改了自动驾驶汽车的传感器数据，会发生什么？** --- ### 二、整体架构 项目由 **4 个 Docker 容器** 组成，通过 `docker-compose.yaml` 编排： | 服务 | 端口 | 作用 | |------|------|------| | **CARLA** | 2000-2002 | 3D 驾驶仿真器，提供虚拟世界和传感器原始数据 | | **Simutack** | 3000 | 核心框架 — 传感器数据采集、攻击注入、Web UI 和 API | | **Traffic-Sign ECU** | 4000 | 交通标志识别 ECU — 用 YOLOv4 检测限速牌 | | **Autopilot ECU** | 5000 | 自动驾驶 ECU — 基于 PID 的纵向/横向控制 | 数据流如下： ``` CARLA 仿真世界 ↓ （原始传感器数据） Simutack 框架 ↓ （可能被攻击篡改的数据） ├── Autopilot ECU（接收 GNSS/IMU/速度 → 计算控制） │ ↑ │ Traffic-Sign ECU（接收摄像头图像 → YOLOv4 识别限速 → 告知 Autopilot） │ ↓ └── Autopilot → POST /control → Simutack → 控制车辆 ``` --- ### 三、核心模块详解 #### 1. Simutack 核心框架（`simutack/simutack/`） 这是项目的心脏，分为以下几个子模块： **`core/` — 核心控制与数据模型** - `Controller.py`：顶层协调器，串联 `DataController` 和 `APIController` - `DataController.py`：连接 CARLA 客户端，加载地图（Town02），生成车辆（红色 Audi e-tron），运行仿真循环（每 100ms 一步），管理所有传感器的生命周期 - `SensorData.py` / `ImageData.py` / `VectorData.py` / `ScalarData.py`：传感器数据的类型封装 **`sensor/` — 传感器实现** - `Sensor.py`：抽象基类，实现观察者模式，每帧从 `data_queue` 取数据并通知订阅者 - `CameraSensor.py`：RGB 相机，安装在车前 (1.5, 0, 2.4)，支持 FOV 和分辨率配置 - `IMUSensor.py`：惯性测量单元（加速度、角速度、罗盘方向） - `GNSSSensor.py`：全球导航卫星系统（经纬度、高度） - `TachometerSensor.py`：车速计（直接从车辆速度向量计算，非 CARLA 原生传感器） - `LidarSensor.py` / `RadarSensor.py`：激光雷达和毫米波雷达（有实现但当前未在 ECU 中使用） **`attack/` — 攻击引擎（项目的核心创新点）** 支持 **6 种攻击类型**： | 攻击类型 | 效果 | |---------|------| | **No Data** | 传感器不返回任何数据 | | **No Update** | 传感器数据冻结在某一帧不再更新 | | **Delay Message** | 传感器数据被延迟若干帧后才传递 | | **Spoofed Value** | 传感器数据被替换为攻击者指定的假值 | | **Constant Offset** | 在真实值上叠加一个固定偏移量 | | **Camera Blinding** | 模拟强光攻击，在图像上叠加遮罩使摄像头致盲 | 每种攻击还可以配置 **period（攻击周期）** 和 **chance（触发概率）**，模拟间歇性攻击。 攻击引擎按数据类型分为三个子类： - `ImageAttackEngine.py`：图像攻击（Camera Blinding 使用预存的 `mask.bin` 在 3D 空间中模拟光照） - `VectorAttackEngine.py`：向量攻击（GNSS、IMU） - `ScalarAttackEngine.py`：标量攻击（车速） **`api/` — REST / WebSocket API** 基于 **Tornado** Web 框架： - `GET/POST /config`：创建、查询、删除传感器 - `POST /control`：接收车辆控制指令（油门、刹车、转向） - `/sensor/{type}/{name}`：各传感器的 HTTP 配置接口 - `/sensor/{type}/{name}/websocket`：各传感器的 WebSocket 实时数据推送 **`webserver/simutack-web-ui/` — Vue.js Web 前端** 基于 Vue 2 + Bootstrap-Vue 的 Web UI，用于： - 可视化查看传感器数据 - 配置传感器参数 - **启用和配置攻击** — 这是给研究者使用的主要交互界面 --- #### 2. Autopilot ECU（`ecus/autopilot/`） 一个简化的自动驾驶系统： - `Autopilot.py`：主逻辑 — 从 Simutack 获取 GNSS/IMU/速度数据，从 Traffic-Sign ECU 获取限速，沿预定义路径点行驶 - `LongitudinalController.py`：纵向 PID 控制（控制油门和刹车使车速匹配目标速度） - `LateralController.py`：横向 PID 控制（控制方向盘使车辆沿路径行驶） - `PIDController.py`：通用 PID 控制器，带低通滤波 - 路径点定义在 `tracks/speed_limit_crash.json` 中 --- #### 3.

这个项目是一个 **让你用 iPhone 远程控制 Mac 上的 Codex** 的工具。 ## 它在做什么 可以把它理解成： > **手机是遥控器，Mac 是真正干活的地方。** 你在手机上发指令、看进度、接着聊、做一些 git 操作； 真正运行 Codex、读取仓库、执行命令的，还是你的 Mac。 ## 这个项目由三部分组成 | 部分 | 作用 | |---|---| | `CodexMobile/` | iPhone App，本体界面在这里 | | `phodex-bridge/` | Mac 端桥接程序，命令是 `remodex` | | `relay/` | 中继层，负责让手机和 Mac 建立连接 | ## 使用者能感受到的核心能力 - 用 iPhone 查看和控制 Codex - 首次扫码配对，之后自动重连 - 任务运行时实时看进度 - 在手机上继续上一轮，不必重开 - 支持 Plan mode、Fast mode、`/subagents` - 可从手机执行常见 git 操作 - 任务结束或需要处理时收到通知 - 可把当前对话切回 Mac 继续 ## 这个项目的重点方向 ### 1. 明确是 local-first 重点不是把东西搬到云上，而是保留本机控制权。 意思是： - Codex 跑在本机 - git 和文件操作在本机 - relay 只负责连通，不替你执行任务 ### 2. 重点是 iPhone 体验 它不是单纯的命令行工具，而是完整的手机使用体验： - 扫码配对 - 自动重连 - 消息时间线 - 通知 - 回到桌面继续同一条对话 ### 3. macOS 支持最完整 目前最成熟的路线是 **Mac + iPhone**。 Mac 上有后台服务能力，终端关掉后也能继续维持连接。 ## 适合怎么理解它 这不是新的 AI 平台，也不是普通聊天 App。 它的价值是： > **你离开电脑时，仍然能继续控制正在 Mac 上运行的 Codex。** ## 判断依据 - 项目定位与功能：`README.md` - iPhone App 入口：`CodexMobile/CodexMobile/CodexMobileApp.swift` - 配对与自动重连入口：`CodexMobile/CodexMobile/ContentView.swift` - Mac 端桥接命令：`phodex-bridge/package.json` - relay 的职责边界：`relay/README.md` 如果你要，我可以继续给你两种版本： 1. **面向使用者的架构说明** 2. **面向开发者的目录导览**

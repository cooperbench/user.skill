## 项目概述

CARLA（Car Learning to Act）是一个开源自动驾驶研究模拟器，当前版本为 **0.10.0**，基于 **Unreal Engine 5.5** 构建（`ue5-dev` 分支）。使用 CMake + Ninja 作为构建系统，支持 C++、Python 和 ROS2 多语言开发。

## 5. 整体架构关系

```
┌─────────────────────────────────────────────┐
│         Unreal Engine 5.5 (服务端)           │
│  Plugins/Carla/ ──► CarlaServer (RPC)        │
│                 ──► 传感器数据采集            │
│                 ──► 物理仿真 (Chaos)          │
└──────────────┬──────────────────────────────┘
               │ TCP (rpclib + streaming)
               │
┌──────────────▼──────────────────────────────┐
│         LibCarla (客户端/服务端共用)          │
│  carla-client ◄──► carla-server              │
│  trafficmanager、opendrive、road、sensor     │
└──────────────┬──────────────────────────────┘
               │ Boost.Python 绑定
               │
┌──────────────▼──────────────────────────────┐
│         PythonAPI (用户接口)                  │
│  carla.Client → World → Actor/Sensor         │
└──────────────────────────────────────────────┘
               ↕
┌──────────────────────────────────────────────┐
│    Ros2Native (可选，原生 ROS2 话题发布)       │
│    Fast-DDS → 直接发布到 ROS2 网络             │
└──────────────────────────────────────────────┘
```

这个项目是一个高度模块化的大型 C++/Python/UE5 混合工程，总源文件数约 1380 个，涵盖从底层道路模型解析到高层 Python API 的完整自动驾驶仿真栈。

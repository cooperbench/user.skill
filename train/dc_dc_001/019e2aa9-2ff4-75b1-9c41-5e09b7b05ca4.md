EAGLE decode 入口：`EAGLEWorker.forward_batch_generation()` 调 `draft()` 再调 `verify()`，见 [eagle_worker.py](/user_4813494d/openbmb/demo-sala/sglang/python/sglang/srt/speculative/eagle_worker.py:660)。 - EAGLE tree 由 `draft_forward()` 产生 `parent_list/top_scores_index/draft_tokens`，再由 `build_tree_kernel_efficient()` 生成 verify tensors，见 [eagle_worker.py](/user_4813494d/openbmb/demo-sala/sglang/python/sglang/srt/speculative/eagle_worker.py:1213) 和 [eagle_utils.py](/user_4813494d/openbmb/demo-sala/sglang/python/sglang/srt/speculative/eagle_utils.py:47)。 - Verify 输入类型是 `EagleVerifyInput`，字段定义在 [eagle_info.py](/user_4813494d/openbmb/demo-sala/sglang/python/sglang/srt/speculative/eagle_info.py:95)。 - Verify acceptance 用 `verify_tree_greedy_func()` / `sgl_kernel.verify_tree_greedy`，只消费 `draft_token + retrive_* + target_predict`，见 [eagle_info.py](/user_4813494d/openbmb/demo-sala/sglang/python/sglang/srt/speculative/eagle_info.py:384) 和 [eagle_utils.py](/user_4813494d/openbmb/demo-sala/sglang/python/sglang/srt/speculative/eagle_utils.py:161)。 **最小接入方式** 在 `build_tree_kernel_efficient()` 返回后，拿到： ```python tree_mask, position, retrive_index, retrive_next_token, retrive_next_sibling, draft_tokens ``` 然后做一个 `_inject_ngram_branch(...)`，只改同 shape tensor： - `draft_tokens`: 把选中 branch 上的 token id 替换为 ngram lookup 的 token。 - `position`: 如果复用原 branch topology，通常不改；若 ngram branch 深度和原 branch 不一致，需要按 `seq_len + depth` 改。 - `tree_mask/custom_mask`: 复用原 branch topology 时不改；若改 parent/sibling topology，必须重建。 - `retrive_index`: 通常保持 `bs x dtn` 的 flat index，不改。 - `retrive_next_token/retrive_next_sibling`: 只有改拓扑或 child 顺序时才改。 - `spec_steps/topk/draft_token_num`: 强烈建议保持原值。 - `capture_hidden_mode`: 保持 `CaptureHiddenMode.FULL`，否则 verify 后没有足够 hidden state 供下一轮 draft，见 [eagle_worker.py](/user_4813494d/openbmb/demo-sala/sglang/python/sglang/srt/speculative/eagle_worker.py:1207)。 **各字段语义** - `draft_token`: flat `(bs * dtn,)`，每 req 第 0 个必须是 user_4813494d/`verified_id`。 - `custom_mask`: flat bool，FULL_MASK 布局是每 req `dtn x (seq_len + dtn)`，prefix 全可见，tree 部分按祖先可见。 - `positions`: flat `(bs * dtn,)`，tree 节点通常是 `seq_len + depth`，siblings 可共享 position。 - `retrive_index`: `(bs, dtn)`，通常是每 req 对应 flat logits row index。 - `retrive_next_token`: `(bs, dtn)`，每个 node 的 first child，`-1` 表示 leaf。 - `retrive_next_sibling`: `(bs, dtn)`，同父右 sibling，`-1` 表示无。 - `spec_steps`: acceptance path 最大深度，`accept_index` 只有 `(bs, spec_steps + 1)`，见 [eagle_info.py](/user_4813494d/openbmb/demo-sala/sglang/python/sglang/srt/speculative/eagle_info.py:309)。 -

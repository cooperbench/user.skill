# AMD RX 7900 GRE 显卡 Linux 软件问题诊断报告

## 硬件与驱动概况

| 项目 | 状态 |
|------|------|
| **显卡** | AMD Radeon RX 7900 GRE (Navi 31) |
| **内核驱动** | amdgpu 已加载 |
| **Vulkan** | 正常（RADV 驱动） |
| **OpenGL** | 正常（radeonsi） |
| **显示** | GNOME Wayland 正常使用 GPU |

## 发现的问题

### 1. VA-API 视频硬件加速未工作（主要问题）

**现象：** Chrome、Cursor 等应用报错：
```
vaInitialize failed: unknown libva error
```

**原因：** 未安装 `mesa-va-drivers`，系统缺少 `radeonsi_drv_video.so`，VA-API 无法初始化。

**影响：** 视频播放、视频会议、浏览器等无法使用 GPU 硬件解码/编码，只能走 CPU。

### 2. OpenCL 无 GPU 支持

**现象：** `clinfo` 显示 `Number of platforms: 0`

**原因：** 只安装了 OpenCL 加载器，未安装 GPU 实现（如 `mesa-opencl-icd` 或 `rocm-opencl-icd`）。

**影响：** 依赖 OpenCL 的应用（部分 AI、视频处理、科学计算）无法使用 GPU。

### 3. 用户未加入 video/render 组

**现象：** 当前用户不在 `video` 和 `render` 组。

**影响：** 可能影响 `/dev/dri/renderD128` 和 `/dev/kfd` 的访问，导致部分应用无法使用 GPU。

---

## 修复步骤

按顺序执行以下命令：

```bash
# 1. 安装 VA-API 驱动（视频硬件加速）
sudo apt update
sudo apt install mesa-va-drivers vainfo

# 2. 安装 OpenCL GPU 支持（二选一）
# 方案 A：Mesa OpenCL（开源，适合通用计算）
sudo apt install mesa-opencl-icd

# 方案 B：ROCm OpenCL（适合 AI/ML，RX 7900 支持）
# sudo apt install rocm-opencl-icd

# 3. 将用户加入 video 和 render 组
sudo usermod -aG video,render $USER

# 4. 验证 VA-API（安装后执行）
vainfo
```

**重要：** 执行第 3 步后需要**重新登录**或**重启**，组权限才会生效。

# Simutack 项目技术报告 ## 一、项目概览 Simutack 是基于 CARLA 的汽车传感器数据生成与攻击测试框架，用于自动驾驶传感器仿真、数据注入和攻击研究。项目通过 Docker Compose 编排 CARLA、Simutack 框架和多个 ECU 服务。 --- ## 二、根目录 Python 文件 **结论：根目录下没有 Python 文件。** 所有 Python 代码都在子目录中。 --- ## 三、主源码目录 (simutack/simutack/) ### 3.1 入口与核心控制器 #### `__main__.py` - **作用**：框架入口，解析命令行参数并启动 Controller。 - **主要逻辑**：解析 `-v/--verbose`、`-i/--ip`、`-p/--port`、`--carla-path`，加载 CARLA egg，创建 `Controller` 并进入主循环（当前为 `while True: time.sleep(1)`，交互式主循环被注释）。 - **依赖**：`Controller`、`logger`。 #### `core/Controller.py` - **作用**：顶层控制器，协调数据与 API。 - **主要类**：`Controller` - `__init__`: 创建 `DataController`、`APIController`，启动仿真。 - `create_sensor` / `delete_sensor`：传感器增删。 - `create_handler`：为传感器创建 API handler。 - `apply_vehicle_control`：车辆控制。 - `main_loop`：交互式菜单（创建/配置/删除传感器、攻击配置等）。 - **依赖**：`DataController`、`APIController`、`Sensor`。 #### `core/DataController.py` - **作用**：管理 CARLA 仿真与传感器生命周期。 - **主要类**：`DataController` - `init_carla`：连接 CARLA、加载 Town02、同步模式、天气、生成车辆（红色 Audi e-tron）。 - `create_sensor`：支持 imu、gnss、camera、tachometer。 - `_simulation_loop`：每步 tick 世界、更新传感器、应用车辆控制。 - **依赖**：IMU/GNSS/Camera/Tachometer 等传感器类。 ### 3.2 API 层 #### `api/APIController.py` - **作用**：Tornado Web 服务器，提供 REST 与 WebSocket。 - **主要类**：`APIController` - 路由：`/`（MainHandler）、`/config`、`/control`、`/sensor/{type}/{name}`、`/sensor/{type}/{name}/websocket`。 - `create_handler`：为传感器创建 HTTP/WebSocket handler 并注册到 Tornado。 - **依赖**：各类 Handler、Tornado。 #### `api/MainHandler.py` - **作用**：提供 Web UI 的 `index.html`。 - **关键**：`MainHandler.get()` 返回 `webserver/simutack-web-ui/dist/index.html`。 #### `api/ConfigHandler.py` - **作用**：传感器配置 REST API。 - **方法**： - `GET`：返回传感器列表和 `worldStep`。 - `POST`：创建传感器（`newSensors`）、重置仿真、设置 `worldStep`。 - `DELETE`：删除传感器。 #### `api/VehicleControlHandler.py` - **作用**：车辆控制 REST API。 - **方法**：`POST` 接收 `throttle`、`brake`、`steer`，构造 `carla.VehicleControl` 并应用。 #### `api/SensorHandler.py` - **作用**：传感器 handler 基类。 - **主要类**：`SensorHandler`（继承 `SensorObserver`） - `sensor_update`：抽象方法，由子类实现。 - `notify_subscribers`：通过 WebSocket 推送数据。 - 内部类：`TornadoHTTPHandler`、`TornadoWebSocketHandler`。 #### `api/CameraSensorHandler.py`、`IMUSensorHandler.py`、`GNSSSensorHandler.py`、`TachometerSensorHandler.py` - **作用**：各传感器类型的 HTTP/WebSocket handler。 - **共同点**：`sensor_update` 将数据转为 JSON 并推送给 WebSocket 客户端；`TornadoHandler` 提供 GET（配置）和 POST（更新配置、攻击参数）。 ### 3.3 传感器层 #### `sensor/Sensor.py` - **作用**：传感器抽象基类。 - **主要类**：`Sensor` - `sensor_callback`：抽象，由子类实现。 - `attach` / `detach`：观察者注册/注销。 - `tick`：每帧调用，从 `data_queue` 取数据并通知观察者。 - 支持攻击引擎、更新间隔、启用/禁用等。 - **依赖**：`DataController`、`SensorObserver`。 #### `sensor/CameraSensor.py` - **作用**：RGB 相机传感器。 - **实现**：使用 `sensor.camera.rgb` blueprint，位置 (1.5, 0, 2.4)，支持 FOV、分辨率、位置/旋转配置。 - **数据流**：`sensor_callback` → `ImageData` → `ImageAttackEngine` → `AnnotationData` → `data_queue`。 - **依赖**：`ImageAttackEngine`、`AnnotationData`、`ImageData`。 #### `sensor/IMUSensor.py` - **作用**：IMU 传感器（加速度、角速度、罗盘）。 - **实现**：使用 `sensor.other.imu` blueprint。 - **数据**：`VectorData`（加速度、角速度、方向），仅对方向做攻击。 - **依赖**：`VectorAttackEngine`。 #### `sensor/GNSSSensor.py` - **作用**：GNSS 传感器（经纬度、高度）。 - **实现**：使用 `sensor.other.gnss` blueprint。 - **依赖**：`VectorAttackEngine`。 #### `sensor/TachometerSensor.py` - **作用**：车速传感器（无 CARLA actor，从车辆速度计算）。 - **实现**：重写 `tick`，从 `get_velocity()` 计算速度。 - **依赖**：`ScalarAttackEngine`。 ### 3.4 攻击引擎 #### `attack/AttackEngine.py` - **作用**：攻击引擎基类。 - **攻击类型**：NO_DATA、NO_UPDATE、SPOOFED_VALUE、CONSTANT_OFFSET、DELAY_MESSAGE、CAMERA_BLINDING。 - **主要方法**：`attack_data`（根据 period/chance 决定是否攻击）、`apply_attack`、`clear_attacks` 等。 - **依赖**：`SensorData`。 #### `attack/ImageAttackEngine.py` - **作用**：图像攻击实现。 - **实现**：`no_update_attack`（复用上一帧）、`camera_blinding_attack`（在固定 3D 位置叠加 mask，模拟强光）。 - **依赖**：`simutack/attack/mask.bin`。 #### `attack/VectorAttackEngine.py`、`ScalarAttackEngine.py` - **作用**：向量/标量攻击实现。 - **实现**：`no_update_attack`、`spoofed_value_attack`、`constant_offset_attack`。 ### 3.5 数据模型 #### `core/SensorData.py` - **作用**：传感器数据基类。 - **主要属性**：`base_unit`、`frame`、`timestamp`。 #### `core/ImageData.py`、`VectorData.py`、`ScalarData.py` - **作用**：图像、向量、标量数据子类。 - **主要属性**：`image`、`vector`、`value`。 #### `core/AnnotationData.py` - **作用**：攻击标注信息。 - **属性**：`attackEnabled`、`attackType`。 #### `core/SensorObserver.py` - **作用**：观察者接口，`sensor_update(data)` 由 handler 实现。 #### `core/Unit.py`、`MeasuringUnit.py` - **作用**：单位枚举与转换（如 m/s、rad、deg、地理坐标等）。 ### 3.6 编码器 #### `encoder/DataEncoder.py`、`CANEncoder.py`、`EthernetEncoder.py` - **作用**：数据编码接口（当前多为占位实现）。 ### 3.7 工具 #### `util/Logger.py` - **作用**：配置 `simutack` 模块 logger，默认 WARNING 级别。 --- ## 四、ECU 组件 ### 4.1 自动驾驶 ECU (ecus/autopilot/) #### `Autopilot.py` -

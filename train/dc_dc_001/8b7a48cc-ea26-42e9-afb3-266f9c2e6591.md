- **`minicpm.py`**：MiniCPM 推理实现；含 `MiniCPMMLP`、`MiniCPMAttention`、`MiniCPMLightningMixer`、`MiniCPMDecoderLayer`、`MiniCPMModel`、`MiniCPMSALAForCausalLM`；从 `hybrid_linear_attn_backend`（Lightning）与 `minicpm_sparse_utils`（稀疏路径）拉取依赖。
- **`llama_eagle3.py`**：LLaMA 系 **EAGLE3** draft 结构（基于 `LlamaDecoderLayer` 等），文档写明参考 SafeAILab/EAGLE；可作为 SALA 侧 EAGLE3 的模板（`CLAUDE.md` 亦指向此文件）。

另有大量其他架构单文件（Qwen、DeepSeek、Gemma、Llama 等）及 `registry.py`、`deepseek_common/` 等。

### `srt/layers/attention/`（约 **79** 个文件）

与 MiniCPM/SALA 直接相关的包括：

- `minicpm_backend.py`、`minicpm_attention_kernels.py`、`minicpm_sparse_utils.py`、`minicpm_sparse_kernels.py`、`minicpm_fuse_kernel.py`
- **`hybrid_linear_attn_backend.py`**（Lightning / GLA 类路径；体量很大，工作区文档称约 1651 行量级）
- `hybrid_attn_backend.py`、`attention_registry.py`（集中注册 flashinfer、triton、nsa 等）
- 以及 `mamba/`、`fla/`、`wave_ops/`、`triton_ops/`、`nsa/` 等子树。

### `srt/layers/quantization/`（约 **206** 个路径）

- **Python 实现约 48 个 `.py` 文件**，包括：`__init__.py`（注册表）、`gptq.py`、`modelopt_quant.py`（ModelOpt FP4/FP8）、`petit.py`（`petit_nvfp4`）、`mxfp4.py`、`fp8.py`、`awq.py`、`compressed_tensors/`、`quark/` 等。
- **`configs/`** 下大量 **GPU 型号 × 形状** 的 **JSON**（FP8/W8A8 等），占路径数的主要部分。
- `__init__.py` 中 `BASE_QUANTIZATION_METHODS` 显式包含 **`modelopt_fp4` / `modelopt_fp8` / `petit_nvfp4` / `mxfp4`**（CUDA/HIP 条件下）等字符串键，与 `CLAUDE.md` 里的启动参数一致。

### `srt/speculative/`（约 **26** 个文件）

- EAGLE 系列：`eagle_worker.py`、`eagle_worker_v2.py`、`multi_layer_eagle_worker.py`、`multi_layer_eagle_worker_v2.py`、`eagle_info.py`、`eagle_draft_*cuda_graph*` 等。
- **`multi_layer_eagle_worker.py`**：多行 import + EAGLE3 验证路径相关逻辑，篇幅约 **750+ 行**（Read 显示总行数约 753）。
- N-gram：`ngram_worker.py`、`cpp_ngram/`（C++ 绑定与头文件）。

## 简要结论

1. **工作区是「完整 SGLang 源码树 + 官方 toolkit + 两份 demo」**；**MiniCPM 权重分片在磁盘上未见**，只有索引里的 **`total_size` ≈ 18.95 GB** 说明。  
2. **demo-sala** 的 `prepare_env.sh` / `preprocess_model.py` 偏「最小可提交骨架」；**demo-quant** 则贴合评测镜像里的 GPTQ 路径并改 dtype。  
3. SALA 相关修改焦点在 **`srt/models/minicpm.py`**、**`srt/layers/attention/`（尤其 minicpm_* 与 hybrid_linear_attn）**、**`srt/layers/quantization/`** 与 **`srt/speculative/`（EAGLE3）** — 目录规模与文件角色已如上。

若你需要**逐文件的精确字节大小**，在本机对上述绝对路径执行 `stat` 或 `du` 即可与这里互补。

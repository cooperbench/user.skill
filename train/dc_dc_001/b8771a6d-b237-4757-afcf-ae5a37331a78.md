以下是 bashrc 中的 `ducc` 函数：

```bash
# Claude CLI via frp bridge (laptop → ali → bedrock)
ducc() {
    [REDACTED] \
    ANTHROPIC_BASE_URL='http://[REDACTED]:18787' \
    NO_PROXY='localhost,127.0.0.1,::1,[REDACTED]' \
    no_proxy='localhost,127.0.0.1,::1,[REDACTED]' \
    IS_SANDBOX=1 \
    ANTHROPIC_DEFAULT_OPUS_MODEL='Claude Sonnet 4.6' \
    ANTHROPIC_DEFAULT_SONNET_MODEL='Claude Sonnet 4.6' \
    ANTHROPIC_DEFAULT_HAIKU_MODEL='Claude Haiku 4.5' \
    CLAUDE_CODE_SUBAGENT_MODEL='Claude Sonnet 4.6' \
    command claude --dangerously-skip-permissions --disallowedTools WebSearch --mcp-config /user_4813494d/.claude-ducc-mcp.json "$@"
}
```

该函数通过 frp 代理桥接调用 `claude`，注入了自定义的 API endpoint、Token 和模型映射，并禁用了 `WebSearch` 工具，同时加载了指定的 MCP 配置。

### Cookie 失效后如何更新

`cail_session` 会过期（一周左右）。失效后报 `checkLogin 失败`，重新在浏览器登录然后：
- F12 → Application → Cookies → 复制 `cail_session` 值
- `echo 'cail_session=<新值>' > ~/.soar_cookie`

### 关键技术点（避免你以后踩坑）

| 字段 | 值 | 坑 |
|------|---|---|
| `raceID` | **字符串 `"0"`** | 传 int 0 直接 500，没有任何错误信息 |
| `cail_tag` | `"2026"` | 比赛年份 |
| `step` | `"0"` | 总决赛阶段硬编码 |
| `env` | `"production"` | |
| 文件 | `.tar.gz`，≤2GB | OSS 多线程分片上传 |
| 流程 | 3 步：precheck → OSS PUT → confirm | precheck 不计提交次数 |

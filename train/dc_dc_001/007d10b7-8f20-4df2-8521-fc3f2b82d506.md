```bash
# 1. 卸掉 apt 版 nvitop 及其拉进来的 NVIDIA 库

```

**`--no-deps` 无法帮助**，它只跳过依赖安装，不会跳过编译。问题在于 **CMake 的 CUDA 架构检测阶段卡住了**。

**1. 让它继续跑（推荐，后台方式）**

cd /opt/SGLang-MiniCPM-SALA/packages/sglang-minicpm/sgl-kernel && \

FETCHCONTENT_FULLY_DISCONNECTED=ON \

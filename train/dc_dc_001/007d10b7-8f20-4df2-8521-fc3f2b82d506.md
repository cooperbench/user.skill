> AGENT

问题是 `apt install nvitop` 自动拉了 `libnvidia-compute-590-server`，它带的 NVML 库（590.48）覆盖了你原来的版本，导致驱动/库版本不匹配。 **解决方法：卸掉 apt 拉进来的 NVIDIA 库包，用 pip 装 nvitop（它不会拉 NVIDIA 库）。** ```bash # 1. 卸掉 apt 版 nvitop 及其拉进来的 NVIDIA 库 apt remove --purge -y nvitop libnvidia-compute-590-server nvidia-kernel-common-590-server nvidia-firmware-590-server-590.48.01 # 2. 清理 apt autoremove -y ldconfig # 3. 确认 nvidia-smi 恢复正常 nvidia-smi # 4. 用 pip 装 nvitop（纯 Python，不会动驱动库） pip install nvitop ``` 核心原因：apt 版 nvitop 依赖 `libnvidia-compute-590-server`，这个包替换了系统原有的 `libnvidia-ml.so`，而内核驱动版本不是 590.48，所以不匹配。pip 版 nvitop 通过 `pynvml` 直接调用系统已有的 NVML 库，不会引入额外的 NVIDIA 包。

1. 加载模型 model = AutoModelForCausalLM.from_pretrained( "path/to/model", torch_dtype=torch.bfloat16, device_map="auto", trust_remote_code=True, ) # 2. 选择 NVFP4 量化配置 quant_cfg = mtq.NVFP4_DEFAULT_CFG # 3. 定义校准前向循环 def forward_loop(model): for batch in calib_dataloader: model(**batch) # 4. 执行量化 model = mtq.quantize(model, quant_cfg, forward_loop=forward_loop) # 5. 导出 with torch.inference_mode(): export_hf_checkpoint(model, export_dir="./quantized_model") ``` ### 可用的 NVFP4 配置变体 从 `hf_ptq.py` 源码中可以看到，modelopt 提供了多种 NVFP4 配置： | 配置名 | 常量 | 说明 | |--------|------|------| | `nvfp4` | `mtq.NVFP4_DEFAULT_CFG` | 默认 NVFP4，W4A4 量化 | | `nvfp4_awq` | `mtq.NVFP4_AWQ_LITE_CFG` | 带 AWQ 优化的 NVFP4 | | `nvfp4_mse` | `mtq.NVFP4_W4A4_WEIGHT_MSE_FP8_SWEEP_CFG` | 基于 MSE 优化权重缩放 | | `nvfp4_mlp_only` | `mtq.NVFP4_MLP_ONLY_CFG` | 仅量化 MLP 层 | | `nvfp4_experts_only` | `mtq.NVFP4_EXPERTS_ONLY_CFG` | 仅量化 MoE expert 层 | | `nvfp4_omlp_only` | `mtq.NVFP4_OMLP_ONLY_CFG` | 仅量化 attention output projection + MLP | | `nvfp4_svdquant` | `mtq.NVFP4_SVDQUANT_DEFAULT_CFG` | SVDQuant 优化 | | `nvfp4_local_hessian` | `mtq.NVFP4_W4A4_WEIGHT_LOCAL_HESSIAN_CFG` | 基于 local Hessian 的权重量化 | | `w4a8_nvfp4_fp8` | `mtq.W4A8_NVFP4_FP8_CFG` | 混合 FP4 权重 + FP8 激活 | ### 官方命令行用法（`hf_ptq.py` 脚本） NVIDIA 官方提供的 PTQ 脚本支持一行命令量化： ```bash #

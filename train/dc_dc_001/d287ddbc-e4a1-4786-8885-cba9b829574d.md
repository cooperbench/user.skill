## 核心挑战

### 1. 训练-测试分布不匹配（最关键）
训练数据是**文档级**的（平均 ~490 字节源文本），测试数据是**句子级**的。如果直接用文档训练，模型在句子级推理时可能表现不佳。

### 2. 数据极度稀缺
仅 1561 条训练样本微调一个 580M 参数模型，过拟合风险极高。

### 3. ByT5 的序列长度问题
ByT5 按**字节**处理，一个字符可能占 1-4 字节。源文本平均 490 字节，95 分位 1024 字节。这意味着注意力计算的开销远大于 subword 模型。

### 4. Kaggle 推理时间限制
ByT5 逐字节生成，4000 条测试句子需要在 9 小时内完成推理。

## 完整训练方案

### 一、数据准备策略

**分三层构建训练数据：**

**第 1 层：句子级数据（主力训练数据）**
- 利用 `Sentences_Oare_FirstWord_LinNum.csv` 中与训练集重叠的 253 个文档（~1207 个句子），从文档级转写中**精确切分**出句子级转写-翻译对
- 对剩余 ~1308 个文档，采用启发式句子切分：基于转写中的常见句首模式（如 `um-ma`、`KIŠIB`、`a-na ... qí-bi-ma`）和翻译中的句号分割
- 目标：从 1561 个文档生成 **~5000-8000 个句子级对**

**第 2 层：原始文档级数据**
- 保留全部 1561 条文档级对作为训练数据
- 文档级训练帮助模型学习上下文和长距离依赖

**第 3 层：无监督预训练续训**
- `published_texts.csv` 提供 ~7953 条无翻译的转写文本
- 用这些数据做 **span corruption** 预训练续训（ByT5 原始预训练目标）
- 让模型先熟悉阿卡德语转写的字节模式

**数据预处理：**

### 二、数据集划分

鉴于数据极度稀缺，推荐 **两阶段方案**：

**阶段 A - 超参调优阶段：5 折交叉验证**
- 将 1561 条文档按 `oare_id` 分 5 折
- 注意：同一文档的所有句子级拆分必须在同一折内（防止数据泄漏）
- 用于确定最优超参数

**阶段 B - 最终提交：全量训练**
- 确定超参后，用**全部 1561 条 + 所有句子级数据**训练
- 根据 CV 最优 epoch 数决定训练轮数（不做早停）

**验证集评估（阶段 A）：**
- 验证集应模拟测试集分布 → 使用**句子级**验证
- 每折中 ~20% 的文档拆成句子作为验证集

### 四、损失函数

**主损失：带标签平滑的交叉熵（Cross-Entropy with Label Smoothing）**

```python
# T5ForConditionalGeneration 默认使用交叉熵
# 加 label_smoothing = 0.1 防止模型对训练数据过度自信
loss_fn = CrossEntropyLoss(label_smoothing=0.1)
```

**为什么选择这个：**
- 标准 seq2seq 翻译任务的默认选择
- 标签平滑在小数据场景尤其有效，防止过拟合
- 不建议用 R-Drop 或对比学习等花哨方法，数据太少容易引入噪声

### 五、学习率调度器

**推荐：Cosine Annealing with Warmup**

```
学习率变化曲线：

lr |  /\
   | /  \____
   |/        \___
   +--+--------+--→ steps
     warmup  decay
```

- **Warmup 阶段**：前 ~280 步（6% 步数）从 0 线性升至 3e-4
- **余弦衰减**：从 3e-4 平滑降至接近 0

**为什么不用其他调度器：**
- Linear decay 也可以，但 cosine 在小数据上通常略优，因为后期衰减更缓
- Polynomial decay 效果类似
- 不建议 constant lr，小数据场景后期需要降低学习率

**评估指标计算：**

```python
import sacrebleu

def compute_metrics(predictions, references):
    bleu = sacrebleu.corpus_bleu(predictions, [references]).score
    chrf = sacrebleu.corpus_chrf(predictions, [references], 
                                  word_order=2).score  # chrF++
    geo_mean = (bleu * chrf) ** 0.5
    return {"bleu": bleu, "chrf++": chrf, "geo_mean": geo_mean}
```

**评估频率建议：**
- 前 10 个 epoch：每个 epoch 评估（学习曲线变化大）
- 10-30 epoch：每 2 个 epoch 评估（节省时间）
- 或者直接每 epoch 评估，总共就 30 个 epoch 不算多

| 项目 | 设定 | 理由 |
|------|------|------|
| 数据源 | `cleaned_datasets/train_clean_manual_v1.csv` | 已清洗的最终版 |
| 划分方式 | 按 `oare_id` 随机 90/10 分 | seed=42，可复现 |

| max_target_length | **1024** 字节 | 覆盖 89.0%，baseline 先接受截断 |
| padding 策略 | **动态 padding**（pad to longest in batch） | ByT5 加速核心 — 中位数仅 ~450 字节，避免全填充到 1024 |

**为什么用 1024 而不是 1536：**
- ByT5 的注意力计算是 O(n²)，1536 比 1024 慢 ~2.25 倍
- 中位数才 ~450 字节，大部分 batch 远不到 1024
- 被截断的长文档在测试时不会以完整文档出现（测试是句子级）

### 二、训练加速手段（全部启用）

| 技术 | 做什么 | 收益 |
|------|--------|------|
| **bf16 混合精度** | 模型计算用 bfloat16 | 内存减半，计算加速 ~1.5-2x |
| **梯度检查点** | 不缓存中间激活，反向时重算 | 显存降 40-60%，允许更大 batch |
| **动态 padding** | 每个 batch pad 到该 batch 最长序列 | 平均节省 ~50% 的无效计算 |

| **tf32** | `torch.backends.cuda.matmul.allow_tf32 = True` | Ampere+ GPU 矩阵乘法加速 |

### 四、损失函数

**带标签平滑的交叉熵（Cross-Entropy + Label Smoothing = 0.1）**

这是 `Seq2SeqTrainer` 在设定 `label_smoothing_factor=0.1` 后自动使用的损失。具体行为：

```
L = (1 - 0.1) × CE(y, ŷ) + 0.1 × uniform_over_vocab
```

- 90% 的 loss 权重给正确 token
- 10% 均匀分散到整个词表（384 个字节 token）
- 防止模型对训练数据过度自信，在 1561 条小数据上尤为关键

不需要其他损失函数。baseline 保持简单。

---

### 五、学习率调度器细节

```
3e-4 |      /‾‾‾‾‾\
     |     /       \
     |    /         \_____
     |   /                \___
  0  |__/                     \____
     +--+----+----+----+----+----→ steps
       0   158  660  1320  2000 2640
       warmup            cosine decay
```

- **预热**：0 → 3e-4，线性增长，约 158 步（2640 × 0.06）
- **余弦衰减**：3e-4 → ~0，平滑下降
- **为什么不用 linear**：cosine 在后期下降更慢，给模型更多时间在低学习率下精修

### 六、Epoch 间评估

**每个 epoch 结束后：**

1. 在 156 条验证集上做**生成式推理**（beam=4）
2. 计算三个指标：

```python
import sacrebleu

bleu = sacrebleu.corpus_bleu(preds, [refs]).score
chrf = sacrebleu.corpus_chrf(preds, [refs], word_order=2).score  # chrF++
geo_mean = (bleu * chrf) ** 0.5  # 竞赛指标
```

3. 按 `geo_mean` 选 best checkpoint
4. 同时记录训练 loss 曲线，监控过拟合

**评估时的生成配置：**

```python
gen_kwargs = {
    "max_new_tokens": 1024,
    "num_beams": 4,
    "early_stopping": True,
    "no_repeat_ngram_size": 0,   # 翻译任务不限制重复
    "length_penalty": 1.0,
}
```

**预期评估时间**：156 条 × beam=4 × ~2s ≈ 5 分钟/epoch。30 个 epoch 共约 2.5 小时评估时间。

> 优化：可以前 5 个 epoch 不做生成评估（只看 eval loss），之后每 epoch 做生成评估。节省约 25 分钟。

## Baseline 终极方案：ByT5-Base 文档级微调

### 一、训练框架选择

**HuggingFace `transformers` Seq2SeqTrainer + `accelerate`**

为什么不选其他：
- **自写训练循环**：灵活但费时，baseline 阶段不值得。Seq2SeqTrainer 内置了 bf16、gradient checkpointing、generation eval、early stopping，一个参数搞定
- **DeepSpeed**：单卡 32GB 跑 580M 模型绰绰有余，不需要多卡并行框架
- **fairseq / OpenNMT**：对 T5 架构支持不如 HuggingFace 原生，自定义 tokenizer 配合也麻烦
- **PyTorch Lightning**：多一层抽象没有实质收益

Seq2SeqTrainer 唯一需要定制的：**自定义 BatchSampler**（下面展开）和 `compute_metrics`。框架本身不是瓶颈。

---

### 二、截断策略：源文本零截断，目标文本近零截断

你说得对，1024 截掉 12.4% 的源文本太粗暴了。数据告诉我们一个好消息：

| 设定 | 覆盖率 | 代价 |
|------|--------|------|
| `max_source = 1088` | **100.0%**（max 就是 1087） | +64 字节，成本可忽略 |
| `max_target = 2048` | **98.6%**（22 条被截断） | 总目标信息丢失仅 2.16% |

**源文本：max_source_length = 1088，零截断**

源文本最长 1087 字节（含 31 字节前缀），设 1088 就是 100% 覆盖。不存在任何信息损失。比起 1024 多出 64 字节，对注意力的额外计算微乎其微（1088² vs 1024² 仅增 6.5%）。

**目标文本：max_target_length = 2048，近零截断**

- 1024 截断 172 条（11%），太狠
- 1536 截断 59 条（3.8%），还是不够好
- **2048 只截断 22 条（1.4%），丢失全语料 2.16% 信息**
- 4096 零截断，但 decoder 端代价太大

那 22 条被截断的样本平均保留了 73% 的翻译内容，模型仍然能从中学到有价值的对齐关系。这是一个可以接受的损失。

**为什么不设 4096？** 因为 decoder 是自回归生成的，`max_target=4096` 意味着这 22 条样本的训练步里 decoder 要跑 4096 步。而且测试是句子级的，目标输出不会超过 500 字节。花大量计算在极少数超长目标上，性价比极低。

---

### 三、注意力加速：SDPA，不是 Flash Attention

你的 RTX 5090 是 **Blackwell 架构（compute capability 12.0）**。关键事实：

- `flash-attn` 库目前支持到 sm_90（Hopper），**尚未正式支持 sm_120（Blackwell）**
- 即使强行安装编译，大概率 kernel 不兼容或者性能回退

**正确做法：用 PyTorch 原生 SDPA**

```python
model = T5ForConditionalGeneration.from_pretrained(
    "./byt5-base", 
    attn_implementation="sdpa"  # PyTorch Scaled Dot-Product Attention
)
```

SDPA 是 PyTorch 2.0+ 内置的注意力调度器，它会自动选择最优 kernel：
- **cuDNN Flash Attention**（Blackwell 原生支持）
- **Memory-efficient attention**（xformers 风格）
- **Math fallback**（保底）

在 Blackwell 上 SDPA 会走 cuDNN 的 Flash Attention 路径，效果和 flash-attn 库等价，且无需额外安装。这是唯一正确的选择。

---

### 四、装桶策略：Token Budget Batching

普通的固定 batch_size 对 ByT5 是灾难性浪费。看数据：
- 最短源文本 **54 字节**（含前缀），最长 **1087 字节** → 20 倍差距
- 如果 batch_size=8 + pad to 1088，短序列浪费 95% 的计算

**HuggingFace 的 `group_by_length=True`** 做了一半的工作（按长度分组），但还不够 —— 它仍然是固定样本数 per batch，只是排列更聪明。

**真正的最优方案：Token Budget Sampler**

核心思想：不固定每批样本数，固定每批的**总 token 量**。

```python
# 概念伪代码
token_budget = 8192  # 每个 batch 的总 source token 上限

# 短序列 batch：~450 bytes × 18 samples ≈ 8100 tokens → 18 样本/batch
# 长序列 batch：~1080 bytes × 7 samples ≈ 7560 tokens → 7 样本/batch
```

从之前的分析：
- budget=8192 → 平均 batch=25.5 样本，中位 18，最小 7
- **GPU 利用率几乎 100%**，每个 batch 的计算量恒定

实现方式：自定义一个 `TokenBudgetBatchSampler`，传入 Trainer 的 DataLoader。这不复杂，几十行代码。

同时配合 **动态 padding**（`DataCollatorForSeq2Seq(padding="longest")`），每个 batch pad 到该 batch 的最长序列，而不是全局 max。

### 六、损失函数

**交叉熵 + 标签平滑 0.1**

```
L = (1 - ε) × CE(y, ŷ) + ε × H(U)    其中 ε = 0.1, U 为词表均匀分布
```

1561 条数据微调 580M 参数，模型极容易对训练标签过度自信。标签平滑的本质是**软化目标分布**，让模型不在任何单个 token 上给出 100% 的概率，这对泛化至关重要。

不需要其他损失。R-Drop、对比学习等方法在数据量如此少时收益不稳定，不适合 baseline。

---

### 七、调度器

**余弦退火 + 线性预热**

为什么余弦比线性衰减好：
- 线性衰减的末尾学习率下降速度恒定，模型精修时间不够
- 余弦退火在中段保持较高学习率（探索更多），在末段**极其缓慢地降低**（精修更细）
- 对小数据集，这个"长尾精修"阶段尤为关键

预热 6% 步数是为了避免初始大梯度破坏预训练权重。ByT5 的预训练分布和阿卡德语差距极大，前几步的梯度会很大。

---

### 八、评估策略

**每 epoch 做完整的生成式评估：**

```python
def compute_metrics(eval_preds):
    preds, labels = eval_preds
    # decode bytes back to strings
    decoded_preds = tokenizer.batch_decode(preds, skip_special_tokens=True)
    decoded_labels = tokenizer.batch_decode(labels, skip_special_tokens=True)
    
    bleu = sacrebleu.corpus_bleu(decoded_preds, [decoded_labels]).score
    chrf = sacrebleu.corpus_chrf(decoded_preds, [decoded_labels], 
                                  word_order=2).score
    
    geo_mean = (bleu * chrf) ** 0.5 if bleu > 0 and chrf > 0 else 0.0
    
    return {"bleu": bleu, "chrf++": chrf, "geo_mean": geo_mean}
```

**为什么每个 epoch 都要做生成评估而不是只看 eval loss**：
- eval loss（交叉熵）和竞赛指标（BLEU/chrF++）不是单调关系
- loss 最低的 checkpoint 不一定 BLEU 最高
- 必须用真正的生成输出来算指标

**评估时间估算**：156 条 × beam=4，批量生成 → 每次评估约 1-2 分钟，50 epochs 共约 1 小时。完全可接受。

你现在 `compute_metrics` 里的核心逻辑在 `scripts/data_utils.py`：

```161:186:scripts/data_utils.py
def make_compute_metrics(tokenizer):
    """Return a compute_metrics closure compatible with Seq2SeqTrainer."""

    def compute_metrics(eval_preds):
        preds, labels = eval_preds

        if isinstance(preds, tuple):
            preds = preds[0]

        preds = np.where(preds != -100, preds, tokenizer.pad_token_id)
        labels = np.where(labels != -100, labels, tokenizer.pad_token_id)

        decoded_preds = tokenizer.batch_decode(preds, skip_special_tokens=True)
        decoded_labels = tokenizer.batch_decode(labels, skip_special_tokens=True)

        decoded_preds = [p.strip() for p in decoded_preds]
        decoded_labels = [l.strip() for l in decoded_labels]

        bleu = sacrebleu.corpus_bleu(decoded_preds, [decoded_labels]).score
        chrf = sacrebleu.corpus_chrf(
            decoded_preds, [decoded_labels], word_order=2
        ).score
```

## 现在这段代码在做什么

流程是：

1. `trainer.predict()` 或 eval 时先拿到 `preds` / `labels`
2. 它们是二维 token 矩阵，比如 `(313, 1024)`
3. 把 `-100` 换成 `pad_token_id`
4. 调 `tokenizer.batch_decode(...)`
5. 得到字符串列表
6. 再交给 `sacrebleu` 计算 BLEU / chrF++

这里面最慢的，不是 `sacrebleu`，而是 **`batch_decode()`**

---

## 为什么这一步会这么慢

因为 ByT5 不是普通 subword tokenizer，它是 **byte-level tokenizer**。

也就是说：
- 一个英文字符可能就是 1 个字节
- 一个带重音/变音的字符可能是多个 UTF-8 字节
- 你的输出矩阵 `(313, 1024)` 本质上是很多很多字节 token

而 `tokenizer.batch_decode()` 会：

1. 逐行处理 313 条样本
2. 每行扫描 1024 个位置
3. 跳过 special token
4. 把 token 转回字节序列
5. 再做 UTF-8 解码

问题是：
- 每行平均只有大约 `466` 个有效 token
- 但它还是会把后面一大截 padding 区域一起处理
- 而且 `batch_decode()` 是通用实现，不是为 ByT5 的这种场景专门优化的

所以就慢了。

---

## “重写 decode 路径”到底指什么

不是说自己发明 BLEU，也不是改评估公式。

而是把这一步：

```python
decoded_preds = tokenizer.batch_decode(preds, skip_special_tokens=True)
decoded_labels = tokenizer.batch_decode(labels, skip_special_tokens=True)
```

换成一种**更适合 ByT5 的实现**。

### 方案 A：先裁掉 padding，再逐条 decode
先把每一行里无效的 `-100` / `pad` 去掉，再 decode。

好处：
- 少处理很多 padding
- 比现在快一些

我已经测过了，大概能从 `43s` 到 `30s`，有提升，但不够大。

---

### 方案 B：直接按 ByT5 的字节规则还原
这是“重写 decode 路径”的核心。

ByT5 的 token 本质上就是：
- `token_id = byte_value + offset`

也就是说，我们完全可以不走 `tokenizer.decode()` 这条慢路径，而是：

1. 把特殊 token 去掉
2. 把 token id 还原成原始 byte
3. 用 `bytes(...).decode("utf-8", ...)` 直接转成字符串

伪代码大概是：

```python
def fast_byt5_decode(row):
    byte_values = []
    for token_id in row:
        if token_id 是 pad/eos/-100:
            continue
        if token_id 对应普通字节:
            byte_values.append(token_id - offset)
    return bytes(byte_values).decode("utf-8", errors="ignore").strip()
```

这就叫“重写 decode 路径”。

本质上是：

- 以前：`tokenizer.batch_decode()`
- 现在：`我们自己按 ByT5 的字节规则解码`

---

## 为什么这招有效

因为 ByT5 的 tokenizer 结构非常简单。

对它来说，decode 不一定需要走 HuggingFace 那套通用 tokenizer 框架。  
我们可以直接做更贴近底层的事情：

- 少一次通用封装
- 少处理一堆 padding
- 少做很多 Python 层逻辑

所以 profiling 才会出现这种结果：

- 当前：`43.15s`
- trim + tokenizer：`30.39s`
- native bytes：`0.59s`

这个量级差距说明，**慢的不是“评估本身”，而是“通用 decode 实现”**

---

## 为什么还不能立刻直接替换

因为我发现有 `14` 条样本和 `tokenizer.decode()` 的结果不完全一致。

原因不是大问题，而是：

- 有些样本在 `max_length=1024` 被截断时
- 截在了某个 UTF-8 多字节字符的中间
- 原生 `bytes.decode()` 和 `tokenizer.decode()` 在这种边界上的处理不完全一样

也就是说，重写 decode 路径之后，需要再做一步：

- 让它和 `tokenizer.decode()` 的结果尽可能一致
- 比如用 `errors="ignore"`，或者尾部做 UTF-8 安全裁切

所以这件事不是不能做，而是要**做成“快且一致”**

---

## 一句话总结

“重写 `compute_metrics` 的 decode 路径”就是：

**不再用慢的 `tokenizer.batch_decode()` 去把 ByT5 的输出转成字符串，而是根据 ByT5 的字节级特性，自己实现一个更快的解码函数，再把解码后的字符串交给 BLEU / chrF++ 计算。**

换句话说：

- **指标不变**
- **结果目标不变**
- **只是把 token -> text 这一步换成更快的实现**

def _canon_decimal(x: float) -> str:
    ip = int(math.floor(x + 1e-12))
    frac = x - ip
    best = min(_ALLOWED_FRACS, key=lambda t: abs(frac - t[0]))

    if abs(frac - best[0]) <= _FRAC_TOL:
        dec = best[1]
        if ip == 0:
            return dec
        return f"{ip}{dec[1:]}" if dec.startswith("0.") else f"{ip}+{dec}"

    return f"{x:.5f}".rstrip("0").rstrip(".")

    (re.compile(r'5\s*/\s*12\s+shekels?', re.I), '⅔ shekel 15 grains'),
    (re.compile(r'7\s*/\s*12\s+shekels?', re.I), '½ shekel 15 grains'),
    (re.compile(r'1\s*/\s*12\s*(?:\(shekel\)|\bshekel)?', re.I), '15 grains'),
]

_SLASH_ALT_RE = re.compile(r'(?<!\d)\s*/\s*(?!\d)\S+')
_STRAY_MARKS_RE = re.compile(r'<<[^>]*>>|<(?!gap\b)[^>]*>')
_MULTI_GAP_RE = re.compile(r'(?:<gap>\s*){2,}')

def _month_repl(m: re.Match) -> str:
    return f"Month {_ROMAN2INT.get(m.group(1).upper(), m.group(1))}"


class VectorizedPostprocessor:
    def postprocess_batch(self, translations: List[str]) -> List[str]:
        s = pd.Series(translations).fillna("").astype(str)

        s = _normalize_gaps_vec(s)
        s = s.str.replace(_PN_RE, "<gap>", regex=True)
        s = s.str.replace(_COMMODITY_RE, _commodity_repl, regex=True)

        for pat, repl in _SHEKEL_REPLS:
            s = s.str.replace(pat, repl, regex=True)

        s = s.str.replace(_EXACT_FRAC_RE, _frac_repl, regex=True)
        s = s.str.replace(_FLOAT_RE, lambda m: _canon_decimal(float(m.group(1))), regex=True)

        s = s.str.replace(_SOFT_GRAM_RE, " ", regex=True)
        s = s.str.replace(_BARE_GRAM_RE, " ", regex=True)
        s = s.str.replace(_UNCERTAIN_RE, "", regex=True)

        s = s.str.replace(_STRAY_MARKS_RE, "", regex=True)
        s = s.str.replace(_SLASH_ALT_RE, "", regex=True)

        # Remove only curly quotes; keep straight quotes and apostrophes.
        s = s.str.replace(_CURLY_QUOTES_RE, "", regex=True)

        s = s.str.replace(_MONTH_RE, _month_repl, regex=True)
        s = s.str.replace(_MULTI_GAP_RE, "<gap>", regex=True)

        s = s.str.replace("<gap>", "\x00GAP\x00", regex=False)
        s = s.str.translate(_FORBIDDEN_TRANS)
        s = s.str.replace("\x00GAP\x00", " <gap> ", regex=False)

        s = s.str.replace(_REPEAT_WORD_RE, r"\1", regex=True)
        for n in range(4, 1, -1):
            pat = r"\b((?:\w+\s+){" + str(n-1) + r"}\w+)(?:\s+\1\b)+"
            s = s.str.replace(pat, r"\1", regex=True)

        s = s.str.replace(_PUNCT_SPACE_RE, r"\1", regex=True)
        s = s.str.replace(_REPEAT_PUNCT_RE, r"\1", regex=True)
        s = s.str.replace(_WS_RE, " ", regex=True).str.strip()

        return s.tolist()
7. Dataset and bucketed batching
The dataset applies preprocessing once. The custom sampler groups similar sequence lengths together to reduce padding waste.

class AkkadianDataset(Dataset):
    def __init__(self, df: pd.DataFrame, preprocessor: OptimizedPreprocessor, logger: logging.Logger):
        self.sample_ids = df["id"].tolist()
        proc = preprocessor.preprocess_batch(df["transliteration"].tolist())
        self.input_texts = ["translate Akkadian to English: " + t for t in proc]
        logger.info(f"Dataset: {len(self.sample_ids)} samples")

    def __len__(self):
        return len(self.sample_ids)

    def __getitem__(self, idx):
        return self.sample_ids[idx], self.input_texts[idx]


class BucketBatchSampler(Sampler):
    def __init__(self, dataset, batch_size, num_buckets, logger, shuffle=False):
        self.batch_size = batch_size
        self.shuffle = shuffle

        lengths = [len(t.split()) for _, t in dataset]
        sorted_idx = sorted(range(len(lengths)), key=lambda i: lengths[i])

        bsize = max(1, len(sorted_idx) // max(1, num_buckets))
        self.buckets = [
            sorted_idx[i * bsize : None if i == num_buckets - 1 else (i + 1) * bsize]
            for i in range(num_buckets)
        ]

        for i, b in enumerate(self.buckets):
            if b:
                bl = [lengths[x] for x in b]
                logger.info(f"  Bucket {i}: {len(b)} samples, len [{min(bl)}, {max(bl)}]")

    def __iter__(self):
        for bucket in self.buckets:
            b = list(bucket)
            if self.shuffle:
                random.shuffle(b)
            for i in range(0, len(b), self.batch_size):
                yield b[i:i+self.batch_size]

    def __len__(self):
        return sum(math.ceil(len(b) / self.batch_size) for b in self.buckets)

class ModelWrapper:
    def __init__(self, model_path: str, cfg: EnsembleMBRConfig, logger: logging.Logger, label: str):
        self.cfg = cfg
        self.logger = logger
        self.label = label
        self.tokenizer = None
        self.model = None

        logger.info(f"[{label}] Loading from {model_path}")
        self.tokenizer = AutoTokenizer.from_pretrained(model_path)
        self.model = AutoModelForSeq2SeqLM.from_pretrained(model_path).to(cfg.device).eval()

        if cfg.device.type == "cuda":
            try:
                torch.set_float32_matmul_precision("high")
            except Exception:
                pass

        n = sum(p.numel() for p in self.model.parameters())
        logger.info(f"[{label}] {n:,} parameters")

        if cfg.device.type == "cuda":
            used = torch.cuda.memory_allocated() / 1e9
            logger.info(f"[{label}] GPU mem used: {used:.2f} GB")

        if cfg.use_better_transformer and cfg.device.type == "cuda":
            try:
                from optimum.bettertransformer import BetterTransformer
                self.model = BetterTransformer.transform(self.model)
                logger.info(f"[{label}] BetterTransformer applied")
            except Exception as e:
                logger.warning(f"[{label}] BetterTransformer skipped: {e}")

    def collate(self, batch_samples):
        ids = [s[0] for s in batch_samples]
        texts = [s[1] for s in batch_samples]

        enc = self.tokenizer(
            texts,
            max_length=self.cfg.max_input_length,
            padding=True,
            truncation=True,
            return_tensors="pt",
        )
        return ids, enc

    def generate_candidates(self, input_ids, attention_mask, beam_size: int) -> List[List[str]]:
        cfg = self.cfg
        B = input_ids.shape[0]
        ctx = _bf16_ctx(cfg.device, cfg.use_bf16_amp)

        with ctx:
            nb = max(beam_size, cfg.num_beam_cands)
            beam_out = self.model.generate(
                input_ids=input_ids,
                attention_mask=attention_mask,
                do_sample=False,
                num_beams=nb,
                num_return_sequences=cfg.num_beam_cands,
                max_new_tokens=cfg.max_new_tokens,
                length_penalty=cfg.length_penalty,
                early_stopping=cfg.early_stopping,
                repetition_penalty=cfg.repetition_penalty,
                use_cache=True,
            )
            beam_texts = self.tokenizer.batch_decode(beam_out, skip_special_tokens=True)

            samp_texts = []
            if cfg.num_sample_cands > 0:
                samp_out = self.model.generate(
                    input_ids=input_ids,
                    attention_mask=attention_mask,
                    do_sample=True,
                    num_beams=1,
                    top_p=cfg.mbr_top_p,
                    temperature=cfg.mbr_temperature,
                    num_return_sequences=cfg.num_sample_cands,
                    max_new_tokens=cfg.max_new_tokens,
                    repetition_penalty=cfg.repetition_penalty,
                    use_cache=True,
                )
                samp_texts = self.tokenizer.batch_decode(samp_out, skip_special_tokens=True)

        Rb, Rs = cfg.num_beam_cands, cfg.num_sample_cands
        pools = []
        for i in range(B):
            p = list(beam_texts[i*Rb:(i+1)*Rb])
            if Rs > 0:
                p += list(samp_texts[i*Rs:(i+1)*Rs])
            pools.append(p)

        return pools

    def unload(self):
        label = self.label

        try:
            from optimum.bettertransformer import BetterTransformer
            self.model = BetterTransformer.reverse(self.model)
        except Exception:
            pass

        del self.model
        del self.tokenizer
        self.model = None
        self.tokenizer = None

        gc.collect()
        if torch.cuda.is_available():
            torch.cuda.empty_cache()
            torch.cuda.synchronize()
            free = (torch.cuda.get_device_properties(0).total_memory - torch.cuda.memory_allocated()) / 1e9
            self.logger.info(f"[{label}] Unloaded. GPU free: {free:.2f} GB")
9. MBR selector
MBR chooses the candidate with the highest average chrF++ agreement against the other candidates in the pool.

class MBRSelector:
    def __init__(self, pool_cap: int = 32):
        self._metric = sacrebleu.metrics.CHRF(word_order=2)
        self.pool_cap = pool_cap

    def _chrfpp(self, a: str, b: str) -> float:
        a, b = (a or "").strip(), (b or "").strip()
        if not a or not b:
            return 0.0
        return float(self._metric.sentence_score(a, [b]).score)

    @staticmethod
    def _dedup(xs: List[str]) -> List[str]:
        seen, out = set(), []
        for x in xs:
            x = str(x).strip()
            if x and x not in seen:
                out.append(x)
                seen.add(x)
        return out

    def pick(self, candidates: List[str]) -> str:
        cands = self._dedup(candidates)

        if self.pool_cap:
            cands = cands[:self.pool_cap]

        n = len(cands)
        if n == 0:
            return ""
        if n == 1:
            return cands[0]

        best_i, best_s = 0, -1e9
        for i in range(n):
            s = sum(self._chrfpp(cands[i], cands[j]) for j in range(n) if j != i)
            s /= max(1, n - 1)
            if s > best_s:
                best_s, best_i = s, i

        return cands[best_i]
10. End-to-end ensemble engine
This class runs the full pipeline:

preprocess test inputs
generate candidates with Model A
generate candidates with Model B
merge candidate pools
postprocess outputs
select the final translation with MBR
write checkpoints and validate the submission
class EnsembleMBREngine:
    def __init__(self, cfg: EnsembleMBRConfig, logger: logging.Logger):
        self.cfg = cfg
        self.logger = logger
        self.preprocessor = OptimizedPreprocessor()
        self.postprocessor = VectorizedPostprocessor()
        self.mbr = MBRSelector(pool_cap=cfg.mbr_pool_cap)

    def _adaptive_beams(self, attn: torch.Tensor) -> int:
        if not self.cfg.use_adaptive_beams:
            return self.cfg.num_beams

        med = float(attn.sum(dim=1).float().median().item())
        short = max(self.cfg.num_beam_cands, self.cfg.num_beams // 2)
        return short if med < 100 else self.cfg.num_beams

    def _build_dataloader(self, dataset: AkkadianDataset, wrapper: ModelWrapper) -> DataLoader:
        if self.cfg.use_bucket_batching:
            sampler = BucketBatchSampler(
                dataset,
                self.cfg.batch_size,
                self.cfg.num_buckets,
                self.logger,
            )
            return DataLoader(
                dataset,
                batch_sampler=sampler,
                num_workers=self.cfg.num_workers,
                collate_fn=wrapper.collate,
                pin_memory=(self.cfg.device.type == "cuda"),
            )

        return DataLoader(
            dataset,
            batch_size=self.cfg.batch_size,
            shuffle=False,
            num_workers=self.cfg.num_workers,
            collate_fn=wrapper.collate,
            pin_memory=(self.cfg.device.type == "cuda"),
        )

    def _run_one_model(self, wrapper: ModelWrapper, dataset: AkkadianDataset) -> dict:
        dl = self._build_dataloader(dataset, wrapper)
        pools_by_id = {}

        with torch.inference_mode():
            for batch_ids, enc in tqdm(dl, desc=f"[{wrapper.label}]"):
                input_ids = enc.input_ids.to(self.cfg.device, non_blocking=True)
                attn = enc.attention_mask.to(self.cfg.device, non_blocking=True)
                beam_size = self._adaptive_beams(attn)

                try:
                    batch_pools = wrapper.generate_candidates(input_ids, attn, beam_size)
                    for sid, pool in zip(batch_ids, batch_pools):
                        pools_by_id[str(sid)] = pool

                except RuntimeError as e:
                    if "out of memory" in str(e).lower():
                        self.logger.error(f"OOM in [{wrapper.label}] — skipping batch")
                        torch.cuda.empty_cache()
                        for sid in batch_ids:
                            pools_by_id.setdefault(str(sid), [])
                    else:
                        raise

                except Exception as e:
                    self.logger.error(f"[{wrapper.label}] batch error: {e}")
                    for sid in batch_ids:
                        pools_by_id.setdefault(str(sid), [])

                if torch.cuda.is_available():
                    torch.cuda.empty_cache()

        return pools_by_id

    def run(self, test_df: pd.DataFrame) -> pd.DataFrame:
        cfg, logger = self.cfg, self.logger

        logger.info("=" * 60)
        logger.info("Ensemble × MBR | Cross-model candidate pooling")
        logger.info(f"  Model A : {cfg.model_a_path}")
        logger.info(f"  Model B : {cfg.model_b_path}")
        logger.info(f"  Pool per model: beam×{cfg.num_beam_cands} + sample×{cfg.num_sample_cands}")
        logger.info(f"  MBR pool cap  : {cfg.mbr_pool_cap}")
        logger.info(f"  BF16 AMP      : {cfg.use_bf16_amp}")
        logger.info(f"  batch_size    : {cfg.batch_size}")
        logger.info("=" * 60)

        dataset = AkkadianDataset(test_df, self.preprocessor, logger)
        sample_ids = [str(s) for s in dataset.sample_ids]

        logger.info("Phase 1/2 — Model A inference")
        wrapper_a = ModelWrapper(cfg.model_a_path, cfg, logger, "Model-A")
        pools_a = self._run_one_model(wrapper_a, dataset)
        wrapper_a.unload()
        del wrapper_a

        logger.info("Phase 2/2 — Model B inference")
        wrapper_b = ModelWrapper(cfg.model_b_path, cfg, logger, "Model-B")
        pools_b = self._run_one_model(wrapper_b, dataset)
        wrapper_b.unload()
        del wrapper_b

        logger.info("Phase 3/3 — Pool merge + MBR selection")
        results: List[Tuple[str, str]] = []

        for sid in tqdm(sample_ids, desc="MBR"):
            combined = pools_a.get(sid, []) + pools_b.get(sid, [])
            pp = self.postprocessor.postprocess_batch(combined) if combined else []
            chosen = self.mbr.pick(pp)

            if not chosen or not chosen.strip():
                chosen = "The tablet is too damaged to translate."

            results.append((sid, chosen))

            if len(results) % cfg.checkpoint_freq == 0:
                ckpt = Path(cfg.output_dir) / f"checkpoint_{len(results)}.csv"
                pd.DataFrame(results, columns=["id", "translation"]).to_csv(ckpt, index=False)
                logger.info(f"  Checkpoint: {len(results)} rows → {ckpt}")

        result_df = pd.DataFrame(results, columns=["id", "translation"])
        self._validate(result_df)
        return result_df

    def _validate(self, df: pd.DataFrame):
        logger = self.logger
        logger.info("=" * 60)

        empty = df["translation"].str.strip().eq("").sum()
        lens = df["translation"].str.len()

        logger.info(f"Empty     : {empty} ({100 * empty / max(1, len(df)):.2f}%)")
        logger.info(
            f"Len mean  : {lens.mean():.1f}  median: {lens.median():.1f}  min: {lens.min()}  max: {lens.max()}"
        )

        for idx in [0, len(df)//4, len(df)//2, 3*len(df)//4, len(df)-1]:
            row = df.iloc[idx]
            logger.info(f"  ID {row['id']}: {str(row['translation'])[:80]}")

        logger.info("=" * 60)

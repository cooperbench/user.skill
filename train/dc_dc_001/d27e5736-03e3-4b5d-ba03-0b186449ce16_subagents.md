## Overview

Antigravity CLI is a command-line interface for interacting with Antigravity's task artifacts, allowing users to examine tasks, recover backup files, and make changes without using the Antigravity web interface. Google transitioned from Gemini CLI to Antigravity CLI at the Google I/O conference on May 19, 2026.

## Key Features

You can install the command line tool to open Antigravity with the `agy` command. Google has launched Antigravity 2.0, featuring an upgraded desktop app, a CLI tool, and an SDK for custom workflows, enhancing its agentic coding capabilities.

## Core Capabilities

The CLI provides several important functions:
- The Antigravity CLI implements a robust versioning system for all artifacts to ensure audit trails and enable rollback capabilities
- The tool can auto-execute terminal commands or request user review and approval before executing terminal commands

Antigravity CLI is the successor to Gemini CLI and is aligned with Google's broader agent platform.

## Antigravity CLI

**Package name:** `antigravity-cli` (also available as the Homebrew cask `antigravity` and npm package `antigravity-ide`)

**What it is:** Antigravity CLI is Google's successor to Gemini CLI, announced at Google I/O 2026 on May 19, 2026. It is an agentic coding tool and command-line interface that lets you interact with Google's Gemini models directly from your terminal. It supports task management, file operations, terminal command execution (with optional auto-execute or user-approval modes), artifact versioning with rollback, and integrates with Google's broader agent platform. The CLI command is `agy`.

**Official repository:** [github.com/google-antigravity/antigravity-cli](https://github.com/google-antigravity/antigravity-cli)

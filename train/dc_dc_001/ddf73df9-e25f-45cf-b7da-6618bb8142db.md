## 你在本机可直接复现的命令（完整 stdout/stderr）

在终端执行下面这一条即可在屏幕上看到**响应正文 + 末尾 `HTTP:xxx`**（`2>&1` 会把报错也合并出来）：

```bash
curl -sS -w "\nHTTP:%{http_code}\n" --max-time 120 -X POST 'https://api.zhenghandong.shop/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer [REDACTED]' \
  -d '{"model":"inclusionAI/Ling-mini-2.0","messages":[{"role":"user","content":"请用一句话：1+1等于几？"}],"max_tokens":100}' 2>&1
```

若 curl 有 SSL/超时问题，可用 **urllib**（与上面写入文件的逻辑一致）：

```bash
python3 - <<'PY'
import json, urllib.error, urllib.request
url = "https://api.zhenghandong.shop/v1/chat/completions"
payload = {
    "model": "inclusionAI/Ling-mini-2.0",
    "messages": [{"role": "user", "content": "请用一句话：1+1等于几？"}],
    "max_tokens": 100,
}
req = urllib.request.Request(
    url,
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Content-Type": "application/json",
        "Authorization": "Bearer [REDACTED]",
    },
    method="POST",
)
try:
    with urllib.request.urlopen(req, timeout=120) as r:
        print("HTTP:", r.status)
        print(r.read().decode("utf-8", errors="replace"))
except urllib.error.HTTPError as e:
    print("HTTP:", e.code)
    print(e.read().decode("utf-8", errors="replace") if e.fp else "")
except Exception as e:
    print(type(e).__name__ + ":", e)
PY
```

## 需要你自行核对的三件事

1. **HTTP 状态**：curl 行尾的 `HTTP:...`，或 urllib 打印的 `HTTP:`。  
2. **响应体**：JSON 里通常含 `choices` 等字段；错误时多为结构化 error message。  
3. **SSL/网络**：常见为 `SSL: ...`、`Connection timed out`、`Name or service not known` 等，会直接出现在终端或 `API_TEST_RESULT.md` 的 `ERROR:` 行。

> — Jorge Luis Borges, "The Garden of Forking Paths" (1941)

**SSD is a new LLM inference algorithm. It is exact, and it is extremely fast.**

SSD is a new type of speculative decoding (SD). In normal SD, a small and fast model guesses the next few tokens that a larger slower model may generate, and the large model then verifies them in one forward pass: drafting and verification happen one after the other on the same hardware.

In SSD, they happen in parallel, on distinct hardware. The small model anticipates likely verification outcomes in advance, and speculates for all of them at once. If it guessed correctly, the speculation can be returned immediately so drafting overhead is eliminated entirely.

This custom inference engine supports:
- A reference implementation of the SSD algorithm
- Optimized SD and autoregressive baselines
- Qwen3 + Llama3 model families
- Tensor Parallelism
- PagedAttention, CUDAgraphs, torch compilation, prefix caching

## Setup

Requirements: Python 3.11+, CUDA >= 12.8. This code was written and tested on H100s.

## Usage

All commands below run from inside the `bench/` directory. Large models (Llama-3 70B, Qwen-3 32B) take a few minutes for load/warmup/compile before generation starts. Always use `python -O` to disable debug overhead.

### Benchmarks

Use `--all` for full eval across four datasets. Since different data distributions are predictable to varying degrees, the speed of SD/SSD depends a lot on the dataset. Averaging over many prompts from many types of datasets 
gives an overall picture. `--numseqs` is per-dataset, so `--numseqs 128 --all` runs 128 × 4 = 512 prompts total.

```bash
cd bench

# AR — Llama 70B, 4 GPUs
python -O bench.py --llama --size 70 --gpus 4 --b 1 --temp 0 --numseqs 128 --output_len 512 --all

# Sync spec decode — 70B target + 1B draft, 4 GPUs, k=6
python -O bench.py --llama --size 70 --gpus 4 --spec --k 6 --b 1 --temp 0 --numseqs 128 --output_len 512 --all

# Async spec decode (SSD) — 70B target (4 GPUs) + 1B draft (1 GPU), k=7, f=3
python -O bench.py --llama --size 70 --gpus 5 --spec --async --k 7 --f 3 --b 1 --temp 0 --numseqs 128 --output_len 512 --all
```

Use `--qwen --size 32` for Qwen models. See `bench/bench.py` for full args. For SGLang/vLLM baselines, see `bench/README.md`.

# Speculative Speculative Decoding: Key Technical Details

## (1) Core SSD Algorithm vs Standard Speculative Decoding

Standard speculative decoding operates **sequentially**: a draft model generates tokens, then a verifier checks them in a single forward pass. 

SSD operates **in parallel**: "The small model anticipates likely verification outcomes in advance, and speculates for all of them at once." This eliminates drafting overhead by pre-computing multiple token paths simultaneously rather than waiting for verification results.

## (2) Hardware Split Requirements

- **Target model**: assigned to multiple GPUs (e.g., 4 GPUs for 70B Llama)
- **Draft model**: assigned to separate GPU(s) (e.g., 1 GPU for the draft model)

Example from benchmarks: "70B target (4 GPUs) + 1B draft (1 GPU)" shows the physical hardware separation enabling parallel operation.

## (3) Parameters f and k

- **k**: speculation depth (number of tokens speculated ahead). Example: k=7 in async SSD benchmarks.
- **f**: appears to be a speculation factor/branching parameter. Example: f=3 in async SSD benchmarks.

The documentation doesn't explicitly define these parameters beyond usage examples.

The page provides **no explicit constraints** on:
- Draft model architecture requirements
- Temperature restrictions
- Batch size limitations

All benchmarks use temperature=0 and batch size=1, but no statement declares these mandatory.

import torch
import torch.distributed as dist
from transformers import AutoTokenizer

from ssd.engine.helpers.speculate_types import SpeculateResult, VerifyResult, SpeculatorBase
from ssd.engine.helpers.runner_helpers import prepare_prefill_payload
from ssd.engine.sequence import Sequence
from ssd.utils.misc import decode_tokens
from ssd.utils.async_helpers.nccl_pack import send_int64


class SpeculatorAsync(SpeculatorBase):

    def __init__(
        self,
        lookahead: int,
        device: torch.device,
        async_fan_out: int,
        max_blocks: int,
        vocab_size: int,
        draft_dtype: torch.dtype,
        kvcache_block_size: int,
        max_model_len: int,
        async_pg: dist.ProcessGroup,
        draft_runner_rank: int,
        tokenizer: AutoTokenizer,
        verbose: bool,
    ):
        super().__init__(lookahead, device)
        self.async_fan_out = async_fan_out
        self.max_blocks = max_blocks
        self.vocab_size = vocab_size
        self.draft_dtype = draft_dtype
        self.kvcache_block_size = kvcache_block_size
        self.max_model_len = max_model_len
        self.async_pg = async_pg
        self.draft_runner_rank = draft_runner_rank
        self.tokenizer = tokenizer
        self.verbose = verbose
        self.K = lookahead

        # Pre-allocate handshake send/recv buffers (reused every step)
        self._alloc_handshake_bufs(1)

        # Pre-allocate speculate() output buffers (avoid torch.tensor(device=cuda) sync)
        self._recovery_buf = torch.empty(1, dtype=torch.int64, device=device)
        self._speculations_buf = torch.empty(1, lookahead + 1, dtype=torch.int64, device=device)

    def _alloc_handshake_bufs(self, B):
        self._hs_B = B
        d = self.device
        self._cmd = torch.zeros(1, dtype=torch.int64, device=d)
        self._meta = torch.tensor([B, self.K, self.async_fan_out], dtype=torch.int64, device=d)
        self._cache_keys = torch.empty(B, 3, dtype=torch.int64, device=d)
        self._num_tokens_buf = torch.empty(B, dtype=torch.int64, device=d)
        self._temps_buf = torch.empty(B, dtype=torch.float32, device=d)
        self._block_tables_buf = torch.full((B, self.max_blocks), -1, dtype=torch.int32, device=d)
        self._fused_response = torch.empty(B + B * self.K, dtype=torch.int64, device=d)
        self._logits_q = torch.empty(B, self.K, self.vocab_size, dtype=self.draft_dtype, device=d)
        self._extend_counts = torch.zeros(B, dtype=torch.int64, device=d)

    def prefill(self, seqs: list[Sequence], verify_result: VerifyResult) -> SpeculateResult:
        eagle_acts = verify_result.eagle_acts
        input_id_list = [seq.token_ids for seq in seqs]

        # EAGLE token-conditioning shift: token at position j gets conditioning
        # from target act at position j-1. Skip first token per seq and drop
        # last eagle_act per seq so they align correctly.
        if eagle_acts is not None:
            sliced = []
            offset = 0
            for ids in input_id_list:
                seq_len = len(ids)
                sliced.append(eagle_acts[offset:offset + seq_len - 1])
                offset += seq_len
            eagle_acts = torch.cat(sliced, dim=0)
            input_id_list = [ids[1:] for ids in input_id_list]

        max_blocks = (self.max_model_len + self.kvcache_block_size - 1) // self.kvcache_block_size
        cmd, metadata, input_ids, num_tokens, draft_block_table, eagle_acts = prepare_prefill_payload(
            input_id_list, eagle_acts, self.device, max_blocks,
            [seq.draft_block_table for seq in seqs],
        )
        dist.send(cmd, dst=self.draft_runner_rank, group=self.async_pg)
        dist.send(metadata, dst=self.draft_runner_rank, group=self.async_pg)
        send_int64(self.async_pg, self.draft_runner_rank,
                   input_ids, num_tokens, draft_block_table.to(torch.int64))
        if eagle_acts is not None:
            dist.send(eagle_acts, dst=self.draft_runner_rank, group=self.async_pg)
        return SpeculateResult([], [])

    def speculate(self, seqs: list[Sequence], verify_result: VerifyResult) -> SpeculateResult:
        for seq in seqs:
            assert seq.recovery_token_id is not None
            seq.append_token(seq.recovery_token_id)

        if self.verbose:
            sep = '=' * 80
            print(f"\n{sep}", flush=True)
            print(f"[TARGET SEQUENCE TRUNK] Batch size: {len(seqs)}", flush=True)
            for i, seq in enumerate(seqs):
                trunk = seq.token_ids[-20:] if len(seq.token_ids) > 20 else seq.token_ids
                print(f"  Seq {seq.seq_id} (len={len(seq.token_ids)}):", flush=True)
                print(f"    Trunk: ...{decode_tokens(trunk, self.tokenizer)}", flush=True)
                print(f"    Recovery: {seq.recovery_token_id} ({decode_tokens([seq.recovery_token_id], self.tokenizer)})", flush=True)
            print(f"{sep}\n", flush=True)

        eagle = verify_result.eagle_acts is not None
        speculations_tokens, logits_q, cache_hits = self._speculation_request(seqs, eagle)

        # Build speculations using pre-allocated buffers (avoids torch.tensor(device=cuda) sync)
        B = len(seqs)
        if B != self._recovery_buf.shape[0]:
            self._recovery_buf = torch.empty(B, dtype=torch.int64, device=self.device)
            self._speculations_buf = torch.empty(B, self.K + 1, dtype=torch.int64, device=self.device)
        _rec_cpu = torch.tensor([seq.recovery_token_id for seq in seqs], dtype=torch.int64)
        self._recovery_buf.copy_(_rec_cpu, non_blocking=True)
        self._speculations_buf[:, 0] = self._recovery_buf
        self._speculations_buf[:, 1:] = speculations_tokens
        speculations = self._speculations_buf

        for i, seq in enumerate(seqs):
            seq.token_ids.extend(speculations_tokens[i].tolist())
            seq.num_tokens = len(seq.token_ids)
            seq.last_token = seq.token_ids[-1]
            seq.num_draft_cached_tokens += len(speculations_tokens[i]) + 1

        return SpeculateResult(speculations, logits_q, cache_hits)

    def _speculation_request(self, seqs: list[Sequence], eagle: bool):
        B = len(seqs)
        if B != self._hs_B:
            self._alloc_handshake_bufs(B)

        # Fill send buffers in-place (avoids torch.tensor from Python lists)
        for i, seq in enumerate(seqs):
            self._cache_keys[i, 0] = seq.seq_id
            self._cache_keys[i, 1] = seq.last_spec_step_accepted_len - 1
            self._cache_keys[i, 2] = seq.recovery_token_id
            self._num_tokens_buf[i] = seq.num_tokens
            self._temps_buf[i] = seq.draft_temperature if seq.draft_temperature is not None else seq.temperature
            bt = seq.draft_block_table
            bt_len = len(bt)
            if bt_len > 0:
                self._block_tables_buf[i, :bt_len] = torch.tensor(bt, dtype=torch.int32, device=self.device)
            self._block_tables_buf[i, bt_len:] = -1

        # Send cmd + meta + fused payload (temps fused into int64 burst)
        dist.send(self._cmd, dst=self.draft_runner_rank, group=self.async_pg)
        dist.send(self._meta, dst=self.draft_runner_rank, group=self.async_pg)
        temps_as_int64 = self._temps_buf.view(torch.int32).to(torch.int64)
        send_int64(
            self.async_pg, self.draft_runner_rank,
            self._cache_keys, self._num_tokens_buf,
            self._block_tables_buf.to(torch.int64), temps_as_int64,
        )

        if eagle:
            recovery_activations = torch.stack(
                [seq.last_target_hidden_state for seq in seqs], dim=0,
            ).to(self.device)
            dist.send(recovery_activations.to(self.draft_dtype),
                      dst=self.draft_runner_rank, group=self.async_pg)

            # Send extend data for glue decode with fused extend
            K = self.K
            act_dim = recovery_activations.shape[-1]
            for i, seq in enumerate(seqs):
                self._extend_counts[i] = seq.extend_count
            extend_eagle_acts = torch.zeros(B, K, act_dim, dtype=self.draft_dtype, device=self.device)
            extend_token_ids = torch.zeros(B, K, dtype=torch.int64, device=self.device)
            for i, seq in enumerate(seqs):
                n = seq.extend_count
                if n > 0 and seq.extend_eagle_acts is not None:
                    extend_eagle_acts[i, :n] = seq.extend_eagle_acts[:n].to(self.draft_dtype)
                    extend_token_ids[i, :n] = seq.extend_token_ids[:n]
            dist.send(self._extend_counts, dst=self.draft_runner_rank, group=self.async_pg)
            dist.send(extend_eagle_acts, dst=self.draft_runner_rank, group=self.async_pg)
            dist.send(extend_token_ids, dst=self.draft_runner_rank, group=self.async_pg)

        # Recv into pre-allocated buffers
        dist.recv(self._fused_response, src=self.draft_runner_rank, group=self.async_pg)
        cache_hits = self._fused_response[:B]
        speculations = self._fused_response[B:].view(B, self.K)
        dist.recv(self._logits_q, src=self.draft_runner_rank, group=self.async_pg)

        return speculations, self._logits_q, cache_hits

135	        positions = num_tokens - 1 + pos_offset # want to write rec token at post N-1 since [0, ..., N-2] filled by prefill 
136	        context_lens = num_tokens + pos_offset # N+1
137	        # Calculate slot mapping vectorized
138	        block_idx = positions // self.block_size
139	        pos_in_block = positions % self.block_size
140	        batch_indices = torch.arange(input_ids.shape[0], device=self.device)
141	        slot_map = draft_block_tables[batch_indices, block_idx] * self.block_size + pos_in_block
142	
143	        hidden_states = None
144	        spec_activations = None
145	        
146	        if self.config.use_eagle:
147	            assert target_recovery_activations is not None
148	            hidden_states = self.model.fc(target_recovery_activations.to(self.model.fc.weight.dtype))
149	            spec_activations = torch.empty(
150	                input_ids.shape[0], self.config.speculate_k,
151	                self.hf_config.hidden_size,
152	                dtype=self.hf_config.torch_dtype, device=self.device)
153	
154	        for i in range(self.config.speculate_k): # we're going to glue after this anyways, and by sending the spec request target has verified we have K more slots left in our last page 
155	            set_context(
156	                is_prefill=False,
157	                slot_mapping=slot_map,
158	                context_lens=context_lens.to(torch.int32),
159	                block_tables=draft_block_tables,
160	                is_jit=True,
161	            )
162	            
163	            if self.config.use_eagle:
164	                logits, prenorm = self.run_model(input_ids, positions, is_prefill=False, last_only=True, hidden_states=hidden_states)
165	                spec_activations[:, i] = prenorm
166	                hidden_states = prenorm
167	            else:
168	                logits = self.run_model(input_ids, positions, is_prefill=False, last_only=True)
169	            
170	            out_logits[:, i, :] = logits
171	            reset_context()
172	            next_tokens = self.sampler(logits, temperatures, is_tree=True)
173	            out_tokens[:, i] = next_tokens
174	            
175	            # Update for next iteration
176	            input_ids = next_tokens
177	            positions = positions + 1
178	            context_lens = context_lens + 1
179	            # Update slot mapping for next position
180	            block_idx = positions // self.block_size
181	            pos_in_block = positions % self.block_size
182	            slot_map = draft_block_tables[batch_indices, block_idx] * self.block_size + pos_in_block
183	
184	        return spec_activations

186	    def hit_cache_and_respond(self, request_keys, B, K, num_tokens, temperatures, draft_block_tables, target_recovery_activations=None):
187	        """Hits the cache (tensor-backed) and returns tensors to respond to the spec request."""
188	        global ttl, ttl_hit
189	        # Draft model now returns full target vocab size logits (after d2t expansion)
190	        V = self.hf_config.vocab_size
191	
192	        # Init miss slots with valid random logits so token IDs are in-vocab (fixes B>1 crash)
193	        out_logits = torch.empty((B, K, V), dtype=self.hf_config.torch_dtype, device=self.device).uniform_()
194	        out_tokens = out_logits.argmax(dim=-1)
195	        cache_hits = torch.zeros(B, dtype=torch.int64, device=self.device)

197	        assert request_keys.shape == (B, 3), f"ERROR in hit_cache_and_respond: request_keys should be (B, 3), got {request_keys.shape}"
198	        
199	        hidden_size = self.hf_config.hidden_size
200	        out_activations = torch.zeros(
201	            B, K, hidden_size,
202	            dtype=self.hf_config.torch_dtype, device=self.device
203	        ) if self.config.use_eagle else None
204	        
205	        # Statistics
206	        ttl += int(B)

208	        if self.config.verbose:

240	            
241	            # Fill hits
242	            if (cache_hits.any() and not self.config.jit_speculate) or (cache_hits.all() and self.config.jit_speculate):
243	                # print(f'[hit_cache_and_respond] got all cache hits, using cached logits and tokens', flush=True)
244	                # [B], arbitrary if no match but masked out
245	                idx = match.float().argmax(dim=1).to(torch.int64)

248	                out_tokens[sel] = self.tree_cache_tokens[idx[sel]]

251	                if self.config.use_eagle:
252	                    out_activations[sel] = self.tree_cache_activations[idx[sel]]

266	                if self.config.use_eagle:

268	        elif self.config.jit_speculate:
269	            # Cache is empty (first iteration), must JIT all
270	            if self.config.verbose:
271	                print(f"[hit_cache_and_respond] Cache empty, running JIT speculate for all", flush=True)

280	                )
281	            if self.config.use_eagle:

290	        meta = self.recv_tensor((3,), torch.int64)

292	
293	        # Receive all request payload in one fused int64 burst (includes temperatures encoded as int64)
294	        max_blocks = self.config.max_blocks

297	                               total_length=fused_total, device=self.device)
298	        off = 0
299	        cache_keys = fused_req[off:off + (3 * B)].view(B, 3)
300	        off += 3 * B
301	        seq_ids = cache_keys[:, 0]
302	        num_tokens = fused_req[off:off + B].to(torch.int64)
303	        off += B
304	        draft_block_tables = fused_req[off:off + B *
305	                                       max_blocks].view(B, max_blocks).to(torch.int32)
306	        off += B * max_blocks
307	        temps_as_int64 = fused_req[off:off + B]
308	        off += B
309	        assert off == fused_total
310	        temperatures = temps_as_int64.to(torch.int32).view(torch.float32)
311	
312	        target_recovery_activations = torch.zeros(
313	            B, 3 * self.config.d_model_target, dtype=self.hf_config.torch_dtype, device=self.device
314	        ) if self.config.use_eagle else None
315	
316	        extend_counts = None
317	        extend_eagle_acts = None
318	        extend_token_ids = None
319	
320	        if self.config.use_eagle:
321	            dist.recv(target_recovery_activations, src=0, group=self.async_pg)
322	
323	            # Receive extend data for fused glue decode

331	
332	            if self.config.verbose:
333	                recovery_tokens_target = cache_keys[:, 2].clone()
334	                print(f"\n{'='*80}", flush=True)
335	                print(f"[CACHE REQUEST] Batch size: {B}, Spec depth: {K}", flush=True)
336	                for i in range(B):
337	                    seq_id = cache_keys[i, 0].item()
338	                    keep_idx = cache_keys[i, 1].item()
339	                    rec_token_target = recovery_tokens_target[i].item()
340	                    rec_token_text = self.tokenizer.decode([rec_token_target])
341	                    n_ext = extend_counts[i].item()
342	                    print(f"  Seq {seq_id}: keep_idx={keep_idx}, recovery_token={rec_token_target} ('{rec_token_text}'), n_ext={n_ext}", flush=True)
343	                print(f"{'='*80}\n", flush=True)
344	
345	        out_tokens, out_logits, glue_decode_input_ids, cache_hits, out_activations = self.hit_cache_and_respond(
346	            cache_keys, B, K, num_tokens, temperatures, draft_block_tables, target_recovery_activations)
347	
348	        if self.config.verbose:
349	            print(f"[CACHE RESPONSE]", flush=True)
350	            for i in range(B):
351	                hit_status = "HIT" if cache_hits[i].item() == 1 else "MISS"
352	                print(f"  Seq {cache_keys[i, 0].item()}: {hit_status}", flush=True)
353	                if cache_hits[i].item() == 1 or self.config.jit_speculate:
354	                    tokens_list = out_tokens[i, :K].tolist()
355	                    tokens_text = [self.tokenizer.decode([t]) for t in tokens_list]
356	                    print(f"    Tokens: {tokens_list}", flush=True)
357	                    print(f"    Detokenized: {tokens_text}", flush=True)
358	            print(f"", flush=True)
359	
360	        fused_response = torch.cat([cache_hits.reshape(-1), out_tokens.reshape(-1).to(torch.int64)])
361	        dist.send(fused_response, dst=0, group=self.async_pg)
362	        dist.send(out_logits[:, :K, :].contiguous(), dst=0, group=self.async_pg)
363	
364	        partial_tree_decode_args = {
365	            "num_tokens": num_tokens,
366	            "seq_ids": seq_ids,
367	            "temperatures": temperatures,
368	            "dbt": draft_block_tables,
369	            "cache_hits": cache_hits,
370	            "returned_tokens": out_tokens,
371	            "target_recovery_activations": target_recovery_activations,
372	            "previous_activations": out_activations,
373	            "extend_counts": extend_counts,
374	            "extend_eagle_acts": extend_eagle_acts,
375	            "extend_token_ids": extend_token_ids,
376	        }
377	
378	        return glue_decode_input_ids, partial_tree_decode_args

381	        self,
382	        num_tokens: torch.Tensor,  # [B]
383	        draft_block_table: torch.Tensor,  # [B, max_blocks]
384	    ) -> dict:
385	        """
386	        Prepare context for prefill forward pass.
387	        """
388	        B = num_tokens.shape[0]
389	        total = num_tokens.sum().item()
390	        cu_seqlens_q = torch.zeros(B + 1, dtype=torch.int32, device=self.device)
391	        cu_seqlens_q[1:] = torch.cumsum(num_tokens, dim=0)
392	        batch_indices = torch.arange(B, device=self.device, dtype=torch.int64).repeat_interleave(num_tokens)
393	        positions = torch.arange(total, device=self.device, dtype=torch.int64) - cu_seqlens_q[:-1].to(torch.int64).repeat_interleave(num_tokens)
394	        max_seqlen_q = num_tokens.max().item()
395	
396	        # Calculate block indices and offsets for ALL positions
397	        block_indices = (positions // self.block_size).to(torch.int64)
398	        offsets = (positions % self.block_size).to(torch.int32)
399	
400	        # Get block IDs for each position from dbt
401	        block_ids = draft_block_table[batch_indices, block_indices]
402	
403	        # Calculate slot_map for each position
404	        slot_map = (block_ids * self.block_size + offsets).to(torch.int32)
405	
406	        return {
407	            "positions": positions,
408	            "slot_map": slot_map,
409	            "cu_seqlens_q": cu_seqlens_q,
410	            "cu_seqlens_k": cu_seqlens_q.clone(),
411	            "max_seqlen_q": max_seqlen_q,
412	            "max_seqlen_k": max_seqlen_q,
413	        }

431	        slot_map_grid = blk_ids * self.block_size + offsets

452	    def prepare_glue_decode_ctxt_eagle(self, num_tokens, fused_ids, fused_hs, extend_counts, seqlens_q, cu_seqlens_q, dbt, B):
453	        """Prepare context for EAGLE glue decode with FA varlen causal.
454	
455	        Tokens packed contiguously: [ext_0..ext_{n0-1}, rec_0, spec_0..spec_{K-1}, ext_1..., ...]
456	        No padding within sequences. cu_seqlens_q has variable per-seq lengths.
457	        """
458	        K = self.config.speculate_k
459	        total_real = int(cu_seqlens_q[-1].item())
460	
461	        # Per-token batch index and local offset within each seq
462	        batch_idx = torch.repeat_interleave(torch.arange(B, device=self.device), seqlens_q)  # [total_real]
463	        local_off = torch.arange(total_real, device=self.device) - cu_seqlens_q[:-1].long().repeat_interleave(seqlens_q)
464	
465	        # Positions: extend starts at num_tokens-2-n_ext, then rec, then spec
466	        # base_pos[b] = num_tokens[b] - 2 - extend_counts[b] (position of first extend token)
467	        base_pos = (num_tokens - 2 - extend_counts).long()  # [B]
468	        positions = (base_pos[batch_idx] + local_off).to(torch.int64)
469	
470	        # Context lens: last token (spec K-1) at pos num_tokens-2+K, cache has 0..num_tokens-2+K
471	        context_lens = (num_tokens - 1 + K).to(torch.int32)
472	
473	        # Slot mapping
474	        block_idx = (positions // self.block_size).clamp(0, dbt.shape[1] - 1).to(torch.int64)
475	        block_off = (positions % self.block_size).to(torch.int32)
476	        blk_ids = dbt[batch_idx, block_idx]
477	        slot_map = (blk_ids * self.block_size + block_off).to(torch.int32)
478	
479	        return {
480	            "input_ids": fused_ids,
481	            "positions": positions,
482	            "slot_map": slot_map,
483	            "hidden_states": fused_hs,
484	            "cu_seqlens_q": cu_seqlens_q,
485	            "max_seqlen_q": 2 * K + 1,
486	            "context_lens": context_lens,
487	            "block_tables": dbt,
488	        }

179	        accepted_suffixes.append(suffix)

181	    return accepted_suffixes, rec_final.tolist()

## SSD 的核心机制（基于代码而非 README）

`speculator_async.py` + `draft_runner.py` 揭示的真实结构：

1. **draft 独占 GPU + 自循环**。`DraftRunner.draft_loop()` 在独立 rank 上阻塞 `recv_cmd()`，接收 `PREFILL/SPEC/EXIT` 三种命令；target 多卡 TP，draft 单卡。
2. **核心 trick = 提前枚举多个 recovery_token 的可能性**。`hit_cache_and_respond()` 用 `(seq_id, last_accepted_idx, recovery_token)` 做 cache key — draft 在不知道真正 verify 结果时，**对多个候选 recovery_token 各展开一棵 K 深 × F 宽的 tree**，target 回来真实 recovery_token 后查表命中即返回（`async_fan_out` 就是这个 F；`speculate_k` 是 K）。
3. **glue decode + tree decode 两段式**：先用真实 rec + K spec 跑 K+1 长度 attention 抽 prenorm/logits（"glue"），再 `get_forked_recovery_tokens_from_logits` 从每个深度 topk 出 F 个分支跑 tree。
4. **EAGLE 模式其实没有完全异步**。看 `_service_spec_request`：`dist.recv(target_recovery_activations, src=0)` 仍是阻塞同步 — 因为 EAGLE draft 必须依赖 target hidden states，依赖链断不开。它的 EAGLE 路径主要靠 tree fan-out + cache 拿收益，不是靠"消除 drafting overhead"。

## 和我们当前 EAGLE-3 chain verify 的对比

| 维度 | 当前 (`spec_steps=3, topk=2, dtn=7`) | SSD |
|---|---|---|
| Draft/target 物理位置 | 同卡同进程串行 | 分卡分进程 NCCL |
| Tree 形状 | EAGLE-3 chain（topk=2 浅 tree） | F=3 / K=7 深宽 tree |
| Cache | 单步 plan cache | recovery-token branching cache |
| Dynamic spec | NO_SPEC/D5/D7 按 batch 切换 | 无 |

## 可借鉴的具体方向（按性价比排序）

**P0 — 先 profile 再说。** 当前 EAGLE step 里 draft forward 占 step time 多少？我猜 < 15%（draft 484MB FP4 vs target ~15B FP4）。如果 draft 时间本来就很小，SSD 把它藏到 target verify 后面的天花板就很低 — 这一步不做，后面都是空谈。

**P1 — 抄它的 buffer 工程**（低风险、确定收益）。`speculator_async.py` 里 `_alloc_handshake_bufs` 预分配所有 host↔device tensor、`temps_as_int64.view(...).to(torch.int64)` 把 float 塞进 int64 burst 减一次 dist.send 调用。我们 chain verify 每步现有不少 `torch.tensor(device=cuda)` / `.tolist()` 同步点，可以同款预分配。这部分和 SSD 的算法无关，只是 PyTorch 工程。

**P2 — Tree shape 调整**（中等改动）。SSD 默认 `--k 7 --f 3`，意思是 7 步 × 3 分支。我们 `spec3 × topk2` 是更窄的 tree。同 verify cost 下试 `spec2 × topk4` 或 `spec4 × topk2`，看 accept length。这不需要套 SSD 框架，SGLang EAGLE-3 自带 tree attention。

**P3（探索性）— Recovery-token branching cache**。verify 完成前预先对 top-N 可能的 accepted_len × top-M 可能的下一 token 各跑一棵小 tree。EAGLE 这条路被 hidden_states 依赖卡住了 —— 这正是 SSD 自己也没解决干净的地方。只有 vanilla draft（非 EAGLE）才能真异步起来。

**不推荐 P4 — 真把双 process + NCCL 搬过来**。单卡 sm_120 没有"另一套 SM"给你藏 latency，draft 和 target 抢同一个 SM pool；提交包又是单卡假设，工程量大且收益不确定。

## 一句话总结

**算法层面**它对我们没有银弹（核心 trick 在 EAGLE 上就退化了，单卡部署又用不上物理异步）；**工程层面**有几个具体的 buffer 预分配和 fused NCCL 模式值得抄；**最有用的启发**反而是"recovery_token 是个好的 cache key"这个观察，可能可以用在我们的 dynamic spec 切换逻辑里。

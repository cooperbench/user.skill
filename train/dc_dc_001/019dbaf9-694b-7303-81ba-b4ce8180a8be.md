  自建 DERP 怎么搞

  DERP 是 Tailscale 的中继服务器。官方全在海外，你可以自建一台放阿里云。

  原理：
  - 你在阿里云跑一个 derper 服务
  - Tailscale 控制面告诉所有节点"还有这台可选"
  - 服务器和笔记本都能低延迟到达阿里云 → 都选你这台 DERP
  - 两边流量在阿里云中继，延迟低

  步骤（大致）：

  1. 阿里云上准备一个域名（要能解析到阿里云这台机器的公网 IP）
  2. 装 Go，编译 derper：
  go install tailscale.com/cmd/derper@latest
  3. 跑起来：
  derper -hostname=derp.yourdomain.com -certmode=letsencrypt -a :443
  4. 阿里云开放 443/TCP、3478/UDP
  5. 登录 Tailscale 管理后台 → ACLs → 加一段自定义 DERP map：
  "derpMap": {
    "Regions": {
      "900": {
        "RegionID": 900,
        "RegionCode": "aliyun",
        "Nodes": [{"Name": "aliyun1", "RegionID": 900, "HostName":
  "derp.yourdomain.com"}]
      }
    }
  }
  6. 两端 tailscale netcheck 会看到新 region，自动选更近的

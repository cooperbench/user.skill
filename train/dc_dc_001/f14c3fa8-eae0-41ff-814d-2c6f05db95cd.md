# BirdCLEF+ 2025 Kaggle 竞赛 Top 5 方案详细汇总

## 竞赛背景
- **任务**: 识别哥伦比亚 Magdalena Valley 中部的鸟类、两栖动物、昆虫和哺乳动物的声音
- **数据**: 12GB 音频（来源：Xeno-Canto、iNaturalist、CSA），206个目标类别
- **评价指标**: Macro-ROC-AUC
- **推理限制**: 90分钟 CPU-only
- **测试集**: 700个1分钟长的被动声学监测录音，每5秒切片预测

**方案标题**: "Multi-Iterative Noisy Student Is All You Need"

（Kaggle writeup 页面无法直接抓取，以下信息综合自 Habr 综述文章和搜索结果）

### 核心方法
**Sound Event Detection (SED) 模型**：采用 SED 框架，可以精确定位事件的起始/结束时间，从 per-sample 弱标签过渡到 per-frame 强标签预测。

### 数据策略
- 从 Xeno Archive 额外收集了 **5,489 条鸟类录音**
- 额外收集了 **17,197 条昆虫和两栖动物录音**以加强"其他类别"的模型能力

### 验证策略
- **没有找到可靠的本地验证方法**，直接使用 Public Leaderboard 进行验证

### 多阶段训练流程（Multi-Iterative Noisy Student）
1. **Baseline** (Cross-Entropy, AdamW, Cosine Schedule, EfficientNet-B0 + RegNetY-8): → **0.872**
2. **Pseudo Labeling I + MixUp + StochasticDepth**: 0.872 → **0.898**
3. **Power Scaling + Pseudo Labeling II (4轮迭代)**: 0.898 → **0.930**
4. **独立的昆虫/两栖动物 Pipeline**: 0.930 → **0.933**

### 模型集成 (Final Ensemble)
- **EfficientNet-L0, B4, B3**
- **RegNetY-016, RegNetY-008**
- **EfficientNet-B0**（专门用于两栖/昆虫分类）

### 关键创新
- **PowerTransform 应用于伪标签**：使得多轮迭代伪标签成为可能（避免标签过度自信）
- **SED 用于精炼伪标签标注**
- **独立处理不同分类群**（鸟类 vs 昆虫/两栖动物各有专门模型）

## 🥈 第2名: volodymyr & vialactea (Vladimir Sydor) — Score: 0.928
**方案标题**: "Journey Down the Rabbit Hole of Pseudo Labels"
- **论文**: [CEUR-WS Paper](https://ceur-ws.org/Vol-4038/paper_256.pdf)
- **代码**: [GitHub](https://github.com/VSydorskyy/BirdCLEF_2025_2nd_place)

### 五大核心组件
1. 强 Baseline 模型
2. In-domain 迁移学习
3. 半监督学习（伪标签模型蒸馏）
4. 后处理
5. 模型集成

### Baseline 模型架构
- **CNN 骨干**: EfficientNetV2-S + NFNet-L0
- **分类头**: 512 hidden channels, dropout 0.25/0.5, ReLU, GeM pooling
- **损失函数**: Focal Loss + BCE 的线性组合
- **Label Smoothing**: α = 0.05

### 数据增强
- **MixUp** (50%概率): 音频域叠加两个波形，标签取 element-wise maximum
- **Background Mixing**: 用往年 soundscape 和 ESC-50 数据集做背景噪声叠加 (50%概率)
- **SpecAugment**: 标准时间和频率掩码
- **RandomFiltering**: 简化版随机均衡器，模拟通道失真

### 迁移学习 (Pre-training)
- 收集了来自所有往年 BirdCLEF 竞赛的 **16,607 个物种**的分类体系
- 最终预训练数据集: **819,032 条录音，覆盖 7,489 个物种**
- 预训练后只保留 CNN backbone，重新初始化分类头
- **效果**: 0.84 → 0.87 (显著提升)

### 伪标签策略（核心创新）
- **迭代式伪标签**: 初始8个模型→平均预测→筛选→训练新模型→重复
- **筛选逻辑**: 最大类概率 < 0.5 的 chunk 丢弃；低于 0.1 的概率置零
- **Soft Target**: 使用软标签而非硬标签，实现知识蒸馏效果
- **采样策略**: 对每个训练样本，如果对应类在伪标签数据中存在，40%概率替换为伪标签样本
- **3轮迭代**: Iter1 选出 4,430 文件/19,405 chunks; Iter2 选出 1,483/3,750; Iter3 选出 1,437/4,108
- **OOF vs Full 策略**: 也尝试了 Out-of-Fold 伪标签（每轮刷新标签），两种策略的结果合并提升多样性
- **效果**: 0.87 → 0.91 (两轮伪标签)

### 后处理
- **TopN 方法 (N=1)**: 每个片段的物种概率 × 该音频中该物种最高概率值
- 基于假设: "如果动物在录音中发声，它会出现在多个片段中"
- **效果**: +1~1.5% ROC AUC

### 推理优化
- **TTA**: 左右偏移 2.5 秒的测试时增强 → 0.91 → 0.922
- 模型转为 **FP16 OpenVINO** 格式部署
- 频谱提取只做一次，所有集成模型共享

### 训练配置
- 50 epochs, batch size 64
- EfficientNetV2-S: AdamW (lr=1e-4)
- NFNet-L0: RAdam (lr=1e-3)
- Cosine schedule → 1e-6, 无 warmup
- 频谱: 32kHz, 128 mel bands, f_min=20, n_fft=2048, hop=512

### 样本权重 (Class Balancing)
```python
sample_weights = (count_i / total_count) ** (-0.5)
```

### 最终集成
- 3个实验 × 5个fold = **15个模型**的简单平均
- 使用 **Optuna** 选择最优实验组合（最大化 OOF validation macro ROC AUC）

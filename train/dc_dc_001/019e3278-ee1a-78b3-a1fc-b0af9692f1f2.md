KV layout 风险：当前生产是 page size 1，InfLLMv2 paged KV 和 page64 原型都更偏连续 block/page 假设，直接替换容易错。 - CUDA graph / wrapper 状态风险：FlashInfer wrapper 缓存内部 buffer 地址，plan cache 和 cross-forward refresh 一旦处理不严，会出现跨请求污染或 stale metadata。 -

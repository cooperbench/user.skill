---

## 安装结果

| 组件 | 版本 |
|------|------|
| Node.js | v24.14.0 (LTS) |
| npm | v11.9.0 |
| nvm | 已安装 |

---

## 国内源配置

1. **Node 二进制**：通过 `NVM_NODEJS_ORG_MIRROR` 使用 npmmirror 下载  
2. **npm 包**：registry 已设为 `https://registry.npmmirror.com`

---

## 临时使用国内源（最佳实践）

**当前会话临时使用：**
```bash
export npm_config_registry=https://registry.npmmirror.com
# 或单次命令
npm install --registry=https://registry.npmmirror.com
```

**切回官方源：**
```bash
npm config set registry https://registry.npmjs.org
```

**再切回国内源：**
```bash
npm config set registry https://registry.npmmirror.com
```

---

## 新开终端时

nvm 已写入 `~/.bashrc`，新终端会自动加载。若未生效，可执行：

```bash
source ~/.bashrc
# 或
export NVM_DIR="$HOME/.nvm" && [ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
```

---

## 常用命令

```bash
nvm ls              # 查看已安装版本
nvm install 20      # 安装 Node 20
nvm use 20          # 切换版本
npm config get registry   # 查看当前 registry
```

## 答案总结

Claude Code **支持手动限制上下文长度**，有以下配置方式：

### 1. **限制特定模型的上下文长度**

**使用环境变量组合：**
```bash
export CLAUDE_CODE_MAX_CONTEXT_TOKENS=200000    # 限制为 200K
export DISABLE_COMPACT=1                         # 必须同时设置
```

**作用范围：** 全局（当前终端会话）

**说明：** 
- `CLAUDE_CODE_MAX_CONTEXT_TOKENS` 告诉 Claude Code 应该假定的上下文窗口大小
- 仅当 `DISABLE_COMPACT` 同时设置时才生效
- 适用于通过 `ANTHROPIC_BASE_URL` 路由到的模型，且该模型的实际上下文窗口与内置大小不匹配的场景

---

### 2. **限制整体上下文长度（推荐方案）**

**使用 `CLAUDE_CODE_AUTO_COMPACT_WINDOW` 环境变量：**
```bash
export CLAUDE_CODE_AUTO_COMPACT_WINDOW=500000   # 将 1M 模型视为 500K
```

**作用范围：** 全局（当前终端会话）

**说明：**
- 设置自动压缩计算时使用的上下文容量
- 默认值为模型的实际上下文窗口（200K 或 1M）
- 值会被限制在模型的实际上下文窗口以内
- 例如在 1M 模型上设置为 `500000`，会让 Claude 将可用空间视为 500K

---

### 3. **调整自动压缩触发时机**

```bash
export CLAUDE_AUTOCOMPACT_PCT_OVERRIDE=50       # 50% 时触发压缩（默认 95%）
```

**作用范围：** 全局

**说明：**
- 百分比范围：1-100
- 默认在 **95% 容量** 时触发自动压缩
- 设置较低值可更早压缩，保持更多可用空间

```bash
export CLAUDE_CODE_DISABLE_1M_CONTEXT=1
```

**作用范围：** 全局

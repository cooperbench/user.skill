### 可用模型

| 模型名 | 状态 | 调用入口 |
|---|---|---|

| `GLM-5.1` | 可用 | `/v1/chat/completions` |
| `GLM-5-Turbo` | 可用 | `/v1/chat/completions` |

### 基础地址

```bash
https://oneapi-comate.baidu-int.com
```

### 注意

`Kimi-K2.5` 和 `Kimi-K2.6` 调用时需要：

```json
"temperature": 1
```

否则会报参数错误。

### 示例

```bash
curl https://oneapi-comate.baidu-int.com/v1/chat/completions \
  -H "Authorization: Bearer 你的key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "GLM-5",
    "messages": [
      {"role": "user", "content": "ping"}
    ],
    "max_tokens": 32
  }'
```

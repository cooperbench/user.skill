整理了一下你当前的字体配置：

---

## 1. Cursor 编辑器

`~/.config/Cursor/User/settings.json` 里**没有**单独设置字体，会使用系统默认：

```json
{
    "window.commandCenter": true,
    "remote.SSH.remotePlatform": { "5090": "linux" },
    "cursor.general.disableHttp2": true,
    "cursor.general.disableHttp1SSE": true
}
```

也就是说，Cursor 会跟随系统 fontconfig 和 GNOME 的字体设置。

---

## 2. 系统 fontconfig（`/etc/fonts/local.conf`）

你有一套全局字体策略，大致是：

| 用途 | 字体 |
|------|------|
| **无衬线 / UI** | Inter（替代 Sans、Ubuntu Sans、Cantarell、Arial、Helvetica） |
| **等宽 / 代码** | JetBrains Mono（替代 Monospace、Ubuntu Mono、DejaVu Sans Mono） |
| **中文无衬线** | Noto Sans CJK SC（替代微软雅黑、MiSans、PingFang、文泉驿、SimHei） |
| **中文衬线** | Noto Serif CJK SC（替代 SimSun、NSimSun） |

`sans-serif`、`serif`、`monospace` 的 fallback 顺序也按 Inter / Noto / JetBrains Mono 做了配置。

---

## 3. GNOME 桌面字体

- **界面字体**：Inter 11  
- **等宽字体**：JetBrains Mono 11  
- **文档字体**：Inter 11  

---

整体来看，系统字体已经统一成：英文/UI 用 Inter，代码用 JetBrains Mono，中文用 Noto CJK。  
如果你是想在 Cursor 里单独指定字体，可以在 `settings.json` 里加上 `editor.fontFamily` 和 `editor.fontSize`。

Noto Sans CJK SC是什么字体？

> AGENT

**Noto Sans CJK SC** 是 Google Noto 字体项目中的一款无衬线字体，专门用于**简体中文**。

---

### 名称含义

| 部分 | 含义 |
|------|------|
| **Noto** | Google 的 Noto 字体项目，目标是覆盖 Unicode 中的主要语言 |
| **Sans** | 无衬线（sans-serif）风格 |
| **CJK** | 支持中日韩（Chinese, Japanese, Korean）字符 |
| **SC** | 简体中文（Simplified Chinese）版本 |

---

### 特点

- 开源免费（SIL Open Font License）
- 覆盖常用简体中文字符
- 与 Noto Sans 拉丁字母搭配，中英文混排较协调
- 在 Linux 上常用作系统默认中文字体，替代微软雅黑、思源黑体等

---

### 其他 CJK 变体

- **TC**：繁体中文（台湾）
- **HK**：繁体中文（香港）
- **JP**：日文
- **KR**：韩文

这些变体在字形细节上略有差异，以适应不同地区的书写习惯。

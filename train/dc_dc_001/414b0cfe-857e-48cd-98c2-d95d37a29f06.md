## 步骤 3：`run_public_eval_full.py` 中 `infer()`、`None` 与 `output_tokens`

**API 响应处理：** `POST /v1/chat/completions`，`raise_for_status()` 后取 `result["choices"][0]["message"]["content"]`；任意异常则打日志并 **`return idx, ""`**（空字符串，不是 `None`）。

```209:228:/root/shared-nvme/openbmb/scripts/run_public_eval_full.py
    def infer(idx, prompt):
        payload = {
            "model": model_name,
            "messages": [{"role": "user", "content": prompt}],
            "temperature": 0.0,
            "max_tokens": 65536,
            "stop": list(set(stop_words)),
        }
        try:
            resp = requests.post(
                f"{args.api_base.rstrip('/')}/v1/chat/completions",
                json=payload,
                timeout=args.timeout,
            )
            resp.raise_for_status()
            result = resp.json()
            return idx, result["choices"][0]["message"]["content"]
        except Exception as e:
            LOGGER.error("Request failed: %s", e)
            return idx, ""
```

**何时 `prediction` 为 `None`（而不是 `""`）？**  
仅当 **HTTP 成功** 且 JSON 里 **`content` 为 JSON `null`** 时，`requests` 解析后 Python 侧为 `None`，`infer` 会直接把它返回；**不会**走 `except`。这与「200 但 content 为空 / null」的现象一致。  
若请求失败，脚本只会得到 `""`，写入后应为 `"prediction": ""`，而你的文件中**没有**这类记录。

**`output_tokens` 怎么算的：** 不是用 API 的 `usage.completion_tokens`，而是对 **`pred` 字符串** 再跑一遍 `tokenizer.apply_chat_template([{"role": "user", "content": pred}], ...)`，取 **`input_ids` 长度**。即：用「把预测文本当作单条 user 消息」时的 **token 数** 作为 `output_tokens` 的代理指标。

```244:257:/root/shared-nvme/openbmb/scripts/run_public_eval_full.py
                in_len = len(
                    tokenizer.apply_chat_template(
                        [{"role": "user", "content": inputs[idx]}],
                        add_generation_prompt=True,
                        return_dict=True,
                    )["input_ids"]
                )
                out_len = len(
                    tokenizer.apply_chat_template(
                        [{"role": "user", "content": pred}],
                        add_generation_prompt=True,
                        return_dict=True,
                    )["input_ids"]
                )
```

当 `pred` 为 `None` 时，是否报错取决于 `apply_chat_template` 对 `None` 的处理；若能继续，通常会对应一个很小的 `output_tokens`（与你们在 `CLAUDE.md` 里写的 “约 9” 一致）。

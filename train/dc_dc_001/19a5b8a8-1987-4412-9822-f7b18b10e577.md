# Simutack 攻击能力报告

## 1. 攻击类型枚举与常量

定义位置：`/home/user_0a329be7/Downloads/simutack-main/simutack/simutack/attack/AttackEngine.py`（第 24–36 行）

| 常量名 | 位掩码值 | 标签 (ATTACK_LABELS) |
|--------|----------|----------------------|
| `NO_DATA_ATTACK` | 2^0 = 1 | "No Data" |
| `NO_UPDATE_ATTACK` | 2^1 = 2 | "No Update" |
| `SPOOFED_VALUE_ATTACK` | 2^2 = 4 | "Spoofed Value" |
| `CONSTANT_OFFSET_ATTACK` | 2^3 = 8 | "Constant Offset" |
| `DELAY_MESSAGE_ATTACK` | 2^4 = 16 | "Delay Message" |
| `CAMERA_BLINDING_ATTACK` | 2^5 = 32 | "Camera Blinding" |

---

## 2. 攻击引擎架构

- **基类**：`AttackEngine`（`AttackEngine.py`）
- **子类**：
  - `ScalarAttackEngine`：标量数据
  - `VectorAttackEngine`：向量数据
  - `ImageAttackEngine`：图像数据
  - `PointCloudAttackEngine`：点云数据（未完成）

---

## 3. 各攻击类型说明

### 3.1 No Data Attack（无数据攻击）

- **位掩码**：1 (2^0)
- **实现**：`AttackEngine.attack_data()` 中 `data = None`，直接丢弃数据包
- **参数**：无
- **适用传感器**：IMU、GNSS、Camera、Tachometer
- **说明**：完全丢弃当前传感器数据，不向观察者传递

---

### 3.2 No Update Attack（无更新攻击）

- **位掩码**：2 (2^1)
- **实现**：各引擎实现不同
  - **ScalarAttackEngine**：`data.value = self.previous_data.value`，用上一帧值覆盖当前值
  - **VectorAttackEngine**：`data.vector = self.previous_data.vector`
  - **ImageAttackEngine**：`data.image = self.previous_data.image`
  - **PointCloudAttackEngine**：仅有空实现 `pass`
- **参数**：无
- **适用传感器**：Tachometer（Scalar）、IMU/GNSS（Vector）、Camera（Image）
- **说明**：保持上一帧数据不变，模拟传感器“卡住”

---

### 3.3 Spoofed Value Attack（欺骗值攻击）

- **位掩码**：4 (2^2)
- **实现**：
  - **ScalarAttackEngine**：`data.value = self.spoofed_value`
  - **VectorAttackEngine**：`data.vector = self.spoofed_value`
  - **ImageAttackEngine**：未实现（会抛出 `NotImplementedError`）
  - **PointCloudAttackEngine**：仅有空实现
- **参数**：
  - **Tachometer**：`spoofed_value`（float，m/s）
  - **IMU**：`spoofed_value`（list，仅用于 orientation，单位：弧度）
  - **GNSS**：`spoofed_value`（list，[lat, lon, alt]）
- **适用传感器**：Tachometer、IMU、GNSS
- **说明**：用预设值替换真实测量值

---

### 3.4 Constant Offset Attack（恒定偏移攻击）

- **位掩码**：8 (2^3)
- **实现**：
  - **ScalarAttackEngine**：`data.value += self.offset_value`
  - **VectorAttackEngine**：`data.vector += self.offset_value`
  - **ImageAttackEngine**：未实现（会抛出 `NotImplementedError`）
  - **PointCloudAttackEngine**：未实现
- **参数**：
  - **Tachometer**：`offset_value`（float，m/s）
  - **IMU**：`offset_value`（list，仅 orientation）
  - **GNSS**：`offset_value`（list，[lat, lon, alt]）
- **适用传感器**：Tachometer、IMU、GNSS
- **说明**：在真实值上叠加固定偏移

---

### 3.5 Delay Message Attack（消息延迟攻击）

- **位掩码**：16 (2^4)
- **实现**：`AttackEngine.delay_message_attack()`：`data.timestamp = data.timestamp + self.message_delay`
- **参数**：`message_delay`（float，秒）
- **适用传感器**：IMU、GNSS、Camera、Tachometer
- **说明**：仅修改时间戳，模拟消息延迟

---

### 3.6 Camera Blinding Attack（相机致盲攻击）

- **位掩码**：32 (2^5)
- **实现**：`ImageAttackEngine.camera_blinding_attack()`
- **流程**：
  1. 从 `simutack/attack/mask.bin` 加载遮罩图像
  2. 将世界坐标 `attack_location`（默认 `carla.Location(161.39, 309.05, 2.23)`）投影到相机 2D 平面
  3. 根据车辆到攻击点的距离缩放遮罩：`scale_factor = min(15.0 / distance, 1.0)`
  4. 在投影位置叠加遮罩，产生“强光致盲”效果
- **参数**：
  - `vehicle_transform`：车辆位姿
  - `camera_transform`：相机位姿
  - `fov`：视场角
  - 攻击位置：代码中硬编码
- **适用传感器**：仅 Camera
- **说明**：在图像上叠加强光遮罩，模拟激光致盲
- **注意**：`mask.bin` 在项目中未找到，可能导致 `FileNotFoundError`

---

## 4. 传感器与攻击引擎对应关系

| 传感器类型 | 攻击引擎 | 数据格式 | 支持的攻击类型 |
|------------|----------|----------|----------------|
| **IMU** | VectorAttackEngine | VectorData (orientation) | No Data, No Update, Spoofed Value, Constant Offset, Delay Message |
| **GNSS** | VectorAttackEngine | VectorData [lat, lon, alt] | No Data, No Update, Spoofed Value, Constant Offset, Delay Message |
| **Tachometer** | ScalarAttackEngine | ScalarData (速度 m/s) | No Data, No Update, Spoofed Value, Constant Offset, Delay Message |
| **Camera** | ImageAttackEngine | ImageData | No Data, No Update, Delay Message, Camera Blinding |
| **Lidar** | PointCloudAttackEngine | PointCloudData | 未集成（Lidar 在 DataController 中已注释） |
| **PointCloud** | PointCloudAttackEngine | PointCloudData | 仅有 stub 实现 |

---

## 5. 攻击调度参数

- **attack_period**：攻击周期（秒）
  - 0：持续攻击
  - > 0：周期性攻击
  - < 0：随机触发
- **attack_chance**：随机模式下的触发概率（0–1）
- **message_delay**：消息延迟（秒）

---

## 6. 攻击执行顺序

`AttackEngine.attack_data()` 中按以下顺序执行：

1. NO_DATA_ATTACK
2. NO_UPDATE_ATTACK
3. DELAY_MESSAGE_ATTACK
4. SPOOFED_VALUE_ATTACK
5. CONSTANT_OFFSET_ATTACK
6. CAMERA_BLINDING_ATTACK

---

## 7. 注释掉 / 未实现的攻击

- `invalidate_data_attack`
- `glitch_attack`
- `random_value_attack`（仅 PointCloudAttackEngine 有 stub）

---

## 8. 已知问题

1. **Controller.py 第 197 行**：Message Delay 使用 `apply_attack(2**6)`，应为 `apply_attack(2**4)` 或 `apply_attack(16)`。
2. **IMU 攻击范围**：仅对 orientation 做攻击，acceleration 和 angular_velocity 未应用攻击引擎。
3. **Camera 的 Spoofed / Constant Offset**：ImageAttackEngine 未实现，会抛出 `NotImplementedError`。
4. **PointCloudAttackEngine**：未调用 `AttackEngine.__init__()`，且方法均为空实现。
5. **mask.bin**：`ImageAttackEngine` 依赖的 `simutack/attack/mask.bin` 在项目中不存在。
6. **NO_DATA 与其它攻击组合**：若同时启用 NO_DATA 与 NO_UPDATE 等，`data` 会变为 `None`，后续攻击可能触发 `AttributeError`。

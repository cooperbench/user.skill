## 1. Phase 2 Validation (`/home/[REDACTED]fromhust/Downloads/graduate/outputs/phase2_validation/`)

### 时间戳目录
- **20260316-224832**（唯一一次运行）

### 顶层汇总文件
| 文件 | 格式 |
|------|------|
| `attack_rows.json` | JSON |
| `attack_curves.json` | JSON |
| `attack_thresholds.json` | JSON |
| `attack_rows.csv` | CSV |
| `attack_curves.csv` | CSV |
| `attack_thresholds.csv` | CSV |

### 单次运行子目录结构
`{scenario}/{variant}/{attack_name}/{timestamp}/`

- **场景**：`town03_curve_validation`（曲线）、`town05_intersection_validation`（路口）
- **变体**：`ekf`、`ekf_guarded`
- **攻击**：`no_attack`、`gnss_constant_5m_east`、`gnss_constant_5m_north`、`imu_heading_10deg`、`imu_heading_minus10deg`、`joint_3m_5deg`

每个运行目录包含：
- `config.json`：实验配置（Carla、传感器、EKF、控制器、攻击等）
- `summary.json`：运行摘要（步数、时长、碰撞、偏离、跟踪误差等）
- `events.json`：事件记录
- `trajectory.csv`：轨迹
- `route.csv`：路线

### 关键 JSON 结构

**attack_rows.json**：每条记录对应一次运行，包含：
- 场景：`scenario`、`scenario_category`、`town`
- 配置：`variant`、`attack_name`、`attack_type_requested`、`attack_intensity`、`attack_unit`
- 结果：`steps`、`duration_seconds`、`completed`、`collision_count`、`offroad_count`、`failure`、`final_route_progress`、`max_tracking_error_m`、`first_failure_time_seconds`、`guard_trigger_count` 等

**attack_curves.json**：按场景/变体/攻击类型聚合的曲线数据，字段包括：
- `scenario`、`variant`、`attack_type`、`attack_unit`、`attack_intensity`
- `samples`、`failure_rate`、`collision_rate`、`offroad_rate`、`completion_rate`
- `mean_max_tracking_error_m`、`mean_final_route_progress`、`mean_first_failure_time_seconds`

**attack_thresholds.json**：临界强度阈值，字段包括：
- `scenario`、`variant`、`attack_type`、`attack_unit`
- `critical_interval_lower`、`critical_interval_upper`、`half_failure_intensity`

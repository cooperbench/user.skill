> AGENT

在 Linux 上安装支持 XeLaTeX 的 LaTeX 发行版，可以按下面几种方式选一种。

## 方案一：TeX Live（推荐）

TeX Live 是常用发行版，自带 XeLaTeX，适合长期使用。

### 1. 通过包管理器安装（简单）

**Ubuntu/Debian：**
```bash
sudo apt update
sudo apt install texlive-full
```

如果不想装完整版（体积较大），可以只装常用包：
```bash
sudo apt install texlive-base texlive-xetex texlive-fonts-recommended texlive-fonts-extra texlive-latex-extra
```

**Fedora：**
```bash
sudo dnf install texlive-scheme-full
```

**Arch Linux：**
```bash
sudo pacman -S texlive-most
```

### 2. 从官网安装最新版（更灵活）

```bash
# 下载安装脚本
wget https://mirror.ctan.org/systems/texlive/tlnet/install-tl-unx.tar.gz
tar -xzf install-tl-unx.tar.gz
cd install-tl-*
sudo ./install-tl
```

安装时选择包含 `xetex` 的 scheme，或选 `scheme-full` 即可。

---

## 方案二：MiKTeX

MiKTeX 体积相对小，会自动下载缺失的包。

```bash
# Ubuntu/Debian
sudo apt install miktex

# 或从官网下载安装包
# https://miktex.org/download
```

---

## 方案三：TinyTeX（轻量）

适合只需要少量 LaTeX 包的情况：

```bash
wget -qO- "https://yihui.org/tinytex/install-bin-unix.sh" | sh
tlmgr install xetex
```

---

## 安装后验证 XeLaTeX

```bash
xelatex --version
```

应能看到 XeLaTeX 的版本信息。

---

## 建议

- 需要完整、稳定环境：用 **TeX Live**（方案一），优先用系统包管理器安装。
- 想用最新版、自定义安装：用 TeX Live 官网安装脚本。
- 磁盘空间有限：用 **TinyTeX** 或 **MiKTeX**。

XeLaTeX 在 TeX Live 和 MiKTeX 中都是默认包含的，安装后即可使用。

## 推荐方案：apt 安装 TeX Live（含 XeLaTeX）

你的系统是 Ubuntu 25.10，用 apt 安装最省事，且源在国内，下载会较快。

### 方案 A：轻量安装（优先推荐）

适合主要用 XeLaTeX 写中文文档，占用空间较小：

```bash
sudo apt update
sudo apt install texlive-base texlive-xetex texlive-fonts-recommended texlive-fonts-extra texlive-latex-extra texlive-latex-recommended
```

- 包含 XeLaTeX
- 包含常用字体和宏包
- 体积相对较小（约 500MB–1GB）

### 方案 B：完整安装（空间充足时）

你磁盘空间充足，如果希望尽量少遇到缺包问题，可以用完整版：

```bash
sudo apt update
sudo apt install texlive-full
```

- 包含 XeLaTeX、pdflatex、lualatex 等
- 自带 `latex-cjk-all`，中文支持完整
- 体积较大（约 5–7GB）

### 方案 C：仅 XeLaTeX + 中文支持

如果只写中文论文、报告，可以更精简：

```bash
sudo apt update
sudo apt install texlive-xetex texlive-latex-base texlive-fonts-recommended latex-cjk-all
```

---

## 安装后验证

```bash
xelatex --version
```

应能看到类似：

```
XeTeX, Version 3.14159265-2.6-0.999994 ...
```

---

## 建议选择

- 日常写中文论文、报告：用 **方案 A** 或 **方案 C**
- 需要各种宏包、不想频繁补装：用 **方案 B**

你当前磁盘和内存都够用，三种方案都可以；如果希望安装快、占用小，优先用 **方案 A**。

# HUSTtex 项目分析报告

## 一、项目概述

**HUSTtex** 是华中科技大学本科毕业论文相关的 LaTeX 模板集合，作者冯洲（@zfengg），2019 年发布，采用 MIT 协议。

---

## 二、项目结构

```
HUSTtex/
├── README.md
├── LICENSE (MIT)
├── install_fonts.sh          # Linux/macOS 字体安装脚本
├── InstallFonts.ps1          # Windows 字体安装脚本
├── fonts/                    # 所需字体（Windows 字体）
│   ├── SimSun.ttf            # 宋体
│   ├── SimHei.ttf            # 黑体
│   ├── SimKai.ttf             # 楷体
│   ├── SimStzhongs.ttf        # 华文中宋
│   └── TraMingLiU.ttf        # 明体（繁体）
├── HUSTproposal/             # 开题报告
├── HUSTopening/              # 开题答辩（Beamer 幻灯片）
├── HUSTtrans/                # 外文翻译
│   └── myHUSTtrans/          # 用户翻译示例
└── HUSTthesis/               # 毕业论文
```

---

## 三、四个模板概览

| 模板 | 用途 | 文档类 | 特点 |
|------|------|--------|------|
| **HUSTproposal** | 开题报告 | article | 页眉「开题报告」 |
| **HUSTopening** | 开题答辩 | beamer | 答辩幻灯片 |
| **HUSTtrans** | 外文翻译 | article | 页眉「参考文献译文」 |
| **HUSTthesis** | 毕业论文 | article | 含声明页、摘要、目录、参考文献等 |

---

## 四、技术实现要点

### 1. 编译要求

- 必须使用 **XeLaTeX**（模板首行 `%!TEX program = xelatex`）
- 依赖 TeX Live / MacTeX / MiKTeX

### 2. 字体配置（重要）

模板统一使用以下字体：

| 用途 | 中文字体 | 英文字体 |
|------|----------|----------|
| 正文 | SimSun（宋体） | Times New Roman |
| 楷体 | KaiTi | - |
| 黑体 | SimHei | - |
| 华文中宋 | STZhongsong | - |

这些多为 Windows 自带字体，在 **Linux 上默认没有**，需要安装项目自带的 `fonts/` 目录中的字体。

### 3. 版式与结构

- 页边距：上下 2.5cm，左右 3cm
- 行距：约 1.62 倍
- 图表编号：`section-figure` 形式（如 2-1）
- 公式编号：`section-equation` 形式
- 声明页：原创性声明、版权使用授权书
- 摘要：中英文摘要环境 `cnabstract`、`enabstract`

### 4. 依赖宏包

- 中文：`ctex`、`xeCJK`
- 数学：`amsmath`、`amssymb`、`mathrsfs`
- 版式：`geometry`、`fancyhdr`、`setspace`
- 图表：`graphicx`、`float`、`caption`、`booktabs`
- 参考文献：`natbib`
- 其他：`hyperref`、`listings`、`titletoc` 等

---

## 五、在 Linux 上的使用注意

### 1. 字体问题（必须处理）

系统字体检查结果：**SimSun、SimHei、KaiTi、STZhongsong 在 Linux 上均未找到**。

需要先安装项目提供的字体：

```bash
cd /home/[REDACTED]fromhust/Downloads/graduate/HUSTtex
./install_fonts.sh
```

脚本会把 `fonts/` 中的字体复制到 `~/.fonts/`，并执行 `fc-cache -f -v`。

### 2. 字体名称对应关系

项目字体文件与 LaTeX 中使用的字体名对应如下：

| 文件名 | LaTeX 中的字体名 |
|--------|------------------|
| SimSun.ttf | SimSun |
| SimHei.ttf | SimHei |
| SimKai.ttf | KaiTi |
| SimStzhongs.ttf | STZhongsong |

安装后，fontconfig 会按字体元数据识别这些名称。

### 3. Times New Roman

英文字体使用 Times New Roman，Linux 上通常也没有。可选方案：

- 安装 `fonts-liberation` 或 `texlive-fonts-recommended` 中的 Times 替代字体；
- 或安装 `ttf-mscorefonts-installer`（需接受 EULA）。

---

## 六、潜在问题与建议

### 1. `install_fonts.sh` 兼容性

脚本中使用了 `basename -a`（GNU 扩展），在部分系统上可能不支持。若报错，可改为：

```bash
fontsToInstall=$(ls $pathfonts | xargs -I {} basename {})
fontsInstalled=$(ls $pathUsrFonts | xargs -I {} basename {})
```

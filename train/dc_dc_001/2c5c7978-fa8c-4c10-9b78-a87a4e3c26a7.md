## 项目推理脚本后处理方案

根据分析，该项目的推理脚本主要使用了以下后处理方案：

### 1. **TTA (Test Time Augmentation) - 测试时增强**
- 8倍 TTA（2×2×2 = 8种翻转组合）
- 包含 Z轴、Y轴、X轴的翻转及组合翻转
- 增益：约 +0.005 ~ +0.010 LB 分数

### 2. **Frangi Filtering - Hessian 过滤**
- 增强"片状/板状"结构（表面）
- 基于 Hessian 矩阵计算，抑制斑点噪声
- 对 VOI Score（拓扑分数）至关重要

### 3. **Sliding Window with Overlap - 滑动窗口**
- 高重叠度（stride=64）进行预测
- 累加所有 patch 预测后取平均
- 作用：使边缘更平滑

### 4. **Thresholding - 二值化**
- 使用 0.5 阈值进行二值化分割

### 5. **Graph-Based Component Stitching - 基于图的组件拼接**
- 26-连通性提取 3D 连通分量
- 基于表面法向量对齐判断组件是否应合并
- 提升 VOI Split 和 TopoScore

### 6. **形态学操作（训练时使用）**
- `soft_erode`、`soft_dilate`、`soft_open`
- 用于损失函数的软形态学操作

### 推理流程
```
模型加载 → Sliding Window → 8x TTA → 平均 → [Frangi Filter] → [Graph Stitching] → 阈值二值化 → 输出
```

def frangi_surface_filter(volume, scale=1.0, alpha=0.5, beta=0.5, gamma=15.0):
    """Refined Frangi filter to enhance sheet-like structures."""
    from skimage.filters import frangi
    # In actual usage, black_ridges=False as we want white (surface) on black (bg)
    return frangi(volume, sigmas=[scale], alpha=alpha, beta=beta, gamma=gamma, black_ridges=False)

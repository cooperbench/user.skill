1. **Widget Elementor Events View (TEC Pro)** — tem controles para algumas cores (title, date, description) mas geralmente **não** expõe controles para nav arrows/today button/month separator.
2. **Customizer do WordPress** — TEC oferece em `Aparência > Personalizar > Calendário e Cor`, mas é limitado a 3-4 cores principais (background, accent, primary text) e aplica via inline CSS.
3. **CSS custom properties do TEC v2** — overrride no `:root` ou específico, definindo `--tec-color-text-primary` etc. Esta é a forma "canônica" no sistema do TEC v2 sem precisar de `!important`.

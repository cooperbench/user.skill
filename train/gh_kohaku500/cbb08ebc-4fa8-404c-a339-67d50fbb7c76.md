248	### D-2. HI（Health Indicator）計算式
249	
250	**ESI（Envelope Spectral Indicator）の参考実装**（MDPI 2024 論文ベース）:
251	```
252	ESI(t) = Σ_{k=1}^{K} Σ_{h=1}^{H} S_env(k×f_c + h×f_r, t)
253	
254	f_c : 故障特性周波数（BPFO/BPFI等、仕様から計算）
255	f_r : 軸回転周波数（仕様から計算）
256	h   : 側帯波次数
257	K   : 積算する成分数
258	```
259	
260	**当アプリ独自HI（Physical Residual Energy Index, PREI）**:
261	```
262	PREI(t) = Σ_f |S_measured(f,t) - S_theory(f,t)|²  / Σ_f |S_theory(f,t)|²
263	
264	S_measured : 実測スペクトル（時刻 t）
265	S_theory   : 仕様から計算した理論正常成分スペクトル（時刻によらず一定）
266	```
267	
268	- PREI ≈ 0   → 実測が理論値とほぼ一致 → 正常
269	- PREI 増大  → 理論から外れた異常成分が増加 → 劣化進行中

611	## I. Fast Kurtogram の理論と当アプリへの統合設計
612	
613	### I-1. Kurtogram の本質
614	
615	**問題設定**: 軸受故障信号は高周波共振帯域に「インパルス応答」として現れるが、
616	その共振帯域（中心周波数・帯域幅）は軸受の構造・取付環境によって異なる。
617	
618	```
619	正解の帯域を知らずに包絡線解析 → 故障ピークが見えない
620	↓
621	Kurtogram: 「どの帯域でデータを取れば最もインパルス性が高いか」を全帯域で探索
622	```
623	
624	**数学的定義**:
625	
626	```
627	スペクトルカーテシス（Spectral Kurtosis, SK）:
628	  SK(f) = E[|H(f,t)|⁴] / (E[|H(f,t)|²])² - 2
629	
630	  H(f,t): 信号の短時間スペクトル（時刻 t、周波数 f）
631	  SK → 0:   ガウス性（正常機械のランダム振動）
632	  SK > 0:   インパルス性あり（故障の可能性）
633	
634	Kurtogram = SK を (中心周波数, 帯域幅) の2次元プロットとして表現
635	Fast Kurtogram = 1/3 バイナリツリー構造でO(N log N)に高速化
636	```
637	
638	### I-2. Fast Kurtogram の計算フロー
639	
640	```
641	入力: 時系列信号 x[n]（長さ N）
642	
643	1. STFT または Filter Bank で信号を各周波数帯域 H_k(t) に分解
644	   └ 1/3 バイナリツリー: 各レベルで3分割 → Level L で 3^L サブバンド
645	
646	2. 各サブバンドでスペクトルカーテシス SK_k を計算
647	   SK_k = E[|H_k(t)|⁴] / (E[|H_k(t)|²])² - 2
648	
649	3. Kurtogram マップ（周波数 vs. 帯域幅の2次元マップ）を作成
650	
651	4. SK が最大となる (f_c*, B*) を選択 → 最適フィルタ中心周波数・帯域幅
652	
653	5. x[n] を (f_c*, B*) でバンドパスフィルタ → 包絡線検波 → 包絡線スペクトル
654	
655	6. 包絡線スペクトルで BPFO/BPFI ピーク確認
656	```
657	
658	### I-3. Fast Kurtogram の限界と最新改良手法
659

731	## J. Cyclostationary 理論と PREI の理論的根拠
732	
733	### J-1. なぜ軸受信号は Cyclostationary か
734	
735	軸受の転動体が外輪欠陥を通過するたびに**インパルス状の衝撃振動**が発生する。
736	この衝撃は**周期的**（BPFO 周期で繰り返し）かつ**ランダム変動**（振幅・位相にゆらぎ）を持つ。
737	
738	```
739	Cyclostationary 信号の定義:
740	  x(t) の統計量（平均・分散）が周期 T で変動する信号
741	
742	軸受故障信号:
743	  BPFO 周期 T₁ = 1/f_BPFO で振幅変調するランダムインパルス列
744	  → Second-Order Cyclostationary (CS2) 信号
745	
746	CS2 の特性:
747	  自己相関 Rₓ(t, τ) = Rₓ(t+T₁, τ)  （T₁ 周期で繰り返す）
748	```
749	
750	### J-2. 包絡線解析（Envelope Analysis）の理論的正当化
751	
752	```
753	CS2 信号の解析には「Spectral Correlation（SC）」が最適:
754	  SC(f, α) = E[X(f + α/2) × X*(f - α/2)]
755	
756	  f  : 搬送周波数（共振帯域の中心周波数）
757	  α  : 巡回周波数（= BPFO、BPFI 等の故障周波数）
758	
759	包絡線スペクトル（SES）は SC を搬送周波数 f で積分したもの:
760	  SES(α) = ∫ SC(f, α) df
761	
762	→ SES に α = BPFO でピークが現れる = 故障の存在証明
763	
764	【PREI との関係】:
765	  PREI（当アプリ）= 「SES の内で理論外成分のエネルギー比」
766	  これは SC の巡回周波数 α ≠ BPFO の成分を異常成分と見なす操作に等価
767	```

782	## K. NMF（非負値行列因子分解）による音源分離と軸受故障特定（2024-2025）
783	
784	### K-1. NMF の軸受診断への適用原理
785	
786	```
787	入力スペクトログラム V（m×n）:
788	  m = 周波数ビン数
789	  n = 時間フレーム数
790	
791	NMF: V ≈ W × H
792	  W（m×r）: スペクトルテンプレート行列（r = 成分数）
793	  H（r×n）: 時間的活性化行列
794	
795	解釈:
796	  W の各列 w_k = k 番目の「音の種類」のスペクトル形状
797	  H の各行 h_k = k 番目の音が「いつ鳴っているか」
798	
799	軸受故障への応用:
800	  成分1: w₁ = 正常回転音（軸回転・歯車噛合い音）
801	  成分2: w₂ = 背景騒音（工場の定常ノイズ）
802	  成分3: w₃ = 軸受故障音（BPFO 周期のインパルス列）→ これを抽出
803	```
804	
805	### K-2. 最新 NMF 実装手法（2024-2025）
806	
807	#### ① Robust Sparse NMF-MCC（MDPI Sensors, 2025）― 最重要
808	
809	| 項目 | 内容 |
810	|------|------|
811	| **論文** | Robust Sparse Non-Negative Matrix Factorization for Identifying Signals of Interest in Bearing Fault Detection |
812	| **出典** | MDPI Sensors, Vol.25, No.22, 7041（2025） |
813	| **革新点** | 最大相互情報量基準（Maximum Correntropy Criterion, MCC）を損失関数に採用 |
814	| **効果** | ガウス性ノイズ + 重裾ノイズ（インパルス性ノイズ）の両方に対してロバスト |
815	| **実証** | CWRU データセットで有効性確認 |
816	
817	```
818	MCC ベースの NMF:
819	  従来 NMF: minimize ||V - WH||_F²  （ユークリッド距離 = ガウス分布仮定）
820	  NMF-MCC: maximize Σ K_σ(V_ij - (WH)_ij)
821	
822	  K_σ(e) = exp(-e²/2σ²)  （ガウスカーネル）
823	  → 外れ値（インパルスノイズ）への感度が低く、故障成分を正確に分離
824	```

826	#### ② Multi-Constraint NMF（PMC/MDPI, 2024）― 複合故障向け
827	
828	| 項目 | 内容 |
829	|------|------|
830	| **革新点** | β-divergence 制約 + 行列式制約を NMF に追加 |
831	| **効果** | 複数故障（内輪 + 外輪同時）の成分を独立分離 |
832	| **当アプリ意義** | 実機では複合故障が多い → Phase 3 以降の複合故障対応に有望 |
833	
834	#### ③ NMF 最適帯域選択（arxiv 2403.12547, 2024）
835	
836	```
837	手法: Non-negative matrix underapproximation as optimal frequency band selector
838	  NMU（Non-negative Matrix Underapproximation）を使って:
839	  1. スペクトログラムを「信号成分」と「ノイズ成分」に分解
840	  2. 信号成分が最も集中する周波数帯域 = 最適帯域

842	```

855	### K-4. NMF + PREI 統合アーキテクチャ（新提案）
856	
857	```
858	【NMF-guided PREI パイプライン】:
859	
860	入力音響信号
861	  ↓
862	STFT スペクトログラム V（周波数 × 時間）
863	  ↓
864	NMF 分解: V ≈ W × H（成分数 r = 3〜5 程度）
865	  ↓
866	成分照合:
867	  各 w_k と理論スペクトル（BPFO/BPFI の倍音テンプレート）との相関 cos_k を計算
868	  最大相関成分 k* = argmax(cos_k) → 「故障候補成分」
869	  残余成分（故障候補以外）= 「正常 + 背景ノイズ」
870	  ↓
871	PREI（NMF ドメイン版）:
872	  PREI_NMF = ||W_{k*} × H_{k*}||_F² / ||V - W_{k*} × H_{k*}||_F²
873	  （故障候補成分エネルギー / 残余成分エネルギー）
874	  ↓
875	PREITracker → RUL 推定
876	```
877	
878	**この設計の特許的価値**:
879	- 「仕様書から生成した理論スペクトルテンプレートを NMF 成分の照合基準として使用し、
880	  最適成分を自動選択して残差エネルギーを計算する手法」は既存特許に存在しない

## Overview

Synchrosqueezing is a powerful reassignment method that focuses time-frequency representations, and allows extraction of instantaneous amplitudes and frequencies.

## Python Implementation Libraries

**ssqueezepy** is the primary open-source Python library for synchrosqueezing:
- ssqueezepy was originally ported from MATLAB's Synchrosqueezing Toolbox, authored by E. Brevdo and G. Thakur.
- The library supports Continuous Wavelet Transform (CWT), forward & inverse, and its Synchrosqueezing, as well as Short-Time Fourier Transform (STFT), forward & inverse, and its Synchrosqueezing.
- GPU requires CuPy >= 8.0.0 and PyTorch >= 1.8.0 installed.

## Instantaneous Frequency Estimation Approaches

IFE-SST (Instantaneous Frequency-Embedded SST) uses an estimation of the IF of a targeted component to produce accurate IF estimation, with the phase transformation associated with the targeted component.

SST performs very well in estimating instantaneous frequencies and separating the components of non-stationary multicomponent signals with slowly changing frequencies, however its performance is not desirable for signals having fast-changing frequencies.

## Performance and Resolution

For both STFT-based and CWT-based settings, the frequency resolution is optimized while time resolution remains unchanged, therefore improved detectability in noisy environments.

49	## 技術的な実装
50	
51	### アーキテクチャ
52	
53	WebViewベースの構成にしています。
54	
55	```
56	Android (Kotlin)
57	  └── WebView
58	        └── HTML/JavaScript（計算ロジック）
59	```
60	
61	この構成を選んだ理由は、**PC版の締付トルク計算アプリと計算ロジックを共通化できる**ためです。JIS B 1083の計算ロジックを一度実装すれば、AndroidとPCで同じコードを使い回せます。
62	
63	### WebView ↔ JavaScript 連携のポイント
64	
65	WebViewでJavaScriptを呼び出す場合、`WebSettings.javaScriptEnabled = true` の設定が必要です。また、ローカルHTMLを読み込む際は `loadUrl("file:///android_asset/...")` を使います。
66	
67	```kotlin
68	webView.settings.javaScriptEnabled = true
69	webView.loadUrl("file:///android_asset/index.html")
70	```
71	
72	計算ロジックはHTMLファイル内のJavaScriptに書かれており、Androidネイティブ側からは結果を受け取るだけ。ロジックの変更がAndroid側のコード修正に影響しない設計にしています。
73	
74	### JIS B 1083への準拠と検証
75	
76	計算ロジックの詳細は非公開ですが、精度については以下の検証を実施しています。

78	- JIS規格の計算例との照合

80	- **全85ケースで計算結果が一致**

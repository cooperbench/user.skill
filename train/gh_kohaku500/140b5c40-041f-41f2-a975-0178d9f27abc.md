2012	## JIS B 2704-1 の計算式
2013	
2014	まず設計計算の全体像を整理します。入力値から得られる出力値の順で説明します。
2015	
2016	### 入力パラメータ
2017	
2018	| 変数 | 記号 | 単位 | 備考 |
2019	|------|------|------|------|
2020	| 線径 | d | mm | |
2021	| 平均コイル径 | D | mm | 外径 − 線径 |
2022	| 有効巻数 | Na | 回 | 実際に変形に寄与する巻数 |
2023	| 総巻数 | Nt | 回 | 両端の座巻含む |
2024	| 自由長 | L0 | mm | 無荷重時の長さ |
2025	| 荷重 | F | N | 設計荷重 |
2026	| 材料 | — | — | 後述の材料データベースから選択 |
2027	
2028	### 計算の流れ
2029	
2030	#### Step 1: ばね指数 C
2031	
2032	```
2033	C = D / d
2034	```
2035	
2036	JIS B 2704 では **4 ≤ C ≤ 16** を推奨範囲としています。
2037	C が小さすぎると製造が困難、大きすぎると座屈しやすくなります。
2038	
2039	#### Step 2: ワール応力修正係数 Kw
2040	
2041	```
2042	Kw = (4C − 1) / (4C − 4) + 0.615 / C
2043	```
2044	
2045	コイルの曲率によって内側に応力集中が発生します。
2046	このKwを掛けることで、単純なせん断応力計算では見えない実際の最大応力を得ます。
2047	**ここを省くと応力を10〜30%過小評価します。**
2048	
2049	#### Step 3: ばね定数 k
2050	
2051	```
2052	k = G × d⁴ / (8 × D³ × Na)   [N/mm]
2053	```
2054	
2055	G は材料の横弾性係数（せん断弾性係数）です。
2056	後述の材料データベースに各材料のG値を持たせています。
2057	
2058	#### Step 4: たわみ δ と荷重時長さ
2059	
2060	```
2061	δ = F / k                [mm]
2062	L1 = L0 − δ             [mm] (荷重時長さ)
2063	```
2064	
2065	#### Step 5: 最大せん断応力 τmax
2066	
2067	```
2068	τmax = Kw × 8 × F × D / (π × d³)   [N/mm²]
2069	```
2070	
2071	Kwを掛けた値が「実際に材料が受ける応力」です。
2072	
2073	#### Step 6: 密着長さ Ls と密着余裕
2074	
2075	```
2076	Ls = Nt × d              [mm]
2077	密着余裕 = L1 − Ls       [mm]  ← 正値であること必須
2078	```
2079	
2080	密着余裕が負 = 荷重でばねが完全に圧縮されてしまう状態。
2081	設計NGの判定基準の一つです。
2082	
2083	#### Step 7: 座屈チェック
2084	
2085	JIS B 2704-1 附属書Aに基づく座屈線図を使います。
2086	Androidアプリでは下記の近似式で判定しています。
2087	
2088	```
2089	λ = L0 / D   (細長比)
2090	
2091	両端ピン:   座屈しない条件 → λ < 2.6
2092	両端固定:   座屈しない条件 → λ < 5.3
2093	片端固定:   座屈しない条件 → λ < 3.7
2094	```
2095	
2096	精密な座屈解析には非線形FEMが必要ですが、
2097	設計初期フィルタリングとしてこの近似で十分実用的です。
2098	
2099	#### Step 8: 許容応力との比較
2100	
2101	```
2102	応力余裕 = τallow − τmax   [N/mm²]
2103	安全率 = τallow / τmax
2104	```
2105	
2106	τallow（許容せん断応力）は材料と線径によって変わります。
2107	JIS B 2704-1 の附属書に材料・線径ごとの許容応力図があります。
2108	アプリでは近似式を実装しています（後述）。

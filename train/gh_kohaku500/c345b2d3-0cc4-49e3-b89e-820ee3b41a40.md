118	## 圧縮コイルばねの基本計算式
119	
120	### ばね定数 k
121	
122	```
123	k = G × d⁴ / (8 × D³ × Na)
124	```
125	
126	- `G`: 横弾性係数 [MPa]
127	- `d`: 線径 [mm]
128	- `D`: コイル平均径 [mm]
129	- `Na`: 有効巻数
130	
131	### ねじり応力 τ
132	
133	```
134	τ = Kw × (8 × P × D) / (π × d³)
135	```
136	
137	Kwはワール応力修正係数:
138	```
139	Kw = (4C - 1) / (4C - 4) + 0.615 / C
140	C = D / d  (ばね指数)
141	```
142	
143	### たわみ δ
144	
145	```
146	δ = P / k
147	```

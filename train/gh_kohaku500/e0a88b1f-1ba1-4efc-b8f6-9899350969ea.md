81	### WebViewでJavaScriptが動かない
82	
83	WebViewを表示しても計算が全く動きませんでした。エラーも出ないのに何も動かない状態。しばらく悩んで調べてみると、デフォルトでJavaScriptが無効になっているとのことでした。
84

87	```
88	
89	この1行を追加したら動きました。エラーも出ずに静かに失敗していたので、原因にたどり着くまで時間がかかりました。
90	
91	### ローカルHTMLからJSファイルが読み込めない
92	
93	`assets/js/calc.js` を `<script src="js/calc.js">` で読み込もうとしたら動かないケースがありました。
94	
95	`loadUrl("file:///android_asset/index.html")` で開くと `assets/` 配下を相対パスで参照できることがわかり、HTMLとJSをassetsにフラットに置く構成にしてから安定しました。
96	
97	### INTERNET権限は不要だった
98	
99	WebViewを使うのでINTERNET権限が必要だと思い込んでいましたが、ローカルHTMLだけなら不要でした。結果的にオフライン動作の根拠にもなったので、これはよかったと思っています。
100	
101	### 外部リンクをタップしても何も起きない
102	
103	v1.1.0でフィードバックボタン（外部URLを開く機能）を追加したところ、タップしても何も起きない問題が発生しました。エラーは一切出ません。
104	
105	原因は `WebViewClient` のデフォルト動作にありました。デフォルトの `WebViewClient` は `http://` / `https://` のURLをWebView内部で処理しようとします。ローカルHTMLからの外部リンクは `file://` スキームのコンテキストになるため、外部URLへの遷移が黙って無視されていました。
106	
107	```kotlin
108	// 修正前: 外部URLを開けない
109	webView.webViewClient = WebViewClient()
110	
111	// 修正後: http/https はシステムブラウザへ委譲
112	webView.webViewClient = object : WebViewClient() {
113	    override fun shouldOverrideUrlLoading(view: WebView, request: WebResourceRequest): Boolean {
114	        val url = request.url.toString()
115	        if (url.startsWith("http://") || url.startsWith("https://")) {
116	            startActivity(Intent(Intent.ACTION_VIEW, request.url))
117	            return true
118	        }
119	        return false  // file:// はWebView内で継続処理
120	    }
121	}
122	```
123	
124	`shouldOverrideUrlLoading` をオーバーライドして、外部URLは `Intent.ACTION_VIEW` でシステムブラウザに渡すようにしたら解決しました。`return false` の部分でローカルファイル（`file://`）は引き続きWebViewで処理されます。
125	
126	ローカルHTMLをメインコンテンツにするアーキテクチャでは、この対応が必須になります。

186	
187	### ボルトサイズ早見表
188	
189	「計算はしなくていい、サイズだけ確認したい」という場面があります。M2〜M42の主要パラメータ（ピッチ・推奨トルク・有効断面積）をモーダルで一覧表示する機能を追加しました。
190	
191	BOLT定数から動的にテーブルを生成します。表示する推奨トルクは強度区分8.8・乾燥条件（μ=0.15）で固定計算しています。
192	
193	```javascript
194	function openBoltTable() {
195	  const tbody = ge('bolt-table-body');
196	  if (!tbody.children.length) {  // 初回のみ計算・以降はキャッシュ
197	    const gr = GRADE['8.8'];
198	    const { mt, mw } = MU_MAP['dry'];
199	    const bolts = Object.keys(BOLT).map(Number).sort((a, b) => a - b);
200	    tbody.innerHTML = bolts.map(d => {
201	      const b = BOLT[d];
202	      const Db = (b.dw + b.dh) / 2;
203	      const K = b.p / (2 * Math.PI * d) + 0.577 * mt * b.d2 / d + mw * Db / (2 * d);
204	      // ...
205	      const T_rec = (Knd * Fy / 1.5).toFixed(2);
206	      return `<tr><td>M${d}</td><td>${b.p.toFixed(2)}</td><td>${T_rec}</td><td>${b.As}</td></tr>`;
207	    }).join('');
208	  }
209	}
210	```
211	
212	BOLT定数は `const BOLT = { 3: {...}, 4: {...}, ... }` と数値キーで管理しています。`Object.keys()` が返すのは文字列なので `.map(Number)` で数値化してからソートしています。
213	
214	### M2・M2.5 対応追加
215	
216	M2・M2.5はJIS B 1082（ねじ部品の許容限界寸法および公差）とJIS B 1180（六角ボルト）から寸法データを取得しました。有効断面積Asは `As = π/4 × ((d2+d3)/2)²` で算出し、JIS規格値と一致することを確認しています。
217	
218	```javascript
219	const BOLT = {
220	  2:   { p: 0.40, d2: 1.740, d3: 1.509, As: 2.07, dw: 4.0, dh: 2.2 },
221	  '2.5': { p: 0.45, d2: 2.208, d3: 1.948, As: 3.39, dw: 5.0, dh: 2.7 },
222	  3:   { p: 0.50, d2: 2.675, d3: 2.459, As: 5.03, ... },
223	  // ...
224	};
225	```
226	
227	M2.5のキーは文字列 `'2.5'` にしています。JavaScriptでは数値キーでアクセスしても `2.5.toString() === '2.5'` になるため、`BOLT[2.5]` と `BOLT['2.5']` は等価で問題なく動作します。

Entity IDs are derived automatically using HA's built-in Jinja2 functions: ```jinja2 {% set title = config_entry_attr(config_entry, 'title') %} {% set all_entities = integration_entities(title) %} {% set pin_entity = all_entities | select('match', 'text\\..*_code_slot_' ~ slot ~ '_pin') | first | default('') %} ``` **Why this works:** `integration_entities(title)` returns all entity IDs for a config entry matching the title (`template/__init__.py:1163`). `config_entry_attr(id, 'title')` gets the title from a config entry ID (`:1204`). Neither function is blocked in HA's limited template block list (`template/__init__.py:1974-2000`), so they work in both `trigger_variables` and `variables:`. **Variable evaluation order:** HA's `ScriptVariables.async_render()` (`script_variables.py:51-59`) renders variables in insertion order, with each result available to subsequent variables.

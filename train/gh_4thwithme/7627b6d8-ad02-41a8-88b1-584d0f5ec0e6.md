> AGENT

Consolidated logs per request > sampling. Here's why:

**Sampling is dangerous:**
- You lose visibility into the exact request that caused an incident
- Debugging becomes guesswork — "was this request sampled out?"
- Intermittent bugs become near-impossible to trace

**Consolidation (1-2 logs per request) is better:**
- Every request still has a trace
- You keep params + response + timing in a single structured log entry
- Massive size reduction (80-90% fewer log lines)
- No blind spots

**Recommended approach:** Merge `@LogExecution` output into 1 log per method — single JSON with `{params, response, executionTime, error}` instead of separate log lines for each.

## Rule: Named Object Params

**Rule trigger:** Functions receiving multiple params should use a single named object param.

```typescript
// ❌ Fails
export function buildQuery(
	styleId: string,
	limit: number,
	offset: number,
): Knex.QueryBuilder {}

// ✅ Passes
export function buildQuery({
	styleId,
	limit,
	offset,
}: {
	styleId: string;
	limit: number;
	offset: number;
}): Knex.QueryBuilder {}
```

**In class methods:**

```typescript
// ❌
async findByStyleId(styleId: string, colorId: number): Promise<StyleColor | undefined> {}

// ✅
async findByStyleId({
  styleId,
  colorId,
}: {
  styleId: string;
  colorId: number;
}): Promise<StyleColor | undefined> {}
```

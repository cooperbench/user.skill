Nice work overall — clean structure, good accessibility, solid test coverage. A few things worth looking at:

**`useImperativeHandle` needs a dep array** (`Carousel.tsx`)
The factory function runs on every render without one. Since `instanceRef` is stable, just pass `[]` as the third arg.

**`useBreakpoint` hydration mismatch**
The `useState` initializer reads `window.innerWidth` on the client but falls back to `'desktop'` on the server. If someone lands on a mobile viewport, React 18 will see a server/client mismatch on hydration. Safer to always init with `'desktop'` and update inside `useEffect` instead.

**`ARROW_PATH` leaks through Carousel's internal module**
`RecentlyViewedCarousel` imports directly from `../Atoms/Carousel/constants` which isn't re-exported from the Carousel's public `index.ts`. If Carousel's internals change, this breaks silently. Either expose `ARROW_PATH` through the public barrel or just inline the path in `RecentlyViewedCarousel` since it owns those buttons anyway.

**`CardSlide` could use `React.memo`**
`handleCardClick` is already memoized, but `CardSlide` itself isn't — so all slides re-render whenever `breakpoint` changes. Wrapping it in `memo` is a quick win given the deps are already stable.

**Magic `699px` in CSS**
That breakpoint is derived from `units.size.breakpoint.tablet` in the JS hook but hardcoded in the CSS. If the token ever changes, they'll drift. At minimum a comment linking the two would help future-you.

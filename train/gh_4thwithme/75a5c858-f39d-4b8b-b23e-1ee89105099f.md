> AGENT

Set it in `~/.claude/settings.json` for persistence across all sessions:

```json
{
  "env": {
    "CLAUDE_CODE_NEW_INIT": "1"
  }
}
```

Or per-session:
```bash
CLAUDE_CODE_NEW_INIT=1 claude
```

**What it does:** Makes `/init` run an interactive setup flow (asks what to generate) instead of auto-generating `CLAUDE.md`.

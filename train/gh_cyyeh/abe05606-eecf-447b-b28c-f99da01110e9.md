     9→### SQL Playground
    10→
    11→- **In-browser SQL engine** — DuckDB compiled to WebAssembly, no server required
    12→- **CSV file upload** — Drag-and-drop or click to import CSV files (up to 500 MB) with automatic schema detection
    13→- **Sample dataset** — One-click load of the Titanic dataset to get started quickly
    14→- **SQL query editor** — Write and execute queries with Ctrl+Enter
    15→- **Results table** — Sortable columns, per-column filters, and global search across results
    16→- **EXPLAIN support** — Markdown-rendered output for `EXPLAIN` and `EXPLAIN ANALYZE` queries
    17→- **Collapsible table sidebar** — Browse uploaded tables, inspect columns and types, toggle to expand your workspace
    18→
    19→### AI Agent

    21→- **Natural language data analysis** — Ask questions about your data in plain English and get SQL queries + results

    24→- **Inline query results** — SQL results displayed inline within the conversation

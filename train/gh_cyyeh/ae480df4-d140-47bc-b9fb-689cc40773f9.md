The `get_endpoint()` method resolves sandbox service URLs for client access. According to the documentation:

**API Endpoint:**

## Proxy URL Format

The documentation references a proxy route pattern:
`*` `ROUTE` `/v1/sandboxes/{id}/proxy/{port}/{path}` — "Server-side proxy to sandbox service"

This indicates the control plane can optionally forward traffic directly through the server itself rather than requiring direct client-to-sandbox communication.

## How It Works

The endpoint resolution process follows this sequence:

1. **SDK Query:** Client requests the execd daemon address via `GET /v1/sandboxes/{id}/endpoints/44772`
2. **Server Response:** Returns resolved endpoint URL based on network configuration
3. **Direct Communication:** SDK communicates directly with the data plane (execd) at the provided address

## Network Mode Considerations

- **Host Mode:** Endpoints resolve to `http://{host}:{port}` with direct port access
- **Bridge Mode:** Requires ingress proxy routing with port mapping in the 40000-60000 range

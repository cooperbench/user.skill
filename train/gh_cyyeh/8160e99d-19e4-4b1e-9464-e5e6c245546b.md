## 7. POTENTIAL GAPS/MISSING FIELDS

Looking at the flow, here are fields that **might** be expected but are **not** currently persisted in segments:

1. **toolInput for non-ask_user_question tools**: Line 580 only stores toolInput for ask_user_question. Other tools don't save their input to the segment.
   - **Why**: Tool inputs can be very large; only question tools store them.
   - **Stored**: Only in ask_user_question segments (line 580)

2. **Tool execution time**: Individual tool execution time is not tracked per tool.
   - **What's tracked**: Only `durationMs` at metadata root level (total response time)

3. **Subagent intermediate SQL queries**: Only final SQL results are stored in subagent_end.
   - **Captured**: In `subagent_sql_data` dict (internal tracking)
   - **Persisted**: Only the final results in sqlResults array

4. **Chat_spec for non-subagent render_chart**: chart_spec is attached to tool segments for render_chart, but buildChatMessages.ts only explicitly expects it for subagent_end (line 48).
   - **Actually works**: The reconstruction includes chart_spec for tool segments (line 40)

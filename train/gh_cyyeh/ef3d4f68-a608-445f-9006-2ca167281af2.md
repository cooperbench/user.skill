`BACKEND_BASE_URL` is used by the **sidecar containers** (Docker) to call back into the backend. Two usages in `agent.py`: 1. **Line 193** — Sets `ANTHROPIC_BASE_URL` for subagent SDK processes to `{BACKEND_BASE_URL}/anthropic`, so their API calls route through the proxy. 2. **Line 250** — Sets the MCP server URL to `{BACKEND_BASE_URL}/mcp/sse?session_id=...`, so subagents can connect to the MCP server running on the backend. In docker-compose, it defaults to `http://duckdb-data-agent:10000` (the Docker service name).

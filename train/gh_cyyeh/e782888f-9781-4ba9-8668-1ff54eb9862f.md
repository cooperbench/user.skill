The bug is clear. Both `ChatInput.tsx` and `MessageBubble.tsx` handle Enter key to submit but don't check for IME composition state. When typing Chinese characters, pressing Enter to confirm a character in the IME also triggers the send action.

The fix is to use the `isComposing` property on the keyboard event (or track it via `onCompositionStart`/`onCompositionEnd`). The simplest and most reliable approach is checking `e.nativeEvent.isComposing`.

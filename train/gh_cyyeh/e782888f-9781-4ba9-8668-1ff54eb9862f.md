> AGENT

The bug is clear. Both `ChatInput.tsx` and `MessageBubble.tsx` handle Enter key to submit but don't check for IME composition state. When typing Chinese characters, pressing Enter to confirm a character in the IME also triggers the send action. The fix is to use the `isComposing` property on the keyboard event (or track it via `onCompositionStart`/`onCompositionEnd`). The simplest and most reliable approach is checking `e.nativeEvent.isComposing`.

> AGENT

Fixed both files by adding `!e.nativeEvent.isComposing` to the Enter key check: - **`ChatInput.tsx:23`** — prevents sending a message while composing Chinese characters - **`MessageBubble.tsx:125`** — prevents saving an edit while composing Chinese characters The `isComposing` property on the native keyboard event is `true` when the user is in the middle of an IME composition (e.g., selecting a Chinese character). This ensures that pressing Enter to confirm a character in the IME won't accidentally trigger the send/save action.

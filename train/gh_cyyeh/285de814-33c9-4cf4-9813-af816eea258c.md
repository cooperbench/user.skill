This is the Anthropic proxy (`proxy.py`) rejecting a `GET /v1/models` request with 401 because the request has **no valid session token** registered in `proxy_token_store`.

Here's what's happening:

1. The backend acts as an auth proxy — it only accepts requests with a short-lived UUID token created by `proxy_token_store.create_token()` per-session.
2. The Claude Code SDK/CLI, when given a **short model name** like `"sonnet"` (instead of a full ID like `claude-sonnet-4-6`), makes a `GET /v1/models` call at startup to resolve/validate the model name.
3. That `GET /v1/models` request arrives **before** or **outside of** a valid session token — so the proxy rejects it with 401.

**Root cause in your `.env`:**


   142→## Security
   143→
   144→### Bifrost LLM Gateway
   145→
   146→When the agent runs, the backend spawns a sidecar container via the Docker SDK. A naive approach would pass `ANTHROPIC_API_KEY` directly into that container's environment — but any tool or shell command the agent executes could then read and exfiltrate the key.
   147→
   148→Instead, a [Bifrost](https://github.com/maximhq/bifrost) LLM gateway service manages API keys centrally and routes requests to LLM providers:
   149→
   150→```
   151→Sidecar Container
   152→  → ANTHROPIC_BASE_URL=http://bifrost:8080/anthropic
   153→  → ANTHROPIC_API_KEY=placeholder
   154→        ↓
   155→Bifrost Gateway (/anthropic)
   156→  → ignores client-sent key
   157→  → injects the real provider API key
   158→  → forwards request to provider (Anthropic, OpenAI, Bedrock, etc.)
   159→```
   160→
   161→**How it works:**
   162→
   163→1. Bifrost runs as a Docker Compose service with real API keys stored in `bifrost/config.json` (referencing environment variables).
   164→2. Sidecar containers receive a placeholder `ANTHROPIC_API_KEY` and point `ANTHROPIC_BASE_URL` to Bifrost's native `/anthropic` endpoint.
   165→3. Bifrost injects the real provider API key when forwarding requests upstream. The Claude Agent SDK works unchanged since Bifrost speaks native Anthropic Messages API.
   166→4. Additional providers (OpenAI, Bedrock, Vertex, etc.) can be added to `bifrost/config.json` or via Bifrost's Web UI. Use provider prefixes in model names (e.g., `openai/gpt-4o-mini`) to route subagent requests to different providers. See [`bifrost/README.md`](bifrost/README.md) for configuration examples.
   167→
   168→The sidecar container only ever holds a placeholder string. Even if a tool call reads the environment, it cannot obtain any real API key.

You still get container isolation (filesystem, process, network, capability drop, read-only rootfs) — only gVisor's syscall interception layer is absent. For production multi-tenant deployments, use a Linux host with gVisor for full sandboxing.

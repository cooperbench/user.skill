| **Response Display** | ✓ Same | ✓ Same |

### 2. `sidecar/src/server.ts` — Capture CLI stderr
- Added `stderr` callback to the SDK `query()` options to capture Claude CLI error output
- Appended stderr to the error message sent to the backend so the actual failure reason is visible
- Changed error SSE format from `event: error\ndata:` to just `data:` so the backend properly processes it via `msg_type`

## Root Cause Analysis Complete

**The problem:** The charting instructions contain language that causes OpenAI models to stop generating after the first chart:

- Step 3: **"STOP making tool calls"**
- **"HARD CONSTRAINT: You are FORBIDDEN from calling execute_sql or render_chart in the same response where you just received a render_chart result"**

**Why this breaks:** In the Claude Agent SDK, when a model generates a text-only response (no tool calls), the **conversation ends**. There is no "pause and resume" mechanism. The SDK loop only continues when there are tool calls to execute.

## 5. KEY DIFFERENCES: CONTAINER VS NON-CONTAINER MODE

### Container Mode (CONTAINER_ENABLED=true)

**Execution Path**:
1. Backend sends request to containerized sidecar (TypeScript/Node.js)
2. Sidecar runs Claude agent using SDK inside Docker
3. Sidecar parses SDK messages and emits SSE events
4. Backend relays sidecar SSE events to frontend

**Chart Handling**:
- Sidecar extracts chart_spec from subagent output (lines 414-450 in agent.py)
- Sidecar emits `subagent_end` SSE event with chart_spec
- Backend relays to frontend

**File**: `/Users/cyyeh/Desktop/duckdb-data-agent/sidecar/src/server.ts`
- Container receives `agents` payload with subagent definitions
- Container processes all tool results and emits events

### Non-Container Mode (CONTAINER_ENABLED=false)

**Execution Path**:
1. Backend runs Claude SDK directly as local subprocess
2. SDK returns messages with tool results
3. Backend processes and extracts chart_spec
4. Backend emits SSE events to frontend

**Chart Handling**:
- Backend extracts chart_spec from subagent output (lines 679-695 in agent.py)
- Same `_extract_chart_spec()` function
- Backend emits `subagent_end` SSE event with chart_spec

   427→                                        result_data["rows"] = parsed.get("rows", [])[:100]
   428→                                        result_data["rowCount"] = parsed.get("rowCount", 0)
   429→                                elif parsed.get("status") == "error":
   430→                                    result_data["error"] = parsed.get("error", "")
   431→                                else:
   432→                                    result_data["output"] = text
   433→                            except (json.JSONDecodeError, AttributeError):
   434→                                result_data["output"] = text
   435→                            if block.get("is_error"):
   436→                                try:
   437→                                    parsed_err = json.loads(text)
   438→                                    result_data["error"] = parsed_err.get("error", text)
   439→                                except (json.JSONDecodeError, AttributeError):
   440→                                    result_data["error"] = text
   441→                            # Detect subagent result (Task tool)
   442→                            if name in ("sql-analyst", "chart-builder"):

   444→                                chart_spec = _extract_chart_spec(text)
   445→                                if chart_spec:
   446→                                    end_data["chart_spec"] = chart_spec
   447→                                else:
   448→                                    end_data["result"] = text
   449→                                yield f"event: subagent_end\ndata: {json.dumps(end_data, default=str)}\n\n"

   452→

   454→                    elif msg_type == "result":
   455→                        actual_session_id = msg.get("session_id") or actual_session_id
   456→                        if msg.get("is_error"):

   462→

   464→                    elif msg_type == "error":

   467→                        yield f"event: error\ndata: {json.dumps({'message': error_text})}\n\n"

   479→

   707→        # Guard: always send done even if SDK ended without ResultMessage

### 5. Why the `simplify` Skill Might Still Appear

- The `PreToolUse` hook intercepts ALL `Skill` tool invocations
- When an agent tries to invoke a skill (e.g., `simplify`), the hook checks if the skill name is in `ALLOWED_SKILLS`
- If not, the hook returns a `deny` permission decision with reason: "Skill 'simplify' is not in the allowlist."
- This effectively blocks the built-in `simplify` skill from being used

**If `simplify` Still Shows Up:**
This could happen if:
1. **The Docker image is old** — Was built before the hook was added or before the Dockerfile was updated to copy `.claude/` files
2. **The hook is not being applied** — If there's a version mismatch between the SDK version and the code
3. **The skill invocation bypasses the hook** — Unlikely, but possible if using an older SDK version that doesn't support `PreToolUse` hooks properly
4. **Running locally without the hook** — If testing locally without the sidecar Docker setup

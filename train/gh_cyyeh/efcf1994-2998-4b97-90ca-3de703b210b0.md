## Design Section 3: Plotly Chart Re-initialization Plotly charts rendered by `react-plotly.js` create `<div>` elements with internal state that gets lost when we clone the DOM. To restore interactivity: 1. **Before cloning:** For each Plotly chart container in the conversation, extract the data/layout/frames using `Plotly.Plots?.getSubplotData` or by reading the `__data` attribute on the Plotly div (react-plotly.js stores data on the element's `.data` and `.layout` properties) 2. **During cloning:** Replace each chart `<div>` with a placeholder `<div data-plotly-chart="N">` and store the extracted data in a JSON array 3. **In the export script:** On page load, iterate over `[data-plotly-chart]` elements and call `Plotly.newPlot(el, data, layout)` for each This approach keeps the chart data as JSON in the HTML and lets the CDN-loaded Plotly.js re-render them with full interactivity (zoom, pan, hover tooltips).

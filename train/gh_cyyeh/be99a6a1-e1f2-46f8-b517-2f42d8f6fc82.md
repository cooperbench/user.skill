```typescript
function handleSSEEvent(
  eventType: string,
  data: Record<string, unknown>,
  callbacks: AgentCallbacks,
) {
  switch (eventType) {
    case 'thinking':
    case 'answer':
      callbacks.onTextChunk(data.text as string);  // Same handler!
      break;
    case 'thinking_done':
      callbacks.onThinkingDone();
      break;
    case 'tool_call':
      callbacks.onToolCall({...});
      break;
    case 'tool_result':
      callbacks.onToolResult(result);
      break;
    case 'subagent_start':
      callbacks.onSubagentStart?.({
        id: data.id as string,
        name: data.name as string,
        prompt: (data.prompt as string) ?? '',
      });
      break;
    case 'subagent_end':
      callbacks.onSubagentEnd?.({
        id: data.id as string,
        name: data.name as string,
        result: (data.result as string) ?? undefined,
        chart_spec: (data.chart_spec as { data: unknown[]; layout?: Record<string, unknown> }) ?? undefined,
      });
      break;
    case 'done':
    case 'error':
      // ...
  }
}
```

**Key insight:** Both `'thinking'` and `'answer'` events call `onTextChunk()` - the distinction is made later at the React level!

### Key Design Insights

1. **Event routing is simple**: Both `thinking` and `answer` events call `onTextChunk()` - the React state machine decides where text goes based on `has_tool_calls` and the explicit `thinking_done` event

2. **Subagent text is hidden**: Text streaming from subagents is accumulated server-side in `subagent_texts` dict, NOT emitted as thinking/answer events (filtered by `parent_tool_use_id`)

3. **Chart extraction is resilient**: The backend tries three sources for `chart_spec`: tool_result text, SDK's tool_use_result.content, and accumulated streaming text

4. **Buffering for batching**: Frontend uses a 50ms flush timer to batch text chunks, reducing re-renders while still feeling responsive

5. **Segments preserve metadata**: Each segment tracks type, text, tool results, subagent info, and chart specs - enabling rich UI rendering logic

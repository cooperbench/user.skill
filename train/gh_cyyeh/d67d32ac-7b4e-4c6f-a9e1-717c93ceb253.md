## Root Cause

The backend (uvicorn) is bound to `127.0.0.1:8000` (localhost only). The sidecar container resolves `host.docker.internal` to `192.168.107.1` (the Docker gateway IP), but since the backend only listens on localhost, the connection is **refused**.

The Makefile runs:
```
cd backend && poetry run uvicorn app.main:app --reload --port 8000
```

Uvicorn defaults to binding `127.0.0.1`, which rejects connections from any non-localhost interface — including Docker's `host.docker.internal`.

## Fix

Add `--host 0.0.0.0` to the uvicorn command so it accepts connections from Docker containers:

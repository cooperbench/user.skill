### WHY CHARTS MIGHT NOT BE VISIBLE

Based on this analysis, charts could fail to appear if:

1. **Extraction Fails**: `_extract_chart_spec()` doesn't find valid JSON
   - Subagent doesn't return proper markdown fenced code block
   - JSON is malformed

2. **Container Mode Missing Subagent Text**: Before the recent changes, container mode couldn't fallback to captured assistant messages, so chart_spec extraction relied only on tool_result metadata (which is often empty from Task tools)

3. **Frontend Filtering Issue**: `stripChartSpecBlocks()` might be over-aggressive
   - Or chart_spec might not be properly threaded through segments

4. **Orchestrator Prompt**: System prompt (line 59) tells agent to use subagents for charts but NOT repeat the JSON in the answer
   - If agent ignores this, answer text contains the JSON instead of chart_spec

5. **Missing Integration**: Chart segments only render if they pass through the `chartSegments` filter in MessageBubble

   423→

   425→                    elif msg_type == "user":

   427→                        for block in message_obj.get("content", []):
   428→                            if block.get("type") != "tool_result":
   429→                                continue

   432→                            content_parts = block.get("content", [])
   433→                            text = ""
   434→                            if isinstance(content_parts, list):
   435→                                for part in content_parts:
   436→                                    if isinstance(part, dict) and part.get("type") == "text":

   438→                            elif isinstance(content_parts, str):

   440→

   442→                            result_data: dict = {"id": tool_id, "name": name}

   446→                                result_data["sql"] = original_sql
   447→                            try:

   449→                                if parsed.get("status") == "success":
   450→                                    if "chart_spec" in parsed:
   451→                                        result_data["chart_spec"] = parsed["chart_spec"]

   458→                                else:

   460→                            except (json.JSONDecodeError, AttributeError):

   462→                            if block.get("is_error"):

   464→                                    parsed_err = json.loads(text)
   465→                                    result_data["error"] = parsed_err.get("error", text)
   466→                                except (json.JSONDecodeError, AttributeError):
   467→                                    result_data["error"] = text
   468→                            # Detect subagent result (Task tool)
   469→                            if name in ("sql-analyst", "chart-builder"):
   470→                                end_data: dict = {"id": tool_id, "name": name}
   471→                                # Try the tool_result text first, then fall back to
   472→                                # captured subagent assistant text.  The TS SDK's
   473→                                # Task tool_result often contains only metadata
   474→                                # (agentId, usage) — the real output lives in
   475→                                # intermediate assistant messages.
   476→                                chart_spec = _extract_chart_spec(text)
   477→                                if not chart_spec:
   478→                                    captured = subagent_texts.get(tool_id, "")
   479→                                    if captured:
   480→                                        chart_spec = _extract_chart_spec(captured)
   481→                                if chart_spec:
   482→                                    end_data["chart_spec"] = chart_spec
   483→                                else:
   484→                                    end_data["result"] = subagent_texts.get(tool_id, text)
   485→                                yield f"event: subagent_end\ndata: {json.dumps(end_data, default=str)}\n\n"
   486→                                continue
   487→                            yield f"event: tool_result\ndata: {json.dumps(result_data, default=str)}\n\n"
   488→
   489→                    # --- Final result ---
   490→                    elif msg_type == "result":
   491→                        actual_session_id = msg.get("session_id") or actual_session_id
   492→                        if msg.get("is_error"):
   493→                            errors = msg.get("errors", [])
   494→                            error_text = msg.get("result") or "; ".join(errors) or "Unknown error"
   495→                            yield f"event: error\ndata: {json.dumps({'message': error_text})}\n\n"
   496→                        yield f"event: done\ndata: {json.dumps({'session_id': actual_session_id})}\n\n"
   497→                        done_sent = True
   498→
   499→                    # --- Sidecar error (e.g. SDK/CLI crash inside container) ---
   500→                    elif msg_type == "error":
   501→                        error_text = msg.get("message") or "Sidecar error"
   502→                        logger.error("Sidecar reported error: %s", error_text)
   503→                        yield f"event: error\ndata: {json.dumps({'message': error_text})}\n\n"
   504→
   505→                    # --- Extract session_id early from system init ---
   506→                    elif msg_type == "system":
   507→                        sys_session = msg.get("session_id")
   508→                        if sys_session:
   509→                            actual_session_id = sys_session
   510→
   511→        # Guard: always send done even if sidecar ended without result message
   512→        if not done_sent:
   513→            logger.warning("Sidecar stream ended without result message; sending done event")
   514→            yield f"event: done\ndata: {json.dumps({'session_id': actual_session_id})}\n\n"
   515→
   516→    except Exception as e:
   517→        logger.error("Container agent error: %s", str(e))
   518→        yield f"event: error\ndata: {json.dumps({'message': str(e)})}\n\n"
   519→    finally:

   523→        # CONTAINER_MAX_LIFETIME_SECONDS, or on application shutdown.

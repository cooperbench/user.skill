what's difference with flushText and flushSubagentText

> AGENT

Good question. They serve the same purpose (batched rendering) but handle different text streams: **`flushText`** — handles **orchestrator** text (the main agent's thinking/answer). It appends to `message.content` (a flat string), which gets rendered via `streamingRemainder` in `MessageBubble`. This is the text that appears outside of subagent blocks. **`flushSubagentText`** — handles **subagent** text (sql-analyst/chart-builder output). It appends to `answer` **segments** tagged with a `subagentId`, since subagent text lives in the segments array, not in `message.content`. The split exists because the two text streams have different destinations in the React state: - Orchestrator text → `message.content` (string) - Subagent text → `message.segments[]` (array of typed objects) They can't share a flush function because they write to different data structures.

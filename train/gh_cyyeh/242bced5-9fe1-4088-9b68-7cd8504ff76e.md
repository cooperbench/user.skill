### 2. Calling `query()` with Streaming

`query()` returns a `Query` object that extends `AsyncGenerator<SDKMessage, void>`. You consume it with a `for await...of` loop:

```typescript
import { query } from "@anthropic-ai/claude-agent-sdk";

for await (const message of query({
  prompt: "Review utils.py for bugs that would cause crashes. Fix any issues you find.",
  options: {
    allowedTools: ["Read", "Edit", "Glob"],
    permissionMode: "acceptEdits"
  }
})) {
  if (message.type === "assistant" && message.message?.content) {
    for (const block of message.message.content) {
      if ("text" in block) {
        console.log(block.text);      // Claude's reasoning
      } else if ("name" in block) {
        console.log(`Tool: ${block.name}`); // Tool call
      }
    }
  } else if (message.type === "result") {
    console.log(`Done: ${message.subtype}`);
  }
}
```

**Function signature:**

```typescript
function query({
  prompt,
  options
}: {
  prompt: string | AsyncIterable<SDKUserMessage>;
  options?: Options;
}): Query
```

The `Query` object also has methods: `interrupt()`, `rewindFiles(userMessageUuid)`, `setPermissionMode(mode)`, `setModel(model)`, `setMaxThinkingTokens(n)`, `supportedCommands()`, `supportedModels()`, `mcpServerStatus()`, and `accountInfo()`.

### 5. MCP Server Configuration

MCP servers are configured via the `mcpServers` option. The `McpServerConfig` type supports four transport types:

**SSE (Server-Sent Events):**
```typescript
type McpSSEServerConfig = {
  type: "sse";
  url: string;
  headers?: Record<string, string>;
}
```

Example:
```typescript
for await (const message of query({
  prompt: "Query the database",
  options: {
    mcpServers: {
      "my-sse-server": {
        type: "sse",
        url: "http://localhost:8000/mcp/sse",
        headers: {
          "Authorization": "Bearer my-token"
        }
      }
    }
  }
})) {
  // handle messages
}
```

**HTTP (Streamable HTTP):**
```typescript
type McpHttpServerConfig = {
  type: "http";
  url: string;
  headers?: Record<string, string>;
}
```

**Stdio:**
```typescript
type McpStdioServerConfig = {
  type?: "stdio";  // default if type is omitted
  command: string;
  args?: string[];
  env?: Record<string, string>;
}
```

Example:
```typescript
mcpServers: {
  playwright: { command: "npx", args: ["@playwright/mcp@latest"] }
}
```

**SDK (in-process):**
```typescript
type McpSdkServerConfigWithInstance = {
  type: "sdk";
  name: string;
  instance: McpServer;
}
```

For creating in-process MCP servers, you can use the `tool()` and `createSdkMcpServer()` helper functions:

   538→```python
   539→import logging
   540→from dataclasses import dataclass, field
   541→from datetime import datetime, timedelta, timezone
   542→
   543→import docker
   544→
   545→logger = logging.getLogger(__name__)
   546→
   547→
   548→@dataclass
   549→class ContainerConfig:
   550→    image: str = "duckdb-agent-sidecar:latest"
   551→    runtime: str = "runsc"
   552→    memory_limit: str = "256m"
   553→    cpu_limit: float = 0.5
   554→    max_lifetime_seconds: int = 600
   555→    network: str = "agent-sandbox"
   556→
   557→
   558→@dataclass
   559→class ContainerInfo:
   560→    container_id: str
   561→    session_id: str
   562→    ip_address: str
   563→    port: int = 3000
   564→    created_at: datetime = field(default_factory=lambda: datetime.now(timezone.utc))
   565→    _container: object = field(default=None, repr=False)
   566→
   567→    @property
   568→    def url(self) -> str:
   569→        return f"http://{self.ip_address}:{self.port}"
   570→
   571→
   572→class ContainerManager:
   573→    """Manages per-session gVisor-sandboxed sidecar containers."""
   574→
   575→    def __init__(self, config: ContainerConfig | None = None):
   576→        self._config = config or ContainerConfig()
   577→        self._client = docker.from_env()
   578→        self._containers: dict[str, ContainerInfo] = {}
   579→
   580→    def create(self, session_id: str, env: dict[str, str]) -> ContainerInfo:
   581→        """Spin up a new sidecar container for a session."""
   582→        if session_id in self._containers:
   583→            return self._containers[session_id]
   584→
   585→        container = self._client.containers.run(
   586→            image=self._config.image,
   587→            detach=True,
   588→            runtime=self._config.runtime,
   589→            mem_limit=self._config.memory_limit,
   590→            nano_cpus=int(self._config.cpu_limit * 1e9),
   591→            read_only=True,
   592→            cap_drop=["ALL"],
   593→            security_opt=["no-new-privileges"],
   594→            tmpfs={"/tmp": "size=50m"},
   595→            network=self._config.network,
   596→            environment=env,
   597→            labels={
   598→                "app": "duckdb-agent-sidecar",
   599→                "session_id": session_id,
   600→            },
   601→            auto_remove=False,  # We remove manually to handle errors
   602→        )
   603→
   604→        # Reload to get network info
   605→        container.reload()
   606→        networks = container.attrs.get("NetworkSettings", {}).get("Networks", {})
   607→        network_info = networks.get(self._config.network, {})
   608→        ip_address = network_info.get("IPAddress", "127.0.0.1")
   609→
   610→        info = ContainerInfo(
   611→            container_id=container.id,
   612→            session_id=session_id,
   613→            ip_address=ip_address,
   614→            _container=container,
   615→        )
   616→        self._containers[session_id] = info
   617→        logger.info(
   618→            "Created sidecar container %s for session %s at %s",
   619→            container.id[:12],
   620→            session_id,
   621→            info.url,
   622→        )
   623→        return info
   624→
   625→    def get(self, session_id: str) -> ContainerInfo | None:
   626→        """Get container info for a session."""
   627→        return self._containers.get(session_id)
   628→
   629→    def stop(self, session_id: str) -> None:
   630→        """Stop and remove the container for a session."""
   631→        info = self._containers.pop(session_id, None)
   632→        if info is None:
   633→            return
   634→
   635→        container = info._container
   636→        try:
   637→            container.stop(timeout=5)
   638→        except Exception as e:
   639→            logger.warning("Failed to stop container %s: %s", info.container_id[:12], e)
   640→        try:
   641→            container.remove(force=True)
   642→        except Exception as e:
   643→            logger.warning("Failed to remove container %s: %s", info.container_id[:12], e)
   644→
   645→        logger.info("Stopped sidecar container %s for session %s", info.container_id[:12], session_id)
   646→
   647→    def cleanup_expired(self) -> int:
   648→        """Remove containers that have exceeded max lifetime."""
   649→        cutoff = datetime.now(timezone.utc) - timedelta(seconds=self._config.max_lifetime_seconds)
   650→        expired = [
   651→            sid for sid, info in self._containers.items()
   652→            if info.created_at < cutoff
   653→        ]
   654→        for sid in expired:
   655→            logger.info("Container for session %s exceeded max lifetime, removing", sid)
   656→            self.stop(sid)
   657→        return len(expired)
   658→
   659→    def shutdown_all(self) -> None:
   660→        """Stop and remove all active containers. Called on backend shutdown."""
   661→        session_ids = list(self._containers.keys())
   662→        for sid in session_ids:
   663→            self.stop(sid)
   664→        logger.info("Shut down %d sidecar containers", len(session_ids))
   665→```

   138→### Credential Proxy
   139→
   140→When the agent runs, the backend spawns a Claude Code subprocess via the Anthropic Agent SDK. A naive approach would pass `ANTHROPIC_API_KEY` directly into that subprocess's environment — but any tool or shell command the agent executes could then read and exfiltrate the key.
   141→
   142→Instead, the backend runs a built-in reverse proxy at `/anthropic` that sits between Claude Code and `api.anthropic.com`:
   143→
   144→```
   145→Claude Code subprocess
   146→  → ANTHROPIC_BASE_URL=http://127.0.0.1:{PORT}/anthropic
   147→  → ANTHROPIC_API_KEY=<short-lived UUID token>
   148→        ↓
   149→FastAPI proxy (/anthropic/{path})
   150→  → validates UUID token
   151→  → swaps it for the real ANTHROPIC_API_KEY
   152→  → forwards request to api.anthropic.com
   153→```
   154→
   155→**How it works:**
   156→
   157→1. Before each agent session, the backend mints a random UUID token with a 10-minute TTL.
   158→2. The token is injected into the subprocess environment as `ANTHROPIC_API_KEY`; the real key is never exposed.
   159→3. The proxy validates every inbound request against the token store and substitutes the real key before forwarding upstream.
   160→4. When the session ends, the token is explicitly revoked in a `finally` block, regardless of success or error.
   161→5. A background task runs every 60 seconds to sweep any tokens that outlived their TTL.
   162→
   163→The subprocess only ever holds a single-session UUID. Even if a tool call reads the environment, all it gets is a temporary token scoped to that conversation.

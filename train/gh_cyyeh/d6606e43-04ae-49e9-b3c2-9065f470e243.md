Here are 3 approaches for how to identify and track per-user DuckDB instances: --- **Approach A — Frontend-generated UUID (Recommended)** Frontend calls `crypto.randomUUID()` on page load, stores it in memory (not localStorage). Every request sends it via an `X-Session-ID` header.

> AGENT

I can see the bug. `shutdown_all()` only stops containers tracked in the in-memory `self._containers` dict. Containers can be missed in several scenarios:

1. **Orphaned from previous runs** - If the backend crashed or was killed (SIGKILL), the in-memory registry is lost and orphaned containers remain running on the next restart.
2. **Race during creation** - A container being created in `run_in_executor` during shutdown may not yet be in the registry.
3. **Any tracking gap** - If `create()` succeeds at Docker level but crashes before `self._containers[session_id] = info`, the container is orphaned.

The fix: use Docker labels (`app=duckdb-agent-sidecar`) to find and stop **all** sidecar containers, not just those in-memory. I'll also add a startup cleanup for orphans from previous runs.

**Root Cause (Phase 2 complete):**

The fix is clean and consistent. Here's a summary:

**Bug:** Intermediate orchestrator text (e.g., "Great choice! Let me pull together a few demographic charts.", "The width_bucket function doesn't exist in DuckDB...") was appearing in the ANSWER block instead of being hidden in the THINKING section.

**Root Cause:** In `AgentContext.tsx`, once `thinking_done` fires, `phaseRef` is set to `'answer'` permanently. When `onToolCall`, `onSubagentStart`, or `onUserQuestion` subsequently fires, accumulated text was classified as `'answer'` based on this phase — even though text preceding a tool call is intermediate narration, not the final answer.

**Fix:** In all 6 callbacks (`onToolCall`, `onSubagentStart`, `onUserQuestion` — each in both `sendMessage` and `editMessage`), always classify accumulated text as `'thinking'` instead of conditionally based on phase. Only the text remaining at `onDone` (the final text after all tool calls complete) is classified as `'answer'`, which was already the correct behavior in that handler.

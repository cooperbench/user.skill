def list_tables(self) -> list[dict[str, Any]]:
    """List all tables with their schema info."""
    tables_result = self.conn.execute("SHOW TABLES")
    table_names = [row[0] for row in tables_result.fetchall()]
    return [self.get_table_info(name) for name in table_names]

**Agent Data Flow:**

```
User sends message in Agent Mode
    ↓
sendMessage() in AgentContext
    ↓
runAgentLoop() in agentService.ts
    ↓
POST /api/chat with message and optional session_id
    ↓
stream_chat() in agent.py
    ↓
ClaudeSDKClient processes message with system prompt
    ↓
Agent uses mcp__duckdb__execute_sql tool
    ↓
SQL execution on DuckDB database
    ↓
SSE streaming events back to frontend:
    event: thinking
    event: tool_call
    event: tool_result
    event: answer
    event: done
    ↓
AgentContext processes each event:
  - onTextChunk: buffers and flushes text
  - onToolCall: creates pending tool segment
  - onToolResult: updates tool segment with results
  - onDone: saves session_id for resume
    ↓
MessageBubble renders with:

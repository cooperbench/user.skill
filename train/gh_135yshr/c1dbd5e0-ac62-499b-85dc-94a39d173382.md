2. 左サイドバーで **「ログイン」** キーチェーン > 上部タブで **「証明書」** を選択

4. その証明書を **右クリック** > **「"Developer ID Application: ..."を書き出す...」**
5. フォーマット: **個人情報交換 (.p12)** を選択して保存
6. **パスワードを設定する**（このパスワードは後で `MACOS_SIGN_PASSWORD` として使うのでメモしておく）

### 1-4. Base64 エンコードする

ターミナルで以下を実行:

```bash
base64 -i ~/Desktop/Certificates.p12 | pbcopy
```

クリップボードにコピーされた文字列 → これが **`MACOS_SIGN_P12`** の値になります。テキストエディタに一旦貼り付けて保存しておくと安心です。

## Step 2: App Store Connect API キーの作成

### 2-1. API キーを発行する

1. ブラウザで https://appstoreconnect.apple.com/access/integrations/api を開く
2. **「Team Keys」** タブを選択
3. **「Generate API Key」** をクリック
4. 名前: `meow-notarization`（任意の名前でOK）
5. アクセス: **「Developer」** を選択
6. 「Generate」をクリック

### 2-2. 3つの情報を控える

| 情報 | 場所 | メモ |
|------|------|------|
| **Key ID** | キー一覧の「Key ID」列（10文字の英数字） | → `MACOS_NOTARY_KEY_ID` |
| **Issuer ID** | ページ上部に表示される UUID | → `MACOS_NOTARY_ISSUER_ID` |
| **.p8 ファイル** | 「Download API Key」ボタン | → `MACOS_NOTARY_KEY` |

> **.p8 ファイルは1回しかダウンロードできません。** ダウンロードしたら安全な場所に保管してください。

### 2-3. .p8 ファイルを Base64 エンコードする

```bash
base64 -i ~/Downloads/AuthKey_XXXXXXXXXX.p8 | pbcopy
```

クリップボードにコピーされた文字列 → これが **`MACOS_NOTARY_KEY`** の値です。

    42→

    56→## Features
    57→
    58→- **Cat-themed syntax** — Every keyword is a cat word (`nyan`, `meow`, `sniff`, `purr`, ...)
    59→- **Transpiles to Go** — Generates clean, readable Go code
    60→- **Native binaries** — Compiled output runs at full Go speed
    61→- **Gradual typing** — Optional type annotations with `meow.Value` boxing
    62→- **First-class functions** — Lambdas with `paw(x) { x * 2 }`
    63→- **Structs & newtypes** — `kitty` (struct), `collar` (newtype), `breed` (alias)
    64→- **Interfaces & methods** — `pose` (interface), `groom` (method impl)
    65→- **Standard library** — `nab "file"`, `nab "http"` for file I/O and HTTP
    66→- **List operations** — `lick` (map), `picky` (filter), `curl` (reduce)
    67→- **Pattern matching** — `peek` expression with ranges and wildcards
    68→- **Pipe operator** — Chain operations with `|=|`
    69→- **Cat error messages** — `Hiss! "x" is not defined, nya~`
    70→- **Modern Go internals** — Built with `iter.Seq`, `iter.Pull`, generics, `go:embed`

   314→## How It Works
   315→
   316→```
   317→.nyan → [Lexer] → iter.Seq[Token] → [Parser] → AST → [Codegen] → .go → go build → Binary
   318→```
   319→
   320→The compiler pipeline:
   321→
   322→1. **Lexer** (`pkg/lexer`) — Tokenizes source using `iter.Seq[Token]`
   323→2. **Parser** (`pkg/parser`) — Pratt parser with `iter.Pull` for push-to-pull conversion
   324→3. **Codegen** (`pkg/codegen`) — Transforms AST into Go source code
   325→4. **Compiler** (`compiler`) — Orchestrates the pipeline, runs `go build`
   326→5. **Runtime** (`runtime/meowrt`) — Provides `Value` interface, operators, and builtins

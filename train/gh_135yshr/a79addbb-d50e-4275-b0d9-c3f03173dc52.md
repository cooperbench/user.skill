## エラーの原因

`go generate ./...` の実行時に以下のエラーが出ています：

```
go: go.mod requires go >= 1.26.0 (running go 1.25.7; GOTOOLCHAIN=local)
```

**`actions/setup-go` v5 → v6 のメジャーバージョンアップ**による破壊的変更が原因です。

`actions/setup-go` v6 では、デフォルトの動作が変わり、`GOTOOLCHAIN=local` が設定されるようになりました。これにより、`go.mod` で指定された `go 1.26.0` より古い Go 1.25 ではビルドできなくなっています（v5 では `GOTOOLCHAIN=auto` がデフォルトで、自動的に必要なバージョンをダウンロードしていた）。

### 解決方法

いくつかの選択肢があります：

1. **Go 1.25 のテストマトリクスを削除する** — `go.mod` が `go 1.26.0` を要求しているので、1.25 のテストは本来不要
2. **CIで `GOTOOLCHAIN` を上書きする** — `GOTOOLCHAIN: auto` を環境変数に設定する
3. **setup-go v6 へのアップグレードを見送る** — PRをクローズして v5 のまま維持する

プロジェクトが Go 1.26+ を要求している（`iter` パッケージ使用）ので、**オプション1（Go 1.25 のマトリクスを削除）** が最も適切です。対応しますか？

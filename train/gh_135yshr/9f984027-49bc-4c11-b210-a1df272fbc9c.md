## savanna - Goテストスメル検出CLIツール **概要**: Go のテストファイル (`*_test.go`) を AST解析し、テストスメル（品質の悪いテストパターン）を検出するCLIツールです。Java版 [savanna-maven-plugin](https://github.com/kawasima/savanna-maven-plugin) にインスパイアされており、スメル検出時にライオンのAAが @t_wada ミームメッセージと共に吠えます。外部依存ゼロ（標準ライブラリのみ）。 **規模**: Go約1,400行 ### ディレクトリ構成 ``` cmd/savanna/main.go … エントリポイント（CLIフラグ解析→Scanner→Reporter） analyzer/ detector.go … Detector インターフェース定義 + 共通ヘルパー scanner.go … ファイル走査・AST解析・検出パイプラインのオーケストレーション smell.go … SmellType定数・表示名・ライオンメッセージ registry.go … 全Detectorの登録 scanner_test.go … テスト（ScanSourceでソース文字列を直接テスト） *_detector.go … 各スメル検出器（7種） reporter/ reporter.go … Reporter インターフェース console.go … コンソール出力（ライオンバナー付き） json.go … JSON出力 banner/ lion.go … ライオンASCIIアート testdata/ smelly_test.go … テスト用サンプル ``` ### 検出できるテストスメル（7種） | Detector | 検出内容 | |---|---| | `empty_test` | 空のテスト関数 | | `missing_assertion` | アサーションが無いテスト | | `missing_error_check` | エラーチェック漏れ | | `conditional_test_logic` | テスト内の条件分岐ロジック | | `magic_number` | マジックナンバーの使用 | | `redundant_print` | 不要なprint文 | | `sleepy_test` | `time.Sleep` の使用 | | `missing_helper` | `t.Helper()` 呼び出し漏れ | ### 処理フロー ``` main.go → Scanner.ScanDir() → *.go ファイルをAST解析 → 各 FuncDecl に対して Detector.Detect() を実行 → TestSmell を収集 → Reporter.Report() で出力 ``` ### CLI使用例 ```bash go run ./cmd/savanna/ ./path/to/project # 基本実行 go run ./cmd/savanna/ -format json ./project # JSON出力 go run ./cmd/savanna/ -fail ./project # スメル検出時 exit 1 go run ./cmd/savanna/ -enable EmptyTest,SleepyTest ./project # 特定スメルのみ ``` コンパクトで明快な設計です。新しいスメル検出器を追加する場合は、`Detector` インターフェースを実装して `registry.go` に登録するだけで拡張できます。

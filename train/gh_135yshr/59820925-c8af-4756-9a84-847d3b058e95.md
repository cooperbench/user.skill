# ドキュメントに含める内容

## 1. tmux のインストール
Homebrew を使用して tmux をインストールする手順

含めるコマンド

brew install tmux

tmux -V

## 2. tmux の基本設定
~/.tmux.conf を作成する

以下の設定を含める

- prefix を Ctrl+a に変更
- マウス操作
- vim風キーバインド
- history-limit
- pane index
- pane移動設定

例

set -g prefix C-a
unbind C-b
bind C-a send-prefix
set -g mouse on
setw -g mode-keys vi
set -g history-limit 100000

## 3. tmux Plugin Manager (TPM) 導入

インストール

git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm

.tmux.conf に追加

set -g @plugin 'tmux-plugins/tpm'
set -g @plugin 'tmux-plugins/tmux-sensible'
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'
set -g @plugin 'tmux-plugins/tmux-yank'

run '~/.tmux/plugins/tpm/tpm'

プラグインインストール

Ctrl+a → Shift+i

## 4. tmux の便利設定

以下を追加

- prefix + r で設定リロード
- pane移動
- pane resize
- ステータスバー

例

bind r source-file ~/.tmux.conf \; display "tmux config reloaded"

bind -n C-h select-pane -L
bind -n C-j select-pane -D
bind -n C-k select-pane -U
bind -n C-l select-pane -R

## 5. tmux-resurrect / continuum

自動保存設定

set -g @continuum-restore 'on'
set -g @continuum-save-interval '15'

保存

Ctrl+a Ctrl+s

復元

Ctrl+a Ctrl+r

## 6. tmux の基本操作

以下を表形式で説明

pane操作

Ctrl+a %
Ctrl+a "

pane移動

Ctrl+h/j/k/l

window操作

Ctrl+a c
Ctrl+a n
Ctrl+a p
Ctrl+a w

detach

Ctrl+a d

## 7. tmuxinator 導入

インストール

brew install tmuxinator

プロジェクト作成

tmuxinator new claude

## 8. Claude Code 用 tmuxinator 設定

~/.config/tmuxinator/claude.yml のサンプルを作る

内容

name: claude
root: ~/project

windows:
  - dev:
      layout: main-horizontal
      panes:
        - claude
        - nvim
        - zsh

  - logs:
      panes:
        - zsh

## 9. tmuxinator の起動

tmuxinator start claude

## 10. セッション終了

detach

Ctrl+a d

セッション終了

tmux kill-session -t claude

全tmux終了

tmux kill-server

   305→## 10. セッションの終了

   307→### デタッチ（セッションを維持したまま抜ける）

   317→```bash
   318→tmux kill-session -t claude
   319→```
   320→
   321→### すべての tmux セッションを終了する

   323→```bash

   327→`kill-server` はすべてのセッションを強制終了します。他に動いているセッションがないか確認してから実行してください。

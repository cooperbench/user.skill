```go
func ParsePagination(r *http.Request) (page, perPage int) {
	page = 1
	perPage = 25
	if v := r.URL.Query().Get("page"); v != "" {
		if p, err := strconv.Atoi(v); err == nil && p > 0 {
			page = p
		}
	}
	if v := r.URL.Query().Get("per_page"); v != "" {
		if pp, err := strconv.Atoi(v); err == nil && pp > 0 && pp <= 100 {
			perPage = pp
		}
	}
	return
}
```

**Supported query parameters:**
- `page` — integer > 0 (default: 1)
- `per_page` — integer > 0 and ≤ 100 (default: 25)

## Design

### Search Box
- Text input with a `Search` (Lucide) icon, placed in the header row between the title and the toggle/button group
- Filters projects by name (case-insensitive substring match)
- Typing resets pagination to page 1

### Pagination
- 12 projects per page
- Simple "Previous / Page X of Y / Next" controls at the bottom of the list
- Disabled previous on page 1, disabled next on last page
- Styled consistently with existing design system

### Data Flow
- Fetch all projects with `projects.list(1, 100)` 
- Client-side filter: `items.filter(p => p.name.toLowerCase().includes(query))`
- Client-side slice: `filtered.slice((page-1)*12, page*12)`
- Search and page are local `useState` — no persistence, no URL params

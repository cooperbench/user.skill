**Polling Flow** (`orchestrator.go`):

4. Passes results to `Service.ProcessResults()` which persists to database

### 5. Ingestion → Database → Notification Flow

- `ProcessResults()` takes `IngestionResult` objects and persists them

**PgStore** (`pgstore.go`) — Transactional Outbox Pattern:

### 11. Key Design Patterns

**1. Abstraction via Interface**:
- `IIngestionSource` decouples polling logic from orchestration
- Same interface for all providers: GitHub, Docker Hub, ECR Public

**2. Dynamic Loading**:
- Sources loaded from database on each poll cycle
- New providers can be added without restarting (only code change needed)
- Unsupported providers logged as warnings, skipped gracefully

**3. Idempotent Ingestion**:
- `UNIQUE(source_id, version)` constraint prevents duplicates
- Duplicate constraint violations handled as expected behavior (no error)
- Transactional outbox ensures no event loss

**4. Transactional Outbox**:
- Release insert and job enqueue happen in same transaction
- Guarantees job is created only if release is persisted
- PostgreSQL ACID guarantees exactly-once delivery

**5. Version Filtering**:
- Applied at UI level (form validation) and storage level (optional fields)
- Regex patterns for include/exclude
- Pre-release flag specific to GitHub (conditionally shown in UI)

**6. Version Filter Use**:
- `exclude_prereleases`: Suppresses pre-release versions (GitHub only)
- `version_filter_include`: Regex to only notify matching versions
- `version_filter_exclude`: Regex to suppress matching versions
- Applied during Service.ProcessResults() for filtering decisions

## Design: GitLab Provider

The GitLab provider follows the exact same pattern as the GitHub provider. Here's the design:

### Data Source
- **API**: GitLab REST API v4 — `GET /api/v4/projects/:id/releases` ([docs](https://docs.gitlab.com/api/releases/))
- **Base URL**: `https://gitlab.com` (hardcoded, self-hosted later)
- **Repository format**: `owner/repo` (URL-encoded as `owner%2Frepo` for the API path)
- **Auth**: `GITLAB_TOKEN` env var → `PRIVATE-TOKEN` header
- **Pagination**: 20 per page (configurable via `per_page`), keyset/offset pagination
- **Filtering**: Exclude drafts (same as GitHub). Support `exclude_prereleases` via the upcoming_release field or release metadata.

### Mapped Fields (GitLab → IngestionResult)
| GitLab field | IngestionResult field |
|---|---|
| `tag_name` | `RawVersion` |
| `description` | `Changelog` |
| `released_at` | `Timestamp` |
| `_links.self` | `Metadata["release_url"]` |
| `upcoming_release` | `Metadata["prerelease"]` (for `exclude_prereleases` support) |

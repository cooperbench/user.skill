The two are interchangeable; the resulting APK is the same dev-client APK. **Then separately, `npm run start:dev-client`** — this is **not** a build. It starts Metro (the JS dev server). The already-installed APK connects to Metro and downloads the JS bundle. You leave it running all day; only JS changes flow through it. **So the right sequence:** - Native deps changed → run path 1 OR path 2 to produce a new APK and install it. - Then `npm run start:dev-client` to start Metro. - App on phone → opens, connects to Metro, loads JS. **Which one were you doing?** If you ran `npm run android` and it actually compiled, you're on path 1 (local).

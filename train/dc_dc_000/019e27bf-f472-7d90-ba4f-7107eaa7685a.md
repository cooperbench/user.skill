> AGENT

Yes. Main downsides: - **Contract drift**: if contracts are hand-authored separately from the workflow graph, they become another stale metadata file. Mitigation: infer as much as possible from the built workflow and only require explicit declarations for non-inferable things like SageAttention, system packages, probes, and output expectations. - **Bureaucracy for new workflows**: authors may need to fill more fields before a workflow runs. Mitigation: treat the contract as preflight plus evidence schema, not proof of performance.

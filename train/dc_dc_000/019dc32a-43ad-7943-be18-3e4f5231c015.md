### Step 2: Create `dataclaw/privacy_filter.py` (new module)
**Scope:** Medium
1. **Lazy imports.** All `transformers`/`torch` imports go inside function bodies. Top-level only imports `dataclasses`, `hashlib`, `json`, `re`, `typing`, `logging`. Add a one-shot module-level `_PIPE_CACHE: dict[tuple[str|None, float], Any] = {}`.
2. **Constants:** `MODEL_ID = "openai/privacy-filter"`, `_DEFAULT_MIN_SCORE = 0.85`, `_CHUNK_TOKENS = 480`.
3. **`Finding` dataclass** (`@dataclass(frozen=True)`): `entity: str`, `score: float`, `start: int`, `end: int`, `text: str`, `session_id: str | None = None`, `field: str | None = None`. Method `fingerprint(self) -> str` returns `hashlib.sha256(f"{entity}|{text}".encode()).hexdigest()` (entity + verbatim text — score/offset excluded so re-runs converge).
4. **`is_available() -> bool`**: try `import transformers`; return False on `ImportError`.
5. **`_load(device: str | None, min_score: float)`**: cache key = `(device, min_score)`. Lazy import `from transformers import pipeline` and instantiate `pipeline("token-classification", model=MODEL_ID, aggregation_strategy="simple", device=device)`. Cache and return.
6. **`_chunk_by_tokens(text: str, max_tokens: int = _CHUNK_TOKENS) -> list[tuple[int, str]]`** — naive whitespace token slice that returns `(char_offset, chunk_text)` so we can map findings back to absolute offsets. Sufficient for v1; the doc allows it.
7. **`scan_text(text, *, device=None, min_score=_DEFAULT_MIN_SCORE) -> list[Finding]`** — runs the pipeline per chunk, filters `entity["score"] >= min_score`, builds `Finding`s with absolute offsets.
8. **`scan_session(session, *, device=None, min_score=...)`** — iterate `session["messages"]` (the post-redact format used by `export_to_shards`); concatenate `content`/`thinking`/`tool_uses[*].input`/`tool_uses[*].output.text` strings; tag each `Finding` with `session_id` + a coarse `field` label.
9. **`scan_jsonl(path, *, device=None, min_score=...)`** and **`scan_shards(run_dir, manifest, *, ...)`** — iterate shard files (use `_iter_manifest_shard_paths` from `cli.py` re-exposed, or duplicate the 3-line helper inside `privacy_filter.py` to avoid a circular import). Yield findings.
10. **`scan_shards` and `scan_jsonl` never mutate sessions** — they read-only, return list.
11. **Imports kept minimal**: `from typing import Iterable, Iterator`. The whole module ~150 LOC.

### Step 3: Known-findings registry (same module, `dataclaw/privacy_filter.py`)
**Scope:** Small
1. **`diff_findings(findings, known) -> tuple[list[Finding], list[Finding]]`** returns `(new, already_known)` partitioning by `Finding.fingerprint() in known`. `known` is a `set[str]` of fingerprints OR a dict `{fingerprint: {"count": N, "first_seen": iso, "last_seen": iso}}` — accept both for forward-compat.
2. **`record_findings(findings, known: dict | None) -> dict`**: returns updated dict where each fingerprint's `count` increments and `last_seen` is bumped; `first_seen` set on new entries. O(1) lookup per finding.
3. Pure-Python; no I/O. Caller persists into `config["known_findings"]` via `save_config`.

   ```python
   pf_block = config.get("privacy_filter") or {}
   pf_enabled = bool(pf_block.get("enabled"))
   pf_payload = None
   if pf_enabled:
       from . import privacy_filter as pf
       if not pf.is_available():
           pf_payload = {"status": "unavailable",
                         "hint": "Install with: pip install dataclaw[pii]"}
       else:
           device = pf_block.get("device")
           min_score = float(pf_block.get("min_score", 0.85))
           findings = (pf.scan_shards(path, manifest, device=device, min_score=min_score)
                       if mode == "shards" and manifest is not None
                       else pf.scan_jsonl(path, device=device, min_score=min_score))
           known = config.get("known_findings") or {}
           pf_new, pf_known = pf.diff_findings(findings, known)
           pf_payload = {"status": "scanned",
                         "new": [_finding_dict(f) for f in pf_new],
                         "known": [_finding_dict(f) for f in pf_known],
                         "device": device, "min_score": min_score}
   ```
3. **Strict block.** When `pf_payload and pf_payload.get("status") == "scanned" and pf_payload["new"] and policy == "strict" and not ack_privacy_findings`:

4. **Ack path.** When `ack_privacy_findings` is True and `pf_payload["new"]` is non-empty:
   - `config["known_findings"] = pf.record_findings(pf_new, config.get("known_findings") or {})`.
5. **Permissive path.** When `policy == "permissive"`, log via `dataclaw.logging` (Phase C) and proceed without blocking.
6. **Output.** Add `"privacy_filter": pf_payload` to the result JSON when `pf_payload is not None`. When PF is disabled, output is unchanged (preserves legacy test expectations).
7. **Helper `_finding_dict(f)`** — small local helper for stable JSON serialization of `Finding` (omit nothing; include `fingerprint` so the UI can dedupe).

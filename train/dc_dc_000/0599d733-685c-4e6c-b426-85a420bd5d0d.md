- Plan hash: `sha256` over the canonical-JSON-serialized `plan.json` bytes; `active_run.json` stores `{"run_id", "plan_hash"}` and pins it (SD-003).
- Gate fires **before** `_prepare_project_request()` and `thread_wrapper.begin_orchestrator_run()` so a rejected command writes zero project-run side effects (SD-012, A7).
- Single-host, honor-based, accidental-edit tripwire only (SD-025, A risk row 4).
- The "incoming command" matched against the plan cursor in Phase 1 is the canonical argv of the dispatch (no new verbs); cursor advances when `step_completed` is appended to `events.jsonl` (SD-013).
- `ARTAGENTS_TASK_RUN_ID` is the env contract that ties child orchestrator/executor/hype calls back to the parent run (SD-017, A9). In Phase 1 it is **set** by the gate when it enters a task run and **read** by gate re-entry in child processes; full inheritance plumbing into `prepare_project_run` (skipping child `run.json`) ships in Phase 2 — for Phase 1 we only ensure the env var propagates and the gate honors it on re-entry, leaving `prepare_project_run` behavior untouched.

### Step 3: Hash-chained event log (`artagents/core/task/events.py`)

**Scope:** Medium

1. **Implement** `canonical_event_json(event: Mapping) -> str`: stable JSON via `json.dumps(event, sort_keys=True, separators=(",", ":"), ensure_ascii=False)`. No trailing newline; serialization is the unit hashed.
2. **Implement** `append_event(events_path: Path, event: dict) -> str`:
   - Compute `prev_hash`: if file does not exist or is empty, use `"sha256:" + "0"*64` as the seed; otherwise read the last non-empty line and take its `hash` field.
   - Set `event["seq"]` to current line count; set `event["prev_hash"]` to `prev_hash`; do **not** include `hash` in the canonicalization input.
   - Compute `hash = "sha256:" + hashlib.sha256((prev_hash + canonical_event_json(event)).encode("utf-8")).hexdigest()`.
   - Append `json.dumps(event_with_hash, ...) + "\n"` atomically (open append, fsync, close); return the new hash.
3. **Implement** `verify_chain(events_path: Path) -> tuple[bool, int, str | None]`: stream lines, recompute each hash from `prev_hash + canonical(event_without_hash)`, return `(ok, last_seq, error_message)`. A missing file returns `(True, -1, None)`.
4. **Implement** `read_events(events_path: Path) -> list[dict]` for the gate cursor and tests.
5. Define event-shape helpers for Phase 1: `make_run_started_event(run_id, plan_hash)`, `make_step_dispatched_event(plan_step_id, command, argv)`, `make_step_completed_event(plan_step_id, returncode)`. Each returns a dict including `ts` (UTC ISO-8601) and `kind`.

### Step 6: The gate (`artagents/core/task/gate.py`)

**Scope:** Medium

1. **Define** `TaskRunGateError(RuntimeError)` with attributes `(reason: str, recovery: str)`. The exception's `__str__` includes both. The CLI layer prints `recovery` to stderr and exits non-zero.
2. **Implement** `gate_command(slug: str, command: str, argv: Sequence[str], *, root=None) -> GateDecision`:
   - **Pre-check**: if `read_active_run(slug)` returns `None`, return `GateDecision(active=False)` — this means "no task run, pass through to legacy dispatch unchanged". This is what makes Phase 1 additive.
   - **Active run path**: load `active_run.json`, locate `runs/<run_id>/plan.json`, recompute hash, compare to `active_run.json["plan_hash"]`. Mismatch → reject with recovery `"artagents abort --project <slug>"` (Phase 5 will provide the verb; in Phase 1 we still print this string per SD-011 — it's the authoritative recovery the user must type once Phase 5 ships, and matches the doc).
   - **Chain integrity**: call `verify_chain(events_path)`. Failure → reject, same recovery.
   - **Cursor derivation**: `cursor = number_of_step_completed_events`. If `cursor >= len(plan.steps)`, the run is complete; reject any further dispatch with recovery `"artagents abort --project <slug>"`.
   - **Command match**: compare `command` to `plan["steps"][cursor]["command"]` via exact string equality on a canonical form (strip surrounding whitespace; do not interpolate). Mismatch → reject with recovery `"artagents next --project <slug>"`.
   - On accept: append a `step_dispatched` event, call `apply_task_run_id_env(run_id, slug)`, and return `GateDecision(active=True, run_id=..., plan_step_id=..., events_path=...)`.
3. **Implement** `record_dispatch_complete(decision: GateDecision, returncode: int) -> None` that appends a `step_completed` event. Caller wraps the dispatch try/finally.
4. **Define** `command_for_argv(argv: Sequence[str]) -> str`: returns the canonical textual form the gate matches against. For Phase 1, this is `" ".join(shlex.quote(a) for a in argv[1:])` if `argv[0]` ends in `artagents` or is `python3 -m artagents`; otherwise the full argv joined. Document the exact rule in a single docstring line so authors of `plan.json` know what string to put in `steps[].command`.

        # Implementation Plan: Collapsible Accordion Sections in VideoGenerationModal

## Overview

**Goal:** Restructure `VideoGenerationModal` to have two independently collapsible accordion sections: (1) "Shot Images" showing `ShotImagesEditor` in read-only batch mode, and (2) "Generation Settings" containing the existing `BatchSettingsForm` + `MotionControl`. The Generate button stays in an always-visible footer.

**Current state:**
- `VideoGenerationModal.tsx` (145 lines) — header with thumbnail strip, scrollable form body, fixed footer
- `VideoGenerationModalSections.tsx` (265 lines) — `VideoGenerationModalHeader`, `VideoGenerationModalLoadingContent`, `VideoGenerationModalFormContent`
- `useVideoGenerationModalController.ts` (459 lines) — orchestrates settings, images, generation
- Existing `CollapsibleSection` component in `src/shared/components/ui/composed/collapsible-section.tsx` supports controlled/uncontrolled modes with `defaultOpen`
- `ShotImagesEditor` already supports `readOnly: boolean` and `generationMode: 'batch'` with `preloadedImages`

**Key constraint:** `ShotImagesEditor` has a massive 4-sub-interface props type. In read-only mode, all edit callbacks can be no-ops, but the props object must be fully constructed. A thin wrapper component that handles the boilerplate is warranted.

## Phase 1: Data Layer — Expose image data from controller

### Step 1: Extend controller return type (`useVideoGenerationModalController.ts`)
**Scope:** Small
1. **Expose** `positionedImages` as full `GenerationRow[]` (already available internally as the filtered+sorted result at line 250-255). Currently returned but typed as `PositionedImagePreview[]` in the sections. No type change needed in the controller — it already returns the full objects; only the sections file narrows them via its local interface.
2. **Also expose** `effectiveAspectRatio` (line 260) — needed by `ShotImagesEditor` for proper rendering. Currently computed but not returned.

## Phase 2: UI Components — Collapsible sections + read-only editor wrapper

### Step 2: Create `ReadOnlyShotImagesGrid` wrapper component (`VideoGenerationModalSections.tsx`)
**Scope:** Medium
1. **Add** a new component `ReadOnlyShotImagesGrid` in `VideoGenerationModalSections.tsx` that wraps `ShotImagesEditor` with:
   - `readOnly: true`
   - `generationMode: 'batch'`
   - `preloadedImages: GenerationRow[]`
   - All `editActions` as no-op functions
   - Minimal `displayOptions` (columns=4, isMobile=false, isModeReady=true)
   - Empty `shotWorkflow`
2. **Props:** `shotId: string`, `images: GenerationRow[]`, `aspectRatio: string`, `batchVideoFrames: number`
3. This keeps the ShotImagesEditor boilerplate isolated from the modal layout logic.

### Step 3: Create collapsed summary components (`VideoGenerationModalSections.tsx`)
**Scope:** Small
1. **Add** `ShotImagesSummary` — renders a horizontal thumbnail strip (reuse the existing thumbnail pattern from `VideoGenerationModalHeader` lines 43-58) plus an image count badge. Shown when the "Shot Images" section is collapsed.
2. **Add** `GenerationSettingsSummary` — renders a compact one-liner: model name, frame count, and truncated prompt. Props: `settings: VideoTravelSettings`. Shown when "Generation Settings" is collapsed.

### Step 4: Build the accordion section layout (`VideoGenerationModalSections.tsx`)
**Scope:** Medium
1. **Add** `VideoGenerationModalAccordionContent` component that renders two `CollapsibleSection` instances:
   - Top: title="Shot Images", `defaultOpen` from prop, collapsed content = `ShotImagesSummary`, expanded content = `ReadOnlyShotImagesGrid`
   - Bottom: title="Generation Settings", `defaultOpen` from prop, collapsed content = `GenerationSettingsSummary`, expanded content = existing `VideoGenerationModalFormContent`
2. **Note on CollapsibleSection behavior:** The existing `CollapsibleSection` doesn't support showing a summary when collapsed (it just hides content). Two approaches:
   - **Option A (recommended):** Use controlled mode — manage open state locally, render summary outside the collapsible when `!isOpen`, render full content inside `CollapsibleContent`.
   - **Option B:** Extend `CollapsibleSection` with a `collapsedContent` prop. This changes the shared component which may not be desired.
   - Go with Option A to avoid shared component changes.
3. **Props interface:**
   ```typescript
   interface VideoGenerationModalAccordionContentProps {
     defaultTopOpen?: boolean;
     defaultBottomOpen?: boolean;
     // ... all existing VideoGenerationModalFormContentProps
     // ... image grid props (shotId, images, aspectRatio, batchVideoFrames)
   }
   ```

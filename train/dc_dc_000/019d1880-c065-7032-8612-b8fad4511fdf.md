**Decision logic (first match wins):**

| Condition | Guidance |
|-----------|----------|
| `iteration == 1` | "First iteration — follow gate recommendation: {recommendation}." |
| `PROCEED` + preflight passed | "Plan passed gate and preflight. Proceed to execute." |
| `PROCEED` + preflight failed | "Gate says PROCEED but preflight blocked. Fix preflight issues before executing: {failing_checks}." |
| `ESCALATE` + `robustness == "light"` and `weighted_score <= 4.0` | "Auto-force-proceed eligible. Run: `megaplan override force-proceed --plan <name> --reason \"light robustness, score {score}\"`" |

| `ITERATE` + plateaued (score unchanged or worsened for 2+ iterations) + recurring critiques | "Score plateaued with recurring critiques the loop can't fix. Consider force-proceeding: `megaplan override force-proceed --plan <name>`" |
| `ITERATE` + improving (score decreased) | "Score improving ({history} → {current}). Continue to revise." |
| `ITERATE` + worsening (score increased) | "Score worsening ({history} → {current}). Investigate — the loop may be diverging." |
| `ITERATE` fallthrough | "Gate recommends another iteration. Revise the plan." |

- Unresolved flags exist → "Verify unresolved flags against the plan and project code before accepting."

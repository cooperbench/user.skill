The current projection-based architecture has produced a recurring class of bugs that we cannot fix incrementally — every patch surfaces another bug because the underlying model is wrong. This refactor eliminates the entire bug class structurally. ## Why (the structural problem) The previous "first-class shot groups" megaplan introduced a pinnedShotGroups[i] = { shotId, trackId, start, children: [{clipId, offset, duration}], clipIds, mode, ... } data shape. Cohesion is enforced by re-deriving clip positions from pinnedShotGroups[].children via projectPinnedShotGroups, which runs three times per commit cycle (inside resizeGroupEdge, inside applyEdit, and inside buildDataFromCurrentRegistry via repairConfig). This is "cohesion by re-projection," which means: 1. Two parallel data shapes for the same thing. pinnedShotGroups[i].children[j].duration vs clips[k].hold. Any edit that bypasses the projection (a free-clip resize fallback, a stale closure, a missing prop) gets silently reverted because the next projection re-derives from children. 2. Auto-save fires during drags and drops pointer capture. The save round-trip causes a re-render mid-drag, which can drop pointer capture, which fires a fresh pointerdown on whatever's under the cursor — breaking one user gesture into multiple resize sessions. 3. The prop chain has 8 hand-offs for startGroupEdgeResize. Any one can drop the prop silently because TypeScript widens object literal types to satisfy the interface even when fields are missing. We just hit one (VideoEditorProvider.tsx was missing the field, surfacing as "snaps back to full shot length"). 4. resizeGroupEdge has wrong semantics — it scales every child of the group proportionally when you drag an outer edge. Users expect: drag the right edge of the last clip → only that clip's duration changes. The current code shrinks every clip in the group. 5. Three different views of the same data (PinnedShotGroup → ShotGroup → PositionedShotGroup), each with its own filter that can drop the group from view, each with its own slightly different fields. This entire conversation has been bug → fix → bug → fix for hours. Each fix passes type-check and tests.

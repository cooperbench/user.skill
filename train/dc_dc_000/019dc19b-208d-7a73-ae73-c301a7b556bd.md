### Step 35: `dataclaw/logging.py` — JSON-lines rotating logger (new module)
**Scope:** Medium
1. **`setup_logging(run_id, level="INFO") -> logging.Logger`**:
   ```python
   import logging, json, sys
   from pathlib import Path
   from logging.handlers import TimedRotatingFileHandler
   LOG_DIR = Path.home() / ".dataclaw" / "logs"
   class JsonFormatter(logging.Formatter):
       def format(self, record):
           payload = {"ts": self.formatTime(record), "level": record.levelname,
                      "logger": record.name, "msg": record.getMessage(),
                      "run_id": getattr(record, "run_id", None),
                      "phase": getattr(record, "phase", None),
                      "session_id": getattr(record, "session_id", None),
                      "project": getattr(record, "project", None),
                      "source": getattr(record, "source", None),
                      "extra": getattr(record, "extra_data", None)}
           if record.exc_info: payload["exc"] = self.formatException(record.exc_info)
           return json.dumps({k:v for k,v in payload.items() if v is not None})
   def setup_logging(run_id, level="INFO"):
       LOG_DIR.mkdir(parents=True, exist_ok=True)
       handler = TimedRotatingFileHandler(LOG_DIR / "auto.jsonl",
                                          when="midnight", backupCount=30, utc=True)
       handler.suffix = "%Y-%m-%d"; handler.setFormatter(JsonFormatter())
       stderr_handler = logging.StreamHandler(sys.stderr); stderr_handler.setLevel("WARNING")
       stderr_handler.setFormatter(JsonFormatter())
       logger = logging.getLogger("dataclaw")
       logger.setLevel(level); logger.handlers = [handler, stderr_handler]
       return logging.LoggerAdapter(logger, {"run_id": run_id})
   ```

## Phase 9: macOS Keychain HF token + `dataclaw hf {login,logout,whoami}` + sidecar token delivery

### Step 41: `_resolve_hf_token()` helper (`dataclaw/auth.py` — new)
**Scope:** Medium
1. **New module**:
   ```python
   import os
   from pathlib import Path
   KEYRING_SERVICE = "io.dataclaw.app"
   KEYRING_ACCOUNT = "hf_token"

   def _resolve_hf_token() -> str | None:
       """Order: env > macOS Keychain (via keyring) > huggingface_hub default path."""
       tok = os.environ.get("HF_TOKEN")
       if tok: return tok
       try:
           import keyring
           tok = keyring.get_password(KEYRING_SERVICE, KEYRING_ACCOUNT)
           if tok: return tok
       except ImportError:
           pass
       p = Path.home() / ".cache" / "huggingface" / "token"
       if p.exists():
           try: return p.read_text().strip() or None
           except OSError: return None
       return None

   def _store_hf_token(tok: str) -> None:
       import keyring
       keyring.set_password(KEYRING_SERVICE, KEYRING_ACCOUNT, tok)

   def _delete_hf_token() -> None:
       try:
           import keyring; keyring.delete_password(KEYRING_SERVICE, KEYRING_ACCOUNT)
       except Exception: pass
   ```
2. **Wire** `push_to_huggingface` and `push_shards_to_huggingface` to set `os.environ["HF_TOKEN"] = _resolve_hf_token()` (if found) before `HfApi()` calls — `huggingface_hub` picks it up natively.

## Phase 10: Push retry + exponential backoff + persistent failed-run staging

### Step 46: Retry wrapper around `push_shards_to_huggingface` (`dataclaw/cli.py`)
**Scope:** Medium
1. **New helper `_push_with_retry(run_dir, repo_id, manifest, logger)`**:
   ```python
   import time, random
   BACKOFF_SECONDS = [30, 120, 600]   # 30s, 2m, 10m
   RETRIABLE = (ConnectionError, TimeoutError)   # + urllib3.exceptions.*

   def _is_retriable(exc) -> bool:
       from huggingface_hub.utils import HfHubHTTPError
       if isinstance(exc, RETRIABLE): return True
       if isinstance(exc, HfHubHTTPError):
           sc = exc.response.status_code if exc.response else 0
           if sc in (401, 403, 400): return False  # auth / bad request — fail fast
           if sc == 429 or 500 <= sc < 600: return True
       return False

   def _retry_after_seconds(exc, attempt: int) -> float:
       # Honor Retry-After header on 429
       try:
           retry = exc.response.headers.get("Retry-After")
           if retry: return float(retry)
       except Exception: pass
       return BACKOFF_SECONDS[min(attempt, len(BACKOFF_SECONDS) - 1)] + random.uniform(0, 5)

   def _push_with_retry(run_dir, repo_id, manifest, logger):
       total_wait = 0.0
       last_exc = None
       for attempt in range(3):
           try:
               logger.info("hf_upload_start", extra={"phase":"push","attempt":attempt})
               url = push_shards_to_huggingface(run_dir, repo_id, manifest)
               logger.info("hf_upload_end", extra={"phase":"push","attempt":attempt,"url":url})
               return url, attempt + 1, total_wait
           except Exception as exc:
               last_exc = exc
               if not _is_retriable(exc) or attempt == 2:
                   logger.exception("hf_upload_failed", extra={"phase":"push","attempt":attempt})
                   break
               wait = _retry_after_seconds(exc, attempt)
               logger.warning("hf_upload_retry", extra={"wait": wait, "attempt": attempt})
               time.sleep(wait); total_wait += wait
       raise PushFailed(last_exc, attempts=3, backoff_seconds_total=total_wait)
   ```
2. **`auto` handler**: on `PushFailed`, **move the run dir** from `~/.dataclaw/export/runs/{run_id}` → `~/.dataclaw/staging/{run_id}` (preserved for `--retry-only`), record `last_auto_run.result="error"` + `push_attempts` + `backoff_seconds_total`, exit code 4.

## Risk & tradeoff notes

- **Keychain in launchd gui-domain**: works when user is logged in. If user is logged out, auto-run fails with a clear exit-2 error; next run at the scheduled time re-attempts. Documented in Phase 9 Step 44.
- **PyInstaller universal2 sidecar**: ~40–80 MB per arch; `.dmg` ~120 MB total. Acceptable for a menubar app.
- **Notarization roundtrip**: adds ~5–15 min to `release.yml` runtime per arch. Tauri bundler handles the polling.
- **`tauri-plugin-updater` signing**: ed25519 private key must be rotated if leaked. Rotation involves publishing a new public key in a plan-documented app release, then the next release uses it. Users on older versions won't accept the new key — document as a known limitation.
- **PushFailed preservation**: the failed-run dir is NOT garbage-collected automatically (separate from `_cleanup_stale_runs(keep=3)` on the normal runs dir). User must `dataclaw clean-staging` or retry.
- **Rollback scope**: reverts the HF repo tree only; local `last_export_cutoff` is NOT auto-rewound, so sessions present in the pre-rollback revision won't be re-pushed. Plan for v2: `dataclaw rollback --reset-cutoff`. Document as `info`-level TODO.
- **Entitlements minimalism**: `disable-library-validation=false` by default; bump only if PyInstaller runtime fails at launch. Notarization works either way.

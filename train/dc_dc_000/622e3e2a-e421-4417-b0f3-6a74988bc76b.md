## Overview

Megaplan currently has no model of what an executor or reviewer can actually do. Specs with human-only criteria (browser observation, runtime counts) are handed to container agents, which fail at review — wasting a full execute pass. The M0 incident is the canonical example.

This release adds **capability matching**: workers declare what they can verify, criteria declare what they require, and the harness rejects mismatches at plan time. Four guardrails (closed registry, mandatory `requires` on `must` criteria, worker discovery, complementary pre-critique audit) address the failure modes identified in the critique and losses analysis.

**Current state:** v0.16.0. Success criteria in `plan.json`/`revise.json`/`finalize.json` are `{criterion, priority}` objects. Review verdict enum is `pass | fail | waived`. State machine has 9 states, no `awaiting_human_verify`. No capability concept exists anywhere.

**Key files:**
- `megaplan/schemas.py` — JSON schemas for all step outputs
- `megaplan/types.py` — states, TypedDicts, constants
- `megaplan/_core/workflow.py` — state machine transitions
- `megaplan/handlers.py` — step handlers (critique, gate, finalize, review)
- `megaplan/prompts/review.py` — review prompt builder
- `megaplan/prompts/planning.py` — plan prompt builder
- `megaplan/prompts/critique.py` — critique/revise prompt
- `megaplan/checks.py` — critique check registry
- `megaplan/cli.py` — CLI argument parsing and dispatch
- `megaplan/workers.py` — worker orchestration
- `pyproject.toml` — version

## Phase 2: Core Logic — Audit, Review Changes, CLI

### Step 5: Create verifiability audit module (`megaplan/verifiability.py`)
**Scope:** Medium
1. **Create** `megaplan/verifiability.py` with:
   - `audit_criteria(criteria: list[dict], worker_caps: dict[str, set[str]]) -> list[CriterionAudit]` — pure-Python check: for each criterion, verify `set(criterion.get("requires", [])) ⊆ union_verifies`. Return list of audit results with `{criterion_idx, verdict, rationale, missing_caps}`.
   - `classify_criteria(criteria: list[dict], worker_caps: dict[str, set[str]]) -> tuple[list[dict], list[dict]]` — split into machine-verifiable and human-deferred based on `requires` vs available capabilities.
   - Verdict enum: `machine_verifiable`, `human_only`, `unverifiable_no_worker` (requires caps no configured worker has, including human).
2. **Implement** plan-time validation: `validate_requires(criteria, registry)` checks all `requires` entries are known capability strings, and that `must` criteria have non-empty `requires` (empty only allowed with explicit opt-out — but for migration, empty is allowed with a deprecation warning).

### Step 6: Wire audit into critique phase (`megaplan/handlers.py`, `megaplan/checks.py`)
**Scope:** Medium
1. **Add** a new critique check `verifiability` to `megaplan/checks.py` (tier: `core`, category: `verifiability`, severity: `likely-significant`).
2. **Hook** into `handle_critique` (`megaplan/handlers.py:861`): before the worker call, run `audit_criteria` from Step 5. Inject results as synthetic critique flags with category `verifiability`:
   - `requires` references unknown capability → blocking flag
   - `must` criterion with empty `requires` → advisory flag (deprecation notice)
   - `requires` not satisfiable by any configured worker AND no `human_reviewer` configured → blocking flag ("criterion unreachable: no worker can verify")
   - `requires` satisfiable only by `human_reviewer` → noted flag (informational, routes to pending-human at review)
3. **These flags** enter the existing gate→revise loop: blocking verifiability flags must be resolved (rewrite criterion, add `requires`, configure a worker) before PROCEED.

360	def _handle_outcome(
361	    outcome: DriverOutcome,
362	    *,
363	    spec: ChainSpec,
364	    writer,
365	) -> str:
366	    """Decide the next action given a DriverOutcome.
367	
368	    Returns one of: "advance" (move to next milestone), "stop" (chain halts),
369	    "retry" (re-run the same milestone), "skip" (advance without waiting).
370	    """
371	    status = outcome.status
372	    if status == "done":
373	        return "advance"
374	    if status == "aborted":
375	        # auto.drive returns aborted both for user aborts and on-escalate=abort.
376	        # Treat according to on_escalate policy so the chain can skip if asked.
377	        writer(f"[chain] plan {outcome.plan} ended aborted\n")
378	        policy = spec.on_escalate
379	    elif status == "escalated":
380	        writer(f"[chain] plan {outcome.plan} escalated — applying on_escalate policy\n")
381	        policy = spec.on_escalate
382	    else:
383	        # failed, stalled, cap → treat as failure
384	        writer(f"[chain] plan {outcome.plan} ended {status}: {outcome.reason}\n")
385	        policy = spec.on_failure
386	    if policy == "stop_chain":
387	        return "stop"
388	    if policy == "skip_milestone":
389	        return "skip"
390	    if policy == "retry_milestone":
391	        return "retry"
392	    return "stop"

395	def run_chain(
396	    spec_path: Path,
397	    root: Path,
398	    *,
399	    writer=sys.stdout.write,
400	) -> dict[str, Any]:
401	    """Drive the full chain. Returns a structured JSON-serializable result."""
402	    spec = load_spec(spec_path)
403	    validate_paths(spec, root)
404	    state = load_chain_state(spec_path)
405	
406	    events: list[dict[str, Any]] = []
407	
408	    def log(msg: str, **fields: Any) -> None:
409	        events.append({"msg": msg, **fields})
410	        writer(f"[chain] {msg}\n")
411	
412	    # ---- Seed phase ----
413	    if spec.seed_plan and state.current_milestone_index < 0:
414	        seed_state = _plan_state(root, spec.seed_plan, timeout=spec.status_timeout)
415	        log(f"seed plan {spec.seed_plan} state={seed_state}")
416	        if seed_state not in TERMINAL_SKIP_STATES:
417	            state.current_plan_name = spec.seed_plan
418	            save_chain_state(spec_path, state)
419	            outcome = _drive_plan(root, spec.seed_plan, spec, writer=writer)
420	            state.last_state = outcome.status
421	            save_chain_state(spec_path, state)
422	            decision = _handle_outcome(outcome, spec=spec, writer=writer)
423	            if decision == "stop":
424	                return _result("stopped", state, events, reason=f"seed plan {outcome.status}")
425	            if decision == "retry":
426	                # Recursive retry kept simple: re-drive seed once.
427	                outcome = _drive_plan(root, spec.seed_plan, spec, writer=writer)
428	                state.last_state = outcome.status
429	                save_chain_state(spec_path, state)
430	                if outcome.status != "done":
431	                    return _result("stopped", state, events, reason="seed retry failed")
432	            # skip / advance both proceed to milestones
433	        state.completed.append(
434	            {"label": "seed", "plan": spec.seed_plan, "status": state.last_state or seed_state}
435	        )
436	        state.current_milestone_index = 0
437	        state.current_plan_name = None
438	        save_chain_state(spec_path, state)
439	
440	    elif state.current_milestone_index < 0:
441	        state.current_milestone_index = 0
442	        save_chain_state(spec_path, state)
443	
444	    # ---- Milestones ----
445	    idx = max(state.current_milestone_index, 0)
446	    while idx < len(spec.milestones):
447	        milestone = spec.milestones[idx]
448	        log(f"milestone {milestone.label} starting")
449	
450	        # Resume mid-milestone if we already have a plan name recorded.
451	        if (
452	            state.current_plan_name
453	            and state.current_milestone_index == idx
454	            and _plan_state(root, state.current_plan_name, timeout=spec.status_timeout)
455	            not in ("missing",)
456	        ):
457	            plan_name = state.current_plan_name
458	            log(f"resuming existing plan {plan_name} for {milestone.label}")
459	        else:
460	            _refresh_main(root, writer=writer)
461	            plan_name = _init_plan(
462	                root,
463	                milestone.idea,
464	                robustness=spec.robustness,
465	                auto_approve=spec.auto_approve,
466	                writer=writer,
467	            )
468	            state.current_milestone_index = idx
469	            state.current_plan_name = plan_name
470	            save_chain_state(spec_path, state)
471	
472	        outcome = _drive_plan(root, plan_name, spec, writer=writer)
473	        state.last_state = outcome.status
474	        save_chain_state(spec_path, state)
475	        decision = _handle_outcome(outcome, spec=spec, writer=writer)
476	
477	        if decision == "stop":
478	            return _result(
479	                "stopped",
480	                state,
481	                events,
482	                reason=f"milestone {milestone.label} ended {outcome.status}",
483	            )
484	        if decision == "retry":
485	            log(f"retrying milestone {milestone.label}")
486	            state.current_plan_name = None  # force re-init next loop
487	            save_chain_state(spec_path, state)
488	            continue
489	        # advance or skip
490	        state.completed.append(
491	            {"label": milestone.label, "plan": plan_name, "status": outcome.status}
492	        )
493	        idx += 1
494	        state.current_milestone_index = idx
495	        state.current_plan_name = None
496	        save_chain_state(spec_path, state)
497	
498	    log("all milestones complete")
499	    return _result("done", state, events)

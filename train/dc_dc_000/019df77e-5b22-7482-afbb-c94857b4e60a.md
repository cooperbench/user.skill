## Overview
Add a per-project content-addressable store under `<project>/.cas/<sha256>` and wire task produces checks so accepted file artifacts are interned once, then replaced at their declared produces path with a relative symlink to the CAS object. The runtime insertion point is `artagents/core/task/gate.py` around `_run_inline_checks()` after `entry.check.run(artifact_path)` succeeds and before `make_produces_check_passed_event(...)` is appended. Project-attached hype artifact mirroring in `artagents/core/project/run.py` should continue to write normal files into the step `produces/` directory; the gate should be responsible for interning after checks pass.

The design stays per-project only: CAS root is derived from `decision.project_root / ".cas"`, never from repo root, user home, global cache, or a shared service.

## Main Phase

### Step 1: Add the CAS helper module (`artagents/core/task/cas.py`)
**Scope:** Small
1. Implement `cas_path(project_dir, sha256) -> Path` as `Path(project_dir) / ".cas" / sha256`, validating only enough to keep the helper direct and predictable.
2. Implement `intern(project_dir, source_path) -> Path` using stdlib `hashlib.sha256()` streaming reads.
3. In `intern`, create `<project>/.cas/`, move the source into `.cas/<hash>` when absent, and when present delete the duplicate source file. Keep it idempotent for the case where `source_path` already resolves to the target CAS entry.
4. Implement `link_into_produces(cas_path, target_path)` by unlinking the target path and creating a relative symlink from the target’s parent to the CAS entry. Ensure parent directories exist.
5. Avoid new dependencies and avoid any shared cache abstraction.

**Scope:** Small

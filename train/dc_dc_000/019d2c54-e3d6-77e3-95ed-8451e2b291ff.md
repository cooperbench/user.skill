        Idea:
Add tuneable parameters to custom effects. Each effect defines a schema of user-adjustable settings (e.g. direction, spin count, color, speed) that the LLM generates alongside the effect code. These params render as controls (sliders, selects, color pickers, toggles) in both the effect creator preview and the clip properties panel. The effect component receives params at render time via an extended EffectComponentProps. Key pieces: (1) Define a ParameterSchema type (array of {name, type: 'number'|'select'|'boolean'|'color', label, default, min/max/options}). (2) LLM generates both code and parameterSchema in its response. (3) The schema is stored in the effect's resource metadata. (4) A generic ParameterControls component renders controls from any schema. (5) EffectComponentProps gets a params: Record<string,unknown> field. (6) Current param values are stored per-clip in ClipMeta (e.g. entrance.params, exit.params, continuous.params). (7) The creator preview and clip properties both render controls and pass values through.

        Idea:
Add tuneable parameters to custom effects. Each effect defines a schema of user-adjustable settings (e.g. direction, spin count, color, speed) that the LLM generates alongside the effect code. These params render as controls (sliders, selects, color pickers, toggles) in both the effect creator preview and the clip properties panel. The effect component receives params at render time via an extended EffectComponentProps. Key pieces: (1) Define a ParameterSchema type (array of {name, type: 'number'|'select'|'boolean'|'color', label, default, min/max/options}). (2) LLM generates both code and parameterSchema in its response. (3) The schema is stored in the effect's resource metadata. (4) A generic ParameterControls component renders controls from any schema. (5) EffectComponentProps gets a params: Record<string,unknown> field. (6) Current param values are stored per-clip in ClipMeta (e.g. entrance.params, exit.params, continuous.params). (7) The creator preview and clip properties both render controls and pass values through.

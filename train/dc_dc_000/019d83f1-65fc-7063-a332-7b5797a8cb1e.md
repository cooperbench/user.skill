        # Implementation Plan: Add FLUX.2 Klein 4B/9B Image Edit Models

## Overview

Add two new fal.ai image-to-image edit models — FLUX.2 Klein 4B (`fal-ai/flux-2/klein/4b/edit`) and FLUX.2 Klein 9B (`fal-ai/flux-2/klein/9b/edit`) — as cloud-only models with **no LoRA support**. These models need to appear in:
1. The **Media Lightbox** model dropdown (for text/inpaint/annotate/reposition edit modes)
2. The **Image Edit Mode** panel (same dropdown)
3. The **Image Edit tool** (`/tools/edit-images`)
4. The **API Orchestrator** backend (task handling)

The existing `z_image_turbo_i2i` handler in `reigh-worker-orchestrator/api_orchestrator/handlers/fal.py:172-273` is the closest pattern — it calls fal.ai with image URL, prompt, strength, and auto-scales image dimensions. The Klein models follow the same image-to-image pattern but without LoRA support.

**Key architectural decision:** The current model selector uses `QwenEditModel` type for the non-img2img edit modes (text/inpaint/annotate/reposition). The Klein models are image-to-image edit models that fit this same dropdown. We should **expand the existing model type** to include Klein models, then conditionally hide the LoRA UI when a Klein model is selected and route to the correct backend handler based on model selection.

- `reigh-worker-orchestrator/` — backend API orchestrator

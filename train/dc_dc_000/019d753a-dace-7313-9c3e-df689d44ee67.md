        # Implementation Plan: First-Run Model Storage Location Selector

## Overview

When `wgp_config.json` doesn't exist (first run), present an interactive terminal UI letting the user pick which drive/volume to store model checkpoints on. The selector shows mounted drives with free space, supports arrow-key navigation, and writes the chosen path into `checkpoints_paths` in the new config. On single-drive systems, skip the selector entirely and use the default.

**Current state:** Config creation happens at `Wan2GP/wgp.py:2359-2398` — when no config file exists, a default dict (with `checkpoints_paths: ["ckpts", "."]`) is written. The existing terminal UI approach uses raw ANSI escape codes (see `source/runtime/worker/status_display.py`), not curses or rich.

**Constraint:** No new dependencies. Use stdlib only (`os`, `sys`, `shutil`, `subprocess`, `tty`, `termios` / `msvcrt`) for both drive detection and the interactive UI. This keeps consistency with the existing ANSI-based display approach.

## Phase 1: Core — Drive Detection and Terminal Selector

### Step 1: Create cross-platform drive/volume detection module (`Wan2GP/shared/utils/drive_detector.py`)
**Scope:** Medium
1. **Create** `Wan2GP/shared/utils/drive_detector.py` with a `detect_drives()` function returning a list of `DriveInfo` named tuples: `(mount_point, label, total_bytes, free_bytes)`.
2. **macOS:** Parse output of `diskutil list` / use `os.statvfs()` on mount points from `/Volumes/` plus `/`.
3. **Linux:** Read `/proc/mounts` or `os.statvfs()` on common mount points (`/`, `/home`, `/mnt/*`, `/media/*/*`). Filter out virtual filesystems (proc, sysfs, tmpfs, devtmpfs, etc.).
4. **Windows:** Use `ctypes` + `kernel32.GetLogicalDriveStringsW` and `kernel32.GetDiskFreeSpaceExW` to enumerate drive letters and their free space.
5. **Add** a `is_single_drive()` helper that returns `True` when only one real drive is detected.
6. **Add** a `suggest_checkpoint_path(mount_point)` helper that returns `os.path.join(mount_point, "WanGP", "checkpoints")` (or just `"ckpts"` for the CWD drive).

### Step 2: Create arrow-key navigable terminal selector (`Wan2GP/shared/utils/storage_selector.py`)
**Scope:** Medium
1. **Create** `Wan2GP/shared/utils/storage_selector.py` with a `select_storage_drive(drives: list[DriveInfo]) -> str` function.
2. **Render** a compact display: each drive on one line showing mount point, label, and free space (human-readable GB/TB). Highlight the currently selected row with `>` prefix and ANSI bold/color.
3. **Input handling:**
   - Unix: use `tty.setraw()` + `sys.stdin.read(1)` to capture arrow keys (escape sequences `\x1b[A` / `\x1b[B`) and Enter.
   - Windows: use `msvcrt.getwch()` to capture arrow keys (`\xe0H` / `\xe0P`) and Enter.
4. **Return** the selected mount point string. On Ctrl+C or `q`, return `None` (caller uses default).
5. **Format** free space as `X.Y GB` or `X.Y TB` for readability.
6. **Handle** non-interactive terminals (e.g. piped stdin): detect via `sys.stdin.isatty()`, return `None` to fall back to default.

### Step 3: Integrate into first-run config creation (`Wan2GP/wgp.py:2359`)
**Scope:** Small
1. **Before** the `if not Path(config_load_filename).is_file():` block at `wgp.py:2359`, add logic:
   - Import `drive_detector` and `storage_selector`.
   - Call `detect_drives()`.
   - If `is_single_drive()` or not `sys.stdin.isatty()`: skip selector, use default `["ckpts", "."]`.
   - Otherwise: call `select_storage_drive(drives)`.
   - If a drive was selected: compute the checkpoint path via `suggest_checkpoint_path()`, create the directory with `os.makedirs(..., exist_ok=True)`.
   - Set a local variable `selected_checkpoints_paths` to either `[selected_path, "."]` or the default.
2. **Replace** `"checkpoints_paths": fl.default_checkpoints_paths` in the default config dict (line 2382) with `"checkpoints_paths": selected_checkpoints_paths`.
3. **Ensure** the selector only runs during first-run (config file doesn't exist). Existing configs are never touched.

## Phase 2: Testing and Edge Cases

**Scope:** Medium

2. **Test `select_storage_drive()`:** Verify non-interactive fallback (`isatty() == False` → returns `None`). Verify `suggest_checkpoint_path()` produces expected paths.
3. **Test integration:** Verify that when config doesn't exist and single drive is detected, config is written with default paths (no UI shown). Verify that when config already exists, the selector is never invoked.

### Step 5: Manual smoke test on macOS
**Scope:** Small

2. **Run** the worker or `wgp.py` and verify the drive selector appears.

4. **Re-run** and verify the selector does NOT appear on subsequent launches.

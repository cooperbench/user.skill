### 1. `[PanesBoot]` render loop in `src/shared/state/panesStore.ts`

**Symptom:** Runtime console shows `[PanesBoot] PanesStoreBootstrapBoundary render` → `useBootstrapPanesStore render` → `effect fires (bootstrapInput changed identity)` → `bootstrap APPLY set()` → repeat. Endless loop visible in `localhost-1777161431011.log` at the project root.

**Cause:** `useBootstrapPanesStore` has a `useEffect` keyed on `bootstrapInput`. The `bootstrapInput` reference changes identity on every render (likely an inline object literal or a useMemo with unstable deps), so the effect fires constantly, triggering `bootstrapPanesStore(...)` → `set()` → re-render → new identity → repeat.

**Fix:** Stabilize the `bootstrapInput` reference. Either memoize it correctly with primitive deps, or compare by value inside the effect before calling `set()`. ### 3. `AgentChatContext` bridge default = noop violates CLAUDE.md

**Symptom:** `useAgentChatBridge()` returns a default value with `replaceSelectedTimelineClips: noopReplace` when no `VideoEditorProvider` is mounted. This silently swallows attachment-removal attempts when AgentChatPanel renders on routes where the video editor isn't mounted. CLAUDE.md explicitly forbids this pattern: "Required-provider hooks must throw when their context is missing. Do not hide missing providers behind default objects with no-op setters."

**Fix:** This is nuanced because the bridge has a real use case: AgentChatPanel renders globally on all tool routes (`/tools`, `/shots`, `/art`), but `VideoEditorProvider` only mounts on `/tools/video-editor`. So the bridge legitimately HAS no real value on other routes.

Two acceptable resolutions — pick whichever is least intrusive:
- (a) Split `useAgentChatBridge` into two: `useAgentChatBridgeRequired` (throws) and `useAgentChatBridgeOptional` (returns null). Update AgentChatPanel callsites to use the optional variant and gate behavior on whether the bridge is available (e.g., disable attachment X clicks when bridge is null).
- (b) Replace the noop with a real failure mode: e.g., warn in dev when removal is called but no provider is registered, AND still update local UI state so the chip disappears (managing attachment state inside AgentChatPanel as a fallback when no bridge override is registered).

Choose the resolution that requires the fewest callsite changes while satisfying CLAUDE.md's spirit (no silent failures).

### 4. `panesStore` subscription consolidation in TasksPane

**Symptom:** TasksPane currently does ~10 individual `usePanesStore((state) => state.X)` calls. Each one is a separate subscription that triggers an independent re-render. Render budget shows TasksPane at 6/5 (over budget) in the log.

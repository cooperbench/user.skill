So does this mean that like when someone's creating an orchestra they can add an optional task that doesn't have to be completed for it to be done?

> AGENT

Yes, exactly. When authoring a plan, set `optional: true` on any step (leaf or group), and the run can complete without that step ever being `step_completed`/`step_attested` — an operator (or an inbox decision) just emits `step_skipped` and the cursor moves past it. Two caveats baked in: (1) you can't combine `optional: true` with `requires_ack: true` (the validator rejects it at plan load), and (2) skipping isn't silent — every skip lands in `events.jsonl` with actor + optional reason, and `astrid run show` tallies a `skipped_steps` count so it's auditable.

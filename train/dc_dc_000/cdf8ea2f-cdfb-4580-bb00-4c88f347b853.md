# ArtAgents

A file-based toolkit for agents to make art and creative work alongside a human.

Three kinds of beings live here:

- **Executors** — run one concrete unit of work
- **Orchestrators** — coordinate executors (and other orchestrators) into workflows
- **Elements** — reusable render building blocks (effects, animations, transitions)

`python3 -m artagents` is the executable package gateway. Every summons passes through this one gate.

## First commands

Run from the repository root:

```bash
git status --short
python3 -m artagents --help
python3 -m artagents doctor
python3 -m artagents orchestrators list
python3 -m artagents executors list
python3 -m artagents elements list
python3 -m artagents setup
```

`setup` is dry-run by default; pass `--apply` to mutate.

## Using tools

Find an id:

```bash
python3 -m artagents [executors|orchestrators|elements] list
```

Inspect to see inputs, outputs, and intent:

```bash
python3 -m artagents [executors|orchestrators|elements] inspect <id> --json
```

Run it:

```bash
python3 -m artagents [executors|orchestrators] run <id> -- <args>
```

Each tool has its own `STAGE.md` next to its `run.py`. That is the source of truth — read it before invoking. The JSON inspect output points at the folder root and `stage_file`; load only the one relevant `STAGE.md`, not all of them.

## Make something new

Read `docs/creating-tools.md`, then copy the closest template:

- `docs/templates/executor/` — one concrete unit of work
- `docs/templates/orchestrator/` — a workflow that combines executors
- `docs/templates/element/` — a reusable render building block

Public folders have exactly one format: `artagents/orchestrators/<slug>/{orchestrator.yaml,STAGE.md,run.py}` and `artagents/executors/<slug>/{executor.yaml,STAGE.md,run.py}`, with optional local `src/` modules. Top-level `artagents/*.py` files are shared libraries or system commands, not alternate runnable implementations.

Do not chain pipeline internals by hand unless you are debugging one specific stage. If the user gives a topic instead of a brief, use a brief-generation executor coordinated by an orchestrator — don't fake source media just to enter a source-video path. Render requires the `hype.timeline.json` and `hype.assets.json` pair produced by cut; don't skip cut unless both files already exist.

## Defaults

Built-in orchestrators: `builtin.hype`, `builtin.event_talks`, `builtin.thumbnail_maker`, `builtin.understand`.

Built-in executors include `builtin.transcribe`, `builtin.cut`, `builtin.render`, `builtin.validate`, and the rest of the pipeline. External executors include `external.moirae` and `external.vibecomfy.run` (executor only, not an orchestrator).

Element source priority: active theme → `.artagents/elements/overrides` → `.artagents/elements/managed` → `artagents/elements/bundled`.

```bash
python3 -m artagents elements sync --dry-run
python3 -m artagents elements fork effects text-card
```

## Rules

- Generated files live under `runs/` (or another ignored output directory) and stay out of git. Don't commit source media, rendered videos, local dependency envs, or secrets.
- Don't print or hardcode API keys; use `--env-file` or nearby `.env` files.
- Treat curated tool stages as protected unless explicitly asked to edit them — notably `artagents/executors/moirae/STAGE.md` and `artagents/executors/vibecomfy/STAGE.md`.
- Orchestrators may call declared child orchestrators; executors must not call orchestrators.

After adding or renaming effects, animations, transitions, or theme elements:

```bash
python3 scripts/gen_effect_registry.py
cd remotion && npm run gen-types
```

## Validate

```bash
pytest tests/test_doctor_setup.py tests/test_canonical_cli.py
pytest --tb=no -q --no-header
```

## Upstream friction

When a workflow is awkward, brittle, or undocumented, tell the user directly. Suggest the smallest durable fix; if the issue belongs upstream, recommend a PR there.

397	def _format_seconds(seconds: float | int | None) -> str:
398	    if seconds is None:
399	        return ""
400	    whole = int(float(seconds))
401	    minutes, sec = divmod(whole, 60)
402	    hours, minutes = divmod(minutes, 60)
403	    if hours:
404	        return f"{hours:02d}:{minutes:02d}:{sec:02d}"
405	    return f"{minutes:02d}:{sec:02d}"

409	    out_path.parent.mkdir(parents=True, exist_ok=True)
410	    try:
411	        from PIL import Image, ImageDraw, ImageFont
412	    except ImportError:
413	        out_path.write_bytes(MINIMAL_JPEG)
414	        return out_path
415	    cols = max(1, min(4, len(candidates) or 1))
416	    rows = max(1, math.ceil((len(candidates) or 1) / cols))
417	    tile_width = 420
418	    tile_height = 236

420	    draw = ImageDraw.Draw(sheet)

426	        small = ImageFont.load_default()

428	    for index, candidate in enumerate(items, start=1):
429	        col = (index - 1) % cols
430	        row = (index - 1) // cols

432	        y = row * tile_height

437	        draw.text((x + 14, y + 64), label[:52], fill=(230, 230, 230), font=small)

568	def _parse_selected_indices(raw_text: str) -> tuple[list[int], str]:
569	    text = raw_text.strip()
570	    if not text:
571	        return [], "empty"
572	    try:
573	        payload = json.loads(text)
574	    except json.JSONDecodeError:
575	        match = re.search(r"\{.*\}", text, flags=re.DOTALL)
576	        if not match:
577	            numbers = [int(value) for value in re.findall(r"\b(?:frame|candidate)?\s*#?(\d{1,2})\b", text, flags=re.I)]
578	            return numbers, "regex" if numbers else "unparseable"
579	        try:
580	            payload = json.loads(match.group(0))
581	        except json.JSONDecodeError:
582	            return [], "unparseable"
583	    if isinstance(payload, dict):
584	        values = payload.get("selected_indices") or payload.get("selected") or payload.get("frames") or []
585	        if isinstance(values, list):
586	            indices: list[int] = []
587	            for value in values:
588	                if isinstance(value, int):
589	                    indices.append(value)
590	                elif isinstance(value, dict) and isinstance(value.get("index"), int):
591	                    indices.append(value["index"])
592	                elif isinstance(value, str) and value.strip().isdigit():
593	                    indices.append(int(value.strip()))
594	            return indices, "json"
595	    if isinstance(payload, list):
596	        return [int(value) for value in payload if isinstance(value, int)], "json"
597	    return [], "unparseable"

618	def normalize_query_selection(
619	    raw_result: dict[str, Any] | None,
620	    candidates: list[dict[str, Any]],
621	    *,
622	    count: int,
623	    dry_run: bool,
624	) -> dict[str, Any]:
625	    if dry_run:
626	        selection = _fallback_selection(candidates, count=count, reason="dry_run")
627	        selection["mode"] = "dry_run"
628	        return selection
629	    if raw_result is None:
630	        return _fallback_selection(candidates, count=count, reason="missing_model_result")
631	    answer = str(raw_result.get("answer") or "")
632	    indices, parse_mode = _parse_selected_indices(answer)
633	    by_index = {int(candidate["index"]): candidate for candidate in candidates}
634	    selected_candidates = []
635	    seen: set[int] = set()
636	    for index in indices:
637	        if index in seen or index not in by_index:
638	            continue
639	        seen.add(index)
640	        selected_candidates.append(by_index[index])
641	        if len(selected_candidates) >= count:
642	            break
643	    if not selected_candidates:
644	        selection = _fallback_selection(candidates, count=count, reason=f"model_output_{parse_mode}")
645	        selection["raw_result"] = raw_result
646	        return selection
647	    return {
648	        "mode": "visual_model",
649	        "fallback": False,
650	        "parse_mode": parse_mode,
651	        "raw_result": raw_result,
652	        "selected": [
653	            {
654	                "candidate_id": candidate["candidate_id"],
655	                "index": candidate["index"],
656	                "reason": "Selected by query-relevance visual pass.",
657	            }
658	            for candidate in selected_candidates
659	        ],
660	    }

803	def _materialize_crop(source_path: str | None, dest_path: Path, box: dict[str, float]) -> str | None:
804	    if not source_path:
805	        return None
806	    source = Path(source_path)
807	    if not source.is_file():
808	        return None
809	    try:
810	        from PIL import Image
811	    except ImportError:
812	        return None
813	    with Image.open(source) as opened:
814	        image = opened.convert("RGB")
815	        left = int(round(float(box["x"]) * image.width))
816	        top = int(round(float(box["y"]) * image.height))
817	        right = int(round((float(box["x"]) + float(box["width"])) * image.width))
818	        bottom = int(round((float(box["y"]) + float(box["height"])) * image.height))
819	        dest_path.parent.mkdir(parents=True, exist_ok=True)
820	        image.crop((left, top, right, bottom)).save(dest_path, quality=92)
821	    return str(dest_path)

824	def build_reference_pack(
825	    args: argparse.Namespace,
826	    layout: dict[str, Path],
827	    plan: dict[str, Any],
828	) -> dict[str, Any]:
829	    candidates_payload = load_json_file(layout["evidence"] / "candidates.json")
830	    selection_payload = load_json_file(layout["evidence"] / "query-selection.json")
831	    candidates = candidates_payload.get("candidates") or []
832	    by_id = {candidate.get("candidate_id"): candidate for candidate in candidates}
833	    by_index = {candidate.get("index"): candidate for candidate in candidates}
834	    selected_records = selection_payload.get("selection", {}).get("selected") or []
835	    include_crops = _needs_composition_crops(plan, args)
836	
837	    references: list[dict[str, Any]] = []
838	    for selected in selected_records:
839	        candidate = by_id.get(selected.get("candidate_id")) or by_index.get(selected.get("index"))
840	        if not isinstance(candidate, dict):
841	            continue
842	        candidate_id = str(candidate["candidate_id"])
843	        frame_path = candidate.get("frame_path")
844	        copied_frame = _copy_reference_frame(
845	            frame_path,
846	            layout["references"] / f"{candidate_id}_full_frame.jpg",
847	        )
848	        crops: list[dict[str, Any]] = []
849	        if include_crops:
850	            for crop in _crop_variants():
851	                crop_payload = dict(crop)
852	                crop_path = _materialize_crop(
853	                    frame_path,
854	                    layout["references"] / f"{candidate_id}_{crop['variant_id']}.jpg",
855	                    crop["box_normalized"],
856	                )
857	                crop_payload["path"] = crop_path
858	                crop_payload["materialized"] = crop_path is not None
859	                crops.append(crop_payload)
860	        references.append(
861	            {
862	                "candidate_id": candidate_id,
863	                "selection_index": selected.get("index"),
864	                "selection_reason": selected.get("reason"),
865	                "source": candidate.get("source"),
866	                "scene_index": candidate.get("scene_index"),
867	                "timestamp_sec": candidate.get("timestamp_sec"),
868	                "full_frame": {
869	                    "source_path": frame_path,
870	                    "path": copied_frame,
871	                    "materialized": copied_frame is not None,
872	                },
873	                "composition_crops": crops,
874	            }
875	        )
876	
877	    payload = {
878	        "version": 1,
879	        "query": args.query,
880	        "video": plan["video"],
881	        "selection_ref": str(layout["evidence"] / "query-selection.json"),
882	        "candidates_ref": str(layout["evidence"] / "candidates.json"),
883	        "reference_mode": args.reference_mode,
884	        "composition_crop_policy": {
885	            "enabled": include_crops,
886	            "kind": "composition_crop",
887	            "note": "Fixed broad framing aids only; no face, person, or speaker detection is claimed.",
888	        },
889	        "references": references,
890	    }
891	    write_json(layout["evidence"] / "reference-pack.json", payload)
892	    return payload

86	        registry = executor_registry or self._executor_registry or load_default_executor_registry()
87	        known_executor_ids = set(registry.as_mapping())
88	        for orchestrator in self._orchestrators.values():
89	            for child_executor in orchestrator.child_executors:

95	    def _validate_child_orchestrators(self) -> None:
96	        known_orchestrator_ids = set(self._orchestrators)
97	        graph: dict[str, tuple[str, ...]] = {}
98	        for orchestrator in self._orchestrators.values():
99	            children: list[str] = []
100	            for child_orchestrator in orchestrator.child_orchestrators:
101	                if child_orchestrator not in known_orchestrator_ids:
102	                    raise OrchestratorRegistryError(
103	                        f"orchestrator {orchestrator.id!r} references unknown child orchestrator {child_orchestrator!r}"
104	                    )
105	                if child_orchestrator == orchestrator.id:
106	                    raise OrchestratorRegistryError(f"orchestrator {orchestrator.id!r} cannot reference itself")
107	                children.append(child_orchestrator)
108	            graph[orchestrator.id] = tuple(children)
109	        self._validate_no_cycles(graph)
110	
111	    def _validate_no_cycles(self, graph: dict[str, tuple[str, ...]]) -> None:
112	        visiting: set[str] = set()
113	        visited: set[str] = set()
114	        stack: list[str] = []
115	
116	        def visit(orchestrator_id: str) -> None:
117	            if orchestrator_id in visited:
118	                return
119	            if orchestrator_id in visiting:
120	                cycle = stack[stack.index(orchestrator_id) :] + [orchestrator_id]
121	                raise OrchestratorRegistryError(f"orchestrator cycle detected: {' -> '.join(cycle)}")
122	            visiting.add(orchestrator_id)
123	            stack.append(orchestrator_id)
124	            for child in graph.get(orchestrator_id, ()):
125	                visit(child)
126	            stack.pop()
127	            visiting.remove(orchestrator_id)
128	            visited.add(orchestrator_id)
129	
130	        for orchestrator_id in sorted(graph):
131	            visit(orchestrator_id)

How it runs:
- `--ideas "..."` → Kimi K2.5 on Fireworks (`accounts/fireworks/models/kimi-k2p5`, OpenAI-compatible chat at `api.fireworks.ai/inference/v1/chat/completions`, `response_format: json_object`) drafts `--count` (default 9) varied prompts, each with name/rationale/prompt.
- Each prompt → fal queue (`https://queue.fal.run/{model_id}`, `Authorization: Key $FAL_KEY`), poll `status_url`, fetch `response_url`, download `images[0].url`.
  - `--provider z-image` → `fal-ai/z-image/turbo` (default, 1 image per call).
  - `--provider gpt-image` → `openai/gpt-image-2`.
- Pillow assembles a `grid.jpg` contact sheet of all renders (skipped here because Pillow isn't installed in the active Python; renders themselves don't need it).

Real run example:
```
python3 -m artagents orchestrators run builtin.logo_ideas --out runs/coffee \
  -- --ideas "modernist coffee roaster, warm earth tones, sans serif" \
     --out runs/coffee --count 9

One thing to flag: the `python3 -m artagents orchestrators run` shim requires a top-level `--out` *and* the orchestrator's own `--out` after `--`; that's a quirk of the gateway, not this orchestrator.

# ArtAgents

A file-based toolkit for agents to make art and creative work alongside a human.

Three kinds of beings live here:

- **Executors** — run one concrete unit of work
- **Orchestrators** — coordinate executors (and other orchestrators) into workflows

        # Implementation Plan: Video-Editor Soft-Tag Rollback Finish

## Overview
This is a narrow finish-the-job refactor inside `src/tools/video-editor`, not a redesign. The repository already moved the core model to soft-tag `PinnedShotGroup.clipIds`, but the remaining drift comes from three residual patterns still visible in the codebase: `rows -> config` commits still round clip timing too coarsely in [`timeline-data.ts`](src/tools/video-editor/lib/timeline-data.ts); several production/test callsites still build or expect legacy `start`/`children` projection shape through the compatibility layer in [`pinned-group-projection.ts`](src/tools/video-editor/lib/pinned-group-projection.ts); and the resize handles in [`TimelineCanvas.tsx`](src/tools/video-editor/components/TimelineEditor/TimelineCanvas.tsx) wire only `pointerup`/`pointercancel` teardown, leaving no recovery path when the browser silently drops capture mid-resize.

The simplest fix is to keep the existing editor state flow and finish the rollback at the remaining boundaries: make row materialization numerically stable, add a lost-pointer-capture fallback to the unified resize session, rewrite the last legacy callers to operate on `clipIds` plus live row actions, then physically delete the shims and legacy fields.

        # Implementation Plan: Carry Forward Subjective Review Marker on Force-Rescan

## Overview

When `--force-rescan` runs during plan mode, `scan_count` increments (merge_history.py:18) and `postflight_scan_completed_at_scan_count` gets set to the new count (plan_reconcile.py:225). But `subjective_review_completed_at_scan_count` still points to the *old* scan count. This makes `_subjective_review_current_for_cycle` (workflow.py:275) return `False`, causing all subjective reviews to be re-queued via synthetic.py:308–316 even though they were already completed for this plan stage.

**Invariant to enforce:** During plan mode, subjective reviews should happen only once per plan stage, regardless of force-rescan.

**Root cause location:** `_reset_cycle_for_force_rescan` (plan_reconcile.py:53–80) clears synthetic items but never carries forward the subjective review marker. Then `_sync_postflight_scan_completion_and_log` (plan_reconcile.py:243) stamps the *new* scan_count into `postflight_scan_completed_at_scan_count`, creating the mismatch.

**Scope:** Small
1. **Add** a new function `carry_forward_subjective_review(plan, *, scan_count)` in `refresh_lifecycle.py` after `mark_subjective_review_completed` (~line 206).
   - Check if `subjective_review_completed_at_scan_count` is already set (to any value). If it is, update it to the new `scan_count`. If it isn't set, do nothing (reviews were never completed — nothing to carry forward).
   - Return `True` if the marker was updated.
   ```python
   def carry_forward_subjective_review(
       plan: PlanModel,
       *,
       scan_count: int | None,
   ) -> bool:
       """Bump the subjective-review marker to *scan_count* if already set.

       Used by force-rescan to preserve review completion across scan_count bumps.
       """
       refresh_state = plan.get("refresh_state")
       if not isinstance(refresh_state, dict):
           return False
       if _SUBJECTIVE_REVIEW_KEY not in refresh_state:
           return False
       try:
           normalized = int(scan_count or 0)
       except (TypeError, ValueError):
           normalized = 0
       if refresh_state.get(_SUBJECTIVE_REVIEW_KEY) == normalized:
           return False
       refresh_state[_SUBJECTIVE_REVIEW_KEY] = normalized
       return True
   ```

   ```python
       cycle being replaced.  Stale markers from earlier cycles are left
       untouched so they naturally fail the scan_count equality check and
       trigger fresh reviews.
       """
       refresh_state = plan.get("refresh_state")
       if not isinstance(refresh_state, dict):
           return False
       if _SUBJECTIVE_REVIEW_KEY not in refresh_state:
           return False
       try:
           old_postflight = int(old_postflight_scan_count or 0)
       except (TypeError, ValueError):
           old_postflight = 0
       if refresh_state[_SUBJECTIVE_REVIEW_KEY] != old_postflight:
           return False  # stale marker — do not promote
       try:
           normalized_new = int(new_scan_count or 0)
       except (TypeError, ValueError):
           normalized_new = 0
       if refresh_state[_SUBJECTIVE_REVIEW_KEY] == normalized_new:
           return False
       refresh_state[_SUBJECTIVE_REVIEW_KEY] = normalized_new
       return True
   ```

## Overview

Both runtime entry points are cold-per-call today: `run_embedded()` enters/exits a fresh `Comfy()` per generation (`vibecomfy/runtime/run.py:125-138`) whose `__aexit__` runs `unload_all_models()`, and `run()` spawns/terminates `comfyui serve` per call (`vibecomfy/runtime/server.py:27-50`). ComfyUI itself keeps models warm in-process and evicts under pressure — the work here is structural.

We add a `VibeSession` abstraction with two backends — `EmbeddedSession` (one long-lived `Comfy()`) and `ServerSession` (one long-lived `comfyui serve` subprocess) — plus a CLI session pool under `out/sessions/<id>/` (pidfile + URL file) so multiple `vibecomfy run` invocations share one warm pool. Existing `run`/`run_embedded` stay as one-shot wrappers (backwards-compatible).

Per the brief, the long-lived **managed** server is the default for CLI users. The plan changes `vibecomfy run`'s default runtime to `auto` and routes through a discovered session when one exists. The schema provider is taught to share the same URL so we don't accidentally spin up a second cold subprocess for `/object_info`. Default policy: keep-warm with smart memory; explicit `flush()` and a fingerprint-gated auto-flush handle model swaps under VRAM pressure.

Settled decisions carried forward (unchanged):
- `vibecomfy run --runtime auto` is the new default; auto-attaches to a warm session if any.
- Schema provider URL discovery before `get_schema_provider`; same URL into both call sites.
- Daemon folded into `vibecomfy/commands/session.py` (single file).
- Managed-mode warmth verified at the test layer (subprocess spawn count == 1 + `/api/free` payload assertions).
- ServerSession default port 8188 with `--port` override; auto-flush threshold default 2.0 GB.
- Pattern-based loader fingerprint: any `class_type` containing `"Loader"` contributes its non-edge string-valued slots.
- Shared runtime helpers move from `run.py` into `session.py` (one-direction import).
- `tests/test_cli.py:25-40` registry assertion gets `"session"` inserted between `"runtime"` and `"logs"`.
- `SessionConfig` has an `extra: dict[str, Any]` escape hatch; `from_workflow_metadata` partitions known keys into typed fields and unknown into `extra`; merge order: typed → extra → `VIBECOMFY_COMFY_CONFIGURATION` env override.

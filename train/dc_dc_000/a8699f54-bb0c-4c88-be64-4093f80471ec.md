- A Stop hook runs `artagents next`. The Stop hook is configured in `.claude/settings.json` via the user's hooks setting. The hook should be conditional: only fire when the cwd has an `active_run.json` (i.e., agent is in task mode). Otherwise no-op.
- Every `next` response includes the prohibition preamble verbatim, including on repeated calls — context-decay re-injection (SD-023).

EXIT CRITERIA (from design doc):
- Repeated `artagents next` calls include the prohibition preamble verbatim.
- One no-cursor-move golden run: calling `next` repeatedly does NOT advance the run cursor (it's idempotent and informational).
- CLI snapshot tests for the preamble.

WHAT TO IMPLEMENT:

1. Define the prohibition preamble as a constant string in `artagents/core/task/preamble.py` (new file). Content should restate task-mode rules: "You are in task mode for run <run_id>. Do not run code outside the listed steps. Do not edit files outside the run scope. Use `artagents ack <decision>` to advance. Use `artagents abort` to leave task mode."

2. Modify the existing `artagents next` handler (shipped in Phase 5) to ALWAYS prepend the preamble to its output, on every call, even if cursor hasn't moved.

3. Add a Stop-hook helper command `artagents hook stop` that:
   - Detects whether cwd has an `active_run.json`.
   - If yes, prints the result of `artagents next` to stdout (so Claude Code re-injects it).
   - If no, exits 0 silently.

4. Document the hook setup in a new short markdown file: `docs/HOOKS.md` (or update an existing docs index if cleaner). Include the `.claude/settings.json` JSON snippet authors must add. Hook command is `artagents hook stop`.

5. Tests:
   - `tests/test_task_preamble.py`: snapshot test that the preamble constant matches expected text and is non-empty.
   - `tests/test_task_next_preamble.py`: invoking `artagents next` twice without ack returns the preamble in BOTH responses, and the run cursor in `events.jsonl` does NOT advance between calls (idempotent).
   - `tests/test_task_hook_stop.py`: when no `active_run.json` exists, `artagents hook stop` exits 0 with empty stdout. When one exists, it outputs the same content as `artagents next`.

6. Update `docs/AGENT.md` template (created in Phase 5) to mention the Stop hook and link to `docs/HOOKS.md`.

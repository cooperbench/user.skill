Add an example file listing names only/default-safe placeholders.

Arnold’s equivalent is split across CLI bootstrapping in [arnold/cli.py](/Users/user_c042661f/Documents/arnold-v2/arnold/cli.py:154) and `ResidentRunner.start/stop` in [agent_kit/resident.py](/Users/user_c042661f/Documents/arnold-v2/agent_kit/resident.py:169).

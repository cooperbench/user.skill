        # Implementation Plan: Hide / Show Hidden Shots on Video Travel Tool

## Overview
Add a per-shot **Hide** action and a **Show Hidden (N)** toggle to the Video Travel Tool shot list header. Hidden shots are filtered out of `ShotListDisplay` by default; toggling the header pill reveals them (visually distinguished) while keeping the count accurate.

Touch points (from repo audit):
- `reigh-app/src/tools/travel-between-images/pages/ShotListView.tsx` — owns `shots`, `filteredShots`, and renders `VideoTravelListHeader` + `ShotListDisplay`. This is where the hidden-set state and filtering go.
- `reigh-app/src/tools/travel-between-images/components/VideoGallery/VideoTravelListHeader.tsx` — sort props already live here; add a `hidden` prop group with `{ hiddenCount, showHidden, setShowHidden }` rendered next to the sort button.
- `reigh-app/src/tools/travel-between-images/components/VideoGallery/VideoShotDisplayParts.tsx` — `ActionButtonsRow` (`ShotControls`) is the right spot to add a Hide (EyeOff) button between Duplicate and Delete.
- `reigh-app/src/tools/travel-between-images/components/VideoGallery/VideoShotDisplay.tsx` — thread `onHideShot` and `isHidden` props through to `ShotControls` and apply a faded style when `isHidden && showHidden`.
- `reigh-app/src/tools/travel-between-images/components/VideoGallery/SortableShotItem.tsx` + `ShotListDisplay.tsx` — pass the new props through.
- `reigh-app/src/tools/travel-between-images/components/VideoGallery/VideoTravelListHeader.test.tsx` — extend tests for the new toggle.

**Persistence choice (assumption, see questions):** hidden set is stored in `localStorage` keyed by `selectedProjectId` (`reigh-hidden-shots:{projectId}`). This matches the existing client-side `SKIP_DELETE_CONFIRMATION_KEY` pattern in `VideoShotDisplay.tsx` and avoids a schema change. Encapsulate behind a small hook `useHiddenShots(projectId)`.

Search/sort behavior: hide filter is applied **after** search filtering in `ShotListView`, so `hiddenCount` reflects hidden-among-currently-visible-after-search (matches what the user sees). Sort is unaffected.

## Main Phase

### Step 1: Audit call sites and confirm prop flow
**Scope:** Small
1. **Confirm** no DB/schema involvement by scanning Shot model (`reigh-app/src/domains/generation/types/shotViewRow.ts`) — Shot has no hidden field today.
2. **Confirm** `ShotListView.tsx:114` (`filteredShots` memo) is the single list-shaping site before `ShotListDisplay`.

### Step 2: Add hidden-shots state hook (`reigh-app/src/tools/travel-between-images/hooks/useHiddenShots.ts`)
**Scope:** Small
1. **Create** `useHiddenShots(projectId: string | undefined)` returning `{ hiddenIds: Set<string>, isHidden(id), hide(id), unhide(id), toggle(id) }`.
2. **Persist** to `localStorage` under `reigh-hidden-shots:{projectId}`; parse as string array; guard SSR/JSON errors by returning empty set.
3. **Memoize** so prop identity is stable across renders.

### Step 3: Wire state + filter in `ShotListView` (`reigh-app/src/tools/travel-between-images/pages/ShotListView.tsx`)
**Scope:** Small
1. **Call** `useHiddenShots(selectedProjectId)` and add local `const [showHidden, setShowHidden] = useState(false)`.
2. **Compute** `visibleShots` from `filteredShots` (`ShotListView.tsx:114`): when `showHidden` is false, drop shots whose id is in `hiddenIds`; otherwise keep all. `hiddenCount` = `filteredShots.filter(s => hiddenIds.has(s.id)).length`.
3. **Pass** `visibleShots` to `ShotListDisplay` (replaces `filteredShots`), pass `hiddenIds`, `hide`, and `showHidden` down.
4. **Extend** the `VideoTravelListHeader` props with a new `hidden` group.

### Step 4: Add Show Hidden toggle to header (`reigh-app/src/tools/travel-between-images/components/VideoGallery/VideoTravelListHeader.tsx`)
**Scope:** Small
1. **Add** a `HiddenProps` interface `{ hiddenCount: number; showHidden: boolean; setShowHidden: (v: boolean) => void }` and include it in `VideoTravelListHeaderProps` (only rendered when `!showVideosView`).
2. **Render** a `<Button variant={showHidden ? 'default' : 'outline'} size="sm" className="h-8 text-xs">` with `Eye` / `EyeOff` icon next to the existing sort button (`VideoTravelListHeader.tsx:196-223`). Only show when `hiddenCount > 0` OR `showHidden` is true (avoids clutter when nothing is hidden). Label: `Show Hidden ({hiddenCount})`.
3. **Toggle** on click; stop pointer propagation to match sibling patterns.

### Step 5: Add Hide button to shot card (`VideoShotDisplayParts.tsx`, `VideoShotDisplay.tsx`, `SortableShotItem.tsx`, `ShotListDisplay.tsx`)
**Scope:** Medium
1. **Extend** `ShotControlsProps` / `ActionButtonsRow` (`VideoShotDisplayParts.tsx:458`) with `isHidden: boolean` and `onToggleHidden: (e?: React.MouseEvent) => void`.
2. **Insert** a `<Button variant="ghost" size="icon">` with `EyeOff` (or `Eye` when hidden) between the Duplicate and Delete buttons, tooltip "Hide shot" / "Unhide shot", `onClick` stops propagation and calls `onToggleHidden`.
3. **Thread** props: `VideoShotDisplay` accepts `isHidden` + `onToggleHidden`; when `isHidden`, render the card container with `opacity-50` and a small "Hidden" badge in `ShotMetadata` row.
4. **Pass** through `SortableShotItem` (`SortableShotItem.tsx:21-39`) to `VideoShotDisplay`; pass through `ShotListDisplay` (`ShotListDisplay.tsx:23-36,116`) to each `SortableShotItem`.
5. **In `ShotListView`**, supply `isHidden={hiddenIds.has(shot.id)}` and `onToggleHidden={() => hiddenIds.has(shot.id) ? unhide(shot.id) : hide(shot.id)}` via new props on `ShotListDisplay`.

### Step 6: Prove the change (`VideoTravelListHeader.test.tsx`, new `useHiddenShots.test.ts`)
**Scope:** Small
1. **Add** a unit test for `useHiddenShots`: hide → persists to localStorage → unhide removes it → isolated per projectId.
2. **Extend** `VideoTravelListHeader.test.tsx` to assert the Show Hidden button renders with correct count, is hidden when `hiddenCount === 0 && !showHidden`, and calls `setShowHidden` on click.
3. **Run** `npm --prefix reigh-app test -- VideoTravelListHeader useHiddenShots` (targeted) then the broader `npm --prefix reigh-app test` once green.
4. **Manually verify** in dev: hide a shot → disappears, badge shows `Show Hidden (1)` → toggle reveals it with faded style → click Eye on hidden card to unhide → reload preserves hidden set → switching projects clears the hidden list for that project.

3. Tests last (Step 6).

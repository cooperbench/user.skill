        # Implementation Plan: Tuneable Parameters for Custom Effects

## Overview

The video editor's custom effects system currently supports LLM-generated Remotion components with a fixed `EffectComponentProps` interface (`children`, `durationInFrames`, `effectFrames`, `intensity`). Users can create/edit effects via `EffectCreatorPanel`, which calls the `ai-generate-effect` edge function (Groq/Kimi K2), compiles the result with Sucrase, and stores it as a resource with `EffectMetadata`.

This plan adds **user-tuneable parameters** to custom effects. The LLM will generate both component code and a parameter schema. The schema defines controls (sliders, selects, toggles, color pickers) that render in both the creator preview and the clip properties panel. Parameter values are stored per-clip and passed to the effect at render time.

**Key constraint**: The effect compilation pipeline uses `new Function()` with injected globals — no module system. Parameter values must be passed as a prop, not via imports or context.

**Scope**: ~8 files modified, 1 new component, 0 DB migrations (params stored in existing JSONB metadata and existing clip JSON fields).

        # Implementation Plan: Tuneable Parameters for Custom Effects

## Overview

The video editor's custom effects system currently supports LLM-generated Remotion components with a fixed `EffectComponentProps` interface (`children`, `durationInFrames`, `effectFrames`, `intensity`). Users can create/edit effects via `EffectCreatorPanel`, which calls the `ai-generate-effect` edge function (Groq/Kimi K2), compiles the result with Sucrase, and stores it as a resource with `EffectMetadata`.

This plan adds **user-tuneable parameters** to custom effects. The LLM will generate component code, a parameter schema, and a well-written effect description. Each parameter includes a short description of what it does. The schema defines controls (sliders, selects, toggles, color pickers) that render in both the creator preview and the clip properties panel. Parameter values are stored per-clip and passed to the effect at render time.

**Key constraint**: The effect compilation pipeline uses `new Function()` with injected globals — no module system. Parameter values must be passed as a prop, not via imports or context.

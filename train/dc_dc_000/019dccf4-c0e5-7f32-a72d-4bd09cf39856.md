# Implementation Plan: Convert ready_templates to real Python via emitter + driver

## Overview

**Goal.** Replace the 49 JSON-flavored `ready_templates/*.py` files with real Python that calls `wf.node(class_type, **kwargs)` directly — like the already-converted `ready_templates/image/z_image.py`. Stand up a small `tools/` package with one emitter (`format_as_python.py`) and one driver (`convert_ready_templates.py`), validate locally with the existing `tests/test_ready_templates.py` and a new compile-equivalence harness, then live-test the 8 AUTHORED templates on a real RunPod 4090 via `tests/smoke/test_layer2_runpod_ops.py` and `test_layer2_runpod_dropped.py`.

**Repo shape (verified).**
- `ready_templates/` has 50 files: 41 LEGACY (`API_WORKFLOW` dict + `build_api_ready_workflow`), 8 AUTHORED (`NODES` tuple with UUID class types + `build_authored_ready_workflow`), 1 hand-authored real-Python (`image/z_image.py`).
- `vibecomfy/workflow.py:136` exposes the emitter target `wf.node(class_type, **kwargs)` with `.out(slot)` handles.
- `vibecomfy/ingest/normalize.py:25` provides `normalize_to_api` (delegates to HiddenSwitch's `comfy.component_model.workflow_convert.convert_ui_to_api` when importable — that's the path that inlines `definitions.subgraphs`).
- `vibecomfy/registry/ready_template.py:11` (LEGACY) and `:66` (AUTHORED) are the existing build entry points whose output is the roundtrip oracle for the converted modules.
- `tests/test_ready_templates.py` has `_class_type_counter`/`_widget_value_counter`/`_topology_counter` — the same shape we need for `compile_equivalent`. Snapshots live in `tests/snapshots/{name}.{api,class_types,widget_values}.json` (9 templates). They are pre-refactor for the AUTHORED 8 (encode the 2-node UUID-wrapper shape) and must be re-captured.
- `node_index.json` at repo root is currently `[]` — empty. The schema source for `widget_X → real_name` must therefore start from a hardcoded table.
- `tools/` directory does not exist; needs creating.
- Live tests are gated on `--runpod` (cheap) and `--runpod-full` (~$5–10, release-gate).

**Constraints.**
- One emitter, not N converters — variation lives in the input layer; everything funnels through `VibeWorkflow`.
- Conversion is faithful, not corrective — preserve whatever quirks exist in the source. Don't fix templates that were already broken.
- Local loop is the bar: pytest must go green on a Mac before any pod spend.
- AUTHORED-with-subgraph templates must DIVERGE from their pre-refactor snapshots (snapshots are the broken shape).

## Phase 1: Foundation — schema map + emitter, prove on z_image

### Step 1: Create `tools/` package skeleton (`tools/__init__.py`, `tools/_widget_schema.py`)
**Scope:** Small
1. **Create** `tools/__init__.py` (empty marker).
2. **Create** `tools/_widget_schema.py` with a `WIDGET_SCHEMA: dict[str, list[str]]` mapping the ~25 stock-ComfyUI class types to ordered input names so `widget_0..widget_N` resolve to `unet_name`, `text`, `cfg`, etc. Seed it from the classes used in the 9 snapshot templates (`UNETLoader`, `CLIPLoader`, `VAELoader`, `CLIPTextEncode`, `EmptySD3LatentImage`, `EmptyHunyuanLatentVideo`, `ModelSamplingAuraFlow`, `ModelSamplingSD3`, `KSampler`, `KSamplerAdvanced`, `VAEDecode`, `SaveImage`, `SaveVideo`, `LoadImage`, `CreateVideo`, `ImageScaleToTotalPixels`, `LoraLoaderModelOnly`, `PrimitiveStringMultiline`, `TextEncodeQwenImageEdit`, ...). Cross-check each against `vendor/ComfyUI/nodes.py` / `vendor/ComfyUI/comfy_extras/` `INPUT_TYPES` declaration order.
3. **Expose** a single helper `resolve_widget_name(class_type: str, idx: int) -> str` that returns the real input name when known and `f"widget_{idx}"` otherwise.

### Step 2: Build the emitter (`tools/format_as_python.py`)
**Scope:** Medium
1. **Implement** `format_as_python(wf: VibeWorkflow, *, module_doc: str | None = None) -> str` that:
   - Walks `wf.nodes` in deterministic order (numeric node-id ascending; matches existing snapshot ordering).
   - Computes a stable variable-name per node using the heuristic in the brief (role-from-connection → role-from-text-content → numbered fallback).
   - Walks `wf.edges` to build a `(to_node, to_input) → Handle` map so edges become `<src_var>.out(slot)` kwargs.
   - For each node, applies `_widget_schema.resolve_widget_name(class_type, idx)` to translate `widget_X` keys to real names.
   - Emits a complete module: `from __future__ import annotations`, `from vibecomfy.workflow import VibeWorkflow, WorkflowSource`, the original `READY_METADATA` and `READY_REQUIREMENTS` dicts (preserve verbatim — `pprint.pformat` is fine), then a `def build() -> VibeWorkflow` body that constructs `wf = VibeWorkflow(...)` and emits one `wf.node("CLASS", arg=...)` line per source node, ending with `wf.finalize_metadata()` + `return wf`.
2. **Add** a `__main__` so `python -m tools.format_as_python <template_path>` parses the module's existing `API_WORKFLOW`/`NODES` (or for the AUTHORED 8 the source UI JSON), runs it through the parser, and prints the new Python to stdout.
3. **Apply** any per-template `.override.json` patches (rename_inputs / set_inputs / remove_inputs / metadata_overrides) **before** stringifying — schema in the brief at `convert_templates_to_real_python.md:467`.
4. **Keep** the file ≤ ~350 LOC; resist adding speculative features.

### Step 3: Pin down the parser path for both shapes (helpers inside `tools/convert_ready_templates.py`)
**Scope:** Medium
1. **For LEGACY** (`API_WORKFLOW` dict): import the existing module by file path (`importlib.util.spec_from_file_location`), pull `module.API_WORKFLOW`, pass through `vibecomfy.ingest.normalize.convert_to_vibe_format(api_dict, source_path=..., workflow_id=...)`.
2. **For AUTHORED** (`NODES` tuple with UUIDs): load the corresponding `workflow_corpus/official/<category>/<name>.json` (path comes from `READY_METADATA["source_workflow"]`), pass through `vibecomfy.ingest.normalize.normalize_to_api(ui_json)` to inline subgraphs via HiddenSwitch's `convert_ui_to_api`, then `convert_to_vibe_format(...)`. If `comfy.component_model.workflow_convert` is not importable from the local `.venv`, install `comfyui` CPU-only as a one-time prereq (the brief says this is acceptable).
3. **Skip** files whose first non-blank line contains the magic `# vibecomfy: manual` comment (z_image carries this implicitly by virtue of being hand-authored — the converter must not overwrite it).

### Step 4: Local validation harness — `compile_equivalent` + per-template grid (inside `tools/convert_ready_templates.py`)
**Scope:** Small
1. **Reuse** the counters from `tests/test_ready_templates.py` (`_class_type_counter`, `_widget_value_counter`, `_topology_counter`) by lifting them into a `tools._compile_equivalence` module so both the driver and the test can call them. Function signature: `compile_equivalent(api_a: dict, api_b: dict) -> tuple[bool, list[str]]` returning a structured diff when False.
2. **Per-template grid row**: `(template_id, parse: ok|fail, build: ok|fail, validate: ok|fail, roundtrip: ok|fail|skipped, snapshot: ok|fail|missing)` — print as one line per template + a JSON summary at the end. Reason codes match the brief's failure-modes table at `convert_templates_to_real_python.md:498`.

### Step 5: Prove the loop on z_image and one LEGACY (`ready_templates/image/z_image.py`, `ready_templates/video/wan_t2v.py`)
**Scope:** Small
1. **Run** the emitter on z_image's `build()` output (skip writing — z_image is `# vibecomfy: manual`); diff vs the current hand-written file. Cosmetic differences OK; structural differences are emitter bugs.
2. **Run** end-to-end on `wan_t2v` (LEGACY, no UUID): emitter produces a new `wan_t2v.py`; `compile_equivalent(old_build, new_build)` must be True before writing to disk. Once green, overwrite `ready_templates/video/wan_t2v.py`.
3. **Run** `pytest tests/test_ready_templates.py -k "wan_t2v or z_image" -x` — must pass.

## Phase 2: Drive across all 50 + reconcile

### Step 6: Build the driver (`tools/convert_ready_templates.py`)
**Scope:** Medium
1. **Implement** `python -m tools.convert_ready_templates [--all | --template <id> | --category image|video|edit|audio] [--dry-run] [--write]`.
2. **Enumerate** templates via `vibecomfy.registry.ready.ready_template_ids()`.
3. **For each template**: detect shape (LEGACY / AUTHORED / manual-skip), call the parser path, run the emitter, run `compile_equivalent` if applicable, emit a grid row. With `--write`, overwrite the `.py` in place. With `--dry-run`, write to `<path>.converted.py` for review.
4. **Apply overrides**: if `<path>.override.json` exists, patch the IR before emit.
5. **Print** a final summary grid + `Converted N/M (compile + validate + roundtrip pass)`. Failures are structured (layer + diff + hint), per `convert_templates_to_real_python.md:201`.

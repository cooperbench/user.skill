## The Bug Pattern

All 15 sites use the same escape handling:
```python
if ch == in_str and prev_ch != "\\":
    in_str = None
```

**Problem**: This fails on `\\"` because:
- At position `"`: `prev_ch = \` → condition `\ != \` is False → **incorrectly exits string**
- Actually: `\"` escapes the quote, but `\\` escapes the backslash, so quote is NOT escaped

**Correct approach**: Count consecutive backslashes before the quote:
```python
# Count backslashes before this position
backslash_count = 0
i_back = pos - 1
while i_back >= 0 and text[i_back] == '\\':
    backslash_count += 1
    i_back -= 1

# Only exit string if even number of backslashes (they escape each other, quote is unescaped)
if backslash_count % 2 == 0:
    in_str = None
```

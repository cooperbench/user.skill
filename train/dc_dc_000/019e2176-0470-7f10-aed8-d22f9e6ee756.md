1. **Prep doc visibility** Do **not** show the prep doc. It is bot homework, not user-facing material. Showing the raw plan will make the session feel pre-judged and clinical. Add a short editable **session card** before start instead: - “Today Rosi will help you talk through: moving before birth” - 3-5 plain-language focus areas - “Anything to add or avoid?” text box - “This is not medical care / crisis support” footer if relevant No graph, no generated summaries about their relationship, no internal state fields. 2. **Right-side tree pane** The checklist is too sterile for this use case. For a pregnant woman in an emotionally loaded conversation, a visible task tree says: “perform the session correctly.” Bad taste. Default should be **minimal mode**: transcript, soft current focus, controls. Example: “We’re talking about timing right now.” Hide checklist behind “Show structure.” The structure is useful for power users and partner sessions, but it should never dominate the emotional surface. 3. **Missing footer affordances** The footer is underpowered. Do not make these voice-only. In emotionally charged moments, people freeze, whisper, cry, or do not want to interrupt out loud. Buttons are safety rails. 4. **Post-session synthesis** Silent synthesis is wrong. The user must see a **review screen before memory write**.

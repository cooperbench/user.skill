**Findings**

1. **High: poll sync can silently turn a conflict into last-write-wins.**  
   [usePollSync.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/hooks/usePollSync.ts:154) advances `configVersionRef` as soon as a newer polled version is observed, before the polled data is accepted into local state. If the editor has unsaved edits, the payload is rejected/deferred later at [usePollSync.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/hooks/usePollSync.ts:232), but saves use the already-advanced expected version at [useTimelinePersistence.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/hooks/useTimelinePersistence.ts:154). Result: local stale config can overwrite a newer backend/agent/import update without a version conflict.

2. **High: agent uses raw DB config, while UI load repairs/migrates before use.**  
   UI load runs `repairConfig`, `repairShotGroupContiguity`, then `migrateToFlatTracks` in [timeline-data.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/lib/timeline-data.ts:393). Agent `loadTimelineState` only casts/normalizes the row and returns `config` directly at [db.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/supabase/functions/ai-timeline-agent/db.ts:323). That means backend tools can edit legacy, duplicate, or non-contiguous shapes the UI would have canonicalized, then save them via [db.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/supabase/functions/ai-timeline-agent/db.ts:624).

3. **High: duration semantics diverge between UI/render and agent tools.**  
   UI duration is `hold` or `(to ?? 0) - (from ?? 0)` divided by speed via [config-utils.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/lib/config-utils.ts:11). Agent tools fall back to `asset_registry.duration` when `from/to` are absent at [timeline.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/supabase/functions/ai-timeline-agent/tools/timeline.ts:54). The same clip can therefore have `0s` in editor row/render-derived state and nonzero duration in agent `view`, `split`, `duplicate`, `query`, and `find-issues`.

4. **Medium: rendered sequence duration bypasses the shared duration helper.**  
   `ThemeEffectSequence` and generated-module placeholders compute frames as `(hold + to-from) * fps` at [TimelineRenderer.tsx](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/compositions/TimelineRenderer.tsx:91) and [TimelineRenderer.tsx](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/compositions/TimelineRenderer.tsx:110). `useDerivedTimeline`/Remotion metadata uses `getClipDurationInFrames`, which applies speed at [useDerivedTimeline.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/hooks/useDerivedTimeline.ts:68). Speeded theme/generated clips can render with a different duration than composition metadata and timeline rows.

5. **Medium: pinned shot groups are treated as soft metadata in UI, but backend clip CRUD does not maintain them.**  
   The persisted group model requires ordered `clipIds` at [types/index.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/types/index.ts:204), and UI commit paths explicitly require callers to pass group overrides when membership changes at [useTimelineCommit.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/hooks/useTimelineCommit.ts:149). Agent `split`, `delete`, and `duplicate` mutate `clips` only at [timeline.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/supabase/functions/ai-timeline-agent/tools/timeline.ts:198), [timeline.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/supabase/functions/ai-timeline-agent/tools/timeline.ts:372), and [timeline.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/supabase/functions/ai-timeline-agent/tools/timeline.ts:680). This leaves groups referencing deleted clips or excluding split/duplicated children.

6. **Medium: import and editor validate different contracts.**  
   `timeline-import` accepts the shared `@banodoco/timeline-schema` at [handler.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/supabase/functions/timeline-import/handler.ts:68). Editor load/save uses a local closed allowlist at [serialize.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/lib/serialize.ts:119), and `SupabaseDataProvider.loadTimeline` rejects before migration at [SupabaseDataProvider.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/data/SupabaseDataProvider.ts:63). If the shared schema grows before Reigh’s allowlist, imports can write timelines the editor refuses to load.

**Architecture Snapshot**

Persisted state is `TimelineConfig` plus separate `asset_registry`; editor runtime expands that into `TimelineData` with `rows`, `meta`, `clipOrder`, `resolvedConfig`, `signature`, and `stableSignature` at [timeline-data.ts](/Users/user_c042661f/Documents/reigh-workspace/reigh-app/src/tools/video-editor/lib/timeline-data.ts:66). The main architectural weakness is that not all writers go through the same canonicalization and duration/serialization layer. The UI is mostly canonicalized; import and agent paths are closer to raw DB config.

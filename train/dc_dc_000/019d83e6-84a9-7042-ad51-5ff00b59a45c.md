        # Implementation Plan: Lightbox Navigation from Video Editor

## Overview

When double-clicking a media clip in the video editor's timeline, the lightbox opens with **no navigation** — the `MediaLightbox` in `VideoEditorProvider.tsx:255-261` receives no `navigation` prop. The goal is to add left/right chevron navigation with a priority-ordered item list:

1. **Same shot items** (clips in the same pinned shot group)
2. **Same track items** (other clips on the same track)
3. **Other track items** (clips from remaining visual tracks)

Plus a visual indicator showing which items belong to the current shot group.

**Current state:**
- `VideoEditorProvider.tsx:87` stores `lightboxAssetKey` (a single asset key string)
- `onDoubleClickAsset` sets this key, which fetches the generation and opens `MediaLightbox`
- The lightbox receives `media`, `onClose`, and `features` — no `navigation` props
- Shot groups are tracked via `pinnedShotGroups` in timeline config (see `useShotGroups.ts`)
- The existing `LightboxNavigationProps` interface (`types.ts:38-44`) has `onNext`, `onPrevious`, `showNavigation`, `hasNext`, `hasPrevious`

**Key constraint:** The video editor doesn't use the `ShotImageManager/useLightbox` hook — it has its own lightbox mechanism based on asset keys. Navigation must be built within this asset-key model.

## Phase 1: Navigation Hook

### Step 1: Create `useVideoEditorLightboxNavigation` hook (`src/tools/video-editor/hooks/useVideoEditorLightboxNavigation.ts`)
**Scope:** Medium

1. **Create** a new hook that takes:
   - `lightboxAssetKey: string | null` — the currently open asset
   - `resolvedConfig` — for access to clips, tracks, and registry
   - `pinnedShotGroups` — from timeline config
   - `meta: Record<string, ClipMeta>` — clip metadata mapping clips to asset keys and tracks
   - `rows: TimelineRow[]` — to iterate clips in track order

2. **Implement** the navigation list builder:
   - Find the clip that references the current `lightboxAssetKey` via `meta`
   - Determine which shot group (if any) that clip belongs to (via `pinnedShotGroups`)
   - Determine which track that clip is on (via `meta[clipId].track`)
   - Build an ordered list of navigable asset keys:
     - First: other assets in the same shot group (ordered by timeline position)
     - Then: other assets on the same track not already included (ordered by timeline position)
     - Then: assets from other visual tracks not already included (ordered by track index, then timeline position)
   - Filter to only openable assets (`isOpenableAssetType` from `VideoEditorProvider.tsx:29`)
   - Deduplicate by asset key (same asset can appear in multiple clips)

3. **Return** `LightboxNavigationProps`-compatible object:
   - `onNext` / `onPrevious` — navigate within the ordered list, calling back to set `lightboxAssetKey`
   - `hasNext` / `hasPrevious` — boundary checks
   - `showNavigation` — `true` when list has more than 1 item
   - `currentShotGroupId: string | null` — for the visual indicator
   - `currentItemShotGroupId: string | null` — shot group of currently viewed item (for indicator transitions)

### Step 2: Wire the hook into `VideoEditorProvider` (`src/tools/video-editor/contexts/VideoEditorProvider.tsx`)
**Scope:** Small

1. **Call** the new hook inside `InnerProvider`, passing the existing `editor.resolvedConfig`, `editor.data?.config.pinnedShotGroups`, `editor.data?.meta`, `editor.data?.rows`, and `lightboxAssetKey`.
2. **Pass** the returned navigation props to `MediaLightbox` via the `navigation` prop (`VideoEditorProvider.tsx:255-261`).
3. **Pass** `setLightboxAssetKey` as the callback the hook uses to change the current asset.

## Phase 2: Visual Shot Group Indicator

### Step 3: Add shot group indicator to lightbox header area (`src/domains/media-lightbox/`)
**Scope:** Medium

1. **Extend** `LightboxNavigationProps` (`types.ts:38-44`) with optional fields:
   - `groupLabel?: string` — e.g. "Shot: Intro" (null when not in a shot group)
   - `groupColor?: string` — the shot color from `getShotColor()`
   - `positionInGroup?: { current: number; total: number }` — e.g. "2 of 5"

2. **Add** a small pill/badge in the `NavigationArrows` component area (or adjacent) that shows:
   - Shot group name + color dot when navigating within a shot group
   - Position counter (e.g., "2/5 in Shot: Intro")
   - Smoothly transitions/fades when entering/leaving a shot group boundary

3. **Style** using the existing shot group colors from `useShotGroups.ts:6` (`SHOT_COLORS` / `getShotColor()`), displayed as a colored dot or border accent.

### Step 4: Add position counter to navigation area
**Scope:** Small

1. **Add** a subtle "N of M" counter near the navigation arrows showing position in the full navigation list.
2. **Extend** `LightboxNavigationProps` with optional `positionLabel?: string` (e.g., "3 of 12").
3. **Render** in `NavigationArrows.tsx` as a centered label between the arrows, styled with `text-white/60` on the overlay.

## Phase 3: Validation

### Step 5: Manual testing and edge cases
**Scope:** Small

1. **Test** double-click on clip → lightbox opens → arrows appear → clicking navigates correctly.

6. **Verify** the lightbox query (`loadGenerationForLightbox`) fires correctly for each navigation step.

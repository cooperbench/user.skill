## Overview

Add `runs/<run-id>/inbox/` as an opt-in external completion-signal protocol. External processes (humans, scripts, other tools) drop JSON files into the inbox directory to signal that an attested step has completed. On the next `artagents next` or `artagents status` call, the inbox is scanned. Valid entries are consumed (recorded as hash-chained events), advancing the cursor past the corresponding attested step. Malformed or stale entries are logged and ignored.

**Repository shape:** The task-mode kernel lives in `artagents/core/task/` with separate modules for events (`events.py`), the gate (`gate.py`), lifecycle verbs (`lifecycle.py`, `lifecycle_ack.py`), and the plan model (`plan.py`). The top-level pipeline (`artagents/pipeline.py`) short-circuits lifecycle verbs to the handler functions. `artagents/core/task/__init__.py` exports the public API surface. Tests live in `tests/test_task_*.py` and use `tmp_projects_root` from `tests/conftest.py`.

**Key constraints:**
- Additive only — no changes to Phase 7 CAS or earlier phases.
- No new dependencies.
- Inbox is opt-in: presence of `inbox/` directory triggers scanning, absence skips it (no error).
- Honor existing patterns: hash-chained `events.jsonl` via `append_event`, gate-above-dispatch, file-based state.
- Stale/malformed files are logged (stderr) but never crash.

## Phase 1: Inbox Module + Event Type

### Step 1: Create `artagents/core/task/inbox.py`
**Scope:** Medium — new module with three functions and an `InboxEntry` dataclass.

1. Define the `InboxEntry` dataclass in `artagents/core/task/inbox.py`:1:
   ```python
   @dataclass(frozen=True)
   class InboxEntry:
       step_id: str
       decision: str  # "approve" | "retry" | "abort"
       evidence: dict[str, Any]
       submitted_at: str  # ISO 8601
       submitted_by: str
       source_path: Path  # path to the file on disk
   ```

2. Implement `inbox_dir(run_dir: Path) -> Path` — returns `<run_dir>/inbox/`. Does not create the directory; caller must check existence.

3. Implement `scan_inbox(run_dir: Path) -> list[InboxEntry]`:
   - Returns empty list if `inbox/` does not exist.
   - Iterates over `*.json` files in the inbox directory (non-recursive).
   - Skips files starting with `.`.
   - For each file, attempts to parse as JSON and validate against the required shape (dict with string keys `step_id`, `decision`, `evidence`, `submitted_at`, `submitted_by`).
   - `decision` must be one of `"approve"`, `"retry"`, `"abort"`.
   - Malformed files: log a warning to stderr (`print(f"inbox: skipping malformed file {path}: {reason}", file=sys.stderr)`) and continue — never raise.
   - Returns valid entries sorted by `submitted_at` (oldest first).

4. Implement `consume_inbox_entry(slug: str, run_id: str, entry: InboxEntry, *, projects_root: Path | None = None) -> dict[str, Any]`:
   - Load the active run, plan, and events to get the current cursor via `peek_current_step`.
   - Validate that `entry.step_id` matches the current step's `id` (only the leaf id, not the full path — the step_id in an inbox file references the plan-level step id). If it doesn't match, log a warning and return `None` (stale entry).
   - Validate that the current step is an `AttestedStep` (only attested steps accept external completion signals). If not, log a warning and return `None`.
   - Construct an event via `make_step_attested_event(plan_step_path, attestor_kind="external", attestor_id=entry.submitted_by, evidence=tuple(entry.evidence.keys()))`.
   - Append the event to `events.jsonl` via `append_event`.
   - Move the inbox file to `<run_dir>/inbox/.consumed/<sha256_of_content>.json` using sha256 of the file content.
   - Create `.consumed/` directory if it doesn't exist.
   - Return the appended event dict.

## Phase 2: Hook Into Lifecycle Handlers

### Step 4: Wire inbox scanning into `cmd_next` (`lifecycle.py`)
**Scope:** Medium — integration point.

In `artagents/core/task/lifecycle.py`, in `cmd_next` (after the preamble is printed and before computing `peek`):

1. Determine the run directory: `run_dir = proj_root / "runs" / run_id`.
2. Call `scan_inbox(run_dir)` to get pending entries.
3. If there are pending entries and the peek reveals an `AttestedStep`, match the first pending entry's `step_id` against the current step id:
   - If it matches, call `consume_inbox_entry(slug, run_id, entry, projects_root=projects_root)`.
   - Re-read events and re-compute `peek` after consumption.
   - Print a notice: `f"consumed inbox entry from {entry.submitted_by}"`.
4. If the entry doesn't match, print a notice: `f"inbox: skipping stale entry for step {entry.step_id} (current step is {peek.path_tuple[-1]})"`.

### Step 5: Wire inbox scanning into `cmd_status` (`lifecycle.py`)

332	def _find_step_by_path(plan, path_tuple):
333	    """Walk a TaskPlan to find the step at ``path_tuple`` (descending NestedStep
334	    children). Returns the step or None if the path does not resolve.
335	    """
336	    if not path_tuple:
337	        return None
338	    steps = plan.steps
339	    for segment in path_tuple[:-1]:
340	        match = next((s for s in steps if s.id == segment), None)
341	        if match is None or not isinstance(match, NestedStep):
342	            return None
343	        steps = match.plan.steps
344	    return next((s for s in steps if s.id == path_tuple[-1]), None)

347	def _completed_items_from_events(events, host_path):
348	    """Return the set of item ids that have a completed/attested event under
349	    ``host_path``. ``host_path`` is the STEP_PATH_SEP-joined string form.
350	    """
351	    path_list = host_path.split(STEP_PATH_SEP) if host_path else []
352	    completed: set[str] = set()
353	    for ev in events:
354	        if not isinstance(ev, dict):
355	            continue
356	        kind = ev.get("kind")
357	        if kind not in ("item_completed", "item_attested"):
358	            continue
359	        if ev.get("plan_step_path") != path_list:
360	            continue
361	        item_id = ev.get("item_id")
362	        if isinstance(item_id, str):
363	            completed.add(item_id)
364	    return completed

368	    argv: Sequence[str],
369	    *,
370	    projects_root: Optional[Path] = None,
371	) -> int:
372	    parser = argparse.ArgumentParser(prog="artagents next", add_help=True)
373	    parser.add_argument("--project", required=True, help="project slug")

381	    except Exception as exc:
382	        # Preamble must precede every operator-facing message (SD-023).
383	        print(PROHIBITION_PREAMBLE)
384	        print()
385	        _print_err(f"next: {exc}")
386	        return 1
387	
388	    # Always print preamble first, verbatim, every call (SD-023) — even on
389	    # error / exhausted paths so Stop-hook context re-injection is consistent.
390	    print(PROHIBITION_PREAMBLE)
391	    print()
392	
393	    active_run = read_active_run(slug, root=projects_root)
394	    if active_run is None:
395	        _print_err(
396	            f"next: no active run for project {slug!r}; "
397	            f"recovery: artagents start <orchestrator-id> --project {slug}"
398	        )
399	        return 1
400	
401	    run_id = active_run["run_id"]
402	    proj_root = project_dir(slug, root=projects_root)
403	    plan_path = proj_root / "plan.json"
404	    events_path = proj_root / "runs" / run_id / "events.jsonl"
405	
406	    plan = load_plan(plan_path)
407	    events = read_events(events_path)
408	    peek = peek_current_step(
409	        plan, events, slug, project_root=proj_root, run_id=run_id
410	    )
411	
412	    if peek.exhausted or peek.step is None:
413	        print("run complete")
414	        print(f"recovery: artagents abort --project {slug}")
415	        return 0
416	
417	    path_str = STEP_PATH_SEP.join(peek.path_tuple)
418	
419	    if isinstance(peek.step, CodeStep):
420	        print(f"run: {peek.step.command}")
421	        print(
422	            "(rerun the same command if it failed; the gate detects re-entry "
423	            "and skips a duplicate step_dispatched event.)"
424	        )
425	    elif isinstance(peek.step, AttestedStep):
426	        print(peek.step.instructions)
427	        print()
428	        # peek.step.repeat is None when the leaf is the body of a repeat
429	        # frame (the body is a clone with repeat stripped) — peek.item_id
430	        # being set is the reliable signal that we're inside a for_each
431	        # host. Fall back to looking up the host in the plan when item_id
432	        # is None to handle a top-level for_each that hasn't dispatched yet.
433	        host_has_for_each = peek.item_id is not None
434	        if not host_has_for_each:
435	            host_step = _find_step_by_path(plan, peek.path_tuple)
436	            if host_step is not None and isinstance(
437	                getattr(host_step, "repeat", None), RepeatForEach
438	            ):
439	                host_has_for_each = True
440	        print(
441	            _format_ack_template(
442	                path_str=path_str,
443	                slug=slug,
444	                ack_kind=peek.step.ack.kind,
445	                has_repeat_for_each=host_has_for_each,
446	            )
447	        )
448	    else:
449	        # Defensive: peek_current_step should never surface a NestedStep.
450	        _print_err(f"next: unexpected step kind {type(peek.step).__name__}")
451	        return 1
452	
453	    # Iteration ledger: at peek.iteration == N (>=2), read iteration N-1's
454	    # cumulative feedback.json (written by write_iteration_feedback).
455	    if peek.iteration is not None and peek.iteration >= 2:
456	        prev_iter = peek.iteration - 1
457	        try:
458	            prev_dir = step_dir_for_path(
459	                slug,
460	                run_id,
461	                peek.path_tuple,
462	                iteration=prev_iter,
463	                root=projects_root,
464	            )
465	        except Exception:
466	            prev_dir = None
467	        if prev_dir is not None:
468	            feedback_path = prev_dir / "feedback.json"
469	            if feedback_path.is_file():
470	                try:
471	                    payload = json.loads(feedback_path.read_text(encoding="utf-8"))
472	                except (OSError, json.JSONDecodeError):
473	                    payload = None
474	                if isinstance(payload, list):
475	                    print()
476	                    print(f"feedback ledger (through iteration {prev_iter}):")
477	                    for idx, entry in enumerate(payload, start=1):
478	                        print(f"  [{idx}] {entry}")
479	
480	    # for_each item ledger: when peek.item_id is set, the leaf is the body
481	    # step inside a for_each frame; peek.path_tuple matches the host path
482	    # because _make_item_frame uses path_prefix = parent_prefix and the body
483	    # carries the host's id. Look the host step up directly from the plan
484	    # (peek does not persist for_each_expanded to events.jsonl, so
485	    # derive_cursor's for_each_progress would be empty here).
486	    if peek.item_id is not None:
487	        host_path = STEP_PATH_SEP.join(peek.path_tuple)
488	        host_step = _find_step_by_path(plan, peek.path_tuple)
489	        items: list[str] = []
490	        if host_step is not None and isinstance(
491	            getattr(host_step, "repeat", None), RepeatForEach
492	        ):
493	            host_for_each: RepeatForEach = host_step.repeat  # type: ignore[assignment]
494	            if host_for_each.items_source == "static":
495	                items = list(host_for_each.items)
496	            # Dynamic items source — items are resolved at gate dispatch from
497	            # a sibling produces JSON file. peek shares the same resolution
498	            # path; if events.jsonl has a for_each_expanded event for this
499	            # host (because dispatch ran earlier) we can recover items from
500	            # there instead.
501	        if not items:
502	            for ev in events:
503	                if (
504	                    isinstance(ev, dict)
505	                    and ev.get("kind") == "for_each_expanded"
506	                    and ev.get("plan_step_path") == list(peek.path_tuple)
507	                ):
508	                    raw = ev.get("item_ids") or []
509	                    if isinstance(raw, list):
510	                        items = [str(x) for x in raw]
511	                    break
512	        completed = _completed_items_from_events(events, host_path)
513	        if items:
514	            print()
515	            print(f"for_each items (host {host_path}):")
516	            for item in items:
517	                marker = "x" if item in completed else " "
518	                star = "  <- next" if item == peek.item_id else ""
519	                print(f"  [{marker}] {item}{star}")

521	    return 0

529	def _summarize_run_dir(run_dir: Path) -> tuple[str, str, str]:
530	    """Return (status, last_event_kind, last_ts) for a run directory.
531	
532	    Per FLAG-P5-006: only ``aborted`` vs ``in-progress`` are reliably
533	    distinguishable in V1. A naturally completed plan still leaves
534	    ``active_run.json`` in place, so the "complete" bucket is mostly
535	    unobservable.
536	    """
537	    events_path = run_dir / "events.jsonl"
538	    if not events_path.is_file():
539	        return "in-progress", "", ""
540	    events = read_events(events_path)
541	    if not events:
542	        return "in-progress", "", ""
543	    last = events[-1]
544	    last_kind = str(last.get("kind", ""))
545	    last_ts = str(last.get("ts", ""))
546	    status = "aborted" if last_kind == "run_aborted" else "in-progress"
547	    return status, last_kind, last_ts

53	def verify_chain(path: str | Path) -> tuple[bool, int, str | None]:
54	    events_path = Path(path)
55	    try:
56	        handle = events_path.open("r", encoding="utf-8")
57	    except FileNotFoundError:
58	        return True, -1, None
59	    except OSError as exc:
60	        return False, -1, f"failed to read {events_path}: {exc}"
61	
62	    prev_hash = ZERO_HASH
63	    last_index = -1
64	    with handle:
65	        for index, line in enumerate(handle):
66	            if not line.endswith("\n"):
67	                return False, index, f"event log line {index + 1} is not newline-terminated"
68	            raw = line[:-1]
69	            if not raw:
70	                return False, index, f"event log line {index + 1} is empty"
71	            try:
72	                event = json.loads(raw)
73	            except json.JSONDecodeError as exc:
74	                return False, index, f"invalid JSON on event log line {index + 1}: {exc.msg}"
75	            if not isinstance(event, dict):
76	                return False, index, f"event log line {index + 1} is not an object"
77	            stored_hash = event.get("hash")
78	            if not isinstance(stored_hash, str):
79	                return False, index, f"event log line {index + 1} is missing hash"
80	            expected_hash = _event_hash(prev_hash, event)

82	                return (
83	                    False,
84	                    index,
85	                    f"event log line {index + 1} hash mismatch: expected {expected_hash}, got {stored_hash}",
86	                )

88	            last_index = index

## Overview

Add `runs/<run-id>/inbox/` as an opt-in external completion-signal protocol. External processes (humans, scripts, other tools) drop JSON files into the inbox directory to signal that an attested step has completed. On the next `artagents next` or `artagents status` call, the inbox is scanned. Valid entries targeting the current step are consumed (recorded as `step_attested` hash-chained events with `attestor_kind='external'`), advancing the cursor past the corresponding attested step. Malformed or stale entries are logged and ignored.

**Repository shape:** The task-mode kernel lives in `artagents/core/task/` with `events.py` (event record factories + append), `gate.py` (cursor derivation at line 257 advances on `step_attested`/`step_completed`; `record_step_attested` at line 1183 wraps `make_step_attested_event`), `lifecycle.py` (`cmd_next` at line 367, `cmd_status` at line 245, `_AGENT_MD_TEMPLATE` at line 53), and `plan.py` (`STEP_PATH_SEP = "/"`, plan model types).

        # Implementation Plan: Final Video Available Badge on Shot Groups

## Overview

Add a "final video available" badge to shot group overlays in the video editor timeline. When a shot has a completed final video (from the `shot_final_videos` view), a video icon badge appears on the right side of the shot group border overlay. Clicking it opens a context menu with two actions: (1) "Switch to final video" — replaces all image clips in that shot group with a single video clip spanning the same time range, and (2) "Dismiss reminder" — hides the badge for that shot.

**Key patterns to follow:**
- Stale variant badge: `useStaleVariants.ts` provides `staleAssetKeys` + `dismissedAssetKeys`; `ClipAction.tsx` renders amber badge at top-right → this is the per-clip pattern. We need a per-shot-group variant.
- Shot group overlays: `useShotGroups.ts` → `TimelineCanvas.tsx` positions groups and renders border + hover label + context menu.
- Final video data: `useShotFinalVideos.ts` (in travel tool) provides `finalVideoMap: Map<shotId, ShotFinalVideo>`.
- Asset registration + clip insertion: `useAssetManagement.ts` shows `registerGenerationAsset` + `handleAssetDrop` patterns.
- Clip deletion: `useClipEditing.ts` `handleDeleteClips()`.

**Architecture:** The badge renders on the shot group overlay in `TimelineCanvas.tsx`. A new hook `useFinalVideoAvailable.ts` computes which shot groups have final videos and tracks dismissed state. The "switch" action lives in `TimelineEditor.tsx` which has access to both asset management and clip editing.

## Phase 3: Switch-to-Final-Video Action

### Step 4: Implement the switch action in `TimelineEditor.tsx` (`src/tools/video-editor/components/TimelineEditor/TimelineEditor.tsx`)
**Scope:** Medium
1. **Import** `useFinalVideoAvailable` and wire it after the existing `useShotGroups` call (line 264).
2. **Pass** `finalVideoShotIds`, `onShotGroupSwitchToFinalVideo`, and `onShotGroupDismissFinalVideo` as props to `TimelineCanvas`.
3. **Implement** `handleSwitchToFinalVideo(shotId: string)`:
   - Look up the `ShotFinalVideo` from the hook's `finalVideoMap`.
   - Find the shot group matching `shotId` from `shotGroups`.
   - Calculate the time span: `startTime = min(action.start for clips in group)`, `endTime = max(action.end for clips in group)`.
   - Find the track (rowId) the clips are on.
   - Register the final video as an asset: call `registerGenerationAsset({ generationId: finalVideo.id, imageUrl: finalVideo.location, mimeType: 'video/mp4' })` — this returns the assetKey.
   - **Need the video duration:** Fetch it from the asset or default to `endTime - startTime`. Since `shot_final_videos` is a view on `generations`, we can use the time span of the clips being replaced (the final video spans the same content). If the actual video duration differs, we use `from`/`to` trimming to fit.
   - Delete the existing clips: call `handleDeleteClips(group.clipIds)`.
   - Insert a single video clip at `startTime` with `end = endTime`: call `handleAssetDrop(assetKey, group.rowId, startTime)`.
   - **Problem:** `handleDeleteClips` and `handleAssetDrop` each call `applyEdit` independently, creating two history entries. Better approach: build the combined edit manually (delete clips + insert new one) and call `applyEdit` once. This follows the same immutable-row-construction pattern seen in `handleAssetDrop` (line 255-268).
4. **Single atomic edit approach:**
   ```typescript
   // Remove old clips from the row
   const nextRows = current.rows.map(row => ({
     ...row,
     actions: row.actions.filter(a => !clipIdSet.has(a.id)),
   }));
   // Add new video clip to the target row
   const videoAction = { id: clipId, start: startTime, end: endTime, effectId: `effect-${clipId}` };
   const finalRows = nextRows.map(row => 
     row.id === group.rowId ? { ...row, actions: [...row.actions, videoAction] } : row
   );
   // Apply as single edit
   applyEdit({
     type: 'rows',
     rows: finalRows,
     metaUpdates: { [clipId]: videoClipMeta },
     metaDeletes: group.clipIds,
   });
   ```

### Step 5: Wire asset registration for final video (`TimelineEditor.tsx`)
**Scope:** Small
1. **Before** the atomic edit in Step 4, register the final video asset using `registerGenerationAsset` from `useAssetManagement`.
2. **The asset key** comes back from `registerGenerationAsset`. The entry will have `type: 'video/mp4'`, `generationId: finalVideo.id`, `file: finalVideo.location`.
3. **Build** the `ClipMeta` for the video clip following the video branch of `handleAssetDrop` (line 237-252):
   ```typescript
   const clipMeta: ClipMeta = {
     asset: assetKey,
     track: group.rowId,
     clipType: 'media',
     from: 0,
     to: endTime - startTime,  // or actual video duration
     speed: 1,
     volume: 1,
     opacity: 1,
   };
   ```

   ```typescript
     const finalVideo = finalVideoMap.get(group.shotId);
     const current = dataRef.current;
     if (!finalVideo || !current) return;

     // 1. Register asset directly (like useStaleVariants pattern, NOT registerGenerationAsset)
     const assetKey = generateUUID();
     const assetEntry: AssetRegistryEntry = {
       file: finalVideo.location,
       type: 'video/mp4',
       generationId: finalVideo.id,
     };
     patchRegistry(assetKey, assetEntry, finalVideo.location);
     void registerAsset(assetKey, assetEntry).catch(console.error);

     // 2. Calculate time span from the group's clips
     const clipIdSet = new Set(group.clipIds);
     let startTime = Infinity, endTime = -Infinity;
     for (const row of current.rows) {
       for (const action of row.actions) {
         if (clipIdSet.has(action.id)) {
           startTime = Math.min(startTime, action.start);
           endTime = Math.max(endTime, action.end);
         }
       }
     }
     if (!isFinite(startTime) || !isFinite(endTime)) return;

     // 3. Build atomic edit: remove old clips + insert new video clip
     const duration = endTime - startTime;
     const clipId = getNextClipId(current.meta);
     const videoMeta: ClipMeta = {
       asset: assetKey,
       track: group.rowId,
       clipType: 'media',
       from: 0,
       to: duration,
       speed: 1,
       volume: 1,
       opacity: 1,
     };
     const videoAction: TimelineAction = {
       id: clipId,
       start: startTime,
       end: endTime,
       effectId: `effect-${clipId}`,
     };

     const nextRows = current.rows.map(row => ({
       ...row,
       actions: [
         ...row.actions.filter(a => !clipIdSet.has(a.id)),
         ...(row.id === group.rowId ? [videoAction] : []),
       ],
     }));

     applyEdit({
       type: 'rows',
       rows: nextRows,
       metaUpdates: { [clipId]: videoMeta },
       metaDeletes: group.clipIds,
     });
   }, [finalVideoMap, dataRef, patchRegistry, registerAsset, applyEdit]);
   ```

        Idea:
Two features for the timeline editor:

FEATURE 1 - TRACK SETTINGS POPOVER: Each track label on the left side of the timeline should have a gear/settings button that opens a popover or inline panel for setting default properties for that track. For visual tracks: scale, fit (cover/contain/manual), opacity, blend mode. For audio tracks: volume, opacity. These are the DEFAULT settings - any clip on the track inherits them unless the clip has its own override. The TrackPanel component already exists in viewer/src/TrackPanel.tsx but it's in the right sidebar which is disconnected from the track labels. Instead, the settings should be accessible directly from the track label - either as a popover that opens when you click a gear icon, or as an expandable section below the track label. The track label currently just shows ID + name at 56px height matching ROW_HEIGHT. Need to keep the height aligned with timeline rows while still providing access to settings.

FEATURE 2 - VISUAL CLIP POSITIONING ON CANVAS: Users should be able to drag and resize how a clip appears on the video preview canvas. Like in Premiere/After Effects - click a clip, then drag it on the preview to reposition, or drag corners to resize/zoom. This should work for clips on any visual track. The OverlayEditor.tsx already has some of this for overlay clips but it needs to work for ALL visual clips. When a clip is selected in the timeline, the preview should show handles/bounds that let you: drag to reposition (updates clip x/y), drag corners to resize (updates clip width/height), optionally crop by holding a modifier key. The positioning is in content coordinates (1280x720) and gets stored as x/y/width/height on the clip in timeline.json. If a clip has no position set, it uses the track's fit setting (cover/contain). Once you manually position it, it overrides the track default.

CONSTRAINTS: Keep the track label height at ROW_HEIGHT (56px) to stay aligned with timeline rows. Settings popover should appear on click, not permanently expand. Canvas positioning must work with the Remotion Player (overlay div on top of it, convert mouse coords to content coords accounting for scale). All changes persist to timeline.json.

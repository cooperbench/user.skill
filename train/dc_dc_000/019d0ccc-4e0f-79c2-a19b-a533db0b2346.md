## Intent

Add a mandatory "strategize" stage that runs before "observe" in the triage pipeline. An LLM sub-agent analyzes cross-cycle history (progression.jsonl, scan_history, execution_log, resolved/recurring work items) and produces a structured `StrategistBriefing` persisted in `epic_triage_meta`. Structured fields are consumed programmatically; prose sections are injected into observe and reflect stage prompts. This prevents rework loops, dimension neglect, and score-neutral churn that individual triage stages can't see.

## Architecture

```
Triage Start
     │
     ▼
┌─────────────┐
│ STRATEGIZE  │  NEW mandatory first stage
│ (LLM agent) │  Reads: scan_history, execution_log,
└──────┬──────┘  progression.jsonl, work_items, dimension_scores,
       │         skipped, clusters, queue_order, completed_clusters
       │
       │  Persists StrategistBriefing → epic_triage_meta["strategist_briefing"]
       │  + triage_stages["strategize"] (stage record)
       │
       ▼
┌─────────────┐  ← observe_guidance prose injected
│  OBSERVE    │
└──────┬──────┘
       ▼
┌─────────────┐  ← reflect_guidance prose + structured focus/avoid injected
│  REFLECT    │
└──────┬──────┘
       ▼
┌─────────────┐  ← organize_guidance (focus areas, avoid areas) injected
│  ORGANIZE   │
└──────┬──────┘
       ▼
┌─────────────┐  ← rework warnings passed to value sub-agent
│ SENSE-CHECK │
└──────┬──────┘
       ▼
   ... enrich (unchanged) → commit (unchanged)
```

**Location:** `app/commands/plan/triage/` (LLM sub-agent layer, not engine pure functions)
**Data layer:** `engine/_plan/triage/strategist_data.py` (pure functions, engine layer)
**Lookback:** ~5 scans via scan_history, plus execution_log/progression.jsonl

    stages: dict[str, Any],
) -> dict[str, Any]:
    """If any stage after strategize is recorded but strategize is missing,
    inject a synthetic strategize record so downstream code treats it as satisfied.

            "stage": "strategize",
            "report": "(legacy: predates strategize stage)",
            "timestamp": "",
            "confirmed_at": "legacy",
            "confirmed_text": "auto-backfilled",

    return stages

Prompt structure:
1. **Preamble:** "You are a Big Picture Strategist. Analyze cross-cycle codebase health data and produce strategic guidance for the upcoming triage cycle."
2. **Score trajectory** — formatted table from ScoreTrajectory
3. **Dimension trajectories** — markdown table: name | trend | headroom | strict | investment
4. **Lifecycle inventory** — backlog by dimension, skipped by reason, deferred count, cluster names, promoted count
5. **Rework loops** — if any: dimension, resolved count, new open count, affected files
6. **File churn hotspots** — if any: file, resolved count, open count, detectors
7. **Completed clusters** — what was accomplished (names, theses, issue counts)
8. **Execution patterns** — skip rate, resolve rate, throughput
9. **Wontfix debt** — trend, worst dimension, gap size
10. **Recurring patterns** — from `detect_recurring_patterns()`
11. **Anti-pattern checklist** — instructions to detect and flag:
    - Repeated refactoring of same area (file churn > 2 cycles)
    - Dimension stagnation despite investment (resolved > 0 but score unchanged)
    - Score-neutral churn (issues resolved but overall score flat)
    - Neglected high-headroom dimensions (headroom > 10 but no recent investment)
    - Growing wontfix debt (especially if concentrated in one dimension)
    - Skip-heavy execution (skip_rate > 0.3 signals unclear priorities)
12. **Output format** — JSON conforming to `StrategistBriefing` schema, including `organize_guidance` and `sense_check_guidance` prose fields

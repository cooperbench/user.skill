## Step 1: Add sparkline renderer (`desloppify/app/commands/status/sparkline.py`)
**Scope:** Small — pure function, no side effects
1. **Create** `desloppify/app/commands/status/sparkline.py` with:
   - `render_sparkline(scores: list[float], width: int = 20) -> str` — maps scores to `▁▂▃▄▅▆▇█` characters, scaled to min/max of the input range.
   - If all values are equal, return a flat line (`▄` repeated).
   - Return the raw string (no ANSI) — caller applies styling.
   ```python
   BLOCKS = "▁▂▃▄▅▆▇█"

   def render_sparkline(scores: list[float], width: int = 20) -> str:
       if len(scores) < 3:
           return ""
       lo, hi = min(scores), max(scores)
       span = hi - lo
       if span < 0.01:
           return BLOCKS[3] * min(len(scores), width)
       # Resample if more points than width
       if len(scores) > width:
           step = len(scores) / width
           scores = [scores[int(i * step)] for i in range(width)]
       return "".join(
           BLOCKS[min(7, int((s - lo) / span * 7))]
           for s in scores
       )
   ```
2. **Add** `extract_strict_trend(events: list[dict]) -> list[float]` — filters for `plan_checkpoint` events and extracts `payload.scores.strict` in order.

## Step 1: Add sparkline renderer (`desloppify/app/commands/status/sparkline.py`)
**Scope:** Small — two pure functions, no side effects
1. **Create** `desloppify/app/commands/status/sparkline.py` with:
   - `render_sparkline(scores: list[float], width: int = 20) -> str` — maps scores to `▁▂▃▄▅▆▇█` characters scaled to min/max. Returns empty string if `len(scores) < 3`. Returns raw string (no ANSI).
   - `extract_strict_trend(events: list[dict]) -> list[float]` — filters for `event_type == "plan_checkpoint"`, extracts `payload.scores.strict` in order, skips malformed entries.
   ```python
   BLOCKS = "▁▂▃▄▅▆▇█"

   def render_sparkline(scores: list[float], width: int = 20) -> str:
       if len(scores) < 3:
           return ""
       lo, hi = min(scores), max(scores)
       span = hi - lo
       if span < 0.01:
           return BLOCKS[3] * min(len(scores), width)
       if len(scores) > width:
           step = len(scores) / width
           scores = [scores[int(i * step)] for i in range(width)]
       return "".join(
           BLOCKS[min(7, int((s - lo) / span * 7))]
           for s in scores
       )

   def extract_strict_trend(events: list[dict]) -> list[float]:
       result = []
       for ev in events:
           if ev.get("event_type") != "plan_checkpoint":
               continue
           payload = ev.get("payload")
           if not isinstance(payload, dict):
               continue
           scores = payload.get("scores")
           if not isinstance(scores, dict):
               continue
           strict = scores.get("strict")
           if isinstance(strict, (int, float)):
               result.append(float(strict))
       return result
   ```

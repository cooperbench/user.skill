4. **Scratch dir isolation**: Author test runs entirely in `tempfile.mkdtemp` and cleans up after.

5. **Golden stores raw events**: Normalization happens only during comparison. The golden remains a valid events.jsonl for manual inspection.

6. **Nested plan handling during replay**: The gate auto-traverses nested plans (emits nested_entered/exited events). We run leaf code steps recursively through the same peek→gate→subprocess.run→complete loop. Attested leaves in nested plans also auto-approve.

54	## 7. Gate Above Dispatch
55

66	## 9. Ack Decisions
67	
68	`approve` advances when the current step is awaiting approval and checks pass. `retry` is only valid after verifier failure and reruns with stderr/verifier output as feedback. `iterate --feedback` is only valid for `repeat.until=user_approves` and appends to cumulative constraints. `abort` ends the run. 70	## 10. Authoring
71

73

        # Implementation Plan: Smooth video editor layout transition on pane lock/unlock

## Overview

When the generations pane is locked, `VideoEditorShell.tsx` instantly switches from standard layout (stacked preview+timeline) to condensed layout (side-by-side) because line 148 uses `isGenerationsPaneLocked` directly in the condensed calculation. Meanwhile, `LayoutMainContent` animates its bottom padding over 300ms via CSS transitions. The fix: let the ResizeObserver naturally detect the shrinking container rather than short-circuiting with the boolean flag, and add CSS transitions to soften the layout swap.

**Key architectural constraint:** The condensed and standard layouts are entirely different React subtrees (ternary at line 360 vs 426). We cannot CSS-transition grid properties between them. Instead, we'll (a) fix the timing so the swap happens when space actually runs out, and (b) add an opacity/transform crossfade on the layout containers.

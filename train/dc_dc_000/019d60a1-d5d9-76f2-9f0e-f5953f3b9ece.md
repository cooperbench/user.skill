        Idea:
Implement three capabilities for the ai-timeline-agent edge function:

1. **Duplicate generation tool** — A new tool the agent can call to duplicate an existing generation (DB copy, instant). Takes a generation_id, creates a new generation record with same image/asset but new ID, sets based_on to the original. Returns the new generation_id and asset URL so the LLM can reference them in subsequent calls. The agent already has access to the generation ID via resolveClipGenerationIds from selected clips.

2. **Add media clip timeline command** — A new timeline command like add-media <track> <at> <generation_id> that inserts a new media clip on the timeline at a given position, referencing a generation's asset. Similar to the existing add-text command but for media. Needs to register the asset in the registry and add the clip to the timeline config.

3. **Fix based_on passthrough in create_task** — Currently executeCreateTask in create-task.ts resolves based_on only from selected clips. If the LLM explicitly passes based_on (e.g., from a duplicated generation), that value should take precedence. Small fix.

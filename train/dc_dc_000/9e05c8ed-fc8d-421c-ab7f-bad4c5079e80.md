253	- `load_bearing`: `true`
254	- `decision`: Use a hybrid fork shape: maintain `banodoco/Wan2GP` as the long-running fork and consume it in `reigh-worker` as a git submodule mounted at `reigh-worker/Wan2GP/`.
255	  Path/import contract sub-clause:
256	  - The submodule mount path stays exactly `reigh-worker/Wan2GP/`; no relocation or rename.
257	  - `ensure_wan2gp_on_path()` must continue inserting the absolute `Wan2GP/` directory itself into `sys.path`, not the repo root or a parent/sibling path.

260	  - Deviations that do not belong in the fork stay in the existing `source/models/wgp/wgp_patches.py` seam, which is module-loaded via `source/__init__.py:6` and applied by `apply_all_wgp_patches(wgp, self.wan_root)` at `source/models/wgp/orchestrator.py:265-266`.
261	  - No parallel runtime-side Wan2GP patch package is introduced.
262	- `rationale`: This preserves the current runtime contract while restoring maintainability. The stable mount path protects the import surface already used by both dotted `Wan2GP.*` imports and the bare-module import sites, and the existing patch seam prevents fork-only changes from being scattered into a second, conflicting patch registry.

266	- `load_bearing`: `true`
267	- `decision`: Every deviation between the current vendored tree and upstream is triaged into one of four buckets: `(a) accept-upstream`, `(b) upstreamable`, `(c) banodoco-fork-or-banodoco-patch`, `(d) cruft`. The canonical artifact is `docs/wan2gp-triage.csv` with columns `path,hunk,bucket,carry_location,owner,verification`.

A forced bucket per hunk makes carry decisions reviewable, gives Sprint 1 a concrete deliverable, and prevents load-bearing customizations like `clear_conditioning` from being lost inside an undifferentiated merge.

### Step 4: Compute the differing-file inventory
**Scope:** Medium
1. **Walk** both trees (`reigh-worker/Wan2GP/` and `/tmp/wan2gp-upstream/`) and build three sets: vendored-only paths, upstream-only paths, and common paths whose contents differ. Excluded path prefixes: `__pycache__/`, `.git/`, `*.pyc`, and the upstream repo's own top-level `.git` if the walker traverses it.
2. **Implement** the walker inline. Emit two outputs in this invocation: (a) tab-separated rows of `STATUS<TAB>relpath` on stdout for human review, and (b) a plain newline-delimited list of differing relative paths written to `/tmp/wan2gp-differ.paths` for machine-checkable verification later. This list is the authoritative set the CSV must cover (FLAG-001 fix).
   ```bash
   python3 - <<'PY'
   import hashlib, os, sys
   VEND = [REDACTED]
   UP   = "/tmp/wan2gp-upstream"
   SKIP_DIRS = {"__pycache__", ".git"}
   SKIP_SUFFIX = (".pyc",)
   def walk(root):
       out = {}
       for dp, dns, fns in os.walk(root):
           dns[:] = [d for d in dns if d not in SKIP_DIRS]
           for fn in fns:
               if fn.endswith(SKIP_SUFFIX): continue
               p = os.path.join(dp, fn)
               rel = os.path.relpath(p, root)
               with open(p, "rb") as f:
                   out[rel] = hashlib.sha256(f.read()).hexdigest()
       return out
   v, u = walk(VEND), walk(UP)
   keys = sorted(set(v) | set(u))
   differ = []
   for k in keys:
       if k not in u:
           status = "VENDORED_ONLY"
       elif k not in v:
           status = "UPSTREAM_ONLY"
       elif v[k] != u[k]:
           status = "CONTENT_DIFF"
       else:
           continue
       differ.append(k)
       print(f"{status}\t{k}")
   with open("/tmp/wan2gp-differ.paths", "w") as f:
       for k in differ:
           f.write(f"Wan2GP/{k}\n")
   PY
   wc -l /tmp/wan2gp-differ.paths
   ```
3. **Sanity-check** the output: the `models/ltx2/` subset should be ~22 rows per the plan's Section 2a. If it is drastically off (e.g., 0 or >50), stop and escalate — the plan's inventory assumption is wrong and Sprint 1 cannot proceed until the discrepancy is explained.

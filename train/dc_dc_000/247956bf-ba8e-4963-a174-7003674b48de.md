# Implementation Plan: Inline media (images, videos, links, carousels) in Recommendations body_markdown

## Overview

**Goal:** Let `body_markdown` for a recommendation include:
- A single image (optionally wrapped in a link).
- A single video.
- A carousel mixing images and videos with prev/next navigation.

Each element supports a width (`full | half | third`) and a layout (`block` on its own line, or `wrap-left`/`wrap-right` floated with text wrapping around it).

**Approach (per brief):** Custom block-directive syntax `:::media{...}` and `:::carousel{...}` is preprocessed in `Recommendations.tsx` *before* marked runs. `:::media` blocks compile to raw HTML; `:::carousel` blocks are replaced with a placeholder that, after marked + sanitization, gets split out and rendered as a React component (so prev/next can be interactive). One new Supabase migration seeds a single example recommendation that exercises all three element types.

**Repo shape that matters:**
- `src/pages/Recommendations.tsx` — `renderBody()` currently does `sanitizeHtml(marked.parse(...))` and is wired via `dangerouslySetInnerHTML` (single blob). Will change to a segmented renderer.
- `src/styles/global.css` — `.recommendation-image` lives at line 2918; new layout classes go adjacent.
- `supabase/migrations/` — pattern is `YYYYMMDDNNNNNN_*.sql`. Last existing is `20260330000006_add_recommendation_status.sql`. Next file: `20260330000007_seed_media_demo_recommendation.sql`.
- `src/types/index.ts` and `src/lib/recommendations.ts` — no schema column added; no changes needed.

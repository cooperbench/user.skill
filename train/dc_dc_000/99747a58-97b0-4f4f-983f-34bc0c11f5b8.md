        # Implementation Plan: Phase 9 — Author Test with Golden Runs (Revision 4)

## Overview

Phase 9 implements `artagents author test` as a full runtime replay: initialize a scratch project directory, drive the plan step-by-step by calling `gate_command` in a `while True`-until-exhaustion loop, auto-approve attested steps via `ARTAGENTS_AUTHOR_TEST=1`, normalize the resulting `events.jsonl`, and diff against the pack's committed golden file.

**Stop-condition resolution** (tiebreaker between literal wording and additive-only constraint): The issue says `--orchestrator hype --fixture smoke`, but `builtin.hype` is already a production multi-executor pipeline (registered via `orchestrator.yaml` + `run.py`, depended on by ~15 tests) that requires API keys and real audio — it cannot serve as the Phase 9 smoke fixture. We create a `builtin.smoke` Python-DSL orchestrator in a separate pack subdirectory (`artagents/packs/builtin/smoke/`) for deterministic golden testing. The `author` CLI's Python-DSL resolution path (`<pack>/<name>.py`) is orthogonal to the `orchestrators` CLI's yaml-based path (`orchestrator.yaml`), so no collision occurs. The stop-condition closes with: `artagents author test --pack builtin --orchestrator smoke --fixture smoke` exits 0. **This deliberately relaxes the literal wording of the issue's stop-condition in favor of the hard constraint "additive only; existing tests must pass."**

**Critical driver corrections from Revision 3**: The driver pseudocode had two fatal bugs: (1) `gate_command(command="next", ...)` would be rejected by `_dispatch_code` at `gate.py:804` which enforces `command != step.command`, and (2) `decision.command` doesn't exist — `GateDecision` (`gate.py:79-91`) has no `command` field. The corrected driver loads the plan, calls `gate_command` with the step's actual command (obtained by peeking the cursor/events before each call), and runs subprocesses using the step's command from the plan, not from the decision.

Key constraints:
- Runs in scratch dirs via `tempfile.mkdtemp` — does not touch real project state.
- Auto-approval for attested steps gated behind `ARTAGENTS_AUTHOR_TEST=1`.
- Hash-chain hashes (`hash`) and timestamps (`ts`) stripped during normalization; `run_id`, `actor`, and absolute paths also stripped or normalized.
- `--regenerate` flag writes current output as the new golden.
- Evidence token uses `=` delimiter (`source=author_test`) per gate.py convention.
- Auto-approval handles both `step_attested` and `item_attested` branches.

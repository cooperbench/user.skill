        # Implementation Plan: Implement ArtAgents Thread / Variant / Iteration-Video Layer

## Overview
Ship the 10-day sprint in `docs/sprint-thread-layer.md`: Week 1 creates the durable thread/run/variant metadata layer at executor and orchestrator chokepoints, and Week 2 consumes that metadata to produce `builtin.iteration_video` outputs.

The new critique does not change the root cause of the overall plan, but it does identify one wrong implementation assumption in the iteration-video phase: `builtin.render` is not a generic renderer for arbitrary `iteration.timeline.json` names. It currently consumes `{brief_out}/hype.timeline.json` and `{brief_out}/hype.assets.json` and emits `{brief_out}/hype.mp4`. The plan must therefore make `iteration.assemble` a render-adapter stage that writes both human-facing iteration artifacts and render-compatible `hype.*` adapter files before invoking `builtin.render`.

The corrected iteration-video approach is: `iteration.prepare -> iteration.assemble -> builtin.render -> finalize/copy outputs`. `iteration.assemble` emits canonical `iteration.timeline.json`, `iteration.manifest.json`, `iteration.quality.json`, and `iteration.report.html`, and also materializes byte-equivalent render inputs at `{brief_out}/hype.timeline.json` and `{brief_out}/hype.assets.json`. The orchestrator then calls existing `builtin.render` against those `hype.*` names and copies or renames `{brief_out}/hype.mp4` to `iteration.mp4`. `builtin.cut` is not run after assemble because assemble has already produced the render-ready `hype.timeline.json` and `hype.assets.json` pair; this follows the repo rule that render can proceed without cut when both files already exist.

The implementation should bridge into existing systems instead of inventing parallel ones: use `artagents/audit/*` and hype audit parent propagation as provenance inputs, add the new thread block at allowed wrapper/orchestrator integration points rather than by modifying forbidden executor `run.py` files, keep generated dogfood media out of CI by using a tracked compact fixture, and preserve all DEF trims.

- The form stores references in ProjectImageSettings.references array

- The selected reference for a shot is in selectedReferenceIdByShot[shotId]

- What's missing: the agent doesn't know about the user's saved references. We need to:

  b) Include it in the system prompt so the LLM knows it can use it
  c) When the LLM uses style-transfer/subject-transfer, it can reference the user's active reference

- The enrichClipsWithPrompts in selectedClips.ts already fetches generation prompts
- For references, need similar: load the generation that created the reference image and attach its prompt

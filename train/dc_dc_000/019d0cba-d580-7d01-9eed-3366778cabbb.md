## Intent

Add a mandatory "strategize" stage that runs before "observe" in the triage pipeline. An LLM sub-agent analyzes cross-cycle history (progression.jsonl, scan_history, execution_log, commit_log, resolved/recurring work items) and produces a structured `StrategistBriefing` persisted in `epic_triage_meta`. Structured fields are consumed programmatically; prose sections are injected into observe and reflect stage prompts. This prevents rework loops, dimension neglect, and score-neutral churn that individual triage stages can't see.

## Architecture

```
Triage Start
     │
     ▼
┌─────────────┐
│ STRATEGIZE  │  NEW mandatory first stage
│ (LLM agent) │  Reads: scan_history, execution_log, commit_log,
└──────┬──────┘  progression.jsonl, work_items, dimension_scores
       │
       │  Persists StrategistBriefing → epic_triage_meta["strategist_briefing"]
       │  + triage_stages["strategize"] (stage record)
       │
       ▼
┌─────────────┐  ← observe_guidance prose injected
│  OBSERVE    │
└──────┬──────┘
       ▼
┌─────────────┐  ← reflect_guidance prose + structured focus/avoid injected
│  REFLECT    │
└──────┬──────┘
       ▼
   ... organize → enrich → sense-check → commit (unchanged)
```

**Location:** `app/commands/plan/triage/` (LLM sub-agent layer, not engine pure functions)
**Data layer:** `engine/_plan/triage/strategist_data.py` (pure functions, engine layer)
**Lookback:** ~5 scans via scan_history, plus execution_log/commit_log/progression.jsonl

```python
@dataclass(frozen=True)
class ScoreTrajectory:
    strict_scores: list[float]        # last N strict scores
    strict_delta: float               # net change over window
    trend: str                        # "improving" | "stable" | "declining"
    best_scan_delta: float            # largest single-scan gain
    worst_scan_delta: float           # largest single-scan drop

@dataclass(frozen=True)
class DimensionTrajectory:
    name: str
    strict_scores: list[float]        # last N strict scores for this dim
    trend: str                        # "improving" | "stagnant" | "declining"
    headroom: float                   # 100 - current strict
    recent_investment: int            # resolved issues in this dim (window)

@dataclass(frozen=True)
class FileChurnEntry:
    file: str
    resolved_count: int               # times issues in this file were resolved
    current_open_count: int           # open issues in this file now
    detectors: list[str]              # detectors that flagged it

@dataclass(frozen=True)
class ReworkLoopEntry:
    dimension: str
    resolved_count: int
    new_open_count: int
    reopen_count: int                 # sum of work_item.reopen_count
    affected_files: list[str]

@dataclass(frozen=True)
class CompletedClusterSummary:
    name: str
    issue_count: int
    dimensions: list[str]
    completed_at: str                 # ISO from execution_log

@dataclass(frozen=True)
class ExecutionPatterns:
    total_resolved: int
    total_skipped: int
    total_done: int
    skip_rate: float
    avg_cluster_size: float

@dataclass(frozen=True)
class DebtTrajectory:
    current_wontfix: int
    trend: str                        # "growing" | "stable" | "shrinking"
    worst_dimension: str | None
    worst_dimension_gap: float

@dataclass
class StrategistInput:
    score_trajectory: ScoreTrajectory
    dimension_trajectories: dict[str, DimensionTrajectory]
    file_churn: list[FileChurnEntry]
    rework_loops: list[ReworkLoopEntry]
    completed_clusters: list[CompletedClusterSummary]

    debt_trajectory: DebtTrajectory
    recurring_patterns: dict[str, dict]  # from existing detect_recurring_patterns()

    scan_count: int
```


Prompt structure:
1. **Preamble:** "You are a Big Picture Strategist. Analyze cross-cycle codebase health data and produce strategic guidance for the upcoming triage cycle."
2. **Score trajectory** — formatted table from ScoreTrajectory
3. **Dimension trajectories** — markdown table: name | trend | headroom | strict | investment
4. **Rework loops** — if any: dimension, resolved count, new open count, affected files
5. **File churn hotspots** — if any: file, resolved count, open count, detectors
6. **Completed clusters** — what was accomplished (names, issue counts, dimensions)
7. **Execution patterns** — skip rate, resolve rate, throughput
8. **Wontfix debt** — trend, worst dimension, gap size
9. **Recurring patterns** — from `detect_recurring_patterns()`
10. **Anti-pattern checklist** — instructions to detect and flag:
    - Repeated refactoring of same area (file churn > 2 cycles)
    - Dimension stagnation despite investment (resolved > 0 but score unchanged)
    - Score-neutral churn (issues resolved but overall score flat)
    - Neglected high-headroom dimensions (headroom > 10 but no recent investment)
    - Growing wontfix debt (especially if concentrated in one dimension)
    - Skip-heavy execution (skip_rate > 0.3 signals unclear priorities)
11. **Output format** — JSON conforming to `StrategistBriefing` schema

## Intent

Add a mandatory "strategize" stage that runs before "observe" in the triage pipeline. An LLM sub-agent analyzes cross-cycle history (progression.jsonl, scan_history, execution_log, commit_log, resolved/recurring work items) and produces a structured `StrategistBriefing` persisted in `epic_triage_meta`. Structured fields are consumed programmatically; prose sections are injected into observe and reflect stage prompts. This prevents rework loops, dimension neglect, and score-neutral churn that individual triage stages can't see.

## Architecture

```
Triage Start
     │
     ▼
┌─────────────┐
│ STRATEGIZE  │  NEW mandatory first stage
│ (LLM agent) │  Reads: scan_history, execution_log, commit_log,
└──────┬──────┘  progression.jsonl, work_items, dimension_scores,
       │         skipped, clusters, queue_order, completed_clusters
       │
       │  Persists StrategistBriefing → epic_triage_meta["strategist_briefing"]
       │  + triage_stages["strategize"] (stage record)
       │
       ▼
┌─────────────┐  ← observe_guidance prose injected
│  OBSERVE    │
└──────┬──────┘
       ▼
┌─────────────┐  ← reflect_guidance prose + structured focus/avoid injected
│  REFLECT    │
└──────┬──────┘
       ▼
┌─────────────┐  ← organize_guidance (focus areas, avoid areas) injected
│  ORGANIZE   │
└──────┬──────┘
       ▼
┌─────────────┐  ← rework warnings passed to value sub-agent
│ SENSE-CHECK │
└──────┬──────┘
       ▼
   ... enrich (unchanged) → commit (unchanged)
```

Prompt structure:
1. **Preamble:** "You are a Big Picture Strategist. Analyze cross-cycle codebase health data and produce strategic guidance for the upcoming triage cycle."
2. **Score trajectory** — formatted table from ScoreTrajectory
3. **Dimension trajectories** — markdown table: name | trend | headroom | strict | investment
4. **Lifecycle inventory** — backlog by dimension, skipped by reason, deferred count, cluster names, promoted count
5. **Rework loops** — if any: dimension, resolved count, new open count, affected files
6. **File churn hotspots** — if any: file, resolved count, open count, detectors
7. **Completed clusters** — what was accomplished (names, theses, issue counts)
8. **Execution patterns** — skip rate, resolve rate, throughput
9. **Wontfix debt** — trend, worst dimension, gap size
10. **Recurring patterns** — from `detect_recurring_patterns()`
11. **Anti-pattern checklist** — instructions to detect and flag:
    - Repeated refactoring of same area (file churn > 2 cycles)
    - Dimension stagnation despite investment (resolved > 0 but score unchanged)
    - Score-neutral churn (issues resolved but overall score flat)
    - Neglected high-headroom dimensions (headroom > 10 but no recent investment)
    - Growing wontfix debt (especially if concentrated in one dimension)
    - Skip-heavy execution (skip_rate > 0.3 signals unclear priorities)
12. **Output format** — JSON conforming to `StrategistBriefing` schema, including `organize_guidance` and `sense_check_guidance` prose fields

An LLM sub-agent analyzes cross-cycle history (progression.jsonl, scan_history, execution_log, resolved/recurring work items) and produces a structured `StrategistBriefing` persisted in `epic_triage_meta`.

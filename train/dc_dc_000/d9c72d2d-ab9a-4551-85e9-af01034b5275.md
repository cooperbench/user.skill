        # Implementation Plan: Phase 7 — Per-project CAS

## Overview

Add a per-project content-addressable store (CAS) at `<project_slug>/.cas/<sha256>` for produced artifacts. When a step's produces check passes, the artifact file is moved into the CAS and replaced by a relative symlink. Identical content from any step reuses the same CAS entry. The CAS is strictly per-project — no shared store across projects.

**Constraint**: Additive only. No new dependencies. Stdlib `hashlib` + `os.symlink`. Existing tests must continue passing.

## Main Phase

### Step 1: Create `artagents/core/task/cas.py` with CAS primitives
**Scope**: Small (new file, ~60 lines)

1. Create `artagents/core/task/cas.py` with three functions:
   - `cas_path(project_dir: Path, sha256_digest: str) -> Path` — returns `<project_dir>/.cas/<sha256_digest>`.
   - `intern(project_dir: Path, source_path: Path) -> Path` — reads `source_path`, computes sha256 hex digest, checks `<project_dir>/.cas/<digest>`. If the CAS entry already exists (directory present), removes `source_path` and returns the CAS path. Otherwise `mkdir(parents=True, exist_ok=True)`, moves `source_path` into the CAS dir (keeping the original basename), and returns the CAS file path. Idempotent.
   - `link_into_produces(cas_file_path: Path, target_path: Path) -> None` — removes `target_path` if it exists, creates parent dirs, then creates a relative symlink `target_path -> <relpath to cas_file>` (using `os.path.relpath`).

2. Errors: `FileNotFoundError` if source doesn't exist, `ValueError` if source is not a regular file.

3. Export all three from `artagents/core/task/__init__.py`.

### Step 2: Extend `produces_check_passed_event` to carry optional `cas_hash`
**Scope**: Small

1. In `artagents/core/task/events.py`, update `make_produces_check_passed_event` to accept `cas_hash: str | None = None`. Include in payload only when not None.

### Step 3: Hook CAS interning into `_run_inline_checks` in gate.py
**Scope**: Small

1. In `_run_inline_checks` (`gate.py` line ~1159), after check passes and before emitting `produces_check_passed`: compute sha256 of artifact, call `intern()`, call `link_into_produces()`, pass `cas_hash` to the event maker.

2. Wrap in try/except: if intern fails (e.g., race), emit `produces_check_failed` instead.

### Step 4: Update `.gitignore`
**Scope**: Tiny

1. Add `**/.cas/` to `.gitignore`.

### Step 5: Write `tests/test_cas_intern.py`
**Scope**: Medium

Tests for CAS primitives: move, idempotency, dedup, error cases, symlink correctness.

### Step 6: Write `tests/test_cas_symlink.py`
**Scope**: Medium

Full produces-flow tests: symlink into `.cas/<sha256>`, event includes `cas_hash`, two steps with identical content share CAS entry.

### Step 7: Write `tests/test_cas_per_project.py`
**Scope**: Small

Two projects, identical content → separate CAS entries per project.

### Step 8: Run full test suite
**Scope**: Validation

Targeted new tests first, then `pytest tests/ -v` for full regressions.

        # Implementation Plan: Phase 7 — Per-project CAS

## Overview

Add a per-project content-addressable store (CAS) at `<project_slug>/.cas/<sha256>` for produced artifacts. The hash **is** the file (flat layout, per `docs/orchestrator-v1-plan.md:33` line 33 and SD-008). When a step's produces check passes, the artifact file is moved into `.cas/<sha256>` and replaced by a relative symlink `<original-path> -> ../../../../.cas/<sha256>`. Identical content from any step reuses the same CAS entry — no duplication. The CAS is strictly per-project — no shared store across projects.

**Constraint**: Additive only. No new dependencies. Stdlib `hashlib` + `os.symlink`. Existing tests must continue passing.

**CAS layout**: Flat files. `intern()` moves the source into `<project_dir>/.cas/<sha256>` (the hash is the filename, no subdirectories). This matches the design-doc exit criterion "Symlinks resolve to `.cas/<sha256>`" and eliminates cross-basename ambiguity (two steps with identical content but different filenames both symlink to the same CAS file by hash).

**`run.py` deviation**: The issue lists `artagents/core/project/run.py` as a file to touch, but `.cas/` lives at the project-root level (parallel to `runs/`), not inside any run directory. The CAS is created on-demand by `intern()` via `mkdir(parents=True, exist_ok=True)` on the `.cas/` parent directory. No change to `run.py` is needed; the on-demand creation is deliberate so CAS init costs are only paid when an artifact is actually interned.

## Main Phase

### Step 1: Create `artagents/core/task/cas.py` with CAS primitives
**Scope**: Small (new file, ~55 lines)

1. Create `artagents/core/task/cas.py` with three functions:
   - `cas_path(project_dir: Path, sha256_digest: str) -> Path` — returns `<project_dir>/.cas/<sha256_digest>`. This is the flat file path where the artifact will live.
   - `intern(project_dir: Path, source_path: Path) -> Path` — reads `source_path`, computes sha256 hex digest, checks if `<project_dir>/.cas/<digest>` already exists. If yes: remove `source_path` (discard the duplicate) and return the existing CAS path. If no: `mkdir(parents=True, exist_ok=True)` on the `.cas/` directory, move `source_path` (via `os.replace` for atomicity) to `<project_dir>/.cas/<digest>`, and return the new CAS path. Idempotent across identical content regardless of original filename.
   - `link_into_produces(cas_file_path: Path, target_path: Path) -> None` — removes `target_path` if it exists, creates parent dirs via `mkdir(parents=True, exist_ok=True)`, then creates a relative symlink `target_path -> <relpath to cas_file_path>` (using `os.path.relpath` so the run directory stays portable).

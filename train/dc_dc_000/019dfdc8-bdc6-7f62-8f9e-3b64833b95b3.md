## Overview
Reigh currently stores custom sequence components as `SequenceComponentMetadata` on `sequence-component` resources, with top-level fields such as `code`, `schemaJson`, `defaultsJson`, `controlsManifest`, `assetSlots`, `clipType`, and `themeId`. Those fields are used by resource metadata (`src/features/resources/hooks/useResources.ts`), the sequence component catalog (`src/tools/video-editor/lib/sequence-component-catalog.ts`), dynamic sequence registration (`src/tools/video-editor/sequences/SequenceComponentRegistryContext.tsx`), materialization, and SequenceCreator save/load behavior.

ArtAgents elements are file-backed definitions with an `element.yaml`/JSON-like manifest plus `component.tsx`, shaped around `id`, `kind`, `schema`, `defaults`, `metadata`, `dependencies`, descriptions, keywords, pack/source provenance, and catalog lookup. The shared layer should be a light TypeScript interop contract plus adapters, not a UI redesign, DB migration, or full ArtAgents file loader.

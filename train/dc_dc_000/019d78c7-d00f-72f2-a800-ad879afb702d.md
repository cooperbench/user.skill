        # Implementation Plan: Test Baselining in Finalize Phase

## Overview

**Problem:** When the megaplan executor runs against a project with pre-existing test failures, it may attempt to fix those failures — even though they're outside the plan's scope. This causes scope creep: the executor burns attempts, triggers no-progress safeguards, or produces unrelated changes.

**Solution:** During the `finalize` phase, capture a test baseline (a snapshot of which tests pass/fail *before* execution begins). Include this baseline in the execution briefing so the executor and reviewer can distinguish pre-existing failures from regressions introduced by the plan.

**Constraint:** The megaplan source code is installed as a Python package (entry point at `/Users/user_c042661f/.pyenv/versions/3.11.11/bin/megaplan`) but the exact source layout is unknown due to sandbox restrictions. Step 1 must locate and audit the source before implementation begins.

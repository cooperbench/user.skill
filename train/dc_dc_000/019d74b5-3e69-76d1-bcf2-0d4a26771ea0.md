        # Implementation Plan: Fix Windows Worker Launch

## Overview
Three distinct issues prevent reliable Windows worker launches:

1. **Guardian `get_vram_info` crash** — `guardian.py:52` calls `subprocess.run(["nvidia-smi", ...])` directly (not through `run_subprocess`) without Windows-safe creation flags. In a daemon process on Windows, subprocess calls without `CREATE_NO_WINDOW` can crash on console handle allocation. Additionally, there's already a cross-platform `get_gpu_memory_usage()` using `torch.cuda` in `heartbeat_utils.py:53-66` that doesn't require subprocess at all.

2. **cmd.exe command generation gaps** — `commandUtils.ts:124-143` (`buildWindowsCmdCommand`) is missing the venv backup prelude and the `.uv-migrated` sentinel creation that both the Linux (`buildLinuxCommand`) and PowerShell (`buildWindowsPowerShellCommand`) paths include.

3. **Import through deprecation shim** — `heartbeat_utils.py:4` imports `from heartbeat_guardian import guardian_main`, routing through the root-level deprecation shim instead of importing directly from `source.runtime.worker.guardian`.

Repos touched: `reigh-worker` (Python), `reigh-app` (TypeScript).

## Phase 1: Fix Guardian VRAM on Windows

### Step 1: Make `get_vram_info` Windows-safe (`reigh-worker/source/runtime/worker/guardian.py`)
**Scope:** Small
1. **Replace** the direct `subprocess.run` call at `guardian.py:54` with `run_subprocess` (already imported at line 14) for consistent binary resolution via `shutil.which`.
2. **Add** `creationflags=subprocess.CREATE_NO_WINDOW` on Windows (`os.name == "nt"`) to the subprocess call, preventing console allocation crashes in daemon processes.
3. **Keep** the existing `except Exception: pass` fallback returning `(0, 0)` — the catch-all is correct for a best-effort VRAM report.

```python
def get_vram_info() -> tuple[int, int]:
    try:
        kwargs = {}
        if os.name == "nt":
            kwargs["creationflags"] = subprocess.CREATE_NO_WINDOW
        result = run_subprocess(
            ["nvidia-smi", "--query-gpu=memory.total,memory.used", "--format=csv,noheader,nounits"],
            capture_output=True,
            text=True,
            timeout=5,
            **kwargs,
        )
        if result.returncode == 0:
            total, used = result.stdout.strip().split(",")
            return int(float(total)), int(float(used))
    except Exception:
        pass
    return 0, 0
```

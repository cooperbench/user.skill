## Overview

DataClaw today is a Python CLI that discovers coding-agent sessions (`claude`/`codex`/`gemini`/`opencode`/`openclaw`/`kimi`/`custom`), anonymizes paths & usernames (`dataclaw/anonymizer.py`), runs regex + entropy redaction (`dataclaw/secrets.py`), writes a single flat `dataclaw_conversations.jsonl`, and pushes `conversations.jsonl` + `metadata.json` + `README.md` to one HF dataset repo (`dataclaw/cli.py:409–456`). Config is a TypedDict at `~/.dataclaw/config.json` (`dataclaw/config.py:8–54`). The publish gate is `confirm` (`dataclaw/cli.py:941–1108`).

This plan: (1) replaces the human `confirm` gate with a policy check so runs can happen automatically on a schedule; (2) augments regex redaction with the `openai/privacy-filter` MoE token classifier whose **new** findings drive the policy; (3) splits the single JSONL into `{bucket}/{source}/YYYY-MM-DD.jsonl` dated shards with per-session-id dedup, per-run staging, manifest-scoped uploads, and an incremental cutoff; (4) lets the user group projects into buckets; (5) wraps it all in a Tauri menubar app.

## User decisions (open — recommendations baked in; user must confirm or override)

**1. Auto-mode default policy — plan defaults to `strict`.** Any new privacy-filter finding blocks the push; user acks via `dataclaw confirm --ack-privacy-findings` or `dataclaw auto --force`. `permissive` (auto-redact + push + surface after) is available via `dataclaw enable-auto --policy permissive`. Rationale: publishing is irreversible and permissive silently launders hits the regex pipeline missed. **Open question: confirm strict, or override to permissive.**

**2. Folder-rules specification style — plan defaults to explicit buckets.** `folder_rules.buckets = {name: [project_key, ...]}` as primary; optional tag fallback via `project_tags` + `buckets_by_tag`. Rationale: explicit lists are a 30-second setup; tag-only forces a from-scratch taxonomy before anything works. **Open question: confirm explicit-first, or require tag-only.**

Both defaults are implemented so work can proceed. If either is overridden, only the default value and help text change — no architectural rework.

## Hard constraints (back-compat + correctness invariants)

- **Legacy function signatures preserved exactly.** `export_to_jsonl(projects, output_path, anonymizer, include_thinking, custom_strings)` and `push_to_huggingface(jsonl_path, repo_id, meta)` keep their current positional shapes — no caller breakage.
- **Sharded exports never overwrite prior sessions.** Same-date shards use per-session-id dedup on write, and when a remote shard already exists at the target path, it is fetched and merged before being rewritten.
- **Uploads are manifest-scoped.** `upload_folder` is invoked with `allow_patterns = [s["path"] for s in manifest["shards"]]` (exact relative paths), not a glob — stale files from prior runs cannot sneak in.
- **Per-run staging dirs**, not a persistent staging root. Each `export_to_shards` writes to `~/.dataclaw/export/runs/{export_id}/`. Blocked runs are preserved; successful runs are kept for a brief debugging window; older runs are garbage-collected.
- **`last_export_cutoff` advances only on push success.**
- **Privacy-filter is opt-in.** Base `pip install dataclaw` must not import `torch`/`transformers`; enforced by `tests/test_import_isolation.py`.
- **`confirm` is directory-aware.** Detects sharded exports via `{root}/.dataclaw/manifest.json`; single-file mode unchanged.
- **Tauri shells out only.** CLI gains `--set-<list>`, `--remove-<list>`, `--show-secrets` verbs so the GUI can round-trip values.
- **User-facing copy stays in sync** across the full `claude|codex|gemini|opencode|openclaw|kimi|custom|all` set.

   ```python
   import time
   from datetime import datetime, timezone
   COOL_DOWN_SECONDS = 24 * 60 * 60

   def _parse_iso(ts: str | None) -> datetime | None:
       if not ts or not isinstance(ts, str): return None
       try:
           s = ts[:-1] + "+00:00" if ts.endswith("Z") else ts
           dt = datetime.fromisoformat(s)
           return dt if dt.tzinfo else dt.replace(tzinfo=timezone.utc)
       except (ValueError, TypeError):
           return None

   def _is_cooled_path(p: Path, now: float | None = None) -> bool:
       try: return (now or time.time()) - p.stat().st_mtime >= COOL_DOWN_SECONDS
       except OSError: return False

   def _is_cooled_ts(ts: str | None, now: float | None = None) -> bool:
       dt = _parse_iso(ts)
       return bool(dt and (now or time.time()) - dt.timestamp() >= COOL_DOWN_SECONDS)
   ```

   ```python
   def _project_candidates(session: dict) -> list[str]:
       out = []
       if session.get("_project_dir_name"): out.append(session["_project_dir_name"])
       p = session.get("project") or ""
       if p:
           out.append(p)
           if ":" in p: out.append(p.split(":", 1)[1])
       return out

   def _bucket_for_project(session, config) -> str | None:
       rules = config.get("folder_rules") or {}
       buckets = rules.get("buckets") or {}
       cands = _project_candidates(session)
       for b, members in buckets.items():
           if any(c in members for c in cands): return b
       tag_map = config.get("project_tags") or {}
       tags = set(); [tags.update(tag_map.get(c, [])) for c in cands]
       if tags:
           for b, btags in (rules.get("buckets_by_tag") or {}).items():
               if tags.intersection(btags): return b
       return rules.get("default_bucket")
   ```

1. **Create** the module (lazy imports, `device`/`min_score` as first-class params):
   ```python
   from __future__ import annotations
   import hashlib, sys
   from dataclasses import dataclass
   from pathlib import Path

   MODEL_ID = "openai/privacy-filter"
   _PIPE_CACHE: dict[str, object] = {}

   @dataclass(frozen=True)
   class Finding:
       kind: str; text: str; start: int; end: int
       score: float; session_id: str; field: str
       def fingerprint(self) -> str:
           return hashlib.sha256(f"{self.kind}|{self.text}".encode()).hexdigest()[:12]

   def is_available() -> bool:
       try:
           import transformers, torch  # noqa
           return True
       except ImportError:
           return False

   def _load(device: str = "auto"):
       """Load as a token-classification pipeline. Transformers' pipeline with
       aggregation_strategy='simple' merges contiguous BIOES spans of the same
       entity type. Exact-Viterbi reproduction is NOT required for our new/known
       diffing because fingerprints hash final text spans, not tag probabilities.
       A contract test (Step 20) verifies pipeline output against canonical
       model-card example strings before we trust the decoder in production."""
       if device in _PIPE_CACHE: return _PIPE_CACHE[device]
       import torch
       from transformers import pipeline
       resolved = ("mps" if torch.backends.mps.is_available() else "cpu") if device == "auto" else device
       print(f"dataclaw: loading {MODEL_ID} on {resolved} (first run downloads ~1.5GB)", file=sys.stderr)
       pipe = pipeline("token-classification", model=MODEL_ID,
                       aggregation_strategy="simple", device=resolved)
       _PIPE_CACHE[device] = pipe
       return pipe

   def scan_text(text: str, session_id: str, field: str, *, device: str = "auto", min_score: float = 0.5) -> list[Finding]:
       pipe = _load(device)
       out = []
       for chunk_start, chunk in _chunk_by_tokens(text, pipe.tokenizer, max_tokens=480):
           for r in pipe(chunk):
               if r["score"] < min_score: continue
               out.append(Finding(kind=r["entity_group"], text=r["word"],
                                  start=chunk_start + r["start"], end=chunk_start + r["end"],
                                  score=float(r["score"]), session_id=session_id, field=field))
       return out

   def scan_session(session: dict, *, device: str = "auto", min_score: float = 0.5) -> list[Finding]: ...
   def scan_shards(root_dir: Path, *, device: str = "auto", min_score: float = 0.5) -> list[Finding]: ...
   def scan_jsonl(path: Path, *, device: str = "auto", min_score: float = 0.5) -> list[Finding]: ...
   ```

3. **Never mutate sessions.** `scan_*` returns `Finding` objects only.

## Risk & tradeoff notes

- **Same-day merge via HF round-trip**: each run that writes to a shard path that already exists on HF performs one `hf_hub_download`. For a typical user with 5–15 source directories, this adds < 3 seconds per run. On network failure, the run aborts rather than silently drop prior sessions.
- **Per-run staging dir vs single persistent dir**: per-run isolates blast radius and lets blocked runs preserve their context for `dataclaw confirm <run_dir>` without contaminating the next run. Cost: GC keeps the 3 most recent runs.
- **Manifest-scoped upload**: explicit `allow_patterns` list of exact paths means stale files cannot be pushed even if they exist in the run dir. Trade-off: uploading 50+ shards adds ~50 strings to the commit's allow-patterns; well within HF Hub's limits.
- **Pipeline-based decoding (locked)**: swapped for hand-rolled Viterbi only if the canonical-inputs contract test (Step 20.5) fails on a minor Transformers release. Fingerprint-based diffing hashes final text spans, so minor decoder-calibration differences don't change the new/known set in practice.
- **Transformers floor**: preflight verification (Step 21) runs at PR time; floor will be bumped if `>=4.57` doesn't actually load the arch.
- **Staging env leaks**: `_ENV_ALLOWLIST` limits what lands in the plist/systemd unit. `HF_TOKEN`, if set, gets copied — this is the same trust boundary as `~/.dataclaw/config.json` (user's own home, 0600).

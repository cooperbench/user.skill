# Implementation Plan: `orchestrator_guidance` Field + Instructions Rewrite

## Overview
Add a computed `orchestrator_guidance` string to the gate response that tells the orchestrator exactly what to do next. Then slim `instructions.md` from ~174 lines to ~70 by removing the manual interpretation guidance that `orchestrator_guidance` replaces.

---

## Step 1: Add `build_orchestrator_guidance()` to `evaluation.py`

Pure function, no LLM call. Signature:

```python
def build_orchestrator_guidance(
    gate_payload: dict,          # recommendation, rationale, signals_assessment
    signals: dict,               # the signals dict from build_gate_signals
    preflight_passed: bool,
    preflight_results: dict,     # {check_name: bool} — for listing failing checks
    robustness: str,
    plan_name: str,              # for exact override commands
) -> str:
```

**Decision logic (first match wins):**

| Condition | Guidance |
|-----------|----------|
| `iteration == 1` | "First iteration — follow gate recommendation: {recommendation}." + contextual hints |
| `PROCEED` + preflight passed | "Plan passed gate and preflight. Proceed to execute." |
| `PROCEED` + preflight failed | "Gate says PROCEED but preflight blocked. Fix: {failing_check_names}." |
| `ESCALATE` + `robustness == "light"` and `weighted_score <= 4.0` | "Auto-force-proceed eligible. Run: `megaplan override force-proceed --plan {plan_name} --reason \"light robustness, score {score}\"`" |
| `ESCALATE` otherwise | "Gate escalated. Ask the user: force-proceed, add-note, or abort." |
| `ITERATE` + plateaued + recurring critiques | "Score plateaued with recurring critiques the loop can't fix. Consider force-proceeding: `megaplan override force-proceed --plan {plan_name}`" |
| `ITERATE` + improving (score decreased) | "Score improving ({prev} → {current}). Continue to revise." |
| `ITERATE` + worsening (score increased) | "Score worsening ({prev} → {current}). Investigate — the loop may be diverging." |
| `ITERATE` fallthrough | "Gate recommends another iteration. Revise the plan." |

**Contextual hints appended (all that apply):**
- Unresolved flags exist → "Verify unresolved flags against the plan and project code before accepting."
- Recurring critiques non-empty → "Recurring critiques ({list}) — the loop likely can't fix these; judge if they're real blockers."
- Scope creep flags exist → "Scope creep detected — compare current plan against original idea."

**Plateau detection** (inline): `weighted_history` has >= 1 prior entry and `weighted_score >= weighted_history[-1]`.

## Step 2: Wire into both `build_gate_artifact()` call sites in `cli.py`

### `build_gate_artifact()` changes:
- Add parameter: `orchestrator_guidance: str = ""`
- Add `"orchestrator_guidance": orchestrator_guidance` to the returned dict

### `handle_gate()` changes (line ~715):
- After building `signals_artifact` and getting `worker_payload`, call:
  ```python
  guidance = build_orchestrator_guidance(
      gate_payload=worker_payload,
      signals=signals_artifact["signals"],
      preflight_passed=all(signals_artifact["preflight_results"].values()),
      preflight_results=signals_artifact["preflight_results"],
      robustness=signals_artifact.get("robustness", "standard"),
      plan_name=state["name"],
  )
  ```
- Pass `orchestrator_guidance=guidance` to `build_gate_artifact()`

### `_override_force_proceed()` changes (line ~990):
- Call `build_orchestrator_guidance()` with the synthetic PROCEED payload and `override_forced=True` context. Since this is a user-initiated force-proceed, the guidance is straightforward: "Override applied. Proceed to execute."
- Simpler approach: pass a static string directly: `orchestrator_guidance="Force-proceed override applied. Proceed to execute."`
- Pass to `build_gate_artifact(..., orchestrator_guidance=...)`

### `StepResponse` TypedDict update (`_core.py`):
- Add `orchestrator_guidance: str` to `StepResponse`

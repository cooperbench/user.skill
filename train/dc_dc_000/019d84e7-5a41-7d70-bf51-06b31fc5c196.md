        # Implementation Plan: Snap-to-Edge Overlap Resolution for Timeline Drops

## Overview

When a clip is dropped onto a track that has an existing clip at the drop position, the current behavior (`findNearestFreeTrack`) immediately searches for a different track. The goal is to first try resolving the overlap by snapping the dropped clip to the nearest edge of the overlapping clip — keeping it on the same track — and only fall back to track switching if snapping can't work.

**Core change:** A new utility function `trySnapToEdge` in `coordinate-utils.ts`, called before `findNearestFreeTrack` at all 5 call sites. It accepts pre-filtered rows (same contract as `findNearestFreeTrack`), checks for overlap, and returns an adjusted time if the drop can snap to a nearby sibling edge.

**Preview/commit parity:** `computeDropPosition` returns the snapped time in both `DropPosition.time` and `screenCoords.clipLeft`. The indicator in `useDragCoordinator.ts:66-86` renders directly from these fields. The subsequent `snapDrag` in `useClipDrag.ts:216-223` receives the already-snapped time — since it's aligned to an edge that `snapDrag` also collects, `snapDrag` is a no-op (distance=0 < threshold). Therefore preview and commit agree. No changes needed to `useClipDrag.ts` or `useDragCoordinator.ts`.

**Threshold:** Use the dragged clip's own duration as the default threshold. If the nearest free edge requires moving more than one clip-length from the drop point, fall back to `findNearestFreeTrack`. This is larger than visual snap (8px) since overlap resolution is a placement conflict, not visual alignment, but still bounded to avoid jarring jumps. Callers can pass a custom threshold.

## Phase 1: Core Utility

### Step 1: Implement `trySnapToEdge` in `coordinate-utils.ts`
**Scope:** Medium

1. **Add** a new exported function after `findNearestFreeTrack` (~line 168) in `coordinate-utils.ts`:
   ```ts
   export const trySnapToEdge = (
     rows: { id: string; actions: { start: number; end: number; id: string }[] }[],
     trackId: string,
     time: number,
     duration: number,
     excludeClipIds?: string | Set<string>,
     thresholdS?: number,
   ): { time: number; snapped: boolean }
   ```

2. **Logic:**
   - Find the row matching `trackId`. Build the sibling list (excluding `excludeClipIds`, supporting `string | Set<string> | undefined` — same normalization pattern as `findNearestFreeTrack:134-138`).
   - Check if `[time, time+duration)` overlaps any sibling. If no overlap, return `{ time, snapped: false }`.
   - If overlapping, collect candidate snap positions from **all** siblings' edges (not just overlapping ones, since snapping to a non-overlapping sibling's edge can also resolve the overlap):
     - For each sibling: `candidate = sibling.end` (snap clip start to right edge) and `candidate = sibling.start - duration` (snap clip end to left edge).
   - Filter candidates: `candidate >= 0` and `[candidate, candidate+duration)` overlaps NO sibling.
   - Among valid candidates, pick the one nearest to original `time`. If `|candidate - time| > thresholdS` (default: `duration`), reject.
   - Return `{ time: candidate, snapped: true }` or `{ time, snapped: false }`.

3. **Key contract:** The function operates on the `rows` it is given. Group callers that pre-strip members via `rowsWithoutGroup` pass their filtered rows, so group clips don't block their own snap candidates. This matches `findNearestFreeTrack`'s existing contract.

4. **Performance:** O(n) to find overlapping siblings, O(n) candidates × O(n) overlap check = O(n²). With n typically <20 clips per track, this is negligible on every pointer move.

**Scope:** Small

   - No overlap → `{ snapped: false }`, original time.
   - Overlap, room after sibling → snaps to `sibling.end`.
   - Overlap, room before sibling → snaps to `sibling.start - duration`.
   - Overlap, both edges valid → picks nearest to original time.
   - Overlap, snapped position would overlap another sibling → `{ snapped: false }`.
   - Clip at t=0, sibling starts at 0 → can't snap left (candidate < 0), tries right.
   - Multiple overlapping siblings → picks nearest valid edge across all.
   - Exact fit in gap between two siblings → snaps to gap start.
   - `excludeClipIds` as string → correctly excludes single clip.
   - `excludeClipIds` as Set → correctly excludes all dragged clips.
   - `excludeClipIds` undefined → no exclusions (asset drop case).
   - Threshold exceeded → `{ snapped: false }`, falls through.
   - Custom threshold → respects override.

        # Implementation Plan: Right-Click Context Menu for Gallery/Timeline Selection Actions

## Overview

**Goal:** Add a right-click context menu on selected gallery and timeline items with "Create Shot" and "Generate Video" actions, plus button-based equivalents.

**Current state:**
- Gallery selection: `GallerySelectionContext` manages `selectedGalleryIds` / `gallerySelectionMap` / `selectedGalleryClips` — no context menu exists on gallery items.
- Timeline selection: `useMultiSelect` in video editor — ClipAction.tsx already has a custom portal-based context menu with delete/split/mute actions.
- Shot creation: `useCreateShot()` creates a shot; `addImageToShotHelpers.ts` adds **one** image at a time (no batch add).
- Video generation modal: `VideoGenerationModal` takes `{ isOpen, onClose, shot: Shot }`.
- No shadcn context-menu primitive installed; timeline uses a custom portal + fixed-position div.

**Key constraint:** Gallery and timeline have separate selection systems. "Both contexts" means reading from whichever system has a selection, not a unified cross-context selection.

---

## Phase 1: Foundation — Batch Add Hook + Create-Shot-From-Selection Hook

### Step 1: Create batch add-images-to-shot helper (`src/shared/hooks/shots/addImageToShotHelpers.ts`)
**Scope:** Small
1. **Add** a `batchInsertUnpositionedShotGenerations(shotId, generationIds[], projectId)` function that calls the existing single-image RPC in a loop (or a new batch RPC if one exists). Check `supabase/migrations/` for an existing batch insert RPC first.
2. **Fallback**: If no batch RPC, use `Promise.all` over `insertUnpositionedShotGeneration()` for each item. This is acceptable for small batches (< 20 items).

### Step 2: Create `useCreateShotFromSelection` hook (`src/shared/hooks/shots/useCreateShotFromSelection.ts`)
**Scope:** Medium
1. **Implement** a hook that:
   - Accepts an array of `{ generationId: string; url: string; thumbUrl?: string }` items
   - Creates a new shot via `useCreateShot()` with an auto-generated name (e.g. "Shot from N items")
   - Batch-adds all items to the new shot using Step 1's helper
   - Returns the new `Shot` object
   - Exposes `{ createShotFromItems, isCreating }` 
2. **Wire** React Query invalidation for shots list after creation.

### Step 3: Create `useGenerateVideoFromSelection` hook (`src/shared/hooks/shots/useGenerateVideoFromSelection.ts`)
**Scope:** Small
1. **Implement** a thin wrapper that:
   - Calls `useCreateShotFromSelection` to create the shot
   - Returns the new shot so the caller can open `VideoGenerationModal` with it
   - Exposes `{ createShotAndOpenModal, isCreating, pendingShot }` where `pendingShot` is the shot to pass to the modal

---

## Phase 2: Gallery Context Menu

### Step 4: Create shared `SelectionContextMenu` component (`src/shared/components/SelectionContextMenu.tsx`)
**Scope:** Medium
1. **Build** a portal-based context menu component following the existing pattern in `ClipAction.tsx` (fixed position, createPortal to document.body, click-away/Escape dismissal).
2. **Props:**
   ```tsx
   {
     position: { x: number; y: number } | null;  // null = hidden
     onClose: () => void;
     selectedCount: number;
     onCreateShot: () => void;
     onGenerateVideo: () => void;
   }
   ```
3. **Menu items:** "Create Shot" (with item count badge) and "Generate Video" (with item count badge). Use lucide icons (`Film`, `Clapperboard` or similar).
4. **Style** using existing Tailwind patterns (`bg-popover`, `text-popover-foreground`, `border`, `rounded-md`, `shadow-md`).

### Step 5: Wire context menu into `GenerationsPaneGallery` (`src/features/gallery/components/GenerationsPane/components/GenerationsPaneGallery.tsx`)
**Scope:** Medium
1. **Add** `onContextMenu` handler to the gallery grid area (or delegate from `MediaGalleryItem`). The handler should:
   - Check if right-clicked item is in `selectedGalleryIds`; if not, select it first (matching ClipAction behavior)
   - Set context menu position state
   - Prevent default browser context menu
2. **Pass** the `onContextMenu` callback through `MediaGallery` → `MediaGalleryGrid` → `MediaGalleryItem` via the existing `ItemActions` type or a new prop on `MediaGallery`.
3. **Render** `SelectionContextMenu` with actions wired to the hooks from Phase 1.
4. **After** "Create Shot": clear selection, show the new shot (navigate or toast).
5. **After** "Generate Video": clear selection, open `VideoGenerationModal` with the new shot.

### Step 6: Add `VideoGenerationModal` rendering in gallery context (`src/features/gallery/components/GenerationsPane/components/GenerationsPaneGallery.tsx` or parent)
**Scope:** Small
1. **Add** local state `{ isVideoModalOpen, videoModalShot }` to manage the modal lifecycle.
2. **Render** `<VideoGenerationModal isOpen={isVideoModalOpen} onClose={...} shot={videoModalShot} />` conditionally.
3. **Import** from `src/tools/travel-between-images/components/VideoGenerationModal.tsx`.

---

## Phase 3: Timeline Context Menu Extension

### Step 7: Extend timeline ClipAction context menu (`src/tools/video-editor/components/TimelineEditor/ClipAction.tsx`)
**Scope:** Small
1. **Add** "Create Shot from Selection" and "Generate Video" menu items to the existing context menu, gated on `selectedClipIds.size >= 1`.
2. **Resolve** selected clip IDs → generation IDs using the asset registry (`ClipMeta.asset` → `AssetRegistry` → `generationId`). Filter out clips without generation assets.
3. **Wire** to the same `useCreateShotFromSelection` / `useGenerateVideoFromSelection` hooks.
4. **Add** `VideoGenerationModal` rendering in `TimelineEditor` or `VideoEditorShell` with the same pattern as Step 6.

---

## Phase 4: Button-Based Alternatives

### Step 8: Add selection action bar to gallery (`src/features/gallery/components/GenerationsPane/components/GenerationsPaneGallery.tsx`)
**Scope:** Medium
1. **Add** a floating action bar (or toolbar row) that appears when `selectedGalleryIds.size > 0`.
2. **Include** "Create Shot" and "Generate Video" buttons, wired to the same hooks.
3. **Position:** Bottom of the gallery pane or top toolbar, matching existing UI patterns. Check if there's already a selection-dependent UI element to extend.

### Step 9: Validate and test
**Scope:** Small
1. **Run** existing tests: `vitest run` for any gallery/shot tests.
2. **Manual smoke test** the following flows:
   - Single gallery item → right-click → Create Shot
   - Multi-select gallery items → right-click → Create Shot
   - Multi-select gallery items → right-click → Generate Video → modal opens with new shot
   - Timeline multi-select → right-click → Create Shot
   - Button-bar equivalents of above
3. **Verify** context menu dismisses on click-away, Escape, and after action completes.
4. **Verify** no regressions to existing gallery selection, lasso selection, or timeline context menu.

---

## Execution Order
1. Phase 1 (Steps 1–3) first — foundational hooks with no UI changes.
2. Phase 2 (Steps 4–6) — gallery context menu, the primary deliverable.
3. Phase 3 (Step 7) — timeline extension, leveraging same hooks.
4. Phase 4 (Steps 8–9) — button alternatives + validation.

## Validation Order
1. Unit-test the batch add helper and create-shot-from-selection hook.
2. Manual test gallery context menu flows.
3. Manual test timeline context menu flows.
4. Run full test suite to catch regressions.

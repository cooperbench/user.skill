The right deep move is to treat this as a distributed protocol, not shared application logic. Right now Reigh has three independently deployed programs speaking an implicit protocol through Postgres rows, JSONB, route strings, worker metadata, and edge-function payloads. That protocol has no owner, no compiler, no version negotiation, and no release gate. So the system is behaving exactly like an unversioned distributed system behaves: asymmetric rollout creates silent incompatibility. I would create a **single control-plane contract artifact** and make every surface consume it.

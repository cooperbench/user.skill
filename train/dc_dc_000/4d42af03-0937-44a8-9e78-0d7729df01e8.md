**Summary:**

This hook manages lightbox transition overlay state to prevent visual flashes when navigating between different lightbox types (image ↔ segment). Key features:

1. **State Management:**
   - `isLightboxTransitioning`: Boolean tracking whether a transition is in progress
   - `transitionOverlayRef`: Direct DOM ref for synchronous overlay control

2. **Core Functions:**
   - `showTransitionOverlay()`: Instantly shows overlay via DOM manipulation (bypassing React's async state batching)
   - `hideTransitionOverlay()`: Fades out overlay over 150ms then hides it
   - `navigateWithTransition(doNavigation)`: Orchestrates the transition by showing overlay, using double requestAnimationFrame to ensure paint, then executing navigation

3. **Safety Features:**
   - Adds/removes `lightbox-transitioning` class on document.body
   - 500ms safety timeout to prevent overlay getting stuck
   - Ensures body scroll is restored after transition ends (100ms delay)
   - Cleanup effects remove the transition class and restore scroll when not transitioning

The hook uses a combination of synchronous DOM manipulation (for immediate visual feedback) and requestAnimationFrame for proper timing with the browser's rendering cycle.

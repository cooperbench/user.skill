## The core mechanic

Hunyuan-Foley generates one audio track for one video clip — it has no concept of "region." To get *spatial* Foley you have to make the spatial split yourself: **crop the video into tiles, run each tile through Foley independently, then mix the resulting tracks in the browser based on where the viewport is looking.** The Foley model only "hears" what's in the crop, so a tile of just the creature's mouth gets mouth-sounds; a tile of swirling water gets water.

## Design decisions, in order of how much they matter

1. **Tile grid.** For 3072×3840, a 2×3 (six tiles, ~1536×1280 each) is the sweet spot — small enough that each tile has a distinct subject, large enough that Foley still has semantic context. 3×4 (twelve tiles) gives finer spatial resolution but doubles cost and risks Foley generating generic ambience for tiles that are too zoomed-in to read. **Overlap the tiles by ~25%** so neighboring tracks share content and crossfades sound continuous instead of seamed.

2. **Temporal handling.** Hunyuan-Foley's per-call limit is ~10–15s; 18.8s is borderline. Either trim to 15s, or split each tile into two ~9.4s halves and concatenate. One call per tile is much simpler — I'd start by trimming.

3. **Zoom as a separate layer, not a continuum.** Don't try to interpolate Foley between zoom levels. Generate **two passes**: (a) one global Foley for the full frame, (b) the tile grid. When the user is zoomed out, you hear the global track; as they zoom past some threshold, you crossfade into the local tile mix. Trying to do 3+ zoom levels multiplies cost without proportional payoff.

4. **Browser playback.** Web Audio API. One `<audio>` (or `AudioBufferSourceNode`) per tile, all started in sync, all looping the 15s clip. A `GainNode` per tile whose value is a function of distance from viewport center to tile center (gaussian falloff works well). Pan/zoom updates gains every animation frame. The video element sits underneath with `pointer-events` driving a CSS transform for pan/zoom.

5. **Sync.** All tile clips and the video must be frame-locked. Drive everything off a single `requestAnimationFrame` clock and `currentTime`-set the audio nodes; don't trust independent `<audio>` elements to stay in sync.

- 6 tiles + 1 global = 7 Foley calls per pass. Cheap, but you'll iterate — budget for ~5 passes while tuning crops.
- Foley quality degrades when the crop is visually ambiguous (pure texture, no subject). Expect 1–2 tiles to come back as generic noise; you may need to re-roll those or accept them as ambient.
- The existing audio track on the source — decide upfront whether you're *replacing* it or *layering* the Foley over it. Replacing is cleaner for the spatial concept.

# ArtAgents

A file-based toolkit for agents to make art and creative work alongside a human.

Three kinds of beings live here:

- **Executors** — run one concrete unit of work
- **Orchestrators** — coordinate executors (and other orchestrators) into workflows
- **Elements** — reusable render building blocks (effects, animations, transitions)

`python3 -m artagents` is the executable package gateway. Every summons passes through this one gate.

## First commands

Run from the repository root:

```bash
git status --short
python3 -m artagents --help
python3 -m artagents doctor
python3 -m artagents orchestrators list
python3 -m artagents executors list
python3 -m artagents elements list
python3 -m artagents setup
```

`setup` is dry-run by default; pass `--apply` to mutate.

## Using tools

Find an id:

```bash
python3 -m artagents [executors|orchestrators|elements] list
```

Inspect to see inputs, outputs, and intent:

```bash
python3 -m artagents [executors|orchestrators|elements] inspect <id> --json
```

Run it:

```bash
python3 -m artagents [executors|orchestrators] run <id> -- <args>
```

Each tool has its own `STAGE.md` next to its `run.py`. That is the source of truth — read it before invoking. The JSON inspect output points at the folder root and `stage_file`; load only the one relevant `STAGE.md`, not all of them.

At the start of any session that will produce runs, run python3 -m artagents thread show @active first. The [thread] prefix on every command output is your continuous indicator; if it shows the wrong thread, run thread new or pass --thread @new to your next command. Selections are append-only; the most recent write is authoritative on read; prior selections are preserved as history but do not affect current keepers.

Before rendering an iteration video, run `python3 -m artagents.packs.builtin.iteration_video.run inspect <thread>` to see modalities, renderers, quality, cache counts, and estimated cost without rendering.

## Make something new

Read `docs/creating-tools.md`, then follow this build order — every step before falling back to the next:

1. **Compose existing executors first.** `python3 -m artagents executors list` and `inspect` the candidates. If existing executors can be wired together to do the job, build only an orchestrator that calls them.
2. **Create the missing executors next.** Each new executor must do *one* concrete, focused unit of work — independently runnable, inspectable, and testable. Don't pack workflow logic into an executor; that belongs in an orchestrator.
3. **Then write the orchestrator.** It composes the executors (existing + newly created) into the workflow. Orchestrators may call other orchestrators; executors must not.

Skipping step 1 to write a god-orchestrator that bakes in network calls and business logic is the anti-pattern. Suspect it whenever a `run.py` grows past a couple of hundred lines without delegating to executors.

Templates:

- `docs/templates/executor/` — one concrete unit of work
- `docs/templates/orchestrator/` — a workflow that combines executors
- `docs/templates/element/` — a reusable render building block

Content lives under packs at `artagents/packs/<pack>/`. Executor folders use the layout `artagents/packs/<pack>/<slug>/{executor.yaml,STAGE.md,run.py}` and orchestrator folders use `artagents/packs/<pack>/<slug>/{orchestrator.yaml,STAGE.md,run.py}`, with optional local `src/` modules. Element folders live at `artagents/packs/<pack>/elements/<kind>/<id>/{component.tsx,element.yaml}` (kind ∈ {effects, animations, transitions}). Top-level `artagents/*.py` files are shared libraries or system commands, not alternate runnable implementations. Executor and orchestrator ids are always qualified — `<pack>.<name>` (e.g. `builtin.cut`, `external.vibecomfy.run`); bare ids are rejected.

Do not chain pipeline internals by hand unless you are debugging one specific stage. If the user gives a topic instead of a brief, use a brief-generation executor coordinated by an orchestrator — don't fake source media just to enter a source-video path. Render requires the `hype.timeline.json` and `hype.assets.json` pair produced by cut; don't skip cut unless both files already exist.

44	def _parse_timestamp(value: str) -> float:
45	    raw = value.strip()
46	    if not raw:
47	        _die("empty timestamp")
48	    if ":" not in raw:
49	        return float(raw)
50	    parts = [float(part) for part in raw.split(":")]
51	    if len(parts) == 2:
52	        minutes, seconds = parts
53	        return minutes * 60 + seconds
54	    if len(parts) == 3:
55	        hours, minutes, seconds = parts
56	        return hours * 3600 + minutes * 60 + seconds
57	    _die(f"invalid timestamp: {value}")
58	    return 0.0

205	def _crop_box(width: int, height: int, aspect_width: int, aspect_height: int, position: str) -> tuple[int, int, int, int]:
206	    target_ratio = aspect_width / aspect_height
207	    source_ratio = width / height
208	    if source_ratio > target_ratio:
209	        crop_h = height
210	        crop_w = int(round(height * target_ratio))
211	        if position in {"left", "top-left", "bottom-left"}:
212	            x = 0
213	        elif position in {"right", "top-right", "bottom-right"}:
214	            x = width - crop_w
215	        else:
216	            x = (width - crop_w) // 2
217	        y = 0
218	    else:
219	        crop_w = width
220	        crop_h = int(round(width / target_ratio))
221	        if position in {"top", "top-left", "top-right"}:
222	            y = 0
223	        elif position in {"bottom", "bottom-left", "bottom-right"}:
224	            y = height - crop_h
225	        else:
226	            y = (height - crop_h) // 2
227	        x = 0
228	    return x, y, x + crop_w, y + crop_h

374	def run(args: argparse.Namespace) -> int:
375	    if args.max_images < 1 or args.max_images > DEFAULT_MAX_IMAGES:
376	        _die(f"--max-images must be between 1 and {DEFAULT_MAX_IMAGES}")
377	    frames, image_for_query = _collect_inputs(args)
378	    primary_model = args.model or MODEL_PRESETS[args.mode]
379	    models = [primary_model, *args.compare_model]
380	    payload_preview = {
381	        "endpoint": API_URL,
382	        "models": models,
383	        "query": args.query,
384	        "image": str(image_for_query),
385	        "frames": [{"index": index, "path": str(path), "label": label} for index, (path, label) in enumerate(frames, start=1)],
386	        "detail": args.detail,
387	    }
388	    if args.dry_run:
389	        print(json.dumps(payload_preview, indent=2))
390	        return 0
391	
392	    api_key = load_api_key(args.env_file)
393	    results: list[dict[str, Any]] = []
394	    for model in models:
395	        print(f"querying={model} image={image_for_query}", file=sys.stderr)
396	        started = time.time()
397	        try:
398	            response = _call_responses_api(
399	                api_key=api_key,
400	                model=model,
401	                query=args.query,
402	                image_path=image_for_query,
403	                detail=args.detail,
404	                max_output_tokens=args.max_output_tokens,
405	                timeout=args.timeout,
406	            )
407	            result = {
408	                "model": model,
409	                "status": "ok",
410	                "elapsed_sec": round(time.time() - started, 2),
411	                "answer": _response_text(response),
412	                "usage": response.get("usage"),
413	                "response_id": response.get("id"),
414	            }
415	        except Exception as exc:
416	            result = {
417	                "model": model,
418	                "status": "error",
419	                "elapsed_sec": round(time.time() - started, 2),
420	                "error": f"{type(exc).__name__}: {exc}",
421	            }
422	        results.append(result)
423	
424	    output = {**payload_preview, "results": results}
425	    text = json.dumps(output, indent=2)
426	    print(text)
427	    if args.out:
428	        args.out.parent.mkdir(parents=True, exist_ok=True)
429	        args.out.write_text(text + "\n", encoding="utf-8")
430	        print(f"wrote={args.out}", file=sys.stderr)
431	    return 0 if all(result["status"] == "ok" for result in results) else 1

61	    if spec.lower() == "all":
62	        return list(range(1, total + 1))
63	    picked: list[int] = []
64	    for token in spec.split(","):
65	        token = token.strip()
66	        if not token:
67	            continue
68	        if "-" in token:
69	            lo, hi = token.split("-", 1)
70	            a, b = int(lo), int(hi)
71	            if a < 1 or b < a or b > total:
72	                raise argparse.ArgumentTypeError(f"--cells range '{token}' out of bounds (1..{total})")
73	            picked.extend(range(a, b + 1))
74	        else:
75	            n = int(token)
76	            if n < 1 or n > total:
77	                raise argparse.ArgumentTypeError(f"--cells '{n}' out of bounds (1..{total})")
78	            picked.append(n)
79	    seen: set[int] = set()
80	    unique: list[int] = []
81	    for n in picked:
82	        if n not in seen:
83	            seen.add(n)
84	            unique.append(n)
85	    if not unique:
86	        raise argparse.ArgumentTypeError("--cells parsed to empty list")
87	    return unique

119	    from PIL import Image
120	
121	    out_dir.mkdir(parents=True, exist_ok=True)
122	    img = Image.open(grid_path).convert("RGB")
123	    W, H = img.size
124	    cw, ch = W // cols, H // rows

471	def main(argv: Sequence[str] | None = None) -> int:
472	    parser = build_parser()
473	    args = parser.parse_args(argv)
474	    _validate_args(parser, args)
475	
476	    out_root = args.out.expanduser().resolve()
477	    out_root.mkdir(parents=True, exist_ok=True)
478	    cells_dir = out_root / "source_cells"
479	    refs_dir = out_root / "refs"
480	
481	    rows, cols = detect_source_layout(args.from_path, args.source_rows, args.source_cols)
482	    total_cells = rows * cols
483	    picks = parse_cells(args.cells, total_cells)
484	    cells = slice_grid(args.from_path, rows, cols, cells_dir)
485	    refs = write_refs(cells, picks, refs_dir)
486	
487	    plan = {
488	        "tool": "vary_grid",
489	        "version": 1,
490	        "mode": "dry-run" if args.dry_run else "run",
491	        "from": str(args.from_path.resolve()),
492	        "source_layout": {"rows": rows, "cols": cols, "total": total_cells},
493	        "cells_spec": args.cells,
494	        "picked_cells": picks,
495	        "ref_paths": [r["path"] for r in refs],
496	        "ideas": args.ideas,
497	        "count": args.count,
498	        "size": args.size,
499	        "quality": args.quality,
500	        "output_format": args.output_format,
501	        "fal_edit_model_id": FAL_EDIT_MODEL_ID,
502	        "fireworks_model": None if args.no_kimi else args.model,
503	        "out": str(out_root),
504	    }
505	    write_json(out_root / "vary-plan.json", plan)
506	
507	    if args.no_kimi:
508	        concepts: list[dict[str, Any]] = []
509	        concepts_payload = {"mode": "no-kimi", "concepts": []}
510	        grid_prompt = build_no_kimi_prompt(args.ideas, args.count, len(refs))
511	    elif args.dry_run:
512	        concepts = _planned_concepts(args.ideas, args.count)
513	        concepts_payload = {"mode": "dry-run", "concepts": concepts, "raw_response": None}
514	        grid_prompt = build_grid_prompt(args.ideas, concepts, len(refs))
515	    else:
516	        fireworks_key = _load_env_var("FIREWORKS_API_KEY", args.env_file)
517	        response = call_kimi_variations(
518	            ideas=args.ideas,
519	            count=args.count,
520	            ref_count=len(refs),
521	            model=args.model,
522	            api_key=fireworks_key,
523	        )
524	        raw = parse_concepts(response, count=args.count)
525	        concepts = renumber_concepts(raw)
526	        concepts_payload = {
527	            "mode": "run",
528	            "model": args.model,
529	            "usage": response.get("usage"),
530	            "concepts": concepts,
531	        }
532	        grid_prompt = build_grid_prompt(args.ideas, concepts, len(refs))
533	
534	    write_json(out_root / "concepts.json", concepts_payload)
535	    write_json(
536	        out_root / "prompts.json",
537	        {
538	            "fal_edit_model_id": FAL_EDIT_MODEL_ID,
539	            "size": args.size,
540	            "quality": args.quality,
541	            "ref_count": len(refs),
542	            "grid_prompt": grid_prompt,
543	            "concepts": [
544	                {"candidate_id": c["candidate_id"], "name": c.get("name"), "prompt": c["prompt"]}
545	                for c in concepts
546	            ] if concepts else None,
547	        },
548	    )

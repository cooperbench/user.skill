        # Implementation Plan: Add Cameraman IC LoRA mode for LTX2.3 Distilled

## Overview

The goal is to add a `cameraman` guidance mode for LTX2.3 distilled that provides camera motion control via the Cameraman IC LoRA, and remove the `uni3c` option from the distilled LTX guidance mode list in the frontend.

**Current state:** LTX2.3 distilled supports guidance modes `['video', 'pose', 'depth', 'canny', 'uni3c']`. The `uni3c` mode uses a completely different guidance system (kind=`uni3c`) from the other LTX modes (kind=`ltx_control`). The IC LoRA union control file (`ltx-2.3-22b-ic-lora-union-control-ref0.5.safetensors`) is already loaded for `pose`, `depth`, and `canny` modes.

**Approach:** Add `cameraman` as a new mode under the existing `ltx_control` kind. It will use raw frames (no preprocessing, like `video` mode) but WITH the IC LoRA loaded (like `pose`/`depth`/`canny`). The video prompt type will be `"VG"` (same as other `ltx_control` modes). Replace `uni3c` with `cameraman` in the `DISTILLED_LTX_GUIDANCE_MODES` list — `uni3c` remains valid as a kind for WAN models and the backend still parses it; it's just no longer offered in the distilled LTX UI.

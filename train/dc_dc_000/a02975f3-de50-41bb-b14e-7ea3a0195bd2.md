## Overview

Phase 7 adds a per-project content-addressable store at `<slug>/.cas/<sha256>`. After a produces check passes, the artifact file is moved into `.cas/<hash>` and replaced with a relative symlink. Identical content from different steps shares the same CAS entry. The CAS is strictly per-project — there is no shared CAS across projects.

**Current state:** The produces flow in `_run_inline_checks()` (gate.py:1110) runs checks against artifact files written into `step_dir`. When checks pass, a `produces_check_passed` event is appended. The file stays in place as a regular file. There is no deduplication or content-addressing.

**Target state:** After a produces check passes, the file is interned into `.cas/<sha256>`, a relative symlink replaces the original path, and the `produces_check_passed` event includes the CAS hash.

**Constraints:** Additive only. No new dependencies. Per-project CAS — no shared CAS. stdlib `hashlib` + `os.symlink`.

## Main Phase

### Step 1: Create the CAS module (`artagents/core/task/cas.py`)

**Scope:** Medium — new file

1. **Implement** three public functions:

   - `cas_path(project_dir: Path, sha256: str) -> Path` — returns `<project_dir>/.cas/<sha256>`. The sha256 is the hex digest (no prefix). The `.cas/` directory path derives from the project directory (not projects root), which is the `<slug>` subdir under the projects root.

   - `intern(project_dir: Path, source_path: Path) -> tuple[Path, str, bool]` — computes the SHA-256 of `source_path`, moves it into `.cas/<hash>` (creating `.cas/` if needed), returns `(cas_path, hex_digest, was_new)`. If the hash already exists, `source_path` is removed (discarded) and `was_new=False`; the existing CAS entry is preserved. The move is atomic-ish: write to temp then rename so no partial `.cas/` entries.

   - `link_into_produces(cas_path: Path, target_path: Path) -> None` — creates a relative symlink at `target_path` pointing to `cas_path`. Computes the relative path from `target_path.parent` to `cas_path` so the run directory stays portable. Removes `target_path` first if it exists (it should — it's the original file).

   - Helper: `_sha256_file(path: Path) -> str` — reads file in chunks and returns hex digest (no prefix). Uses `hashlib.sha256()`.

2. **Edge cases:**
   - Empty file: hashes correctly (sha256 of empty bytes).
   - Large file: chunked read (64KB buffer).
   - Concurrent identical interns: second call finds hash exists, discards source.
   - Target path parent dirs may not exist for symlink — `link_into_produces` should ensure `target_path.parent.mkdir(parents=True, exist_ok=True)`.

### Step 2: Wire CAS into the produces flow (`artagents/core/task/gate.py`)

**Scope:** Small — targeted insertions in `_run_inline_checks()`

1. **Import** `cas.intern` and `cas.link_into_produces` at the top of `gate.py` (around line 50-60 where other task imports are).

2. **Insert** CAS interning into `_run_inline_checks()` after each `make_produces_check_passed_event` call (line 1161):

   - Call `link_into_produces(cas_entry, artifact_path)` to replace the file with a symlink.
   - The code already imported `hashlib` — that stays for plan hashing.

3. **Update** `make_produces_check_passed_event` signature or the event emitted inline: include `cas_hash` in the event payload. Two approaches:
   - (a) Add `cas_hash` as an optional param to `make_produces_check_passed_event` in `events.py`, defaulting to `None` for back-compat. Pass the hex digest when calling from `_run_inline_checks`.

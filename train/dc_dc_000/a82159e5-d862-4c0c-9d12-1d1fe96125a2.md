# Implementation Plan: Phase 7 — Per-Project CAS for Produces Artifacts

## Overview
Phase 7 adds a per-project content-addressable store (CAS) at `<project_dir>/.cas/<sha256>` and rewrites every produces-checked file artifact to a relative symlink that points at its CAS entry. The CAS is **per-project, never shared** (SD-008, SD-029). Implementation is additive: a new `artagents/core/task/cas.py` module supplies `intern` / `link_into_produces` helpers, and a single hook inside `gate._run_inline_checks` interns each artifact after its check passes and emits the `cas_hash` on the existing `produces_check_passed` event. `artagents/core/project/run.py` already mirrors hype artifacts under `produces/` (line 160) — the CAS hook runs at the gate layer, so the same flow naturally feeds it for both code-step and attested produces.

Critical constraints:
- Stdlib only: `hashlib.sha256`, `os.symlink`, `os.replace`.
- Per-project scope: `cas_path` derives from `project_dir` (i.e. `<projects_root>/<slug>/.cas`) — the helper does NOT accept a `projects_root` and there is no top-level `.cas`. Two projects with identical content produce two separate CAS entries.
- Relative symlinks (computed via `os.path.relpath`) so the run dir stays portable when `<projects_root>` moves.
- `intern` is idempotent: if `<project_dir>/.cas/<sha256>` already exists, it discards the source rather than overwriting; subsequent identical content reuses the same entry.
- Symlinks already at the target path (e.g. on retry / reentry) are not re-walked.
- The hook lives **after** `entry.check.run(artifact_path)` returns ok and **before** the `produces_check_passed` event is appended, so the event records the CAS hash atomically with the pass.

Existing tests (`tests/test_task_inline_checks.py:113` `test_code_produces_check_passes_advances`) write a real file and currently assert it remains a regular file by implication only (they re-read no content). After Phase 7 that file becomes a symlink — `Path.read_text` follows symlinks so the existing assertion `kinds == [..., "produces_check_passed"]` keeps passing. No other test depends on the artifact being a non-symlink.

## Main Phase

### Step 1: Create the CAS module (`artagents/core/task/cas.py`)
**Scope:** Small
1. **Add** a new file `artagents/core/task/cas.py` exposing three functions and the constant:
   - `CAS_DIRNAME = ".cas"`
   - `cas_path(project_dir: Path, sha256: str) -> Path` — returns `project_dir / CAS_DIRNAME / sha256`. Pure pathjoin; no I/O.
   - `hash_file(path: Path) -> str` — streams the file in 1 MiB chunks through `hashlib.sha256`, returns the hex digest.
   - `intern(project_dir: Path, source_path: Path) -> tuple[Path, str]` — returns `(cas_path, sha256)`. Behavior:
     - If `source_path` is already a symlink whose resolved target sits inside `project_dir / CAS_DIRNAME`, short-circuit: read the existing CAS hash from the link target's filename and return `(link_target, hash)` without touching anything.
     - Otherwise compute `digest = hash_file(source_path)`, `target = cas_path(project_dir, digest)`.
     - `mkdir(parents=True, exist_ok=True)` on `target.parent`.
     - If `target.exists()`, treat as duplicate content: `source_path.unlink()` (the source is being replaced by a symlink in the next step anyway). Return `(target, digest)`.
     - Else `os.replace(source_path, target)` — atomic on the same filesystem; the projects root is single-host single-volume by design (SD-029).
     - Return `(target, digest)`.
   - `link_into_produces(cas_entry: Path, target_path: Path) -> None`:
     - If `target_path` exists or is a symlink, `target_path.unlink()` first.
     - Compute `rel = os.path.relpath(cas_entry, target_path.parent)` so the link stays portable.
     - `os.symlink(rel, target_path)`.
2. **Keep** the module under ~80 lines; pure stdlib; no logging, no tracing.
3. **Export** `intern`, `link_into_produces`, `cas_path`, `CAS_DIRNAME` via `__all__`.

# Implementation Plan: Phase 7 — Per-Project CAS for Produces Artifacts

## Overview
Phase 7 adds a per-project content-addressable store at `<project_dir>/.cas/<sha256>` and rewrites every produces-checked file artifact into a relative symlink that points at its CAS entry. The CAS is **per-project, never shared** (SD-008, SD-029). A new `artagents/core/task/cas.py` module supplies `intern` / `link_into_produces` helpers; one hook inside `gate._run_inline_checks` interns each artifact after its check passes and records the `cas_hash` on the existing `produces_check_passed` event. One small defensive edit in `artagents/core/project/run.py` (the file the brief explicitly lists as touched) keeps the hype-artifact mirror compatible with CAS by preserving symlinks rather than dereferencing them.

Critical constraints:
- Stdlib only: `hashlib.sha256`, `os.symlink`, `os.replace`, `shutil.copyfile`.
- Per-project scope: `cas_path(project_dir, sha256)` lives at `<projects_root>/<slug>/.cas/<sha256>`. No top-level / cross-project CAS exists.
- Relative symlinks via `os.path.relpath` so the project dir stays portable across `<projects_root>` relocations.
- `intern` is idempotent and **always stores regular file content** in `.cas/<sha>`, never a symlink — even when the source is itself a non-CAS symlink (correctness flag fix below).
- The hook lives **after** `entry.check.run(artifact_path)` returns ok and **before** the `produces_check_passed` event is appended, so the event records the CAS hash atomically with the pass.
- `cas_hash` is the **bare hex digest** (matches the on-disk filename and lets event consumers locate the CAS entry by direct string concatenation). This deliberately diverges from `plan_hash`'s `sha256:<hex>` form, because `plan_hash` is an opaque identifier while `cas_hash` is a filesystem path component (Settled: see SD-P7-cas-hash-format below).

### Resolution of unresolved flags
- **FLAG-P7-001 / issue_hints-1 (`run.py` divergence).** The gate IS the single chokepoint for produces interning; `mirror_hype_artifacts` runs upstream of `_run_inline_checks` (the parent task gate's produces check fires AFTER the mirror has copied the hype output to `<step_dir>/produces/<name>`), so the mirrored file is interned naturally. **However**, if the hype-side source is already a CAS symlink (from an earlier interning pass), `shutil.copy2(source, dest)` defaults to `follow_symlinks=True` and dereferences it into a fresh regular file — wasting an intern cycle and briefly doubling storage. Step 4 below adds `follow_symlinks=False` to that single `shutil.copy2` call, so the dest becomes a symlink replica that `intern`'s short-circuit immediately recognizes. This is the minimum touch in `run.py` that the brief listing requires.
- **issue_hints-2 (`cas_hash` format).** Settled as **bare hex**. Rationale recorded in Overview and as SD-P7-cas-hash-format.
- **correctness (symlink source).** `intern` is rewritten to never `os.replace` a symlink. When the source is a symlink, it `shutil.copyfile`'s the dereferenced bytes into the CAS target and then unlinks the source — guaranteeing the CAS entry is always a regular file.
- **all_locations (gitignore).** The misleading "runs/ already covers per-run-tree" comment is removed; the new gitignore entry stands on its own merits as the in-repo-test-fixture guardrail.

## Main Phase

### Step 1: Create the CAS module (`artagents/core/task/cas.py`)
**Scope:** Small
1. **Add** a new file `artagents/core/task/cas.py` exposing:
   - `CAS_DIRNAME = ".cas"`
   - `cas_path(project_dir: Path, sha256: str) -> Path` — pure pathjoin: `project_dir / CAS_DIRNAME / sha256`. No I/O.
   - `hash_file(path: Path) -> str` — streams `path` (open with default symlink-following) in 1 MiB chunks through `hashlib.sha256`; returns the hex digest.
   - `intern(project_dir: Path, source_path: Path) -> tuple[Path, str]` — guaranteed to leave a regular file in CAS:
     - If `source_path.is_symlink()`:
       - Read its real target via `source_path.resolve(strict=True)`.
       - If the resolved target sits inside `project_dir / CAS_DIRNAME`, short-circuit: extract the existing hash from the resolved filename (`resolved.name`) and return `(resolved, hash)` without any writes or unlinks.
       - Otherwise: compute `digest = hash_file(source_path)`, `target = cas_path(project_dir, digest)`, `mkdir(parents=True, exist_ok=True)` on `target.parent`. If `target.exists()`, just `source_path.unlink()`; else `shutil.copyfile(source_path, target)` then `source_path.unlink()`. Return `(target, digest)`.

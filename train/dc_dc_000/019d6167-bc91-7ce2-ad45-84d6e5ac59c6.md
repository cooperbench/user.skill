## Overview
The lightbox (double-click to view asset fullscreen) is currently owned by `PreviewPanel`, which registers a callback via a ref-based pattern (`registerLightboxHandler`). In condensed mode, `PreviewPanel` isn't mounted, so a `CondensedLightboxProvider` duplicates the same logic in `VideoEditorShell.tsx`. The fix: move lightbox state into `VideoEditorProvider` where both layout branches can use it, eliminating the ref indirection and the duplicate component.

`editor.resolvedConfig` is already available in InnerProvider (line 49), so the provider can validate asset keys directly. `onDoubleClickAsset` is consumed from context by TimelineEditor (line 169) and passed as a prop by PreviewPanel to OverlayEditor (line 102).

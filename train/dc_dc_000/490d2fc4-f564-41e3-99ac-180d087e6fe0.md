```
   433→def _fixer_help_lines(langs: list[str]) -> list[str]:
   434→    fixer_help_lines: list[str] = []
   435→    for lang_name in langs:
   436→        try:
   437→            fixer_names = sorted(get_lang(lang_name).fixers.keys())
   438→        except (ImportError, ValueError, TypeError, AttributeError):
   439→            fixer_names = []
   440→        fixer_list = ", ".join(fixer_names) if fixer_names else "none yet"
   441→        fixer_help_lines.append(f"fixers ({lang_name}): {fixer_list}")
   442→    fixer_help_lines.append("special: review — prepare structured review data")
   443→    return fixer_help_lines
```

```python
def resolve_ids_from_patterns(
    state: StateModel,
    patterns: list[str],
    *,
    plan: PlanModel | None = None,
    status_filter: str = "open",
) -> list[str]:
    """Resolve one or more patterns to a deduplicated list of finding IDs.

    When *plan* is provided, literal IDs that exist only in the plan
    (e.g. ``subjective::*`` synthetic items) are included even if they
    have no corresponding entry in ``state["findings"]``.
    """
    seen: set[str] = set()
    result: list[str] = []

    # Collect all plan IDs for literal-match fallback
    plan_ids: set[str] = set()
    if plan is not None:
        plan_ids.update(plan.get("queue_order", []))
        plan_ids.update(plan.get("skipped", {}).keys())
        for cluster in plan.get("clusters", {}).values():
            plan_ids.update(cluster.get("finding_ids", []))

    for pattern in patterns:
        matches = match_findings(state, pattern, status_filter=status_filter)
        if matches:
            for finding in matches:
                fid = finding["id"]
                if fid not in seen:
                    seen.add(fid)
                    result.append(fid)
        elif pattern in plan_ids and pattern not in seen:
            # Literal plan ID (e.g. subjective::foo) not in state findings
            seen.add(pattern)
            result.append(pattern)
    return result
```

**Pattern types accepted:**
- **Literal ID**: `f41b3eb7` (8-char hash suffix)
- **ID prefix**: `review::path::name`
- **Detector name**: `review` (all findings from detector)
- **File path**: `src/foo.py` (all findings in file)
- **Finding name**: `timing_attack` (last ::segment of ID)
- **Glob pattern**: `review::*naming*`

```python
def move_items(
    plan: PlanModel,
    finding_ids: list[str],
    position: str,
    target: str | None = None,
    offset: int | None = None,
) -> int:
    """Move finding IDs to a position in queue_order. Returns count moved."""
    ensure_plan_defaults(plan)
    order: list[str] = plan["queue_order"]

    # Remove from skipped if present
    skipped: dict[str, SkipEntry] = plan.get("skipped", {})
    for fid in finding_ids:
        skipped.pop(fid, None)

    # Remove from current position in order
    for fid in finding_ids:
        if fid in order:
            order.remove(fid)

    # Resolve insertion point
    idx = _resolve_position(order, position, target, offset, finding_ids)

    # Insert in original order
    for i, fid in enumerate(finding_ids):
        order.insert(idx + i, fid)

    # Track user-promoted IDs only when explicitly moved to the front.
    # Moving to bottom/down/after should not create a promotion barrier.
    if position == "top":
        promoted: list[str] = plan.get("promoted_ids", [])
        existing_promoted = set(promoted)
        for fid in finding_ids:
            if fid not in existing_promoted:
                promoted.append(fid)
                existing_promoted.add(fid)
        plan["promoted_ids"] = promoted

    return len(finding_ids)
```

**Key behaviors:**
- Removes items from `skipped` if present
- Removes from current queue position first
- Resolves insertion point via `_resolve_position()`
- Maintains original order when inserting multiple IDs
- Tracks "promoted_ids" ONLY for "top" moves

```python
    offset: int | None = None,

    """Move all cluster members as a contiguous block. Returns count moved."""
    ensure_plan_defaults(plan)
    cluster = plan["clusters"].get(cluster_name)
    if cluster is None:
        raise ValueError(f"Cluster {cluster_name!r} does not exist")

    member_ids = list(cluster.get("finding_ids", []))
    if not member_ids:
        return 0

    return move_items(plan, member_ids, position, target, offset)
```

**Implementation:** Delegates to `move_items()` with cluster's member IDs.

---

#### **Position Resolution Helpers** (`operations.py:71-145`)

Three position resolution functions:

1. **`_resolve_position()`** (lines 71-102): Main dispatcher
   - "top" → 0
   - "bottom" → len(order)
   - "before"/"after" → calls `_resolve_relative_position()`
   - "up"/"down" → calls `_resolve_offset_position()`

2. **`_resolve_relative_position()`** (lines 105-115):
   - Finds target ID in order (excluding items being moved)
   - Returns insertion index before/after target
   - Fallback: 0 (before) or len(order) (after) if target not found

3. **`_resolve_offset_position()`** (lines 125-144):
   - Finds current position of first ID in filtered list (excluding moving items)
   - "up" N: max(0, current_idx - N)
   - "down" N: min(len(order), current_idx + N)
   - Handles cases where item not in list (uses queue length)

### 9. CLI WIRING

The move commands are wired into the main CLI via:
1. `cli.py` calls `create_parser()` → `parser.py:create_parser()`
2. `parser.py:127` calls `_add_plan_parser(sub)`
3. `parser_groups_admin.py:_add_plan_parser()` adds plan subcommands, including "move"
4. `cmd.py:cmd_plan()` dispatches "move" action to `cmd_plan_move()`
5. `cmd.py:cmd_plan()` dispatches "cluster" action to `cmd_cluster_dispatch()`, which routes "move" to `_cmd_cluster_move()`

### 10. EXECUTION FLOW DIAGRAMS

**Plan Move Flow:**
```
$ desloppify plan move <patterns> <position> [target]
    ↓
cmd_plan() [cmd.py]
    ↓
cmd_plan_move() [move_handlers.py]
    ├─ load_plan()
    ├─ resolve_ids_from_patterns(state, patterns)
    │   └─ match_findings(state, pattern) × len(patterns)
    ├─ move_items(plan, finding_ids, position, target, offset)
    │   ├─ _resolve_position() → insertion index
    │   ├─ order.remove() × len(finding_ids)
    │   ├─ order.insert(idx) × len(finding_ids)
    │   └─ plan["promoted_ids"] += finding_ids (if position=="top")
    ├─ append_log_entry(plan, "move", ...)
    └─ save_plan(plan)
```

### 11. POSITION SEMANTICS

| Position | Behavior | Target Required? | Offset Meaning |
|----------|----------|------------------|----------------|
| `top` | Move to index 0 | No | N/A |
| `bottom` | Move to end | No | N/A |
| `before <id>` | Insert before target ID | Yes | N/A |
| `after <id>` | Insert after target ID | Yes | N/A |
| `up <N>` | Move N positions earlier | Yes (→offset) | Number of positions |
| `down <N>` | Move N positions later | Yes (→offset) | Number of positions |

### 12. KEY ARCHITECTURAL FEATURES

1. **Deduplication**: Pattern resolution collects unique IDs across multiple patterns
2. **Atomic moves**: All matched IDs move as a group maintaining their relative order
3. **Contiguous clusters**: Cluster move delegates to item move, ensuring all members stay together
4. **Skip auto-cleanup**: Moving items removes them from `skipped` dict automatically
5. **Promotion tracking**: Only "top" moves are tracked in `promoted_ids` (for queue reordering logic)
6. **Relative positioning**: "before"/"after" work with other queue items; "up"/"down" work with numeric offsets
7. **Execution logging**: All moves logged with position/target/offset details for audit trail
8. **Graceful fallback**: Patterns matching no findings print "yellow" warning; unmatched positions default to bottom

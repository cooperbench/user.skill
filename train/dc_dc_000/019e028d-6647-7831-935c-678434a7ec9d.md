Yes. It supports bounded recurring scheduled tasks, not a single “period” field. The recurrence model supports: - `hourly`, `daily`, or `weekly` - `interval`, like every 2 days - `until`, a timezone-aware end datetime - `remaining_occurrences` So “for the next month” would be represented as recurrence with an `until` about one month out. Example shape: ```json { "brief": "Check in about X", "local_when": { "date": "2026-05-09", "time": "09:00:00", "timezone": "Europe/Berlin" }, "recurrence": { "type": "daily", "interval": 1, "until": "2026-06-08T09:00:00+02:00" } } ``` Weekly also works, e.g. Mondays and Fridays for the next month: ```json { "type": "weekly", "interval": 1, "weekdays": [0, 4], "until": "2026-06-08T09:00:00+02:00" } ``` So the scheduler can do it, but the interface is “repeat until X” or “repeat N occurrences,” not “period: next_month.”

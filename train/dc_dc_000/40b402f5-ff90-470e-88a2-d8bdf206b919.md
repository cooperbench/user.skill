### Step 7: `Pod` class — async facade (`src/runpod_lifecycle/pod.py`)
**Scope:** Medium
1. **Define** `class Pod` with attributes `id: str`, `name: str`, `config: RunPodConfig`, `hooks: EventHooks`, `_ram_tier: int`, `_storage_volume: str | None`, `_ssh_details: dict | None`, `_last_exec_at: float | None`, `_created_at: float`.
2. **Implement** `async def wait_ready(self, timeout: float = 600) -> None`:
   - Polls `get_pod_status` via `asyncio.to_thread` every 5s until `desiredStatus == "RUNNING"` and SSH port mapping (privatePort=22) is present (`lifecycle.py:283-345`).
   - Transitions state `PROVISIONING → STARTING → READY`, emitting `on_state_change` for each.
   - Raises `NotReadyTimeout` on timeout; raises `LaunchFailure` if `desiredStatus in {"FAILED","TERMINATED"}`.
   - On READY, calls `get_pod_ssh_details` and caches in `self._ssh_details`.
3. **Implement** `async def status(self) -> dict` wrapping `get_pod_status(self.id, self.config.api_key)` via `to_thread`.
4. **Implement** `async def exec_ssh(self, cmd: str, timeout: int = 600) -> tuple[int, str, str]`:
   - Ensures `_ssh_details` is cached (else calls `get_pod_ssh_details`).
   - Builds `SSHClient` using config SSH keys (mirror selection logic from source `client.py:119-173`: inline key env var > private key path > password).
   - Runs `client.connect() / execute_command / disconnect` inside `asyncio.to_thread`.
   - Updates `self._last_exec_at = time.monotonic()`. Raises `SSHError` on failure.
5. **Implement** `async def is_idle(self, threshold_seconds: float) -> bool`:
   - **Assumption:** "idle" = no `exec_ssh` activity for `threshold_seconds` AND GPU utilization < 5% on `nvidia-smi --query-gpu=utilization.gpu --format=csv,noheader,nounits`.
   - If `_last_exec_at is None`, use `_created_at`.
   - If now − last_activity < threshold → `False`.
   - Else run `nvidia-smi` via `exec_ssh`; parse first int; return `True` if < 5 (any parse error → `False`, log warning).
6. **Implement** `async def terminate(self) -> None` wrapping `terminate_pod(self.id, self.config.api_key)` via `to_thread`; emits state `TERMINATED`; raises `TerminateError` on failure (after hook).
7. **Implement** `async def check_storage_health(self, min_free_gb=50, max_percent_used=85) -> dict` using the Step 6 helper with `self.exec_ssh` as the callable.

### Step 8: `launch()` orchestration with fallback (`src/runpod_lifecycle/lifecycle.py`)
**Scope:** Medium
1. **Implement** `async def launch(config: RunPodConfig, *, name: str | None = None, hooks: EventHooks | None = None) -> Pod`:
   - Emits `PROVISIONING` hook immediately.
   - Resolves GPU type via `find_gpu_type` (fail fast `LaunchFailure` if unknown).
   - Resolves `public_key_string` from config (inline > file path); warn if missing.
   - Builds `ram_tiers` list: if `config.ram_tiers_enabled`, filter `config.ram_tiers` to those `>= config.min_memory_gb` (fallback to `[min_memory_gb]` if empty); else `[min_memory_gb]`. Mirrors `lifecycle.py:64-74`.
   - Builds ordered list of storage volumes: `[config.storage_name] + list(config.storage_volumes)` de-duplicated, skipping `None`; each resolved to volume_id via `get_storage_volume_id`, missing ones skipped with warning.
   - Outer loop: for each `ram_tier`; inner loop: for each resolved `(storage_name, storage_volume_id)`:
     - On the **first** ram tier per storage, call `check_and_expand_storage(..., min_free_gb=50)` (preserves `lifecycle.py:85-86`).
     - Call `create_pod` via `to_thread` with the tier's RAM, the volume id, mount path, SSH key, env_vars, template.
     - On success: construct `Pod(id=..., name=..., _ram_tier=ram_tier, _storage_volume=storage_name, ...)`, emit state event with detail including ram_tier/storage, return.
     - On `"no longer any instances available"` (case-insensitive substring match, preserves `lifecycle.py:128`) or generic exception: record last error, continue.
   - All combinations exhausted → emit `on_error`, raise `LaunchFailure` with tried tiers/storages.
2. **Re-export** module-level helpers `find_gpu_type`, `get_network_volumes` from `api.py` in `lifecycle.py` and the package `__init__.py`.

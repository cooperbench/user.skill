        # Implementation Plan: Split `megaplan/handlers.py` into a `handlers/` subpackage by workflow phase

## Overview
`megaplan/handlers.py` is 2529 lines holding ~60 module-level callables — 14 public `handle_*` entry points plus ~45 private helpers and a few module globals (`log`, `_AUTO_NEXT_STEP`, `MOCK_ENV_VAR`, `shutil`, `subprocess`, `worker_module`). It is imported from `megaplan/__init__.py`, `megaplan/cli.py`, `megaplan/tiebreaker.py` (lazy), and four test modules. Callers reach into private symbols, and tests patch package-level names in two distinct ways:

- **Shared-object patches** (safe across the split because the object is module-identity global): `megaplan.handlers.worker_module`, `megaplan.handlers.shutil`, `megaplan.handlers.subprocess`, `megaplan.handlers.MOCK_ENV_VAR`.
- **Name-rebinding patches** (dangerous across the split — rebinding a name on the package object does NOT update bindings already captured inside submodules): `megaplan.handlers.run_pre_checks`, `megaplan.handlers.run_parallel_review`, `megaplan.handlers.update_flags_after_review`, `megaplan.handlers.resolve_agent_mode` (see `tests/test_handle_review_robustness.py:164,182-183,235,343-344,338-342,530-535,534-535`).

If the moved handlers import those four functions directly (e.g. `from megaplan.review_mechanical import run_pre_checks`) at the top of `handlers/review.py`, test patches of the package attribute will silently miss the real call site — tests currently green would start failing or the patches would have no effect. The fix is to re-export these four names at the package level and have the submodule callers resolve them **through the package at call time** instead of binding them at module import.

Also tests patch private helpers (`_apply_gate_outcome`, `_is_substantive_reviewer_verdict`, `_capture_test_baseline`, `_emit_phase_notice`, `_resolve_review_outcome`, `_synthesize_review_rework_items`) by calling them as `megaplan.handlers._foo(...)`. These are *called*, not *rebound*, so package-level re-exports from the owning submodule are sufficient.

Goal: convert `handlers.py` into a package (`handlers/`) with phase-scoped submodules plus `shared.py` for cross-phase helpers. `handlers/__init__.py` re-exports every name in the current public surface, **including the four patchable upstream symbols**. Handlers that call those four resolve them via the package namespace so test monkeypatches land on the actual call site. No behavior changes; the full test suite must pass with no test edits.

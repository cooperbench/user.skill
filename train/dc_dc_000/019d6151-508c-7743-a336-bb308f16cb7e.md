        # Implementation Plan: Aspect-Ratio-Aware Condensed Mode Threshold

## Overview
The video editor switches to condensed mode when the container is too short, but the threshold (`MIN_STANDARD_HEIGHT = 412px`) is a hardcoded constant that ignores the video's aspect ratio. A 9:16 portrait video needs far more vertical space than a 16:9 landscape video, but they share the same threshold. Fix: compute the minimum preview height dynamically from the video aspect ratio and available width, using the ResizeObserver that already fires on resize.

**Key file:** `src/tools/video-editor/components/VideoEditorShell.tsx`
**Current behavior (line 133):** `MIN_STANDARD_HEIGHT = MIN_PREVIEW_HEIGHT + MIN_TIMELINE_HEIGHT + 40 + 28 + 24` (= 412px fixed)

## Main Phase

### Step 1: Compute aspect-ratio-aware threshold (`VideoEditorShell.tsx:25,133-146`)
**Scope:** Small — ~15 lines changed in one file

1. **Import** `parseResolution` from `config-utils.ts` (line 25 area).
2. **Derive** the video aspect ratio from `editorData.resolvedConfig.output.resolution` using `parseResolution()`. Compute once via `useMemo`, falling back to 16:9 (1.778) when `resolvedConfig` is not yet available.
3. **Replace** the fixed `MIN_STANDARD_HEIGHT` constant (line 133) with a dynamic computation inside the `ResizeObserver` callback:
   - Standard layout grid: `grid-cols-[minmax(0,1fr)_360px]` with `gap-3` (12px) and `p-3` (12px each side).
   - `availablePreviewWidth = entry.contentRect.width - 360 - 12 - 24` (properties panel + gap + horizontal padding = 396px).
   - `minPreviewHeight = availablePreviewWidth / aspectRatio`.
   - Apply a floor of `MIN_PREVIEW_HEIGHT` (180px) so the preview never gets absurdly short.
   - `minStandardHeight = Math.max(MIN_PREVIEW_HEIGHT, minPreviewHeight) + MIN_TIMELINE_HEIGHT + 92` (92 = 40 header + 28 divider + 24 padding, same chrome overhead as before).
   - `setTooSmall(entry.contentRect.height < minStandardHeight)`.
4. **Add `aspectRatio` to the `useEffect` dependency array** (alongside `forceCondensed`). Remove `MIN_STANDARD_HEIGHT` from deps since it's no longer a stable constant.

```tsx
// Before (line 133):
const MIN_STANDARD_HEIGHT = MIN_PREVIEW_HEIGHT + MIN_TIMELINE_HEIGHT + 40 + 28 + 24;

// After:
const CHROME_OVERHEAD = MIN_TIMELINE_HEIGHT + 40 + 28 + 24; // timeline + header + divider + padding
const PROPERTIES_AND_GAPS = 360 + 12 + 24; // properties panel + gap + horizontal padding

const aspectRatio = useMemo(() => {
  if (!editorData.resolvedConfig?.output?.resolution) return 16 / 9;
  const { width, height } = parseResolution(editorData.resolvedConfig.output.resolution);
  return width / height;
}, [editorData.resolvedConfig?.output?.resolution]);

// In the ResizeObserver callback:
const availablePreviewWidth = entry.contentRect.width - PROPERTIES_AND_GAPS;
const minPreviewHeight = Math.max(MIN_PREVIEW_HEIGHT, availablePreviewWidth / aspectRatio);
setTooSmall(entry.contentRect.height < minPreviewHeight + CHROME_OVERHEAD);
```

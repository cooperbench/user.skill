### **1. MAJOR PIPELINE STAGES**

#### **A. Post-Scan Reconciliation Phase** (`engine/_plan/reconcile.py`, `app/commands/scan/plan_reconcile.py`)
Triggered after every scan to keep the plan in sync with new/disappeared issues:

1. **Reconcile Plan After Scan** — `reconcile_plan_after_scan()`
   - Supersedes issues that no longer exist (moved to `plan.superseded`)
   - Prunes old superseded entries (>90 days)
   - Resurfaces stale temporary skips (return issues that were skipped but haven't been reviewed)
   - Cleans up dead issues from clusters and epic references

2. **Sync Unscored Dimensions** — `sync_unscored_dimensions()`
   - Prepends never-scored (placeholder) subjective dimensions to the *front* of queue (onboarding priority)
   - These are dimensions that have never been assessed yet
   - Location: *front of queue unconditionally*

3. **Sync Stale Dimensions** — `sync_stale_dimensions()`
   - Manages previously-scored dimensions that need review
   - Injects stale/under-target dimensions when:
     - No objective mechanical items remain (append to back), OR
     - A cycle just completed (insert at front for post-cycle priority)
   - Prunes dimensions that were refreshed and reached target
   - Location: *conditional, back or front depending on lifecycle*

4. **Auto-Cluster Issues** — `auto_cluster_issues()`
   - Regenerates automatic task clusters based on scanner output
   - Groups related issues together by detector/file patterns
   - Subject to `target_strict_score` threshold

5. **Seed/Clear Plan Start Scores** — `_seed_plan_start_scores()` / `_clear_plan_start_scores_if_queue_empty()`
   - Seeds score snapshot when starting a new queue cycle
   - Clears snapshot when queue is fully drained (cycle complete)
   - Used to track progress across a work cycle

6. **Sync Triage Needed** — `sync_triage_needed()`
   - Injects 4 triage stage IDs (`triage::observe`, `triage::reflect`, `triage::organize`, `triage::commit`) when review issues change
   - Auto-prunes stale stages if all new review issues have been resolved
   - Location: *front of queue*

7. **Sync Communicate Score / Create Plan Workflows** — `sync_communicate_score_needed()`, `sync_create_plan_needed()`
   - Injects synthetic workflow items (`workflow::communicate-score`, `workflow::create-plan`)

Executed when rendering the plan or selecting next items. 6-step pipeline:

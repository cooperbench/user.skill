## Overview

This change adds two CLI verbs (`install`, `ensure`), an opt-in `EmbeddedSession.run(..., ensure_packs=True)` convenience, and the QwenTTS lockfile follow-up.

Notable repo facts that shape the design:
- Canonical install path is `custom_nodes/<pack-name>/` (used by every script in `scripts/`, e.g. `scripts/runpod_corpus_matrix.py:438`, and matched by `_installed_nodepack_dir` at `vibecomfy/commands/nodes.py:130`). Vendor paths exist as fallbacks for doctor reads only.
- `KNOWN_NODE_PACKS` already includes `ComfyUI-QwenTTS` with `AILab_Qwen3TTSVoiceClone` and the rest of the AILab class set (`vibecomfy/node_packs.py:116`). So deliverable #3 only needs the `custom_nodes.lock` pin / docs note.
- Current `custom_nodes.lock` is the legacy 2-line format. `read_lockfile`/`write_lockfile` round-trip legacy → TOML cleanly.
- `_installed_nodepack_dir` and `_git_head` helpers already exist and can be reused.

Constraints honored: existing `install-plan` is untouched; no real clone/pip in tests; `vibecomfy/blocks/` and `vibecomfy/workflow.py` are not touched; `runtime/session.py` gets a strictly-additive kwarg.

## Main Phase

### Step 1: Add a lockfile UPSERT helper (`vibecomfy/node_packs_lockfile.py`)
**Scope:** Small
1. **Add** `upsert_lockfile_entry(entry: LockEntry, path: Path = Path(\"custom_nodes.lock\")) -> None` next to `write_lockfile` (`vibecomfy/node_packs_lockfile.py:38`). Read existing entries, replace by `name` if present else append, then call `write_lockfile`.
2. **Note:** First UPSERT migrates legacy → TOML, which `read_lockfile` already accepts (`vibecomfy/node_packs_lockfile.py:34`).

### Step 2: Implement `vibecomfy nodes install` (`vibecomfy/commands/nodes.py`)
**Scope:** Medium
1. **Add** `_cmd_nodes_install(args)` accepting `<pack-name>` positional **or** `--repo <url>` (with optional `--name` override). Resolve the catalog `CustomNodePack` for the pip-package list when invoked by name.
2. **Compute** install dir as `Path(\"custom_nodes\") / name`, matching the priority of `_installed_nodepack_dir` (`vibecomfy/commands/nodes.py:130`).
3. **Idempotent path** — if the dir exists:
   - clean (`git -C <dir> status --porcelain` empty) → read HEAD via `_git_head`, UPSERT, exit 0.
   - dirty → refuse unless `--force`. With `--force`, skip clone but UPSERT current HEAD (do not destroy local edits).
4. **Clone path** — dir absent:
   - `subprocess.run([\"git\", \"clone\", pack.repo, str(install_dir)], check=True, capture_output=True, text=True)`. On failure, print stderr, return non-zero, **no UPSERT**.
   - If catalog `pip_packages` non-empty, `subprocess.run([sys.executable, \"-m\", \"pip\", \"install\", *pip_packages], check=True, ...)`. On failure, print stderr, return non-zero, **no UPSERT**.
   - On success: `_git_head(install_dir)` → `upsert_lockfile_entry(LockEntry(name=pack.name, git_commit_sha=sha, url=pack.repo))`.
5. **Wire** in `register()` (`vibecomfy/commands/nodes.py:165`) — new `install` subparser, leave `install-plan` parser intact.

### Step 3: Implement `vibecomfy nodes ensure` (`vibecomfy/commands/nodes.py`)
**Scope:** Medium
1. **Add** `_cmd_nodes_ensure(args)` taking mutually-exclusive `--template` or `--workflow`, both flowing through `load_workflow_reference`.
2. **Extract** the resolve step from `_cmd_nodes_install_plan` into `_missing_packs_for_workflow(workflow) -> (list[CustomNodePack], list[str unresolved])` so both verbs share it. No behavior change to `install-plan`.
3. **Dry-run**: `--dry-run` prints the same human plan as `install-plan`, exits with the same code semantics.
4. **Install loop**: for each missing pack, call `_cmd_nodes_install(argparse.Namespace(name=pack.name, repo=None, force=False))`; on first non-zero, abort and propagate.
5. **Reload hint**: after success, print one line telling the user to call `session.reload_for_nodepack_change(...)` or restart their session.
6. **Wire** in `register()` — new `ensure` subparser with mutex `--template` / `--workflow` and `--dry-run`.

### Step 4: Optional `ensure_packs` kwarg on `EmbeddedSession.run` (`vibecomfy/runtime/session.py`)
**Scope:** Small
1. **Extend** `EmbeddedSession.run(self, workflow, *, backend=\"api\", ensure_packs: bool = False)` (`vibecomfy/runtime/session.py:112`). When `True`, before `_run_untracked`: call shared `_missing_packs_for_workflow`, run each install via `_cmd_nodes_install`, then `await self.reload_for_nodepack_change(reason=\"ensure_packs\")` if anything was installed. On any install failure raise `RuntimeError(\"ensure_packs: install failed for <pack>\")` before queueing.
2. **Do not** wire `ServerSession` — out of scope.
3. **One-line comment** on the new kwarg flagging dev-convenience only.

### Step 5: Tests (`tests/test_nodes_install.py`, `tests/test_runtime_session.py`)

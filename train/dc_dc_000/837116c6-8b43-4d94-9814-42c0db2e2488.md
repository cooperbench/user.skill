1. **Structural Hash**: Computed from node kind and children hashes recursively
   - `"compute_structural_hash(node_kind: &str, children: Vec<md5::Digest>)"`
   - Creates a digest by consuming the node kind and each child's digest

2. **Source Hash**: MD5 hash of actual source text
   - `"source_hash: md5::compute(current.utf8_text(source_file.contents.as_bytes())"`

3. **Tree-Based Approach**: Works on abstract syntax tree nodes with:
   - Start/end line and byte positions
   - Child node relationships
   - Mass calculation (1 + sum of children's mass)

## Detection Strategy

Rather than token-based or suffix tree approaches, this is **AST-based structural matching**. The algorithm:
- Hashes structural patterns (node types + relationships)
- Compares these hashes across code segments
- Identifies duplicated subtrees through matching `structural_hash` values
- Maintains context with configurable `CONTEXT_LINES` (set to 10)

The approach prioritizes semantic/syntactic similarity over raw text matching, making it resilient to formatting variations while detecting functionally duplicate code blocks.

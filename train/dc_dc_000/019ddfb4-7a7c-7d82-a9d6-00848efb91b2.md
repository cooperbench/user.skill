## Overview
ArtAgents already has a first-class `artagents/nodes/` package with schema, folder discovery, registry, CLI, runner, installation helpers, and tests. The hype pipeline orchestration still lives in `artagents/pipeline.py`, with `pipeline.py` as a root compatibility launcher. Event-talk orchestration similarly lives in `artagents/event_talks.py`, with `event_talks.py` as a root launcher.

The simplest durable fix is to add a parallel `artagents/conductors/` package that reuses the proven node patterns where they fit, but keeps conductors semantically separate: conductors coordinate nodes and declared child conductors; nodes remain executable units and must not call conductors. The hype and event-talk flows should become curated conductor folders, while existing `pipeline.py ...` and `event_talks.py ...` commands continue to work as wrappers.

## Phase 1: Define The Conductor Substrate

### Step 1: Add conductor schema and API helpers (`artagents/conductors/schema.py`, `artagents/conductors/api.py`, `artagents/conductors/__init__.py`)
**Scope:** Medium
1. Create `ConductorDefinition` and `ConductorSpec` analogous to `NodeDefinition` and `NodeSpec`, reusing `NodePort`, `NodeOutput`, `CachePolicy`, `CommandSpec`, and `IsolationMetadata` where practical instead of inventing duplicate port schemas.
2. Add conductor-specific graph metadata such as `child_nodes`, `child_conductors`, `provides`, and `consumes`.
3. Validate conductor IDs, kind values, command shape, outputs, and graph metadata.
4. Enforce the architectural distinction in data shape: conductors may declare node and conductor children; node schema remains conductor-blind.

### Step 2: Add folder discovery for conductors (`artagents/conductors/folder.py`)
**Scope:** Medium
1. Mirror node folder discovery but search for `conductor.py` instead of `node.py`.
2. Support `CONDUCTOR`, `CONDUCTORS`, lowercase `conductor`, and decorated callables, matching the node authoring ergonomics.
3. Attach folder metadata: `source`, `conductor_root`, `conductor_file`, `folder_id`, plus optional `requirements_file`, `pyproject_file`, and `SKILL.md` if present.
4. Keep extraction out-of-process like nodes so folder metadata imports cannot mutate the parent process.

### Step 3: Add registry validation (`artagents/conductors/registry.py`)
**Scope:** Medium
1. Implement `ConductorRegistry` with `register`, `get`, `list`, `validate_all`, `to_dict`, and `to_json` methods analogous to `NodeRegistry`.
2. Load curated conductor folders from `artagents/conductors/curated/`.

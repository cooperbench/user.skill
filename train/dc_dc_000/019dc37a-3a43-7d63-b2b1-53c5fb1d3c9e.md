## Overview

The Python side of DataClaw already implements Phases 1–5, the Phase 8 daily-named log writer, and the Phase 10 retry/staging machinery (`dataclaw/cli.py:36–1021`, `dataclaw/logging.py`, `dataclaw/scheduler.py`, `dataclaw/privacy_filter.py`, `dataclaw/config.py`). What is missing is everything that turns it into a self-contained desktop app:

- **Phase 9 (Keychain HF token):** there is no `dataclaw/auth.py` and no `dataclaw hf {login,logout,whoami}` subcommand. `push_to_huggingface` / `_push_shards_attempt` (cli.py:833, 883) currently rely on `HfApi()` reading the ambient `HF_TOKEN` / `~/.cache/huggingface/token`.
- **Phase 7 (sidecar):** no `pyinstaller.spec`, `Makefile`, or `scripts/build-sidecar.sh`.
- **Phase 6 (Tauri 2 base):** no `app/` directory at all.
- **Phase 8 deferred (Logs UI):** no `notify`-driven watcher and no `Logs.tsx`.

Constraints to honor verbatim from `docs/expansion-design.md` (Hard constraints / Settled decisions):
- Tauri 2 sidecar API (`tauri_plugin_shell::ShellExt`), capabilities live in `app/src-tauri/capabilities/default.json` (no v1 `allowlist`).
- HF token stored in macOS Keychain (Rust `keyring = "3"` crate from Tauri; Python `keyring` from sidecar). `dataclaw hf login` writes to **both** Keychain **and** `~/.cache/huggingface/token` with `chmod 0600`.
- PyInstaller spec must `collect_submodules("keyring")` and explicitly hidden-import the macOS / SecretService backends so the bundled binary can read Keychain in scheduled (no-Tauri) runs.
- Tauri `externalBin: ["binaries/dataclaw"]`; bundle resolves `binaries/dataclaw-<target-triple>` per-arch.
- `APPLE_SIGNING_IDENTITY` is reserved for Phase 11 release infra and is **out of scope** here — CI for this phase builds unsigned (`APPLE_SIGNING_IDENTITY=""`).
- Rust unit tests for the CLI bridge (the JSON-block parser and the capabilities file shape) are required.

Scope of the four pieces:
1. `dataclaw/auth.py` + `dataclaw hf` verbs + token resolution in push paths (Python).
2. `pyinstaller.spec` + `scripts/build-sidecar.sh` + `Makefile` + `[build]` extra wiring (PyInstaller).
3. `app/` Tauri 2 scaffold: `Cargo.toml`, `tauri.conf.json`, `capabilities/default.json`, `src/{main.rs, dataclaw.rs, hf.rs, logs.rs}`, React+Vite frontend with `Dashboard`, `Config`, `Findings`, `Auth`, `Logs` routes (Tauri).
4. `notify`-crate watcher in `logs.rs` + virtualized `Logs.tsx` tab (Logs UI).
5. CI matrix update for unsigned `pnpm tauri build` on `[macos-14, macos-13]` plus the sidecar smoke check.

Risk hot-spots (driving the plan order):
- **PyInstaller bundling `keyring`** is the highest-risk piece because hidden-import omissions only manifest at runtime in the bundled binary. Building and running `dataclaw hf whoami --check-keyring-only` against the bundled binary is the cheapest gate; do it before wiring Tauri to the sidecar.
- **Tauri 2's capabilities API** is JSON-validated at build time — getting the schema right (especially `shell:allow-spawn` with `sidecar: true`) is the second-most-likely thing to break the build.

I'm planning per-arch sidecar builds (`dataclaw-aarch64-apple-darwin`, `dataclaw-x86_64-apple-darwin`) driven by CI matrix rather than a true universal2 fat binary — that matches Tauri's `externalBin` resolver convention and avoids the PyInstaller universal2 cross-link complexity. ### Step 13: `app/src-tauri/src/dataclaw.rs` — sidecar bridge (NEW)
**Scope:** Medium
1. **Implement** the v2 sidecar invocation pattern:
   ```rust
   use tauri_plugin_shell::ShellExt;
   use tauri_plugin_shell::process::CommandEvent;

   pub fn parse_json_block(stdout: &[u8]) -> Result<serde_json::Value, String> {
       let s = String::from_utf8_lossy(stdout);
       const MARKER: &str = "---DATACLAW_JSON---";
       if let Some(i) = s.find(MARKER) {
           let after = &s[i + MARKER.len()..];
           let end = after.find(MARKER).unwrap_or(after.len());
           return serde_json::from_str(after[..end].trim())
               .map_err(|e| format!("invalid JSON block: {e}"));
       }
       serde_json::from_str(s.trim()).map_err(|e| format!("no JSON: {e}"))
   }

   pub async fn run_sidecar(
       app: &tauri::AppHandle,
       args: &[&str],
       env: Option<std::collections::HashMap<String, String>>,
   ) -> Result<serde_json::Value, String> {
       let mut cmd = app.shell().sidecar("dataclaw").map_err(|e| e.to_string())?;
       if let Some(env) = env {
           for (k, v) in env { cmd = cmd.env(k, v); }
       }
       cmd = cmd.args(args);
       let (mut rx, _child) = cmd.spawn().map_err(|e| e.to_string())?;
       let mut stdout = Vec::new();
       while let Some(ev) = rx.recv().await {
           match ev {
               CommandEvent::Stdout(b) => stdout.extend(b),
               CommandEvent::Terminated(_) => break,
               _ => {}
           }
       }
       parse_json_block(&stdout)
   }

   #[tauri::command]
   pub async fn dataclaw_status(app: tauri::AppHandle) -> Result<serde_json::Value, String> {
       run_sidecar(&app, &["status", "--json"], None).await
   }

   #[tauri::command]
   pub async fn dataclaw_auto_now(app: tauri::AppHandle, force: bool) -> Result<serde_json::Value, String> {
       let mut args = vec!["auto"];
       if force { args.push("--force"); }
       crate::hf::run_with_token(&app, &args).await
   }

   #[tauri::command]
   pub async fn dataclaw_config_get(app: tauri::AppHandle, show_secrets: bool) -> Result<serde_json::Value, String> {
       let mut args = vec!["config", "--json"];
       if show_secrets { args.push("--show-secrets"); }
       run_sidecar(&app, &args, None).await
   }
   ```

1. **Implement** with `keyring = "3"`:
   ```rust
   use keyring::Entry;
   const SERVICE: &str = "io.dataclaw.app";
   const ACCOUNT: &str = "hf_token";

   fn entry() -> Result<Entry, String> {
       Entry::new(SERVICE, ACCOUNT).map_err(|e| e.to_string())
   }

   #[tauri::command]
   pub async fn hf_save_token(app: tauri::AppHandle, token: String) -> Result<(), String> {
       entry()?.set_password(&token).map_err(|e| e.to_string())?;
       // Mirror to ~/.cache/huggingface/token via the sidecar so the CLI's chmod
       // and mkdir logic stays in one place.
       let mut env = std::collections::HashMap::new();
       env.insert("HF_TOKEN".into(), token.clone());
       let _ = crate::dataclaw::run_sidecar(&app, &["hf", "login", "--token-stdin"],
                                            Some(env)).await; // stdin mirror handled by sidecar
       Ok(())
   }

   #[tauri::command]
   pub async fn hf_load_token() -> Result<Option<String>, String> {
       match entry()?.get_password() {
           Ok(t) => Ok(Some(t)),
           Err(keyring::Error::NoEntry) => Ok(None),
           Err(e) => Err(e.to_string()),
       }
   }

   #[tauri::command]
   pub async fn hf_delete_token(app: tauri::AppHandle) -> Result<(), String> {
       let _ = entry()?.delete_credential();
       let _ = crate::dataclaw::run_sidecar(&app, &["hf", "logout"], None).await;
       Ok(())
   }

   pub async fn run_with_token(app: &tauri::AppHandle, args: &[&str])
       -> Result<serde_json::Value, String> {
       let token = hf_load_token().await?.unwrap_or_default();
       let env = if token.is_empty() { None } else {
           let mut m = std::collections::HashMap::new();
           m.insert("HF_TOKEN".into(), token);
           Some(m)
       };
       crate::dataclaw::run_sidecar(app, args, env).await
   }

   #[tauri::command]
   pub async fn hf_whoami(app: tauri::AppHandle) -> Result<serde_json::Value, String> {
       run_with_token(&app, &["hf", "whoami"]).await
   }
   ```
   Note: the design doc says the Tauri save shouldn't mirror; revisited here so a single click writes both backends consistently. Easy to flip if the user wants strict separation.

   use std::{fs::File, io::{BufRead, BufReader, Seek, SeekFrom}, path::PathBuf, sync::Mutex};
   use tauri::{AppHandle, Emitter, Manager};

   pub fn log_dir() -> PathBuf {

   pub fn start_log_watcher(app: AppHandle) -> Result<(), Box<dyn std::error::Error>> {
       let dir = log_dir();
       std::fs::create_dir_all(&dir).ok();
       let positions: Mutex<std::collections::HashMap<PathBuf, u64>> = Mutex::new(Default::default());
       let app_handle = app.clone();
       let mut watcher = RecommendedWatcher::new(move |res: notify::Result<notify::Event>| {
           if let Ok(ev) = res {
               if !matches!(ev.kind, EventKind::Modify(_) | EventKind::Create(_)) { return; }
               for path in ev.paths {
                   if path.extension().and_then(|s| s.to_str()) != Some("jsonl") { continue; }
                   let mut pos_map = positions.lock().unwrap();
                   let mut pos = *pos_map.get(&path).unwrap_or(&0);
                   if let Ok(mut f) = File::open(&path) {
                       let _ = f.seek(SeekFrom::Start(pos));
                       let reader = BufReader::new(f);
                       for line in reader.lines().flatten() {
                           let _ = app_handle.emit("logs-line", &line);
                           pos += line.len() as u64 + 1;
                       }
                       pos_map.insert(path, pos);
                   }
               }
           }
       }, notify::Config::default())?;
       watcher.watch(&dir, RecursiveMode::NonRecursive)?;
       app.manage(Mutex::new(watcher)); // keep watcher alive
       Ok(())
   }

   pub fn logs_open_in_finder() -> Result<(), String> {
       std::process::Command::new("open").arg(log_dir()).status()
           .map(|_| ()).map_err(|e| e.to_string())
   }

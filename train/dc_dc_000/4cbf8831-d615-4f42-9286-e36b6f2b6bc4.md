        # Implementation Plan: Phase 5 — Lifecycle Verbs Split by Audience

## Overview
Phase 5 lands the audience-scoped task-mode CLI on top of the Phase 1-4 kernel. The kernel (`artagents/core/task/`) already exposes `gate_command`, `derive_cursor`, `compute_plan_hash`, `read_active_run`/`write_active_run`/`clear_active_run`, the full event-maker set including `make_run_started_event`, and the `iter_steps_with_path` plan walker. Author CLI in `artagents/orchestrate/cli.py` already implements `compile`, `check`, `describe`, `new`. Phase 5 adds (a) lifecycle verbs `start`, `next`, `ack`, `abort`, `status`, `runs ls` directly in `artagents/pipeline.py`, (b) author verbs `test` (scaffold + diff against existing golden) and `explain` to the author CLI, and (c) the prohibition-preamble constant printed verbatim by `next`.

The kernel's gate currently runs in `pipeline.main` whenever `--project <slug>` is present. The new lifecycle verbs themselves carry `--project` but must not be matched against `plan[cursor].command` — `next`, `status`, `abort`, `runs ls`, `start`, `author *` are out-of-band. The exception is `ack --decision approve` for attested steps, which needs to route into the gate's existing `_dispatch_attested` path. So `pipeline.main` must short-circuit the gate for known lifecycle verbs and let `ack` re-enter the gate explicitly when (and only when) the decision is `approve`.

Constraints:
- `artagents orchestrators run|list|inspect|validate` paths in `artagents/core/orchestrator/cli.py` stay untouched.
- Author `test` golden-run capture is Phase 9; the verb must scaffold but emit a clear "implement Phase 9" message when no golden file exists.
- Stop-hook wiring is Phase 6; only the verbatim preamble constant lands here.
- Run-id is operator-supplied via `--name` if given (slugified), otherwise generated as `run-<UTC timestamp>-<8 hex>` to satisfy `validate_run_id` regex `^[A-Za-z0-9][A-Za-z0-9_.:-]{0,127}$`.
- `start <orchestrator-id>` consumes the compiled `<packs_root>/<pack>/build/<name>.json`. If absent, the verb prints the exact `artagents author compile <id>` recovery and exits non-zero — does not silently call compile (compile is gitignored output, materializing it during start crosses the additive line).

112	class CursorPath:
113	    frames: list[_Frame] = field(default_factory=list)
114	    for_each_progress: dict[str, dict[str, Any]] = field(default_factory=dict)
115	    pinned_failure: tuple[str, str] | None = None  # (reason, host_path) for iteration_exhausted=fail

117	    @property
118	    def at_root_done(self) -> bool:
119	        return len(self.frames) == 1 and self.frames[-1].child_index >= len(self.frames[-1].plan.steps)

123	        top = self.frames[-1]

127	def derive_cursor(plan: TaskPlan, events: Sequence[dict[str, Any]], *, slug: str = "") -> CursorPath:
128	    """Replay ``events.jsonl`` left-to-right to reconstruct the path-stack cursor.
129	
130	    Reconstructible from events alone (supports partial-replay resume):
131	    ``nested_entered`` pushes, ``nested_exited`` pops + advances parent,
132	    ``step_completed`` / ``step_attested`` mark a step advance-eligible iff it
133	    has no produces; otherwise advance is deferred until the contiguous block
134	    contains a ``produces_check_passed`` for every declared produces name.
135	    ``produces_check_failed`` / ``cursor_rewind`` clear pending state without
136	    advancing. ``iteration_started`` pushes an iteration frame; ``iteration_failed``
137	    pops it without advancing the host. ``for_each_expanded`` records the host's
138	    item set on the cursor (used as the source of truth — derive_cursor never
139	    re-reads disk during replay). ``item_started`` pushes a per-item frame;
140	    ``item_completed`` / ``item_attested`` pop the item frame and advance the
141	    host once every item is done. ``step_dispatched`` / ``run_started`` do not
142	    advance.
143	    """
144	    frames: list[_Frame] = [_Frame(plan=plan, path_prefix=(), child_index=0)]
145	    pending: list[set[str] | None] = [None]
146	    for_each_progress: dict[str, dict[str, Any]] = {}
147	    pinned_failure: tuple[str, str] | None = None
148	    for event in events:
149	        kind = event.get("kind")
150	        if kind == "iteration_exhausted":
151	            on_exhaust = event.get("on_exhaust")
152	            host_path = _path_str_from_event(event)
153	            if on_exhaust == "fail":
154	                pinned_failure = ("repeat.until max_iterations exhausted", host_path)
155	                continue
156	            if on_exhaust == "escalate":
157	                top = frames[-1]
158	                if top.child_index < len(top.plan.steps):
159	                    host_step = top.plan.steps[top.child_index]
160	                    override_plan = TaskPlan(
161	                        plan_id=f"__exhaust_{host_step.id}",
162	                        version=1,
163	                        steps=(_make_exhaust_override_step(slug, host_path),),
164	                    )
165	                    frames.append(
166	                        _Frame(
167	                            plan=override_plan,
168	                            path_prefix=top.path_prefix + (host_step.id,),
169	                            child_index=0,
170	                            repeat_step_id=host_step.id,
171	                        )
172	                    )
173	                    pending.append(None)
174	            continue
175	        if kind == "nested_entered":
176	            top = frames[-1]
177	            if top.child_index >= len(top.plan.steps):
178	                raise TaskRunGateError(
179	                    reason="nested_entered points past end of frame",
180	                    recovery="inspect events.jsonl",
181	                )
182	            step = top.plan.steps[top.child_index]
183	            if not isinstance(step, NestedStep):
184	                raise TaskRunGateError(
185	                    reason="nested_entered did not land on a NestedStep",
186	                    recovery="inspect events.jsonl",
187	                )
188	            frames.append(
189	                _Frame(
190	                    plan=step.plan,
191	                    path_prefix=top.path_prefix + (step.id,),
192	                    child_index=0,
193	                )
194	            )
195	            pending.append(None)
196	        elif kind == "nested_exited":
197	            if len(frames) <= 1:
198	                raise TaskRunGateError(
199	                    reason="nested_exited at root frame",
200	                    recovery="inspect events.jsonl",
201	                )
202	            frames.pop()
203	            pending.pop()
204	            frames[-1].child_index += 1
205	            pending[-1] = None
206	        elif kind == "iteration_started":
207	            top = frames[-1]
208	            if top.child_index >= len(top.plan.steps):
209	                continue
210	            host_step = top.plan.steps[top.child_index]
211	            iteration = int(event.get("iteration", 1))
212	            frames.append(_make_iteration_frame(host_step, top.path_prefix, iteration))
213	            pending.append(None)
214	        elif kind == "iteration_failed":
215	            if frames[-1].repeat_step_id is None:
216	                continue
217	            frames.pop()
218	            pending.pop()
219	            pending[-1] = None
220	        elif kind == "for_each_expanded":
221	            host_path = _path_str_from_event(event)
222	            items = tuple(event.get("item_ids") or ())
223	            for_each_progress.setdefault(host_path, {"items": items, "completed": set()})
224	            for_each_progress[host_path]["items"] = items
225	        elif kind == "item_started":
226	            top = frames[-1]
227	            if top.child_index >= len(top.plan.steps):
228	                continue
229	            host_step = top.plan.steps[top.child_index]
230	            item_id = event.get("item_id")
231	            if not isinstance(item_id, str):
232	                continue
233	            frames.append(_make_item_frame(host_step, top.path_prefix, item_id))
234	            pending.append(None)
235	        elif kind in ("item_completed", "item_attested"):
236	            host_path = _path_str_from_event(event)
237	            item_id = event.get("item_id")
238	            if not isinstance(item_id, str):
239	                continue
240	            entry = for_each_progress.setdefault(host_path, {"items": (), "completed": set()})
241	            entry["completed"].add(item_id)
242	            if frames[-1].item_id == item_id:
243	                frames.pop()
244	                pending.pop()
245	                pending[-1] = None
246	            # If all items now completed and the host's parent frame is on top, advance host.
247	            if entry["items"] and set(entry["items"]) <= entry["completed"]:
248	                host_segments = host_path.split(STEP_PATH_SEP) if host_path else []
249	                expected_parent_prefix = tuple(host_segments[:-1])
250	                if tuple(frames[-1].path_prefix) == expected_parent_prefix:
251	                    if frames[-1].child_index < len(frames[-1].plan.steps):
252	                        candidate = frames[-1].plan.steps[frames[-1].child_index]
253	                        if host_segments and candidate.id == host_segments[-1]:
254	                            frames[-1].child_index += 1
255	                            pending[-1] = None
256	        elif kind in ("step_completed", "step_attested"):
257	            top = frames[-1]
258	            if top.child_index >= len(top.plan.steps):
259	                continue
260	            step = top.plan.steps[top.child_index]
261	            produces = getattr(step, "produces", ())
262	            if not produces:
263	                top.child_index += 1
264	                pending[-1] = None
265	            else:
266	                pending[-1] = {entry.name for entry in produces}
267	        elif kind == "produces_check_passed":
268	            current = pending[-1]
269	            if current is not None:
270	                name = event.get("produces_name")
271	                current.discard(name)
272	                if not current:
273	                    frames[-1].child_index += 1
274	                    pending[-1] = None
275	        elif kind in ("produces_check_failed", "cursor_rewind"):
276	            pending[-1] = None
277	        elif kind == "step_dispatched":
278	            pending[-1] = None
279	        # run_started / iteration_exhausted: no-op for cursor
280	    _finalize_cursor(frames, pending, for_each_progress)
281	    return CursorPath(frames=frames, for_each_progress=for_each_progress, pinned_failure=pinned_failure)

308	def _finalize_cursor(
309	    frames: list[_Frame],
310	    pending: list[set[str] | None],
311	    for_each_progress: dict[str, dict[str, Any]],
312	) -> None:
313	    """Pop exhausted iteration/item frames after event replay.
314	
315	    For verifier_passes / approve cases, the iteration frame ends with
316	    ``produces_check_passed`` coverage or ``step_attested`` (no following
317	    iteration_failed) — the iter frame's child_index is at end-of-plan.
318	    Pop it and advance the host. Same for item frames whose item is in
319	    the for_each_progress.completed set.
320	    """
321	    while True:
322	        top = frames[-1]
323	        if top.repeat_step_id is None:
324	            break
325	        if top.child_index < len(top.plan.steps):
326	            break
327	        if top.item_id is not None:
328	            host_path_segments = top.path_prefix + (top.repeat_step_id,)
329	            host_path = STEP_PATH_SEP.join(host_path_segments)
330	            entry = for_each_progress.get(host_path)
331	            frames.pop()
332	            pending.pop()
333	            pending[-1] = None
334	            if entry is not None and entry["items"] and set(entry["items"]) <= entry["completed"]:
335	                frames[-1].child_index += 1
336	                pending[-1] = None
337	        else:
338	            frames.pop()
339	            pending.pop()
340	            frames[-1].child_index += 1
341	            pending[-1] = None

344	def _path_str_from_event(event: dict[str, Any]) -> str:
345	    path = event.get("plan_step_path")
346	    if isinstance(path, list):
347	        return STEP_PATH_SEP.join(str(p) for p in path)
348	    pid = event.get("plan_step_id")
349	    return pid if isinstance(pid, str) else ""

352	def gate_command(
353	    slug: str,
354	    command: str,
355	    argv: Sequence[str],
356	    *,
357	    root: str | Path | None = None,
358	    reentry: bool = False,
359	) -> GateDecision:
360	    active_run = read_active_run(slug, root=root)
361	    if active_run is None:
362	        if not is_in_task_run(slug):
363	            return GateDecision(active=False)
364	        _reject(slug, "active_run.json is missing", abort=True)
365	
366	    project_root = project_dir(slug, root=root)
367	    plan_path = project_root / "plan.json"
368	    plan_hash = compute_plan_hash(plan_path)
369	    if plan_hash != active_run["plan_hash"]:
370	        _reject(slug, "plan.json hash does not match active_run.json pin", abort=True)
371	
372	    run_id = active_run["run_id"]
373	    events_path = project_root / "runs" / run_id / "events.jsonl"
374	    ok, _last_index, error = verify_chain(events_path)
375	    if not ok:
376	        _reject(slug, error or "events.jsonl chain integrity check failed", abort=True)
377	
378	    plan = load_plan(plan_path)
379	    events = read_events(events_path)
380	    cursor = derive_cursor(plan, events, slug=slug)
381	    if cursor.pinned_failure is not None:
382	        reason, _host_path = cursor.pinned_failure
383	        raise TaskRunGateError(reason=reason, recovery=f"artagents abort --project {slug}")
384	    run_started_actor = _find_run_started_actor(events)
385	
386	    # Auto-traverse: nested_entered/exited for nested plans; iteration_started/
387	    # for_each_expanded/item_started for repeat hosts. We loop until we land on a
388	    # dispatchable leaf (CodeStep or AttestedStep) inside the appropriate frame.
389	    while True:
390	        if cursor.at_root_done:
391	            _reject(slug, "plan is exhausted", abort=True)
392	        if cursor.top_exhausted:
393	            top = cursor.frames[-1]
394	            if top.repeat_step_id is not None:
395	                # Defensive: _finalize_cursor should have popped these already.
396	                cursor.frames.pop()
397	                cursor.frames[-1].child_index += 1
398	                continue
399	            exit_path_str = STEP_PATH_SEP.join(top.path_prefix)
400	            append_event(events_path, make_nested_exited_event(exit_path_str, 0))
401	            cursor.frames.pop()
402	            cursor.frames[-1].child_index += 1
403	            continue
404	        top = cursor.frames[-1]
405	        current_step = top.plan.steps[top.child_index]
406	        current_path = top.path_prefix + (current_step.id,)
407	        path_str = STEP_PATH_SEP.join(current_path)
408	        repeat = getattr(current_step, "repeat", None)
409	        in_repeat_frame = top.repeat_step_id is not None
410	        if repeat is not None and not in_repeat_frame:
411	            if isinstance(repeat, RepeatUntil):
412	                _enter_repeat_until(
413	                    slug=slug,
414	                    cursor=cursor,
415	                    host=current_step,
416	                    repeat=repeat,
417	                    path_str=path_str,
418	                    parent_prefix=top.path_prefix,
419	                    events=events,
420	                    events_path=events_path,
421	                )
422	                # Refresh local references.
423	                events = read_events(events_path)
424	                top = cursor.frames[-1]
425	                current_step = top.plan.steps[top.child_index]
426	                current_path = top.path_prefix + (current_step.id,)
427	                path_str = STEP_PATH_SEP.join(current_path)
428	                continue
429	            if isinstance(repeat, RepeatForEach):
430	                next_item_id = _enter_repeat_for_each(
431	                    slug=slug,
432	                    cursor=cursor,
433	                    host=current_step,
434	                    repeat=repeat,
435	                    path_str=path_str,
436	                    parent_prefix=top.path_prefix,
437	                    events=events,
438	                    events_path=events_path,
439	                    project_root=project_root,
440	                    run_id=run_id,
441	                    incoming_command=command,
442	                )
443	                events = read_events(events_path)
444	                top = cursor.frames[-1]
445	                current_step = top.plan.steps[top.child_index]
446	                current_path = top.path_prefix + (current_step.id,)
447	                path_str = STEP_PATH_SEP.join(current_path)
448	                continue
449	        if isinstance(current_step, NestedStep):
450	            child_hash = _compute_inline_plan_hash(current_step.plan)
451	            append_event(events_path, make_nested_entered_event(path_str, child_hash))
452	            cursor.frames.append(
453	                _Frame(plan=current_step.plan, path_prefix=current_path, child_index=0)
454	            )
455	            continue
456	        break
457	
458	    iteration = top.iteration if top.repeat_step_id is not None else None
459	    item_id = top.item_id if top.repeat_step_id is not None else None
460	
461	    if isinstance(current_step, CodeStep):
462	        return _dispatch_code(
463	            slug=slug,
464	            command=command,
465	            step=current_step,
466	            path_str=path_str,
467	            path_tuple=current_path,
468	            events_path=events_path,
469	            run_id=run_id,
470	            reentry=reentry,
471	            project_root=project_root,
472	            iteration=iteration,
473	            item_id=item_id,
474	        )
475	    if isinstance(current_step, AttestedStep):
476	        return _dispatch_attested(
477	            slug=slug,
478	            command=command,
479	            step=current_step,
480	            path_str=path_str,
481	            path_tuple=current_path,
482	            events_path=events_path,
483	            run_id=run_id,
484	            run_started_actor=run_started_actor,
485	            project_root=project_root,
486	            iteration=iteration,
487	            item_id=item_id,
488	        )
489	    raise TaskRunGateError(
490	        reason=f"unexpected step kind: {type(current_step).__name__}",
491	        recovery=f"artagents next --project {slug}",
492	    )

496	    return sum(
497	        1

529	def _enter_repeat_until(
530	    *,
531	    slug: str,
532	    cursor: CursorPath,
533	    host: Any,
534	    repeat: RepeatUntil,
535	    path_str: str,
536	    parent_prefix: tuple[str, ...],
537	    events: Sequence[dict[str, Any]],
538	    events_path: Path,
539	) -> None:
540	    failed = _count_iteration_failed(events, path_str)
541	    iteration = failed + 1
542	    path_tuple = parent_prefix + (host.id,)
543	    if iteration > repeat.max_iterations:
544	        existing = _has_iteration_exhausted(events, path_str)
545	        if existing is None:
546	            append_event(
547	                events_path,
548	                make_iteration_exhausted_event(
549	                    path_tuple,
550	                    on_exhaust=repeat.on_exhaust,
551	                    max_iterations=repeat.max_iterations,
552	                ),
553	            )
554	        if repeat.on_exhaust == "fail":
555	            raise TaskRunGateError(
556	                reason="repeat.until max_iterations exhausted",
557	                recovery=f"artagents abort --project {slug}",
558	            )
559	        # escalate: park on a synthetic exhaust-override attested step.
560	        override_step = _make_exhaust_override_step(slug, path_str)
561	        override_plan = TaskPlan(
562	            plan_id=f"__exhaust_{host.id}",
563	            version=1,
564	            steps=(override_step,),
565	        )
566	        cursor.frames.append(
567	            _Frame(
568	                plan=override_plan,
569	                path_prefix=path_tuple,
570	                child_index=0,
571	                repeat_step_id=host.id,
572	            )
573	        )
574	        return
575	    append_event(events_path, make_iteration_started_event(path_tuple, iteration))
576	    cursor.frames.append(_make_iteration_frame(host, parent_prefix, iteration))

579	def _resolve_for_each_items(
580	    *,
581	    slug: str,
582	    repeat: RepeatForEach,
583	    project_root: Path,
584	    run_id: str,
585	) -> tuple[str, ...]:
586	    if repeat.items_source == "static":
587	        items = repeat.items
588	    else:
589	        target_id, produces_name = parse_from_ref(repeat.from_ref or "")
590	        prior_step_dir = step_dir_for_path(slug, run_id, (target_id,), root=project_root.parent)
591	        # Find the prior step's declared produces path. We need the plan for that.
592	        # We re-load plan.json which is allowed at gate_command (not in derive_cursor).
593	        plan = load_plan(project_root / "plan.json")
594	        target_step = next((s for s in plan.steps if s.id == target_id), None)
595	        if target_step is None:
596	            raise TaskRunGateError(
597	                reason=f"for_each.from references unknown sibling step {target_id!r}",
598	                recovery=f"artagents abort --project {slug}",

914	def match_attested_command(incoming: str, expected_prefix: str) -> tuple[bool, AttestedArgs]:
915	    """Strip ``--agent``/``--actor``/``--evidence``/``--item`` (repeatable evidence)
916	    tokens from ``incoming`` and compare the canonical remainder to ``expected_prefix``.
917	    """
918	    try:
919	        tokens = shlex.split(incoming)
920	    except ValueError:
921	        return False, AttestedArgs(agent=None, actor=None, evidence=())
922	    agent: str | None = None
923	    actor: str | None = None
924	    item: str | None = None
925	    evidence: list[str] = []
926	    remaining: list[str] = []
927	    i = 0
928	    while i < len(tokens):
929	        token = tokens[i]
930	        if token == "--agent" and i + 1 < len(tokens):
931	            agent = tokens[i + 1]
932	            i += 2
933	            continue
934	        if token == "--actor" and i + 1 < len(tokens):
935	            actor = tokens[i + 1]
936	            i += 2
937	            continue
938	        if token == "--item" and i + 1 < len(tokens):
939	            item = tokens[i + 1]
940	            i += 2
941	            continue
942	        if token == "--evidence" and i + 1 < len(tokens):
943	            evidence.append(tokens[i + 1])
944	            i += 2
945	            continue
946	        remaining.append(token)
947	        i += 1
948	    rejoined = " ".join(shlex.quote(token) for token in remaining)
949	    matched = rejoined == expected_prefix
950	    return matched, AttestedArgs(agent=agent, actor=actor, evidence=tuple(evidence), item=item)

        # Implementation Plan: Extract AgentChat to Global Floating Button

## Overview

AgentChat is a 703-line component in `src/tools/video-editor/components/AgentChat/AgentChat.tsx` rendered 3× inside `VideoEditorShell.tsx`. It uses `createPortal(content, document.body)` so it already renders as a fixed-position overlay. The goal is to render it once at the app level (inside `AppInternalContent` in `src/app/App.tsx`) so it appears on every page, while preserving all video-editor-specific functionality (timeline clip selection, timeline editor ops) when the user is on the video editor page.

**Core challenge:** Two hooks — `useTimelineEditorOps()` and `useSelectedMediaClips()` — throw if called outside `TimelineEditorContext`. These are used for attachment management (selecting/deselecting timeline clips). All other hooks (agent sessions, voice, panes, gallery selection) work at app level already.

**Approach:** Create an `AgentChatContext` that bridges the gap. The video editor provides timeline-specific capabilities into this context when mounted; AgentChat consumes the context instead of calling the video-editor hooks directly. When not on the video editor page, timeline clip features gracefully degrade (no timeline clips, attachment removal for timeline clips is a no-op).

## Phase 1: Create AgentChatContext Bridge

### Step 1: Create AgentChatContext (`src/shared/contexts/AgentChatContext.tsx`)
**Scope:** Medium
1. **Define** an `AgentChatContextValue` interface with:
   - `timelineId: string | null` — null when not on video editor
   - `timelineClips: SelectedMediaClip[]` — empty array when not on video editor
   - `replaceSelectedTimelineClips: (clips: SelectedMediaClip[]) => void` — no-op when not on video editor
2. **Create** provider and hook (`useAgentChatBridge`).
3. **Export** a default provider that returns `{ timelineId: null, timelineClips: [], replaceSelectedTimelineClips: noop }` for non-video-editor pages.

### Step 2: Wire VideoEditorProvider to supply AgentChatContext (`src/tools/video-editor/contexts/VideoEditorProvider.tsx`)
**Scope:** Small
1. **Add** a child component inside VideoEditorProvider (after TimelineEditorOpsContextProvider) that calls `useTimelineEditorOps()` and `useSelectedMediaClips()` and pushes them into `AgentChatContext` via the provider.
2. This replaces the current pattern of AgentChat calling these hooks directly.

## Phase 2: Move AgentChat to Shared & Render Globally

### Step 3: Relocate AgentChat files to `src/shared/components/AgentChat/`
**Scope:** Medium
1. **Move** `AgentChat.tsx`, `AgentChatMessage.tsx`, and `index.ts` from `src/tools/video-editor/components/AgentChat/` to `src/shared/components/AgentChat/`.
2. **Update** imports:
   - Replace `useTimelineEditorOps()` call with `useAgentChatBridge()` from the new context.
   - Replace `useSelectedMediaClips()` call with reading `timelineClips` from `useAgentChatBridge()`.
   - Replace `replaceSelectedTimelineClips` callback with the one from context.
   - Keep `useAgentSession`, `useAgentSessions`, `useSendMessage`, `useCancelSession`, `useCreateSession` — these are React Query hooks that work anywhere, they just need `timelineId` which now comes from context.
   - Keep `useAgentVoice`, `usePanes`, `useGallerySelection` — already app-level.
3. **Change** the `AgentChatProps` type: remove `timelineId` prop (now from context). The component becomes prop-less.
4. **Guard** agent session hooks: when `timelineId` is null, don't fetch sessions and don't render the chat (or render with reduced functionality — see Questions below).

### Step 4: Render AgentChat in AppInternalContent (`src/app/App.tsx`)
**Scope:** Small
1. **Add** `<AgentChat />` inside the `DndContext` in `AppInternalContent`, alongside `<AppRoutes />`. Since it uses `createPortal` already, placement in the tree is for context access, not DOM position.
2. **Wrap** with `AgentChatProvider` (the default/fallback provider) in `AppProviders.tsx` — or render the default provider directly in `App.tsx`.

### Step 5: Remove AgentChat from VideoEditorShell (`src/tools/video-editor/components/VideoEditorShell.tsx`)
**Scope:** Small

### Step 6: Move supporting hooks/types to shared (`src/tools/video-editor/hooks/useAgentSession.ts`, `useAgentVoice.ts`, `useSelectedMediaClips.ts`)

2. **Move** `useAgentVoice.ts` to `src/shared/hooks/useAgentVoice.ts` — wraps `useVoiceRecording`, no video-editor dependency.

Export `SelectedMediaClip` type and `buildSummary`/`buildAttachedSummary` from there (or from a shared types file if needed by `AgentChatContext`).

5. **Move** `loadGenerationForLightbox` utility if it lives in video-editor — check if it has video-editor dependencies.

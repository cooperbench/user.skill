        # Implementation Plan: Generalize Eval Harness for Multi-Benchmark Support

## Overview

The `evals/` harness currently has three next-evals-oss-specific hardcoded concerns:

1. **Workspace setup** (`setup_evals_repo` → clone next-evals-oss, `prepare_workspace` → npm install + next@canary)
2. **Task prompt extraction** (`_read_prompt` → reads `PROMPT.md` from eval dir)
3. **Scoring** (`check_build` → npm run build, `run_eval_ts` → vitest EVAL.ts, `generate_results_json` → next-evals schema)

The megaplan orchestration (`run_megaplan_loop`) and audit system are already benchmark-agnostic. The `run_all_evals` function already accepts dependency-injected callables for setup, prepare, build, eval, and results generation.

**Existing asset**: `environments/benchmarks/terminalbench_2/terminalbench2_env.py` already implements a full TB2 evaluation flow using the Atropos framework (HuggingFace dataset, Modal sandboxes, binary pass/fail). This is a _different_ execution model (Atropos agent loop) from the megaplan loop. The new TB2 backend for the eval harness needs to use megaplan orchestration + Docker containers locally, not the Atropos path.

**Strategy**: Extract a `Benchmark` protocol/ABC from the existing next-evals code, implement a parallel `TerminalBenchBackend`, and route via a `benchmark` config field. The megaplan loop, audit, phase routing, and stuck detection remain untouched.

## Phase 1: Foundation — Benchmark Interface and Config

### Step 1: Define the `Benchmark` protocol (`evals/benchmarks/__init__.py`)
**Scope:** Small
1. **Create** `evals/benchmarks/__init__.py` with an ABC/Protocol defining the benchmark contract:
   ```python
   class Benchmark(Protocol):
       def setup_source(self, config: EvalConfig) -> Path:
           """Clone/fetch the benchmark source. Returns source root."""
       def list_tasks(self, source: Path, filter_names: list[str] | None) -> list[str]:
           """Return available task names."""
       def prepare_workspace(self, task_name: str, source: Path, workspace_dir: Path, timeout: int) -> PreparedWorkspace:
           """Set up an isolated workspace for one task."""
       def read_prompt(self, task_name: str, source: Path) -> str:
           """Extract the task prompt/instruction."""
       def score(self, workspace: PreparedWorkspace, audit: EvalAudit, config: EvalConfig) -> ScoringResult:
           """Run build/test scoring. Returns structured result."""
       def capture_environment(self, source: Path) -> dict[str, Any]:
           """Capture benchmark-specific environment metadata."""
   ```
2. **Define** a `ScoringResult` dataclass that unifies the next-evals `BuildResult`+`EvalRunResult`+`results_json` into a common return type with fields: `status` (passed/failed/error), `build_result`, `eval_result`, `results_json`, `notes`.

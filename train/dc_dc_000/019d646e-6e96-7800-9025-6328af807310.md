### Step 2: Add get_effective() to io.py (`megaplan/_core/io.py`)
**Scope:** Small
1. **Add** `get_effective(section, key)` after `save_config()` (after line 248):
   ```python
   def get_effective(section: str, key: str) -> Any:
       dot_key = f"{section}.{key}"
       config = load_config()
       try:
           return config[section][key]
       except (KeyError, TypeError):
           pass
       from megaplan.types import DEFAULTS
       return DEFAULTS[dot_key]
   ```
   - Checks user config first (`config[section][key]`), falls back to `DEFAULTS[dot_key]`.
   - Raises `KeyError` if the key isn't in DEFAULTS either (caller bug).
   - Import DEFAULTS lazily to avoid circular imports (types.py doesn't import io.py, but being safe).

## Step 3 — Rewrite snapshot phase resolution

**File:** `desloppify/engine/_work_queue/snapshot.py`

### 3a. Replace `_phase_for_snapshot()` with `_mode_for_snapshot()`

New logic is simple:
1. Read persisted mode via `current_mode(plan)`.
2. If it returns a valid mode, use it.
3. If None (no plan / no persisted value): infer from partitions — if any plan-mode partitions are non-empty → `"plan"`, else if execution items exist → `"execute"`, else → `"scan"`.

This replaces ~150 lines (`_phase_for_snapshot`, `_legacy_phase_inference`, `_sticky_postflight_phase`, `_ordered_postflight_phase`) with ~15 lines.

### 3b. Replace `_execution_items_for_phase()` with `_execution_items_by_priority()`

Instead of switching on phase, scan partitions in fixed priority order (same as the activity table in Step 2). Return items from the first non-empty partition. Also return the activity string.

```python
def _execution_items_by_priority(
    *,
    initial_review_items, postflight_assessment_items,
    postflight_workflow_items, triage_items,
    postflight_review_items, explicit_queue_items, scan_items,
) -> tuple[list[WorkQueueItem], str]:
    _PRIORITY = [
        (initial_review_items, "reviewing"),
        (postflight_assessment_items, "assessing"),
        (postflight_workflow_items, "workflow"),
        (triage_items, "triaging"),
        (postflight_review_items, "reviewing"),
        (explicit_queue_items, "executing"),
        (scan_items, "scanning"),
    ]
    for items, activity in _PRIORITY:
        if items:
            return items, activity
    return [], "scanning"
```

### 3c. Update `build_queue_snapshot()`

Call `_mode_for_snapshot()` for `phase`, call `_execution_items_by_priority()` for `execution_items` + `current_activity`.

### 3d. Remove dead code

Delete: `_FINE_GRAINED_ITEM_MAP`, `_COARSE_POSTFLIGHT_PHASES`, `_phase_for_snapshot`, `_ordered_postflight_phase`, `_legacy_phase_inference`, `_sticky_postflight_phase`, all `PHASE_*` aliases.

## Step 4 — Simplify `_resolve_reconcile_phase()` in the reconcile pipeline

**File:** `desloppify/engine/_plan/sync/pipeline.py`

### 4a. Rename to `_resolve_mode()`

New logic:
- If any plan-mode items exist in queue_order (subjective, workflow, triage, scan items) → `MODE_PLAN`
- If objective execution items exist → `MODE_EXECUTE`
- Fallback → `MODE_SCAN`

This collapses the current 8-branch function to 3 branches.

### 4b. Fix the circular deadlock

Reorder `reconcile_plan()` so that:
1. Compute mode FIRST (before `sync_subjective_dimensions`)
2. Pass mode to `sync_subjective_dimensions` — it checks `mode != MODE_EXECUTE` before injecting stale dimensions
3. After sync, recompute mode (queue_order may have changed)
4. Persist via `set_mode()`

The key fix: `sync_subjective_dimensions` no longer needs the phase to decide whether to inject — it uses the mode, and the mode is stable (plan stays plan until queue drains to execute).

### 4c. Gate stale injection to plan mode

In `sync_subjective_dimensions()` (dimensions.py), add a guard: only inject stale/under-target dimensions when `mode != MODE_EXECUTE`. This replaces the current implicit gating through phase ordering.

## Step 3 — Simplify `_resolve_reconcile_phase` in pipeline.py

**File:** `desloppify/engine/_plan/sync/pipeline.py`

Replace `_resolve_reconcile_phase()` with `_resolve_reconcile_mode()`. Critical fix: `workflow::run-scan` and `workflow::deferred-disposition` are scan-mode items despite the `workflow::` prefix — they must NOT trigger plan mode.

```python
from desloppify.engine._plan.constants import WORKFLOW_RUN_SCAN_ID, WORKFLOW_DEFERRED_DISPOSITION_ID

_SCAN_WORKFLOW_IDS = frozenset({WORKFLOW_RUN_SCAN_ID, WORKFLOW_DEFERRED_DISPOSITION_ID})

def _resolve_reconcile_mode(plan, state, *, result, policy) -> str:
    order = [item for item in plan.get("queue_order", []) if isinstance(item, str)]

    # Any subjective, non-scan workflow, or triage items → plan mode
    has_planning_items = any(
        item.startswith("subjective::")
        or item.startswith("triage::")
        or (item.startswith("workflow::") and item not in _SCAN_WORKFLOW_IDS)
        for item in order
    )
    if has_planning_items:
        return LIFECYCLE_MODE_PLAN

    # Check if triage completed but open issues remain (post-triage review)
    triage_snapshot = build_triage_snapshot(plan, state)
    if (
        triage_snapshot.triage_has_run
        and not triage_snapshot.has_triage_in_queue
        and not triage_snapshot.is_triage_stale
        and bool(triage_snapshot.live_open_ids)
    ):
        return LIFECYCLE_MODE_PLAN

    # Non-synthetic items in queue → execute
    if any(
        not is_synthetic_id(item) and item not in plan.get("skipped", {})
        for item in order
    ):
        return LIFECYCLE_MODE_EXECUTE

    # Scan workflow items present → scan
    if any(item in _SCAN_WORKFLOW_IDS for item in order):
        return LIFECYCLE_MODE_SCAN

    return LIFECYCLE_MODE_SCAN
```

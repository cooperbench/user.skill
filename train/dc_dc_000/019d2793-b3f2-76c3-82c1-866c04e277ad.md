## Phase 3: Orchestrator — The Main Loop

### Step 7: Workspace setup (`evals/run_evals.py` — setup portion)
**Scope:** Medium
1. **Implement** `setup_evals_repo(config: EvalConfig) -> Path`:
   - Clone next-evals-oss if not present, else fetch
   - Checkout specified ref
   - Run `npm run sync-evals`
   - Return path to `evals/` directory
2. **Implement** `prepare_workspace(eval_dir: Path, workspace_dir: Path) -> Path`:
   - Copy eval directory to clean workspace
   - `git init` the workspace (for diffing)
   - Run `npm install && npm install next@canary`
   - `git add -A && git commit -m "initial"`
   - Return workspace path

### Step 8: Megaplan invocation (`evals/run_evals.py` — megaplan loop)
**Scope:** Large — core orchestration logic
1. **Implement** `run_megaplan_loop(prompt: str, workspace: Path, config: EvalConfig, audit: EvalAudit) -> bool`:
   - Shell out to megaplan CLI for each phase, using `--hermes` flag and `--phase-model` for per-phase model routing
   - Phase sequence:
     ```
     megaplan init --idea "{prompt}" --project-dir {workspace}
     megaplan plan --hermes --phase-model plan={config.models["plan"]}
     megaplan critique --hermes --phase-model critique={config.models["critique"]}
     megaplan gate
     # If gate returns ITERATE: loop back to plan (max config.max_gate_iterations times)
     megaplan finalize --hermes --phase-model finalize={config.models["finalize"]}
     megaplan execute --user-approved --hermes --phase-model execute={config.models["execute"]}
     megaplan review --hermes --phase-model review={config.models["review"]}
     ```
   - After each phase: read the artifact from `.megaplan/plans/{name}/`, add to audit
   - After execute: extract conversation trace from SessionDB using session_id from state.json
   - Handle timeouts per-phase
   - Return success/failure

2. **Implement** gate iteration handling:
   - After `megaplan gate`, read `gate.json` from plan directory
   - If `gate_recommendation == "ITERATE"`: increment counter, loop back to `megaplan plan` (which generates plan_v{n+1})
   - If counter exceeds `max_gate_iterations`: force PROCEED with a warning in audit
   - If `gate_recommendation == "ESCALATE"`: mark eval as escalated, skip to next

### Step 9: Main orchestrator loop (`evals/run_evals.py` — main)
**Scope:** Medium
1. **Implement** `run_all_evals(config_path: str)`:
   - Load config
   - Capture environment snapshot
   - Setup evals repo
   - For each eval (filtered by config.evals_to_run):
     - Prepare workspace
     - Read PROMPT.md as idea text
     - Run megaplan loop
     - Run build check
     - Generate results.json from traces
     - Run EVAL.ts scoring
     - Save audit trail
     - Print summary line (eval name, build pass/fail, eval score, cost, duration)
   - Generate summary report across all evals
2. **Implement** CLI entry point:

# DataClaw v0.4.2 — 45-second launch script

Write a 45-second spoken spot announcing DataClaw v0.4.2. The spot must land three new things and frame them around what DataClaw actually is: a tool that helps you publish your AI coding history to Hugging Face — voluntarily, knowingly, and now from a menu bar.

## What DataClaw is (the frame)

Performance-art project. Anthropic trained on the world's freely-shared data, then introduced "dystopian data policies" to stop anyone else from doing the same with theirs. DataClaw lets users throw the ladder back down: it parses Claude Code / Codex / Cursor / etc. session logs into a structured dataset and uploads it to Hugging Face. Every export gets tagged `dataclaw` so it joins a growing distributed corpus of real-world AI-coding collaboration.

## Three features the script must land (clearly, briefly)

1. **Mac menu-bar app.** Apple Silicon DMG. Drag to Applications. Bundles the Python sidecar — no `pip install`, no terminal. Auto-updater built in.
2. **Ongoing syncing.** Toggle "Sync to Hugging Face automatically." Pick an interval (1 hour to 30 days, default daily). Set it once, your dataset stays current as you keep coding.
3. **Privacy mode** (Privacy filter). On-device PII / sensitive-content scanner with GPU acceleration (Auto / Apple GPU / CPU). Sits on top of the existing username + secret-regex + email + entropy + custom-string redaction layers.

Dark, knowing, salesman-who-knows-the-joke. The voice that openly admits the absurdity of the product and sells it harder for the admission. ## Hard constraints

- Must reference Hugging Face publication.

- Both-sidesing the Anthropic frame — the spot has a position.

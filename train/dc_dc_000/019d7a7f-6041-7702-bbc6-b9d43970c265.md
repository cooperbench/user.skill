# Implementation Plan: Clean up 10 junk sources in real worker logs

## Overview
Ten small, unrelated log-hygiene fixes across the worker. Most live in `source/core/log/` (lifecycle, core), `source/runtime/worker/` (server, status_display), and `source/task_handlers/queue/` (task_queue, task_processor, wgp_init). The common pattern: raw `print()` calls from Wan2GP/mmgp/GGUF/UNI3C bypass the logging stack, `[WORKER]` bootstrap uses `print()` instead of `essential()`, the dandelion TUI writes VT100 escapes to redirected stdout, `lifecycle.task()` reopens a second anchor on worker threads because its `contextvars.ContextVar` isn't inherited, PNG conversion has no retry, and `RunSummary.render()` passes dicts to `DebugCard` where `reprlib + textwrap` break them mid-token.

Scope is strictly the 10 items below; no adjacent refactors.

## Main Phase

### Step 1: Add a stdout filter + register WGP/mmgp/GGUF/UNI3C substrings (`source/core/log/core.py`, `source/runtime/worker/server.py`)
**Scope:** Medium

1. **Add** a `StdoutFilter` class in `source/core/log/core.py` (near `set_log_interceptor`, ~line 365). It wraps the original `sys.stdout`, buffers per-write into lines, and drops any line whose text matches a registered substring set; non-matching lines pass through untouched. Expose `install_stdout_filter(substrings: Iterable[str]) -> None` and `uninstall_stdout_filter() -> None`. Keep `sys.__stdout__` unmodified so the log interceptor and `_write_to_log_file` paths remain correct.
2. **Seed** the default substring set with the known raw prints: `"Incorrect version of mmgp"` (`Wan2GP/wgp.py:118`), `"[UNI3C]"` (`Wan2GP/models/wan/modules/model.py:1466,1726..1942`, `Wan2GP/models/wan/any2video.py:418..484`), `"[GGUF]"` and `"GGUF qtypes:"` (`Wan2GP/shared/qtypes/gguf.py:302`, `Wan2GP/models/ltx2/ltx_core/model/transformer/transformer_args.py:226`). In debug mode (`is_debug_enabled()`), do NOT install the filter — the user asked about real worker logs, but we must not hide noise when they are actively debugging.
3. **Call** `install_stdout_filter()` from `main()` in `source/runtime/worker/server.py` right after `suppress_library_logging()` at `server.py:354`, and from `run_preview` in `scripts/preview/run_preview.py:458` alongside `suppress_library_logging()`.

   ```python

   suppress_library_logging()
   ```

4. **Do not** swap `sys.stdout` before the `CustomLogInterceptor` is wired — the interceptor reads from the already-written formatted strings, not from stdout, so order is safe, but keep the filter install before `set_log_interceptor()` so the interceptor sees a stable stream.

### Step 2: Thread-safe nested-task guard in `lifecycle.task()` (`source/core/log/lifecycle.py`)
**Scope:** Small

1. **Inspect** the current contextvars-based guard (`source/core/log/lifecycle.py:180-205`). `_active_anchor` is a `ContextVar`, which is thread-local: when `HeadlessTaskQueue` dispatches into a `GenerationWorker-N` thread (`source/task_handlers/queue/queue_lifecycle.py:43-49`), the inner `lifecycle.task(...)` call in `source/task_handlers/queue/task_processor.py:134` sees `_active_anchor.get() is None` → it opens a **second** anchor for the same `task_id`, producing a duplicated `❀ Task started` / `✿ Task done` pair.
2. **Add** a module-level thread-safe active set next to the emitter:

   ```python
   class TaskLifecycleEmitter:
       def __init__(self):
           self._active_anchor = contextvars.ContextVar(
               "task_lifecycle_active_anchor", default=None,
           )
           self._active_task_ids: set[str] = set()
           self._active_lock = threading.Lock()
           self.run_summary = RunSummary()
   ```

3. **Change** the `task()` contextmanager entry (`lifecycle.py:195-205`) to treat a match on either the contextvar OR a concurrently-active `task_id` as nested:

   ```python
   active = self._active_anchor.get()
   if active is None and task_id:
       with self._active_lock:
           if task_id in self._active_task_ids:
               active = _RemoteHandle(task_id, task_type, details)
   if active is not None:
       if details:
           active.set(**details)
       yield _PassthroughHandle(active)
       return
   ```

   Because the original `_TaskHandle` for the outer anchor lives in the parent thread's context, the worker thread cannot mutate it directly. Introduce a thin `_RemoteHandle` that silently absorbs `.set()` calls (or reuse `_PassthroughHandle` against a no-op stub) — the outer anchor is already doing the accounting, the inner just needs to stay quiet and hand back a handle so caller code continues to work.
4. **Register/unregister** the task_id in the outer-anchor branch only:

   ```python
   if task_id:
       with self._active_lock:
           self._active_task_ids.add(task_id)
   try:
       ...
   finally:
       self._active_anchor.reset(token)
       if task_id:
           with self._active_lock:
               self._active_task_ids.discard(task_id)
   ```
5. **Keep** the `None` task_id case behaving exactly as today (no registration, no dedup) so ad-hoc anchors continue to stack.

### Step 6: Add a retry loop around PNG conversion (`source/task_handlers/queue/task_queue.py`)
**Scope:** Small

1. **Wrap** the cv2 read/write section in `_convert_single_frame_video_to_png` (`source/task_handlers/queue/task_queue.py:449-485`) in a bounded retry loop — 3 attempts, 0.25s backoff:

   ```python
   last_error = None
   for attempt in range(3):
       cap = cv2.VideoCapture(str(video_path_obj))
       try:
           if cap.isOpened():
               ret, frame = cap.read()
               if ret and cv2.imwrite(str(png_path), frame) and png_path.exists():
                   try:
                       video_path_obj.unlink()
                   except OSError as e_cleanup:
                       self.logger.warning(f"[PNG_CONVERSION] Task {task.id}: Could not remove original video: {e_cleanup}")
                   return str(png_path)
               last_error = "frame-read-or-write"
           else:
               last_error = "cap-not-opened"
       finally:
           cap.release()
       time.sleep(0.25)
   self.logger.error(f"[PNG_CONVERSION] Task {task.id}: conversion failed after 3 attempts ({last_error})")
   ```
2. **Preserve** the existing `ImportError` / catch-all branches at lines 479-485 and the "return original video path" fallback at line 485.

**Scope:** Small

   ```python
   def _fmt_summary(pairs: dict[str, Any]) -> str:
       return "  ".join(
           f"{k}={v}" for k, v in pairs.items()
           if v not in (None, "")
       )

   card.row("Overall", _fmt_summary({
       "tasks": len(entries),
       "successes": overall_successes,
       "failures": overall_failures,

   }))
   ```

## Overview
`banodoco/Reigh-Worker.git` now embeds `Wan2GP/` as a git submodule. The two places that provision/refresh that repo — the install/run command builder in `reigh-app/src/shared/components/SettingsModal/commandUtils.ts` and the RunPod bootstrap script `reigh-worker-orchestrator/gpu_orchestrator/runpod/worker_startup.template.sh` — use `git clone --depth 1` + `git pull --ff-only` (or `git reset --hard origin/main`) which do not populate submodules. The fix is to insert `git submodule update --init --recursive` after the sync step in every branch, using the shell dialect appropriate to that branch. Changes must be left staged, not committed.

Constraints:
- Three shell dialects in `commandUtils.ts` (bash `&&` chain, PowerShell newline, cmd `&&` chain joined on one line).
- `worker_startup.template.sh` has two entry paths (fresh clone vs existing dir) that both converge at `git reset --hard origin/main` (L261), so one submodule call after the reset block is sufficient and simpler than duplicating at the clone site.
- Depth-1 clones still work with `git submodule update --init --recursive`; the submodule fetch is independent.
- The fallback `Headless-Wan2GP` dir has no submodule; running the command there is a harmless no-op.
- No commit — leave staged only.

Two independent bugs caused this:

### Bug 1 — stdout/stderr from the remote training command is invisible

Current `train_cmd` (around line 72):
```python
train_cmd = (
    "cd /app/ai-toolkit && "
    f"python3 run.py {args.config_path} --log {args.remote_log}"
)
```

ai-toolkit's `run.py --log <file>` redirects all of stdout/stderr to the pod-local file via `toolkit.print.Logger`. Locally we get nothing in `exec_result.json["stdout"]` / `["stderr"]`. When the pod dies (RunPod eviction or container exit), we lose the log entirely.

**Fix:** use shell tee so stdout AND the local file both capture output:
```python
train_cmd = (
    "cd /app/ai-toolkit && "
    f"python3 run.py {args.config_path} 2>&1 | tee {args.remote_log}"
)
```

Confirm this still works — `--log` invokes ai-toolkit's internal Logger; with `tee` instead, ai-toolkit's print statements go to stdout normally. Tee captures them to file AND lets cmd_exec slurp them.

### Bug 2 — remote command failures don't propagate

Around lines 84-95:
```python
rv = subprocess.run(exec_argv, cwd=repo_root)
# ... read exec_result.json into training_log ...
log_text = training_log.read_text(...) if training_log.exists() else ""
failure = _scan_failures(log_text)

if failure or rv.returncode != 0:
    ...
    return rv.returncode or 4
```

`rv.returncode` is the exit code of `astrid.packs.external.runpod.run exec` — a wrapper that returns 0 even when the remote command exited non-zero. The remote exit code is in `exec_result.json["returncode"]`.

**Fix:** read `exec_result.json["returncode"]` and treat any non-zero value as failure.

```python
result_data = {}
if result_json.exists():
    try:
        result_data = json.loads(result_json.read_text(encoding="utf-8"))
    except json.JSONDecodeError:
        pass

remote_rc = int(result_data.get("returncode", -1))
training_log.write_text(
    (result_data.get("stdout", "") or "") + (result_data.get("stderr", "") or ""),
    encoding="utf-8",
)
log_text = training_log.read_text(encoding="utf-8")
failure = _scan_failures(log_text)

if failure or remote_rc != 0 or rv.returncode != 0:
    tail = "\n".join(log_text.splitlines()[-200:])
    (produces / "training.failure.log").write_text(tail, encoding="utf-8")
    manifest_path.write_text(
        json.dumps(
            {"status": "failed", "reason": failure or f"remote_exit_{remote_rc}_wrapper_{rv.returncode}", "checkpoints": []},
            indent=2,
        ) + "\n",
        encoding="utf-8",
    )
    print(f"aitoolkit_train: FAILED (remote_rc={remote_rc} wrapper_rc={rv.returncode} pattern={failure})", file=sys.stderr)
    return remote_rc or rv.returncode or 4
```

        # Implementation Plan: Standardize & Extend Audio Handling on the Video-Editor Timeline

## Overview

Two repos share nearly-identical timeline types and composition code but have drifted:

- **art-agents** (`shared/`) — uses Remotion `startFrom` (older API), no `trimAfter`, no per-track volume/muted
- **reigh-app** (`src/tools/video-editor/`) — uses Remotion `trimBefore`/`trimAfter` (newer `@remotion/media` API), has crop fields, effect layers

Neither repo has per-track volume/muted on `TrackDefinition`, and neither has a detach-audio-from-video operation. The underlying data model (`from`/`to`/`volume` on `TimelineClip`) is already aligned — the divergence is in how Remotion renders it.

### Scope of this plan
1. Add `volume?` and `muted?` to `TrackDefinition` (both repos) — track-level audio control
2. Add `detachAudioFromVideo` operation (both repos) — mutes the video clip and creates a corresponding audio clip
3. Standardize art-agents AudioTrack to use `trimBefore`/`trimAfter` instead of `startFrom` (requires upgrading art-agents' `@remotion/media` import pattern to match reigh-app)

## Phase 1: Type & Serialization Foundation

### Step 1: Add `volume` and `muted` to `TrackDefinition` type (both repos)
**Scope:** Small
1. **Edit** `art-agents/shared/types.ts:19-27` — add `volume?: number` and `muted?: boolean` to `TrackDefinition`.
2. **Edit** `reigh-app/src/tools/video-editor/types/index.ts:40-48` — same additions.
3. Both fields are optional with sensible defaults (volume=1, muted=false), so all existing configs remain valid.

### Step 2: Update serialization allow-lists (both repos)
**Scope:** Small
1. **Edit** `art-agents/shared/serialize.ts:28-36` — add `"volume"` and `"muted"` to `TRACK_DEFINITION_FIELDS`.

3. Without this, `validateSerializedConfig()` will reject saved configs that include the new fields.

### Step 3: Wire track-level volume/muted into AudioTrack composition (both repos)
**Scope:** Medium
1. **Edit** `art-agents/shared/compositions/AudioTrack.tsx` — accept `track: TrackDefinition` prop (currently only takes `trackId`). Compute effective volume: `track.muted ? 0 : (track.volume ?? 1) * (clip.volume ?? 1)`. Pass to `<Audio volume={...}>`.
2. **Edit** `reigh-app/src/tools/video-editor/compositions/AudioTrack.tsx` — same change.
3. **Edit** both `TimelineRenderer.tsx` files to pass the `track` object (not just `trackId`) to `<AudioTrack>`. Both already have the track object available in the render loop.
4. **Edit** `art-agents/shared/compositions/VisualClip.tsx` — also apply track-level volume to `<Video>`/`<OffthreadVideo>` so visual-track audio respects track muting.
5. **Edit** `reigh-app/src/tools/video-editor/compositions/VisualClip.tsx` — same.

### Step 4: Add track-level mute/volume utilities to editor-utils (both repos)
**Scope:** Small
1. **Add** to `art-agents/shared/editor-utils.ts` and `reigh-app/src/tools/video-editor/lib/editor-utils.ts`:
   ```typescript
   export const isTrackMuted = (track: TrackDefinition): boolean => {
     return track.muted === true || (track.volume ?? 1) <= 0;
   };

   export const toggleTrackMute = (
     config: ResolvedTimelineConfig,
     trackId: string,
   ): ResolvedTimelineConfig => {
     return {
       ...config,
       tracks: config.tracks.map((track) =>
         track.id === trackId ? { ...track, muted: !isTrackMuted(track) } : track
       ),
     };
   };

   export const setTrackVolume = (
     config: ResolvedTimelineConfig,
     trackId: string,
     volume: number,
   ): ResolvedTimelineConfig => {
     return {
       ...config,
       tracks: config.tracks.map((track) =>
         track.id === trackId ? { ...track, volume } : track
       ),
     };
   };
   ```

## Phase 2: Detach Audio Operation

### Step 5: Implement `detachAudioFromVideo` in editor-utils (both repos)
**Scope:** Medium
1. **Add** to both `editor-utils.ts` files:
   ```typescript
   export const detachAudioFromVideo = (
     config: ResolvedTimelineConfig,
     clipId: string,
   ): ResolvedTimelineConfig => { ... };
   ```
2. **Logic:**
   - Find the clip by ID; verify it's on a visual track and has a video asset (not image).
   - Mute the video clip (set `volume: 0`).
   - Find or create an audio track (prefer first existing `A*` track, else call `addTrack(config, 'audio')`).
   - Create a new audio clip on that track with the same `asset`, `at`, `from`, `to`, `speed`, and `volume` (original, pre-mute) as the source clip. Generate a unique ID (e.g., `${clipId}-audio-${Date.now()}`).
   - Return the updated config.
3. **Edge case:** If the clip is already muted or an image, return config unchanged.

### Step 6: Expose detach-audio in the viewer/editor UI hooks (both repos)
**Scope:** Medium — this step is repo-specific
1. **art-agents** — wire into `viewer/src/tools/video-editor/hooks/useTimelineEditing.ts` as a new handler alongside existing operations like `toggleClipMute`.
2. **reigh-app** — wire into the equivalent hook/component that manages clip context-menu or properties-panel actions. Likely `ClipPanel.tsx` or the parent hook.
3. Both should expose a `onDetachAudio(clipId)` callback that calls `detachAudioFromVideo` and updates state.

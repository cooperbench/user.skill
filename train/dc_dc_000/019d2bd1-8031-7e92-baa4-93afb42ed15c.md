        # Implementation Plan: Timeline Auto-Scroll on Edge Proximity

## Overview

The existing `createAutoScroller` utility (`src/tools/video-editor/lib/auto-scroll.ts`) already implements the core RAF-based edge-proximity scrolling logic (40px edge zone, 0–12 px/frame linear acceleration). It's fully built but **not wired into any hook**. The task is to integrate it into the three drag interaction hooks, each of which has a different event model:

| Hook | Event model | Scroll container access | Cleanup location |
|------|------------|------------------------|------------------|
| `useClipDrag` | `window.pointermove` | `timelineWrapperRef` → querySelector | `clearSession()` :124 |
| `useExternalDrop` | `React.DragEvent` (`dragover`) | `coordinator.editAreaRef` | `clearExternalDragState()` :58 |
| `useMarqueeSelect` | `window.pointermove` | `editAreaRef` (direct) | `clearSession()` :57 |

The scroll container in all cases is the `.timeline-canvas-edit-area` element (single scrollable div handling both axes).

## Main Phase

### Step 1: Validate auto-scroll utility behavior in isolation
**Scope:** Small

1. **Inspect** the existing utility (`src/tools/video-editor/lib/auto-scroll.ts:1-65`) — already done. The API is `createAutoScroller(container) → { update(clientX, clientY), stop() }`.
2. **Quick test:** Temporarily wire it into `useMarqueeSelect` (simplest hook) to confirm the RAF loop scrolls correctly. This is the cheapest validation because `useMarqueeSelect` already has a direct `editAreaRef`.

### Step 2: Integrate into `useMarqueeSelect` (`src/tools/video-editor/hooks/useMarqueeSelect.ts`)
**Scope:** Small

1. **Import** `createAutoScroller` from `../lib/auto-scroll`.
2. **Create scroller ref:** Add `const autoScrollerRef = useRef<ReturnType<typeof createAutoScroller> | null>(null)` alongside existing refs.
3. **Initialize on drag start:** Inside `onPointerDown` (`:82`), after the `editArea` null-check (`:85-87`), create the scroller:
   ```ts
   autoScrollerRef.current = createAutoScroller(editArea);
   ```
4. **Feed pointer position:** In `handlePointerMove` (`:121`), **before** `updateSelection()` (`:145`), add:
   ```ts
   autoScrollerRef.current?.update(moveEvent.clientX, moveEvent.clientY);
   ```
   This must come before `updateSelection` so the scroll position is updated before intersection calculations read `scrollLeft`/`scrollTop`.
5. **Stop on cleanup:** In `clearSession` (`:57`), add `autoScrollerRef.current?.stop(); autoScrollerRef.current = null;` before the event listener removal.

### Step 3: Integrate into `useClipDrag` (`src/tools/video-editor/hooks/useClipDrag.ts`)
**Scope:** Medium

1. **Import** `createAutoScroller`.
2. **Add scroller ref:** `const autoScrollerRef = useRef<ReturnType<typeof createAutoScroller> | null>(null)`.
3. **Resolve scroll container:** `useClipDrag` only has `timelineWrapperRef`. In the `onPointerDown` handler (around `:200`), after the wrapper is accessed, query the scroll container:
   ```ts
   const editArea = timelineWrapperRef.current?.querySelector<HTMLElement>('.timeline-canvas-edit-area');
   if (editArea) autoScrollerRef.current = createAutoScroller(editArea);
   ```
4. **Feed pointer position:** In `handlePointerMove` (`:251`), after the threshold/capture checks and `preventDefault()` (`:271`), before the coordinator update (`:273`):
   ```ts
   autoScrollerRef.current?.update(moveEvent.clientX, moveEvent.clientY);
   ```
5. **Stop on cleanup:** In `clearSession` (`:124`), add `autoScrollerRef.current?.stop(); autoScrollerRef.current = null;`.

**Note:** The coordinator re-reads DOM positions each frame, so scrolling mid-drag should be transparent to drop-position calculations. Verify this during testing — if the coordinator caches stale `getBoundingClientRect`, it would need to be called again after scroll.

### Step 4: Integrate into `useExternalDrop` (`src/tools/video-editor/hooks/useExternalDrop.ts`)
**Scope:** Medium

1. **Import** `createAutoScroller`.
2. **Add scroller ref:** Same pattern as above.
3. **Get scroll container:** The `coordinator` has an `editAreaRef`. Pass `editAreaRef` as an additional argument to `useExternalDrop`, or resolve it via `coordinator.editAreaRef.current`. The scroller should be lazily created on first `dragover` if not yet initialized:
   ```ts
   // Inside onTimelineDragOver, after preventDefault (:80)
   if (!autoScrollerRef.current) {
     const editArea = coordinator.editAreaRef?.current;
     if (editArea) autoScrollerRef.current = createAutoScroller(editArea);
   }
   autoScrollerRef.current?.update(event.clientX, event.clientY);
   ```
4. **Stop on cleanup:** In `clearExternalDragState` (`:58`), add `autoScrollerRef.current?.stop(); autoScrollerRef.current = null;`.
5. **Also stop on drop:** In `onTimelineDrop` (`:113`), call `autoScrollerRef.current?.stop()` before processing the drop.

### Step 5: Edge case — left-edge horizontal scroll offset
**Scope:** Small

1. **Inspect** whether the left edge zone should account for the sticky track label column (`LABEL_WIDTH = 144px`). Currently `createAutoScroller` uses `rect.left` directly from `getBoundingClientRect()`, which includes the label area in the container's visual bounds.
2. **If labels are sticky and overlay the scroll area:** The effective left edge for horizontal scrolling should be `rect.left + LABEL_WIDTH`. Add an optional `insets` parameter to `createAutoScroller`:
   ```ts
   export function createAutoScroller(container: HTMLElement, insets?: { left?: number; top?: number; right?: number; bottom?: number })
   ```
   Then adjust edge calculations to use `rect.left + (insets?.left ?? 0)` etc.
3. **If labels are outside the scroll container:** No change needed — verify by inspecting the DOM structure in `TimelineCanvas.tsx`.

### Step 6: Verify and tune constants
**Scope:** Small

1. **Manual QA:** Test all three interactions:
   - Clip drag near top/bottom/left/right edges → scrolls, accelerates closer to edge
   - External asset drop near edges → scrolls during dragover
   - Marquee selection near edges → scrolls and updates selection rectangle correctly
2. **Tune if needed:**
   - `EDGE_ZONE_PX = 40` — may need to increase to ~60px if 40 feels too tight
   - `MAX_SCROLL_SPEED = 12` — 12 px/frame ≈ 720 px/s; may feel fast for horizontal (time axis). Consider different horizontal vs vertical max speeds if needed.
3. **Edge case: pointer leaves container during scroll** — the RAF loop continues scrolling even if the pointer exits the container bounds. The current code handles this correctly (distances become negative → dx/dy reset to 0). Verify this.

## Overview

The existing `createAutoScroller` utility (`src/tools/video-editor/lib/auto-scroll.ts`) implements RAF-based edge-proximity scrolling (40px edge zone, 0–12 px/frame linear acceleration). It's fully built but **not wired into any hook**.

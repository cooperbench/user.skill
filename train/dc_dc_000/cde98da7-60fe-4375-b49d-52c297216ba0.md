# Implementation Plan: Phase 7 — Per-project CAS

## Overview
Add a per-project content-addressable store at `<project_dir>/.cas/<sha256>/` that owns produces artifacts. After a `produces_check_passed` is about to fire in the gate, the artifact file is hashed, atomically moved into `.cas/<hash>`, and the original artifact path is replaced by a *relative* symlink into `.cas/`. The CAS hash is recorded on the `produces_check_passed` event so audits can correlate steps to interned blobs. Scope is strictly per-project; there is no shared CAS, matching SD-008 / SD-029.

Key facts gathered from the repo:
- The single produces-check site is `_run_inline_checks` in `artagents/core/task/gate.py:1110` (called from `record_dispatch_complete` for code steps and inline from `_dispatch_attested` for attested steps). All produces flows funnel through there.
- Artifact directory derives from `step_dir_for_path(slug, run_id, path_tuple, iteration=…, item_id=…, root=projects_root)` and `entry.path` (`gate.py:1119-1130`). Project dir comes from `decision.project_root` (guaranteed non-`None` for both call sites — code dispatch sets it in `_code_decision`, attested dispatch sets it in `_dispatch_attested`).
- `make_produces_check_passed_event` in `artagents/core/task/events.py:185` is the only writer; existing tests assert on event `kind`, not on full payload — adding an optional `cas_hash` field is safe.
- The gate's event chain re-verifies on every append (`events.py:27`); adding a new optional field keeps the chain valid as long as the canonical JSON is well-formed.
- `artagents/structure.py` only validates *top-level repo* directories; there is no per-project whitelist. Per the brief, leave it alone.
- `.gitignore` already has `runs/` (line 38) but does not name `.cas/` — add `**/.cas/`.

Constraints honored: stdlib only (`hashlib`, `os.symlink`, `os.replace`, `os.readlink`); additive (existing produces tests inspect event kinds, not file types — they continue to pass once an artifact becomes a symlink to its CAS entry).

## Main Phase

### Step 1: Add the CAS module (`artagents/core/task/cas.py`)
**Scope:** Small
1. **Create** `artagents/core/task/cas.py` with these helpers (single-responsibility, stdlib only):
   - `cas_path(project_dir: Path, sha256: str) -> Path` — returns `project_dir / ".cas" / sha256`.
   - `hash_file(path: Path) -> str` — streams the file in 1 MiB chunks through `hashlib.sha256()` and returns the hex digest.
   - `cas_hash_from_symlink(target_path: Path) -> str | None` — if `target_path.is_symlink()`, resolve the link via `target_path.resolve()`, check that the resolved path's parent is named `.cas` and that the parent's parent is some project dir; return the resolved file's name (digest) when matched, else `None`. Used to detect "already interned" inputs.
   - `intern(project_dir: Path, source_path: Path) -> Path` — idempotent move-into-CAS:
     - If `source_path.is_symlink()` and `cas_hash_from_symlink(source_path)` returns a non-`None` digest matching `cas_path(project_dir, digest)`, return that CAS path unchanged.
     - Otherwise hash the source file, compute `dest = cas_path(project_dir, digest)`.
     - If `dest.exists()`: `source_path.unlink()` and return `dest` (deduplication).
     - Else `dest.parent.mkdir(parents=True, exist_ok=True)` then `os.replace(source_path, dest)` (same-filesystem atomic move because `.cas/` lives inside the project dir), and return `dest`.
   - `link_into_produces(cas_dest: Path, target_path: Path) -> None` — relative-symlink swap:
     - `target_path.parent.mkdir(parents=True, exist_ok=True)`.
     - If `target_path` exists or is a dangling symlink, `target_path.unlink()`.
     - Compute `relative = os.path.relpath(cas_dest, start=target_path.parent)` so the link survives a run-dir move.
     - `os.symlink(relative, target_path)`.
2. **Export** `cas_path`, `intern`, `link_into_produces`, `hash_file`, `cas_hash_from_symlink` in `__all__`.

### Step 2: Wire CAS into the produces check (`artagents/core/task/events.py`, `artagents/core/task/gate.py`)
**Scope:** Medium
1. **Extend** `make_produces_check_passed_event` in `artagents/core/task/events.py:185` with an optional `cas_hash: str | None = None` keyword. When non-`None`, include `"cas_hash": cas_hash` in the returned dict; when `None`, omit the key entirely so existing call paths that produce no interning still emit byte-identical canonical JSON.
2. **Update** `_run_inline_checks` in `artagents/core/task/gate.py:1110` so that, after `result.ok` is True and *before* appending the `produces_check_passed` event:
   - Import `from artagents.core.task.cas import intern, link_into_produces, cas_hash_from_symlink`.
   - Determine `digest`:
     - If `artifact_path.is_symlink()`: `digest = cas_hash_from_symlink(artifact_path)` (no intern needed; idempotent re-pass case).
     - Elif `artifact_path.is_file()`: `cas_dest = intern(decision.project_root, artifact_path)`; `link_into_produces(cas_dest, artifact_path)`; `digest = cas_dest.name`.
     - Else (e.g. a directory artifact): `digest = None`.
   - Pass `cas_hash=digest` into the existing `make_produces_check_passed_event(...)` call at `gate.py:1161`.
3. **Confirm** retry semantics: a `produces_check_failed` rerun overwrites the artifact path (or writes a new file), `_run_inline_checks` runs again on the new bytes, and `intern` either dedupes (if content matches an existing CAS entry) or creates a new one. No special-case code needed.

        # Implementation Plan: Refactor Video Editor to Reigh-App Architecture

## Overview

The viewer (`viewer/src/`) is a functional NLE video editor built around a 1325-line `App.tsx` god component and a 1199-line `App.css`. The goal is to refactor it to match the reigh-app architecture: Tailwind + shadcn-ui, React Query, Context-based state, feature-based directory structure, and clean component separation — while preserving all current functionality and the `shared/` composition layer.

**Current shape:** 7 source files in a flat `src/` directory. App.tsx owns all state, all event handlers, all layout. `@xzdarcy/react-timeline-editor` is the timeline rendering library. Vite dev server provides API endpoints for load/save/render/upload. Data flows: `loadTimelineJson() → state → commitData() → scheduleSave() → POST /api/save-timeline`.

**Constraints:** Keep `shared/` intact, keep `timeline.json` schema, keep Remotion Player integration, keep `@xzdarcy/react-timeline-editor` (core timeline rendering), keep all current functionality.

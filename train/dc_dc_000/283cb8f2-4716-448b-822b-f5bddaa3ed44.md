## Phase 1: Inbox Core Module

### Step 1: Create `artagents/core/task/inbox.py`
**Scope:** Medium

1. Define inbox entry file format (JSON):
   ```python
   # InboxEntry dataclass
   @dataclass(frozen=True)
   class InboxEntry:
       step_id: str
       decision: Literal["approve", "retry", "abort"]
       evidence: dict[str, Any]  # step-specific artifacts
       submitted_at: str  # ISO 8601
       submitted_by: str  # external system name
       file_path: Path  # the on-disk file this was parsed from
   ```

2. Implement `inbox_dir(run_dir: Path) -> Path` — returns `<run_dir>/inbox/`.

3. Implement `scan_inbox(run_dir: Path) -> list[InboxEntry]`:
   - Read all `.json` files in `<run_dir>/inbox/` (excluding `.consumed/` subdirectory).
   - Parse each as JSON, validate against required fields.
   - Malformed files are logged via `logging.getLogger("artagents.inbox").warning()` and skipped — never raised.
   - Missing or non-dict JSON is skipped.
   - Files with `step_id` that is not a non-empty string are skipped.
   - Sort results by `submitted_at` ascending.

4. Implement `consume_inbox_entry(run_dir: Path, entry: InboxEntry, project_root: Path, slug: str, run_id: str) -> dict[str, Any]`:
   - Validates `entry.step_id` matches the current cursor's `STEP_PATH_SEP.join(peek.path_tuple)`. If not, logs warning and returns None (stale entry).
   - Validates `entry.decision` is one of `approve`, `retry`, `abort`.
   - For `approve`: synthesizes event via `make_step_attested_event()` and `append_event()`.
   - For `retry`: appends `make_cursor_rewind_event()`.
   - For `abort`: delegates to `cmd_abort` (via `make_run_aborted_event` + `clear_active_run`).
   - Moves the consumed file to `<run_dir>/inbox/.consumed/<sha256>.json` (preserves for audit).
   - Returns the appended event dict.

5. Implement `pending_inbox_count(run_dir: Path) -> int` — returns count of valid inbox files (for status display).

333	    """Walk a TaskPlan to find the step at ``path_tuple`` (descending NestedStep

335	    """

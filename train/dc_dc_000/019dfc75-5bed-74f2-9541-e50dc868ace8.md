        # Implementation Plan: Sprint 5 Qwen, Edit-Mode, VLM, and LoRA Preprocessing Parity

## Overview
Sprint 5 should still be implemented primarily in `reigh-worker`, with `vibecomfy` touched only for ready-template input patching and validation. The new critique does not mean the plan is targeting the wrong subsystem; it shows that the LoRA manifest rule must account for all existing LoRA callers, not only Qwen.

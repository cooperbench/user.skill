        # Implementation Plan: Agent Response Messages in Effect Generation

## Overview

The effect generation flow is a synchronous dialog-based interaction: user types prompt → edge function calls LLM → response with code is displayed in `EffectCreatorPanel`. Currently the LLM returns only code + metadata (NAME, DESCRIPTION, PARAMS). This plan adds three capabilities:

1. **Agent message on code responses** — LLM explains what it built
2. **Question triage** — conversational responses when user asks a question instead of requesting an effect
3. **Frontend display** — inline message area in the EffectCreatorPanel

**Key design decision**: Single LLM call (no separate triage step). The prompt instructs the LLM to include a `// MESSAGE: <text>` metadata line, and to output *only* a message (no code) when the input is a question. The extraction logic detects question-only responses by the absence of `exports.default` combined with presence of a MESSAGE line.

## Overview
Add a new travel guidance kind `ltx_anchor` that routes anchor images directly to LTX's keyframe-index conditioning (`VideoConditionByKeyframeIndex`) via the existing `image_refs_paths` / `frames_positions` / `image_refs_strengths` plumbing, **without** baking a pixel cross-fade guide video. This sits alongside — not replaces — `ltx_control`, `ltx_hybrid`, and `ltx_control` pixel-guide paths. The default `kind` is NOT flipped.

Key behaviors:
- Anchors-only contract (no `videos`, no control mode).
- VPT is forced to `"KFI"`.
- Per-anchor strength exposed on the contract; the orchestrator (or segment processor) applies the count-based default when the caller omits strengths:
  - **2 anchors** (FF+LF): `strength=1.0` on both (Inplace semantics at LTX layer).
  - **3+ anchors**: `strength=1.0` on FF+LF, `strength=0.0` on middles (AddGuide semantics — prompt steers middles; documented community fix for middle-frame stutter).
- Guide builder does **not** run the pixel cross-fade for this kind (skip `create_guide_video_for_travel_segment` entirely; `guide_required=False`).
- `ltx_control` pixel-guide path is untouched.

Constraints that matter:
- The payload contract (`image_refs_paths`, `frames_positions`, `image_refs_strengths`) is already serialized for `ltx_hybrid` in `segment_processor._build_hybrid_anchor_payload` and already passed through by `wgp_params.py` — so the wiring exists; we reuse it.
- The orchestrator already remaps anchors onto segments for `ltx_hybrid` via `_build_segment_hybrid_guidance_config` and anchor-aware overlap checks in `_segment_has_travel_guidance_overlap`. We need analogous branches for `ltx_anchor`.
- `clear_conditioning` in `Wan2GP/models/ltx2/ltx_core/tools.py` strips the keyframe tokens before VAE decode, so no cleanup is required on our side.
- `wgp_params.py` already threads `image_refs_strengths` / `frames_positions` / `image_refs` — no param-passthrough change is needed.

Out of scope (explicitly per the brief, call out as follow-ups in the PR description, not tasks):
- Flipping the default kind to `ltx_anchor`.
- Upscaler-stage re-injection of anchors.
- Identity drift fixes (ID-LoRA / IP-adapter).
- Real-GPU empirical validation.

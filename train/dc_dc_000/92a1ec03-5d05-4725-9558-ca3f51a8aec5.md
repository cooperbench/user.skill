        # Implementation Plan: Phase 4 — `artagents.orchestrate` DSL + `author check/describe/new/compile`

## Overview

Phase 4 adds the **only committed authoring surface** for V1 task plans: a tiny Python DSL under `artagents/orchestrate/` that compiles to the same JSON shape `artagents/core/task/plan.py` already validates (Phase 1–3 schema). The DSL must:

- Build plans equivalent to `TaskPlan.to_dict()` so `load_plan()` accepts them unchanged.
- Provide typed step references (`step.<produces_name>`) that raise at module-import / definition time on typos, not at runtime.
- Re-use `artagents/verify/` helpers verbatim (`file_nonempty`, `json_file`, `json_schema`, `audio_duration_min`, `image_dimensions`, `all_of`).
- Reject `code` argv that targets `artagents orchestrators run` (parity with `_reject_orchestrators_run` in `plan.py:441`).
- Reject sentinel-only checks on `attested` non-trivial produces (parity with attested validator in `plan.py:283`).

A new `author` verb is mounted on `artagents/pipeline.py:_dispatch` (top-level, **not** under `artagents orchestrators`, per SD-014). Subcommands:

| Verb | Behavior |
| --- | --- |
| `compile <pack>.<name>` | Imports `<pack>/<name>.py`, compiles to `TaskPlan`, writes `<pack>/build/<name>.json`. |
| `check <pack>.<name>` | Sub-second static validation: imports module, runs DSL compile (which calls `_validate_plan` via round-trip to `load_plan`), enforces semantic-check rule for attested, plus DAG resolvability. |
| `describe <pack>.<name>` | Pretty-prints DAG (kinds, produces, requires/repeat refs, max_iterations, cost ceiling if metadata present). |
| `new <pack>.<name>` | Scaffolds `<pack>/<name>.py`, `<pack>/fixtures/<name>/`, `<pack>/golden/<name>.events.jsonl` from a template. |

Compile output is gitignored: root `.gitignore` adds `artagents/packs/*/build/`. Doctor's `TOP_LEVEL_ARTAGENTS_DIRS` (`artagents/structure.py:27`) is extended with `orchestrate`. `verify` is already accepted.

Existing JSON manifests under `artagents/packs/builtin/<pack>/orchestrator.yaml` and `RUNTIME_KINDS={python,command}` continue to load through `artagents/core/orchestrator/schema.py:load_orchestrator_manifest` — Phase 4 is purely additive.

### Step 2: Implement step builders and typed produces handles (`artagents/orchestrate/dsl.py`)
**Scope:** Medium
1. **Define** internal builder classes that mirror `artagents/core/task/plan.py` step kinds:
   - `_StepHandle` — frozen wrapper around `{id, kind, command|argv|plan, produces, repeat, instructions, ack}` with a `produces` mapping `{name -> _ProducesHandle}`.
   - `_ProducesHandle(step_id, name)` — its `__str__()` returns the canonical `"<step-id>.produces.<name>"` ref-string used by `repeat.for_each.from`.
   - `_StepHandle.__getattr__(name)` — looks up `name` in the produces dict; raises `OrchestrateDefinitionError(f"step {step_id!r} has no produces named {name!r}; declared: {sorted(produces)}")` on miss. **This is the typo trap and must fire at definition time** (i.e., when the author writes `transcribe.transcrpt` in the next step's argv list, not at compile / runtime).
2. **Add** factories:
   - `code(step_id, *, argv: list[str], produces: dict[str, Check] | None = None, repeat=None) -> _StepHandle`. `argv` joined via `shlex.join` produces `command` for `CodeStep.command`.    - `nested(step_id, *, plan: "TaskPlanLike" | str, produces: dict[str, Check] | None = None, repeat=None)`. The `plan` arg may be (a) a `_PlanBuilder` returned by `plan(...)`; or (b) a qualified `<pack>.<name>` string that `compile.py` resolves by importing `<pack>/<name>.py` and calling its `@orchestrator` function.
3. **Add** repeat helpers:
   - `repeat_until(condition, *, max_iterations, on_exhaust, quorum_n=None)` returns a frozen `_RepeatUntilSpec`.
   - `repeat_for_each(items=None, *, from_=None)` returns a frozen `_RepeatForEachSpec`. The `from_` value may be a `_ProducesHandle` (it's `__str__`-ified at compile) or a literal string.
4. **Add** `plan(plan_id, steps) -> _PlanBuilder` capturing `(plan_id, version=1, steps)`; raise on duplicate sibling step ids before returning.
5. **Add** `@orchestrator(plan_id)` decorator: calls the wrapped function, expects a `_PlanBuilder` (or a list of steps that will be wrapped via `plan(plan_id, steps)`), and stamps the resulting builder with the qualified id. 6. **Implement** `_PlanBuilder.to_dict()` — returns the JSON shape `_validate_plan` already accepts. Resolve `_ProducesHandle` instances inside `repeat.for_each.from` to their canonical strings.
7. **Round-trip self-check**: at the end of `to_dict()`, call `artagents.core.task.plan._validate_plan(payload)` so the same canonicalization catches anything the DSL layer missed (e.g. duplicate ids, malformed repeat). Re-raise as `OrchestrateDefinitionError`.

557	    """Reject sibling-id collisions inside any one frame.

560	    """

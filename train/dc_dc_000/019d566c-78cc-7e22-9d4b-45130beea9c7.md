        # Implementation Plan: Expand timeline agent create_task to all generation paths

## Overview
The timeline agent currently supports 5 task types (text-to-image, style-transfer, subject-transfer, scene-transfer, image-to-video) routed through 2 families (image_generation, travel_between_images). The create-task edge function already has resolvers for 12+ families. We need to teach the agent about 6 additional generation paths and add model selection for existing ones — touching only agent-side code in 4 files.

**Scope**: 4 files to change, all in `reigh-app/supabase/functions/ai-timeline-agent/`. No resolver or edge function changes.

**Skipping**: masked-edit (requires mask drawing, impractical from agent), crossfade-join / join-clips / edit-video-orchestrator (complex orchestration tools not suited to single-shot agent calls), individual-travel-segment (internal to orchestrator).

## Phase 1: Schema & Routing

### Step 1: Expand tool schema (`tool-schemas.ts`)
**Scope:** Small
1. **Add** new task_type enum values at `tool-schemas.ts:36`:
   - `"image-to-image"` — z-image i2i transform
   - `"magic-edit"` — prompt-based image editing (qwen)
   - `"image-upscale"` — upscale an image
   - `"video-enhance"` — interpolation + upscaling for video
   - `"character-animate"` — animate character image with motion video
2. **Add** new optional properties to the schema at `tool-schemas.ts:38`:
   - `model`: `{ type: "string", enum: ["wan", "z-image", "qwen-image", "ltx-2.3", "ltx-2.3-fast"], description: "Model override. text-to-image: wan (default), z-image (fast), qwen-image. image-to-video: wan (default), ltx-2.3, ltx-2.3-fast." }`
   - `video_url`: `{ type: "string", description: "Video URL from a selected clip (for video-enhance, or motion reference for character-animate)." }`
   - `strength`: `{ type: "number", description: "Transform strength 0-1 for image-to-image (default 0.6). Lower = more like original." }`
3. **Update** the `description` of `reference_image_urls` to clarify it's used for image inputs across all image-based task types.

### Step 3: Update validation and param passing in `create-task.ts`

2. **Update** validation logic at `create-task.ts:33-46`:

   - `image-to-video` still requires `reference_image_urls.length >= 2`.
   - `image-to-image`, `magic-edit`, `image-upscale` require `reference_image_urls.length >= 1` (single source image).

   ```python
   def _marker_dir(cloud_yaml_path: Path) -> Path:
       sha = hashlib.sha256(str(cloud_yaml_path.resolve()).encode()).hexdigest()[:16]
       path = Path.home() / ".megaplan" / "cloud" / "markers" / sha
       path.mkdir(parents=True, exist_ok=True)
       return path
   ```
   Rationale: the marker identifies one deployment (= one `cloud.yaml`), and two deployments at different paths get distinct markers even if they share a `compose_project` name. This also means Railway gets durable markers despite its ephemeral deploy dir.

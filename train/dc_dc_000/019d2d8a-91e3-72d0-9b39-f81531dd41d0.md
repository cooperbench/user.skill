        # Implementation Plan: Top Drop Zone + Full-Width Tabs

## Overview
Two independent UX fixes in the video editor:

1. **Top drop zone** — The committed code at HEAD already implements this feature across 6 files (commits `f93683867`, `1d33ef8a1`). However, the working tree has **uncommitted changes that revert it** back to bottom-only. The plan is to discard those reverts and verify/refine the existing implementation.

2. **Full-width tabs** — `TAB_COLUMNS_CLASS` in `ClipPanel.tsx:35-38` only maps `3` and `4` column counts. Effect-layer clips show 2 tabs, which falls through to the `grid-cols-4` default, leaving them crammed left. Fix: add entries for `2` and `5`.

### Current repo state
- **HEAD** contains a working top drop zone (6 files touched).
- **Working tree** has unstaged changes that remove the top drop zone + a staged change to ClipPanel.
- The tab fix is fully independent of the drop zone work.

**Scope:** Small

   {newTrackDropLabel?.includes('at top') && (

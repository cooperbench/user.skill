**1b.** Add internal `_scan_global_installs() -> list[SkillInstall]` that finds ALL global installs (both stale and current). This is the shared primitive used by both public functions.

```python
def _scan_global_installs() -> list[SkillInstall]:
    """Find all globally-installed skill documents."""
    home = Path.home()
    results: list[SkillInstall] = []
    for rel_path, _interface, _dedicated in GLOBAL_SEARCH_PATHS:
        full = home / rel_path
        if not full.is_file():
            continue
        try:
            content = full.read_text(encoding="utf-8", errors="replace")
        except OSError:
            continue
        version_match = SKILL_VERSION_RE.search(content)
        if not version_match:
            continue
        installed_version = int(version_match.group(1))
        overlay_match = SKILL_OVERLAY_RE.search(content)
        overlay = overlay_match.group(1) if overlay_match else None
        results.append(SkillInstall(
            rel_path=f"~/{rel_path}",
            version=installed_version,
            overlay=overlay,
            stale=installed_version < SKILL_VERSION,
        ))
    return results
```

**1c.** Add two public functions built on `_scan_global_installs`:

```python
def find_stale_global_installs() -> list[SkillInstall]:
    """Return all globally-installed skill documents that are stale."""
    return [i for i in _scan_global_installs() if i.stale]

def find_any_global_install() -> bool:
    """Return True if any global skill install exists (stale or current)."""
    return bool(_scan_global_installs())
```

`find_stale_global_installs` returns ALL stale installs (not just the first) for multi-tool users. `find_any_global_install` is needed by Step 4 to distinguish "has current global install" from "has no install at all".

**1d.** Update `check_skill_version()` to check per-project first, then global:

```python
def check_skill_version() -> str | None:
    """Return a warning if installed skill doc is outdated."""
    # Per-project takes precedence (it's what the tool loads in-project)
    install = find_installed_skill()
    if install:
        if not install.stale:
            return None
        return (
            f"Your desloppify skill document is outdated "
            f"(v{install.version}, current v{SKILL_VERSION}). "
            "Run: desloppify update-skill"
        )
    # Check all global installs
    stale_globals = find_stale_global_installs()
    if stale_globals:
        return (
            f"Your global desloppify skill is outdated "
            f"(v{stale_globals[0].version}, current v{SKILL_VERSION}). "
            "Run: desloppify setup"
        )
    return None
```

```python
def auto_update_skill() -> None:
    """Warn if skill document is outdated. Does not auto-update.

    Called from the scan workflow. Checks per-project first, then global.
    """
    if not is_agent_environment():
        return

    warning = skill_docs_mod.check_skill_version()
    if warning:
        print(warning)
        return

    # check_skill_version returned None — either a current install exists,
    # or no install at all.  Distinguish the two cases.
    if not skill_docs_mod.find_installed_skill() and not skill_docs_mod.find_any_global_install():
        print(
            "No skill document found. Install globally for better workflow guidance: "
            "desloppify setup"
        )
```

Logic walkthrough:
- Per-project stale → `check_skill_version` returns warning with "update-skill"
- Global stale (no per-project) → `check_skill_version` returns warning with "setup"
- Per-project current → `check_skill_version` returns None, `find_installed_skill()` is truthy → silence
- Global current (no per-project) → `check_skill_version` returns None, `find_installed_skill()` is None, `find_any_global_install()` is True → silence
- No install anywhere → `check_skill_version` returns None, both checks false → "No skill document found"

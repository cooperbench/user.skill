# Implementation Plan: Phase 6 — Stop-hook Nudge

## Overview

Phase 6 lands the out-of-process Stop-hook nudge for Claude Code: a `Stop` hook configured in `.claude/settings.json` runs `artagents hook stop`, which (when the cwd is an active project) re-invokes `artagents next` so the prohibition preamble is re-injected into the model's context (SD-023).

The bulk of the work is already done as Phase 5 groundwork:

- `artagents/core/task/preamble.py:10` defines `PROHIBITION_PREAMBLE` (Phase 5 module-docstring explicitly notes "do not import this into hook config from Phase 5").
- `artagents/core/task/lifecycle.py:cmd_next` (line 384) already prints the preamble verbatim on every call, including the slug-error path at line 377 and the exhausted path at line 406.
- `_AGENT_MD_TEMPLATE` in `artagents/core/task/lifecycle.py:53` already embeds the preamble and is written to each run's `AGENT.md` by `cmd_start`.
- `tests/test_lifecycle_next.py:67 test_preamble_byte_identical_across_two_calls` already proves byte-stability across two `cmd_next` calls.

What's missing is the Stop-hook entry point itself, the hook setup docs, an AGENT.md mention of the hook, and the brief's three named tests. The wiring points are `LIFECYCLE_VERBS` (`pipeline.py:20`) and the `_dispatch` chain (`pipeline.py:52`).

Scope-narrowing note: there is no `docs/AGENT.md` file in the repo — Phase 5 created an in-process template constant, not a docs file. The brief's reference to "the AGENT.md template created in Phase 5" therefore means the `_AGENT_MD_TEMPLATE` constant; that's what we update.

Constraints honored:
- Additive only; no existing tests change. Existing `test_preamble_byte_identical_across_two_calls` keeps passing because the preamble bytes do not change in this phase.
- No new dependencies.
- `hook` is added to `LIFECYCLE_VERBS` so it short-circuits the implicit task-mode gate (otherwise the hook running mid-run would be intercepted by `gate_command`, defeating its purpose).
- New module `artagents/core/task/hook.py` keeps `lifecycle.py` (593 lines today) under its size budget.
- `cmd_next` writes no events, so the "no-cursor-move" guarantee is structural; we still assert it via `events.jsonl` byte equality.

## Context

The lifecycle phase system persists 8 fine-grained phases, has two independent phase-resolution codepaths (reconcile-time and snapshot-time) that can disagree, and suffers a stuck-phase bug where `assessment_postflight` never transitions to `execute`. Root cause: `sync_subjective_dimensions()` runs on every reconcile (not just boundaries), re-injecting stale subjective items into `queue_order`, which `_resolve_reconcile_phase()` then reads back as "still in assessment." The phase is redundant — it's derived from queue contents at reconcile time, persisted, then re-derived *differently* at snapshot time.

**Fix:** Persist only mode (`plan`/`execute`), derive pipeline stage from queue contents in one shared pure function, make subjective sync boundary-only.

## Target Model

**Persisted:** `refresh_state["mode"]` = `"plan"` | `"execute"`

**Persisted:** `refresh_state["needs_scan"]` = `bool` (independent of mode)

**Derived:** `derive_pipeline_stage(queue_order, unscored_ids)` — pure function:
1. PRE_REVIEW_WORKFLOW_IDS in queue → `"workflow"` (highest priority)
2. `subjective::` items with any unscored → `"review"`
3. `subjective::` items, all scored → `"assessment"`
4. `workflow::` items → `"workflow"`
5. `triage::` items → `"triage"`
6. Otherwise → `"complete"`

**Display phase** = `stage_to_display_phase(mode, stage, needs_scan)`:
- plan + review → `"review"`
- plan + assessment → `"assessment"`
- plan + workflow → `"workflow"`
- plan + triage → `"triage"`
- execute → `"execute"`
- needs_scan (any mode) → `"scan"`

Display phase strings are the **new short names**. `directives.py` already uses these 5 names (`execute`, `review`, `triage`, `scan`, plus `postflight` as catch-all). Transition message config keys get the same names. `COARSE_PHASE_MAP` is eliminated.

```python
MODE_PLAN = "plan"
MODE_EXECUTE = "execute"
STAGE_WORKFLOW = "workflow"
STAGE_REVIEW = "review"
STAGE_ASSESSMENT = "assessment"
STAGE_TRIAGE = "triage"
STAGE_COMPLETE = "complete"

def derive_pipeline_stage(
    queue_order: list[str],
    unscored_ids: set[str] | frozenset[str] = frozenset(),
) -> str:
    """Pure function: derive plan-mode pipeline stage from queue contents."""
    order = [item for item in queue_order if isinstance(item, str)]
    if any(item in PRE_REVIEW_WORKFLOW_IDS for item in order):
        return STAGE_WORKFLOW
    subjective = [item for item in order if item.startswith("subjective::")]
    if subjective:
        if any(item in unscored_ids for item in subjective):
            return STAGE_REVIEW
        return STAGE_ASSESSMENT
    if any(item.startswith("workflow::") for item in order):
        return STAGE_WORKFLOW
    if any(item.startswith("triage::") for item in order):
        return STAGE_TRIAGE
    return STAGE_COMPLETE

def stage_to_display_phase(mode: str, stage: str, scan_needed: bool) -> str:
    """Map mode + derived stage to a display phase string."""
    if scan_needed:
        return "scan"
    if mode == MODE_EXECUTE or stage == STAGE_COMPLETE:
        return "execute"
    return {
        STAGE_REVIEW: "review",
        STAGE_ASSESSMENT: "assessment",
        STAGE_WORKFLOW: "workflow",
        STAGE_TRIAGE: "triage",
    }.get(stage, "execute")

def current_mode(plan: dict) -> str: ...       # reads refresh_state["mode"], migration fallback
def set_mode(plan: dict, mode: str) -> bool: ...
def needs_scan(plan: dict) -> bool: ...         # reads refresh_state["needs_scan"], migration fallback
def set_needs_scan(plan: dict, value: bool): ...
```

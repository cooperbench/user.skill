GOAL
Replace the three parallel framework dirs (artagents/executors/, artagents/orchestrators/, artagents/elements/) with:
- artagents/core/{executor,orchestrator,element}/ — framework code only (registry, schema, folder, runner, cli, api, install)
- artagents/packs/<pack-name>/<thing>/<manifest>.yaml — all registered content. A pack is any folder under packs/ with a pack.yaml. Each thing is a folder with a manifest file whose filename signals kind (executor.yaml / orchestrator.yaml / element.yaml).
- artagents/packs/builtin/ — the shipped pack containing all 33 executors + 4 orchestrators + 9 elements.
- artagents/packs/local/ — gitignored scratch pack for one-offs.

Qualified ids (e.g. builtin.cut) become the only id format. Bare-name resolution is purged. The system already uses qualified ids internally in manifests, so the breaking change is at the user-facing CLI surface only.

Per-executor venvs move from .artagents/executors/<bare>/venv to .artagents/venvs/<pack>.<name>/venv. The package_id metadata field is renamed pack_id and naturally implements pack-level shared venvs. NO compat shim, NO fallback path lookup, NO migration command — users reinstall.

**Confusing Gaps**

- The documented first command fails in the default shell here: `python3 pipeline.py doctor` raises `ModuleNotFoundError: No module named 'jsonschema'`. The docs put dependency installation much later in [README.md](/Users/user_c042661f/Documents/reigh-workspace/ArtAgents/README.md:193), after telling agents to run `doctor`.
- `doctor` cannot diagnose missing core dependencies if `artagents.pipeline` cannot import. Root [pipeline.py](/Users/user_c042661f/Documents/reigh-workspace/ArtAgents/pipeline.py:9) imports `artagents.pipeline`, which eagerly imports `editor_review` at [artagents/pipeline.py](/Users/user_c042661f/Documents/reigh-workspace/ArtAgents/artagents/pipeline.py:23), which reaches `jsonschema` before doctor dispatch.
- `setup` sounds like general repo setup, but [artagents/setup_cli.py](/Users/user_c042661f/Documents/reigh-workspace/ArtAgents/artagents/setup_cli.py:30) only plans element sync/install. It does not install `requirements.txt`, create/select a Python env, or install Remotion deps.
- Architecture wording is slightly stale: [docs/architecture.md](/Users/user_c042661f/Documents/reigh-workspace/ArtAgents/docs/architecture.md:9) says executors “have begun moving,” while later it says every `STEP_ORDER` stage lives under `artagents/executors/builtin`.

**Highest-Priority Fixes**

1. Make `python3 pipeline.py doctor` bootstrap-safe. Dispatch `doctor` and probably `setup` from the root wrapper before importing full `artagents.pipeline`, or make `artagents.pipeline` avoid eager imports that require optional/installed deps.
2. Move environment setup before first commands in docs. The first block should include the required Python version/env and `python3 -m pip install -r requirements.txt`, or explicitly say the first commands assume dependencies are already installed.
3. Clarify `setup` scope. Rename docs wording to “element setup” or expand `setup` so it also reports core Python/Node dependency steps.
4. Add an onboarding test that simulates missing `jsonschema` or runs `pipeline.py doctor` through a minimal import path. Current tests prove the happy path, not the clean-checkout failure mode.

## Overview
The user cannot reliably type into the edit-panel textarea, and the model `Select` snaps shut when opened. Root cause hypothesis (confirmed by brief): `LoraSelectorModal` and `PhaseConfigSelectorModal` early-return `null` while still mounted with `open={true}`, so Base UI Dialog skips its cleanup (body `pointer-events:none`, focus scope) and strands the page. A second, silent contributor is `useImageEditFormSafe` returning `EMPTY_FORM` with no-op setters when a provider is missing — typing then disappears. Phase 1 ships those fixes alone so the user can confirm the bug is gone before we pay for Phases 2–4 (panel split, persistence model, regression guards).

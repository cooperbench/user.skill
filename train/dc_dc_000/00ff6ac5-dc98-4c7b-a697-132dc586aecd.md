## Phase 4: `Pod` + `launch` with fallbacks + hooks

### Step 7: `Pod` class — async facade (`src/runpod_lifecycle/pod.py`)
**Scope:** Medium
1. **Define** `class Pod` with attributes `id: str`, `name: str`, `config: RunPodConfig`, `hooks: EventHooks`, `_ram_tier: int`, `_storage_volume: str | None`, `_ssh_details: dict | None`, `_last_exec_at: float | None`, `_created_at: float`.
2. **Implement** `async def wait_ready(self, timeout: float = 600) -> None`:
   - Polls `get_pod_status` via `asyncio.to_thread` every 5s.
   - **Uses the normalized snake_case keys returned by `get_pod_status`** (`desired_status`, `ports`) — NOT the raw SDK `desiredStatus`. This addresses FLAG-001.
   - Ready when `desired_status == "RUNNING"` AND `ports` contains an entry with `privatePort == 22`.
   - Fails if `desired_status in {"FAILED", "TERMINATED"}` → `LaunchFailure`.
   - Timeout → `NotReadyTimeout`.
   - Transitions `PROVISIONING → STARTING → READY`, emitting `on_state_change` at each boundary.
   - On READY, calls `get_pod_ssh_details` via `to_thread` and caches in `self._ssh_details`.
3. **Implement** `async def status(self) -> dict` wrapping `get_pod_status(self.id, self.config.api_key)` via `to_thread`. Returns the normalized dict from Step 4.2.
4. **Implement** `async def exec_ssh(self, cmd: str, timeout: int = 600) -> tuple[int, str, str]`:
   - Ensures `_ssh_details` is cached (else calls `get_pod_ssh_details` via `to_thread`).
   - Builds `SSHClient` using config SSH keys (mirror selection logic from source `client.py:119-173`: inline key content > private key path > password).
   - Runs `client.connect() / execute_command / disconnect` inside a single `asyncio.to_thread` call.
   - Updates `self._last_exec_at = time.monotonic()`. Raises `SSHError` on failure.
5. **Implement** `async def is_idle(self, threshold_seconds: float) -> bool`:
   - "Idle" = no `exec_ssh` activity for `threshold_seconds` AND GPU utilization < 5% on `nvidia-smi --query-gpu=utilization.gpu --format=csv,noheader,nounits`.
   - If `_last_exec_at is None`, use `_created_at`.
   - If now − last_activity < threshold → `False`.
   - Else run `nvidia-smi` via `exec_ssh`; parse first int; return `True` if < 5 (any parse error → `False`, log warning).
6. **Implement** `async def terminate(self) -> None`:
   - Calls `terminate_pod(self.id, self.config.api_key)` via `to_thread`.
   - On exception (per Step 4.3 terminate now re-raises): emit `on_error` hook, then raise `TerminateError`. (Addresses FLAG-002 end-to-end.)
   - On success: emit `PodState.TERMINATED`.
7. **Implement** `async def check_storage_health(self, min_free_gb=50, max_percent_used=85) -> dict`:
   - `_, raw, _ = await self.exec_ssh(STORAGE_CHECK_COMMAND, timeout=30)`.
   - `parsed = parse_df_output(raw)`.
   - Optionally fetches `api_total_gb` via `to_thread(get_network_volumes)` if `_storage_volume` is set.
   - `return evaluate_storage_health(parsed, api_total_gb, min_free_gb, max_percent_used)`.

### Step 8: `launch()` orchestration with fallback (`src/runpod_lifecycle/lifecycle.py`)
**Scope:** Medium
1. **Implement** `async def launch(config: RunPodConfig, *, name: str | None = None, hooks: EventHooks | None = None) -> Pod`:
   - Emits `PROVISIONING` hook immediately.
   - Resolves GPU type via `find_gpu_type` (fail fast `LaunchFailure` if unknown).
   - Resolves `public_key_string` from config (inline > file path); warn if missing.
   - Builds `ram_tiers` list: if `config.ram_tiers_enabled`, filter `config.ram_tiers` to those `>= config.min_memory_gb` (fallback to `[min_memory_gb]` if empty); else `[min_memory_gb]`. Mirrors `lifecycle.py:64-74`.
   - Builds ordered list of storage targets: `[config.storage_name] + list(config.storage_volumes)` de-duplicated, skipping `None`; each resolved to volume_id via `get_storage_volume_id`, missing ones skipped with warning. **If the resolved list is empty (no `storage_name` and no `storage_volumes`)**, use a single sentinel target `[(None, None)]` meaning "create pod with `network_volume_id=None`". This addresses FLAG-004 — the underlying `create_pod` already supports volumeless pods (`api.py:117-119` only adds volume params when `network_volume_id` is truthy).
   - Outer loop: for each `ram_tier`; inner loop: for each `(storage_name, storage_volume_id)`:
     - If `storage_volume_id is not None` and this is the first ram tier for this storage, call `check_and_expand_storage(..., min_free_gb=50)` via `to_thread` (preserves `lifecycle.py:85-86`). Skip for the volumeless sentinel.
     - Call `create_pod` via `to_thread` with the tier's RAM, `network_volume_id=storage_volume_id` (may be `None`), mount path, SSH key, env_vars, template.
     - On success: construct `Pod(id=..., name=..., _ram_tier=ram_tier, _storage_volume=storage_name, ...)`, emit state event with detail including ram_tier/storage, return.
     - On `"no longer any instances available"` (case-insensitive substring match, preserves `lifecycle.py:128`) or generic exception: record last error, continue.
   - All combinations exhausted → emit `on_error`, raise `LaunchFailure` with tried tiers/storages.
2. **Re-export** module-level helpers `find_gpu_type`, `get_network_volumes` from `api.py` in `lifecycle.py` and the package `__init__.py`.

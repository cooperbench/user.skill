## Overview

Phase 6 adds an out-of-process Stop-hook for Claude Code so the prohibition preamble (SD-023) is re-injected into the conversation whenever the agent stops while inside a task run. The constant already exists (`artagents/core/task/preamble.py`) and Phase 5 already prepends it on every `cmd_next` call (`artagents/core/task/lifecycle.py:377-384`); a byte-identical-across-calls assertion already exists at `tests/test_lifecycle_next.py:67`. ### Step 2: Implement the hook command (`artagents/core/task/hook.py` — new)
**Scope:** Small

   - Resolve `cwd_path = Path(cwd).resolve() if cwd else Path.cwd().resolve()`.
   - Resolve `root = resolve_projects_root(projects_root)`.
   - **Discover active runs** in priority order:
     1. **cwd-ancestor walk** — climb from `cwd_path` up to `cwd_path.parents[-1]`; for each ancestor `d`, if `(d / "active_run.json").is_file()` and `d.parent` matches `root` (resolve both), treat `d.name` as the slug and use the configured `root`.      2. **projects_root scan** — if no ancestor matched and `root.is_dir()`, iterate `sorted(root.iterdir())`; for each subdir whose name matches `_SLUG_RE` (validate via `validate_project_slug`, swallow `ProjectPathError`), include it if `(subdir / "active_run.json").is_file()`.

   - For each discovered slug, call `cmd_next(["--project", slug], projects_root=root)`. If multiple runs exist, print them in slug-sorted order separated by a blank line, and return the worst (max) non-zero return code, else 0. (V1 typically has 0 or 1 in flight; multi-run handling is defensive.)
2. **Accept and ignore** unknown argv defensively so future Claude Code Stop-hook payloads (which may pass JSON via stdin or extra args) don't break the hook.

        # Implementation Plan: Fix Custom Effects Invisible on Remotion Timeline

## Overview

Custom AI-generated effects (like ChromaticGlitchStorm) render correctly in the EffectCreatorPanel preview but produce broken/invisible output on the Remotion timeline. The effect is found in the registry, the component renders without errors, but the visual output is wrong.

**Root cause analysis** identified these structural differences between the two rendering contexts:

| Aspect | EffectCreatorPanel (works) | Timeline (broken) |
|---|---|---|
| Children passed to effect | `<PreviewRect>` = `<AbsoluteFill><img objectFit:cover /></AbsoluteFill>` | `<AbsoluteFill overflow:hidden><Img objectFit:contain /></AbsoluteFill>` |
| Image element | Plain HTML `<img>` | Remotion `<Img>` with `crossOrigin="anonymous"` |
| Object fit | `cover` — fills 100% of area | `contain` — may have transparent letterboxing |
| Container nesting | Player → Composition (shallow) | Player → TimelineRenderer (3x AbsoluteFill) → Sequence → VisualClip → Effect |
| Overflow | No overflow clipping on children | `overflow: hidden` on content AbsoluteFill |
| Background context | Direct child of Player (opaque) | Nested under `backgroundColor: 'black'` AbsoluteFill with intermediate transparent layers |

**Leading hypotheses** (in priority order):
1. **`objectFit: contain` + blend mode chain**: With `contain`, transparent letterbox areas break the multiply→screen compositing chain. multiply with no backdrop = solid color; screen(red, green, blue solids) = white. The image appears surrounded by bright white wash, or if image is small, appears "broken/invisible."
2. **Missing backdrop for blend modes**: The effect's container div (`position: relative`) has no background. CSS `mix-blend-mode` relies on what's behind it. With transparent backdrop + `isolation: isolate`, the compositing may produce unexpected results differently in the deeper timeline nesting.
3. **Stacking context interference**: The triple AbsoluteFill in TimelineRenderer + Sequence nesting creates additional stacking contexts that change what `mix-blend-mode: screen` on channel layers blends against.

**Strategy**: Validate hypotheses cheaply with targeted diagnostics, then apply the minimal fix. The fix likely lives in `wrapWithClipEffects` (normalizing children) or in the LLM prompt template (generating more robust effects), or both.

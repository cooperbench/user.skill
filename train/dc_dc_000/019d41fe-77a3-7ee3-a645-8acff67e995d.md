### Step 4: Fix `auto_fail_stale_tasks` orphan detection for `uuid[]` dependant_on (`reigh-app/supabase/migrations/`)
**Scope:** Small — new migration
1. **Inspect** the current `auto_fail_stale_tasks()` in `20260213200000_stale_task_timeout_cron.sql` lines 31-40. The orphan detection uses `dep.id = t.dependant_on` but `dependant_on` was changed to `uuid[]` in migration `20260121000000_support_multiple_dependencies.sql`. The `=` comparison against an array silently matches nothing, so orphaned children are never auto-failed.
2. **Create** a new migration that replaces the function with the correct array-aware query:
   ```sql
   -- Fix: use unnest to match any dependency in the array
   UPDATE tasks t
   SET
     status = 'Failed'::task_status,
     error_message = 'Auto-failed: dependency task failed',
     updated_at = NOW()
   WHERE t.status = 'Queued'::task_status
     AND t.dependant_on IS NOT NULL
     AND EXISTS (
       SELECT 1
       FROM unnest(t.dependant_on) AS dep_id
       JOIN tasks dep ON dep.id = dep_id
       WHERE dep.status IN ('Failed'::task_status, 'Cancelled'::task_status)
     );
   ```

   ```sql
       error_message = 'Worker crashed (heartbeat guardian detected process death)',
   ```

   ```sql
   CREATE OR REPLACE FUNCTION public.auto_fail_stale_tasks()
   RETURNS INTEGER
   LANGUAGE plpgsql
   SECURITY DEFINER
   AS $$
   DECLARE
     stale_count INTEGER;
     orphan_count INTEGER;
   BEGIN
     -- 1. Fail tasks stuck In Progress for >24 hours
     UPDATE tasks
     SET
       status = 'Failed'::task_status,
       error_message = 'Auto-failed: stuck in progress for >24 hours',
       updated_at = NOW()
     WHERE status = 'In Progress'::task_status
       AND updated_at < NOW() - INTERVAL '24 hours';

     GET DIAGNOSTICS stale_count = ROW_COUNT;

     -- 2. Fail Queued tasks where ANY dependency has failed (array-aware)
     UPDATE tasks t
     SET
       status = 'Failed'::task_status,
       error_message = 'Auto-failed: dependency task failed',
       updated_at = NOW()
     WHERE t.status = 'Queued'::task_status
       AND t.dependant_on IS NOT NULL
       AND EXISTS (
         SELECT 1
         FROM unnest(t.dependant_on) AS dep_id
         JOIN tasks dep ON dep.id = dep_id
         WHERE dep.status IN ('Failed'::task_status, 'Cancelled'::task_status)
       );

     GET DIAGNOSTICS orphan_count = ROW_COUNT;

     IF stale_count > 0 OR orphan_count > 0 THEN
       RAISE NOTICE 'auto_fail_stale_tasks: failed % stale + % orphaned task(s)', stale_count, orphan_count;
     END IF;

     RETURN stale_count + orphan_count;
   ```

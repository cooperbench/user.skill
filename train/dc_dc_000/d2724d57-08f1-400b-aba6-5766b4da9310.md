### Pack shape

- `executor.yaml` format: `{"executors": [...]}` (dict wrapping array), or single executor dict.

### Kernel surface

- `compute_plan_hash` requires `version: 2`. DSL emits v2 (S3 fix).
- `_validate_plan` is strict in production; conftest.py has a test-only auto-migration shim for legacy v1 fixtures.
- Step paths are versioned: `steps/<id>/v<N>/[iterations|items]/...`.
- `step_dir_for_path` defaults `step_version=1` for backward compat (S3 fix).
- `append_event_locked` callable only from session-bound CLI verbs and parent processes of subprocess executors.
- The six-invariant validator (`astrid/core/task/validator.py`) gates all plan mutations.

### Session gate

- `_verb_is_unbound_allowlisted` in `astrid/pipeline.py` controls which verbs run without `ASTRID_SESSION_ID`.
- Audit verbs like `events verify`, `events tail`, `timeline show`, `timeline cost`, `project cost` consume run state — they should require a bound session. Don't add to the unbound allowlist.
- Export verbs same: require a session. (Reads run-bound state.)

### Cost contract

- `cost: {amount, currency, source}` on step completion events per S3.
- `source` is free-text but consistent within a pack — e.g. `claude`, `gpt-4`, `runpod`, `gemini`.
- Rollups group by source.

### `events.jsonl` hash chain

- Each event has `prev_hash` referring to the prior event's sha256.
- Genesis event has `prev_hash: null`.
- S1's locked event-append (`append_event_locked`) guarantees the chain is consistent under multi-tab writers via flock + last-hash CAS + epoch CAS.

### Export bundle format

- Tarball (`.tar.gz`) is the simplest; no need for a new format. Include:
  - `assembly.json`, `manifest.json`, `display.json` from the timeline container
  - Each contributing run's `plan.json` + `events.jsonl` + `produces/` tree
  - `MANIFEST.txt` at the bundle root listing all included paths + their sha256
- Verify-on-import: future `astrid timeline import` (out of scope for this sprint) can re-check the chain on read. Not built here, just leave the door open by including hashes.

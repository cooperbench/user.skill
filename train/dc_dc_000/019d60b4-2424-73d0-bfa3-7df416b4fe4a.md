## Overview
Add an audio analysis layer that extracts frequency/amplitude/beat data from all timeline audio tracks and exposes it to compiled custom effects via a `useAudioReactive()` hook. The hook is injected as a new global into the `new Function()` sandbox in `compileEffect.tsx`, documented in `effectPromptTemplate.ts`, and supported by a new `audio-binding` parameter type. The existing effect wrapping pipeline (`wrapWithEffect`/`wrapWithClipEffects` in `effects/index.tsx`) remains untouched — audio data flows through React context, not props.

**Approach:** Web Audio API for offline analysis (no new Remotion packages). Audio is decoded and analyzed per-frame ahead of time, stored in a frame-indexed cache, and served to effects via a React context provider wrapping the composition in `TimelineRenderer.tsx`.

**Scope:** Large — this is the core audio engine
1. **Define** the `AudioAnalysisData` type:
   ```typescript
   type AudioAnalysisData = {
     frequency: Float32Array;  // full FFT bins (e.g. 256)
     amplitude: number;        // 0-1 overall RMS amplitude
     bass: number;             // 0-1 low-frequency energy (0-250Hz)
     mid: number;              // 0-1 mid-frequency energy (250-4000Hz)
     treble: number;           // 0-1 high-frequency energy (4000Hz+)
   ```

2. **Define** the `AudioAnalysisContext` React context holding a frame-indexed `Map<number, AudioAnalysisData>` (or `AudioAnalysisData[]`), plus a `ready` boolean.
3. **Implement** `AudioAnalysisProvider` component that:

   - Fetches and decodes each audio source URL via `fetch` + `AudioContext.decodeAudioData`.

   - Stores results in a frame-indexed array for O(1) lookup.
   - Beat detection: energy-threshold on bass bins with a cooldown window (~300ms).

   ```typescript
     frequency: Float32Array;  // raw FFT magnitude bins (e.g. 128)
     amplitude: number;        // 0-1 RMS amplitude
     bass: number;             // 0-1 low-frequency energy (0-250Hz)
     mid: number;              // 0-1 mid-frequency energy (250-4000Hz)
   ```

2. **Define** `AudioAnalysisContext` holding `AudioAnalysisData[]` (frame-indexed array) plus `ready: boolean`.
3. **Implement** `AudioAnalysisProvider` component:
   - Props: `clips: ResolvedTimelineClip[]` (audio clips), `fps: number`, `totalDurationInFrames: number`, `children`.
   - **Render-gating:** Calls `delayRender()` from Remotion on mount. Calls `continueRender(handle)` once analysis is complete (or immediately if no audio clips).

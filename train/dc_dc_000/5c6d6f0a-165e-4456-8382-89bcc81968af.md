## How it classifies
Walks back from the file tail, strips `system`/`attachment`/`summary`/`last-prompt` metadata lines, then looks at the last real user/assistant turn's trailing content block:

- `assistant` → trailing `text` block = **COMPLETED**, trailing `tool_use` = **DROPPED (killed mid tool call)**
- `user` → `tool_result` with `is_error: true` = **DROPPED (tool error at cutoff)**, plain `tool_result` = **DROPPED (tool result, no reply)**, typed prompt = **AWAITING REPLY**
- First user message matches the megaplan harness preamble → **MEGAPLAN-SUB** (excluded from resume candidates)
- mtime within 60s → **ACTIVE?** (excluded from resume candidates)

Each entry prints a ready-to-paste `claude --resume <id>` line, and a `CANDIDATES TO RESUME` block at the bottom lists only the ones flagged dropped.

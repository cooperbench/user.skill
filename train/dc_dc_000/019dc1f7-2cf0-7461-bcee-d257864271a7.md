The likely issue is Codex/App sandbox networking on macOS. - Codex App network config not reliably honored: https://github.com/openai/codex/issues/13373

- Codex CLI docs show `--sandbox read-only | workspace-write | danger-full-access`: https://developers.openai.com/codex/cli/reference
- RunPod status currently online: https://uptime.runpod.io/

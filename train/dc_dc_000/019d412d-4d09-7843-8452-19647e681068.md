### Step 2: Extract `run_step()` helper to eliminate 8× handler boilerplate (`handlers.py`)
**Scope:** Medium-Large
1. **Define** a `run_step()` helper in `handlers.py` (or a private `_run_step.py` if it gets large) that encapsulates the repeated pattern observed in `handle_prep`, `handle_research`, `handle_plan`, `handle_critique`, `handle_revise`, `handle_gate`, `handle_finalize`:
   ```python
   def run_step(
       root, args, step_name, allowed_states, next_state,
       *, artifact_filename, post_worker_fn=None, summary_fn=None,
   ) -> StepResponse:
       plan_dir, state = load_plan(root, args.plan)
       require_state(state, step_name, allowed_states)
       iteration = state["iteration"]
       try:
           worker, agent, mode, refreshed = worker_module.run_step_with_worker(...)
       except CliError as error:
           record_step_failure(plan_dir, state, step=step_name, iteration=iteration, error=error)
           raise
       payload = worker.payload
       if post_worker_fn:
           post_worker_fn(plan_dir, state, payload, worker)
       atomic_write_json(plan_dir / artifact_filename, payload)
       state["current_state"] = next_state
       apply_session_update(state, step_name, agent, worker.session_id, mode=mode, refreshed=refreshed)
       append_history(state, make_history_entry(...))
       save_state(plan_dir, state)
       ...
   ```
2. **Refactor** the 7 simple handlers (`handle_prep`, `handle_research`, `handle_plan`, `handle_critique`, `handle_revise`, `handle_gate`, `handle_finalize`) to delegate to `run_step()`. Each handler becomes ~5-15 lines: a `run_step()` call plus any step-specific `post_worker_fn` logic.
3. **Leave** `handle_execute` and `handle_review` as-is for now — they have unique control flow (batch dispatch, rework loop) that doesn't fit the pattern cleanly.
4. **Run** full `pytest` suite after this step — this is the highest-risk refactor.

### Step 3: Fix callback injection in `handle_execute` by moving state ops to `_core.py` (`handlers.py:1342-1406`, `execution.py`)

        # Implementation Plan: Carry Forward Subjective Review Marker on Force-Rescan

## Overview

When `--force-rescan` runs during plan mode, `scan_count` increments (merge_history.py:18) and `postflight_scan_completed_at_scan_count` gets set to the new count (plan_reconcile.py:225). But `subjective_review_completed_at_scan_count` still points to the *old* scan count. This makes `_subjective_review_current_for_cycle` (workflow.py:275) return `False`, causing all subjective reviews to be re-queued via synthetic.py:308–316 even though they were already completed for this plan stage.

**Invariant to enforce:** During plan mode, subjective reviews should happen only once per plan stage, regardless of force-rescan.

**Root cause location:** `reconcile_plan_post_scan` (plan_reconcile.py:356) calls `_sync_postflight_scan_completion_and_log` (line 395) which stamps the *new* scan_count into `postflight_scan_completed_at_scan_count`, but nothing updates `subjective_review_completed_at_scan_count` to match.

**Key guards:**
- **Flag-1 (resolved):** Only carry forward when the old review marker matches the old postflight scan marker — not when it's stale from an earlier cycle.
- **Flag-3 (resolved):** The carry-forward runs at the `reconcile_plan_post_scan` call site, NOT inside `_reset_cycle_for_force_rescan`. This avoids the early return at plan_reconcile.py:62–63 that skips the function body when no synthetic items exist.

## Step 1: Add `carry_forward_subjective_review` to refresh_lifecycle.py
**Scope:** Small
1. **Add** a new function in `refresh_lifecycle.py` after `mark_subjective_review_completed` (~line 206):
   ```python
   def carry_forward_subjective_review(
       plan: PlanModel,
       *,
       old_postflight_scan_count: int | None,
       new_scan_count: int | None,
   ) -> bool:
       """Bump the subjective-review marker when force-rescan replaces a cycle.

       Only carries forward when the old review marker matches the old
       postflight scan marker — i.e., the reviews were completed for the
       cycle being replaced.  Stale markers from earlier cycles are left
       untouched so they naturally fail the scan_count equality check and
       trigger fresh reviews.
       """
       refresh_state = plan.get("refresh_state")
       if not isinstance(refresh_state, dict):
           return False
       if _SUBJECTIVE_REVIEW_KEY not in refresh_state:
           return False
       try:
           old_postflight = int(old_postflight_scan_count or 0)
       except (TypeError, ValueError):
           old_postflight = 0
       if refresh_state[_SUBJECTIVE_REVIEW_KEY] != old_postflight:
           return False  # stale marker — do not promote
       try:
           normalized_new = int(new_scan_count or 0)
       except (TypeError, ValueError):
           normalized_new = 0
       if refresh_state[_SUBJECTIVE_REVIEW_KEY] == normalized_new:
           return False
       refresh_state[_SUBJECTIVE_REVIEW_KEY] = normalized_new
       return True
   ```
2. **Export** it in `__all__` (refresh_lifecycle.py:225).

## Step 2: Wire carry-forward at the call site in `reconcile_plan_post_scan` (plan_reconcile.py)
**Scope:** Small

`_reset_cycle_for_force_rescan` is left unchanged — it keeps its existing responsibility of clearing synthetic items.

1. **Import** `carry_forward_subjective_review` from `refresh_lifecycle` at plan_reconcile.py top-of-file.
2. **Add** the carry-forward call in `reconcile_plan_post_scan` (plan_reconcile.py:356), directly after the existing `_reset_cycle_for_force_rescan` call at line 368, gated on `force_rescan`. This runs unconditionally on force-rescan regardless of whether `_reset_cycle_for_force_rescan` found synthetic items:
   ```python
   # Line 367-368 (existing, unchanged):
   force_rescan = getattr(runtime, "force_rescan", False)
   dirty = _reset_cycle_for_force_rescan(plan) if force_rescan else False

   # NEW — carry forward subjective review marker (runs independently):
   if force_rescan:
       refresh_state = plan.get("refresh_state")
       old_postflight = (
           refresh_state.get("postflight_scan_completed_at_scan_count")
           if isinstance(refresh_state, dict)
           else None
       )
       if carry_forward_subjective_review(
           plan,
           old_postflight_scan_count=old_postflight,
           new_scan_count=int(runtime.state.get("scan_count", 0) or 0),
       ):
           dirty = True
   ```
   This reads the old postflight marker *before* `_sync_postflight_scan_completion_and_log` (line 395) overwrites it.

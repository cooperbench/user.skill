   335→        line_state = _build_ts_line_state(lines)

   338→        for check in checks:

   354→                    line.strip(),

   356→                    continue
   357→                smell_counts[check["id"]].append(
   358→                    {
   359→                        "file": filepath,
   360→                        "line": i + 1,
   361→                        "content": line.strip()[:100],
   362→                    }
   363→                )
   364→
   365→        # Multi-line smell helpers (brace-tracked)

   268→def _count_return_fields(func_body: str) -> int | None:
   269→    """Count fields in the last return { ... } object in a function body.
   270→
   271→    Finds the last `return {` at depth 1 (top-level of function) and counts
   272→    comma-separated fields at depth 1 within that object.
   273→    """
   274→    # Find all "return" positions at depth 1
   275→    lines = func_body.splitlines()
   276→    depth = 0
   277→    return_positions: list[int] = []
   278→
   279→    for i, line in enumerate(lines):
   280→        # Check depth BEFORE processing braces on this line
   281→        pre_depth = depth
   282→        for _, ch, in_s in scan_code(line):
   283→            if in_s:
   284→                continue
   285→            if ch == "{":
   286→                depth += 1
   287→            elif ch == "}":
   288→                depth -= 1
   289→
   290→        # pre_depth == 1 means we were at function body level at line start
   291→        stripped = line.strip()
   292→        if pre_depth == 1 and stripped.startswith("return") and "{" in stripped:
   293→            return_positions.append(i)
   294→
   295→    if not return_positions:
   296→        return None
   297→
   298→    # Take the last return statement
   299→    return_line = return_positions[-1]
   300→
   301→    # Count fields in the returned object — track braces from the return {
   302→    ret_text = "\n".join(lines[return_line:])
   303→    brace_start = ret_text.find("{")
   304→    if brace_start == -1:
   305→        return None
   306→
   307→    obj_depth = 0
   308→    field_count = 0
   309→    started = False
   310→
   311→    for _, ch, in_s in scan_code(ret_text, brace_start):
   312→        if in_s:
   313→            continue
   314→        if ch == "{":
   315→            obj_depth += 1
   316→            started = True
   317→        elif ch == "}":
   318→            obj_depth -= 1
   319→            if started and obj_depth == 0:
   320→                break
   321→        elif ch == "," and obj_depth == 1:
   322→            field_count += 1
   323→
   324→    # field_count counts commas; fields = commas + 1 (if any content)
   325→    if field_count > 0:
   326→        field_count += 1
   327→    else:
   328→        # Check if there's any content at all (single field, no comma)
   329→        obj_content = ""
   330→        d = 0
   331→        for ch in ret_text[brace_start:]:
   332→            if ch == "{":
   333→                d += 1
   334→            elif ch == "}":
   335→                d -= 1
   336→                if d == 0:
   337→                    break
   338→            elif d == 1:
   339→                obj_content += ch
   340→        if obj_content.strip():
   341→            field_count = 1
   342→
   343→    return field_count

   448→def _detect_async_no_await(
   449→    filepath: str, content: str, lines: list[str], smell_counts: dict[str, list[dict]]
   450→):
   451→    """Find async functions that don't use await.
   452→
   453→    Algorithm: for each async declaration, track brace depth to find the function
   454→    body extent (up to 2000 lines). For each line, accumulate code-only characters
   455→    (skipping strings/comments via scan_code) and regex for \\bawait\\b on the
   456→    code-only text. If the opening brace closes without seeing await, flag it.
   457→    """
   458→    async_re = re.compile(r"(?:async\s+function\s+(\w+)|(\w+)\s*=\s*async)")

   460→    for i, line in enumerate(lines):

   471→            code_chars: list[str] = []

   477→                    break  # Rest of line is comment

   479→                    brace_depth += 1
   480→                    found_open = True
   481→                elif ch == "}":

### 5. Risk Assessment and Edge Cases

**Risk: `_extract_block_body` behavioral equivalence.** The inline loops do `content[brace_start + 1 : body_end]`. The utility must do the same. The key subtlety is that `_find_block_end` returns the position of the closing `}` itself, so `content[brace_start + 1 : body_end]` excludes both `{` and `}`. This matches the inline pattern exactly.

**Risk: `_detect_catch_return_default` nested call.** This detector calls `_extract_block_body` on the extracted `body` substring for the inner object. The `brace_start` for the inner call is relative to `body`, not `content`. This works correctly because `_extract_block_body` operates on whatever string is passed.

**Risk: `_detect_dead_useeffects` secondary brace tracking.** The `text` variable is built from `"\n".join(lines[line_no:end_line + 1])`, and `brace_pos` is an offset within `text`. Using `_extract_block_body(text, brace_pos)` works correctly.

**Risk: Test `_ctx` helper computing `line_state`.** For most tests this is fine -- the `_build_ts_line_state` call is cheap. The exception is `TestDetectWindowGlobals.test_skips_lines_in_block_comment` where the test needs a specific `line_state` to simulate being inside a block comment. This test must manually construct `_FileContext` rather than using `_ctx`.

**Risk: External consumers.** `react.py`, `fixers/syntax_scan.py`, and `fixers/if_chain.py` import `_strip_ts_comments`, `_ts_match_is_in_string`, and `scan_code` from `_smell_helpers`. These APIs are unchanged. `_find_block_end` is moving from `_smell_detectors` to `_smell_helpers`, but nobody outside `_smell_detectors` imports it. Safe.

The phases can be done in order but Phases 1-3 should ideally be a single commit (since Phase 3 depends on the signature changes in Phase 2, which depend on Phase 1's utilities). Phase 4 (tests) is tied to Phases 2-3.

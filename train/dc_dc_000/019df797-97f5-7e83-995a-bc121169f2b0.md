        # Implementation Plan: Phase 7 Per-Project CAS

## Overview
Add a per-project content-addressable store under `<project>/.cas/<sha256>` and wire task produces checks so accepted file artifacts are interned once, then replaced at their declared produces path with a relative symlink to the CAS object. The runtime insertion point remains the produces-check flow in `artagents/core/task/gate.py`, specifically `_run_inline_checks()` around the successful `entry.check.run(artifact_path)` path. The critique does not point to the wrong root cause; it points to two missing edge cases in the same root path: successful checks may still refer to non-regular paths, and attested steps already call `_run_inline_checks()` directly during `_dispatch_attested()` even though `record_dispatch_complete()` returns early for attested decisions.

The revised approach is still the same core design, with two corrections: add an explicit regular-file guard immediately before CAS interning, and make the shared `_run_inline_checks()` helper the only CAS hook so both code-step completion and attested-step approval get identical CAS behavior. The design stays per-project only: CAS root is derived from `decision.project_root / ".cas"`, never from repo root, user home, global cache, database, daemon, network service, or a shared cache.

The scope tension is resolved by following the later explicit implementation requirements: `.gitignore` should be updated for generated `.cas/` directories, and `artagents/structure.py` should be touched only if a relevant per-project directory whitelist actually exists.

## Main Phase

### Step 1: Add the CAS helper module (`artagents/core/task/cas.py`)
**Scope:** Small
1. Implement `cas_path(project_dir, sha256) -> Path` as `Path(project_dir) / ".cas" / sha256`.
2. Implement `intern(project_dir, source_path) -> Path` using stdlib `hashlib.sha256()` with streaming reads.
3. In `intern`, create `<project>/.cas/`, move the source into `.cas/<hash>` when absent, and when present delete the duplicate source file. Preserve idempotency when `source_path` already resolves to the target CAS entry.
4. Implement `link_into_produces(cas_path, target_path)` by unlinking `target_path` and creating a relative symlink from `target_path.parent` to the CAS entry. Ensure the target parent directory exists.
5. Use only stdlib file APIs. Do not add a shared CAS abstraction, dependency, database, or background service.

### Step 2: Extend produces-passed events (`artagents/core/task/events.py`)
**Scope:** Small

3. Preserve hash-chained event behavior by building the event payload before `append_event()` computes and stores the event hash.

### Step 3: Intern artifacts inside the shared produces-check helper (`artagents/core/task/gate.py`)
**Scope:** Medium

5. Append `produces_check_passed` with `cas_hash=cas_entry.name`.
6. Keep `_run_inline_checks()` as the single hook for CAS. Code steps reach it through `record_dispatch_complete()`, and attested steps already reach it through `_dispatch_attested()` immediately after `step_attested` / `item_attested` is appended.

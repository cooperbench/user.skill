        # Implementation Plan: Timeline Agent Image Generation Alignment

## Overview

The timeline agent creates image generation tasks that don't match the ImageGenerationForm's behavior. Three core problems:

1. **Wrong model default** — The agent tells the LLM to use `wan-2.2` for text-to-image, but `normalizeImageGenerationModelName` returns `null` for it, so the resolver defaults to `wan_2_2_t2i` (invisible in TaskPane). The form always sends a valid model from `selectedTextModel`.
2. **No reference awareness** — The form loads the user's active style reference from project settings and sends `style_reference_image`. The agent has no knowledge of saved references.
3. **Stale prompts/schemas** — The system prompt and tool schema list `wan-2.2` as a text-to-image model when it's actually only valid for image-to-video.

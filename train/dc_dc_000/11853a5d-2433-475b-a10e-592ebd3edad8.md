### 5. **Configuration for Dimensions Per Batch**

**Max Files Per Batch Configuration:**
- Parameter `max_files_per_batch` (optional, int or None) passed to `build_investigation_batches()`
- Passed through to each `_batch_*()` function's `max_files` parameter
- Controls **file count limit per batch**, not dimension count

**No Existing Configuration for Dimensions Per Batch:**
- The number of dimensions per batch is hardcoded and not configurable

### 6. **Dimension Filtering Function**

**Location:** `filter_batches_to_dimensions()` (lines 519-564)
- **Purpose:** Filters batches to only include user-selected dimensions
- **Input:** Full batch list + requested dimensions list
- **Process:**

  3. If selected dimensions aren't covered, creates a "Cross-cutting Sweep" fallback batch (lines 543-563)

**Not Used for Building:** This is for filtering/post-processing, not for initial batch construction.

### 9. **Issue Budget Per Batch**

**Location:** `feedback_contract.py` and `prompt_sections.py`

**Function:** `max_batch_issues_for_dimension_count()` (lines 16-19 in feedback_contract.py)

- Formula: `max(DEFAULT_MAX_BATCH_ISSUES, dimension_count)`
- `DEFAULT_MAX_BATCH_ISSUES = 10` (line 12)
- **Example:** A batch with 3 dimensions allows 10 issues (max of 10 and 3)

- This controls how many issues the reviewer should report for each batch

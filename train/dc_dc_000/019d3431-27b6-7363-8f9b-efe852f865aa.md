        # Implementation Plan: Parallel Worker Support for SWE-bench Eval Harness

## Overview

The SWE-bench eval harness (`evals/run_evals.py`) currently runs tasks sequentially via `run_all_evals()`, which iterates `selected_eval_names` one-by-one. Each task takes ~25 min (clone → megaplan → score), making 300 tasks ~125 hours wall-clock.

**Goal:** Add a `--workers N` flag that splits the task list across N independent subprocesses, each writing predictions to a shared directory, followed by a combined batch-scoring step.

**Key constraints:**
- `--workers 1` (or omitted) = exact current behavior, no code path changes.
- Must not touch the existing sequential `run_all_evals()` loop — only add new parallel orchestration on top.
- Each worker needs its own `workspace_dir` to avoid git clone conflicts.
- Workers use `swebench_patch_only=True` during generation (skip per-task Docker scoring).
- After all workers finish, run `swebench.harness.run_evaluation` once on the combined predictions JSONL.

**Repository shape:**
- CLI entry: `evals/run_evals.py:main()` (argparse, lines 1348-1416)
- Main loop: `evals/run_evals.py:run_all_evals()` (lines 615-803)
- Config: `evals/config.py:EvalConfig` dataclass (lines 31-83)
- SWE-bench backend: `evals/benchmarks/swe_bench.py:SWEBenchBackend`
- Predictions written per-task at `{workspace_dir}/../_swebench_predictions/{instance_id}.jsonl`
- Batch runner precedent: `batch_runner.py` uses `multiprocessing.Pool`

## Phase 2: Parallel Orchestrator

### Step 3: Create `evals/parallel.py` — the parallel orchestrator
**Scope:** Large (core of this feature)
1. **Create** `evals/parallel.py` with a `run_parallel_workers(config_path, eval_names, workers)` function.
2. **Flow:**
   ```
   a. Load config, resolve benchmark, get full task list
   b. Split task list into N roughly-equal chunks (round-robin or contiguous)
   c. Create a shared predictions dir: {workspace_dir}/../_swebench_predictions/
   d. For each worker i=0..N-1:
      - Clone the config JSON to a temp file with overrides:
        * workspace_dir = {original_workspace_dir}-{i}/
        * swebench_patch_only = true
        * evals_to_run = chunk[i]
        * run_name = {original_run_name}/worker-{i}
      - Spawn: subprocess.Popen(["python", "-m", "evals.run_evals", "--config", temp_config_i])
   e. Wait for all subprocesses (poll with timeout, stream stderr)
   f. Collect exit codes; if any worker crashed, log error but continue
   ```
3. **Key detail:** Each worker is a full `run_evals` subprocess that re-enters `run_all_evals()` with its own config. This reuses 100% of existing code with zero modifications to the sequential path.
4. **Predictions directory:** Workers inherit the same parent for predictions because `swe_bench.py:247` uses `workspace_path.parent / "_swebench_predictions"`. Since each worker's `workspace_dir` differs (`workspaces-0/`, `workspaces-1/`), they'd write to *different* prediction dirs. **Fix:** Add a `swebench_predictions_dir` config override (or symlink). Simplest: after workers finish, glob all `workspaces-*/\_swebench_predictions/*.jsonl` into a single combined JSONL.

### Step 4: Merge predictions and run batch scoring (`evals/parallel.py`)
**Scope:** Medium
1. **After** all workers finish, glob `{workspace_dir}-*/_swebench_predictions/*.jsonl` into a single `combined_predictions.jsonl` in the results dir.
2. **Run** batch Docker scoring:
   ```python
   subprocess.run([
       "python", "-m", "swebench.harness.run_evaluation",
       "--predictions_path", str(combined_predictions_path),
       "--max_workers", str(min(workers, 4)),  # Docker parallelism
       "--run_id", f"hermes-batch-{run_timestamp}",
       "--namespace", "",
   ], timeout=config.docker_timeout * total_tasks)
   ```
3. **Parse** the batch results using the existing `_check_resolved()` pattern from `SWEBenchBackend`.

### Step 5: Merge per-worker summaries into unified summary (`evals/parallel.py`)
**Scope:** Medium
1. **Load** each worker's `summary_*.json` from `results/{run_name}/worker-{i}/`.
2. **Merge** the `evals` arrays from all worker summaries into one.
3. **Overwrite** deferred scoring results: for each entry where `scoring=deferred`, look up the batch scoring result and update `status`, `test_result.success`.
4. **Recompute** aggregates (passed/failed/errors/escalated/cost/time).
5. **Write** the unified `summary_{run_timestamp}.json` to the top-level results dir.
6. **Print** the combined summary to stdout (same format as sequential mode).

### Step 3: Create `evals/parallel.py` — the parallel orchestrator
**Scope:** Large (core of this feature)
1. **Create** `evals/parallel.py` with a `run_parallel_workers(config_path, eval_names, workers)` function.
2. **Flow:**
   ```
   a. Load config, resolve benchmark, get full task list via benchmark.list_tasks()
   b. Split task list into N roughly-equal contiguous chunks
   c. Create a shared predictions dir at a deterministic location:
      {results_root}/_swebench_predictions/
   d. For each worker i=0..N-1:
      - Write a temp config JSON with these overrides:
        * workers = 1                          ← PREVENTS RECURSIVE SPAWNING
        * workspace_dir = {original_workspace_dir}-{i}/
        * swebench_patch_only = true
        * evals_to_run = chunk[i]
        * run_name = {original_run_name}/worker-{i}

        * HERMES_HOME = {original_workspace_dir}-{i}/_hermes_home/
      - Spawn: subprocess.Popen(
            ["python", "-m", "evals.run_evals", "--config", temp_config_i],
   ```

4. **HERMES_HOME isolation:** Each worker subprocess inherits a unique `HERMES_HOME` via its environment. This flows through to:

   - Returns `dict[str, bool]` mapping `instance_id → resolved`

   ```python
   def _parse_batch_results(run_id: str) -> dict[str, bool]:
       """Parse swebench batch evaluation into {instance_id: resolved}."""
       results: dict[str, bool] = {}
       # Primary: read the JSON report written by swebench
       for results_dir in [Path("evaluation_results"), Path(f"logs/{run_id}")]:
           for json_file in results_dir.rglob("*.json"):
               data = json.loads(json_file.read_text())
               if isinstance(data, dict):

                   for rid in data.get("resolved_ids", []):

                   # Also check per-instance format
                   if "instance_id" in data and "resolved" in data:
   ```

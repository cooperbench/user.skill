### Where video travel settings are stored
- **Table:** shots.settings JSONB column, keyed by tool_id 'travel-between-images'
- **Scope:** Per-shot (shot > project > user > defaults cascade)
- **NOT in projects.settings** like image gen — this is a different storage path
- Settings loaded via useAutoSaveSettings → useToolSettings → shots.settings['travel-between-images']

### Key defaults the agent needs to know about
From settings.ts defaults (lines 158-194):
- selectedModel: 'wan-2.2' (options: wan-2.2, ltx-2.3, ltx-2.3-fast)
- batchVideoFrames: 61 (4N+1 format)
- batchVideoSteps: 6
- guidanceScale: undefined
- generationTypeMode: 'i2v' (i2v vs vace)
- amountOfMotion: 50 (0-100, converted to 0-1)
- motionMode: 'basic' vs 'advanced'
- turboMode: false
- smoothContinuations: false
- enhancePrompt: false
- loras: [] (Array<ShotLora> with id, name, path, strength, previewImageUrl, trigger_word)
- phaseConfig: undefined (advanced mode only)
- ltxHdResolution: true

- base_prompts, negative_prompts, text_before/after_prompts
- segment_frames, frame_overlap

- amount_of_motion

- pair_loras (per-pair overrides)
- turbo_mode, guidance_scale
- continuation_config (if smooth continuations)
- structure_guidance, travel_guidance

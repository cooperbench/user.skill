## Overview

Phase 7 of the orchestrator V1 design (`docs/orchestrator-v1-plan.md` §12) introduces a **per-project** CAS at `<projects_root>/<slug>/.cas/<sha256>`. When a step's inline produces check passes for a file artifact, the file is moved into `.cas/<hash>` and the original path becomes a relative symlink to the CAS entry. Identical content from later steps reuses the same CAS entry. The CAS is **per-project**, never shared across projects (SD-008, SD-029).

The natural hook point is `_run_inline_checks()` in `artagents/core/task/gate.py:1110-1167`, which runs immediately after a check resolves `ok=True` and emits `produces_check_passed`. Phases 1–6 already landed: gate, three step kinds, produces inline checks, repeat/fan-out, lifecycle verbs, stop-hook nudge. Phase 7 is purely additive.

Project root is computed from `decision.project_root` (a `<projects_root>/<slug>/` Path) — the doc's "project_dir" is exactly this. `step_dir_for_path()` already gives the absolute step dir whose `entry.path` is appended to. After the file passes its check, it lives at `step_dir / entry.path`. We hash that file, move it into `<project_root>/.cas/<sha256>`, and replace the original with a relative symlink.

Key invariants to honor:
- Stdlib only (`hashlib`, `os.symlink`, `pathlib`).
- Symlinks are **relative** so the run dir stays portable (e.g. `../../../../.cas/<hash>` from `runs/<run-id>/steps/<step-id>/produces/file`).
- Idempotent intern: if the CAS entry already exists, drop the source and reuse.
- Per-project scope: never walk above `<project_root>`. Each slug has its own `.cas/`.
- Only intern when the artifact path resolves to a regular file (skip if check passed without producing a file, or path is already a symlink into `.cas/`).
- The `produces_check_passed` event gains an optional `cas_sha256` field so events.jsonl records which CAS entry the artifact was interned into; absence means the artifact was not a file (defensive).

## Main Phase

### Step 1: Add the CAS module (`artagents/core/task/cas.py`)
**Scope:** Small
1. **Create** new module with three functions and stdlib-only imports (`hashlib`, `os`, `pathlib`):
   - `cas_dir(project_dir: Path) -> Path` — returns `<project_dir>/.cas`, creating parents lazily on writes only.
   - `cas_path(project_dir: Path, sha256: str) -> Path` — returns `<project_dir>/.cas/<sha256>`. Validates hex (64 lowercase hex chars) defensively.
   - `hash_file(path: Path) -> str` — streams the file in 64KB chunks through `hashlib.sha256()` and returns the hex digest.
   - `intern(project_dir: Path, source_path: Path) -> tuple[Path, str]` — hashes `source_path`, computes the CAS path, and:
     - If the CAS entry already exists: `source_path.unlink()` (discard duplicate) and return the existing CAS path + hash.
     - Otherwise: `source_path.replace(cas_target)` (atomic on same filesystem). Return `(cas_target, sha256)`.
     - Skip-and-return early if `source_path` is already a symlink whose `readlink()` resolves under `cas_dir(project_dir)` — already interned.
   - `link_into_produces(cas_target: Path, target_path: Path) -> None` — computes `os.path.relpath(cas_target, target_path.parent)` and calls `os.symlink(rel, target_path)`. If `target_path` exists (rare race), unlink first.
2. **Export** `__all__ = ["cas_dir", "cas_path", "hash_file", "intern", "link_into_produces"]`.

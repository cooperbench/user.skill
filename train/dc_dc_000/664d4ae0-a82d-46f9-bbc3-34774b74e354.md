160	## Key Gotchas
161	
162	- **48h log retention**: `system_logs` is pruned after 48 hours. Use `tasks.error_message` for older issues.
163	- **PAT auth**: PAT goes in `Authorization: Bearer` header, NOT in `apikey` header. Edge functions accepting PATs need `verify_jwt = false` in `supabase/config.toml`.
164	- **cloud_enabled**: Workers can only claim tasks from users with cloud processing enabled. Check with `debug.py task <id>` or SQL query in [Worker doc](./debug-gpu-worker.md).
165	- **run_id uniqueness**: When duplicating test tasks, always set a new `run_id`. `complete_task` counts ALL children sharing a `run_id` — stale children cause false failures.
166	- **Worker init time**: ~3-4 min for CUDA/model imports after restart. Don't panic if it's not claiming immediately.

# compactify

Distil the current thread into a "next agent picks up cleanly" handoff doc. Codex reads the transcript and writes; the main thread just orchestrates.

## What it produces

A markdown doc at `<cwd>/.compactify/<sessionId>-<timestamp>.md` with:

- **Goal** — 2-3 sentences on what the user is trying to accomplish next.
- **Critical context** — decisions, constraints, gotchas, file paths + line refs, symbols touched. The minimum a fresh agent needs to be useful in turn one.
- **Open threads** — paused / queued / awaiting verification (megaplan gates, unfinished subagents, untested changes).
- **Next tasks (high level)** — ordered list of ~3–7 outcomes, not prescriptive steps.
- **What to ignore** — dead ends, ruled-out hypotheses, already-tried-and-failed approaches. Stops the next agent retracing.

The doc must be readable in 60 seconds. Codex is told to be ruthlessly selective.

## Steps for the agent

### 1. Resolve the current session

```bash

CWD=$(jq -r .cwd "$SESSION_FILE")
SLUG=$(echo "$CWD" | sed 's|/|-|g')
```

```bash
TS=$(date +%Y%m%d-%H%M%S)

OUT_PATH="$CWD/.compactify/${SESSION_ID}-${TS}.md"
```

### 5. **Key Implementation Patterns**

**Frontend Patterns:**
- **Dynamic element generation**: POM border letters created via JavaScript DocumentFragment
- **Event listeners**: Scroll detection for border visibility
- **Loading animations**: Staggered reveal of elements with `.loading-element` class
- **Image preloading**: GIF assets loaded into memory on page load
- **Video handling**: Mobile-specific attributes applied via script

**Backend Patterns:**
- **Template rendering**: HTML templates with placeholder strings (`{{TITLE}}`, `{{CONTENT}}`, etc.)
- **Inline HTML generation**: Most pages render HTML as template literals in server.js
- **No database**: Everything hardcoded or read from filesystem
- **No form handling**: Site is read-only (no POST endpoints)

**Data Flow:**
- Markdown files → parsed with frontmatter → validated → served
- Hardcoded conversation data → rendered to HTML → sent to client
- Static files → served directly with correct MIME type

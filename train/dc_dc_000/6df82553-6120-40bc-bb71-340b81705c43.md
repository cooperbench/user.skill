Phase 9 implements `artagents author test` as a full runtime replay that mirrors the real `start`/`next` lifecycle: initialize a project directory in a scratch location, drive the plan step-by-step by calling `gate_command` in a loop, auto-approve attested steps via `ARTAGENTS_AUTHOR_TEST=1`, normalize the resulting `events.jsonl`, and diff against the pack's committed golden file. The scaffolded `_cmd_test` in `artagents/orchestrate/cli.py` (lines 311–371) is replaced, and the inlined `_strip_volatile` helper is consolidated into the new `normalize.py` module.

Key constraints:
- Runs in scratch dirs via `tempfile.mkdtemp` — does not touch real project state.
- Auto-approval for attested steps gated behind `ARTAGENTS_AUTHOR_TEST=1`; NOT available in normal `start`/`next`.
- Hash-chain hashes (`hash`) and timestamps (`ts`) are stripped during normalization; `run_id`, `actor`, and absolute paths are also stripped or normalized to `<RUN_DIR>/<rel>`.
- `--regenerate` flag writes current output as the new golden.
- CLI surface matches the stop condition: `--pack builtin --orchestrator hype --fixture smoke`.
- Existing `test_author_test_scaffold.py` tests are rewritten to match the new runtime-replay behavior.

### Step 2: Create event normalization module (`artagents/core/task/normalize.py`)
**Scope:** Medium — consolidates and replaces the inlined `_strip_volatile` at `cli.py:287-308`

1. **Define** `VOLATILE_FIELDS = frozenset({"ts", "hash", "run_id", "actor"})`.
   - `ts` and `hash` are inherently volatile (timestamps, hash-chain dependent).
   - `run_id` is tied to the generated run name — different every time.
   - `actor` comes from `ARTAGENTS_ACTOR` / hostname — would drift across machines/CI.
2. **Define** `def normalize_event(event: dict, *, scratch_root: str) -> dict`:
   - Deep-copy the event dict.
   - Strip `VOLATILE_FIELDS` keys.
   - Replace absolute paths matching `<scratch_root>/...` with `<RUN_DIR>/<rel>` in any string value (case-insensitive, to handle the project directory path).
   - Return the cleaned dict.
3. **Define** `def normalize_events_jsonl(lines: list[str], scratch_root: str) -> list[str]`:
   - Parse each line as JSON, call `normalize_event`, re-serialize with `sort_keys=True`.
   - Skip empty lines. On JSON decode failure, keep the raw line (same as current `_strip_volatile` behavior).
4. **Export** `normalize_event` and `normalize_events_jsonl` in `artagents/core/task/__init__.py`.
5. **Replace** uses of `_strip_volatile` in `cli.py` with `normalize_events_jsonl` (see Step 5).

## Phase 2: Core — Runtime Replay + Auto-Approval

**Scope:** Small — insert at the top of `_dispatch_attested` (before line 918)

   ```python
   if is_author_test():
       append_event(
           events_path,
           make_step_attested_event(path_str, "agent", "author-test", ("source=author_test",)),
       )
       decision = GateDecision(
           active=True,
           run_id=run_id,
           plan_step_id=path_str,
           events_path=events_path,
           reentry=False,
           step_kind="attested",

       )

   ```
   - This bypasses all identity validation (`match_attested_command`, `validate_attested_identity`) when `ARTAGENTS_AUTHOR_TEST=1`.

   - Inline produces checks still run (important for rewind-on-fail fidelity).

### Step 5: Implement the real `_cmd_test` runtime replay (`artagents/orchestrate/cli.py`)
**Scope:** Large — replaces the scaffold `_cmd_test` (lines 311–371)

1. **Compile** the orchestrator DSL to get the plan:
   - Call `compile_to_path(qid, packs_root=packs_root)` to ensure `<pack>/build/<name>.json` exists.
   - Load it: `plan = load_plan(build_path)`.

2. **Create scratch project directory**:
   - `scratch = Path(tempfile.mkdtemp(prefix="artagents-author-test-"))`
   - `project_dir = scratch / fixture_name` (the project slug)
   - Write `plan.json` from the compiled build payload into `project_dir / "plan.json"`.
   - Compute `plan_hash = compute_plan_hash(project_dir / "plan.json")`.
   - Generate a deterministic run_id: `run_id = "test-run"`.
   - Write `active_run.json`: `{"run_id": run_id, "plan_hash": plan_hash}`.
   - Create `project_dir / "runs" / run_id /`.
   - Append `run_started` event to `events.jsonl` (with `actor=None` to avoid hostname drift).

3. **Save and set env vars** (with restore in finally):
   ```python
   saved_project_root = os.environ.get("ARTAGENTS_PROJECTS_ROOT")
   saved_author_test = os.environ.get(AUTHOR_TEST_ENV)
   os.environ["ARTAGENTS_PROJECTS_ROOT"] = str(scratch)
   os.environ[AUTHOR_TEST_ENV] = "1"
   ```

4. **Drive the plan step-by-step in a loop**:
   - Load `plan.json` and iterate through `plan.steps` (handling each step in linear order; `gate_command`'s internal `_auto_traverse_to_leaf` handles nested/repeat).
   - For each step:
     - Call `gate_command(slug=fixture_name, command=step.command, argv=[], root=scratch)`.
     - If `decision.step_kind == "code"`:
       - Run `subprocess.run(shlex.split(step.command), env=child_subprocess_env(), cwd=step_dir_for_path(...), check=False)`.
       - Call `record_dispatch_complete(decision, returncode)`.
     - If `decision.step_kind == "attested"`:
       - Auto-approval already fired inside `gate_command`. `record_dispatch_complete` is a no-op for attested (line 1099-1101).
     - Continue loop to next step.
   - Stop when `gate_command` raises `TaskRunGateError` with "plan is exhausted" (caught and treated as successful completion).

5. **After completion** (or on any error):
   - Read `events.jsonl` from `scratch/fixture_name/runs/test-run/`.
   - Normalize with `normalize_events_jsonl(events_lines, str(scratch))`.
   - If `regenerate`: write normalized output to `<pack>/golden/<fixture_name>.events.jsonl`, print confirmation ("golden regenerated: <path>; commit this file if intentional"), exit 0.
   - Else:
     - Load golden file from `<pack>/golden/<fixture_name>.events.jsonl`.
     - If golden missing: print "no golden file at <path>; use --regenerate to create one", exit 1.
     - Normalize golden with same normalization (golden may already be pre-normalized but we normalize for safety).
     - Diff with `difflib.unified_diff`. Exit 0 on match, exit 1 on drift (printing unified diff to stdout).

6. **Cleanup**: In a `finally` block:
   - Restore env vars: `os.environ["ARTAGENTS_PROJECTS_ROOT"] = saved_project_root` (or `os.environ.pop` if none). Same for `AUTHOR_TEST_ENV`.
   - `shutil.rmtree(scratch, ignore_errors=True)`.

7. **Remove** the old `_strip_volatile` function (lines 287–308) and `_VOLATILE_EVENT_FIELDS` constant — they are now consolidated in `normalize.py`.

## Phase 3: Hype Pack — DSL, Fixture, Golden

### Step 6: Create the hype orchestrator pack (`artagents/packs/builtin/hype/`)
**Scope:** Medium — new pack directory with DSL, fixtures, golden

1. **Create `artagents/packs/builtin/hype/hype.py`** with the canonical `builtin.hype` plan:
   ```python
   from artagents.orchestrate import code, nested, plan
   from artagents.verify import file_nonempty, json_file

   hype = plan("builtin.hype", [
       code("transcribe", argv=[
           "python3", "-m", "artagents", "executors", "run", "builtin.transcribe",
           "--audio", "<FIXTURE_AUDIO>",
       ], produces={"transcript": json_file("transcript.json")}),
       code("cut", argv=[
           "python3", "-m", "artagents", "executors", "run", "builtin.cut",
           "--brief", "<FIXTURE_BRIEF>",
       ], produces={"timeline": json_file("hype.timeline.json"), "assets": json_file("hype.assets.json")}),
       code("render", argv=[
           "python3", "-m", "artagents", "executors", "run", "builtin.render",
       ], produces={"video": file_nonempty("hype.mp4")}),
       nested("thumbnail", plan="builtin.thumbnail_maker", produces={"thumbnail": file_nonempty("thumbnail.png")}),
   ])
   ```
   Note: `<FIXTURE_AUDIO>` and `<FIXTURE_BRIEF>` are placeholders — at runtime, the fixture provides real paths. But since author-test runs against this plan in a scratch dir with auto-approval, the code steps would actually try to run the real executors, which need API keys. **For the smoke fixture test to pass deterministically**, we use a smoke-only plan.

2. **Create `artagents/packs/builtin/hype/hype_smoke.py`** with deterministic echo commands:
   ```python
   from artagents.orchestrate import attested, code, plan
   from artagents.verify import file_nonempty

   hype_smoke = plan("builtin.hype-smoke", [
       code("step-1", argv=["echo", "hello"], produces={"out": file_nonempty("out.txt")}),
       code("step-2", argv=["echo", "world"], produces={"out2": file_nonempty("out2.txt")}),
       attested("review", command="review.sh", instructions="peer review", ack="agent"),
   ])
   ```
   - Three steps: two code steps (echo), one attested step.
   - This plan is fully deterministic and requires no external dependencies.

3. **Create `artagents/packs/builtin/hype/fixtures/smoke/`**:
   - Write a `.keep` file (no special inputs needed for echo commands).

4. **Create `artagents/packs/builtin/hype/golden/smoke.events.jsonl`** — the committed golden:
   - This will be generated by running `artagents author test --pack builtin --orchestrator hype-smoke --fixture smoke --regenerate` once the runtime replay is working.
   - Expected structure: `run_started`, `step_dispatched` (step-1), `step_completed` (step-1), `step_dispatched` (step-2), `step_completed` (step-2), `step_attested` (review with attestor_id=author-test).

   ```python
           # nested step's command (which is the nested plan's entry command).
           step_command = step.command if hasattr(step, 'command') else "next"
           step_argv = [step_command]

       try:
           decision = gate_command(
               slug=fixture_name,
               command=step_command,
               argv=list(step_argv),
               root=scratch,
           )
       except TaskRunGateError as exc:
           if "plan is exhausted" in str(exc.reason).lower():
               break
           raise

       if decision.step_kind == "code":
           # Run the subprocess using the step's command (NOT decision.command — it doesn't exist).
           # GateDecision (gate.py:79-91) has no 'command' field.
           result = subprocess.run(
               shlex.split(step.command),
               cwd=step_dir_for_path(
                   fixture_name, run_id, decision.plan_step_path,
                   root=scratch,
               ),
               capture_output=True,
               text=True,
               check=False,
           )
           record_dispatch_complete(decision, result.returncode)
       # attested steps are auto-approved inside gate_command;
       # record_dispatch_complete is a no-op for attested (gate.py:1099-1101)
   ```

   **Key insight**: The driver must peek the cursor *before* each `gate_command()` call to discover the current step's command. It cannot pass a hardcoded `"next"` string because `_dispatch_code` (gate.py:804) strictly compares `command != step.command`. It cannot read `decision.command` because `GateDecision` has no such field.

5. **After completion** (or on any error):
   - Read `events_path` as lines.
   - Normalize with `normalize_events_jsonl(lines, str(scratch))`.
   - If `regenerate`: write normalized output to `<pack>/golden/<fixture_name>.events.jsonl`, print `golden regenerated: <path>; commit this file if intentional`, exit 0.
   - Else:
     - Load golden file from `<pack>/golden/<fixture_name>.events.jsonl`.
     - If golden missing: print `no golden file at <path>; use --regenerate to create one`, exit 1.
     - Normalize golden with same normalization (for portability).
     - Diff with `difflib.unified_diff`. Exit 0 on match, exit 1 on drift (printing unified diff to stdout).

6. **Finally block** (env restore + cleanup):
   ```python
   finally:
       for key, saved in (
           ("ARTAGENTS_PROJECTS_ROOT", saved_project_root),
           (AUTHOR_TEST_ENV, saved_author_test),
           (ARTAGENTS_ACTOR, saved_actor),
       ):
           if saved is None:
               os.environ.pop(key, None)
           else:
               os.environ[key] = saved
       shutil.rmtree(scratch, ignore_errors=True)
   ```

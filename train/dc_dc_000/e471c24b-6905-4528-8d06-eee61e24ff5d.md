### 2. **`plan["overrides"]` Structure & Clusters**

**Each `ItemOverride` entry is a metadata record for a single issue:**

```python
plan["overrides"]["issue_id"] = {
  "issue_id": "review::test.py::r1",    # Required, matches dict key
  "description": "Custom description",  # Optional, user-provided text
  "note": "Needs review",               # Optional, user annotation
  "cluster": "my-cluster",              # OPTIONAL: links to cluster name
  "created_at": "2026-03-01T...",
  "updated_at": "2026-03-01T..."
}
```

**Key behaviors:**
- `cluster` field is `None|str` — points to the cluster name this issue belongs to
- Overrides are **NOT deleted** when an issue is purged (see purge_ids below)
- They're created automatically when you add an issue to a cluster
- When you remove an issue from a cluster, the override's `cluster` field is cleared to `None`

### 3. **`purge_ids(plan: PlanModel, issue_ids: list[str]) -> int`**

Removes issue IDs **entirely** from the plan.

**What it cleans:**
- Removes from `queue_order`
- Removes from `skipped` (entire dict entry deleted)
- Removes from all cluster `issue_ids` lists
- Clears the `cluster` field in any override that references a deleted issue

**What it does NOT clean:**
- Does NOT delete override records (descriptions/notes kept for history)
- Returns: count of IDs that were actually present somewhere

**Example:**
```python
from desloppify.engine.plan import purge_ids

plan = load_plan()
deleted_count = purge_ids(plan, ["issue1", "issue2"])  # Returns 2
# "issue1" and "issue2" removed from queue, clusters, skipped
# But plan["overrides"]["issue1"] still exists (just with cluster=None)
```

### 6. **How Clusters & Overrides Link Together**

When you add an issue to a cluster:

```python
from desloppify.engine.plan import add_to_cluster

add_to_cluster(plan, "my-cluster", ["issue1", "issue2"])
```

**This happens:**
1. Issue IDs are added to `plan["clusters"]["my-cluster"]["issue_ids"]`
2. Override records are **created or updated** for each issue:
   ```python
   plan["overrides"]["issue1"] = {
     "issue_id": "issue1",
     "cluster": "my-cluster",  # Backlink created
     "created_at": "...",
     "updated_at": "..."
   }
   ```
3. Cluster's `updated_at` is refreshed

When you remove from a cluster:

```python
from desloppify.engine.plan import remove_from_cluster

remove_from_cluster(plan, "my-cluster", ["issue1"])
```

**This happens:**
1. Issue removed from `cluster.issue_ids`
2. Override's `cluster` field set to `None` (override record kept)
3. If cluster is `auto=True`, `user_modified` is set to `True`

   222→            continue
   223→        suggestion = entry.get("suggestion")
   224→        if isinstance(suggestion, str) and suggestion.strip():
   225→            dims.add(dim.strip())
   226→    return dims

   229→def _feedback_dimensions_from_dimension_notes(dimension_notes: object) -> set[str]:

   233→    dims: set[str] = set()
   234→    for dim, note in dimension_notes.items():
   235→        if not isinstance(dim, str) or not dim.strip():
   236→            continue
   237→        if not isinstance(note, dict):
   238→            continue
   239→        if not _has_non_empty_strings(note.get("evidence")):
   240→            continue

   245→def _validate_assessment_feedback(

   248→    """Return dimensions missing required feedback and required low-score issues."""
   249→    assessments = issues_data["assessments"]

   251→        return [], []
   252→
   253→    issue_dims = _feedback_dimensions_from_issues(issues_data["issues"])

   256→        _feedback_dimensions_from_dimension_notes(issues_data["dimension_notes"])

   262→            continue

   264→        if score is None:
   265→            continue
   266→        if score_requires_dimension_issue(score) and dim_name not in issue_dims:
   267→            missing_low_score_issues.append(f"{dim_name} ({score:.1f})")
   268→        if score_requires_explicit_feedback(score) and dim_name not in feedback_dims:
   269→            missing_feedback.append(f"{dim_name} ({score:.1f})")

   354→def _validate_schema_requirements(

   399→    override_enabled, override_attest = resolve_override_context(

   410→    issues_data, policy_errors = apply_assessment_import_policy(

   422→    if issues_data is None:

   425→    feedback_errors = _validate_feedback_requirements(

   432→
   433→    schema_errors = _validate_schema_requirements(
   434→        issues_data,
   435→        lang_name=resolved_options.lang_name,
   436→        allow_partial=resolved_options.allow_partial,
   437→    )
   438→    if schema_errors:
   439→        return None, schema_errors
   440→
   441→    return issues_data, []
   442→
   443→
   444→def load_import_issues_data(
   445→    import_file: str,
   446→    *,

## Overview
Build a worker-local capability-contract source of truth and report loop that separates product capabilities from task types, route keys, VibeComfy template bindings, live cases, app enqueue surfaces, and artifact expectations. The root approach is still correct: the problem is not missing VibeComfy graph validation, it is missing worker-owned product/app parity accounting across routing, app task creation, variant axes, artifact semantics, and live evidence. ## Phase 1: Foundation — Data Sources and Import Boundaries

### Step 1: Add the contract package (`scripts/capability_contracts/`)
**Scope:** Medium
1. **Create** `scripts/capability_contracts/__init__.py`, `scripts/capability_contracts/model.py`, `scripts/capability_contracts/loaders.py`, `scripts/capability_contracts/report.py`, and `scripts/capability_contracts/README.md`.

        # Implementation Plan: ImageVariantPicker for SegmentSettingsForm Thumbnails

## Overview

Add an inline variant picker to the start/end image thumbnails in `SegmentSettingsForm`. When a generation has multiple variants, a small badge appears on the thumbnail. Clicking opens a popover with a grid of variant thumbnails. Selecting a variant calls `setPrimaryVariant` and optimistically swaps the displayed image URL.

**Current state:** The form renders start/end images as clickable `<img>` buttons (`SegmentSettingsForm.tsx:242-304`). It receives `startImageUrl`/`endImageUrl` for display and `startImageShotGenerationId`/`endImageShotGenerationId` for navigation. The callers (`SegmentSlotFormView`, `SegmentRegenerateForm`) also have `startImageGenerationId`/`endImageGenerationId` (the actual generation IDs needed for variant lookup) but these are NOT passed to the form today.

**Key constraint:** The `useVariants` hook needs a `generationId` (not a shot generation ID). We need to thread generation IDs through as new props.

**UI primitives available:** `Popover`/`PopoverTrigger`/`PopoverContent` from `@base-ui/react/popover` wrapper, lucide icons, Tailwind + `@container` for responsive layout.

## Main Phase

### Step 1: Add generation ID props to the form (`types.ts`, callers)
**Scope:** Small
1. **Add** `startImageGenerationId?: string` and `endImageGenerationId?: string` to `SegmentSettingsFormTimelineProps` in `reigh-app/src/shared/components/SegmentSettingsForm/types.ts:164-175`.
2. **Thread** these from callers:
   - `SegmentSlotFormView.tsx:~93` — add `startImageGenerationId: segmentSlotMode.pairData.startImage?.generationId`
   - `SegmentRegenerateForm.tsx:~256` — add `startImageGenerationId` / `endImageGenerationId` (already available in scope)
3. **Destructure** them in `SegmentSettingsForm.tsx` props.

### Step 2: Create the ImageVariantPicker component
**Scope:** Medium
1. **Create** `reigh-app/src/shared/components/SegmentSettingsForm/components/ImageVariantPicker.tsx`.
2. **Props:** `generationId: string`, `currentImageUrl: string`, `onImageUrlChange: (url: string) => void`.
3. **Internal state:** Uses `useVariants({ generationId })` to fetch variants. Only renders if `variants.length > 1`.
4. **UI structure:**
   - **Badge:** A small count indicator (e.g., `Layers` icon from lucide with count) overlaid on the parent thumbnail, positioned absolute bottom-right. Only visible when variants > 1.
   - **Popover:** On badge click, opens a `Popover` with a compact grid (2-3 columns) of variant thumbnails.
   - **Thumbnails:** Each is a small `<img>` with aspect-video, styled similarly to the existing thumbnail approach in `VariantCard.tsx:111-122` (thumbnail_url || location, object-cover, bg-muted fallback). Primary variant gets a green ring (matching `VariantCard.tsx:105`).
   - **Click behavior:** Clicking a variant thumbnail:
     1. Calls `onImageUrlChange(variant.thumbnail_url || variant.location)` immediately (optimistic UI).
     2. Calls `setPrimaryVariant(variant.id)` (fires mutation, handles DB + cache invalidation).
     3. Closes the popover.
5. **No filtering, starring, hover cards, delete.** Just thumbnails with primary highlighted.

### Step 3: Wire ImageVariantPicker into the form thumbnails
**Scope:** Small
1. **Wrap** the start image thumbnail area (`SegmentSettingsForm.tsx:242-258`) to include `<ImageVariantPicker>` as an overlay, only when `startImageGenerationId` is provided.
2. **Same** for end image (`SegmentSettingsForm.tsx:287-303`) with `endImageGenerationId`.
3. **Optimistic URL swap:** The `onImageUrlChange` callback should update a local state override for the displayed image URL. Use `useState` for `startImageUrlOverride` / `endImageUrlOverride`, falling back to the prop URL. When the prop URL changes (parent refetches), clear the override.
4. **Interaction:** The existing click-to-navigate behavior on the thumbnail itself stays unchanged. The variant picker badge is a separate click target positioned inside the thumbnail area.

### Step 4: Validate
**Scope:** Small
1. **Run** TypeScript check: `npx tsc --noEmit` in reigh-app.
2. **Run** existing tests: `SegmentSettingsForm.test.tsx` to ensure no regressions.
3. **Visual check:** Start dev server, open a segment with multiple variants, verify badge appears, popover opens, selecting a variant swaps the image.

3. Step 3 (wiring) — integrates the component.

        # Implementation Plan: Video Editor Full-Screen Integration & Polish

## Overview
The video editor (`/tools/video-editor`) currently renders inside the standard Layout with GlobalHeader (~60px), EditorPane dots, and pane-margin padding — wasting vertical space and creating visual clutter. This plan makes the editor page full-screen with a minimal back bar, suppresses redundant chrome, enables drag from GenerationsPane into the timeline at variant level, collapses the assets panel by default, adds generation click-through from assets, and applies aesthetic polish.

**Key architectural facts from audit:**
- `LayoutMainContent.tsx` renders `GlobalHeader` (line 52) and applies `paddingTop` for editor pane (line 38)
- `EditorPaneTab.tsx:66-68` already returns null on `/tools/video-editor` but the control dots may render separately
- Timeline drop uses HTML5 `dataTransfer` (not @dnd-kit) — `onTimelineDrop` in `useTimelineEditing.ts:530-626` checks for `asset-key` type
- `DraggableImage.tsx` has drag **disabled** (`draggable={false}`) — the wrapper blocks all gallery drag
- `AssetRegistryEntry` type has only `file, type, duration, resolution, fps` — no generation/variant fields
- Assets panel defaults to `useState(true)` at `PropertiesPanel.tsx:25`
- `MediaLightbox` is a controlled component opened via props, not routes

## Phase 1: Full-Screen Layout & Chrome Suppression

### Step 1: Expose route-aware layout mode (`src/app/Layout.tsx`, `src/app/components/LayoutMainContent.tsx`)
**Scope:** Small
1. **Add** a route check in `LayoutMainContent.tsx` using `useLocation().pathname` to detect `/tools/video-editor`.
2. **Conditionally hide** `GlobalHeader` (line 52) when on the editor route — return null or skip render.
3. **Zero out** padding/margins from pane offsets (`paddingTop` at line 38, side margins at lines 58-68) when on editor route.
4. **Verify** `EditorPaneTab.tsx:66-68` null return is working. If EditorPaneControlTab (the dots at top-center) renders through a separate path outside EditorPaneComponent, trace and suppress that too. Check if `EditorPane` is the component at `Layout.tsx:123` — if so the null return should already handle it. If dots come from a different component, find and suppress.

### Step 2: Make VideoEditorShell fill viewport (`src/tools/video-editor/components/VideoEditorShell.tsx`, `src/tools/video-editor/pages/VideoEditorPage.tsx`)

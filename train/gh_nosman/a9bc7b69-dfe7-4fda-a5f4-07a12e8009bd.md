Here's what's actually happening in the terminal ecosystem: ## How terminal background detection actually works ### OSC 11 — the real standard The proper way is to query the terminal directly by sending an escape sequence: ``` \x1b]11;?\x1b\\ → terminal replies with: \x1b]11;rgb:RRRR/GGGG/BBBB\x1b\\ ``` Most modern terminals (kitty, Alacritty, iTerm2, xterm, anything VTE-based like GNOME Terminal) support this. You compute the luminance of the returned RGB and threshold it. This is what libraries like the Rust `termbg` crate implement.

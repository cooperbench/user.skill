**Processing Flow:**

1. **Index Command** (`src/commands/index.rs`):

   - Runs `git ls-tree` to list all files on the branch
   - Filters for `metadata.json` files
   - For each checkpoint, calls `git show entire/checkpoints/v1:<path>` to fetch content

   - Stores session in SQLite gossamer.db with watermark (last_indexed_commit)

2. **Refresh Command** (`src/commands/refresh.rs`):

   - Compares `last_indexed_commit` to current HEAD of branch
   - Only processes new/modified files since watermark
   - Updates watermark after processing

3. **Session Start Hook** (`src/commands/session_start.rs`):

   - Reads JSON from stdin with `session_id` and `cwd`
   - Inserts into gossamer.db sessions table with agent_name="Claude Code"

4. **Session Stop Hook** (`src/commands/session_stop.rs`):
   - Called by Claude Code when session stops
   - Ingests session into witchcraft search DB via `ingest::claude_code::ingest_claude_code()`

### 8. **Ingest & Search Pipeline**

**File:** `src/ingest/claude_code.rs`

**Main Ingestion Function:** `ingest_claude_code(db: &mut DB) -> Result<usize>`

**Steps:**

2. For each repo:
   - Get HEAD of `entire/checkpoints/v1`
   - Compare to `last_search_commit` watermark
   - Get diff of changed metadata.json files since watermark
   - Deduplicate: keep only latest checkpoint per session (highest `<num>`)
3. For each changed checkpoint:
   - `git show` both metadata.json and full.jsonl
   - Parse JSON metadata to get session_id, created_at

   - Generate V5 UUIDs for witchcraft docs
   - Add docs to witchcraft DB with metadata including turn count, branch, etc.
4. Embed chunks using witchcraft embedder
5. Index into search DB

### 10. **Watermark & Incremental Processing**

**Files:** `src/watermark.rs`, checkpoint logic in index.rs and refresh.rs

**Watermarking Strategy:**
- Per-repo git commit SHAs stored as `last_indexed_commit` and `last_search_commit`
- Watermarks prevent reprocessing unchanged content
- On first run, watermark is None → processes all files
- On subsequent runs, watermark is set → `git diff` only shows changed files

**Incremental Search Index** (refresh.rs):
- Uses `git diff --name-only --diff-filter=AM <last> current`
- Only processes Added/Modified metadata.json files
- Avoids reindexing unchanged sessions
- Much faster than full `gossamer index`

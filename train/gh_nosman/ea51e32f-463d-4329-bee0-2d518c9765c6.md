> AGENT

Here's the difference:

**`claude --resume <session_id>`** (what gossamer's `r` keybinding calls):
- Directly reopens a Claude Code conversation by session ID
- Pure chat/conversation restoration — no git operations involved
- Immediately launches an interactive Claude Code session

**`entire resume <branch>`**:
- Higher-level, git-aware operation
- Checks out the specified branch, finds the session ID from commits unique to that branch, restores the session log if missing locally
- Notably it **shows** the command to resume, rather than launching it directly
- Also handles edge cases: fetching from origin if branch is remote-only, resetting git state if commits without checkpoints exist

In short: `entire resume` is a git-branch-centric workflow that recovers a session from the checkpoint history and hands you back a `claude --resume` command. `claude --resume` is the lower-level primitive that actually opens the session.

Gossamer's TUI (`r` key in the sessions screen) calls `claude --resume` directly with a stored session ID — it bypasses `entire resume` entirely since gossamer already tracks the session IDs itself.

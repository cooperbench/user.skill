**Option B (pre-built binaries) is the better path** — no Go needed on the VPS or client machines. ## VPS Setup Build once locally: ```bash cd groove-go make linux ``` Copy to your VPS: ```bash scp dist/groove-relay-linux-amd64 user@1.2.3.4:~/groove-relay ssh user@1.2.3.4 "chmod +x ~/groove-relay" ``` Run it: ```bash ssh user@1.2.3.4 ./groove-relay --port 4001 ``` It prints something like: ``` [relay] node running — share these addresses with your peers: /ip4/1.2.3.4/tcp/4001/p2p/12D3KooWXxxx... /ip4/1.2.3.4/udp/4001/quic-v1/p2p/12D3KooWXxxx... ``` Copy that `/ip4/...` address — clients need it. --- ## Client Setup Give each client the right binary for their OS from your `dist/` folder: | OS | Binary | |----|--------| | Linux | `groove-web-linux-amd64` | | Mac Intel | `groove-web-mac-amd64` | | Mac Apple Silicon | `groove-web-mac-arm64` | | Windows | `groove-web-windows-amd64.exe` | Run it: ```bash ./groove-web-linux-amd64 \ --relay /ip4/1.2.3.4/tcp/4001/p2p/12D3KooWXxxx \ --workspace general \ --http :8080 ``` Then open `http://localhost:8080` in the browser. No Go installation needed. --- ## Keep relay running on VPS Use `systemd` or simply `screen`/`tmux`: ```bash # With screen: screen -S relay ./groove-relay --port 4001 # Ctrl+A D to detach ``` Or a minimal systemd unit: ```ini [Unit] Description=Groove Relay [Service] ExecStart=/home/user/groove-relay --port 4001 Restart=always [Install] WantedBy=multi-user.target ``` ```bash sudo systemctl enable --now groove-relay ``` Also open port 4001 on your VPS firewall (both TCP and UDP for QUIC): ```bash sudo ufw allow 4001/tcp sudo ufw allow 4001/udp ```

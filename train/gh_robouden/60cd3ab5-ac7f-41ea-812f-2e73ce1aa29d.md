This logging enables you to:

✅ **Detect brute force attacks** - Multiple failed attempts from same IP
✅ **Monitor account compromises** - Unusual login patterns or IPs
✅ **Track API key vs password usage** - Understand how users authenticate
✅ **Audit trail** - Complete history of authentication events
✅ **Debug issues** - Detailed failure reasons help troubleshoot problems
✅ **Compliance** - Meet security audit requirements

## Log Format

All logs use the prefix `AUTH:` for easy filtering:

# View all auth events

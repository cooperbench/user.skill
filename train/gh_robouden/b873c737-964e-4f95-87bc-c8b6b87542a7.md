   452→Customize map views with URL parameters:
   453→
   454→| Parameter | Values | Description |
   455→|-----------|--------|-------------|
   456→| `place` | City, country, or location name | Navigate to a specific location by name |
   457→| `lat` | Latitude (-90 to 90) | Latitude coordinate for map center |
   458→| `lon` | Longitude (-180 to 180) | Longitude coordinate for map center |
   459→| `zoom` | 1-18 | Zoom level (used with lat/lon) |
   460→| `minLat`, `minLon`, `maxLat`, `maxLon` | Coordinates | Define map bounds (legacy format) |
   461→| `coloring` | safecast, chicha | Scientific gradient vs. safety bins |
   462→| `unit` | uSv, uR | Display units (microsieverts or microroentgen) |
   463→| `legend` | 1, 0 | Show/hide legend |
   464→| `lang` | en, ru, ja, etc. | Interface language |
   465→| `layer` | OpenStreetMap, Google Satellite | Base map |
   466→| `show` | rt | Filter to show only realtime sensors |
   467→
   468→**Location Examples:**
   469→- Direct to Tokyo: `/?place=Tokyo`
   470→- Coordinates with zoom: `/?lat=48.8566&lon=2.3522&zoom=13`
   471→- Share search result: `/?place=São%20Paulo` (auto-generated when searching)
   472→
   473→**Display Examples:**
   474→- Safety view: `/?coloring=chicha&unit=uR`
   475→- Clean embed: `/?legend=0`
   476→- Russian interface: `/?lang=ru`
   477→- Realtime sensors only: `/?show=rt`
   478→
   479→**Parameter Priority:** When loading URLs, `place` takes priority over `lat/lon`, which takes priority over bounds (`minLat/maxLat`).

   574→
   575→### PostgreSQL Sequence Reset
   576→
   577→After data migration or restore, you may encounter "duplicate key value violates unique constraint" errors. This happens when PostgreSQL sequences are out of sync with existing data.
   578→
   579→**Fix the markers sequence:**
   580→```bash
   581→psql -h 127.0.0.1 -U postgres -d safecast -c \
   582→  "SELECT setval('markers_id_seq', (SELECT MAX(id) FROM markers) + 1);"
   583→```
   584→
   585→**Fix all sequences at once:**
   586→```bash
   587→./tools/reset_postgres_sequences.sh
   588→```
   589→
   590→### Adding Missing Columns
   591→
   592→If you see errors like `column X does not exist`, the database schema may need updating:
   593→
   594→```bash
   595→psql -h 127.0.0.1 -U postgres -d safecast -c "
   596→  ALTER TABLE uploads ADD COLUMN IF NOT EXISTS recording_date TIMESTAMPTZ;
   597→  ALTER TABLE uploads ADD COLUMN IF NOT EXISTS detector TEXT;
   598→  ALTER TABLE uploads ADD COLUMN IF NOT EXISTS username TEXT;
   599→  ALTER TABLE uploads ADD COLUMN IF NOT EXISTS internal_user_id TEXT;
   600→"
   601→```

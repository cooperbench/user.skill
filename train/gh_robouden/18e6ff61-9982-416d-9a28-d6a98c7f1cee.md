## **3. WHAT THE PROJECT DOES**

### **Core Functionality**

The **AnyType Workspace Sync** service is a Go binary that:

1. **Watches a filesystem directory** (`/root/anytype-workspace/`) for file changes
2. **Syncs files to AnyType** using gRPC API calls
3. **Maintains object ID mapping** to enable delete operations
4. **Auto-renews authentication tokens** when they expire
5. **Supports multiple file types**: Markdown, images, PDFs, videos, audio
6. **Broadcasts globally** via P2P network to all connected devices

### **End-to-End Flow**

```
OpenClaw Bot writes file
   ↓
fsnotify detects change
   ↓
Parse file (markdown or binary)
   ↓
gRPC call to AnyType server (127.0.0.1:31010)
   ↓
Store object ID mapping
   ↓
P2P broadcast to all devices
   ↓
File appears in AnyType on all devices (2-10 seconds)
```

## **8. TECHNICAL ARCHITECTURE DETAILS**

### **Authentication Flow**
```
User creates bot account with anytype CLI
   ↓
Account key stored in ~/.anytype/config.json
   ↓
anytype serve -q starts and generates JWT session token
   ↓
Service reads token from config.json
   ↓
Service adds token to gRPC metadata on every request
   ↓
AnyType server validates token signature & expiry
```

### **Token Renewal (Automatic)**
When auth error detected:
1. Check rate limit (30s since last refresh)
2. If OK: Kill anytype process, wait 3s
3. Start new anytype serve, wait 8s
4. Read new token from config
5. Reconnect gRPC
6. Retry operation

### **File Processing Pipeline**
```
File detected by fsnotify
   ↓
Check file type (.md, .jpg, .pdf, etc.)
   ↓
Debounce 2 seconds (wait for more changes)
   ↓
If markdown:
   - Extract title (first # heading or filename)
   - Parse content into blocks with native styles
   - ObjectCreate RPC
   - BlockCreate RPC (for each line)
If binary:
   - Detect type from extension
   - FileUpload RPC
   ↓
Store object ID → filename mapping
   ↓
P2P broadcast (handled by AnyType server)
```

   313→## Troubleshooting
   314→
   315→### Authentication Errors
   316→
   317→**Symptom**: `not authenticated - check network membership`
   318→
   319→**Automatic Recovery**: The service now includes automatic token renewal! When an authentication error is detected:
   320→1. The service automatically restarts the AnyType server
   321→2. Waits for a fresh session token to be generated
   322→3. Reloads the new token from config
   323→4. Retries the failed operation
   324→
   325→You should see logs like:
   326→```
   327→⚠ Authentication error detected: not authenticated
   328→🔄 Attempting to refresh session token...
   329→  → Stopping anytype server...
   330→  → Starting anytype server...
   331→  → Waiting for server to initialize...
   332→  → Reading new session token...
   333→✓ Session token refreshed successfully
   334→🔁 Retrying operation with refreshed token...
   335→```
   336→
   337→**Manual Recovery** (if automatic fails):
   338→1. Restart AnyType server to refresh session token:
   339→   ```bash
   340→   pkill -f 'anytype serve'
   341→   nohup /root/.local/bin/anytype serve -q > /tmp/anytype-serve.log 2>&1 &
   342→   ```
   343→
   344→2. Restart workspace-sync:
   345→   ```bash
   346→   systemctl restart anytype-workspace-sync
   347→   ```
   348→
   349→**Rate Limiting**: Token refresh is rate-limited to once per 30 seconds to prevent rapid refresh loops.

   403→[2026-03-01T12:00:00Z] ✓ file synced to AnyType
   404→```
   405→
   406→**Levels**:
   407→- `✓` Success
   408→- `⚠` Warning (non-fatal)
   409→- `✗` Error (operation failed)
   410→- `→` Debug/Info
   411→
   412→**Destinations**:
   413→- Stdout → systemd journal
   414→- Journal → `journalctl -u anytype-workspace-sync`

   416→## Design Decisions
   417→
   418→### Why Filesystem-Based?
   419→
   420→**Pros**:
   421→- ✅ Simple interface (any tool can write files)
   422→- ✅ Version control friendly (git works)
   423→- ✅ No API learning curve
   424→- ✅ Observable (can see files)
   425→
   426→**Cons**:
   427→- ❌ Not real-time (2s debounce)
   428→- ❌ No conflict resolution
   429→- ❌ Filesystem limits apply
   430→
   431→**Alternative Considered**: Direct gRPC API
   432→- Rejected: Requires every client to understand AnyType protocol
   433→
   434→### Why Session Tokens?
   435→
   436→**Pros**:
   437→- ✅ No password in memory
   438→- ✅ Can be revoked
   439→- ✅ Time-limited
   440→
   441→**Cons**:
   442→- ❌ Expire quickly
   443→- ❌ Require server restart to refresh
   444→
   445→**Alternative Considered**: Account Key directly
   446→- Rejected: Security risk (long-lived credential)
   447→
   448→### Why Object Map?
   449→
   450→**Pros**:
   451→- ✅ Enables delete operations
   452→- ✅ Survives restarts
   453→- ✅ Simple JSON format
   454→
   455→**Cons**:
   456→- ❌ Can get out of sync
   457→- ❌ No garbage collection
   458→
   459→**Alternative Considered**: Query AnyType for object by name
   460→- Rejected: API doesn't support efficient name-based lookup
   461→
   462→### Why Go?
   463→
   464→**Pros**:
   465→- ✅ Static binary (easy deployment)
   466→- ✅ Good gRPC support
   467→- ✅ Cross-compilation
   468→- ✅ AnyType SDK in Go
   469→
   470→**Cons**:
   471→- ❌ Larger binary size (~10 MB)
   472→- ❌ GC overhead (minimal)
   473→
   474→**Alternative Considered**: Python
   475→- Rejected: Requires runtime, slower gRPC
   476→
   477→## Future Enhancements
   478→
   479→### 1. Token Refresh
   480→**Problem**: Session tokens expire
   481→**Solution**: Implement automatic refresh
   482→```go
   483→if resp.Error == "Unauthenticated" {
   484→    token := refreshToken(accountKey)
   485→    retry(request, token)
   486→}
   487→```
   488→
   489→### 2. Bidirectional Sync
   490→**Problem**: Changes in AnyType don't reflect in files
   491→**Solution**: Subscribe to space changes
   492→```go
   493→stream := client.ObjectSubscribe(spaceID)
   494→for change := range stream {
   495→    writeFile(change.ObjectId, change.Content)
   496→}
   497→```
   498→
   499→### 3. Conflict Resolution
   500→**Problem**: Simultaneous changes cause data loss
   501→**Solution**: Implement last-write-wins or merge
   502→```go
   503→if localModTime > remoteModTime {
   504→    pushToRemote()
   505→} else {
   506→    pullFromRemote()
   507→}
   508→```

   511→**Problem**: Hard to monitor service health
   512→**Solution**: HTTP health check
   513→```go
   514→http.HandleFunc("/health", func(w http.ResponseWriter, r *http.Request) {
   515→    if isHealthy() {

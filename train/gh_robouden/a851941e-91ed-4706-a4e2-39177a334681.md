   543→## Deployment
   544→
   545→Pushing to `main` automatically builds and deploys to the VPS via GitHub Actions (only when Go source files, `go.mod`/`go.sum`, or the workflow itself change).
   546→
   547→### How it works
   548→
   549→1. GitHub Action cross-compiles the Go binary
   550→2. Uploads it to the VPS via rsync
   551→3. Restarts the MCP server
   552→4. Runs a health check against the `/mcp-http` endpoint
   553→
   554→### Setting up secrets
   555→
   556→The GitHub Action requires three repository secrets. Go to **Settings** > **Secrets and variables** > **Actions** and add:
   557→
   558→| Secret | Description |
   559→|--------|-------------|
   560→| `SSH_PRIVATE_KEY` | SSH private key with access to the VPS (ed25519 format) |
   561→| `VPS_HOST` | VPS hostname (e.g. `vps-01.safecast.jp`) |
   562→| `DATABASE_URL` | PostgreSQL connection string |
   563→
   564→To generate a deploy key:
   565→
   566→```bash
   567→ssh-keygen -t ed25519 -C "github-deploy@safecast-mcp" -f ~/.ssh/safecast-deploy -N ""
   568→```
   569→
   570→Then add the public key to the VPS:
   571→
   572→```bash
   573→ssh-copy-id -i ~/.ssh/safecast-deploy.pub root@vps-01.safecast.jp
   574→```
   575→
   576→And paste the contents of `~/.ssh/safecast-deploy` (the private key) as the `SSH_PRIVATE_KEY` secret in GitHub.
   577→
   578→### Manual deploy

Yes, there is a one-liner CLI command to add HTTP MCP servers. Here is the exact syntax:

**Add an HTTP MCP server:**

```bash
claude mcp add --transport http <name> <url>
```

**Real examples:**

```bash
# Add a basic HTTP server
claude mcp add --transport http notion https://mcp.notion.com/mcp

# Add with a Bearer token header
claude mcp add --transport http my-api https://api.example.com/mcp \
  --header "Authorization: Bearer your-token"

# Add the Safecast MCP server (relevant to your project)
claude mcp add --transport http safecast https://your-vps-host/mcp-http
```

**Scope options** (where the config is saved):

```bash
# Local scope - only for you in this project (default)
claude mcp add --transport http my-server https://example.com/mcp

# Project scope - shared via .mcp.json (checked into git)
claude mcp add --transport http my-server --scope project https://example.com/mcp

# User scope - available across all your projects
claude mcp add --transport http my-server --scope user https://example.com/mcp
```

**Management commands:**

```bash
claude mcp list           # List all configured servers
claude mcp get <name>     # Get details for a specific server
claude mcp remove <name>  # Remove a server
```

**Add from JSON directly** (useful for scripting):

```bash
claude mcp add-json my-server '{"type":"http","url":"https://example.com/mcp","headers":{"Authorization":"Bearer token"}}'
```

All options (`--transport`, `--scope`, `--header`, `--env`) must come **before** the server name in the command.

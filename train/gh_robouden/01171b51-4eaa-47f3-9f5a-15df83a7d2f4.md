# DeepWiki Documentation Crawler - GitHub Action Guide

## Action Identification
**Name:** DeepWiki Documentation Crawler  
**Owner:** erayack  
**Path:** `erayack/deepwiki-action@v1`  
**Repository:** https://github.com/erayack/deepwiki-action

## Core Functionality
This action "automatically crawls and indexes repository documentation on DeepWiki," making project documentation searchable and accessible through concurrent processing with configurable retry logic.

## Input Parameters

| Input | Description | Required | Default |
|-------|-------------|----------|---------|
| `repository` | Identifier in owner/repo format, GitHub URL, or DeepWiki URL | No | `${{ github.repository }}` |
| `max_concurrency` | Number of concurrent crawl workers | No | `3` |
| `request_timeout` | HTTP request timeout in milliseconds | No | `30000` |
| `retry_attempts` | Number of retry attempts for failed requests | No | `3` |

## Output Parameters

| Output | Description |
|--------|-------------|
| `repo_exists` | Boolean indicating if repository exists on DeepWiki |
| `org_repo` | Extracted org/repo identifier |
| `deepwiki_url` | Generated DeepWiki URL for the repository |

## Example Workflow YAML

```yaml
name: Crawl DeepWiki Documentation

on:
  push:
    branches: [main]
  workflow_dispatch:

jobs:
  crawl-deepwiki:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4
        
      - name: Crawl DeepWiki Documentation
        uses: erayack/deepwiki-action@v1
        with:
          repository: ${{ github.repository }}
          max_concurrency: '3'
          request_timeout: '30000'
          retry_attempts: '3'
```

## Using Outputs

```yaml
- name: Crawl DeepWiki Documentation
  id: deepwiki
  uses: erayack/deepwiki-action@v1

- name: Check results
  run: |
    echo "Repository exists: ${{ steps.deepwiki.outputs.repo_exists }}"
    echo "DeepWiki URL: ${{ steps.deepwiki.outputs.deepwiki_url }}"
```

## Optional Configuration
Set repository variables for environment-level customization:
- `MAX_CONCURRENCY` (default: 3)
- `REQUEST_TIMEOUT` (default: 30000)
- `RETRY_ATTEMPTS` (default: 3)

## Output Artifacts
- `deepwiki-content.md` - Raw markdown documentation
- `index.html` - Formatted HTML documentation with styling
```

   564→Pushing to `main` automatically builds and deploys to **simplemap.safecast.org** (the map server) via GitHub Actions (only when Go source files, `go.mod`/`go.sum`, or the workflow itself change).
   565→
   566→> **Important**: The domain uses CloudFront CDN. SSH deployment must use the server IP (65.108.24.131), not the domain name. See [CloudFront Deployment Guide](docs/CLOUDFRONT_DEPLOYMENT.md) for details.
   567→
   568→> **Note**: The MCP server runs on the same server as the database for optimal performance (localhost connections eliminate network latency). See [MIGRATION_TO_MAP_SERVER.md](MIGRATION_TO_MAP_SERVER.md) for migration details.
   569→
   570→### How it works
   571→
   572→1. GitHub Action cross-compiles the Go binary
   573→2. Uploads it to the map server via rsync
   574→3. Creates `.env` file with localhost database connection
   575→4. Restarts the MCP server via systemd
   576→5. Configures Apache proxy for `/mcp-http`, `/docs/`, and `/api/` endpoints
   577→6. Runs a health check against the `/mcp-http` endpoint
   578→
   579→### Setting up secrets
   580→
   581→The GitHub Action requires two repository secrets. Go to **Settings** > **Secrets and variables** > **Actions** and add:
   582→
   583→| Secret | Description |
   584→|--------|-------------|
   585→| `SSH_PRIVATE_KEY` | SSH private key with access to the map server (ed25519 format) |
   586→| `MAP_SERVER_HOST` | Map server IP address: **`65.108.24.131`** (use IP, not domain) |
   587→
   588→**⚠️ CRITICAL:** Use the IP address `65.108.24.131` for `MAP_SERVER_HOST`, **not** `simplemap.safecast.org`. The domain uses CloudFront CDN which doesn't handle SSH traffic.
   589→
   590→To generate a deploy key:
   591→
   592→```bash
   593→ssh-keygen -t ed25519 -C "github-deploy-mcp@simplemap" -f ~/.ssh/safecast-mcp-deploy -N ""
   594→```
   595→
   596→Then add the public key to the map server (use IP address):
   597→
   598→```bash
   599→ssh-copy-id -i ~/.ssh/safecast-mcp-deploy.pub root@65.108.24.131
   600→```
   601→
   602→And paste the contents of `~/.ssh/safecast-mcp-deploy` (the private key) as the `SSH_PRIVATE_KEY` secret in GitHub.
   603→
   604→### Manual deploy
   605→
   606→**⚠️ IMPORTANT:** The domain `simplemap.safecast.org` uses CloudFront CDN, which only handles HTTP/HTTPS traffic. For SSH/SCP deployment, you **must use the server IP address** (65.108.24.131), not the domain name.

   609→cd go

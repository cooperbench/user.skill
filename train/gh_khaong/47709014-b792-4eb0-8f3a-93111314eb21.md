> DEVELOPER

what does core.hooksPath=/dev/null do in git?

> AGENT

It disables all git hooks by pointing the hooks directory to `/dev/null` (which isn't a directory, so git can't find any hooks there). Any configured hooks — `pre-commit`, `prepare-commit-msg`, `post-commit`, etc. — simply won't run. It's commonly passed as `-c core.hooksPath=/dev/null` to a single git command to skip hooks for just that invocation, without affecting the repo's config.

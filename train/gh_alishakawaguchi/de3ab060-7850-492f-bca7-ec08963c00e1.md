`★ Insight ─────────────────────────────────────`
**Cross-hook state via filesystem:** Kiro hooks fire as separate CLI invocations (no shared memory), so the session ID must be passed through a file (`kiro-active-session`). This creates a lifecycle contract: `agentSpawn` writes, `userPromptSubmit`/`stop` read, and `stop` must clean up. Without cleanup, the file outlives its session and silently poisons the next one — a classic temp-file lifecycle bug that's easy to miss because the "happy path" (agentSpawn always fires) masks it.

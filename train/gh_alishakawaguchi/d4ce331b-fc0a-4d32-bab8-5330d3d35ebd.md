You generate the token by running the device flow login from any machine: ```bash kiro-cli login --license free --use-device-flow ``` This will print a URL and a code. Open the URL in any browser, enter the code, and complete the sign-in (Builder ID, Google, or GitHub). Once authenticated, the token is written to: ``` ~/.aws/sso/cache/kiro-auth-token.json ``` Then copy that file's content as the GitHub secret value: ```bash cat ~/.aws/sso/cache/kiro-auth-token.json ``` That JSON (containing `accessToken`, `refreshToken`, `profileArn`, etc.) becomes the `KIRO_AUTH_TOKEN` secret. **Note:** The `accessToken` expires (check `expiresAt`), but the `refreshToken` is long-lived — kiro-cli uses it to automatically obtain new access tokens. The secret will need rotation if/when the refresh token expires.

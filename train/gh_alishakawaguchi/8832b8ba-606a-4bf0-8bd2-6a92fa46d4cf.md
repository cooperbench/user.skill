# Fix Factory AI Droid E2E Test Failures

## Context

Running `E2E_AGENT=factoryai-droid go test -tags=e2e ./cmd/entire/cli/e2e_test/...` produces 8 failures across 4 root causes. All tests pass with Claude Code but fail with Factory AI Droid because the Droid agent has different hook input behavior and missing method implementations.

## Root Cause Analysis

### RC1: `WriteSession`/`ReadSession` not implemented (1 test)
- **Test:** `TestE2E_ResumeInRelocatedRepo`
- **Error:** `"not implemented"` when resume tries to write session data to new location
- `factoryaidroid.go:132-139` returns stub errors

### RC2: `state.TranscriptPath` not set during carry-forward condensation (5 tests)
- **Tests:** `Scenario4_UserSplitsCommits`, `ExistingFiles_SplitCommits`, `DeletedFiles_CommitDeletion`, `EndedSession_UserCommitsAfterExit`, `Scenario7_PartialStagingSimulated`
- **Root cause:** `state.TranscriptPath` is set in `InitializeSession` (called from `user-prompt-submit` hook) via `event.SessionRef`. If Droid's `user-prompt-submit` hook input omits `transcript_path`, `state.TranscriptPath` stays empty. First commit works because it reads transcript from the shadow branch tree. Carry-forward commits fail because: (a) carry-forward shadow branch intentionally excludes transcript data, and (b) live transcript fallback in `extractSessionData` is skipped when `liveTranscriptPath == ""`.
- **SaveStep works fine** because it uses `StepContext.TranscriptPath` from the `stop` hook's `event.SessionRef` directly, NOT from `state.TranscriptPath`.
- `manual_commit.go` never writes to `state.TranscriptPath` — confirmed by grep showing zero matches.

### RC3: TTY blocking during agent-initiated commits (2 tests)
- **Tests:** `AgentCommitsDuringTurn`, `ExistingFiles_ModifyAndCommit` (both timeout at 120s)
- **Root cause:** When Droid makes a `git commit` during its session, the git `prepare-commit-msg` hook runs. This hook checks `hasTTY()` — since Droid inherits the user's terminal, `hasTTY()` returns true. The hook then calls `askConfirmTTY()` which opens `/dev/tty` and blocks waiting for user input. The 2-minute timeout kills the Droid process.
- `ENTIRE_TEST_TTY` is only set in `GitCommitWithShadowHooks` (test helper), not in the Droid runner's environment.

### RC4: Zero rewind points in Scenario7 (1 test — subset of RC2)
- `TestE2E_Scenario7_PartialStagingSimulated` shows 0 rewind points, meaning `SaveStep` was never called.
- If `event.SessionRef` is empty in the `stop` hook, `handleLifecycleTurnEnd` errors at line 168-169 (`"transcript file not specified"`) and returns before calling SaveStep.

## Plan

### Fix 1: Implement `ReadSession` and `WriteSession` for Factory AI Droid

**File:** `cmd/entire/cli/agent/factoryaidroid/factoryaidroid.go`

Mirror the Claude Code implementation (`cmd/entire/cli/agent/claudecode/claude.go:108-162`):

**ReadSession:**
1. Validate `input.SessionRef` is non-empty
2. `os.ReadFile(input.SessionRef)` to get raw JSONL bytes
3. Parse with `ParseDroidTranscriptFromBytes` to extract computed fields (ModifiedFiles)
4. Return `*agent.AgentSession` with NativeData, ModifiedFiles, etc.

**WriteSession:**
1. Validate session is non-nil, AgentName matches, SessionRef is non-empty, NativeData is non-empty
2. Create parent directories with `os.MkdirAll`
3. `os.WriteFile(session.SessionRef, session.NativeData, 0o600)`

### Fix 2: Propagate `TranscriptPath` to `state` during `SaveStep`

**File:** `cmd/entire/cli/strategy/manual_commit.go` (in `SaveStep` method)

After loading SessionState and before saving it, add:
```go
if state.TranscriptPath == "" && ctx.TranscriptPath != "" {
    state.TranscriptPath = ctx.TranscriptPath
}
```

This ensures `state.TranscriptPath` is set from the stop hook's transcript path if it wasn't set during the user-prompt-submit hook. This fixes carry-forward condensation because `extractSessionData` can then read the live transcript.

**Rationale:** SaveStep already receives `StepContext.TranscriptPath` from the stop hook's `event.SessionRef`. The session state is loaded and saved within SaveStep. This is the narrowest, safest change.

### Fix 3: Set `ENTIRE_TEST_TTY` in Droid runner environment

**File:** `cmd/entire/cli/e2e_test/agent_runner.go`

In `FactoryAIDroidRunner.RunPromptWithTools`, set environment variables on the `cmd`:
```go
cmd.Env = append(os.Environ(),
    "ENTIRE_TEST_TTY=0",  // Prevent TTY prompts in git hooks during agent session
)
```

Setting `ENTIRE_TEST_TTY=0` causes `hasTTY()` to return false, which triggers the fast-path in `PrepareCommitMsg` (line 291) that adds the trailer without prompting. This prevents the Droid process from hanging on TTY input.

### Fix 4: Add dynamic transcript resolution fallback in `extractSessionData`

**File:** `cmd/entire/cli/strategy/manual_commit_condensation.go` (in `extractSessionData`)

After the live transcript path check fails and before falling back to shadow branch, add a dynamic resolution step:
```go
if fullTranscript == "" && liveTranscriptPath == "" {
    // Dynamic fallback: compute transcript path from agent + repo path
    if ag, err := agent.GetByAgentType(agentType); err == nil {
        if repoRoot, pathErr := paths.RepoRoot(); pathErr == nil {
            if sessionDir, dirErr := ag.GetSessionDir(repoRoot); dirErr == nil {
                dynamicPath := ag.ResolveSessionFile(sessionDir, sessionID)
                if liveData, readErr := os.ReadFile(dynamicPath); readErr == nil && len(liveData) > 0 {
                    fullTranscript = string(liveData)
                }
            }
        }
    }
}
```

**Rationale:** This provides defense-in-depth. Even if Fix 2 doesn't cover all edge cases (e.g., session state corruption, agent bugs), the transcript can still be found dynamically.

**Note:** `extractSessionData` already takes `agentType` as parameter. `agent.GetByAgentType` resolves the agent. `GetSessionDir + ResolveSessionFile` computes the path. This mirrors how the resume command resolves transcript paths (resume.go line 476).

   196→	var summary *cpkg.Summary
   197→	if settings.IsSummarizeEnabled() && len(sessionData.Transcript) > 0 {
   198→		logCtx := logging.WithComponent(context.Background(), "attribution")
   199→		summarizeCtx := logging.WithComponent(logCtx, "summarize")
   200→
   201→		// Scope transcript to this checkpoint's portion.
   202→		// For Claude Code (JSONL), CheckpointTranscriptStart is a line offset.
   203→		// For Gemini (JSON), CheckpointTranscriptStart is a message index.
   204→		var scopedTranscript []byte
   205→		if state.AgentType == agent.AgentTypeGemini {
   206→			scopedTranscript = geminicli.SliceFromMessage(sessionData.Transcript, state.CheckpointTranscriptStart)
   207→		} else {
   208→			scopedTranscript = transcript.SliceFromLine(sessionData.Transcript, state.CheckpointTranscriptStart)
   209→		}
   210→		if len(scopedTranscript) > 0 {
   211→			var err error
   212→			summary, err = summarize.GenerateFromTranscript(summarizeCtx, scopedTranscript, sessionData.FilesTouched, state.AgentType, nil)
   213→			if err != nil {
   214→				logging.Warn(summarizeCtx, "summary generation failed",
   215→					slog.String("session_id", state.SessionID),
   216→					slog.String("error", err.Error()))
   217→				// Continue without summary - non-blocking
   218→			} else {
   219→				logging.Info(summarizeCtx, "summary generated",
   220→					slog.String("session_id", state.SessionID))
   221→			}
   222→		}
   223→	}
   224→
   225→	// Write checkpoint metadata using the checkpoint store
   226→	if err := store.WriteCommitted(context.Background(), cpkg.WriteCommittedOptions{
   227→		CheckpointID:                checkpointID,
   228→		SessionID:                   state.SessionID,
   229→		Strategy:                    StrategyNameManualCommit,
   230→		Branch:                      branchName,
   231→		Transcript:                  sessionData.Transcript,
   232→		Prompts:                     sessionData.Prompts,
   233→		Context:                     sessionData.Context,
   234→		FilesTouched:                sessionData.FilesTouched,
   235→		CheckpointsCount:            state.StepCount,
   236→		EphemeralBranch:             shadowBranchName,
   237→		AuthorName:                  authorName,
   238→		AuthorEmail:                 authorEmail,
   239→		Agent:                       state.AgentType,
   240→		TurnID:                      state.TurnID,
   241→		TranscriptIdentifierAtStart: state.TranscriptIdentifierAtStart,
   242→		CheckpointTranscriptStart:   state.CheckpointTranscriptStart,
   243→		TokenUsage:                  sessionData.TokenUsage,
   244→		ExportData:                  sessionData.ExportData,
   245→		InitialAttribution:          attribution,
   246→		Summary:                     summary,
   247→	}); err != nil {
   248→		return nil, fmt.Errorf("failed to write checkpoint metadata: %w", err)
   249→	}
   250→
   251→	return &CondenseResult{
   252→		CheckpointID:         checkpointID,
   253→		SessionID:            state.SessionID,
   254→		CheckpointsCount:     state.StepCount,
   255→		FilesTouched:         sessionData.FilesTouched,
   256→		TotalTranscriptLines: sessionData.FullTranscriptLines,
   257→	}, nil
   258→}

   260→func calculateSessionAttributions(repo *git.Repository, shadowRef *plumbing.Reference, sessionData *ExtractedSessionData, state *SessionState) *cpkg.InitialAttribution {
   261→	// Calculate initial attribution using accumulated prompt attribution data.
   262→	// This uses user edits captured at each prompt start (before agent works),
   263→	// plus any user edits after the final checkpoint (shadow → head).
   264→	//
   265→	// When shadowRef is nil (agent committed mid-turn before SaveStep),
   266→	// HEAD is used as the shadow tree. This is correct because the agent's
   267→	// commit IS HEAD — there are no user edits between agent work and commit.
   268→	logCtx := logging.WithComponent(context.Background(), "attribution")
   269→
   270→	headRef, headErr := repo.Head()
   271→	if headErr != nil {
   272→		logging.Debug(logCtx, "attribution skipped: failed to get HEAD",
   273→			slog.String("error", headErr.Error()))
   274→		return nil
   275→	}
   276→
   277→	headCommit, commitErr := repo.CommitObject(headRef.Hash())
   278→	if commitErr != nil {
   279→		logging.Debug(logCtx, "attribution skipped: failed to get HEAD commit",
   280→			slog.String("error", commitErr.Error()))
   281→		return nil
   282→	}
   283→
   284→	headTree, treeErr := headCommit.Tree()
   285→	if treeErr != nil {
   286→		logging.Debug(logCtx, "attribution skipped: failed to get HEAD tree",
   287→			slog.String("error", treeErr.Error()))
   288→		return nil
   289→	}
   290→
   291→	// Get shadow tree: from shadow branch if available, otherwise HEAD (agent committed directly).
   292→	var shadowTree *object.Tree
   293→	if shadowRef != nil {
   294→		shadowCommit, shadowErr := repo.CommitObject(shadowRef.Hash())
   295→		if shadowErr != nil {
   296→			logging.Debug(logCtx, "attribution skipped: failed to get shadow commit",
   297→				slog.String("error", shadowErr.Error()),
   298→				slog.String("shadow_ref", shadowRef.Hash().String()))
   299→			return nil
   300→		}
   301→		var shadowTreeErr error
   302→		shadowTree, shadowTreeErr = shadowCommit.Tree()
   303→		if shadowTreeErr != nil {
   304→			logging.Debug(logCtx, "attribution skipped: failed to get shadow tree",
   305→				slog.String("error", shadowTreeErr.Error()))
   306→			return nil
   307→		}
   308→	} else {
   309→		// No shadow branch: agent committed mid-turn. Use HEAD as shadow
   310→		// because the agent's work is the commit itself.
   311→		logging.Debug(logCtx, "attribution: using HEAD as shadow (no shadow branch)")
   312→		shadowTree = headTree
   313→	}
   314→
   315→	// Get base tree (state before session started)
   316→	var baseTree *object.Tree
   317→	attrBase := state.AttributionBaseCommit
   318→	if attrBase == "" {
   319→		attrBase = state.BaseCommit // backward compat
   320→	}
   321→	if baseCommit, baseErr := repo.CommitObject(plumbing.NewHash(attrBase)); baseErr == nil {
   322→		if tree, baseTErr := baseCommit.Tree(); baseTErr == nil {
   323→			baseTree = tree
   324→		} else {
   325→			logging.Debug(logCtx, "attribution: base tree unavailable",
   326→				slog.String("error", baseTErr.Error()))
   327→		}
   328→	} else {
   329→		logging.Debug(logCtx, "attribution: base commit unavailable",
   330→			slog.String("error", baseErr.Error()),
   331→			slog.String("attribution_base", attrBase))
   332→	}
   333→
   334→	// Log accumulated prompt attributions for debugging
   335→	var totalUserAdded, totalUserRemoved int
   336→	for i, pa := range state.PromptAttributions {
   337→		totalUserAdded += pa.UserLinesAdded
   338→		totalUserRemoved += pa.UserLinesRemoved
   339→		logging.Debug(logCtx, "prompt attribution data",
   340→			slog.Int("checkpoint", pa.CheckpointNumber),
   341→			slog.Int("user_added", pa.UserLinesAdded),
   342→			slog.Int("user_removed", pa.UserLinesRemoved),
   343→			slog.Int("agent_added", pa.AgentLinesAdded),
   344→			slog.Int("agent_removed", pa.AgentLinesRemoved),
   345→			slog.Int("index", i))
   346→	}
   347→
   348→	attribution := CalculateAttributionWithAccumulated(
   349→		baseTree,
   350→		shadowTree,
   351→		headTree,
   352→		sessionData.FilesTouched,
   353→		state.PromptAttributions,
   354→	)
   355→
   356→	if attribution != nil {
   357→		logging.Info(logCtx, "attribution calculated",
   358→			slog.Int("agent_lines", attribution.AgentLines),
   359→			slog.Int("human_added", attribution.HumanAdded),
   360→			slog.Int("human_modified", attribution.HumanModified),
   361→			slog.Int("human_removed", attribution.HumanRemoved),
   362→			slog.Int("total_committed", attribution.TotalCommitted),
   363→			slog.Float64("agent_percentage", attribution.AgentPercentage),
   364→			slog.Int("accumulated_user_added", totalUserAdded),
   365→			slog.Int("accumulated_user_removed", totalUserRemoved),
   366→			slog.Int("files_touched", len(sessionData.FilesTouched)))
   367→	}
   368→
   369→	return attribution
   370→}

   372→// extractSessionData extracts session data from the shadow branch.
   373→// filesTouched is the list of files tracked during the session (from SessionState.FilesTouched).
   374→// agentType identifies the agent (e.g., "Gemini CLI", "Claude Code") to determine transcript format.
   375→// liveTranscriptPath, when non-empty and readable, is preferred over the shadow branch copy.
   376→// This handles the case where SaveStep was skipped (no code changes) but the transcript
   377→// continued growing — the shadow branch copy would be stale.
   378→// checkpointTranscriptStart is the line offset (Claude) or message index (Gemini) where the current checkpoint began.
   379→func (s *ManualCommitStrategy) extractSessionData(repo *git.Repository, shadowRef plumbing.Hash, sessionID string, filesTouched []string, agentType agent.AgentType, liveTranscriptPath string, checkpointTranscriptStart int) (*ExtractedSessionData, error) {
   380→	commit, err := repo.CommitObject(shadowRef)
   381→	if err != nil {
   382→		return nil, fmt.Errorf("failed to get commit object: %w", err)
   383→	}
   384→
   385→	tree, err := commit.Tree()
   386→	if err != nil {
   387→		return nil, fmt.Errorf("failed to get commit tree: %w", err)
   388→	}
   389→
   390→	data := &ExtractedSessionData{}
   391→	// sessionID is already an "entire session ID" (with date prefix)
   392→	metadataDir := paths.SessionMetadataDirFromSessionID(sessionID)
   393→
   394→	// Extract transcript — prefer the live file when available, fall back to shadow branch.
   395→	// The shadow branch copy may be stale if the last turn ended without code changes
   396→	// (SaveStep is only called when there are file modifications).
   397→	var fullTranscript string
   398→	if liveTranscriptPath != "" {
   399→		if liveData, readErr := os.ReadFile(liveTranscriptPath); readErr == nil && len(liveData) > 0 { //nolint:gosec // path from session state
   400→			fullTranscript = string(liveData)
   401→		}
   402→	}
   403→	if fullTranscript == "" {
   404→		// Fall back to shadow branch copy
   405→		if file, fileErr := tree.File(metadataDir + "/" + paths.TranscriptFileName); fileErr == nil {
   406→			if content, contentErr := file.Contents(); contentErr == nil {
   407→				fullTranscript = content
   408→			}
   409→		} else if file, fileErr := tree.File(metadataDir + "/" + paths.TranscriptFileNameLegacy); fileErr == nil {
   410→			if content, contentErr := file.Contents(); contentErr == nil {
   411→				fullTranscript = content
   412→			}
   413→		}
   414→	}
   415→
   416→	// Process transcript based on agent type
   417→	if fullTranscript != "" {
   418→		data.Transcript = []byte(fullTranscript)
   419→		data.FullTranscriptLines = countTranscriptItems(agentType, fullTranscript)
   420→		data.Prompts = extractUserPrompts(agentType, fullTranscript)
   421→		data.Context = generateContextFromPrompts(data.Prompts)
   422→	}
   423→
   424→	// Use tracked files from session state (not all files in tree)
   425→	data.FilesTouched = filesTouched
   426→
   427→	// Read export data from local metadata directory (e.g., OpenCode SQLite export).
   428→	// This is written by lifecycle.go during TurnEnd and must be stored in the
   429→	// committed checkpoint so resume/rewind can re-import the session.
   430→	exportRelPath := metadataDir + "/" + paths.ExportDataFileName
   431→	if exportAbsPath, absErr := paths.AbsPath(exportRelPath); absErr == nil {
   432→		if exportBytes, readErr := os.ReadFile(exportAbsPath); readErr == nil && len(exportBytes) > 0 { //nolint:gosec // path from session metadata
   433→			data.ExportData = exportBytes
   434→		}
   435→	}
   436→
   437→	// Calculate token usage from the extracted transcript portion
   438→	if len(data.Transcript) > 0 {
   439→		data.TokenUsage = calculateTokenUsage(agentType, data.Transcript, checkpointTranscriptStart)
   440→	}
   441→
   442→	return data, nil
   443→}

   445→// extractSessionDataFromLiveTranscript extracts session data directly from the live transcript file.
   446→// This is used for mid-session commits where no shadow branch exists yet.
   447→func (s *ManualCommitStrategy) extractSessionDataFromLiveTranscript(state *SessionState) (*ExtractedSessionData, error) {
   448→	data := &ExtractedSessionData{}
   449→
   450→	// Read the live transcript
   451→	if state.TranscriptPath == "" {
   452→		return nil, errors.New("no transcript path in session state")
   453→	}
   454→
   455→	liveData, err := os.ReadFile(state.TranscriptPath)
   456→	if err != nil {
   457→		return nil, fmt.Errorf("failed to read live transcript: %w", err)
   458→	}
   459→
   460→	if len(liveData) == 0 {
   461→		return nil, errors.New("live transcript is empty")
   462→	}
   463→
   464→	fullTranscript := string(liveData)
   465→	data.Transcript = liveData
   466→	data.FullTranscriptLines = countTranscriptItems(state.AgentType, fullTranscript)
   467→	data.Prompts = extractUserPrompts(state.AgentType, fullTranscript)
   468→	data.Context = generateContextFromPrompts(data.Prompts)
   469→
   470→	// Extract files from transcript since state.FilesTouched may be empty for mid-session commits
   471→	// (no SaveStep/Stop has been called yet to populate it)
   472→	if len(state.FilesTouched) > 0 {
   473→		data.FilesTouched = state.FilesTouched
   474→	} else {
   475→		// Use the shared helper which includes subagent transcripts
   476→		data.FilesTouched = s.extractModifiedFilesFromLiveTranscript(state, state.CheckpointTranscriptStart)
   477→	}
   478→
   479→	// Read export data from local metadata directory
   480→	metadataDir := paths.SessionMetadataDirFromSessionID(state.SessionID)
   481→	exportRelPath := metadataDir + "/" + paths.ExportDataFileName
   482→	if exportAbsPath, absErr := paths.AbsPath(exportRelPath); absErr == nil {
   483→		if exportBytes, readErr := os.ReadFile(exportAbsPath); readErr == nil && len(exportBytes) > 0 { //nolint:gosec // path from session metadata
   484→			data.ExportData = exportBytes
   485→		}
   486→	}
   487→
   488→	// Calculate token usage from the extracted transcript portion
   489→	if len(data.Transcript) > 0 {
   490→		data.TokenUsage = calculateTokenUsage(state.AgentType, data.Transcript, state.CheckpointTranscriptStart)
   491→	}
   492→
   493→	return data, nil
   494→}

   496→// countTranscriptItems counts lines (JSONL) or messages (JSON) in a transcript.
   497→// For Claude Code and JSONL-based agents, this counts lines.
   498→// For Gemini CLI and JSON-based agents, this counts messages.
   499→// Returns 0 if the content is empty or malformed.
   500→func countTranscriptItems(agentType agent.AgentType, content string) int {
   501→	if content == "" {
   502→		return 0
   503→	}
   504→
   505→	// Try Gemini format first if agentType is Gemini, or as fallback if Unknown
   506→	if agentType == agent.AgentTypeGemini || agentType == agent.AgentTypeUnknown {
   507→		transcript, err := geminicli.ParseTranscript([]byte(content))
   508→		if err == nil && transcript != nil && len(transcript.Messages) > 0 {
   509→			return len(transcript.Messages)
   510→		}
   511→		// If agentType is explicitly Gemini but parsing failed, return 0
   512→		if agentType == agent.AgentTypeGemini {
   513→			return 0
   514→		}
   515→		// Otherwise fall through to JSONL parsing for Unknown type
   516→	}
   517→
   518→	// Claude Code and other JSONL-based agents
   519→	allLines := strings.Split(content, "\n")
   520→	// Trim trailing empty lines (from final \n in JSONL)
   521→	for len(allLines) > 0 && strings.TrimSpace(allLines[len(allLines)-1]) == "" {
   522→		allLines = allLines[:len(allLines)-1]
   523→	}
   524→	return len(allLines)
   525→}

   527→// extractUserPrompts extracts all user prompts from transcript content.
   528→// Returns prompts with IDE context tags stripped (e.g., <ide_opened_file>).
   529→func extractUserPrompts(agentType agent.AgentType, content string) []string {
   530→	if content == "" {
   531→		return nil
   532→	}
   533→
   534→	// Droid has its own envelope format — use its parser to normalize first
   535→	if agentType == agent.AgentTypeFactoryAIDroid {
   536→		lines, err := factoryaidroid.ParseDroidTranscriptFromBytes([]byte(content))
   537→		if err != nil {
   538→			return nil
   539→		}
   540→		var prompts []string
   541→		for _, line := range lines {
   542→			if line.Type != transcript.TypeUser {
   543→				continue
   544→			}
   545→			if text := transcript.ExtractUserContent(line.Message); text != "" {
   546→				if stripped := textutil.StripIDEContextTags(text); stripped != "" {
   547→					prompts = append(prompts, stripped)
   548→				}
   549→			}
   550→		}
   551→		return prompts
   552→	}
   553→
   554→	// OpenCode uses JSONL with a different per-line schema than Claude Code
   555→	if agentType == agent.AgentTypeOpenCode {
   556→		prompts, err := opencode.ExtractAllUserPrompts([]byte(content))
   557→		if err == nil && len(prompts) > 0 {
   558→			cleaned := make([]string, 0, len(prompts))
   559→			for _, prompt := range prompts {
   560→				if stripped := textutil.StripIDEContextTags(prompt); stripped != "" {
   561→					cleaned = append(cleaned, stripped)
   562→				}
   563→			}
   564→			return cleaned
   565→		}
   566→		return nil
   567→	}
   568→
   569→	// Try Gemini format first if agentType is Gemini, or as fallback if Unknown
   570→	if agentType == agent.AgentTypeGemini || agentType == agent.AgentTypeUnknown {
   571→		prompts, err := geminicli.ExtractAllUserPrompts([]byte(content))
   572→		if err == nil && len(prompts) > 0 {
   573→			// Strip IDE context tags for consistency with Claude Code handling
   574→			cleaned := make([]string, 0, len(prompts))
   575→			for _, prompt := range prompts {
   576→				if stripped := textutil.StripIDEContextTags(prompt); stripped != "" {
   577→					cleaned = append(cleaned, stripped)
   578→				}
   579→			}
   580→			return cleaned
   581→		}
   582→		// If agentType is explicitly Gemini but parsing failed, return nil
   583→		if agentType == agent.AgentTypeGemini {
   584→			return nil
   585→		}
   586→		// Otherwise fall through to JSONL parsing for Unknown type
   587→	}
   588→
   589→	// Claude Code and other JSONL-based agents
   590→	return extractUserPromptsFromLines(strings.Split(content, "\n"))
   591→}

   593→// calculateTokenUsage calculates token usage from raw transcript data.
   594→// startOffset is the line number (Claude Code) or message index (Gemini CLI)
   595→// where the current checkpoint began, allowing calculation for only the portion
   596→// of the transcript since the last checkpoint.
   597→func calculateTokenUsage(agentType agent.AgentType, data []byte, startOffset int) *agent.TokenUsage {
   598→	if len(data) == 0 {
   599→		return &agent.TokenUsage{}
   600→	}
   601→
   602→	// Droid has its own envelope format — use its parser to normalize first
   603→	if agentType == agent.AgentTypeFactoryAIDroid {
   604→		lines, err := factoryaidroid.ParseDroidTranscriptFromBytes(data)
   605→		if err != nil || len(lines) == 0 {
   606→			return &agent.TokenUsage{}
   607→		}
   608→		if startOffset > 0 && startOffset < len(lines) {
   609→			lines = lines[startOffset:]
   610→		}
   611→		return factoryaidroid.CalculateTokenUsage(lines)
   612→	}
   613→	// OpenCode uses JSONL with token info on assistant messages (different schema from Claude Code)
   614→	if agentType == agent.AgentTypeOpenCode {
   615→		return opencode.CalculateTokenUsageFromBytes(data, startOffset)
   616→	}
   617→
   618→	// Try Gemini format first if agentType is Gemini, or as fallback if Unknown
   619→	if agentType == agent.AgentTypeGemini || agentType == agent.AgentTypeUnknown {
   620→		// Attempt to parse as Gemini JSON
   621→		transcript, err := geminicli.ParseTranscript(data)
   622→		if err == nil && transcript != nil && len(transcript.Messages) > 0 {
   623→			return geminicli.CalculateTokenUsage(data, startOffset)
   624→		}
   625→		// If agentType is explicitly Gemini but parsing failed, return empty usage
   626→		if agentType == agent.AgentTypeGemini {
   627→			return &agent.TokenUsage{}
   628→		}
   629→		// Otherwise fall through to JSONL parsing for Unknown type
   630→	}
   631→
   632→	// Claude Code and other JSONL-based agents
   633→	lines, err := transcript.ParseFromBytes(data)
   634→	if err != nil || len(lines) == 0 {
   635→		return &agent.TokenUsage{}
   636→	}
   637→	// Slice transcript lines to only include checkpoint portion
   638→	if startOffset > 0 && startOffset < len(lines) {
   639→		lines = lines[startOffset:]
   640→	}
   641→	return claudecode.CalculateTokenUsage(lines)
   642→}

   644→// extractUserPromptsFromLines extracts user prompts from JSONL transcript lines.
   645→// IDE-injected context tags (like <ide_opened_file>) are stripped from the results.
   646→func extractUserPromptsFromLines(lines []string) []string {
   647→	var prompts []string
   648→	for _, line := range lines {
   649→		line = strings.TrimSpace(line)
   650→		if line == "" {
   651→			continue
   652→		}
   653→
   654→		var entry map[string]interface{}
   655→		if err := json.Unmarshal([]byte(line), &entry); err != nil {
   656→			continue
   657→		}
   658→
   659→		// Check for user message (supports both "human" and "user" types)
   660→		msgType, ok := entry["type"].(string)
   661→		if !ok || (msgType != "human" && msgType != "user") {
   662→			continue
   663→		}
   664→
   665→		// Extract message content
   666→		message, ok := entry["message"].(map[string]interface{})
   667→		if !ok {
   668→			continue
   669→		}
   670→
   671→		// Handle string content
   672→		if content, ok := message["content"].(string); ok && content != "" {
   673→			cleaned := textutil.StripIDEContextTags(content)
   674→			if cleaned != "" {
   675→				prompts = append(prompts, cleaned)
   676→			}
   677→			continue
   678→		}
   679→
   680→		// Handle array content (e.g., multiple text blocks from VSCode)
   681→		if arr, ok := message["content"].([]interface{}); ok {
   682→			var texts []string
   683→			for _, item := range arr {
   684→				if m, ok := item.(map[string]interface{}); ok {
   685→					if m["type"] == "text" {
   686→						if text, ok := m["text"].(string); ok {
   687→							texts = append(texts, text)
   688→						}
   689→					}
   690→				}
   691→			}
   692→			if len(texts) > 0 {
   693→				cleaned := textutil.StripIDEContextTags(strings.Join(texts, "\n\n"))
   694→				if cleaned != "" {
   695→					prompts = append(prompts, cleaned)
   696→				}
   697→			}
   698→		}
   699→	}
   700→	return prompts
   701→}

   703→// generateContextFromPrompts generates context.md content from a list of prompts.
   704→func generateContextFromPrompts(prompts []string) []byte {
   705→	if len(prompts) == 0 {
   706→		return nil
   707→	}
   708→
   709→	var buf strings.Builder
   710→	buf.WriteString("# Session Context\n\n")
   711→	buf.WriteString("## User Prompts\n\n")
   712→
   713→	for i, prompt := range prompts {
   714→		// Truncate very long prompts for readability
   715→		displayPrompt := prompt
   716→		if len(displayPrompt) > 500 {

   293→// mergeFilesTouched merges multiple file lists into existing touched files, deduplicating.
   294→func mergeFilesTouched(existing []string, fileLists ...[]string) []string {
   295→	seen := make(map[string]bool)
   296→	for _, f := range existing {
   297→		seen[f] = true
   298→	}
   299→
   300→	for _, list := range fileLists {
   301→		for _, f := range list {
   302→			seen[f] = true
   303→		}
   304→	}
   305→
   306→	result := make([]string, 0, len(seen))
   307→	for f := range seen {
   308→		result = append(result, f)
   309→	}
   310→
   311→	// Sort for deterministic output
   312→	sort.Strings(result)
   313→	return result

   685→// GetLatestCheckpointIDFromHistory walks backwards from HEAD and returns
   686→// the checkpoint ID from the first commit with an Entire-Checkpoint trailer.
   687→// Returns an error if no checkpoint trailer is found in any commit.
   688→func (env *TestEnv) GetLatestCheckpointIDFromHistory() (string, error) {
   689→	env.T.Helper()
   690→
   691→	repo, err := git.PlainOpen(env.RepoDir)
   692→	if err != nil {
   693→		env.T.Fatalf("failed to open git repo: %v", err)
   694→	}
   695→
   696→	head, err := repo.Head()
   697→	if err != nil {
   698→		env.T.Fatalf("failed to get HEAD: %v", err)
   699→	}
   700→
   701→	commitIter, err := repo.Log(&git.LogOptions{From: head.Hash()})
   702→	if err != nil {
   703→		env.T.Fatalf("failed to iterate commits: %v", err)
   704→	}
   705→
   706→	var checkpointID string
   707→	//nolint:errcheck,gosec // ForEach callback returns error to stop iteration, not a real error
   708→	commitIter.ForEach(func(c *object.Commit) error {
   709→		// Look for Entire-Checkpoint trailer
   710→		for _, line := range strings.Split(c.Message, "\n") {
   711→			line = strings.TrimSpace(line)
   712→			if strings.HasPrefix(line, "Entire-Checkpoint:") {
   713→				checkpointID = strings.TrimSpace(strings.TrimPrefix(line, "Entire-Checkpoint:"))
   714→				return errors.New("stop iteration")
   715→			}
   716→		}
   717→		return nil
   718→	})
   719→
   720→	if checkpointID == "" {
   721→		return "", errors.New("no commit with Entire-Checkpoint trailer found in history")
   722→	}
   723→
   724→	return checkpointID, nil
   725→}

`★ Insight ─────────────────────────────────────` **ForEachAgent pattern:** The key architectural insight is that `ForEachAgent` wraps each test in a per-agent subtest with its own `SetupRepo`, concurrency gating via channels, and timeout scaling. The panic/recover mechanism for transient errors (`errScenarioRestart`) is clever — it allows test functions to remain simple (no special return types) while the framework handles retry logic transparently with fresh repos. **Artifact capture strategy:** Artifacts are written eagerly (console.log starts at repo setup) and captured fully at test cleanup. This means even tests killed by global timeouts leave partial artifacts. The `skipArtifacts` flag on `RepoState` prevents stale artifacts from overwriting the final attempt's output during scenario restarts. **Import discipline:** The three sub-packages form a strict DAG: `agents/` → stdlib only, `entire/` → stdlib only, `testutil/` → `agents/` + `entire/`.

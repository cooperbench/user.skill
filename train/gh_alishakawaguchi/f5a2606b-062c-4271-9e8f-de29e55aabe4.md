# Plan: Remove Plugin Layer, Zero-Setup for All AI Tools

## Context

The `entire-external-agent` plugin requires setup for every AI tool (Claude Code needs settings.json config, Codex/OpenCode need symlinks, Cursor needs a plugin manifest). Meanwhile, the `.claude/skills/` directory already provides the `entire-external-agent:{subcommand}` format in Claude Code with **zero setup**. The plugin layer is redundant — we should remove it and use each tool's native project-level auto-discovery instead.

## Architecture: Before → After

```
BEFORE (requires setup for every tool):
  .claude/plugins/entire-external-agent/     ← plugin layer (redundant)
  .claude/skills/entire-external-agent/      ← actual procedures
  .claude/settings.json                      ← plugin marketplace + hooks
  .codex/INSTALL.md                          ← manual symlink instructions
  .opencode/plugins/entire-external-agent.js ← requires ~/.config symlinks
  .opencode/INSTALL.md                       ← manual symlink instructions
  .cursor-plugin/plugin.json                 ← references plugin paths

AFTER (zero setup for all tools):
  .claude/skills/entire-external-agent/      ← source of truth (unchanged)
  .claude/settings.json                      ← hooks + permissions only (no plugin config)
  AGENTS.md                                  ← Codex auto-discovers from project root
  .cursor/rules/entire-external-agent.mdc    ← Cursor auto-discovers from project root
  .opencode/plugins/entire-external-agent.js ← rewritten: project-relative paths, no symlinks
```

# Agent Integration Skill

A three-command toolkit that takes a new AI coding agent from unknown to fully integrated with the Entire CLI. Each command builds on the previous command's output.

## Commands

### `/agent-integration research`
**Assess compatibility.** Inspect the target agent's CLI, research hook/lifecycle support, create a test script, capture payloads, and produce a structured compatibility report.

Detailed instructions: [researcher.md](./researcher.md)

### `/agent-integration write-tests`
**Write the E2E test suite.** Using the research report's findings, generate E2E test files that validate the agent works end-to-end with Entire's checkpoint/rewind system.

Detailed instructions: [test-writer.md](./test-writer.md)

### `/agent-integration implement`
**Build the agent package via TDD.** Using the research report and E2E tests as the spec, implement the Go agent package with a red-green-refactor cycle.

Detailed instructions: [implementer.md](./implementer.md)

## The `*` next to `/agent-integration`

The `*` indicates the skill accepts **arguments** (the space-separated subcommands like `research`, `write-tests`, `implement`). Skills without arguments don't get the `*`.

## The `:` pattern is a **plugin** feature, not a skill feature

Looking at how `commit-commands:commit`, `ralph-loop:help`, etc. work — they're all **plugins**, not local skills:

```
# Plugin structure (gets colon namespace)
~/.claude/plugins/cache/.../commit-commands/
  commands/
    commit.md          → /commit-commands:commit
    commit-push-pr.md  → /commit-commands:commit-push-pr
    clean_gone.md      → /commit-commands:clean_gone

~/.claude/plugins/cache/.../ralph-loop/
  commands/
    help.md            → /ralph-loop:help
    cancel-ralph.md    → /ralph-loop:cancel-ralph
    ralph-loop.md      → /ralph-loop:ralph-loop
```

Each `.md` file in the `commands/` directory becomes a `plugin-name:command-name` entry. Local skills in `.claude/skills/` **cannot** use the colon pattern.

> DEVELOPER

what does it mean by entropy collapse

> AGENT

In MoE routing, the router outputs a probability distribution over K experts for each input. **Entropy** measures how spread out that distribution is: - **Max entropy** (log 5 = 1.609 for K=5): equal probability to all experts — healthy, diverse routing - **Zero entropy** (0.000): 100% probability to one expert — every single input goes to the same expert **Entropy collapse** means the router learns to send all inputs to one expert regardless of what the input looks like. The other 4 experts are dead weight — never activated. This defeats the purpose of having multiple experts. **Why it happens here:** RevIN normalizes every input window to mean=0, variance=1 before the encoder. So by the time the hidden states reach the router, all windows look nearly identical. The router can't distinguish a quiet baseline from a volatile spike, so it defaults to one expert. Gradient co-adaptation then locks this in — the dominant expert gets more gradient, improves faster, gets even more traffic, and within ~50 steps the collapse is irreversible. The paper's key insight: this isn't a training problem (no optimizer trick fixes it across 720 runs) — it's an information problem. The signal the router needs was destroyed before it ever saw it.

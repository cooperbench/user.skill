Let me reason through this carefully. The diagnostic evidence tells us exactly where the information is lost:

**Root cause chain:**
- RevIN strips μ, σ → loses trend/amplitude (confirmed: ρ=-0.96)
- Patching compresses 512 → 64 tokens (8× temporal resolution loss)
- Encoding abstracts away fine-grained patterns
- k-NN on backbone features is 16-33% worse than on raw input
- RF on backbone adds 0.02% complementary signal — backbone has **zero** useful nonlinear information beyond what raw input provides

**The fundamental tension:** The router operates on information-rich raw input (makes great routing decisions), but the experts operate on information-poor hidden states (can't forecast well even with perfect routing). The gap is at the expert input, not the routing.

Here are four architecturally distinct directions, ordered by novelty:

---

### Direction 1: Dual-Stream Experts (most novel)

```
Expert_k(H, X_raw) = α_k · Adapter_k(H) + (1-α_k) · Linear_k(X_raw)
```

Each expert has TWO branches: a backbone branch (existing adapter on H) and a raw branch (linear on X_raw). A learned per-expert scalar α_k controls the blend. The router still operates on raw input (RR-MoA routing unchanged).

**Why it closes the gap:** If α_k → 0, each expert degenerates to DLinear. With routing, it becomes a Mixture of DLinears — which should be ≥ DLinear since routing enables per-sample specialization. If α_k > 0, the backbone adds value where it has complementary information (e.g., cross-channel structure in Weather/Electricity).

**What's novel:** No prior work has given MoE adapter experts dual-stream access to both pre- and post-normalization features. This is the architectural operationalization of the paper's own diagnosis — if normalization destroys information, let the expert recover it.

**Risk:** Backbone may become irrelevant (all α → 0). But this is empirically testable and actually validates the diagnosis further.

---

### Direction 2: Statistics Re-Injection into Hidden States

```
μ, σ = mean(X_raw), std(X_raw)
H' = H + MLP([μ, σ]) ⊗ H    # channel-wise modulation (FiLM-style)
Y = Σ w_k · Expert_k(H')
```

Before experts process H, re-inject the statistics RevIN stripped using FiLM conditioning (Feature-wise Linear Modulation). The MLP maps (μ, σ) to scale-and-shift parameters that modulate each hidden dimension. This is like DishTS but applied at the adapter input, not inside the backbone.

**Why it closes the gap:** The diagnostic shows backbone features plus raw statistics ≈ raw input for forecasting. If we restore (μ, σ) to H, the experts get back the location-scale information while keeping the backbone's semantic structure.

**What's novel:** DishTS re-injects into the backbone's attention layers. We re-inject at the adapter input level on a frozen backbone — no backbone modification needed. This maintains the frozen paradigm while recovering lost information.

**Connection to paper's theory:** Proposition 2 says I(X;E) - I(S;E) ≥ I(M,Σ;E). This architecture directly adds I(M,Σ) back into the expert's input.

---

### Direction 3: Raw-Input Expert in the Pool

```
Expert_1...5: Adapter_k(H)       # existing pooling experts
Expert_6: Linear(X_raw → H)     # raw-input expert (bypass backbone)
Router: G(X_raw) → w ∈ Δ^6       # routes across all 6
```

Add a 6th expert that operates on raw input directly, bypassing the backbone. The router decides per-sample whether to use a backbone-based expert or the raw-input expert.

**Why it closes the gap:** On "easy" windows (stationary, linear dynamics), Expert_6 gets high routing weight ≈ DLinear performance. On "hard" windows (nonstationary, regime changes), backbone experts get higher weight where semantic features help. Overall MSE should be ≤ DLinear because it's a strict superset of DLinear's capability.

**What's novel:** Per-sample decision between foundation model adaptation and from-scratch forecasting via learned routing. This is the first architecture that lets the model itself decide when the backbone helps vs hurts — making the DLinear gap an empirical question answered per-window, not per-dataset.

**Risk:** Least novel of the four (essentially "add DLinear as an expert"). But highest probability of closing the gap.

---

### Direction 4: Multi-Resolution Feature Tapping

```
Features = [
    Proj_raw(X_raw),           # full resolution (B, 512)
    Proj_patch(pre_enc_patches), # post-patch, pre-encoding (B, 64, patch_size)  
    H                           # post-encoding (B, 64, 512)
]
Expert_k(concat(Features)) → forecast
```

Tap features at three stages of the backbone pipeline: pre-RevIN, post-patching, and post-encoding. Each expert sees all abstraction levels via a concatenated representation.

**Why it closes the gap:** The raw-resolution features provide the fine-grained patterns DLinear uses. The patch-level features provide intermediate abstractions. The backbone features provide semantic context. The adapter learns which level matters for each forecast dimension.

**What's novel:** Multi-scale feature tapping for frozen backbone adaptation. Analogous to FPN (Feature Pyramid Networks) in vision, but applied to the temporal dimension of TSFMs.

**Feasibility concern:** Requires hooking into MOMENT's internals at the post-patch stage, which needs architecture-specific code.

---

### My recommendation

**Direction 1 (Dual-Stream) or Direction 3 (Raw Expert)** are the most promising:

- **Direction 3** has the highest probability of closing the gap (it literally includes DLinear's capability) and is simplest to implement (~20 lines of code change to add a 6th expert class). But it's the least novel.

- **Direction 1** is more architecturally interesting and could produce a finding like "α_k varies from 0.1 (ETTh1, backbone unhelpful) to 0.7 (Weather/Electricity, backbone helpful)" — showing that the backbone's value is dataset-dependent and automatically discovered. This is a stronger contribution.

- **Direction 2** is the cleanest connection to existing theory (DishTS, Proposition 2) but may not fully close the gap since it only restores (μ, σ), not the full raw temporal structure.

# NeurIPS 2026 Main Track Handbook Summary

## Submission Steps in OpenReview

Authors must establish OpenReview profiles before the submission deadline with current affiliations and publications. The platform handles all submissions, with emails sent from noreply@openreview.net. Institutional emails enable automatic profile activation; others undergo moderation (up to two weeks).

## Author Responsibilities

All authors must declare conflicts of interest through two categories: domain conflicts (based on Education & Career History) and personal conflicts (family relationships, advisor/advisee relationships, co-authorship within three years). Authors bear full responsibility for paper content, ensuring originality and accuracy, particularly regarding citations and figures generated with AI assistance.

## Required Checklist & Format

Papers require completion of the NeurIPS paper checklist addressing "reproducibility, transparency, research ethics, and societal impact." Submissions must follow the official LaTeX template in PDF format as a single file combining paper content, references, appendices, and checklist.

## Page Limits

The main text is "limited to nine content pages, including all figures and tables." References, technical appendices, and the checklist don't count toward this limit. Camera-ready versions allow one additional content page (10 total).

## Supplementary Materials

Code and data submit separately in a single ZIP file (maximum 100MB). Materials must be anonymized for review, with reviewers required to maintain strict confidentiality. Accepted papers should provide de-anonymized links for reproducibility.

## Anonymization Policy

All submissions must be anonymized, removing identifying information from text, figures, links, and supplementary materials. Self-citations should use neutral phrasing: "Smith et al." rather than "our previous work." Acknowledgments are prohibited at submission.

## Code/Data Submission Guidelines

Code should ideally be self-contained and executable, specifying dependencies clearly. Data submissions should conform to best practices: persistent identifiers, Schema.org/DCAT metadata standards, appropriate licensing, and long-term preservation repository placement. New datasets require responses to checklist questions addressing privacy, consent, and representativeness.

## Reviewer Matching

The handbook specifies conflict-of-interest checks but doesn't detail TPMS or keyword-based matching systems. ACs recommend reviewers while ensuring no conflicts exist. Bidding allows reviewers to express paper preferences before assignment.

## Policy Changes from Prior Years

**Significant 2026 additions include:**
- Contribution type designation (General, Theory, Use-Inspired, Concept & Feasibility, Negative Results) with type-specific reviewer guidelines
- Compute resource reporting requirement (optional information, not used for reviewing)
- Responsible reviewing initiatives: reviewer-authors and AC-authors cannot access their own papers' reviews until completing assigned reviews; desk rejection sanctions possible for negligent reviewing
- LLM experiment: some reviewers receive sanctioned LLM support for specific papers; others prohibited entirely
- Responsible disclosure procedures for security vulnerability papers

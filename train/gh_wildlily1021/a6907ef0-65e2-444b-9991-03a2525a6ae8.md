  2. 创建 composable

  目录：rewrite/src/shared/composables/（新建）

  use-async-action.ts：
  - execute<T>(id: string, fn: () => Promise<T>): Promise<T | undefined>
    - 内部维护 operatingIds: shallowRef<Set<string>>
    - 执行前检查 id 是否已在 operating → 是则 return undefined
    - 执行中 add id → try fn → finally remove id
    - fn 抛异常时：$q.notify({ type: 'negative', message: error.message })，然后 rethrow（让调用方可以进一步处理）或 return undefined
    - 成功时不自动 notify（由调用方决定）
  - isOperating(id: string): boolean

  use-polling.ts：
  - 参数：fn: () => void, intervalMs: number
  - 内部用 rAF + 时间节流 + disposed ref
  - 返回 { start(), stop(), restart() }

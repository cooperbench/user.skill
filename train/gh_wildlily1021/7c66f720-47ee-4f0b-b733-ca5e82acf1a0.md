## 设计要点总结

**改动范围极小**，4 个文件，不改任何 feature 内部：

| 步骤 | 文件 | 做什么 |
|------|------|--------|
| 1 | `runtime/index.ts` | 添加 tick driver（startTickDriver/stopTickDriver/isTickDriverRunning），destroy 自动清理 |
| 2 | `app/rewriteRuntime.ts` | 新增 `bootstrapRewriteRuntime()`：检测 platform bridge → 选 real/noOp adapter → 创建 runtime |
| 3 | `app/AppShell.vue` | 用 `bootstrapRewriteRuntime()` 替代裸调用；`onUnmounted` 调 `destroy()` |
| 4 | `runtime/__tests__/bootstrap-integration.spec.ts` | 端到端骨架：fake adapter → connect → pushData → routingTick → 断言 bridge emit |

**关键决策：**

1. **adapter 选择放 `app/` 不放 `runtime/`**：runtime 保持纯 composition root，不感知 platform
2. **tick driver 放 runtime 返回对象内**：是 runtime 生命周期的一部分，intervalMs 可配置（默认 100ms）
3. **端到端测试只覆盖到 bridge emit**：result feature 不存在，task→send→result 用注释标注未来扩展点

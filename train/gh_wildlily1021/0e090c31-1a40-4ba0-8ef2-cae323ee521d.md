  ### 修复 1：rw-dialog-* class 不存在（基础设施）

  `rw-dialog-md` 在 conventions D2 中被引用、在 ImportFrameDialog.vue 中被使用，但从未定义。
  请在 `_size.scss` 中添加 dialog 尺寸 token，在 `_utilities.scss` 中生成对应的 CSS class。

  推荐值（和 conventions D2 示例对齐）：
  - `dialog-sm`: 400px
  - `dialog-md`: 560px
  - `dialog-lg`: 720px
  - `dialog-xl`: 960px

  class 应设置 `min-width` 和 `max-width: 80vw`（响应式下限），使用 `var(--rw-size-dialog-*)` token。
  同时在 `app.scss` 的 `:root` 中暴露对应的 CSS 变量。

  ### 修复 2：NewConnectionDialog 弹窗宽度硬编码

  文件：features/connection/components/NewConnectionDialog.vue
  位置：`<style>` 中的 `.new-connection-dialog { min-width: 420px; max-width: 520px; }`

  改为：在 template 的 `<q-card>` 上使用 `class="rw-dialog-md"`（修复 1 创建的 class），删除 scoped SCSS 中的硬编码宽度规则。

  ### 修复 3：ConnectionPage 空状态图标颜色硬编码

  文件：pages/ConnectionPage.vue
  位置：空状态 `<q-icon name="link_off" size="48px" color="grey-5" />`

  - pnpm -C rewrite lint
  - grep "rw-dialog" 在整个 rewrite/src/css 中能找到定义

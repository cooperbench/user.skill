### 改了哪些函数 / 类型（按步骤分组）

**步骤 1：词法+语法分析器**
- `types.ts` 新增 VariableValue/VariableMap/FunctionTable/CompileResult/EvalResult/ConditionalCompileResult/ConditionalEvalResult/GroupCompileResult/GroupEvalResult/CompiledExpr/CompiledConditional/CompiledGroup 类型
- `tokenizer.ts:tokenize()` 新增 — 词法分析，支持 Unicode 标识符、大数、科学记数法、字符串字面量
- `parser.ts:parse()` 新增 — 递归下降语法分析，运算符优先级 or → and → comparison → add → mul → unary → primary
- `dependency.ts:extractDependencies()` / `kahnSort()` 新增 — AST 变量依赖提取 + Kahn 拓扑排序

**步骤 2：编译+单表达式求值**
- `functions.ts:defaultMathFunctions` 新增 — 13 个 Math.* 简名函数
- `compile.ts:compileExpression()` 新增 — tokenize → parse → validate functions → compile to closure
- `compile.ts:compileNode()` / `makeBinary()` 新增 — AST → 闭包树编译
- `evaluate.ts:evaluate()` 新增 — 执行闭包 + 错误捕获 + 非有限值检测

**步骤 3：条件表达式**
- `compile.ts:compileConditional()` 新增 — 多分支分别编译 condition + expression
- `evaluate.ts:evaluateConditional()` 新增 — 按序短路求值 + fallback

**步骤 4：批量求值**
- `compile.ts:compileGroup()` 新增 — 逐个编译 + 依赖图构建 + Kahn 排序 + 循环检测
- `evaluate.ts:evaluateGroup()` 新增 — 按拓扑序逐个 evaluate + 中间结果注入 + 部分失败隔离

**步骤 5-6：导出+集成+性能**
- `index.ts` 新增 — 统一导出公共 API（3 compile + 3 evaluate + 1 functionTable + 全部类型）
- `rewrite/src/shared/index.ts:1` 修改 — 增加 expression 模块重导出

### 三个关键设计决策（已对齐）

| 决策 | 结论 |
|------|------|
| Network adapter 拆分 | **统一 RealNetworkAdapter**（tcp-client/tcp-server/udp 共享 platform network API） |
| Serial 重连默认 | **关闭**（端口物理消失风险高，用户可配置开启） |
| 重连调度位置 | **Service 内部 setTimeout**（core 纯函数 + service 编排 + fake timer 测试） |

### 新增内容

**4.11 Network adapter design** — 5 个决策点：
- D1: 统一 createRealNetworkAdapter 工厂，RealSerialAdapter 保持独立
- D2: TCP Server listener + client 事件映射（adapter 不跟踪 client）
- D3: UDP write 无 remote 返回错误
- D4: mapBridgeEvent 提取共享
- D5: 网络错误映射表

**4.12 Reconnection strategy** — 核心设计：
- Policy 模型（enabled/maxAttempts/initialDelay/maxDelay/backoff）
- 传输类型差异化默认（serial→off, tcp→10次, udp→5次）
- 编排流：drainEvents 检测断线 → setTimeout → connect 重试 → backoff
- 取消机制：disconnect/cleanup/config变更
- 状态扩展：ConnectionFact 新增 reconnectAttempt/reconnectNextAt
- 新事件：reconnect-scheduled / reconnect-exhausted

**4.13 结构健康度** — 1 项微重构（提取 mapBridgeEvent，独立退出信号）

64	
65	    for line in lines:
66	        try:
67	            obj = json.loads(line)
68	            role = obj.get('type', obj.get('role', ''))
69	
70	            # 用户消息：提取目标
71	            if role == 'user':
72	                content = obj.get('content', '')
73	                if isinstance(content, list):
74	                    texts = [c.get('text','') for c in content if c.get('type')=='text']
75	                    content = ' '.join(texts)
76	                if content and len(content) > 10:
77	                    print(f"[USER] {content[:200]}")
78	
79	            # 工具调用：提取改了什么文件
80	            elif role == 'tool_use' or obj.get('type') == 'tool_use':
81	                name = obj.get('name', '')
82	                inp = obj.get('input', {})
83	                if name in ('Edit', 'Write', 'Bash'):
84	                    fp = inp.get('file_path', inp.get('command', ''))
85	                    print(f"[{name}] {str(fp)[:120]}")
86	
87	            # Assistant 文本：提取总结性语句
88	            elif role == 'assistant':

126	### 五、表达式引擎学习（2026-05-08）
127	
128	从 18 个生产配置文件中提取真实表达式模式的事实：
129	
130	1. **零数学函数调用**：所有表达式只用四则运算，没有 sin/cos/sqrt/pow。引擎仍提供 Math.* 函数表。
131	2. **中文变量名是常态**：`速度`、`距离`、`光速`、`帧距`等。tokenizer 必须用 `\p{ID_Start}`/`\p{ID_Continue}` Unicode 属性。
132	3. **条件多分支是核心模式**：典型 5 个 `{condition, expression}` 对按序短路求值，必须纳入引擎核心。
133	4. **大数常数常见**：`13743895344000`（~2^37*125）、`299792458`（光速）。IEEE 754 double 精度足够。
134	
135	手写 parser 关键陷阱：一元负号必须加 `unary := ('-'|'+')? primary`；变量/函数名冲突通过语法消歧（标识符后跟 `(` → 函数调用）解决。
136	
137	性能实测：手写 parser + 编译为 JS 闭包，单表达式预编译后求值 < 1us，50 表达式批量拓扑求值 < 20us。高频 receive 场景完全够用，不需要 Web Worker。
138

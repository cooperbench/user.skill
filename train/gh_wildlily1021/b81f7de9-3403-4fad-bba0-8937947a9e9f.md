**关键洞察**：实时展示和历史分析的区别只在数据源，图表/表格/星座图的渲染逻辑完全一样。所以复用的核心是让 widget 数据无关——只接收 props 渲染，数据获取由 composable 在页面层解决。

```
数据获取层（不同）         渲染层（完全复用）
┌──────────────┐          ┌──────────────────┐
│ useDisplayRefresh │────→ │                  │
│ (rAF + selector)  │      │  ChartWidget     │
└──────────────┘          │  DataTable        │
┌──────────────┐          │  ScatterWidget    │
│ useHistoryQuery  │────→ │  columns.ts       │
│ (storage query)  │      │  useECharts       │
└──────────────┘          └──────────────────┘
```

Storage 已有 `listLocalRecords({from, to})` 和 `listHistoryHours()`，基础查询够用。历史分析需要补的是：storage records → DisplayFieldMaterial 转换（一个纯函数就够）。

目录结构规划：

```
rewrite/src/
  pages/
    DisplayPage.vue                # 实时展示
    HistoryPage.vue                # 历史分析

  widgets/
    display/
      DisplayPanel.vue             # 面板容器（复用）
      DisplayModeToggle.vue        # 模式切换（复用）
      GroupSelector.vue            # 分组选择
      RecordingControls.vue        # 录制控制
      DataTable.vue                # 表格（复用）
      ChartWidget.vue              # 折线图（复用）
      ScatterWidget.vue            # 星座图（复用）
      ChartSettingsDialog.vue      # 图表配置（复用）
      ScatterSettingsDialog.vue    # 星座图配置（复用）
      columns.ts                   # 列定义（复用）
    history/
      HistoryTimeSelector.vue      # 时间范围选择
      HistoryDataSelector.vue      # 数据源选择

  composables/
    useDisplayRefresh.ts           # 实时 rAF 刷新
    useHistoryQuery.ts             # 历史查询 + 转换
    useECharts.ts                  # ECharts 生命周期（通用）

  features/
    display/                       # 已有 core/service/selector
    storage-local-baseline/        # 已有，需补 records→DisplayFieldMaterial 转换
```

**复用关系**：

| 组件 | DisplayPage 用法 | HistoryPage 用法 |
|------|-----------------|-----------------|
| DisplayPanel | 直接用，内部读 display selector | 直接用，但数据源改为 history composable |
| DataTable | props: rows from useDisplayRefresh | props: rows from useHistoryQuery |
| ChartWidget | props: series from useDisplayRefresh | props: series from useHistoryQuery |
| ScatterWidget | props: scatter from useDisplayRefresh | props: scatter from useHistoryQuery |
| ChartSettingsDialog | updatePreferences | updatePreferences（偏好格式相同） |
| columns.ts | 同一套列定义 | 同一套列定义 |

**HistoryPage 额外需求**（storage 侧）：

storage 需要新增一个纯函数转换层（可以放 `storage-local-baseline/core/` 或 `display/core/`）：

```typescript
// 将 storage records 转为 DisplayFieldMaterial[]
function convertStorageRecordsToDisplayMaterial(
  records: ReadonlyStorageLocalRecord[]
): DisplayFieldMaterial[]
```

这样 history analysis 页面的数据流就是：
```
用户选时间范围 → storage.listLocalRecords({from, to})
  → convertStorageRecordsToDisplayMaterial()
  → display.ingestSourceMaterial()
  → 同一套 selector → 同一套 widget
```

303	## 8. 性能
304	
305	> 本章规则全部来源于旧系统实际踩坑，是 rewrite 性能底线。
306	
307	### P1. 高频数据必须缓冲后批量刷新
308	
309	串口/网络/SCOE 数据不得逐条触发 Vue 响应式。用 rAF（16ms）或定时器缓冲，每帧批量刷一次。UI 刷新频率与数据源频率解耦。
310	
311	```typescript
312	// ❌ 旧系统：每包数据直接穿透到 store
313	serialPort.on('data', data => store.handleReceivedData(data));
314	
315	// ✅ 缓冲层
316	let pending: Frame[] = [];
317	let rafId: number | null = null;
318	function pushFrame(frame: Frame) {
319	  pending.push(frame);
320	  if (!rafId) rafId = requestAnimationFrame(flush);
321	}
322	function flush() {
323	  displayData.value = [...pending]; pending = [];
324	  rafId = null;
325	}
326	```
327	
328	### P2. 大数组/大对象用 shallowRef，整组替换
329	
330	超 50 元素的数组、嵌套超 2 层的对象用 `shallowRef`。更新时 `arr.value = newArr`，不用 `.push()` / `.splice()`。第三方实例和历史数据用 `markRaw()`。
331	
332	```typescript
333	// ❌
334	const list = reactive<Frame[]>([]); list.push(newFrame);
335	// ✅
336	const list = shallowRef<Frame[]>([]); list.value = [...list.value, newFrame];
337	```
338	
339	### P3. 禁止 deep watch 大对象
340	
341	超 20 属性的对象或超 10 元素的数组禁止 `watch(x, fn, { deep: true })`。改为监听具体 computed、在变更点主动调用。
342	
343	```typescript
344	// ❌
345	watch(() => config, handler, { deep: true });
346	// ✅
347	watch(() => config.groups.length, () => rebuild());
348	// 或在变更点显式调用 rebuild()
349	```
350	
351	### P4. computed 返回对象/数组必须保持引用稳定
352	
353	避免 `.filter()` / `.map()` 直接返回（每次新引用）。Vue 3.4+ 用 computed 的 oldValue 参数比较。
354	
355	推荐模式：表格行数据、筛选结果等派生数组用 `shallowRef` + `watch` 手动更新，不用 `computed` + `.map()`/`.filter()`。
356	
357	```typescript
358	// ❌ 每次 frameList 变化都创建全新数组，触发下游全量 diff
359	const tableRows = computed(() =>
360	  frameList.value.map((f, i) => ({ ...f, _index: i + 1 })),
361	);
362	
363	// ✅ shallowRef + watch，整组替换（与 P2 一致）
364	const tableRows = shallowRef<TableRow[]>([]);
365	watch(frameList, (list) => {
366	  tableRows.value = list.map((f, i) => ({ ...f, _index: i + 1 }));
367	}, { immediate: true });
368	```
369	
370	少量数据（< 50 条）时 computed 也勉强可用，但后续页面数据量可能增大，统一使用 shallowRef 模式减少认知负担。
371	
372	### P5. 定时器用 requestAnimationFrame，不用 setInterval
373	
374	UI 更新和动画驱动用 rAF。长周期轮询（≥1s）可用 setInterval，但必须 onUnmounted 清理。
375	
376	```typescript
377	// ❌ 旧系统：setInterval(fn, 500) 更新表格
378	// ✅ rAF + 节流
379	let last = 0;
380	function loop(now: number) {
381	  if (now - last >= 500) { updateTable(); last = now; }
382	  rafId = requestAnimationFrame(loop);
383	}
384	```
385	
386	### P6. v-for 必须用稳定唯一 key，不用 index
387	
388	```vue
389	<!-- ❌ --> <div v-for="(item, i) in list" :key="i">
390	<!-- ✅ --> <div v-for="item in list" :key="item.id">
391	```
392	
393	### P7. 仪表盘用 v-memo 限制重渲染范围
394	
395	```vue
396	<ConnectionPanel v-memo="[connectionState]" :state="connectionState" />
397	<FrameMetrics v-memo="[frameSnapshot]" :data="frameSnapshot" />
398	```
399	
400	### P8. 模板中禁止内联 .filter() / .map() / .reduce()
401	
402	提取到 computed。

469	## 12. 页面 Composable 模式
470	
471	页面中以下三种模式不得手写，必须使用对应 composable。
472	
473	### CM1. 异步操作用 `useAsyncAction()`
474	
475	操作锁（operatingIds）、try-finally 清理、错误通知统一由 composable 管理。
476	
477	```typescript
478	// ❌ 手写 operatingIds Set + try-finally
479	const operatingIds = ref<Set<string>>(new Set());
480	async function handleConnect(s: ConnectionSummary) {
481	  operatingIds.value = new Set(operatingIds.value).add(s.connectionId);
482	  try { /* ... */ }
483	  finally { const next = new Set(operatingIds.value); next.delete(s.connectionId); operatingIds.value = next; }
484	}
485	
486	// ✅ composable
487	const { execute, isOperating } = useAsyncAction();
488	async function handleConnect(s: ConnectionSummary) {
489	  await execute(s.connectionId, async () => {
490	    const result = await service.connect(config);
491	    // composable 负责 finally 清理 + 错误时 $q.notify
492	  });
493	}
494	```
495	
496	composable 返回：
497	- `isOperating(id: string): boolean` — 查询操作锁
498	- `execute<T>(id: string, fn: () => Promise<T>): Promise<T | undefined>` — 带锁执行，自动清理，失败时 `$q.notify({ type: 'negative' })`
499	
500	### CM2. 页面轮询用 `usePolling()`
501	
502	rAF + 节流 + disposed 检查 + onUnmounted 清理统一由 composable 管理。
503	
504	```typescript
505	// ❌ 手写 rAF + disposed + 节流
506	let rafId = 0; let lastPollTime = 0; const disposed = ref(false);
507	function tick(now: number) { /* ... */ rafId = requestAnimationFrame(tick); }
508	onMounted(() => { rafId = requestAnimationFrame(tick); });
509	onBeforeUnmount(() => { disposed.value = true; if (rafId) cancelAnimationFrame(rafId); });
510	
511	// ✅ composable
512	const { start } = usePolling(() => refreshSummaries(), 500);
513	onMounted(start);
514	```
515	
516	composable 返回：
517	- `start(): void` — 启动轮询
518	- `stop(): void` — 停止轮询
519	- `restart(): void` — 重启轮询
520	- 内部自动 onUnmounted 清理
521	
522	### CM3. 通知用 `useNotify()`
523	
524	封装 `$q.notify` 的成功/失败/警告模式，统一消息格式。
525	
526	```typescript
527	const notify = useNotify();
528	notify.success('连接已创建');
529	notify.error('连接失败', result.error?.message);
530	notify.info('操作已取消');
531	```

536	
537	### O1. 状态声明按用途分组
538	
539	页面 `<script setup>` 中的 ref/computed/shallowRef 按以下顺序声明，组间空一行：
540	
541	```typescript
542	// ===== Service 引用 =====
543	const service = runtime.features.xxxService;
544	
545	// ===== 业务数据 =====
546	const items = ref<readonly Xxx[]>([]);
547	
548	// ===== 查询/筛选 =====
549	const searchText = ref('');
550	const statusFilter = ref<Status | ''>('');
551	
552	// ===== UI 状态 =====
553	const showDialog = ref(false);
554	const selectedIds = ref<string[]>([]);
555	
556	// ===== 派生数据 =====
557	const tableRows = shallowRef<TableRow[]>([]);
558	
559	// ===== 操作 =====
560	const { execute, isOperating } = useAsyncAction();
561	const notify = useNotify();
562	```
563	
564	### O2. runtime tick 错误不可静默吞
565	
566	runtime 层的 `routingTick` 等定期操作，`.catch()` 必须至少 `console.error`，不得写空回调。
567	
568	```typescript
569	// ❌
570	routingTick(wiredFeatures).catch(() => {});
571	
572	// ✅
573	routingTick(wiredFeatures).catch((err) => console.error('[routingTick]', err));
574	```
575	
576	### O3. 2+ 处出现的同一代码模式必须提取
577	
578	标签映射、选项数组、stable key 管理、数组操作样板、默认值工厂等，出现在 2+ 文件/函数中时，提取到 composable、shared 常量或辅助函数。不允许复制粘贴后微调。
579	
580	### O4. 不变数据定义在模块级
581	
582	选项数组、标签映射、枚举→标签 Record 等不随组件实例变化的数据，定义在 `<script setup>` 外（模块级常量）。setup 每次挂载都会执行，不应在其中重建不变数据。

export function useAsyncAction() {
  const $q = useQuasar();
  const operatingIds = shallowRef<Set<string>>(new Set());

  async function execute<T>(id: string, fn: () => Promise<T>): Promise<T | undefined> {
    if (operatingIds.value.has(id)) return undefined;

    const next = new Set(operatingIds.value);
    next.add(id);
    operatingIds.value = next;

    try {
      return await fn();
    } catch (err) {
      const message = err instanceof Error ? err.message : String(err);
      $q.notify({ type: 'negative', message });
      return undefined;
    } finally {
      const after = new Set(operatingIds.value);
      after.delete(id);
      operatingIds.value = after;
    }
  }

  function isOperating(id: string): boolean {
    return operatingIds.value.has(id);
  }

  return { operatingIds, execute, isOperating };
}

import { onUnmounted, ref } from 'vue';

export function usePolling(fn: () => void, intervalMs: number) {
  let rafId = 0;
  let lastTime = 0;
  const disposed = ref(false);

  function tick(now: number): void {
    if (disposed.value) return;
    if (now - lastTime >= intervalMs) {
      fn();
      lastTime = now;
    }
    rafId = requestAnimationFrame(tick);
  }

  function start(): void {
    if (disposed.value) return;
    stop();
    lastTime = performance.now();
    rafId = requestAnimationFrame(tick);
  }

  function stop(): void {
    if (rafId) {
      cancelAnimationFrame(rafId);
      rafId = 0;
    }
  }

  function restart(): void {
    start();
  }

  onUnmounted(() => {
    disposed.value = true;
    stop();
  });

  return { start, stop, restart };
}

Good question. No — `devDependencies` are **not installed** when someone runs `npm install rudel`. npm only installs `dependencies` for packages you consume as a dependency. `devDependencies` are only installed when you clone the repo and run `npm install` from within it (i.e., during development). So the `workspace:*` in `devDependencies` is completely invisible to npm consumers. They'll never encounter it. You can verify this by looking at what's already there — `@rudel/api-routes` and `@rudel/typescript-config` have been in `devDependencies` with `workspace:*` since the beginning, and they've never caused issues for npm users.

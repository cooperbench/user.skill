Just bare GitHub secrets that are almost certainly set to the PRD values. **Three test files write to ClickHouse:** | Test | Pattern | Cleanup | |------|---------|---------| | `apps/api/src/__tests__/ingest.test.ts` | `api_test_*` | Fire-and-forget DELETE (silently swallowed on failure) | | `packages/ch-schema/src/__tests__/ingest.test.ts` | `test_*` | Fire-and-forget DELETE (silently swallowed on failure) | | `apps/cli/src/__tests__/api-upload.integration.test.ts` | `cli_api_test_*`, `e2e-test-session` | **No cleanup at all** | The local `verify` script (`bun run verify`) uses `doppler run --config ci` which presumably points to a separate CI ClickHouse.

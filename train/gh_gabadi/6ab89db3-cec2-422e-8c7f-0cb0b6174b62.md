// It reads WorkerRequest JSON lines from stdin and writes WorkerResponse JSON lines to stdout.

10	`mutate4go --since-last-run` compares **function source hashes** in the manifest against the current source. If only tests changed (not the function under test), the hash is unchanged and 0 sites are selected — even if prior survivors need re-testing.
11	
12	**Why:** After adding boundary tests to kill `board.go` survivors, ran `--since-last-run` and got "Selected mutation sites: 0" because board.go source hadn't changed. Had to manually delete the manifest block from board.go and rerun.
13	
14	**How to apply:** After adding new tests to kill survivors (without changing the source under test), use `mutate4go <file> --lines L1,L2,...` to target just the survivor lines — this is faster than a full run and avoids manifest issues. Alternatively delete the manifest section from the source file and run without `--since-last-run`. Use `--since-last-run` only when the source file itself changed.

> AGENT

Here's how they work:

**`agent_context/`** — Created by the swarm at startup (`prepare_workspace()`). It's a shared read/write space for agents to exchange context files across roles during a swarm run. Any agent can write there; others can read it. Empty between swarm runs.

**`memory/`** — Used by individual Claude agent sessions for their file-based auto-memory (like the system I use at `~/.claude-gabadi/projects/.../memory/`). Agents running in this project's worktrees write here to persist facts across conversations. Gitignored so it stays local and doesn't pollute source control.

**`logs/`** — Also created by `prepare_workspace()`, holds per-agent stdout/stderr logs from the swarm run.

**`logbook.json`** — Written by swarm agents (hardender/QA) to record handoff state: which branch, which commit, what prompt was delivered. It's a delivery audit trail, not source — hence gitignored.

All four are runtime/local artifacts: created on swarm start or during agent runs, never meant to be committed.

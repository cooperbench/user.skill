A few practical ways to skim a transcript file:

**1. Built-in resume picker (easiest for finding which file is which):**

```
claude --resume
```

Shows a list of recent sessions with timestamps and the first user prompt — handy when you don't know which file holds the conversation you want. You can quit out without actually resuming.

**2. Quick text view of just the human/assistant turns** (skip tool noise):

```
jq -r 'select(.type=="user" or .type=="assistant") |
       "── \(.type) ─────\n\(.message.content
         | if type=="string" then .
           else map(select(.type=="text").text) | join("\n") end)"' \
   .claude/fb3c538d-6c5d-4932-a286-b72d5312189a.jsonl | less
```

That strips out tool calls/results so you see just the conversation. Pipe through `less` (or redirect to a file) — these can be megabytes.

**3. Grep for a specific topic** before opening anything:

```
jq -r 'select(.type=="user" or .type=="assistant") |
       .message.content
       | if type=="string" then .
         else map(select(.type=="text").text) | join("\n") end' \
   .claude/fb3c538d-*.jsonl | grep -n -i "cycle protocol"
```

**4. Just look at it raw** — `less .claude/fb3c538d-*.jsonl` works; each line is one record, ugly but searchable.

For your case, option 2 piped to a file is probably best — open it in your editor, search for "Cycle Protocol" or whatever you remember about the refinement, paste the relevant bits back into the next session. Then you can start fresh without losing the thinking.

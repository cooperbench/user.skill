# Plan: Convert `Commands::Ts` to use Execute trait

## Context

`Ts` is the only command variant in `Commands` that doesn't use the Execute trait. It uses an inline struct variant with nested match in main.rs (30 lines). All other commands use `Cmd(XxxCmd)` tuple variants where the struct implements Execute. This conversion makes Ts consistent with every other command.

Additionally, all 5 ts_cmd functions internally call `find_project_root()`. Since the Execute trait already receives `project_root`, we'll thread it through to eliminate the redundant lookups.

## Changes

`TsCmd` struct wrapping `TsCommands`, implementing Execute. Move `TsCommands` enum here from cli.rs.

The Execute impl dispatches to ts_cmd functions, passing `project_root`. The `Set` variant's `key=value` parsing (currently in main.rs) moves here.

### 2. Update `src/cmd/mod.rs`

In each file: remove `find_project_root` from imports, replace `let workspace = find_project_root()?;` with `let workspace = project_root;` (or use `project_root` directly).

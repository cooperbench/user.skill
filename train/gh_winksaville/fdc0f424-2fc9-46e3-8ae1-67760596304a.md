## Step 4: Update single-package execute logic

In each command's `execute()`, when a package is resolved (single-package mode):

- If `tspec` is empty → call once with `None` (unchanged default behavior)
- If `tspec` is non-empty → resolve via `find_tspecs(&package_dir, &self.tspec)`
  (reuse from `crate::find_paths`), then loop over each spec path

This mirrors compare's single-package mode (`src/cmd/compare.rs:55-64`). Each command
needs to import `find_tspecs`, `resolve_package_dir`, `get_package_name` from
`crate::find_paths`.

**Build:** Loop calls `build_package(name, Some(spec_path_str), release)` per spec.
Strip if requested after each build.

**Test:** Loop calls `test_package(name, Some(spec_path_str), release)` per spec.

**Run:** Loop calls build + optional strip + `run_binary()` per spec. Note: pass-through
`args` work with each spec run.

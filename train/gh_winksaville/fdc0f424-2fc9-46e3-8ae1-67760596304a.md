    88→## Conventions
    89→
    90→- **Rust Edition:** 2024
    91→- **Commit style:** Conventional commits (feat:, docs:, refactor:)
    92→- **Naming:** POP (Plain Old Package) refers to single-package projects (no workspace); tspec treats them as trivial workspaces
    93→- **Granularity:** tspec operates at the Cargo package level, not the crate level. "Package" = directory with Cargo.toml. A package may contain multiple crates (targets), but they all share one tspec.
    94→- **Package argument pattern:** All commands accept both `-p <name-or-path>` and a positional `<PACKAGE>` argument. Paths (like `.`) are resolved to the actual cargo package name via `resolve_package_arg()`. At a pure workspace root (no `[package]`), `.` resolves to None (all-packages mode). Resolution order: positional > `-p` > current directory > all packages.
    95→- **`cmd` vs `cmd .` for passthroughs:** For passthrough commands (clean, clippy, fmt), `tspec cmd` passes no `-p` to cargo (operates on everything), but `tspec cmd .` resolves to `cargo cmd -p <name>` (package-specific). The difference is most visible with `clean`: `cargo clean` removes all of target/ while `cargo clean -p <name>` leaves shared metadata. This matches cargo's own behavior. Use `tspec clean` or `tspec clean -w` for a full clean.
    96→- **Markdown refs:** Multiple references use `[1],[2]` not `[1,2]` or `[1][2]` (both break in markdown)

   205→pub fn find_tspecs(pkg_dir: &Path, patterns: &[String]) -> Result<Vec<PathBuf>> {
   206→    let default_pattern = format!("tspec*{}", TSPEC_SUFFIX);
   207→    let patterns: Vec<&str> = if patterns.is_empty() {
   208→        vec![&default_pattern]

   210→        patterns.iter().map(|s| s.as_str()).collect()

   219→            results.push(as_path.canonicalize().unwrap_or(as_path));
   220→            continue;
   221→        }
   222→

   224→        let in_pkg = pkg_dir.join(pattern);
   225→        if in_pkg.exists() && in_pkg.is_file() {
   226→            results.push(in_pkg);
   227→            continue;
   228→        }
   229→
   230→        // Try as glob pattern in pkg_dir
   231→        let glob_pattern =
   232→            Pattern::new(pattern).with_context(|| format!("invalid glob pattern: {}", pattern))?;

   235→            .with_context(|| format!("cannot read directory: {}", pkg_dir.display()))?

   237→            .filter(|e| {
   238→                let name = e.file_name().to_string_lossy().to_string();
   239→                e.path().is_file() && glob_pattern.matches(&name)
   240→            })
   241→            .map(|e| e.path())
   242→            .collect();
   243→
   244→        results.extend(entries);
   245→    }
   246→
   247→    // Remove duplicates and sort
   248→    results.sort();
   249→    results.dedup();
   250→
   251→    if results.is_empty() {
   252→        let pattern_list = patterns.join(", ");
   253→        bail!(
   254→            "no tspec files found matching '{}' in {}",
   255→            pattern_list,
   256→            pkg_dir.display()
   257→        );
   258→    }

   261→}

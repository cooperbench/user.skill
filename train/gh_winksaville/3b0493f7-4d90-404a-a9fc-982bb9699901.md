# Add tspec-build to ex-x2

## Context

ex-x2 uses rlibc-x2 which defines a custom `_start` entry point. The linker flags (`-static`, `-nostdlib`, `-e_start`, etc.) are in `tspec.ts.toml` but only applied when building via `tspec build`. A plain `cargo build --release` fails with a duplicate `_start` symbol because the linker flags aren't emitted. Adding tspec-build (like ex-x1 already has) lets ex-x2 build with plain cargo too.

## Changes

### 1. `apps/ex-x2/Cargo.toml` — add build dependency

Add under existing sections:
```toml
[build-dependencies]
tspec-build = { path = "../../../tspec/tspec-build" }
```

### 2. Create `apps/ex-x2/build.rs`

Same pattern as ex-x1's build.rs:
```rust
fn main() {
    tspec_build::emit_linker_flags_from(Some("tspec.ts.toml"));
}
```

This reads linker args from `tspec.ts.toml` directly when building with cargo, or from `TSPEC_SPEC_FILE` env var when building with tspec (though `Some(...)` always reads the explicit path first).

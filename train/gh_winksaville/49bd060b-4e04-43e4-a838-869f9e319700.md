## Subcommand invocation trait — recommendation

**Step A first — trait + tiny dispatch, no linkme.** Define:

```rust
trait Subcommand {
    type Params;
    fn into_params(&self) -> Result<Self::Params, String>;
    fn run(ctx: &Context, params: &Self::Params)
        -> Result<(), Box<dyn Error>>;
    fn suppress_banner(&self) -> bool { false }   // chid/desc/list/show override
    fn is_detached_exec(&self) -> bool { false }  // finalize overrides
}
```

Each match arm collapses to `Commands::Chid(a) => dispatch(a, cli.log)`. The `suppress_banner` / `is_detached_exec` peek-before-dispatch logic moves behind the trait too. You keep the exhaustiveness check; the enum is still the source of truth.

**Step B — linkme later, if it earns it.** linkme's win is "add a subcommand by adding a file, no edits to `main.rs`". You'd pay:
- Loss of `match` exhaustiveness (a forgotten registration is a runtime gap, not a compile error).
- Help-output ordering becomes link-order unless explicitly sorted.
- Macro-magic dependency, ~`inventory`-class.

Today the per-subcommand cost in `main.rs` is three touchpoints (mod decl, `Commands` variant, match arm). After Step A it's three touchpoints with each arm being one line — at which point linkme's reduction-from-three-to-one (drop the variant + arm, keep only the registration) is real but modest. I'd hold linkme back until the friction is *felt*, not predicted.

**One alternative worth knowing:** [`enum_dispatch`](https://docs.rs/enum_dispatch/) auto-generates trait dispatch off the enum — Step A without writing the match arms by hand, still compile-time exhaustive. Closer-fitting than linkme to what you're describing.

## Implementation note 1: nested `fn` can't capture

Your `fn sb_ide()` references `cli` and `is_detached_exec` from the outer scope. Nested `fn` in Rust *can't capture* (it's an isolated free function); for capture you need a closure. Two paths:

```rust
// (a) Closure — captures is_detached_exec + suppress_banner by value
let sb_ide = || {
    if !is_detached_exec {

            log::info!("{BANNER}");
        }
        finalize::surface_previous_failures();
```

or

```rust
// (b) Regular fn outside main, takes its inputs as args
fn sb_ide(suppress_banner: bool, is_detached_exec: bool) {
    if !is_detached_exec {
        ...
    }
}
```

I'd go with **(a)** since you wanted it "right in `fn main()`".

changes but the summary doesn't explain why. Adding the ignored count to the summary
makes it obvious: without `--all-tests` you see "316 passed (16 ignored)", with it
you see "332 passed" (no ignored).

The `ignored` count is already parsed and stored in `TestResult` — just not displayed.

1. **`src/all.rs`** — `print_test_summary()` (line ~422)

   - In the footer line, append ignored total if > 0
   - Current: `format!("[PASS]  {} passed", counts.passed)`

2. **`src/all.rs`** — tests for `print_test_summary` (update existing tests if needed, add test with ignored > 0)

### No other changes needed

- `TestResult` already has `ignored` field
- `parse_test_result_line` already parses `ignored` count
- `TestResult::merge` already aggregates `ignored`

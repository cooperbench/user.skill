## Custom Profile Support — Analysis

### The core tension

Cargo requires custom profiles to be **declared** in `Cargo.toml` (with at least `inherits = "dev"` or `inherits = "release"`). You can't conjure a profile purely from `--config` flags. So tspec can never be the *sole* source of profile definitions — `Cargo.toml` must declare them.

### What tspec can cleanly own

Two separate concerns:

1. **Profile selection** — which profile to build with (`--profile NAME`)
2. **Profile overrides** — tweaking settings like opt-level, lto, codegen-units

tspec is already good at (2) via `cargo.config.profile.release.opt-level = "z"` etc. — these become `--config` args that override whatever `Cargo.toml` says.

### Proposed approach: tspec selects and overrides, Cargo.toml defines

| Responsibility | Where |
|---|---|
| Profile **definition** (`inherits`, existence) | `Cargo.toml` |
| Profile **selection** (which one to use) | tspec `cargo.profile` |
| Profile **overrides** (opt-level, lto, etc.) | tspec `cargo.config.profile.NAME.*` |

This means:
- Change `cargo.profile` from a `Debug`/`Release` enum to a **string** (or add `Custom(String)`)
- `"debug"` → no flag (cargo default), `"release"` → `--release`, anything else → `--profile <name>`
- Lift the restriction in `validate_config_profiles` to allow custom profile names in `cargo.config.profile.*`
- Update binary path resolution (`find_paths.rs`) to look in `target/<profile-name>/` for custom profiles (cargo uses the profile name as the directory, with `dev` mapping to `debug`)
- `ts set cargo.profile` validation accepts any string (or at least any valid cargo profile name)

### Why this avoids the "two places" problem

The user defines the profile structure in `Cargo.toml` once (this is unavoidable — cargo demands it). tspec just **points at** a profile and optionally **tweaks** it. No duplication. The common case (`debug`/`release`) needs nothing in `Cargo.toml` at all. Only when you want a truly custom profile (like `release-small` or `bench`) do you need a `Cargo.toml` entry — and that's a cargo requirement, not a tspec one.

### Implementation scope

This is fairly contained:
1. `types.rs` — change `Profile` enum to string (or add variant)
2. `cargo_build.rs` — emit `--profile <name>` instead of `--release`
3. `find_paths.rs` — resolve profile name to target subdirectory
4. `ts_cmd/edit.rs` — relax validation for `cargo.profile` and `cargo.config.profile.*`
5. `types.rs` — relax `validate_config_profiles`
6. Tests

   265→        cmd.arg("--target").arg(triple);

   278→    for (key, value) in flatten_config(&spec.cargo.config) {

   202→/// Find multiple tspecs by glob patterns
   203→/// If no patterns given, defaults to "tspec*{TSPEC_SUFFIX}"
   204→/// Returns sorted list of paths, errors if none found
   205→pub fn find_tspecs(pkg_dir: &Path, patterns: &[String]) -> Result<Vec<PathBuf>> {
   206→    let default_pattern = format!("tspec*{}", TSPEC_SUFFIX);
   207→    let patterns: Vec<&str> = if patterns.is_empty() {
   208→        vec![&default_pattern]
   209→    } else {
   210→        patterns.iter().map(|s| s.as_str()).collect()
   211→    };
   212→
   213→    let mut results = Vec::new();
   214→
   215→    for pattern in &patterns {
   216→        // Try as literal path first (relative to cwd or absolute)
   217→        let as_path = PathBuf::from(pattern);
   218→        if as_path.exists() && as_path.is_file() {
   219→            results.push(as_path.canonicalize().unwrap_or(as_path));
   220→            continue;
   221→        }
   222→
   223→        // Try as literal path relative to pkg_dir
   224→        let in_pkg = pkg_dir.join(pattern);
   225→        if in_pkg.exists() && in_pkg.is_file() {
   226→            results.push(in_pkg);
   227→            continue;
   228→        }
   229→
   230→        // Try as glob pattern in pkg_dir
   231→        let glob_pattern =
   232→            Pattern::new(pattern).with_context(|| format!("invalid glob pattern: {}", pattern))?;
   233→
   234→        let entries: Vec<_> = std::fs::read_dir(pkg_dir)
   235→            .with_context(|| format!("cannot read directory: {}", pkg_dir.display()))?
   236→            .filter_map(|e| e.ok())
   237→            .filter(|e| {
   238→                let name = e.file_name().to_string_lossy().to_string();
   239→                e.path().is_file() && glob_pattern.matches(&name)
   240→            })
   241→            .map(|e| e.path())
   242→            .collect();
   243→
   244→        results.extend(entries);
   245→    }
   246→
   247→    // Remove duplicates and sort
   248→    results.sort();
   249→    results.dedup();
   250→
   251→    if results.is_empty() {
   252→        let pattern_list = patterns.join(", ");
   253→        bail!(
   254→            "no tspec files found matching '{}' in {}",
   255→            pattern_list,
   256→            pkg_dir.display()
   257→        );
   258→    }

   116→fn parse_scalar_value(_key: &str, raw: &str) -> Value {
   117→    Value::from(raw)
   118→}

   120→/// Get the existing array for a field, or an empty array if it doesn't exist.
   121→fn get_existing_array(doc: &DocumentMut, key: &str) -> Array {
   122→    let (table_name, field) = parse_key(key);
   123→    match table_name {
   124→        Some(table) => doc
   125→            .get(table)
   126→            .and_then(|t| t.get(field))
   127→            .and_then(|v| v.as_array())
   128→            .cloned()
   129→            .unwrap_or_default(),
   130→        None => doc
   131→            .get(field)
   132→            .and_then(|v| v.as_array())
   133→            .cloned()
   134→            .unwrap_or_default(),
   135→    }
   136→}

   138→/// Set an array value into the document at the given key path.
   139→fn set_array_in_doc(doc: &mut DocumentMut, key: &str, arr: Array) {
   140→    let (table_name, field) = parse_key(key);
   141→    match table_name {
   142→        Some(table) => {
   143→            ensure_table(doc, table);
   144→            doc[table][field] = Item::Value(Value::Array(arr));
   145→        }
   146→        None => {
   147→            doc[field] = Item::Value(Value::Array(arr));
   148→        }
   149→    }
   150→}
   151→
   152→/// Ensure a table exists in the document.
   153→fn ensure_table(doc: &mut DocumentMut, table: &str) {
   154→    if doc.get(table).is_none() {
   155→        doc[table] = Item::Table(toml_edit::Table::new());
   156→    }
   157→}

   161→/// Set a field from string args. Scalars take `values[0]`, arrays take all values.
   162→pub fn set_field(
   163→    doc: &mut DocumentMut,
   164→    key: &str,
   165→    values: &[String],
   166→    kind: FieldKind,
   167→) -> Result<()> {
   168→    let (table_name, field) = parse_key(key);
   169→
   170→    match kind {
   171→        FieldKind::Scalar => {
   172→            if values.len() != 1 {
   173→                bail!(
   174→                    "scalar field '{}' requires exactly one value, got {}",
   175→                    key,
   176→                    values.len()
   177→                );
   178→            }
   179→            let val = parse_scalar_value(key, &values[0]);
   180→            match table_name {
   181→                Some(table) => {
   182→                    ensure_table(doc, table);
   183→                    doc[table][field] = Item::Value(val);
   184→                }
   185→                None => {
   186→                    doc[field] = Item::Value(val);
   187→                }
   188→            }
   189→        }
   190→        FieldKind::Array => {
   191→            let mut arr = Array::new();
   192→            for v in values {
   193→                arr.push(v.as_str());
   194→            }
   195→            set_array_in_doc(doc, key, arr);
   196→        }
   197→        FieldKind::Table => {
   198→            bail!(
   199→                "use set_table_value() for table field '{}'; set_field() does not handle tables",
   200→                key
   201→            );
   202→        }
   203→    }
   204→
   205→    Ok(())
   206→}

   208→/// Add items to an array field. Appends by default, or inserts at `index`.
   209→/// Deduplicates on append; insert adds at position without dedup.
   210→pub fn add_items(
   211→    doc: &mut DocumentMut,
   212→    key: &str,
   213→    values: &[String],
   214→    index: Option<usize>,
   215→) -> Result<()> {
   216→    let mut arr = get_existing_array(doc, key);
   217→
   218→    match index {
   219→        Some(idx) => {
   220→            if idx > arr.len() {
   221→                bail!(
   222→                    "index {} out of bounds for array '{}' with {} elements",
   223→                    idx,
   224→                    key,
   225→                    arr.len()
   226→                );
   227→            }
   228→            // Insert at position (no dedup — user explicitly chose position)
   229→            for (offset, v) in values.iter().enumerate() {
   230→                arr.insert(idx + offset, v.as_str());
   231→            }
   232→        }
   233→        None => {
   234→            // Append with dedup
   235→            let existing: Vec<String> = arr
   236→                .iter()
   237→                .filter_map(|v| v.as_str().map(|s| s.to_string()))
   238→                .collect();
   239→            for v in values {
   240→                if !existing.contains(v) {
   241→                    arr.push(v.as_str());
   242→                }
   243→            }
   244→        }
   245→    }
   246→
   247→    set_array_in_doc(doc, key, arr);
   248→    Ok(())
   249→}

   251→/// Remove items from an array field by value.
   252→/// Keeps the field as an empty array if all items are removed.
   253→pub fn remove_items_by_value(doc: &mut DocumentMut, key: &str, values: &[String]) -> Result<()> {
   254→    let arr = get_existing_array(doc, key);
   255→
   256→    let mut new_arr = Array::new();
   257→    for item in arr.iter() {
   258→        if let Some(s) = item.as_str()
   259→            && !values.iter().any(|v| v == s)
   260→        {
   261→            new_arr.push(s);
   262→        }
   263→    }
   264→
   265→    set_array_in_doc(doc, key, new_arr);
   266→    Ok(())
   267→}
   268→
   269→/// Remove an item from an array field by index.
   270→/// Keeps the field as an empty array if the last item is removed.
   271→pub fn remove_item_by_index(doc: &mut DocumentMut, key: &str, index: usize) -> Result<()> {
   272→    let mut arr = get_existing_array(doc, key);
   273→
   274→    if index >= arr.len() {
   275→        bail!(
   276→            "index {} out of bounds for array '{}' with {} elements",
   277→            index,
   278→            key,
   279→            arr.len()
   280→        );
   281→    }
   282→
   283→    arr.remove(index);
   284→    set_array_in_doc(doc, key, arr);
   285→    Ok(())
   286→}

   288→/// Remove a field from a toml_edit document.
   289→/// Does not remove the containing table, even if it becomes empty.
   290→pub fn unset_field(doc: &mut DocumentMut, key: &str) -> Result<()> {
   291→    let (table_name, field) = parse_key(key);
   292→
   293→    match table_name {
   294→        Some(table) => {
   295→            if let Some(Item::Table(tbl)) = doc.get_mut(table) {
   296→                tbl.remove(field);
   297→            }
   298→        }
   299→        None => {
   300→            doc.remove(field);
   301→        }
   302→    }
   303→
   304→    Ok(())
   305→}

   307→/// Smart-parse a raw value string into a toml_edit Value for table entries.
   308→/// Booleans → bool, integers → i64, everything else → string.
   309→fn parse_smart_value(raw: &str) -> Value {
   310→    match raw {
   311→        "true" => Value::from(true),
   312→        "false" => Value::from(false),
   313→        _ => {
   314→            if let Ok(n) = raw.parse::<i64>() {
   315→                Value::from(n)
   316→            } else {
   317→                Value::from(raw)
   318→            }
   319→        }
   320→    }
   321→}

   323→/// Set a value in a table field (e.g., `cargo.config`).
   324→/// `table_path` is the dotted path to the table (e.g., "cargo.config").
   325→/// `sub_key` is the key within that table (e.g., "profile.release.opt-level").
   326→/// `raw_value` is the string value to set (auto-parsed to bool/int/string).
   327→pub fn set_table_value(
   328→    doc: &mut DocumentMut,
   329→    table_path: &str,
   330→    sub_key: &str,
   331→    raw_value: &str,
   332→) -> Result<()> {
   333→    let (parent, table_name) = parse_key(table_path);
   334→    let val = parse_smart_value(raw_value);
   335→
   336→    match parent {
   337→        Some(p) => {
   338→            ensure_table(doc, p);
   339→            // Ensure the nested table exists
   340→            if doc[p].get(table_name).is_none() {
   341→                doc[p][table_name] = Item::Table(toml_edit::Table::new());
   342→            }
   343→            doc[p][table_name][sub_key] = Item::Value(val);
   344→        }
   345→        None => {
   346→            if doc.get(table_name).is_none() {
   347→                doc[table_name] = Item::Table(toml_edit::Table::new());
   348→            }
   349→            doc[table_name][sub_key] = Item::Value(val);
   350→        }
   351→    }
   352→
   353→    Ok(())
   354→}

   356→/// Remove a single key from a table field.
   357→pub fn unset_table_value(doc: &mut DocumentMut, table_path: &str, sub_key: &str) -> Result<()> {
   358→    let (parent, table_name) = parse_key(table_path);
   359→
   360→    match parent {
   361→        Some(p) => {
   362→            if let Some(Item::Table(parent_tbl)) = doc.get_mut(p)
   363→                && let Some(Item::Table(tbl)) = parent_tbl.get_mut(table_name)
   364→            {
   365→                tbl.remove(sub_key);
   366→            }
   367→        }
   368→        None => {
   369→            if let Some(Item::Table(tbl)) = doc.get_mut(table_name) {
   370→                tbl.remove(sub_key);
   371→            }
   372→        }
   373→    }
   374→
   375→    Ok(())
   376→}

First remind me how to use jj to see the title and body of the commits

> AGENT

The default `jj log` shows a condensed view. To see the full commit description (title + body):

```
jj log --template builtin_log_detailed -R .
```

Or for a specific commit:

```
jj show <change_id> -R .
```

You can also limit how many commits to display:

```
jj log --template builtin_log_detailed --limit 5 -R .
```

The title is the first line of the description, and the body is everything after the blank line separator — same convention as git.

> DEVELOPER

Using --template .... seems very verbose that's really the only way to see both?

> AGENT

You can use `-T` as the short form:

```
jj log -T builtin_log_detailed -R .
```

But if you just want to see the full description of a single commit, `jj show` is the simplest:

```
jj show -R .
jj show @- -R .
```

That shows the full title + body along with the diff.

> DEVELOPER

But I'd like to see all or several at once

> AGENT

You can write a short custom template:

```
jj log -T 'change_id.short() ++ " " ++ description ++ "\n"' -R .
```

That'll show each commit's change ID and full description (title + body) without all the extra detail from `builtin_log_detailed`.

If you find yourself using it often, you could alias it in your jj config (`~/.jjconfig.toml`):

```toml
[aliases]
desc = ["log", "-T", "change_id.short() ++ \" \" ++ description ++ \"\\n\""]
```

Then just `jj desc -R .`.

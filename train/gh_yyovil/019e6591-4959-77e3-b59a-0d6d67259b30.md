> DEVELOPER

tell me how to add a dir without exiting the codex TUI rn

> AGENT

Short answer: you can’t do it from inside a running Codex TUI session.

`--add-dir` is an **startup CLI option only**. So to include another writable directory, you need to start a new session with it.

Use:
```bash
codex --cd /your/current/workdir --add-dir /path/to/extra/dir
```

You can add multiple:
```bash
codex --cd /your/current/workdir --add-dir /a --add-dir /b
```

If you want to keep your current context, use a fresh session (optionally from where you left off), because live hot-adding dirs isn’t exposed in the current TUI flow.

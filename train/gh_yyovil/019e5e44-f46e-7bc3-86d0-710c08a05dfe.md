> AGENT

“Always parenthesized arrow args” means arrow functions use parentheses around their parameter list even when there is only one parameter.

With this setting:

```ts
items.map((item) => item.id);
```

Instead of:

```ts
items.map(item => item.id);
```

It comes from this formatter config:

```json
"arrowParens": "always"
```

So `oxfmt` will normalize single-argument arrow functions to include parentheses.

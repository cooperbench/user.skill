## Real AO Terminal Runtime

The Terminal tab reads the local Agent Orchestrator runtime from `~/.agent-orchestrator`. It lists active orchestrator and worker sessions from `running.json` plus each project's `sessions/*.json` metadata, then attaches the browser terminal to the selected session's real runtime:

- Zellij-backed AO sessions attach with `zellij attach <session>`.
- Legacy tmux-backed AO sessions seed browser scrollback with `tmux capture-pane`, then attach with `tmux attach-session -t =<session>`.
- Windows process-backed AO sessions attach through the AO named-pipe terminal protocol when metadata exposes a `pipePath`.
- Terminal websocket URLs include both the session id and project id, so duplicate session ids across projects still attach to the right runtime.

The browser terminal attachment is separate from the underlying AO runtime. Browser reconnects may recreate the attach process, but they should not kill the AO worker or orchestrator session. If there are no active AO workers, the dashboard shows an empty state instead of demo sessions while still exposing the project orchestrator when AO metadata reports one.

Zellij is the preferred durable-session runtime. tmux support exists as compatibility for existing AO metadata that still reports `runtimeName: "tmux"`.

    const key = assignment.slice(0, separatorIndex).trim();
    const value = assignment.slice(separatorIndex + 1).trim();
    if (!key) {
      continue;
    }

    values[key] = unquoteEnvValue(value);
  }

  return values;
}

export function firstNonEmpty(...values) {
  return values.find((value) => value !== undefined && value !== '') ?? '';
}

export function parsePort(name, value, fallback) {
  if (value === undefined || value === '') {
    return fallback;
  }

  const port = Number(value);
  if (!Number.isInteger(port) || port <= 0 || port > 65_535) {
    throw new UsageError(`${name} must be an integer port between 1 and 65535.`);
  }

  return port;
}

function unquoteEnvValue(value) {
  if (
    (value.startsWith('"') && value.endsWith('"')) ||
    (value.startsWith("'") && value.endsWith("'"))
  ) {
    return value.slice(1, -1);
  }

  return value;
}

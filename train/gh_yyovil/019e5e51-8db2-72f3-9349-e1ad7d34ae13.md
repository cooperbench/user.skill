## My request for Codex:
how to set border radius to be 0 using tailwindcss

> AGENT

Use Tailwind’s `rounded-none` class:

```tsx
<div className="rounded-none border">
  ...
</div>
```

For specific corners/sides:

```tsx
<div className="rounded-t-none" />   // top corners
<div className="rounded-l-none" />   // left corners
<div className="rounded-tr-none" />  // top-right only
```

So in your component, replace any `rounded`, `rounded-md`, `rounded-lg`, etc. with `rounded-none`.

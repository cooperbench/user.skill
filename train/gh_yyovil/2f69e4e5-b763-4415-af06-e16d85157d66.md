## BUG ANALYSIS: Ignored Agent Selection in `ao start --interactive`

### Summary
When using `ao start --interactive`, selecting OpenAI Codex (or any non-default agent) for the orchestrator still launches Claude Code (the default agent). The interactive prompt's agent selection is being ignored.

### Root Cause

The bug is in the **fallback logic for orchestrator agent selection** in `/packages/core/src/agent-selection.ts`.

Looking at lines 41-49:

```typescript
const agentName = persistedAgent
```

**For orchestrator role, the parameter `spawnAgentOverride` is NOT used.** The function has a `spawnAgentOverride` parameter (line 33), which is correctly used for the worker role (line 44), but completely ignored for the orchestrator role (line 49).

The config IS being updated properly in the YAML file (step 1), and the config IS being reloaded (step 1), and the config IS being passed to the session manager (step 2).

The actual fallback should work because `project.orchestrator.agent` is set. Unless there's an issue with how the config is being cached or not properly passed through.

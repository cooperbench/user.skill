`★ Insight ─────────────────────────────────────`

**`setTexture`가 모바일에서 프레임 드롭을 유발하는 이유:**

1. `setTexture`를 호출하면 Phaser WebGL 배치 렌더러가 텍스처 변경을 감지하고, UV 데이터를 갱신하고, 스프라이트를 dirty로 마킹합니다 — **같은 텍스처여도 매번 이 작업을 수행**합니다.

2. 터치 중에는 매 프레임마다 `setTexture('left')` 또는 `setTexture('right')`가 호출됩니다. PC 키보드도 마찬가지지만, 모바일 GPU/CPU는 이 반복 작업에 훨씬 민감합니다.

`★ Insight ─────────────────────────────────────`

**핵심 원인: `fps.target: 60` + `smoothStep: true`의 조합**

1. `smoothStep: true`는 프레임 delta를 지수 이동 평균(EMA)으로 스무딩합니다. 모바일에서 터치 중 프레임 타이밍이 불규칙해지면(20ms → 13ms → 25ms → 11ms), 스무딩된 delta가 실제 delta와 **점점 괴리**됩니다.

2. 이 delta 드리프트가 물리 엔진에 전달되면, 똥의 이동 거리가 실제 경과 시간과 불일치 → **시각적으로 빨라졌다 느려졌다** 보입니다.

3. `fixedStep: true`는 interpolation(보간) 없이 물리를 고정 간격으로 돌리므로, 프레임 드롭 시 "0 이동 → 2배 점프"로 오히려 스터터가 **악화**됩니다.

**해결책**: fps 제한과 smoothStep을 제거하고, 네이티브 리프레시 레이트에서 raw delta로 동작하게 변경합니다.

- `poops / goldPoops / diamondPoops / topazPoops / rainbowPoops` — 각 그룹 (children 조회, 필터링 등)
- `scene: Phaser.Scene` — Phaser Scene (time, tweens, add, cameras, physics 접근)

#### 메서드:
- `updateScore(amount)` — 점수 추가 (건너뛰기 방지 체크 포함)
- `spawnGoldPoop() / spawnDiamondPoop() / spawnTopazPoop() / spawnRainbowPoop()` — 특수 똥 생성
- `collectGoldPoop(poop) / ... / collectRainbowPoop(poop)` — 특수 똥 수집 처리 (점수 += 기본값 + 보너스, 텍스트 표시)

**중요**: API를 통해 능력이 게임 로직을 **직접 조정**하는 구조입니다. 따라서 능력 코드가 게임 밸런스를 강력하게 영향을 미칩니다.

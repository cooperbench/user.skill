`★ Insight ─────────────────────────────────────`
**추적 방식 정리**: `collectBonusTotal`은 특수똥 수집 시마다 `ability.onCollectSpecial(type) + synergy.collectBonus`를 누적하는 구조라, 각성 단계에 따라 값이 달라지는 Maehwa ★2+도 자동으로 반영됨. `onCollectSpecial`이 반환하는 값 자체가 각성 레벨에 따라 바뀌기 때문.
`─────────────────────────────────────────────────`

전수 조사 결과입니다:

| 점수 소스 | 각성/맵 영향 | 추적 상태 |
|---|---|---|
| 금똥/다이아/토파즈/무지개 기본점수 | ✗ | ✅ `goldCollected * 20` 등 서버 계산 |
| R급 수집 +1 | ✗ | ✅ `collectBonusTotal` |
| 광부 수집 +5 | ✗ | ✅ `collectBonusTotal` |
| 매화 ★2+ 수집 +5 | **각성 ★2+** | ✅ `collectBonusTotal` (반환값이 각성에 따라 0 또는 5) |
| 시너지 collectBonus +2 | **맵-캐릭터 조합** | ✅ `collectBonusTotal` |
| 아카이브 tick 배율 ×1.1 | ✗ | ✅ `abilityBonusTotal` (이번 수정) |
| 아카이브 마일스톤 +20 | ✗ | ✅ `abilityBonusTotal` (이번 수정) |
| 레거시 tick 배율 ×1.2 (레거시 모드 시) | ✗ | ✅ `abilityBonusTotal` (이번 수정) |
| 레거시 불태우기 +10 | ✗ | ✅ `abilityBonusTotal` (이번 수정) |
| 해커 삭제 / 매화 칼베기 / 센티넬 충전 | ✗ | ➖ 점수 없음, 해당 없음 |
| 글리치 분신 수집 | ✗ | ✅ `goldCollected` 등 동일 경로 처리 |

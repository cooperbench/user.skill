## 분석 결과 - 구미 캐릭터의 "둔갑술" 기본 효과 구현 방법

### 1. Player.ts에서 텍스처를 바꾸는 방법

**YES, 가능합니다.** 
- `setTexture(key: string)` 메서드 사용 가능 (라인 164)
- `setFrame(frameKey: string)` 는 사용하지 않음 (Player.ts는 텍스처만 사용, 프레임은 미사용)

### 2. 플레이어의 현재 사용 중인 텍스처 키

플레이어는 **캐릭터별로 다른 텍스처 키**를 사용합니다:

**초기화 시 texturePrefix 파라미터로 결정됨:**
```typescript
new Player(scene, x, y, speed, playerTexturePrefix, width, height)
// texturePrefix 예: 'sentiniel_', 'gumi_', '', 등
```

**디렉션별 텍스처 키 패턴:**
- Front: `${texturePrefix}front` (정지 상태, 기본값)
- Left: `${texturePrefix}left` (좌측 이동)
- Right: `${texturePrefix}right` (우측 이동)

**예시:**
- 구미(gumi_): `gumi_front`, `gumi_left`, `gumi_right`
- 센티넬(sentiniel_): `sentiniel_front`, `sentiniel_left`, `sentiniel_right`
- 기본(chibi): `front`, `left`, `right`

### 3. 플레이어 left/right/front 애니메이션 동작 방식

**setTexture를 사용한 동작:**
- 방향 변경 시에만 `setTexture()` 호출 (라인 164)
- 매 프레임 호출하지 않음 (성능 최적화)
- `currentDir` 캐시로 불필요한 setTexture 호출 방지
- 정지 상태에서는 자동으로 `front`로 복귀

**동작 로직 (update 메서드, 라인 130-166):**
```typescript
// 좌우 입력 감지 → nextDir = 'left' or 'right' 설정
// 멈춤 상태 → nextDir = 'front' 설정
// nextDir !== currentDir일 때만:
this.setTexture(`${this.texturePrefix}${nextDir}`);
this.currentDir = nextDir;
```

### 4. 일반 똥 텍스처 키 목록

**일반 텍스처 (REGULAR_POOP_KEYS):**
- `poop` (기본)
- `poop_glasses`
- `poop_sunglass`
- `poop_sunglass2`
- `poop_smile`

**크리스마스 시즌 추가 텍스처 (CHRISTMAS_POOP_KEYS):**
- `xmas_poop_ribbon`
- `xmas_poop_nose`
- `xmas_poop_santa`
- `xmas_poop_rudolf`
- `xmas_poop_beard`

> 게임 시작 시 `isChristmasSeason()` 확인하여 AVAILABLE_TEXTURES 배열 결정

### 5. `onHitPoop`에서 `return true`의 효과

**YES, 게임오버가 완전히 방지됩니다.**

SentinelAbility.ts의 `onHitPoop` 메서드:
```typescript
override onHitPoop(api: GameSceneAPI): boolean {
  if (this.shieldCount > 0) {
    this.shieldCount--;
    // 이펙트 처리...
    return true;  // <-- 게임오버 방지
  }
  return false;
}
```

**return true의 의미:**
- 센티넬의 보호막이 피격을 "흡수"했음을 나타냄
- GameScene에서 이 반환값으로 게임 오버 로직을 스킵
- 같은 프레임에 여러 ability의 `onHitPoop`이 호출될 때, 하나라도 true 반환하면 게임오버 방지

### 6. 변신 중 플레이어를 반투명하게 만드는 방법

**YES, `setAlpha()` 메서드 사용 가능:**

```typescript
// 반투명 (50% 투명도)
player.setAlpha(0.5);

// 완전 투명 (숨김)
player.setAlpha(0);

// 원래대로 복구
player.setAlpha(1);
```

**Player.ts에서 이미 사용 중인 예시:**
- 무적 효과: `setTint(0x00ffff)` (색상 처리)
- 정의되지 않은 효과 해제: `clearTint()`
- `setAlpha()` 패턴 자체는 Phaser Sprite의 기본 메서드이므로 사용 가능

`★ Insight ─────────────────────────────────────`
- `zapNearbyPoops()` 내부 `targets.length`에 이미 제거 수가 계산되어 있음 (198~209번 라인)
- 현재는 이 값을 반환하지 않고 시각 효과만 재생 — 카운트 추적은 구조 변경 없이 `return targets.length` 추가만으로 가능
- 누적 카운트(총 제거 수)는 클래스 프로퍼티 하나면 충분, API 노출 없이 내부에서 관리 가능
`─────────────────────────────────────────────────`

현재 상태를 정리하면:

**가능은 합니다.** `zapNearbyPoops()` 안에서 `targets.length`로 제거된 똥 수를 이미 알고 있는데, 지금은 그냥 버려집니다 (`198~209번 라인`).

어떻게 활용할지에 따라 구현 방법이 달라집니다:

| 목적 | 방법 |
|------|------|
| 보호막 발동 시 "×3개 제거" 팝업 | `zapNearbyPoops` 반환값 → 플로팅 텍스트 |
| 게임 결과 화면에 누적 제거 수 표시 | `SentinelAbility` 내부 카운터 필드 추가 + `GameSceneAPI`로 노출 |
| 제거 수에 따라 보너스 점수 | 반환값 × 단가로 `api.addScore()` 호출 |

어떤 방향으로 쓰시려는 건가요? 방향에 따라 최소한의 코드 변경으로 구현할 수 있습니다.

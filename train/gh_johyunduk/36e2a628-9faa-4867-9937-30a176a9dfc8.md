`★ Insight ─────────────────────────────────────`
**`smoothStep: true` + `fixedStep: false` 조합이 문제입니다.**

1. `smoothStep: true` → Phaser가 프레임 델타를 평균화(smoothing)합니다
2. 모바일 터치 시 프레임이 조금이라도 느려지면 → smoothed delta가 실제보다 작아짐
3. `fixedStep: false` → 물리가 이 줄어든 delta를 그대로 사용 → 똥이 천천히 떨어짐
4. 손을 떼면 → 프레임 복귀 → smoothed delta가 실제보다 커짐 → 똥이 빨라지는 느낌

`fixedStep: true`로 바꾸면 물리 엔진이 **고정 60fps**로 독립 실행되어 렌더링 프레임과 무관하게 일정한 낙하 속도를 유지합니다.

   375→  private burnRandomPoops(api: GameSceneAPI, count: number): void {
   376→    const visible = api.poops.getChildren().filter(
   377→      c => c.active && (c as Phaser.Physics.Arcade.Sprite).y > -10,
   378→    ) as Phaser.Physics.Arcade.Sprite[];
   379→
   380→    if (visible.length === 0) return;
   381→
   382→    // Partial Fisher-Yates: count개만 앞으로 뽑아내고 나머지 순회 생략
   383→    const pool = visible.slice();
   384→    const take = Math.min(count, pool.length);
   385→    for (let i = 0; i < take; i++) {
   386→      const j = i + Math.floor(Math.random() * (pool.length - i));
   387→      [pool[i], pool[j]] = [pool[j], pool[i]];
   388→    }
   389→    const targets = pool.slice(0, take);
   390→
   391→    this.drawFireTrail(
   392→      api.scene,
   393→      api.player.x, api.player.y,
   394→      targets.map(p => ({ x: p.x, y: p.y })),
   395→    );
   396→
   397→    for (const poop of targets) {
   398→      if (!poop.active) continue;
   399→      this.playBurnEffect(api.scene, poop.x, poop.y);
   400→      poop.destroy();
   401→      api.updateScore(10);
   402→    }
   403→  }

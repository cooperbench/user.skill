81	### URL Type Detection Heuristic
82	
83	The detection at §0 uses a simple, deterministic heuristic:
84	
85	| URL Pattern | Classification | Route |
86	|------------|---------------|-------|
87	| `github.com/{owner}/{repo}` | GitHub repo | §1 (standard auto-scope) |
88	| Starts with `/`, `./`, `~/`, or `~` | Local filesystem path | §1 (standard auto-scope) |
89	| `gitlab.com/...`, `bitbucket.org/...`, etc. | Git hosting (future) | §1 (standard auto-scope) |

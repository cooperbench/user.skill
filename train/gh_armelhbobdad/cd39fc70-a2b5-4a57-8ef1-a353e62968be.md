   519→## Tools & Integrations
   520→
   521→### MCP Tools (4 Core — Additive Tier Model)
   522→
   523→Each mode is the previous mode plus one tool. Monotonic capability growth — adding a tool never breaks anything.
   524→
   525→| Mode | Tools | Capability Added |
   526→|------|-------|-----------------|
   527→| **Quick** | `gh_bridge` + `skills_ref` | Source reading + spec validation |
   528→| **Forge** | + `ast_bridge` | Structural truth, T1 confidence, co-import detection |
   529→| **Deep** | + `qmd_bridge` | Knowledge search, temporal provenance, drift detection |
   530→
   531→**`gh_bridge`** — Wraps gh CLI. GitHub source access.
   532→- `list_tree(owner, repo, branch)` → file structure
   533→- `read_file(owner, repo, path)` → file content
   534→- `search_issues(query, repo)` → tacit knowledge mining
   535→- `get_latest_release(owner, repo)` → version/staleness check
   536→- `list_open_prs(repo, label_filter)` → forward intelligence
   537→- `get_changelog(repo, since_version)` → temporal context
   538→- **Required for:** All modes
   539→
   540→**`skills_ref`** — Wraps agentskills.io spec validation.
   541→- `validate_schema(path)` → pass/fail + error list
   542→- `validate_frontmatter(path)` → check required fields
   543→- `check_ecosystem(package_name)` → search if official skill exists (5-second timeout, 24-hour cache, advisory not blocking)
   544→- Spec bundled locally with opt-in update (`setup-forge --update-spec`). 90-day staleness warning.
   545→- **Required for:** All modes
   546→
   547→**`ast_bridge`** — Wraps ast-grep CLI. Structural truth engine.
   548→- `scan_definitions(path, language)` → extract all exports
   549→- `run_rule(yaml_rule, path)` → custom AST queries
   550→- `dump_ast(path, language)` → raw AST for debugging
   551→- `detect_co_imports(path, libraries[])` → integration point detection
   552→- Schema-informed: loads `ast-grep/schemas/{language}_rule.json`
   553→- ast-grep setup: https://ast-grep.github.io/advanced/prompting.html
   554→- **Required for:** Forge and Deep modes
   555→
   556→**`qmd_bridge`** — Wraps QMD (local search engine, already installed).
   557→- `search(query, collection)` → BM25 keyword search (~30ms)
   558→- `vector_search(query, collection)` → semantic search (~2s)
   559→- `deep_search(query, collection)` → full hybrid pipeline (~10s)
   560→- `index_collection(path, name)` → index a repo as QMD collection
   561→- Auto-index current project in `setup-forge`. Additional repos require explicit indexing.
   562→- Always scope queries to specific collection. Cross-collection results require developer confirmation.
   563→- **Required for:** Deep mode
   564→
   565→### Internal Utility
   566→
   567→**`manifest_reader`** — Ecosystem-agnostic dependency detection. Not an MCP tool — internal utility used by workflows.
   568→- `detect_manifests(project_root)` → find dependency files
   569→- `parse_dependencies(manifest_path)` → extract direct dependencies with versions
   570→- `resolve_repo(package_name, ecosystem)` → package name → GitHub URL
   571→
   572→**Supported manifests:**
   573→- **Full support:** `package.json` (Node/JS/TS), `pyproject.toml`/`requirements.txt` (Python), `Cargo.toml` (Rust), `go.mod` (Go)
   574→- **Basic support:** `build.gradle`/`pom.xml` (Java), `Gemfile` (Ruby), `composer.json` (PHP)
   575→- **Planned:** Swift (`Package.swift`), Elixir (`mix.exs`), .NET (`*.csproj`)

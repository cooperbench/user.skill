> DEVELOPER

What's the purpose of the `setTick` function?

> AGENT

It's a workaround for storing the thumbnail cache in refs instead of state. React only re-renders when state or props change. The cache (`cacheRef`) and loading/failed sets are refs — mutations to them don't trigger re-renders. So when a `RenderPage` call resolves and we write to `cacheRef`, nothing would update on screen without an explicit nudge. `setTick` provides that nudge: calling it increments a dummy counter, which causes React to re-render and pick up the new cache contents. The same applies after cache invalidation and after a page fails — any time we mutate a ref and need the component to re-render to reflect it.

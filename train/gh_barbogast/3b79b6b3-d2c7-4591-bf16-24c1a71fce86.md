### 3. **Skip and Rotation Threading Through the System**

**Flow for ExportSplit:**

1. **Frontend (SplitMode/index.tsx):**

   - Converts to plain objects: `Object.fromEntries(rotations)` and `[...skipped]`

   - Delegates to `splitPDF(inPath, splitAfter, skip, rotations, tmpDir)` in pdf.go

3. **PDF Processing (pdf.go - splitPDF function):**
   - **Fast path** (no skip): Applies rotations to whole file first via `applyRotationsToFile()`, then uses pdfcpu's native `SplitByPageNrFile` to split

1. Each file is split into single pages

4. Optional reversal of file B: `slices.Reverse(pagesB)`
5. Interleaving: `interleave(pagesA, pagesB)` alternates pages based on `firstPageInA` flag

**Critical Finding: Page order is ENTIRELY frontend-determined**

# React Timeline Viewer App

## Context
We want a browser-based visualization of `timeline.yaml` — an NLE-style timeline with video playback, using `@xzdarcy/react-timeline-editor` for the timeline UI and a `<video>` element for the rendered output.

## Architecture

```
viewer/                     # new Vite + React + TS app
├── index.html
├── package.json
├── vite.config.ts
├── src/
│   ├── main.tsx
│   ├── App.tsx             # layout: video player + timeline
│   ├── App.css             # dark theme styling
│   └── timeline-data.ts    # parse timeline.yaml → editor data model
```

Vite dev server configured with `server.fs.allow` to serve files from the project root (so `inputs/` and `output/` are accessible as static assets).

## Data flow

1. `timeline.yaml` is loaded at build time (imported as raw text via `?raw`, parsed with `js-yaml`)
2. `timeline-data.ts` maps clips → `TimelineRow[]` + `Record<string, TimelineEffect>`:
   - One row per track ("Video", "Audio")
   - Each clip becomes a `TimelineAction` with `start = clip.at`, `end = clip.at + (to - from) / speed`
3. `App.tsx` renders:
   - `<video>` playing `output/render.mp4`
   - `<Timeline>` from react-timeline-editor
   - Playhead synced: video `timeupdate` → set timeline cursor; timeline cursor drag → video `currentTime`

## Key details

- **Video serving**: Vite's `server.proxy` or `server.fs.allow` to serve `../output/render.mp4` and `../inputs/*`
- **Timeline → video sync**: Use a `timelineState` ref from the Timeline component. On `onCursorDrag`, set `video.currentTime`. On video `timeupdate`, update timeline cursor position.
- **Custom action renderer**: Color-code clips by asset name, show asset label inside each clip
- **Dark theme**: Match typical NLE look (dark background, colored clips)

## Implementation steps

1. **Scaffold app**: `npm create vite@latest viewer -- --template react-ts`
2. **Install deps**: `@xzdarcy/react-timeline-editor`, `js-yaml`, `@types/js-yaml`
3. **Create `vite.config.ts`**: configure `server.fs.allow` to include project root
4. **Create `timeline-data.ts`**: import + parse timeline.yaml, export rows/effects
5. **Create `App.tsx`**: video player + Timeline component with sync logic
6. **Create `App.css`**: dark NLE styling
7. **Test**: `cd viewer && npm run dev`, open in browser

## Fix 2: Fixer file-loop not shared (Mid Elegance, 1 finding)

**Finding:** `review::.::holistic::mid_level_elegance::fixer_file_loop_not_shared::3a214cad`

**Problem:** `fix_unused_vars`, `fix_unused_params`, `fix_debug_logs` each roll their own file-loop (~40-60 lines of boilerplate) instead of using `apply_fixer` from `common.py`.

**Fix:** Adapt each fixer's core logic into a transform function matching `apply_fixer`'s interface: `(lines, file_entries) -> (new_lines, removed_names)`.

### params.py
Currently does in-place line mutations. Wrap in a transform:
```python
def _transform_params(lines, file_entries):
    removed = []
    for entry in file_entries:
        name = _rewrite_unused_param(lines, entry)
        if name:
            removed.append(name)
    return lines, removed  # lines mutated in-place, return as new_lines
```
Then: `return apply_fixer(entries, _transform_params, dry_run=dry_run)`

### vars.py
Multi-step logic. Wrap in a transform with closure for skip_reasons:
```python
skip_reasons: dict[str, int] = defaultdict(int)

def _transform_vars(lines, file_entries):
    lines_to_remove = set()
    inline_removals = defaultdict(set)
    removed_names = []
    for entry in file_entries:
        _handle_unused_entry(entry, lines=lines, lines_to_remove=lines_to_remove,
```

### logs.py
Multi-phase transform (collect removals -> dead vars -> empty blocks):
```python
def _transform_logs(lines, file_entries):
    lines_to_remove = set()
    for e in file_entries:
        start = e["line"] - 1
        if start >= len(lines):
            continue
        end = find_balanced_end(lines, start, track="parens")
        if end is None:
            continue
        for idx in range(start, end + 1):
            lines_to_remove.add(idx)
        _mark_orphaned_comments(lines, start, lines_to_remove)
    dead_vars = _find_dead_log_variables(lines, lines_to_remove)
    lines_to_remove |= dead_vars
    new_lines = collapse_blank_lines(lines, lines_to_remove)
    new_lines = _remove_empty_blocks(new_lines)
    tags = sorted(set(e.get("tag", "") for e in file_entries))
    return new_lines, tags  # tags as removed_names (close enough)
```
Then post-process results to add `log_count` field.

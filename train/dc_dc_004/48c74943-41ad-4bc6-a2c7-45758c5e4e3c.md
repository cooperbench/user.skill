And what will happen when they press both keys at the same time?

> AGENT

Everything shifts by the same delta — including the dragged item. So the map becomes something like `A(15) B(35) C(55) D(75) E(95)`. Then `shrinkOversizedGaps` forces the first item back to 0 and rebuilds left-to-right preserving gaps... which puts everything exactly where it started. It's a no-op. Benign, but potentially confusing if someone does it accidentally. Three options: 1. **Let it be a no-op** — simplest, no extra code, and it's self-evident ("nothing happened, I'll try one key") 2. **Command takes priority** — `if (metaKey) ... else if (altKey)` ordering means Command wins when both are held. Probably the most intuitive since Command is the "primary" modifier on Mac. 3. **Both-keys = move entire timeline** — skip the `shrinkOversizedGaps` first-item-at-0 constraint so the whole timeline actually slides. More complex and probably not useful. I'd go with option 2 — it falls out naturally from `if/else if` ordering, zero extra code.

Thinking about it... not really, at least not one that falls naturally out of the push mechanic. If a "scale timeline" or "expand around item" feature ever feels needed, it can be its own thing later.

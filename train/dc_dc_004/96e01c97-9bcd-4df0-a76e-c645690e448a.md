### 10. `source/media/video/ffmpeg_ops.py`

**`__all__` (line 15):** Added `"video_has_audio"` and `"mux_audio_from_segments"` to exports.

**New function `video_has_audio()` (after line 444):** Uses `ffprobe -select_streams a` to check if a video file contains an audio stream. Returns `True`/`False`. Catches all subprocess and OS errors, returning `False` on failure. Used by `mux_audio_from_segments` to skip videos without audio and to short-circuit when no segments have audio.

**New function `mux_audio_from_segments()` (after `video_has_audio`):** This is the core audio preservation function. Takes a silent stitched video, the list of segment video paths, overlap frame counts, and FPS. Process:

1. **Quick check:** Scans all segment videos for audio streams. If none have audio, returns `None` immediately (no-op for Wan models).
2. **Extract audio per segment:** For each segment video:
   - If it has audio: extracts audio to AAC using ffmpeg. For segments after the first, trims `overlap_frames / fps` seconds from the beginning (matching how the video crossfade removes overlap frames from the start of each segment).
   - If it doesn't have audio: generates a silence track of matching duration using `anullsrc`.
3. **Concatenate:** Writes a concat list file and uses `ffmpeg -f concat` to merge all audio parts into one file.
4. **Mux:** Combines the silent video and merged audio using `ffmpeg -c:v copy -c:a aac -shortest` so the output matches video duration.
5. **Cleanup:** Removes the temp directory on success.

Returns the output path on success, `None` on any failure (allowing the stitch to proceed without audio).

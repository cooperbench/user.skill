# Preview Sequence Pill on Video Lightbox

## Context
When viewing a video segment in the MediaLightbox, there's no way to jump into a sequential preview of surrounding segments. The user wants a visually distinct pill button at top-center (where `AdjacentSegmentNavigation` shows for images — that has a `!isVideo` guard so the space is free for videos). The pill shows prev/current/next video thumbnails and clicking it closes the lightbox and opens `PreviewTogetherDialog` starting from the previous segment.

## Changes

**File:** `src/shared/components/MediaLightbox/types.ts`

Add two optional fields:
```ts
adjacentVideoThumbnails?: {
  prev?: { thumbUrl: string; pairIndex: number };
  current?: { thumbUrl: string; pairIndex: number };
  next?: { thumbUrl: string; pairIndex: number };
};
onOpenPreviewDialog?: (startAtPairIndex: number) => void;
```

### 2. `useSegmentSlotMode.ts` — compute thumbnail data + plumb callback
**File:** `src/tools/travel-between-images/components/ShotImagesEditor/hooks/useSegmentSlotMode.ts`

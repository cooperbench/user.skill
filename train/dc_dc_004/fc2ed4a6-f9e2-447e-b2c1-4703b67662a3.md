# Daily Stats Discord Bot

## Overview
Edge function that queries daily task stats, generates a chart via QuickChart.io, and posts to Discord via webhook. Scheduled daily at 9 AM UTC with pg_cron.

## Components

### 1. Edge Function: `supabase/functions/discord-daily-stats/index.ts`

**Flow:**
1. Query `tasks` joined with `task_types` for **all time**, grouped by day into 3 buckets:
   - **Images generated**: `tool_type = 'image-generation'`
   - **Images edited**: `content_type = 'image' AND tool_type != 'image-generation'`
   - **Videos generated**: `content_type = 'video' AND (category = 'orchestration' OR name IN ('animate_character', 'individual_travel_segment', 'video_enhance'))`
   - Only count `status = 'Complete'`
2. If history > 90 days, aggregate by week for chart readability
3. Build chart config and POST to `https://quickchart.io/chart/create` to get a short image URL
4. Format a Discord embed message with:
   - Title: "Daily Stats — {date}"
   - Fields: yesterday's counts for each category + all-time totals
   - Image: the chart URL (full history trend)
5. POST to Discord webhook URL (env var `DISCORD_STATS_WEBHOOK_URL`)

**Auth:** Called by pg_cron via pg_net — validates service role key from Authorization header.

**Pattern:** Follows existing edge function patterns (serve, createClient, SystemLogger).

### 2. Config update: `supabase/config.toml`

Add:
```toml
[functions.discord-daily-stats]
verify_jwt = false
```

### 3. Migration: pg_cron schedule

```sql
SELECT cron.schedule(
  'discord_daily_stats',
  '0 9 * * *',  -- 9 AM UTC daily
  $$
  SELECT net.http_post(
    url := current_setting('app.settings.supabase_url') || '/functions/v1/discord-daily-stats',
    headers := jsonb_build_object(
      'Content-Type', 'application/json',
      'Authorization', 'Bearer ' || current_setting('app.settings.service_role_key')
    ),
    body := '{}'::jsonb
  );
  $$
);
```

### 4. Environment variable
- `DISCORD_STATS_WEBHOOK_URL` — set via `supabase secrets set DISCORD_STATS_WEBHOOK_URL=https://discord.com/api/webhooks/...`

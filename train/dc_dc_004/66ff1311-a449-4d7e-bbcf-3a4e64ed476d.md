It doesn't really make sense for TypeScript. The TS type system already catches most of what this detector does: - **Phantom reads** — `tsc` errors if you access a key not in the type - **Dead writes** — excess property checks flag keys not in the target type - **Typos** — the compiler catches misspelled property names The one area that *could* add value is **schema drift** — finding similar object literal shapes that should share a type but don't. That's exactly why this detector exists — it's filling the gap that Python's lack of a type system leaves open.

| `audio_duration(path)` | tts.py `audio_duration()` |
| `load_profile(asset_id)` + `get_profile_path()` | view.py profile cache |

| `get_openai_client()` | Key check + client init in view/ingest |

## Each tool gets a standard interface

Every tool exports two functions:
```python
def add_arguments(parser):  # register flags on an argparse parser
def run(args):              # execute with parsed Namespace
```

Plus a standalone `main()` gated on `__name__ == "__main__"` that creates its own parser, calls `add_arguments`, parses, calls `run`. Both paths (`python3 tools/view.py --summary` and `python3 tools/cli.py view --summary`) work identically.

## `cli.py` rewrite

Replace `sys.argv` hacking with proper `argparse` subparsers:
```python
subparsers = parser.add_subparsers(dest="command", required=True)
# For each tool:
from view import add_arguments, run
p = subparsers.add_parser("view", ...)
add_arguments(p)
p.set_defaults(func=run)
# Then: args = parser.parse_args(); args.func(args)
```

Here are the best options for your use case:

**[react-timeline-editor](https://github.com/xzdarcy/react-timeline-editor)** — This is probably the best fit. It's free, MIT-licensed, 699 stars, actively maintained (last release Jan 2026). The data model maps almost directly to your `timeline.yaml`:

```jsx
// Your clips become actions on tracks
const tracks = [
  { id: "video", actions: [{ id: "v1", start: 0, end: 6.36, effectId: "clip" }] },
  { id: "audio", actions: [{ id: "a1", start: 0, end: 6.36, effectId: "clip" }] },
];
```

It gives you draggable/resizable clips on tracks, a playhead, zoom — the core NLE timeline feel. You'd wire it up to an `<video>` element for playback.

**[Remotion](https://www.remotion.dev/docs/building-a-timeline)** — More of a full framework for programmatic video. Overkill if you just want a timeline viewer, but it does React-native video composition. Has a paid [timeline component](https://www.remotion.pro/store/timeline) too.

**[React Video Editor](https://www.reactvideoeditor.com/)** — Polished, but $149/yr commercial license.

**[Twick](https://ncounterspecialist.github.io/twick/)** — Newer SDK with `@twick/timeline` + `@twick/video-editor` packages. Less battle-tested.

My recommendation: **react-timeline-editor** for the timeline UI + a standard `<video>` element for playback. It's the simplest path to a nice-looking visualization of your `timeline.yaml` that you can open in a browser and scrub through.

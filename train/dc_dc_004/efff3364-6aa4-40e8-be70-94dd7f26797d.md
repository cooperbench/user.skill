The `update` function previously performed a direct `supabase.from('users').update({ settings: {...} })` which overwrote the entire `users.settings` JSONB column. This could race with the global settings write queue used by other hooks (e.g., `useToolSettings` writing `user-preferences` or `training-data-helper` settings to the same `users.settings` row), causing one write to silently overwrite the other.

- Serializes all writes (1 in-flight at a time)

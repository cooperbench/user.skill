# Plan: Multi-Language Detector Architecture Refactor

## Context

The decruftify detector system has two languages (TypeScript, Python) but the architecture doesn't cleanly separate language-specific code from shared analysis. This causes: TS leaks in "generic" detectors, duplicated implementations (~530 LOC), a confusing directory structure where 12 TS-specific files are mixed with 10 generic files, and adding a language requires rewriting 6+ detectors.

**Goal**: One clean boundary — `detectors/` is shared algorithms, `lang/X/` is everything language-specific. No language is privileged. Adding a language = adding one directory.

## Three-Layer Architecture

The current code has two kinds of duplication:
1. **Algorithm duplication**: TS and PY each implement complexity, gods, dupes, smells separately (~530 LOC)
2. **Phase boilerplate duplication**: Both languages copy-paste identical finding-normalization code for structural merging, single-use filtering, cycle/orphaned creation, smell grouping (~100 LOC)

The previous plan fixes (1) by genericizing algorithms. This plan also fixes (2) with **three clean layers**:

```
Layer 1: Generic algorithms (detectors/)
  "Given FunctionInfos, find duplicates above threshold"
  "Given ClassInfos + rules, find gods with 2+ violations"
  Pure data-in, data-out. Zero language knowledge.

Layer 2: Shared finding normalization (lang/base.py helpers)
  "Convert structural signal dict → tiered findings"
  "Convert single-use entries → findings with co-located filtering"
  "Convert cycle/orphaned/smell entries → findings"
  These already exist: make_unused_findings, make_dupe_findings.
  We extend the pattern for structural, coupling, smells.

Layer 3: Language orchestration (lang/X/__init__.py)
  "Call MY extractors → generic algorithms → shared helpers"
  "Add MY language-specific detectors on top"
  Thin orchestrators. ~15-25 LOC per phase, not ~80.
```

**The key insight**: `lang/base.py` already has `make_unused_findings` and `make_dupe_findings` — shared helpers that both TS and PY call to avoid duplicating finding-creation boilerplate. We extend this pattern to cover ALL the repeated boilerplate: structural signal merging, single-use filtering, cycle findings, orphaned findings, smell grouping.

## Shared Data Types (`detectors/base.py`)

```python
@dataclass
class FunctionInfo:
    name: str
    params: list[str]
    file: str
    line: int
    end_line: int
    loc: int
    body: str
    normalized: str = ""       # stripped of comments/logs/whitespace
    body_hash: str = ""        # MD5 of normalized (auto-computed)

@dataclass
class ClassInfo:
    name: str
    file: str
    line: int
    loc: int
    methods: list[FunctionInfo] = field(default_factory=list)
    attributes: list[str] = field(default_factory=list)
    base_classes: list[str] = field(default_factory=list)
    metrics: dict[str, int] = field(default_factory=dict)

@dataclass
class ComplexitySignal:
    name: str
    pattern: str | None        # regex (None = uses compute fn)
    weight: int
    threshold: int = 0
    compute: Callable | None = None  # (content, lines) -> (count, label)

@dataclass
class GodRule:
    name: str
    description: str
    extract: Callable          # (ClassInfo) -> int
    threshold: int

@dataclass
class SmellRule:
    id: str
    label: str
    pattern: str
    severity: str
```

## Shared Finding Helpers (`lang/base.py`)

```python

make_unused_findings(entries, stderr_fn) -> list[dict]
make_dupe_findings(entries, stderr_fn) -> list[dict]

# New — structural signal merge (replaces ~20 LOC duplicated in both languages):
def add_structural_signal(structural: dict, file: str, signal: str, detail: dict):
    """Add a signal to the per-file structural dict."""
    f = resolve_path(file)
    structural.setdefault(f, {"signals": [], "detail": {}})
    structural[f]["signals"].append(signal)
    structural[f]["detail"].update(detail)

def merge_structural_signals(structural: dict, stderr_fn) -> list[dict]:
    """Convert structural signal dict → tiered findings.
    3+ signals → T4/high, else T3/medium."""

# New — coupling sub-findings (replaces ~50 LOC duplicated in both languages):
def make_single_use_findings(entries, get_area, *, loc_range=(50, 200),
                              suppress_colocated=True, stderr_fn) -> list[dict]:
    """Filter + normalize single-use entries. Shared LOC range + co-located suppression."""

def make_cycle_findings(cycles, stderr_fn) -> list[dict]:
    """Normalize import cycles → findings."""

def make_orphaned_findings(entries, stderr_fn) -> list[dict]:
    """Normalize orphaned files → findings."""

# New — smell grouping (replaces ~15 LOC duplicated in both languages):
SMELL_TIER_MAP = {"high": 2, "medium": 3, "low": 3}
def make_smell_findings(entries, stderr_fn) -> list[dict]:
    """Group smell entries by file, assign tiers from severity."""
```

## What Each Language Provides (after refactor)

A language config has four parts. Here's Python as an example:

```python
# lang/python/__init__.py

# ── Part 1: Config DATA (~40 LOC) ──────────────────
PY_COMPLEXITY_SIGNALS = [
    ComplexitySignal("imports", r"^(?:import |from )", weight=1, threshold=20),
    ComplexitySignal("many_classes", r"^class\s+\w+", weight=3, threshold=3),
    # ... more signals
]
PY_GOD_RULES = [
    GodRule("methods", "methods", lambda c: len(c.methods), 15),
    GodRule("attributes", "attributes", lambda c: len(c.attributes), 10),
    # ... more rules
]
PY_SMELL_RULES = [SmellRule(...), ...]
PY_ENTRY_PATTERNS = ["__main__.py", "conftest.py", ...]

# ── Part 2: Phase runners (~15-25 LOC each) ────────
def _phase_unused(path, lang):      # Custom (ruff)
    return make_unused_findings(detect_unused(path), _stderr)

def _phase_structural(path, lang):  # Shared helpers + extractors
    structural = {}
    for e in detect_large_files(path, lang.find_files, lang.large_threshold):
        add_structural_signal(structural, e["file"], f"large ({e['loc']} LOC)", {"loc": e["loc"]})
    for e in detect_complexity(path, lang.complexity_signals, lang.find_files, lang.complexity_threshold):
        add_structural_signal(structural, e["file"], f"complexity score {e['score']}", {**e})
    for e in detect_gods(lang.extract_classes(path), lang.god_rules):
        add_structural_signal(structural, e["file"], e["signal_text"], e["detail"])
    results = merge_structural_signals(structural, _stderr)
    results.extend(make_passthrough_findings(
        detect_passthrough(lang.extract_function_params(path), lang.passthrough_pattern), _stderr))
    return results

def _phase_coupling(path, lang):    # Shared helpers
    graph = lang.build_dep_graph(path)
    results = make_single_use_findings(
        detect_single_use(path, graph, barrel_names=lang.barrel_names),
        lang.get_area, stderr_fn=_stderr)
    results.extend(make_cycle_findings(detect_cycles(graph), _stderr))
    results.extend(make_orphaned_findings(
        detect_orphaned(path, graph, extensions=lang.extensions,
                        entry_patterns=lang.entry_patterns, barrel_names=lang.barrel_names), _stderr))
    return results

def _phase_smells(path, lang):      # Shared helper
    return make_smell_findings(detect_line_smells(path, lang.smell_rules, lang.find_files), _stderr)

def _phase_dupes(path, lang):       # Shared helper
    return make_dupe_findings(detect_duplicates(lang.extract_functions(path)), _stderr)

# ── Part 3: Config object (~20 LOC) ────────────────
@register_lang("python")
class PythonConfig(LangConfig):
    def __init__(self):
        super().__init__(
            name="python", extensions=[".py"], ...
            complexity_signals=PY_COMPLEXITY_SIGNALS,
            god_rules=PY_GOD_RULES,
            smell_rules=PY_SMELL_RULES,
            large_threshold=300,
            complexity_threshold=25,
            phases=[
                DetectorPhase("Unused (ruff)", _phase_unused),
                DetectorPhase("Structural", _phase_structural),
                DetectorPhase("Coupling", _phase_coupling),
                DetectorPhase("Smells", _phase_smells),
                DetectorPhase("Dupes", _phase_dupes, slow=True),
            ],
        )
```

**Adding a new language (e.g. Go)**:
1. `lang/go/extractors.py` — `extract_go_functions`, `extract_go_structs` (~200 LOC, genuinely unique parsing)
2. `lang/go/deps.py` — Go import graph builder (~100 LOC)
3. `lang/go/unused.py` — calls `gopls` or similar (~30 LOC)
4. `lang/go/__init__.py` — GoConfig with Go signals/rules/thresholds + thin phase runners (~80 LOC)
5. **Zero changes** to any shared detector or helper

The shared phases (structural, coupling, smells, dupes) work out of the box because Go provides the same extractors + config. Only `_phase_unused` needs a custom implementation (every language has its own unused-detection tool).

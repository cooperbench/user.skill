# Plan: Star Variants in MediaLightbox

## Context
Variants (in the VariantSelector within MediaLightbox) currently have no way to be favorited/starred. Generations have starring via `generations.starred` column + `useToggleGenerationStar()` hook + star button on gallery items. We need the same for variants.

## Changes

### 1. DB Migration
**New file:** `supabase/migrations/YYYYMMDD_add_starred_to_generation_variants.sql`

```sql
ALTER TABLE "generation_variants" ADD COLUMN "starred" boolean DEFAULT false NOT NULL;
CREATE INDEX "idx_generation_variants_starred" ON "generation_variants" USING btree ("starred");
```

Deploy: `npx supabase db push --linked`

### 2. Update Types
- **`src/integrations/supabase/types.ts`** — Manually add `starred: boolean` to Row, `starred?: boolean` to Insert/Update for `generation_variants` (or regenerate types)

### 3. Toggle Mutation Hook
**New file:** `src/shared/hooks/useToggleVariantStar.ts`

Follow `useMarkVariantViewed.ts` pattern:
- `supabase.from('generation_variants').update({ starred }).eq('id', variantId)`
- Optimistic update on `queryKeys.generations.variants(generationId)`
- Rollback on error

### 4. Star Button on VariantCard

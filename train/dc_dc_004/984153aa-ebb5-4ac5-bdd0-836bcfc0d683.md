# Add `uncalled_functions` Detector for Python

## Context

We just manually cleaned up `set_process_runtime_context()` — a function with zero callers that survived a refactor. The existing `dead_function` smell detector only catches **stubs** (body is `pass`/`return None`), not functions with real code that nothing calls. The `orphaned` detector does this analysis at the FILE level (zero importers = orphaned), but no detector does it at the FUNCTION level. This is a mechanical check — provable with a grep — not a judgment call.

## Scope: High-Confidence MVP

Only flag **underscore-prefixed top-level functions** (`_foo`) with zero references across the entire codebase. This is the highest-confidence tier:
- `_private` = explicitly internal, no external API concern
- Top-level only = no method-resolution ambiguity (`obj._process` matching unrelated classes)
- Zero references = not name collisions, not string references — actual AST `Name`/`Attribute` nodes

Skip: public functions, methods, decorated functions, dunders, test functions, entry-point files. These can come in a later iteration.

## Architecture

Follows the exact pattern of `orphaned.py` (engine-level, zero-importers) and `private_imports.py` (Python-specific, cross-file AST analysis).

## Changes

### 1. New detector: `desloppify/languages/python/detectors/uncalled.py`

Two functions:

**`_build_reference_index(files, read_fn) -> set[str]`**
- Walk every Python file's AST
- Collect all `ast.Name.id` and `ast.Attribute.attr` values into a single set
- This is O(files), same cost as other detectors
- Uses `read_file_text` for optional caching

**`detect_uncalled_functions(path, graph, zone_map=None, extract_functions_fn=None) -> (entries, total)`**
- Extract function definitions via `extract_py_functions` (already built)
- Filter to: top-level only (not nested in classes), underscore-prefixed, non-dunder, non-decorated
- For each candidate, check if `func.name` is in the reference index
- Exclude references from the function's own file at its own line (the definition itself doesn't count — but actually `FunctionDef.name` is a string attr, not an `ast.Name` node, so it won't appear in the index anyway)
- Skip files matching entry patterns (`PY_ENTRY_PATTERNS`) and test files
- Skip functions with body ≤ 3 lines (too trivial to flag)
- Return entries shaped like: `{"file": rel_path, "name": func_name, "line": line, "loc": loc}`

```python
    tier=3,
    confidence="high",
    summary=f"Uncalled private function: {entry['name']}() — {entry['loc']} LOC, zero references",

)
```

- `_private_func` referenced via `module._private_func` → NOT detected
- `__dunder__` method → NOT detected
- `public_func` with zero callers → NOT detected (out of scope for MVP)
- Decorated function (`@pytest.fixture def _helper`) → NOT detected
- Function in test file → NOT detected

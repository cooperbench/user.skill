# Plan: Scorecard Badge Image Generation

## Context

After every scan, generate a `scorecard.png` showing the health scores visually. Saved to project root by default (configurable via `.env`). Displayed in README via `![Desloppify Score](scorecard.png)`.

## Design

### Image Layout

```
┌──────────────────────────────────────────────┐
│         (subtle background visual flair)     │
│                                              │
│            Desloppify Score                  │
│                                              │
│          100.0       strict: 98.3            │
│                                              │
│  Dimension          Health    Strict         │
│  ─────────────────────────────────           │
│  Import hygiene     100.0%   100.0%          │
│  File health         92.9%    92.9%          │
│  Coupling           100.0%   100.0%          │
│  Organization        99.5%    99.5%          │
│  Code quality        94.2%    94.2%          │
│  Duplication         99.8%    99.8%          │
│  Dependency health  100.0%   100.0%          │
│                                              │
└──────────────────────────────────────────────┘
```

- "Desloppify Score" title at top
- Main score: large bold, color-coded (green >=90, yellow 70-90, red <70)
- "strict: X" smaller and muted next to main score
- Dimension table: name, health %, strict % — only active dimensions
- Subtle background visual flair (e.g., faint radial gradient or corner accent)
- NO open/total/stats — keep it visually clean
- Dark background, good for READMEs

### Config: `.env` file in project root

```
DESLOPPIFY_BADGE_PATH=scorecard.png
DESLOPPIFY_NO_BADGE=false
```

- Defaults to saving `scorecard.png` in project root
- First scan prints a note: "Scorecard saved to scorecard.png — add to README: `![Desloppify Score](scorecard.png)`"
- `--no-badge` CLI flag or `DESLOPPIFY_NO_BADGE=true` in .env disables

### Files to Change

| File | Change |
|------|--------|
| `desloppify/badge.py` | **NEW** — scorecard image generator (~100 lines) |
| `desloppify/commands/scan.py` | Call `generate_scorecard` at end of `cmd_scan` |
| `desloppify/cli.py` | Add `--no-badge` and `--badge-path` args to scan parser |
| `pyproject.toml` | Add `Pillow>=9.0.0` dependency |

### Implementation

**badge.py**: Pillow-based. `generate_scorecard(state, output_path)` renders the image. Uses system font with fallback. Subtle radial gradient or corner accent for visual flair.

**scan.py**: After `_write_query`, read badge config from .env/CLI args, generate scorecard. Print path on first generation.

**Our repo**: Save scorecard.png in desloppify project root, reference from README.

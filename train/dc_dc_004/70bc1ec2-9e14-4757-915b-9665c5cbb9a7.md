## Data Model (`src/pages/Resources/ArtPicks/data.ts`)

Static placeholder data — a generator function produces ~104 weekly entries:

```ts
interface ArtPickVideo {
  title: string;
  creator: string;
  thumbnailUrl: string | null; // null = placeholder
  videoUrl: string | null;     // null = placeholder
}

interface ArtPickWeek {
  id: string;             // "2025-w02"
  weekOf: string;         // "2025-01-06" (Monday of that week)
  title: string;          // "Week of Jan 6, 2025"
  introText: string;      // placeholder paragraph
  videos: ArtPickVideo[]; // 10 placeholder entries
}
```

`generateWeeks()` creates ~104 entries counting back from the current week. Placeholder video titles like "Community Highlight #1", creators like "Artist Name". All URLs null.

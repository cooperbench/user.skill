**Problem:** `_handle_unused_entry()` mutates 4 parameters (`lines_to_remove`, `inline_removals`, `removed_names`, `skip_reasons`) with no return value.

    inline_removals: dict[int, set[str]]
    removed_name: str | None
    skip_reason: str | None

`_handle_unused_entry()` returns `_EntryAction`. Caller in `_transform` aggregates results. `_record_direct_var_removal()` also returns result instead of mutating.

**Files:** `desloppify/languages/typescript/fixers/vars.py`
**Tests:** `desloppify/languages/typescript/tests/test_ts_fixers.py`
**Risk:** Low-moderate — fixer logic is delicate but well-tested

### Fix 2c: _remove_empty_blocks complexity (#13)

**Problem:** 89-line function with 6 pattern cases, 9 continue statements, nested loops.

**Fix:** Extract each pattern into a handler returning `int | None` (new index if consumed, None to fall through):
```python
def _try_remove_empty_useeffect(lines, i) -> tuple[int, list[str]] | None: ...
def _try_remove_empty_callback(lines, i) -> tuple[int, list[str]] | None: ...
def _try_remove_multiline_callback(lines, i) -> tuple[int, list[str]] | None: ...
def _try_remove_multiline_block(lines, i) -> tuple[int, list[str]] | None: ...
def _try_remove_single_empty_block(lines, i) -> tuple[int, list[str]] | None: ...
```
Main loop becomes: try each handler in order; first non-None result wins.

**Files:** `desloppify/languages/typescript/fixers/logs.py`
**Tests:** `desloppify/languages/typescript/tests/test_ts_fixers.py`
**Risk:** Low-moderate — same as #14

## Step 1: Parse Tree Cache

### Problem
`ts_extract_functions()` and `ts_build_dep_graph()` both call `Path(filepath).read_bytes()` + `parser.parse(source)` for every file. When a generic plugin runs both function extraction and dep graph building in the same scan, every file gets parsed twice.

### Approach
Add a `ParseTreeCache` to the existing `treesitter/` package, following the same scan-scoped pattern as `FileTextCache` in `core/runtime_state.py`.

### `desloppify/languages/framework/treesitter/_cache.py` (new)

```python
"""Scan-scoped tree-sitter parse tree cache."""

class ParseTreeCache:
    """Cache parsed tree-sitter trees during a scan.

    Key: (filepath, grammar_name) -> (source_bytes, parsed_tree)
    Stores source_bytes so normalizer can use them without re-reading.
    """
    _enabled: bool = False
    _trees: dict[tuple[str, str], tuple[bytes, object]]  # (filepath, grammar) -> (source, tree)

    def enable(self):
        self._enabled = True
        self._trees = {}

    def disable(self):
        self._enabled = False
        self._trees = {}

    def get_or_parse(self, filepath: str, parser, grammar: str) -> tuple[bytes, object] | None:
        """Read file and parse, returning (source_bytes, tree). Uses cache if enabled."""
        key = (filepath, grammar)
        if self._enabled and key in self._trees:
            return self._trees[key]

        try:
            source = Path(filepath).read_bytes()
        except (OSError, UnicodeDecodeError):
            return None

        tree = parser.parse(source)
        if self._enabled:
            self._trees[key] = (source, tree)
        return source, tree
```

**Zig** — `@import("utils.zig")`:

```
    (BUILTINIDENTIFIER) @_bi
    (FnCallArguments

            (SuffixExpr
```

## Step 4: JavaScript Plugin

### Why
JavaScript is the most popular language without a desloppify plugin. ESLint is the standard linter with JSON output and auto-fix support. The tree-sitter `"javascript"` grammar is well-supported.

### ESLint JSON format (needs custom parser)
ESLint `--format json` produces a nested per-file structure (like rubocop, not flat):
```json
[{"filePath": "/path/file.js", "messages": [{"ruleId": "no-unused-vars", "line": 3, "message": "..."}]}]
```

### `desloppify/languages/framework/generic.py` — add `parse_eslint`

```python
def parse_eslint(output: str, scan_path: Path) -> list[dict]:
    """Parse ESLint JSON: `[{"filePath": ..., "messages": [...]}]`."""
    entries = []
    try:
        data = json.loads(output)
    except (json.JSONDecodeError, ValueError):
        return entries
    for fobj in data if isinstance(data, list) else []:
        filepath = fobj.get("filePath", "")
        for msg in fobj.get("messages") or []:
            line = msg.get("line", 0)
            message = msg.get("message", "")
            if filepath and message:
                entries.append({"file": str(filepath), "line": int(line), "message": str(message)})
    return entries
```

```python
def resolve_js_import(import_text: str, source_file: str, scan_path: str) -> str | None:
    """Resolve JS/ESM imports to local files."""
    if not import_text.startswith("."):
        return None  # npm package

    base = os.path.dirname(source_file)
    candidate = os.path.normpath(os.path.join(base, import_text))

    # Try extensions: .js, .jsx, .mjs, /index.js, /index.jsx
    for ext in ("", ".js", ".jsx", ".mjs", ".cjs", "/index.js", "/index.jsx"):
        path = candidate + ext
        if os.path.isfile(path):
            return path
    return None
```

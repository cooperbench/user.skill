Use ECS components for state; when the state is genuinely world-scoped, model it as an explicit singleton entity/component and document the allowance. Existing world-attached state is a ratcheted architecture debt tracked by `ratchets/worldStateAttachmentRatchet.test.mjs`. - **Determinism is sacred.** In rules simulation use `world.rand()`, never `Math.random()`.

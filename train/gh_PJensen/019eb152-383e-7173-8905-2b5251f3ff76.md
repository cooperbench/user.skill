This is a distinct bug class: the system becomes slower because time has passed, not because the active workload has grown. That usually means some tick-time structure is accumulating work, state, listeners, entities, closures, allocations, or retained references without being cleared. **Expected behavior**: under a stable workload, tick cost should remain roughly bounded. **Observed behavior**: as tick count increases, tick duration increases in a predictable linear pattern.

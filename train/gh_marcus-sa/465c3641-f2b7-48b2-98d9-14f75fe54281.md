**Root cause:** When `surreal.signin({ username, password })` is called, SurrealDB returns a JWT with an expiration. The SDK stores this as `sessionState.accessToken`. When the WebSocket drops and reconnects, `#restoreSession` → `#applyAuthentication` checks the stored JWT — but if it's expired, there's no refresh token or auth provider callback to fall back to. **Fix:** Pass the `authentication` callback to `connect()` options. The SDK calls this callback on every reconnect to re-authenticate, so root credentials are always re-applied regardless of token expiry. The `namespace` and `database` options on `connect()` also ensure they're restored on reconnect.

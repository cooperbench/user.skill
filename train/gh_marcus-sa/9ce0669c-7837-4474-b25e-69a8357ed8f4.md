What is the difference between a mutex and a semaphore?

> AGENT

**Mutex** — mutual exclusion lock. Binary (locked/unlocked). Only the thread that acquired it can release it. Used to protect a shared resource so exactly one thread accesses it at a time.

**Semaphore** — a counter. Initialized to N. `wait()` decrements (blocks at 0), `signal()` increments. Any thread can signal. Used to limit concurrency to N (e.g., connection pool of 5).

Key differences:

| | Mutex | Semaphore |
|---|---|---|
| Values | 0 or 1 | 0 to N |
| Ownership | Yes — only owner unlocks | No — any thread can signal |
| Purpose | Exclusive access | Rate-limit concurrency |
| Analogy | Bathroom key (one holder) | Parking lot (N spots) |

A binary semaphore (N=1) looks similar to a mutex but lacks ownership — any thread can release it, which makes it unsuitable for protecting critical sections where you need strict lock/unlock pairing.

What is the difference between a mutex and a semaphore?

> AGENT

**Mutex** — mutual exclusion lock. Binary (locked/unlocked). Only the thread that acquired it can release it. Enforces ownership.

**Semaphore** — a counter. Initialized to N, any thread can signal (increment) or wait (decrement). No ownership concept.

Key differences:

| | Mutex | Semaphore |
|---|---|---|
| Values | 0 or 1 | 0 to N |
| Ownership | Yes — only owner unlocks | No — any thread can signal |
| Use case | Protect a single shared resource | Limit concurrent access to N resources |
| Example | One thread writing to a file | Connection pool of 10 DB connections |

A mutex is like a bathroom key — one person takes it, only they return it. A semaphore is like a parking lot with N spots — anyone can enter if spots remain, anyone leaving frees a spot.

> DEVELOPER

does bun test support https://cucumber.io/docs/guides/10-minute-tutorial?lang=javascript ?

> AGENT

No. Bun's built-in test runner (`bun test`) does not support Cucumber/Gherkin `.feature` files. It uses a Jest/Vitest-compatible API (`describe`/`it`/`expect`). Cucumber.js has its own CLI runner (`cucumber-js`) that parses `.feature` files and matches steps. You'd run it separately: ```bash bun --bun npx cucumber-js ``` This uses Bun as the runtime but Cucumber's own test runner, not `bun test`. The two are independent — you can't mix Gherkin scenarios into `bun test` suites. If you want BDD-style acceptance tests that run under `bun test`, the typical approach is to write Given/When/Then as plain functions called from regular `describe`/`it` blocks — no Gherkin parser, but the same structure.

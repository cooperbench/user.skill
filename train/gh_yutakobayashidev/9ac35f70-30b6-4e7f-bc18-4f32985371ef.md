    61→## Use Cases
    62→
    63→- **Library comparison** -- compare downloads, maintenance activity, and dependency count across candidates in one command
    64→- **Maintenance check** -- `last_commit_days`, `commits_30d`, and `issues_closed_30d` reveal whether a project is abandoned, stable, or actively developed
    65→- **Download trends** -- `weekly_downloads` vs `monthly_downloads` (npm, PyPI): `weekly * 4 / monthly > 1` means accelerating adoption
    66→- **License compliance** -- SPDX license identifiers from GitHub, npm, PyPI, crates.io, and Go for quick enterprise checks
    67→- **Supply chain risk** -- `dependencies_count` shows how much a package pulls in; `reverse_dependencies` (crates.io) shows ecosystem penetration
    68→- **Cross-ecosystem evaluation** -- compare equivalent packages across languages (e.g. zod vs pydantic vs serde) using GitHub as the common axis

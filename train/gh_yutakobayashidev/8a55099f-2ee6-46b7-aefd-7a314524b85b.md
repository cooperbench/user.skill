## `dev-tmux` スクリプトの解説 tmuxを使った**マルチプロジェクト開発セッション管理ツール**です。プロジェクトごとに4ペインのウィンドウを作成・管理します。 ### レイアウト ``` ┌───────────┬───────┬───────┐ │ 1: Claude │ 3:srv │ 4:fnt │ ├───────────┤ │ │ │ 2: free │ │ │ └───────────┴───────┴───────┘ ``` - **ペイン1 (左上)**: Claude Code用。起動時に `PANE1_CMD` を実行 - **ペイン2 (左下)**: 汎用シェル。起動時に `PANE2_CMD` を実行 - **ペイン3 (中央)**: サーバー用 (`srv`)。`Option+R` で起動 - **ペイン4 (右)**: フロントエンド用 (`fnt`)。`Option+R` で起動 ### 設定の仕組み `~/.config/dev-tmux/` に `.conf` ファイルを保存します。各confには以下が定義されます: - `PROJECT_DIR` - プロジェクトのルートディレクトリ - `PANE1_CMD` / `PANE2_CMD` - 左側ペインの自動実行コマンド - `PANE3_DIR` / `PANE3_CMD` - サーバーペインのディレクトリとコマンド - `PANE4_DIR` / `PANE4_CMD` - フロントエンドペインのディレクトリとコマンド ### 主なサブコマンド | コマンド | 動作 | |---|---| | `dev` | 全登録プロジェクトをウィンドウとして開く | | `dev <name>` | 特定プロジェクトだけ開く | | `dev add [name] [dir]` | プロジェクト登録（省略時はカレントディレクトリ名を使用） | | `dev config [name]` | 対話的にペイン3,4のコマンド/ディレクトリを設定 | | `dev edit <name>` | confファイルをエディタで直接編集 | | `dev restart <name>` | ペイン3,4のプロセスを停止→再起動 | | `dev rm <name>` | プロジェクト削除（ウィンドウも閉じる） | | `dev ls` | 一覧表示（`▶` が実行中マーク） | ### 設計上のポイント - **セッション管理**: `dev` という単一のtmuxセッション内に、プロジェクトごとのウィンドウを作る構造。既存セッションがあればアタッチ、なければ新規作成 - **tmux内外の判定**: `$TMUX` 変数で判定し、tmux内なら `switch-client`、外なら `attach-session` を使い分けている - **`_esc` 関数**: confファイルへの保存時にバックスラッシュ・ダブルクォート・`$`・バッククォートをエスケープして安全に書き出す - **ペイン3,4は遅延起動**: `create_project_window` ではペイン1,2のみコマンドを自動実行し、3,4は `Option+R` (`dev restart`) での手動起動を想定。ビルドサーバー等を常時起動しないための配慮 - **`resolve_dir`**: サブディレクトリ指定が相対パスなら `PROJECT_DIR` からの相対、絶対パスや`~`始まりならそのまま解決する 典型的な使い方としては、例えばフルスタックプロジェクトで左にClaude Code + シェル、中央でバックエンドサーバー、右でフロントエンドのdev serverを動かす、というワークフローを想定したツールです。

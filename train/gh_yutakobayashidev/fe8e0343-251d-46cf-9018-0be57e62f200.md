   108→## 総合評価
   109→
   110→### repiq が活きるポイント
   111→
   112→- ライブラリ選定で主観でなく数値ベースの回答を組み立てられる
   113→- `commits_30d` / `issues_closed_30d` / `dependencies_count` は GitHub ページをパッと見ただけでは読み取りにくい情報で、差別化になっている
   114→- 1コマンドで GitHub + パッケージレジストリを横断できる
   115→
   116→### 改善の余地
   117→
   118→- **解釈はエージェント任せ**: commits_30d が1なのは「停滞」なのか「安定」なのかは文脈次第。設計思想として正しいが、単体ツールとしての訴求力は弱くなる
   119→- **ライセンス比較の強調**: 企業での採用判断では最重要ファクターの一つ
   120→- **トレンド（時系列変化）の欠如**: 「半年前と比べて DL 数が伸びてるか」がわかると、新興ライブラリの評価精度が上がる
   121→- **PyPI Stats API のレートリミット**: 複数パッケージを短時間に叩くと 429 が出やすい
   122→

   124→
   125→人間が手で使うというより、AI エージェントのツールチェーンに組み込んだときに真価を発揮するツール。MCP サーバー化するとさらに自然に使えるようになる。

### 1. **Providers Implemented**

The repiq codebase has **5 providers**, each implementing the `Provider` interface:

#### **GitHub Provider** (`internal/provider/github/github.go`)
- **Scheme**: `github`
- **Format**: `github:<owner>/<repo>`
- **Metrics** (8 total):
  - `stars`: Star count
  - `forks`: Fork count
  - `open_issues`: Open issue count
  - `contributors`: Number of contributors
  - `release_count`: Total releases
  - `last_commit_days`: Days since last commit
  - `commits_30d`: Commits in last 30 days
  - `issues_closed_30d`: Issues closed in last 30 days
- **Implementation**: Uses go-github library for API calls; parallel fetching with goroutines and mutexes; contributor/release counts via Link header pagination

#### **npm Provider** (`internal/provider/npm/npm.go`)
- **Scheme**: `npm`
- **Format**: `npm:<package>` or `npm:@scope/package`
- **Metrics** (5 total):
  - `weekly_downloads`: Downloads last 7 days
  - `latest_version`: Latest published version
  - `last_publish_days`: Days since last publish
  - `dependencies_count`: Number of runtime dependencies
  - `license`: License identifier
- **Implementation**: Uses npm registry API + npm downloads API; parallel goroutines for metadata, modified date, and weekly downloads

#### **PyPI Provider** (`internal/provider/pypi/pypi.go`)
- **Scheme**: `pypi`
- **Format**: `pypi:<package>`
- **Metrics** (7 total):
  - `weekly_downloads`: Downloads last 7 days
  - `monthly_downloads`: Downloads last 30 days
  - `latest_version`: Latest published version
  - `last_publish_days`: Days since last publish
  - `dependencies_count`: Number of runtime dependencies (excludes extras)
  - `license`: License identifier
  - `requires_python`: Python version requirement (e.g., `>=3.9`)
- **Implementation**: Uses PyPI JSON API + pypistats.org for download stats; parallel goroutines for metadata and downloads

#### **crates.io Provider** (`internal/provider/crates/crates.go`)
- **Scheme**: `crates`
- **Format**: `crates:<crate>`
- **Metrics** (7 total):
  - `downloads`: Total all-time downloads
  - `recent_downloads`: Downloads in last 90 days
  - `latest_version`: Latest stable version (prefers max_stable_version)
  - `last_publish_days`: Days since last publish
  - `dependencies_count`: Number of normal dependencies (excludes optional)
  - `license`: SPDX license identifier
  - `reverse_dependencies`: Number of crates that depend on this one
- **Implementation**: Uses crates.io API with custom User-Agent header; parallel goroutines for dependencies and reverse dependencies counts

#### **Go Modules Provider** (`internal/provider/golang/golang.go`)
- **Scheme**: `go`
- **Format**: `go:<module>` (e.g., `go:golang.org/x/text`)
- **Metrics** (4 total):
  - `latest_version`: Latest version tag
  - `last_publish_days`: Days since last publish
  - `dependencies_count`: Number of direct dependencies
  - `license`: License identifier
- **Implementation**: Uses Go Module Proxy (`proxy.golang.org`) for latest version; deps.dev API for license and dependencies; note: Go doesn't provide public download APIs

func (p *Provider) fetchMonthlyDownloads(ctx context.Context, pkg string) (int, error) {
	encodedPkg := url.PathEscape(pkg)
	u := fmt.Sprintf("%s/downloads/point/last-month/%s", p.downloadsURL, encodedPkg)
	req, err := http.NewRequestWithContext(ctx, "GET", u, nil)
	if err != nil {
		return 0, err
	}
	resp, err := p.client.Do(req)
	if err != nil {
		return 0, err
	}
	defer func() { _ = resp.Body.Close() }()
	if resp.StatusCode != http.StatusOK {
		return 0, fmt.Errorf("npm downloads API: %d %s", resp.StatusCode, http.StatusText(resp.StatusCode))
	}
	var dl struct {
		Downloads int `json:"downloads"`
	}
	if err := json.NewDecoder(resp.Body).Decode(&dl); err != nil {
		return 0, fmt.Errorf("decoding response: %w", err)
	}
	return dl.Downloads, nil
}

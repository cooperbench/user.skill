コマンド自体は `sudo nixos-rebuild switch --flake .#${hostname} |& nom` で、`|&` (stderr も含めてパイプ) を使っているので構文的には正しく見えます。

考えられる原因:

1. **Git tree が dirty** — `flake.nix` が dirty な状態だと、Nix は staged されたファイルだけを評価します。git status を見ると `.direnv/` 配下のファイルが大量に staged されています。これが原因でビルドが想定外に重くなっているか、評価段階で止まっている可能性があります。

2. **`.direnv/` が git に追加されている** — `.direnv/` はキャッシュディレクトリなので、通常は `.gitignore` に入れるべきです。大量のファイルが staged されているのが問題の根本かもしれません。

まず `.direnv/` を unstage して `.gitignore` に追加することをお勧めします:

```bash
git rm -r --cached .direnv/
echo '.direnv/' >> /home/yuta/ghq/github.com/yutakobayashidev/dotnix/.gitignore
```

ただし、`nom` が入力を検出できない件については、`nixos-rebuild` の評価フェーズ（stderr 出力がない段階）で時間がかかっている可能性が高いです。evaluation 中は build ログが出ないため `nom` に何も渡されません。

もう少し待てばビルドが始まって `nom` に出力が流れ始めるかもしれませんが、`.direnv/` の staged ファイルを除去してから再試行する方が確実です。

- `zsh-abbr` プラグインの source を追加（他プラグインより前）

**3. `zsh/config/aliases.zsh`**
- ほとんどの `alias` を `abbr -S -qq`（session abbreviation）に変換
- **aliasのまま残したもの:**
  - `ls`, `ll`, `la`, `lt`, `cat` — コマンド置換系（展開表示が不要）
  - `isv`, `prv`, `brc` — 複雑なクォーティングを含むもの
- **関数のまま残したもの:** `nrn`, `scorecard`

### alias と abbr の違い

| | alias | abbr |
|---|---|---|
| 動作 | サイレントに置換 | 入力時にコマンドラインで展開表示 |
| 学習効果 | なし | 実際のコマンドが見えるので覚えやすい |
| 履歴 | 短縮形で残る | 展開後の実コマンドで残る |

`nix run .#switch` で適用できます。

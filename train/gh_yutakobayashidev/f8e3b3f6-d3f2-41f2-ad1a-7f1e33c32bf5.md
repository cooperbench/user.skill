    53→## Use Cases
    54→
    55→**Compare libraries for the same task**
    56→
    57→```bash
    58→repiq npm:express npm:fastify npm:hono
    59→```
    60→
    61→An agent can compare `weekly_downloads`, `last_commit_days`, and `dependencies_count` to recommend the best fit.
    62→
    63→**Check if a repo is still maintained**
    64→
    65→```bash
    66→repiq github:some-org/some-lib
    67→```
    68→
    69→`last_commit_days: 400` and `issues_closed_30d: 0` tells the agent this project may be abandoned.
    70→
    71→**Cross-ecosystem comparison**
    72→
    73→```bash
    74→repiq npm:zod pypi:pydantic crates:serde
    75→```
    76→
    77→Compare equivalent packages across languages using downloads, dependency count, and license.

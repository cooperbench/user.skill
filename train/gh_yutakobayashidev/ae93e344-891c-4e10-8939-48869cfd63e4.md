porcelainって何？

> AGENT

git のサブコマンドに付ける `--porcelain` フラグのことです。 **意味**: スクリプトやプログラムがパースしやすい、安定したフォーマットで出力するオプション。 git の用語で: - **porcelain**（磁器）= ユーザー向けの高レベルコマンド（`git status`, `git log` など） - **plumbing**（配管）= 内部の低レベルコマンド（`git rev-parse`, `git cat-file` など） `--porcelain` フラグは「porcelain コマンドだけど、出力は plumbing 的に機械可読にしてくれ」という意味です。 ```bash # 通常の出力（人間向け、バージョンで変わりうる） $ git worktree list /home/yuta/repo abc1234 [main] /home/yuta/repo-feature def5678 [feature] # --porcelain（機械向け、フォーマットが安定） $ git worktree list --porcelain worktree /home/yuta/repo HEAD abc1234 branch refs/heads/main worktree /home/yuta/repo-feature HEAD def5678 branch refs/heads/feature ``` `git status --porcelain` も同様で、スクリプトで `git` の出力をパースするときによく使います。gh-poi が `--porcelain` を使っているのは、worktree 一覧を確実にパースするためです。

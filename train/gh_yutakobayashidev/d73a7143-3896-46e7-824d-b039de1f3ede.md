# similarity-ts/rs/py Repository Overview

## What It Is

This is a **high-performance code similarity detection toolset** written in Rust that identifies duplicate functions and similar code patterns across multiple programming languages. It's primarily a **CLI tool** (command-line interface), not a library.

## Core Purpose

The tools detect semantic code similarities using AST-based comparison rather than simple text matching. According to the README, it offers "zero configuration" setup and works across different programming languages with language-specific optimizations.

## Language Support & Maturity Status

**Production Ready:**
- **similarity-ts** (TypeScript/JavaScript) - Most mature and tested

**Beta (not production-tested):**
- **similarity-py** (Python)
- **similarity-rs** (Rust)

**Experimental:**
- similarity-elixir, similarity-generic (Go, Java, C/C++, C#, Ruby), similarity-md, similarity-css

## Installation

Tools are installed via `cargo install` from crates.io:
- `cargo install similarity-ts`
- `cargo install similarity-py`
- `cargo install similarity-rs`

Alternative: build from source by cloning the repository and running `cargo build --release`.

## Implementation Details

- **Written in**: Rust
- **Parsers used**: oxc-parser (TypeScript), tree-sitter (Python/Rust/others)
- **Algorithm**: TSED (Tree Structure Edit Distance) with size penalties
- **Nix packages**: No mention found in the provided content

## Key Features

The tools output VSCode-compatible results, integrate with AI assistants like Claude for refactoring suggestions, and support pre-commit hooks and CI/CD pipelines.

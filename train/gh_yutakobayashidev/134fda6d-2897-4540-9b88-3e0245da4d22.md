> AGENT

このプロジェクトは、**NixOS と macOS の dotfiles（システム設定）を Nix Flake で一元管理するリポジトリ**です。

## 概要

- **Nix Flake** をエントリポイントに、複数マシンのシステム設定・ユーザー環境を宣言的に管理
- **home-manager** で共通のユーザー環境（シェル、エディタ、CLI ツール等）をクロスプラットフォームで統一

## 対応ホスト

| ホスト | OS | アーキテクチャ |
|---|---|---|
| `UM790-Pro` | NixOS | x86_64-linux |
| `Still-Legend-x870` | NixOS-WSL | x86_64-linux |
| `M2-MacBook-Air` | macOS | aarch64-darwin |

## 主な構成要素

- **NixOS**: Niri（タイリングWM）、fcitx5+hazkey（IME）、YubiKey認証、Docker、Tailscale
- **macOS**: Homebrew cask管理、Touch ID sudo、1Password Shell Plugins
- **共通**: zsh、Neovim（Lua設定）、Ghostty、tmux、Git、Claude Code など
- **Overlay**: カスタムパッケージ（polycat、aqua、similarity-ts 等）
- **Agent Skills**: Claude Code 用のスキル定義（`agents/skills/`）

`nix run .#switch` で各ホストに応じた設定が自動的にビルド・適用されます。

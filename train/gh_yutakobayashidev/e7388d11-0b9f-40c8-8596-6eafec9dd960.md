## 調査結果: GitHub Actions Lint ツールの公式CIインストール方法

### 1. actionlint (rhysd/actionlint)

**公式 GitHub Action は存在しない。** rhysd/actionlint 自体はアクションを提供していない。代わりに以下の方法がある。

#### 推奨: suzuki-shunsuke/actionlint-action (サードパーティラッパー)

```yaml
- uses: suzuki-shunsuke/actionlint-action@29e0b7cda52e51a495d15f22759745ef6e19583a # v0.1.1
```

このアクションは内部で:
- `dorny/paths-filter` を使って `.github/workflows/*.yml` の変更を検知
- 変更がある場合のみ `suzuki-shunsuke/actionlint-action-main` を呼び出す
- aqua 経由で actionlint + reviewdog + shellcheck をインストールして実行

**完全なワークフロー例:**

```yaml
name: actionlint
on: pull_request
jobs:
  actionlint:
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    permissions:
      contents: read
      pull-requests: write
    steps:
      - uses: suzuki-shunsuke/actionlint-action@29e0b7cda52e51a495d15f22759745ef6e19583a # v0.1.1
```

**入力パラメータ:**
- `sparse-checkout` (optional): sparse checkout 設定
- `actionlint_options` (optional): actionlint のコマンドラインオプション (例: `-ignore`)

#### 代替: ダウンロードスクリプト (公式推奨の軽量方法)

```yaml
steps:
  - uses: actions/checkout@de0fac2e4500dabe0009e67214ff5f5447ce83dd # v6.0.2
    with:
      persist-credentials: false
  - name: Install actionlint
    run: bash <(curl https://raw.githubusercontent.com/rhysd/actionlint/main/scripts/download-actionlint.bash)
  - name: Run actionlint
    run: ./actionlint
```

**参照:**
- [rhysd/actionlint](https://github.com/rhysd/actionlint) - 最新リリース v1.7.11
- [suzuki-shunsuke/actionlint-action](https://github.com/suzuki-shunsuke/actionlint-action) - v0.1.1
- [actionlint インストールドキュメント](https://github.com/rhysd/actionlint/blob/main/docs/install.md)


**完全なワークフロー例 (バリデーションのみ / push しない):**

```yaml
name: Pinact

jobs:
  pinact:
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    permissions:
      contents: read
    steps:
      - uses: actions/checkout@de0fac2e4500dabe0009e67214ff5f5447ce83dd # v6.0.2
        with:
          persist-credentials: false
      - uses: suzuki-shunsuke/pinact-action@1081f5ad49ac904b7d977784f338145150a32112 # v1.4.0
        with:
          skip_push: "true"
```

**完全なワークフロー例 (自動修正 + コミットpush):**

```yaml
name: Pinact
on: pull_request
jobs:
  pinact:
    runs-on: ubuntu-24.04
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@de0fac2e4500dabe0009e67214ff5f5447ce83dd # v6.0.2
        with:
          persist-credentials: false
      - uses: suzuki-shunsuke/pinact-action@1081f5ad49ac904b7d977784f338145150a32112 # v1.4.0
        with:
          app_id: ${{vars.APP_ID}}
          app_private_key: ${{secrets.APP_PRIVATE_KEY}}
```

**主な入力パラメータ:**
- `skip_push` - `"true"` にするとバリデーションのみ (push しない)。CI で lint として使うならこれ
- `update` - `"true"` でバージョン更新も行う
- `verify` - `"true"` でバージョンアノテーションの検証
- `review` - `"true"` で reviewdog 連携によるPRレビューコメント
- `github_token` / `app_id` + `app_private_key` - 認証方法

**注意:** `${{secrets.GITHUB_TOKEN}}` ではワークフローファイルの更新やワークフロー実行のトリガーができない。GitHub App のインストールアクセストークンが推奨。

**参照:**
- [suzuki-shunsuke/pinact-action](https://github.com/suzuki-shunsuke/pinact-action) - v1.4.0
- [suzuki-shunsuke/pinact](https://github.com/suzuki-shunsuke/pinact) - CLI v3.4.6

```yaml
name: ghalint
```

- `ghalint run` - `.github/workflows/*.ya?ml` を検証
- `ghalint run-action` (alias: `ghalint act`) - `action.yaml` を検証

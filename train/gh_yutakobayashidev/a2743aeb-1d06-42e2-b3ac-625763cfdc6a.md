     2→
     3→PR を作成した後の CI 監視・レビュー対応のワークフロー。
     4→
     5→## 1. CI Watch
     6→
     7→PR 作成直後、CI の完了を待って結果を確認する。
     8→

    11→```

    15→
    16→修正時は最小限の diff に留める。CI を通すためだけの無関係な変更を混ぜない。
    17→
    18→## 2. Review Triage
    19→
    20→レビューコメントの確認を依頼されたら:
    21→
    22→```bash
    23→# レビュースレッド一覧を取得
    24→gh api graphql -f query='
    25→{
    26→  repository(owner: "<OWNER>", name: "<REPO>") {
    27→    pullRequest(number: <NUMBER>) {
    28→      reviewThreads(first: 50) {
    29→        nodes {
    30→          id
    31→          isResolved
    32→          comments(first: 5) {
    33→            nodes { body author { login } }
    34→          }
    35→        }
    36→      }
    37→    }
    38→  }
    39→}'

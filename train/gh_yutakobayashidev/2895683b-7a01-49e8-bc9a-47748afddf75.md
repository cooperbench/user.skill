niri が特殊な理由は、**まだ nixpkgs に公式統合されていない**からです。 ## Hyprland と niri の違い **Hyprland の場合:** ```nix # nixpkgs に含まれているので、これだけでOK programs.hyprland.enable = true; ``` **niri の場合:** ```nix # 外部 flake から読み込む必要がある inputs.niri.url = "github:sodiboo/niri-flake"; # NixOS レベル imports = [ niri.nixosModules.niri ]; # home-manager レベル imports = [ niri.homeModules.niri ]; ``` ## なぜこうなっているか 1. **niri は比較的新しい**: 2023年から開発が始まった新しいウィンドウマネージャー 2. **nixpkgs への統合は時間がかかる**: 安定性やメンテナンス体制が整うまで公式に含まれない 3. **sodiboo/niri-flake が非公式パッケージング**: コミュニティメンテナーが flake として提供 将来的に niri が nixpkgs に統合されれば、Hyprland と同じように `programs.niri.enable = true` だけで使えるようになるはずです。 今は過渡期なので、外部 flake 経由で使う必要があります。

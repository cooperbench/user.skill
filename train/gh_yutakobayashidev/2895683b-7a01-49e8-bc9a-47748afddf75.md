3. **sodiboo/niri-flake が非公式パッケージング**: コミュニティメンテナーが flake として提供

将来的に niri が nixpkgs に統合されれば、Hyprland と同じように `programs.niri.enable = true` だけで使えるようになるはずです。

# Polycat リポジトリについて

## 説明
**Polycat** は、"runcat module for polybar (or waybar) written in C++" です。polybar/waybar用のアニメーション表示モジュールで、CPU負荷に応じて動くキャラクターを表示します。

## ビルド方法
インストールは簡潔です：

```bash
sudo make clean install
```

その後、polybarpの設定ファイルに以下を追加します：
```
[module/polycat]
type = custom/script
exec = <path-to-polycat-executable>
tail = true
```

ウェブページには明示的な依存関係リストはありませんが、以下の点が記載されています：

- Arch Linuxユーザー向けにAURパッケージが利用可能
- C++で開発（言語構成：96.9% C++、3.1% Makefile）

これはポップアップのトグル動作を実現するテクニックです。

## 解説

```bash
bind-key -n M-i if-shell -F '#{==:#{session_name},scratch}' {
  detach-client
} {
  display-popup -d "#{pane_current_path}" -w80% -h80% -E "tmux new-session -A -s scratch"
}
```

**`bind-key -n M-i`** — `Alt+i` でプレフィックスなしに直接発火

**`if-shell -F '#{==:#{session_name},scratch}'`** — 今いるセッションが `scratch` かどうかを判定

- **`scratch` の中にいる場合** → `detach-client` でポップアップを閉じる
- **`scratch` の外にいる場合** → `display-popup` で `scratch` セッションを開く

**`tmux new-session -A -s scratch`** — セッション `scratch` が既にあればアタッチ、なければ新規作成（`-A` がポイント）

## 記事の方法との違い

| | 記事の方法 | このコメントの方法 |
|---|---|---|
| トグル | なし（Escか`C-d`で閉じる） | **同じキーで開閉** |
| プレフィックス | `C-a y` が必要 | `Alt+i` で直接 |
| セッション | ディレクトリごとにハッシュで分離 | `scratch` 1つを共有 |

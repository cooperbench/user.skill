`sharedModules` について: home-manager の設定で `sharedModules` は、そのホストの **全ユーザーに共通で適用される home-manager モジュール** のリストです。

```nix
home-manager = {
  sharedModules = [ ... ];  # 全ユーザー共通のHMモジュール
  users.yuta = { ... };     # ユーザー固有の設定
};
```

`users.yuta.imports` に直接書いても動きますが、`sharedModules` に入れると:
- 将来ユーザーを追加した場合も自動で適用される
- `nix-index-database` のように「モジュールオプションを提供するだけ」のものは `sharedModules` に置くのが慣例

今回のケースでは `agent-skills` も同じパターンで `sharedModules` に入っていたので、それに合わせました。

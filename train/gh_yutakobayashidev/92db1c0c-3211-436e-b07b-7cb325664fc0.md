2つの問題点があります。

## 1. なぜ `flake.nix` に devenv と nix-community がないのか

単純に **同期漏れ** です。`linux/nix.nix` と `darwin/nix.nix` には5つのキャッシュがあるのに、`flake.nix` の `nixConfig` には3つしかありません。

これが本質的な問題で、**役割が重複しています**。

| 設定場所 | 効果 |
|---|---|
| `flake.nix` の `nixConfig` | `nix build .#...` など **flake コマンド実行時** に使われる。このリポジトリを clone した他人にも効く |
| `linux/nix.nix` `darwin/nix.nix` の `nix.settings` | **システム全体の nix.conf** に書き込まれる。全 nix コマンドで常に有効 |

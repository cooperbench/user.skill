## The webhook secret is NOT a Razorpay key
It's **not** an API key from Razorpay's dashboard. It's a **password you invent yourselves** — any random string — that gets put in **two places**:
1. The client types it into Razorpay → Webhooks → "Secret" field

Razorpay uses it to sign each webhook call so your server can verify the request genuinely came from Razorpay and not an attacker faking a "payment done" message.

## So the flow is:
1. **You generate a strong random secret** (e.g. `openssl rand -hex 32`)
2. **Send it to the client securely** (not plain email/WhatsApp ideally — but for this scale, a direct message is acceptable) so they paste it into the webhook "Secret" field
3. **You add the identical value** to Vercel env vars and redeploy

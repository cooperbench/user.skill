Here's what to type in each field, step by step:

**Step 1 — Phone number / ఫోన్ నంబర్**
- The `+91` is already filled in (India country code). Don't change it.
- In the box next to it, type **your own 10-digit mobile number** (the same number you used when you applied for an account).
- Example: `9876543210`
- ⚠️ Don't add `+91` again, don't add spaces, don't add `0` in front. Just 10 digits.

**Step 2 — Activation code / యాక్టివేషన్ కోడ్**
- Type the **activation code the owner sent you** (probably on WhatsApp or SMS).
- It looks like `YFF-` followed by some letters/numbers.
- Example: `YFF-K2847`
- Type it **exactly** as you received it — capital letters, the dash `-`, everything.

**Step 3 — Tap "Activate / యాక్టివేట్ చేయండి"**
- This links your phone number to the account the owner created for you.

**Step 4 — After activation succeeds**
- The page will send you to the **login screen**.
- There, enter the **same phone number** + the **password** the owner gave you (or that you set up).

---

**Quick checklist before tapping Activate:**
- ✅ Phone number = your 10 digits, no `+91`, no spaces
- ✅ Activation code = exactly as sent, including `YFF-` and the dash
- ✅ You haven't already activated this code before (each code works once)

If it says "invalid code," double-check for typos — `0` vs `O`, `1` vs `I` are the usual culprits.

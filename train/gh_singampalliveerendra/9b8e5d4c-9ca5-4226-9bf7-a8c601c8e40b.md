how to see passwords in supabase

> AGENT

You can't see the original passwords — they're stored as one-way **scrypt hashes** in `farmers.password_hash`. That's intentional; even you as the admin can't reverse them. To see what's stored, go to **Supabase Dashboard → Table Editor → farmers** and look at the `password_hash` column. You'll see values like: ``` a3f9b2c1d4e5...:7f8a9b0c1d2e3f4a5b6c7d8e9f0a1b2c... ``` That's `salt:hash` — not the original password. **If a farmer forgets their password**, there's no way to recover it. The fix is to reset it: clear their `password_hash` to `null` in the Table Editor, and when they next log in with any password, the system will accept it and set that as their new password (that's the "first login after migration" path in `src/app/api/auth/login/route.ts:59`). To reset a farmer's password in Supabase SQL editor: ```sql UPDATE farmers SET password_hash = NULL WHERE phone = '9876543210'; ```

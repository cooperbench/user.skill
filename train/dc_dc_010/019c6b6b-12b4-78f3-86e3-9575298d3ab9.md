Scoring is split across 3 layers: detector math, dimension math, and score channels.

**1) Detector math (lowest level)**
- Each detector has a `potential` (denominator: checks/opportunities), and open findings become weighted failures.  
- Lenient counts `open`; strict counts `open + wontfix`.  
- Confidence weights are `high=1.0`, `medium=0.7`, `low=0.3`.  
- Some detectors are file-capped (`smells`, `dict_keys`, `test_coverage`, `security`, `review`, `subjective_review`) so many findings in one file don’t over-penalize.  
- `test_coverage` is special: it uses `loc_weight` (sqrt(LOC), capped), not confidence weight.  
- References: `/user_c042661f/Documents/desloppify/desloppify/scoring.py:37`, `/user_c042661f/Documents/desloppify/desloppify/scoring.py:71`, `/user_c042661f/Documents/desloppify/desloppify/scoring.py:105`, `/user_c042661f/Documents/desloppify/desloppify/detectors/test_coverage.py:77`

**2) Dimension math (middle layer)**
- Mechanical dimensions are fixed:
  - File health (`structural`)
  - Code quality (many detectors)
  - Duplication (`dupes`)
  - Test health (`test_coverage`, `subjective_review`)
  - Security (`security`, `cycles`)
- Dimension score formula:  
  `dimension_score = ((sum_potential - sum_weighted_failures) / sum_potential) * 100`
- References: `/user_c042661f/Documents/desloppify/desloppify/scoring.py:23`, `/user_c042661f/Documents/desloppify/desloppify/scoring.py:173`, `/user_c042661f/Documents/desloppify/desloppify/scoring.py:221`

**3) Score channels (top layer)**
- `overall_score`: lenient + subjective included.  
- `objective_score`: lenient mechanical-only.  
- `strict_score`: strict + subjective included.  
- `verified_strict_score`: strict, but manual `fixed`/`false_positive` are treated as open until scan-verified (`auto_resolved` remains credited).  
- References: `/user_c042661f/Documents/desloppify/desloppify/state_internal/scoring.py:92`, `/user_c042661f/Documents/desloppify/desloppify/state_internal/scoring.py:104`, `/user_c042661f/Documents/desloppify/desloppify/state_internal/scoring.py:131`, `/user_c042661f/Documents/desloppify/desloppify/state_internal/scoring.py:50`, `/user_c042661f/Documents/desloppify/desloppify/state_internal/schema.py:242`

**4) Mechanical vs subjective budget**
- Mechanical dims are sample-dampened: effective weight = tier weight × `min(1, checks/200)`.  
- Subjective dims are not dampened; they’re blended with a fixed budget.  
- Final blend when subjective exists:  
  `overall = mech_avg * 0.75 + subj_avg * 0.25`
- Subjective defaults are 7 per-file dimensions, plus optional holistic dimensions.  
- References: `/user_c042661f/Documents/desloppify/desloppify/scoring.py:42`, `/user_c042661f/Documents/desloppify/desloppify/scoring.py:57`, `/user_c042661f/Documents/desloppify/desloppify/scoring.py:306`, `/user_c042661f/Documents/desloppify/desloppify/review/dimensions.py:318`, `/user_c042661f/Documents/desloppify/desloppify/review/dimensions.py:12`

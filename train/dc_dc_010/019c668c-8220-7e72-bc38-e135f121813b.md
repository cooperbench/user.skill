> AGENT

Cause identified and fixed.

The “Add or manage LoRAs” button was wired to a no-op in join mode:

- In `/user_c042661f/Documents/reigh/src/tools/travel-between-images/components/ShotEditor/hooks/useJoinSegmentsSetup.ts`, `joinLoraManager` had:
  - `isLoraModalOpen: false`
  - `setIsLoraModalOpen: () => {}`
- So clicks were happening, but nothing could open.

I changed it to real stateful modal control in the same file:

- Added `useState` for join LoRA modal open state.
- Wired:
  - `isLoraModalOpen: isJoinLoraModalOpen`
  - `setIsLoraModalOpen: (open) => setIsJoinLoraModalOpen(open)`
- Updated the manager type signature to accept `(open: boolean)`.

Validation:

- `npx tsc --noEmit` passes.

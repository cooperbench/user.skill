# Docker Binary Wrapper Script

## Setup Process

The script renames the original Docker CLI binary and replaces it with a wrapper. During the `cmd_create` function:

```bash
mv -f "${BIN_DIR}/docker" "${BIN_DIR}/docker-cli"
```

The original executable becomes `docker-cli`, then a new wrapper is created at `${BIN_DIR}/docker`.

## Wrapper Implementation

The wrapper script sets environment variables and delegates to the renamed binary:

```bash
#!/bin/bash
export DOCKER_HOST="unix://${DOCKER_SOCKET}"
export DOCKER_CONFIG="${RUNTIME_DIR}/lib/docker"
exec "$(dirname "$0")/docker-cli" "$@"
```

This approach configures the Docker CLI to communicate with the custom socket and use the instance-specific configuration directory without requiring manual environment setup.

## Compose Plugin Installation

Yes, Docker Compose is installed as a plugin. The script downloads the standalone binary and copies it to the CLI plugins directory:

```
${RUNTIME_DIR}/lib/docker/cli-plugins/docker-compose
```

This enables users to invoke `docker compose` commands directly. Docker Buildx is similarly installed as a plugin in the same location.

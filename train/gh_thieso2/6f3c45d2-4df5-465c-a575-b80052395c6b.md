### 3. **Sysbox UID Mapping Configuration**

**Sysbox UID mapping is automatic and per-container.** There's no explicit `/etc/subuid`/`/etc/subgid` configuration in the Sandcastle codebase because:

1. Sysbox automatically allocates UIDs per container from a system-wide pool
2. Sysbox uses Linux user namespaces to map container UID 0 → a random unprivileged host UID (typically offset ~231072+)
3. This is handled entirely by Sysbox at the kernel level

**Relevant comment** (line 50-51 in `entrypoint.sh`):
> "Sysbox assigns a random UID mapping per container, so after a recreate the bind-mounted files appear owned by the previous mapping's offset."

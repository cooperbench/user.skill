> AGENT

Fixed. Here's a summary of what was wrong and what I did:

**Root cause:** `SandboxManager#stop` calls `sandbox.update!(status: "stopped", ssh_port: nil)` to release the port back to the pool, but `ssh_port` had a `NOT NULL` database constraint — so the update failed with `PG::NotNullViolation`.

**Fix:**
- New migration `20260221120000_allow_null_ssh_port.rb` — makes `ssh_port` nullable
- Removed the now-redundant model-level SSH port validation and `assign_ssh_port` callback from `Sandbox` (port assignment already lives exclusively in `SandboxManager.find_free_ssh_port`)
- Updated `schema.rb` accordingly

The migration is already applied to your local DB. It will be baked into the next image on deploy.

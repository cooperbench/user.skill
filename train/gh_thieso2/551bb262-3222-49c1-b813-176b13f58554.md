The GitHub (and Google) login buttons are **conditionally rendered** — they only appear when the `GITHUB_CLIENT_ID` environment variable is set on the server. The entire OAuth section (the "Or continue with" divider and the buttons) is hidden when neither `GITHUB_CLIENT_ID` nor `GOOGLE_CLIENT_ID` is present.

So the demo server at `demo.sandcastle.rocks` simply doesn't have the `GITHUB_CLIENT_ID` and `GITHUB_CLIENT_SECRET` environment variables configured. To fix it, you need to:

1. Create a GitHub OAuth App (Settings → Developer settings → OAuth Apps) with the callback URL `https://demo.sandcastle.rocks/auth/github/callback`
2. Set these env vars on the demo server:
   - `GITHUB_CLIENT_ID`
   - `GITHUB_CLIENT_SECRET`
3. Redeploy or restart the app so the env vars take effect

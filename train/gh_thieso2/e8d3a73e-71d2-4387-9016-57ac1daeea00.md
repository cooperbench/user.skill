### **6. RouteManager Service**

**File:** `/Users/thies/Projects/GitHub/Sandcastle/app/services/route_manager.rb`

This is the core service handling route infrastructure:

**Key Methods:**

1. **`add_route(sandbox:, domain:, port: 8080)`**
   - Validates sandbox is running
   - Creates route record in database
   - Ensures Docker network `sandcastle-web` exists
   - Connects sandbox container to the network
   - Writes Traefik configuration file

2. **`remove_route(route:)`**
   - Deletes route record
   - If routes remain: updates Traefik config
   - If no routes left: deletes config file and disconnects from network

3. **`remove_all_routes(sandbox:)`** & **`suspend_routes(sandbox:)`** & **`reconnect_routes(sandbox:)`**
   - Called during sandbox lifecycle (stop/start/destroy)
   - Suspends routes on stop, reconnects on start, removes on destroy

4. **`sync_all_configs()`**
   - Called periodically (ContainerSyncJob every 5 min)
   - Regenerates all Traefik configs
   - Cleans up stale config files

5. **`write_rails_config(host:)`** & **`write_config(sandbox)`**
   - Generates YAML Traefik dynamic config files
   - Routers and services for each route
   - TLS mode: Let's Encrypt (default) or self-signed
   - Config path: `/data/traefik/dynamic/sandbox-{id}.yml`

**Constants:**
```ruby
DATA_DIR = ENV.fetch("SANDCASTLE_DATA_DIR", "/data")
DYNAMIC_DIR = File.join(DATA_DIR, "traefik", "dynamic")
NETWORK_NAME = "sandcastle-web"
```

**Network Handling:**
- Creates/ensures Docker bridge network `sandcastle-web`
- Connects sandbox container to network so Traefik can reach it
- Uses container's full name (e.g., `username-sandboxname`) as hostname in Traefik config
- Each route proxies to `http://{sandbox.full_name}:{route.port}`

### **Key Architecture Notes**

1. **No single-route-per-sandbox limitation** - Multiple routes per sandbox supported since refactoring to separate `routes` table
2. **Traefik-based routing** - Uses dynamic YAML configs in `/data/traefik/dynamic/`
3. **Docker bridge network** - `sandcastle-web` network allows Traefik to reach sandboxes via DNS
4. **TLS handling** - Automatic via Let's Encrypt (or self-signed if configured)
5. **Sandbox must be running** - Routes can only be added/modified when sandbox status is "running"
6. **Routes suspend on stop** - Prevents routing to stopped containers, reconnect on start
7. **Domain uniqueness** - Global uniqueness constraint prevents domain conflicts across users

- The `docker_chown` self-healing failed because **no busybox image** was available

**Deeper issue:** `DOCKYARD_ROOT="/sandcastle"` equals `SANDCASTLE_HOME="/sandcastle"` in the new dockyard layout. During uninstall, `rm -rf "$DOCKYARD_ROOT"` on line 712 would **delete the entire `/sandcastle` directory including user data**.

**Fixes applied:**

1. **Production hotfix:** `chown -R 220568:220568 /sandcastle/data/users/` + `docker pull busybox:latest`

   - When `DOCKYARD_ROOT == SANDCASTLE_HOME`, only remove dockyard-specific subdirs (`bin/`, `lib/`, `run/`, `log/`) instead of the whole tree

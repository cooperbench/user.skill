how is the network adress for the tailscale network decided?

> AGENT

The network address is decided as follows: 1. **If the network already exists** — the actual subnet is read directly from the existing Docker network (`sc-ts-net-{username}`), so it stays stable across restarts. 2. **If the network doesn't exist yet** — a random `/24` subnet is generated: - Takes the base pool from `DOCKYARD_POOL_BASE` env var (defaults to `10.89.0.0/16`) - Keeps the first two octets fixed (e.g. `10.89`) - Randomizes the third octet (`rand(1..254)`) - Result: `10.89.<random>.0/24` So for example you might get `10.89.142.0/24` or `10.89.37.0/24` — a random `/24` drawn from the `10.89.0.0/16` pool. This replaced the earlier deterministic approach (which was user-ID-based, as noted in the recent commit `03ea177 fix(tailscale): random subnet per install instead of deterministic user-id-based`).

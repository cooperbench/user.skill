> AGENT

Fixed and pushed. **Root cause:** `mise use --global node@lts` installs Node but doesn't automatically populate shims, so `npm` was not found (exit 127). **Fix:** Replace `PATH="/root/.local/share/mise/shims:$PATH" npm install -g ...` with `/opt/sandcastle/bin/mise exec -- npm install -g ...`. The `mise exec` command sets up the PATH to the installed Node directly, without relying on shims being present.

> AGENT

For `deploy:local`, `SANDCASTLE_PRIVATE_NET` is **not set at all** in that task — it's only relevant to the installer, not the local Docker Compose setup.

In the **installer** (`installer/installer.sh.in`), `SANDCASTLE_PRIVATE_NET` is determined like this:

1. **If already set** in the environment: uses that value as-is (`${SANDCASTLE_PRIVATE_NET:-$(pick_private_net)}`)
2. **Otherwise**: calls `pick_private_net()`, which:
   - Inspects existing routes via `ip route` and `ip addr` to find which `10.X.` octets are already in use
   - Shuffles the range 1–254 (using `shuf` or Python fallback)
   - Picks the first `10.{b}.0.0/16` where octet `{b}` isn't already routed
   - Falls back to `10.89.0.0/16` (the old hardcoded default) if nothing else works

So it's **randomized per install** to avoid conflicts with existing network routes on the host — a `/16` from the `10.0.0.0/8` space that's not already in use.

## 💡 Key Findings by Technology

### 🔥 **Firecracker** (AWS Lambda's engine)
- ✅ **Pros:** Best security (hardware isolation), fastest boot (125ms), battle-tested at AWS scale
- ❌ **CRITICAL BLOCKER:** No filesystem sharing (virtio-fs rejected for security reasons)
- ❌ Cannot bind-mount `/data/users/{name}/home` or `/workspace`
- ❌ No hot-plug networking (breaks Tailscale/WeTTY UX)
- ⚠️ High operational complexity (TAP devices, iptables, manual IP allocation)

**Verdict:** Not viable for Sandcastle's architecture

---

### 🔩 **Flintlock** (Liquid Metal project)
- ✅ **Pros:** Higher-level Firecracker API, Kubernetes integration
- ❌ **CRITICAL BLOCKER:** Firecracker can't run inside Docker containers (where Rails lives)
- ❌ Would require moving to bare metal (architectural redesign)
- ⚠️ Community-led after Weaveworks shutdown, inconsistent releases

**Verdict:** Unsuitable, solves problems Sandcastle doesn't have

---

### 🛡️ **gVisor** (Google Cloud Run's engine)
- ✅ **Pros:** Strong isolation, no nested virt needed, OCI-compatible, Google-backed
- ❌ **CRITICAL BLOCKER:** Docker-in-Docker requires tmpfs-only overlay = **ephemeral containers**
- ❌ All Docker container changes lost on restart
- ❌ Breaks persistent workspace model (`/workspace` volumes)
- ⚠️ 10x syscall overhead, I/O degradation

**Verdict:** Not viable due to ephemeral Docker-in-Docker limitation

---

### 📦🖥️ **Kata Containers** (Alibaba, IBM production)
- ✅ **Pros:** OCI drop-in replacement, hardware isolation, multiple hypervisors
- ❌ **CRITICAL BLOCKER:** **2-4x slower Docker builds** (core Sandcastle feature)
- ⚠️ Requires nested virtualization (limits deployment)
- ⚠️ 40-50% I/O degradation on bind mounts
- ⚠️ No native snapshot/restore for VM state

**Verdict:** Performance too poor for Docker-in-Docker use case

---

### 📦 **Docker + Sysbox** (Current solution)
- ✅ **Pros:** Optimized for Docker-in-Docker, near-native performance, standard API, production-proven (2+ years), Docker corporate backing
- ⚠️ **Cons:** Weaker isolation than VMs (but sufficient), moderate installation complexity, kernel dependencies (mitigated with Ubuntu 24.04)
- ✅ **Working well:** SSH, bind mounts, Tailscale, WeTTY, HTTP routing, snapshots

**Verdict:** Best fit for Sandcastle

   179→## Defense in Depth
   180→
   181→Each file key is protected by multiple nested layers. An attacker must break through all layers to access any file content:
   182→
   183→```text
   184→   File Content
   185→     └─ encrypted with ──► fileKey (random, unique per file)
   186→         └─ ECIES-wrapped with ──► User's Public Key
   187→             └─ stored inside ──► Folder Metadata
   188→                 └─ encrypted with ──► folderKey (random, unique per folder)

   190→                         └─ stored on ──► Server (zero-knowledge)
   191→```

   216→### 1. Web3Auth for Key Derivation
   217→
   218→```text

   224→```text
   225→File (AES-256-GCM) → Metadata (AES-256-GCM) → Keys (ECIES)

   227→

   229→
   230→```text
   231→Root IPNS → Folder1 IPNS → Folder2 IPNS (modular sharing-ready)

   239→

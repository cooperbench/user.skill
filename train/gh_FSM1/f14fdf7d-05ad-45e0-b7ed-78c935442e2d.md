ok i am setting up dns entries for sendgrid on cloudflare. should the dns entries have cloudflare proxy mode disabled?

> AGENT

Yes — disable proxy mode (grey cloud / DNS only) for all SendGrid DNS records. SendGrid's domain authentication uses CNAME records for DKIM verification. Receiving mail servers do DNS lookups on these CNAMEs and expect them to resolve directly to SendGrid's servers. If Cloudflare proxy is enabled, the CNAMEs resolve to Cloudflare IPs instead, which breaks DKIM signature validation and your emails will fail authentication or land in spam. Same applies to any SPF-related TXT records — those are pure DNS lookups and aren't HTTP traffic, so the proxy has no purpose there anyway.

> DEVELOPER

and what ttl should be set for the cnames?

> AGENT

Auto (300s) is fine. These records are static — they won't change unless you redo SendGrid domain authentication from scratch.

The `.github/workflows/build-desktop.yml` is created with cross-platform build matrix (macOS ARM64 + Intel, Linux, Windows). Task 2 is a **non-blocking** checkpoint for Ed25519 key setup.

**What you need to do (can be deferred):**

1. Generate keypair: `npx @tauri-apps/cli signer generate -w ~/.tauri/cipherbox.key`
2. Copy PUBLIC KEY into `apps/desktop/src-tauri/tauri.conf.json` replacing `"REPLACE_WITH_ED25519_PUBLIC_KEY"`
3. Add GitHub secrets: `TAURI_SIGNING_PRIVATE_KEY` + `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`
4. Commit updated `tauri.conf.json`

Without this, builds work but update bundles won't have `.sig` files.

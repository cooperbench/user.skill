**I agree with the feedback.** The issues are:

1. **Exact duplication** - Lines 119-125 and 126-132 are identical (4 lines of logic)

3. **Maintenance risk** - Any future fix to Claude parsing needs updating in two places

**The fix is simple:** Remove the explicit `AgentTypeClaudeCode, AgentTypeUnknown, ""` case and let `default` handle it:

```go
switch agentType {
case agent.AgentTypeGemini:

default:
    // Claude format (JSONL) - default for all non-Gemini agent types
    lines, err := transcript.ParseFromBytes(content)
    if err != nil {
        return nil, fmt.Errorf("failed to parse transcript: %w", err)
    }
    return BuildCondensedTranscript(lines), nil
}
```

> AGENT

Two options, from simplest to most proper: **Option 1: Fine-grained PAT (quick)** 1. Go to GitHub > Settings > Developer settings > Personal access tokens > Fine-grained tokens 2. Generate new token: - **Resource owner**: your org (entireio) - **Repository access**: "Only select repositories" — pick the repos that need it - **Permissions**: Contents → Read and write (nothing else) 3.

### Summary
The PR adds validation that the selected AI agent (Claude Code or Gemini CLI) is installed before running `entire enable`. This is a solid UX improvement that prevents confusing failures when hooks try to invoke a missing binary.

### What Works Well
- **Clean interface extension** with idiomatic `(bool, error)` return signature for `IsInstalled()`

- **Mock agent properly updated** to implement the new interface methods

### Issues to Consider

**1. Minor duplicate checking in `findInstalledAgent()`**
The default agent could be checked twice - once explicitly and once when iterating `agent.List()`. Not a bug, just slightly inefficient:
```go
// Default agent checked here...
ag := agent.Default()
// ...and potentially again here if it's in the list
for _, name := range agent.List() {
```

**2. Error message casing**
Go convention is lowercase error messages:
```go
// Current:
return false, fmt.Errorf("IsInstalled failed: %w", err)
// Suggested:
return false, fmt.Errorf("checking installation status: %w", err)
```

**3. Environment-dependent tests**
`TestFindInstalledAgent_ReturnsAgent` has environment-dependent behavior. CI stubs ensure consistency there, but local runs may vary. The test handles this gracefully but a comment explaining the dependency would help.

**4. Weak `IsInstalled()` tests**
The tests only verify no error is returned (`_ = installed`). With CI stubs, you could actually assert `installed == true` in CI environments.

### No Security Concerns
The `exec.LookPath` usage is safe - it only checks PATH existence, doesn't execute anything.

### Recommendation
**Merge as-is.** The suggestions are minor improvements that could be addressed in follow-up work if desired. The core functionality is sound and improves the user experience.

   412→// Returns:
   413→//   - files: list of file paths modified by Claude (from Write/Edit tools)
   414→//   - currentPosition: total number of lines in the file

   417→	if path == "" {

   412→// ChunkTranscript splits a Gemini JSON transcript by distributing messages across chunks.
   413→// Gemini uses JSON format with a {"messages": [...]} structure, so chunking splits
   414→// the messages array while preserving the JSON structure in each chunk.
   415→func (g *GeminiCLIAgent) ChunkTranscript(content []byte, maxSize int) ([][]byte, error) {
   416→	var transcript GeminiTranscript
   417→	if err := json.Unmarshal(content, &transcript); err != nil {
   418→		// Fall back to JSONL chunking if not valid Gemini JSON
   419→		chunks, chunkErr := agent.ChunkJSONL(content, maxSize)
   420→		if chunkErr != nil {
   421→			return nil, fmt.Errorf("failed to chunk as JSONL: %w", chunkErr)
   422→		}
   423→		return chunks, nil
   424→	}
   425→
   426→	if len(transcript.Messages) == 0 {
   427→		return [][]byte{content}, nil
   428→	}
   429→
   430→	var chunks [][]byte
   431→	var currentMessages []GeminiMessage
   432→	currentSize := len(`{"messages":[]}`) // Base JSON structure size
   433→
   434→	for i, msg := range transcript.Messages {
   435→		// Marshal message to get its size
   436→		msgBytes, err := json.Marshal(msg)
   437→		if err != nil {
   438→			logging.Warn(context.Background(), "failed to marshal Gemini message during chunking",
   439→				slog.Int("message_index", i),
   440→				slog.String("error", err.Error()),
   441→			)
   442→			continue
   443→		}
   444→		msgSize := len(msgBytes) + 1 // +1 for comma separator
   445→
   446→		if currentSize+msgSize > maxSize && len(currentMessages) > 0 {
   447→			// Save current chunk
   448→			chunkData, err := json.Marshal(GeminiTranscript{Messages: currentMessages})
   449→			if err != nil {
   450→				return nil, fmt.Errorf("failed to marshal chunk: %w", err)
   451→			}
   452→			chunks = append(chunks, chunkData)
   453→
   454→			// Start new chunk
   455→			currentMessages = nil
   456→			currentSize = len(`{"messages":[]}`)
   457→		}
   458→
   459→		currentMessages = append(currentMessages, msg)
   460→		currentSize += msgSize
   461→	}
   462→
   463→	// Add the last chunk
   464→	if len(currentMessages) > 0 {
   465→		chunkData, err := json.Marshal(GeminiTranscript{Messages: currentMessages})
   466→		if err != nil {
   467→			return nil, fmt.Errorf("failed to marshal final chunk: %w", err)
   468→		}
   469→		chunks = append(chunks, chunkData)
   470→	}
   471→
   472→	// Ensure we created at least one chunk (could be empty if all messages failed to marshal)
   473→	if len(chunks) == 0 {
   474→		return nil, errors.New("failed to create any chunks: all messages failed to marshal")
   475→	}
   476→
   477→	return chunks, nil
   478→}

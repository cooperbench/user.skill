**How Gemini Chunking Works:**
1. **Format:** Gemini uses JSON structure: `{"messages": [...]}`
2. **Strategy:** Splits messages across chunks while preserving JSON structure
3. **Logic:**
   - Parses JSON and calculates size of each message when marshaled
   - Accumulates messages into `currentMessages` array until adding next message would exceed `maxSize`
   - When limit would be exceeded, saves current chunk as `{"messages": [accumulated...]}`
   - Starts new chunk with the message that didn't fit
   - Handles marshaling errors by logging warnings but continuing (line 391)

4. **Reassembly:** Unmarshal each chunk, concatenate `Messages` arrays, remarshal as single JSON

**Example:**
```
Original: {"messages": [{msg1}, {msg2}, {msg3}, {msg4}]}
Chunk 1:  {"messages": [{msg1}, {msg2}]}  (if this fits under maxSize)
Chunk 2:  {"messages": [{msg3}, {msg4}]}
```

### 8. Workflow: How Chunking Happens

1. **User commits or creates checkpoint** with large session transcript
2. **Checkpoint storage code calls** `agent.ChunkTranscript(transcriptBytes, agentType)`
3. **Routing logic:**
   - If `agentType` is empty, calls `agent.DetectAgentTypeFromContent()` to auto-detect
   - Looks up agent (GeminiCLIAgent, ClaudeCodeAgent) by type
   - If agent implements `TranscriptChunker`, uses agent-specific chunking
   - Otherwise falls back to `ChunkJSONL()` (default JSONL line-based)
4. **Agent-specific chunking:**
   - **Gemini:** Splits messages array across chunks
   - **Claude Code:** Delegates to JSONL (line-based)
5. **Files written to git:**
   - Chunk 0: `a3/b2c4d5e6f7/full.jsonl` (or `.json` for Gemini)
   - Chunk 1: `a3/b2c4d5e6f7/full.jsonl.001`
   - Chunk 2: `a3/b2c4d5e6f7/full.jsonl.002`
   - etc.
6. **On read:** Chunks are automatically reassembled using same agent-specific logic

   373→		if chunkErr != nil {
   374→			return nil, fmt.Errorf("failed to chunk as JSONL: %w", chunkErr)
   375→		}

   377→	}
   378→
   379→	if len(transcript.Messages) == 0 {
   380→		return [][]byte{content}, nil
   381→	}
   382→
   383→	var chunks [][]byte
   384→	var currentMessages []GeminiMessage
   385→	currentSize := len(`{"messages":[]}`) // Base JSON structure size
   386→

   388→		// Marshal message to get its size

> DEVELOPER

how can I test these forms while still in a branch on GitHub?

> AGENT

Push the branch and navigate to the issue template URL with a `template` query param: ``` https://github.com/entireio/cli/issues/new?template=bug_report.yml ``` ``` https://github.com/entireio/cli/issues/new?template=feature_request.yml ``` The catch: **GitHub only loads issue templates from the default branch** (usually `main`). Templates on a feature branch won't render through the normal UI. ### Workarounds 1. **Temporarily change the default branch** — In repo Settings > General > Default branch, switch it to your feature branch, test the forms, then switch back. Quickest way to test. 2. **Push to a fork** — Fork the repo, push the branch as `main` on the fork, and test there. No risk to the real repo. 3. **YAML validation only** — If you just want to check for syntax errors without visual preview, GitHub will show YAML parse errors when you push. You can also validate locally: ```bash python3 -c "import yaml; yaml.safe_load(open('.github/ISSUE_TEMPLATE/bug_report.yml'))" ``` Option 2 (fork) is the safest for a shared repo.

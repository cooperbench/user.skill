   243→
   244→The checkpoint ID is the **stable identifier** that links user commits to metadata across branches.
   245→
   246→**Format:** 12-hex-character random ID (e.g., `a3b2c4d5e6f7`)

   248→**Generation:**

   253→

   257→   - Manual-commit: Added by `prepare-commit-msg` hook (user can remove)

   269→

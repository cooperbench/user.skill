Nimbus is a checkpoint-aware code review product for developers using the “Entire” workflow. The core idea is: take a known commit/checkpoint state, build an isolated workspace from it, optionally deploy/validate it in Cloudflare sandbox infrastructure, then run a non-mutating AI review that produces a structured report and can post findings back to a PR. That comes through clearly in the root docs and architecture notes at [README.md](/Users/nickdejesus/Code/nimbus/README.md), [docs/getting-started.md](/Users/nickdejesus/Code/nimbus/docs/getting-started.md), and [docs/architecture/overview.md](/Users/nickdejesus/Code/nimbus/docs/architecture/overview.md).

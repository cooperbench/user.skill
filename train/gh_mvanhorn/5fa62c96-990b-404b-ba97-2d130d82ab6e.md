can you do me a summary for the changes in the branch? maybe 4-6 sentences

> AGENT

This refactor changes how OpenCode transcript handling works. Previously, the TypeScript plugin wrote JSONL transcripts to temp files and passed the file paths to hooks. Now, the plugin only sends the session ID, and the Go hook handler calls `opencode export` directly to fetch the native JSON format. This eliminates race conditions between plugin shutdown and the hook reading the transcript, and ensures full data fidelity by using OpenCode's own export format. The change removed ~150 lines from the TypeScript plugin while adding proper temp file cleanup to the `entire clean` command. Integration tests were updated to use the new JSON format with a test seam that allows mock data injection.

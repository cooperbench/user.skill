# Plan: Auto-delete stale session state files

## Context

Session state files (`.git/entire-sessions/<session-id>.json`) accumulate over time. Sessions that ended more than 24 hours ago are no longer useful but remain on disk. This change makes stale sessions invisible to callers by deleting them transparently during load/list operations.

## Approach

Add an `IsStale()` method to `session.State` and integrate cleanup into the two code paths that read session state files: `StateStore.List()` and `strategy.LoadSessionState()`.

### 1. Add staleness logic to `session/state.go`

- Add constant `StaleSessionThreshold = 24 * time.Hour`
- Add method `(s *State) IsStale() bool` — returns true when `EndedAt != nil && time.Since(*EndedAt) > StaleSessionThreshold`
- Unconditional: no check on `StepCount` or condensation status

### 2. Cleanup in `StateStore.List()` (`session/state.go`)

After loading each state via `s.Load()`, check `state.IsStale()`. If stale:
- Call `s.Clear(ctx, sessionID)` to delete the file
- Log the deletion via `logging.Info`
- Skip the entry (don't append to results)

This makes `strategy.ListSessionStates()` and `strategy.FindMostRecentSession()` automatically exclude stale sessions.

### 3. Cleanup in `strategy.LoadSessionState()` (`strategy/session_state.go`)

After loading and unmarshalling, check `state.IsStale()`. If stale:
- Call `ClearSessionState(sessionID)` to delete the file
- Log the deletion
- Return `(nil, nil)` — same as "not found"

This makes all direct `LoadSessionState()` callers (lifecycle hooks, debug, reset, etc.) see stale sessions as non-existent.

### 4. Tests

- **`session/state_test.go`**: Test `IsStale()` with various `EndedAt` values (nil, recent, >24h)
- **`session/state_test.go`**: Test `StateStore.List()` — create a stale session file, call `List()`, verify it's excluded and the file is deleted from disk
- **`strategy/session_state_test.go`**: Test `LoadSessionState()` — create a stale session file, call `LoadSessionState()`, verify `(nil, nil)` returned and file deleted

   120→// FindMostRecentSession returns the session ID of the most recently interacted session
   121→// (by LastInteractionTime) in the current worktree. Returns empty string if no sessions exist.
   122→// Scoping to the current worktree prevents cross-worktree pollution in log routing.
   123→// Falls back to unfiltered search if the worktree path can't be determined.
   124→func FindMostRecentSession() string {
   125→	states, err := ListSessionStates()
   126→	if err != nil || len(states) == 0 {
   127→		return ""
   128→	}
   129→
   130→	// Scope to current worktree to prevent cross-worktree pollution.
   131→	worktreePath, wpErr := GetWorktreePath()
   132→	if wpErr == nil && worktreePath != "" {
   133→		var filtered []*SessionState
   134→		for _, s := range states {
   135→			if s.WorktreePath == worktreePath {
   136→				filtered = append(filtered, s)
   137→			}
   138→		}
   139→		if len(filtered) > 0 {
   140→			states = filtered
   141→		}
   142→		// If no sessions match the worktree, fall back to all sessions
   143→	}
   144→
   145→	var best *SessionState
   146→	for _, s := range states {
   147→		if s.LastInteractionTime == nil {
   148→			continue
   149→		}
   150→		if best == nil || s.LastInteractionTime.After(*best.LastInteractionTime) {
   151→			best = s
   152→		}
   153→	}
   154→	if best != nil {
   155→		return best.SessionID
   156→	}
   157→
   158→	// Fallback: return most recently started session
   159→	for _, s := range states {
   160→		if best == nil || s.StartedAt.After(best.StartedAt) {
   161→			best = s
   162→		}
   163→	}
   164→	if best != nil {
   165→		return best.SessionID
   166→	}
   167→	return ""

   170→// TransitionAndLog runs a session phase transition, applies actions via the
   171→// handler, and logs the transition. Returns the first handler error from
   172→// ApplyTransition (if any) so callers can surface it. The error is also
   173→// logged internally for diagnostics.
   174→// This is the single entry point for all state machine transitions to ensure
   175→// consistent logging of phase changes.
   176→func TransitionAndLog(state *SessionState, event session.Event, ctx session.TransitionContext, handler session.ActionHandler) error {
   177→	oldPhase := state.Phase
   178→	result := session.Transition(oldPhase, event, ctx)
   179→	logCtx := logging.WithComponent(context.Background(), "session")
   180→
   181→	handlerErr := session.ApplyTransition(state, result, handler)
   182→	if handlerErr != nil {
   183→		logging.Error(logCtx, "action handler error during transition",
   184→			slog.String("session_id", state.SessionID),
   185→			slog.String("event", event.String()),
   186→			slog.Any("error", handlerErr),
   187→		)
   188→	}
   189→
   190→	if result.NewPhase != oldPhase {
   191→		logging.Info(logCtx, "phase transition",
   192→			slog.String("session_id", state.SessionID),
   193→			slog.String("event", event.String()),
   194→			slog.String("from", string(oldPhase)),
   195→			slog.String("to", string(result.NewPhase)),
   196→		)
   197→	} else {
   198→		logging.Debug(logCtx, "phase unchanged",
   199→			slog.String("session_id", state.SessionID),
   200→			slog.String("event", event.String()),
   201→			slog.String("phase", string(result.NewPhase)),
   202→			slog.Any("result", result),
   203→		)
   204→	}
   205→
   206→	if handlerErr != nil {
   207→		return fmt.Errorf("transition %s: %w", event, handlerErr)
   208→	}
   209→	return nil
   210→}

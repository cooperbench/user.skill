# Plan: Add `entire trail enable` / `entire trail disable`

## Context

The `entire trail` command was just implemented but lacks enable/disable subcommands. Users need a way to opt out of trail auto-creation and pushing. The feature should be enabled by default but togglable via settings.

## Approach

Store a `trails` boolean in `StrategyOptions` (same pattern as `push_sessions`). Default: enabled (true). When disabled, skip auto-create on session start and skip pushing the trails branch.

## Implementation Steps

### 1. Add settings convenience functions
**File**: `cmd/entire/cli/settings/settings.go`

Add `IsTrailsDisabled()` method on `*EntireSettings` — follows the `IsPushSessionsDisabled()` pattern exactly:
```go
func (s *EntireSettings) IsTrailsDisabled() bool {
    // Check StrategyOptions["trails"] — false means disabled
    // Missing/nil means enabled (default)
}
```

Add package-level convenience:
```go
func IsTrailsDisabled() bool {
    s, err := Load()
    if err != nil { return false }
    return s.IsTrailsDisabled()
}
```

### 2. Add `enable` and `disable` subcommands
**File**: `cmd/entire/cli/trail_cmd.go`

Add to `newTrailCmd()`:
```
cmd.AddCommand(newTrailEnableCmd())
cmd.AddCommand(newTrailDisableCmd())
```

`entire trail enable` — sets `strategy_options.trails = true` (or removes the key since true is default). Saves to project settings.

`entire trail disable` — sets `strategy_options.trails = false`. Saves to local settings by default, `--project` flag for project settings.

Follow the pattern from `setup.go` `runEnable`/`runDisable` — load settings, modify `StrategyOptions`, save.

### 3. Guard auto-create with settings check
**File**: `cmd/entire/cli/lifecycle.go` — `autoCreateTrailOnTurnStart()`

Where `isTrailsDisabled()` loads settings (same pattern as `isPushSessionsDisabled()`).

   285→	fmt.Fprintf(os.Stderr, "Extracted %d prompt(s) to: %s\n", len(allPrompts), sessionDir+"/"+paths.PromptFileName)
   286→
   287→	// Write summary file
   288→	summaryFile := filepath.Join(sessionDirAbs, paths.SummaryFileName)
   289→	if err := os.WriteFile(summaryFile, []byte(summary), 0o600); err != nil {
   290→		return fmt.Errorf("failed to write summary file: %w", err)
   291→	}
   292→	fmt.Fprintf(os.Stderr, "Extracted summary to: %s\n", sessionDir+"/"+paths.SummaryFileName)
   293→
   294→	// Generate commit message from last prompt
   295→	lastPrompt := ""
   296→	if len(allPrompts) > 0 {
   297→		lastPrompt = allPrompts[len(allPrompts)-1]
   298→	}
   299→	commitMessage := generateCommitMessage(lastPrompt)
   300→	fmt.Fprintf(os.Stderr, "Using commit message: %s\n", commitMessage)
   301→
   302→	// Get repo root for path normalization
   303→	repoRoot, err := paths.RepoRoot()
   304→	if err != nil {
   305→		return fmt.Errorf("failed to get repo root: %w", err)
   306→	}
   307→
   308→	var preUntrackedFiles []string
   309→	if preState != nil {
   310→		fmt.Fprintf(os.Stderr, "Pre-prompt state: %d pre-existing untracked files\n", len(preState.UntrackedFiles))
   311→		preUntrackedFiles = preState.PreUntrackedFiles()
   312→	}
   313→
   314→	// Detect file changes via git status
   315→	changes, err := DetectFileChanges(preUntrackedFiles)
   316→	if err != nil {
   317→		fmt.Fprintf(os.Stderr, "Warning: failed to compute file changes: %v\n", err)
   318→	}
   319→
   320→	// Filter and normalize all paths
   321→	relModifiedFiles := FilterAndNormalizePaths(modifiedFiles, repoRoot)
   322→	var relNewFiles, relDeletedFiles []string
   323→	if changes != nil {
   324→		relNewFiles = FilterAndNormalizePaths(changes.New, repoRoot)
   325→		relDeletedFiles = FilterAndNormalizePaths(changes.Deleted, repoRoot)
   326→	}
   327→
   328→	// Filter transcript-extracted files to exclude files already committed to HEAD.
   329→	// When an agent commits files mid-turn, those files are condensed by PostCommit
   330→	// and should not be re-added to FilesTouched by SaveStep. A file is "committed"
   331→	// if it exists in HEAD with the same content as the working tree.
   332→	relModifiedFiles = filterToUncommittedFiles(relModifiedFiles, repoRoot)
   333→
   334→	// Check if there are any changes
   335→	totalChanges := len(relModifiedFiles) + len(relNewFiles) + len(relDeletedFiles)
   336→	if totalChanges == 0 {
   337→		fmt.Fprintf(os.Stderr, "No files were modified during this session\n")
   338→		fmt.Fprintf(os.Stderr, "Skipping commit\n")
   339→		transitionSessionTurnEnd(sessionID)
   340→		if cleanupErr := CleanupPrePromptState(sessionID); cleanupErr != nil {
   341→			fmt.Fprintf(os.Stderr, "Warning: failed to cleanup pre-prompt state: %v\n", cleanupErr)
   342→		}
   343→		return nil
   344→	}
   345→
   346→	// Log file changes
   347→	logFileChanges(relModifiedFiles, relNewFiles, relDeletedFiles)
   348→
   349→	// Create context file
   350→	contextFile := filepath.Join(sessionDirAbs, paths.ContextFileName)
   351→	if err := createContextFile(contextFile, commitMessage, sessionID, allPrompts, summary); err != nil {
   352→		return fmt.Errorf("failed to create context file: %w", err)
   353→	}
   354→	fmt.Fprintf(os.Stderr, "Created context file: %s\n", sessionDir+"/"+paths.ContextFileName)
   355→
   356→	// Get git author
   357→	author, err := GetGitAuthor()
   358→	if err != nil {
   359→		return fmt.Errorf("failed to get git author: %w", err)
   360→	}
   361→
   362→	// Get strategy and agent type
   363→	strat := GetStrategy()
   364→	agentType := ag.Type()
   365→
   366→	// Get transcript position/identifier from pre-prompt state
   367→	var transcriptIdentifierAtStart string
   368→	var transcriptLinesAtStart int
   369→	if preState != nil {
   370→		transcriptIdentifierAtStart = preState.LastTranscriptIdentifier
   371→		transcriptLinesAtStart = preState.TranscriptOffset
   372→	}
   373→
   374→	// Calculate token usage - prefer SubagentAwareExtractor to include subagent tokens
   375→	var tokenUsage *agent.TokenUsage
   376→	if subagentExtractor, ok := ag.(agent.SubagentAwareExtractor); ok {
   377→		usage, tokenErr := subagentExtractor.CalculateTotalTokenUsage(transcriptRef, transcriptLinesAtStart, subagentsDir)
   378→		if tokenErr != nil {
   379→			fmt.Fprintf(os.Stderr, "Warning: failed to calculate token usage (with subagents): %v\n", tokenErr)
   380→		} else {
   381→			tokenUsage = usage
   382→		}
   383→	} else if calculator, ok := ag.(agent.TokenCalculator); ok {
   384→		// Fall back to basic token calculation (main transcript only)
   385→		usage, tokenErr := calculator.CalculateTokenUsage(transcriptRef, transcriptLinesAtStart)
   386→		if tokenErr != nil {
   387→			fmt.Fprintf(os.Stderr, "Warning: failed to calculate token usage: %v\n", tokenErr)
   388→		} else {
   389→			tokenUsage = usage
   390→		}
   391→	}
   392→
   393→	// Build fully-populated step context and delegate to strategy
   394→	ctx := strategy.StepContext{
   395→		SessionID:                sessionID,
   396→		ModifiedFiles:            relModifiedFiles,
   397→		NewFiles:                 relNewFiles,
   398→		DeletedFiles:             relDeletedFiles,
   399→		MetadataDir:              sessionDir,
   400→		MetadataDirAbs:           sessionDirAbs,
   401→		CommitMessage:            commitMessage,
   402→		TranscriptPath:           transcriptRef,
   403→		AuthorName:               author.Name,
   404→		AuthorEmail:              author.Email,
   405→		AgentType:                agentType,
   406→		StepTranscriptIdentifier: transcriptIdentifierAtStart,
   407→		StepTranscriptStart:      transcriptLinesAtStart,
   408→		TokenUsage:               tokenUsage,
   409→	}
   410→
   411→	if err := strat.SaveStep(ctx); err != nil {
   412→		return fmt.Errorf("failed to save step: %w", err)
   413→	}
   414→
   415→	// Update session state transcript position for auto-commit strategy
   416→	if strat.Name() == strategy.StrategyNameAutoCommit && newTranscriptPosition > 0 {
   417→		updateAutoCommitTranscriptPosition(sessionID, newTranscriptPosition)
   418→	}
   419→
   420→	// Transition session phase and cleanup
   421→	transitionSessionTurnEnd(sessionID)
   422→	if cleanupErr := CleanupPrePromptState(sessionID); cleanupErr != nil {
   423→		fmt.Fprintf(os.Stderr, "Warning: failed to cleanup pre-prompt state: %v\n", cleanupErr)
   424→	}
   425→
   426→	return nil
   427→}

   430→// but stays in ACTIVE phase (unlike TurnEnd which transitions to IDLE).
   431→// Also resets the transcript offset since the transcript may be truncated.
   432→func handleLifecycleCompaction(ag agent.Agent, event *agent.Event) error {
   433→	logCtx := logging.WithAgent(logging.WithComponent(context.Background(), "lifecycle"), ag.Name())

   437→	)

   439→	// Fire EventCompaction to trigger ActionCondenseIfFilesTouched (stays in ACTIVE)

   441→	sessionState, loadErr := strategy.LoadSessionState(sessionID)

   443→		fmt.Fprintf(os.Stderr, "Warning: failed to load session state for compaction: %v\n", loadErr)
   444→	}

   446→		if transErr := strategy.TransitionAndLog(sessionState, session.EventCompaction, session.TransitionContext{}, session.NoOpActionHandler{}); transErr != nil {
   447→			fmt.Fprintf(os.Stderr, "Warning: compaction transition failed: %v\n", transErr)

   451→		sessionState.CheckpointTranscriptStart = 0
   452→
   453→		if saveErr := strategy.SaveSessionState(sessionState); saveErr != nil {
   454→			fmt.Fprintf(os.Stderr, "Warning: failed to save session state after compaction: %v\n", saveErr)
   455→		}
   456→	}
   457→
   458→	fmt.Fprintf(os.Stderr, "Context compaction: transcript offset reset\n")
   459→	return nil
   460→}

   620→	if err := strat.SaveTaskStep(ctx); err != nil {
   621→		return fmt.Errorf("failed to save task step: %w", err)
   622→	}
   623→
   624→	_ = CleanupPreTaskState(event.ToolUseID) //nolint:errcheck // best-effort cleanup
   625→	return nil
   626→}

   630→// resolveTranscriptOffset determines the transcript offset to use for parsing.
   631→// Prefers pre-prompt state, falls back to session state.
   632→func resolveTranscriptOffset(preState *PrePromptState, sessionID string) int {
   633→	if preState != nil && preState.TranscriptOffset > 0 {
   634→		fmt.Fprintf(os.Stderr, "Pre-prompt state found: parsing transcript from offset %d\n", preState.TranscriptOffset)
   635→		return preState.TranscriptOffset
   636→	}
   637→
   638→	// Fall back to session state (e.g., auto-commit strategy updates it after each save)
   639→	sessionState, loadErr := strategy.LoadSessionState(sessionID)
   640→	if loadErr != nil {
   641→		fmt.Fprintf(os.Stderr, "Warning: failed to load session state: %v\n", loadErr)
   642→		return 0
   643→	}
   644→	if sessionState != nil && sessionState.CheckpointTranscriptStart > 0 {
   645→		fmt.Fprintf(os.Stderr, "Session state found: parsing transcript from offset %d\n", sessionState.CheckpointTranscriptStart)
   646→		return sessionState.CheckpointTranscriptStart
   647→	}
   648→
   649→	return 0
   650→}

   652→// updateAutoCommitTranscriptPosition updates the session state with the new transcript position
   653→// for the auto-commit strategy.
   654→func updateAutoCommitTranscriptPosition(sessionID string, newPosition int) {
   655→	sessionState, loadErr := strategy.LoadSessionState(sessionID)

   661→		sessionState = &strategy.SessionState{
   662→			SessionID: sessionID,

   664→	}
   665→	sessionState.CheckpointTranscriptStart = newPosition
   666→	sessionState.StepCount++
   667→	if updateErr := strategy.SaveSessionState(sessionState); updateErr != nil {
   668→		fmt.Fprintf(os.Stderr, "Warning: failed to update session state: %v\n", updateErr)
   669→	} else {
   670→		fmt.Fprintf(os.Stderr, "Updated session state: transcript position=%d, checkpoint=%d\n",
   671→			newPosition, sessionState.StepCount)
   672→	}
   673→}

   713→// transitionSessionTurnEnd transitions the session phase to IDLE and dispatches turn-end actions.
   714→func transitionSessionTurnEnd(sessionID string) {
   715→	turnState, loadErr := strategy.LoadSessionState(sessionID)
   716→	if loadErr != nil {
   717→		fmt.Fprintf(os.Stderr, "Warning: failed to load session state for turn end: %v\n", loadErr)
   718→		return
   719→	}
   720→	if turnState == nil {
   721→		return
   722→	}
   723→	if err := strategy.TransitionAndLog(turnState, session.EventTurnEnd, session.TransitionContext{}, session.NoOpActionHandler{}); err != nil {
   724→		fmt.Fprintf(os.Stderr, "Warning: turn-end transition failed: %v\n", err)
   725→	}
   726→
   727→	// Always dispatch to strategy for turn-end handling. The strategy reads
   728→	// work items from state (e.g. TurnCheckpointIDs), not the action list.
   729→	strat := GetStrategy()
   730→	if handler, ok := strat.(strategy.TurnEndHandler); ok {
   731→		if err := handler.HandleTurnEnd(turnState); err != nil {
   732→			fmt.Fprintf(os.Stderr, "Warning: turn-end action dispatch failed: %v\n", err)
   733→		}
   734→	}
   735→
   736→	if updateErr := strategy.SaveSessionState(turnState); updateErr != nil {
   737→		fmt.Fprintf(os.Stderr, "Warning: failed to update session phase on turn end: %v\n", updateErr)
   738→	}
   739→}

   741→// markSessionEnded transitions the session to ENDED phase via the state machine.
   742→func markSessionEnded(sessionID string) error {
   743→	state, err := strategy.LoadSessionState(sessionID)
   744→	if err != nil {
   745→		return fmt.Errorf("failed to load session state: %w", err)
   746→	}
   747→	if state == nil {
   748→		return nil // No state file, nothing to update
   749→	}
   750→
   751→	if transErr := strategy.TransitionAndLog(state, session.EventSessionStop, session.TransitionContext{}, session.NoOpActionHandler{}); transErr != nil {
   752→		fmt.Fprintf(os.Stderr, "Warning: session stop transition failed: %v\n", transErr)
   753→	}
   754→
   755→	now := time.Now()
   756→	state.EndedAt = &now
   757→
   758→	if err := strategy.SaveSessionState(state); err != nil {
   759→		return fmt.Errorf("failed to save session state: %w", err)
   760→	}
   761→	return nil
   762→}

   450→// uninstallDeselectedAgentHooks removes hooks for agents that were previously
   451→// installed but are not in the selected list. This handles the case where a user
   452→// re-runs `entire enable` and deselects an agent.
   453→func uninstallDeselectedAgentHooks(w io.Writer, selectedAgents []agent.Agent) error {
   454→	installedNames := GetAgentsWithHooksInstalled()
   455→	if len(installedNames) == 0 {
   456→		return nil
   457→	}
   458→
   459→	selectedSet := make(map[agent.AgentName]struct{}, len(selectedAgents))
   460→	for _, ag := range selectedAgents {
   461→		selectedSet[ag.Name()] = struct{}{}
   462→	}
   463→
   464→	var errs []error
   465→	for _, name := range installedNames {
   466→		if _, selected := selectedSet[name]; selected {
   467→			continue
   468→		}
   469→		ag, err := agent.Get(name)
   470→		if err != nil {
   471→			continue
   472→		}
   473→		hookAgent, ok := ag.(agent.HookSupport)
   474→		if !ok {
   475→			continue
   476→		}
   477→		if err := hookAgent.UninstallHooks(); err != nil {
   478→			errs = append(errs, fmt.Errorf("failed to uninstall %s hooks: %w", ag.Type(), err))
   479→		} else {
   480→			fmt.Fprintf(w, "Removed %s hooks\n", ag.Type())
   481→		}
   482→	}
   483→	return errors.Join(errs...)
   484→}

   502→// detectOrSelectAgent tries to auto-detect agents, or prompts the user to select.
   503→// Returns the detected/selected agents and any error.
   504→//
   505→// On first run (no hooks installed):
   506→//   - Single detected agent: used automatically
   507→//   - Multiple/no detected agents: interactive multi-select prompt
   508→//
   509→// On re-run (hooks already installed):
   510→//   - Always shows the interactive multi-select
   511→//   - Pre-selects only agents that have hooks installed (respects prior deselection)
   512→//
   513→// selectFn overrides the interactive prompt for testing. When nil, the real form is used.
   514→// It receives available agent names and returns the selected names.
   515→func detectOrSelectAgent(w io.Writer, selectFn func(available []string) ([]string, error)) ([]agent.Agent, error) {
   516→	// Check for agents with hooks already installed (re-run detection)
   517→	installedAgentNames := GetAgentsWithHooksInstalled()
   518→	hasInstalledHooks := len(installedAgentNames) > 0
   519→
   520→	// Try auto-detection
   521→	detected := agent.DetectAll()
   522→
   523→	// First run: use existing auto-detect shortcuts
   524→	if !hasInstalledHooks {
   525→		switch {
   526→		case len(detected) == 1:
   527→			fmt.Fprintf(w, "Detected agent: %s\n\n", detected[0].Type())
   528→			return detected, nil
   529→
   530→		case len(detected) > 1:
   531→			agentTypes := make([]string, 0, len(detected))
   532→			for _, ag := range detected {
   533→				agentTypes = append(agentTypes, string(ag.Type()))
   534→			}
   535→			fmt.Fprintf(w, "Detected multiple agents: %s\n", strings.Join(agentTypes, ", "))
   536→			fmt.Fprintln(w)
   537→		}
   538→	}
   539→
   540→	// Check if we can prompt interactively
   541→	if !canPromptInteractively() {
   542→		if hasInstalledHooks {
   543→			// Re-run without TTY — keep currently installed agents
   544→			agents := make([]agent.Agent, 0, len(installedAgentNames))
   545→			for _, name := range installedAgentNames {
   546→				ag, err := agent.Get(name)
   547→				if err != nil {
   548→					continue
   549→				}
   550→				agents = append(agents, ag)
   551→			}
   552→			return agents, nil
   553→		}
   554→		if len(detected) > 0 {
   555→			return detected, nil
   556→		}
   557→		defaultAgent := agent.Default()
   558→		if defaultAgent == nil {
   559→			return nil, errors.New("no default agent available")
   560→		}
   561→		fmt.Fprintf(w, "Agent: %s (use --agent to change)\n\n", defaultAgent.Type())
   562→		return []agent.Agent{defaultAgent}, nil
   563→	}
   564→
   565→	if !hasInstalledHooks && len(detected) == 0 {
   566→		fmt.Fprintln(w, "No agent configuration detected (e.g., .claude or .gemini directory).")
   567→		fmt.Fprintln(w, "This is normal - some agents don't require a config directory.")
   568→		fmt.Fprintln(w)
   569→	}
   570→
   571→	// Build pre-selection set.
   572→	// On re-run: only pre-select agents with hooks installed (respect prior deselection).
   573→	// On first run: pre-select all detected agents.
   574→	preSelectedSet := make(map[agent.AgentName]struct{})
   575→	if hasInstalledHooks {
   576→		for _, name := range installedAgentNames {
   577→			preSelectedSet[name] = struct{}{}
   578→		}
   579→	} else {
   580→		for _, ag := range detected {
   581→			preSelectedSet[ag.Name()] = struct{}{}
   582→		}
   583→	}
   584→
   585→	// Build options from registered agents
   586→	agentNames := agent.List()
   587→	options := make([]huh.Option[string], 0, len(agentNames))
   588→	for _, name := range agentNames {
   589→		ag, err := agent.Get(name)
   590→		if err != nil {
   591→			continue
   592→		}
   593→		// Only show agents that support hooks
   594→		if _, ok := ag.(agent.HookSupport); !ok {
   595→			continue
   596→		}
   597→		opt := huh.NewOption(string(ag.Type()), string(name))
   598→		if _, isPreSelected := preSelectedSet[name]; isPreSelected {
   599→			opt = opt.Selected(true)
   600→		}
   601→		options = append(options, opt)
   602→	}
   603→
   604→	if len(options) == 0 {
   605→		return nil, errors.New("no agents with hook support available")
   606→	}
   607→
   608→	// Collect available agent names for the selector
   609→	availableNames := make([]string, 0, len(options))
   610→	for _, opt := range options {
   611→		availableNames = append(availableNames, opt.Value)
   612→	}
   613→
   614→	var selectedAgentNames []string
   615→	if selectFn != nil {
   616→		var err error
   617→		selectedAgentNames, err = selectFn(availableNames)
   618→		if err != nil {
   619→			return nil, err
   620→		}
   621→		if len(selectedAgentNames) == 0 {
   622→			return nil, errors.New("no agents selected")
   623→		}
   624→	} else {
   625→		form := NewAccessibleForm(
   626→			huh.NewGroup(
   627→				huh.NewMultiSelect[string]().
   628→					Title("Which agents are you using?").
   629→					Description("Use space to select, enter to confirm.").
   630→					Options(options...).
   631→					Validate(func(selected []string) error {
   632→						if len(selected) == 0 {
   633→							return errors.New("please select at least one agent")
   634→						}
   635→						return nil
   636→					}).
   637→					Value(&selectedAgentNames),
   638→			),
   639→		)
   640→		if err := form.Run(); err != nil {
   641→			return nil, fmt.Errorf("agent selection cancelled: %w", err)
   642→		}
   643→	}
   644→
   645→	selectedAgents := make([]agent.Agent, 0, len(selectedAgentNames))
   646→	for _, name := range selectedAgentNames {
   647→		selectedAgent, err := agent.Get(agent.AgentName(name))
   648→		if err != nil {
   649→			return nil, fmt.Errorf("failed to get selected agent %s: %w", name, err)
   650→		}
   651→		selectedAgents = append(selectedAgents, selectedAgent)
   652→	}
   653→
   654→	agentTypes := make([]string, 0, len(selectedAgents))
   655→	for _, ag := range selectedAgents {
   656→		agentTypes = append(agentTypes, string(ag.Type()))
   657→	}
   658→	fmt.Fprintf(w, "\nSelected agents: %s\n\n", strings.Join(agentTypes, ", "))
   659→	return selectedAgents, nil
   660→}

Here's how it works:

**`entire trail enable` does NOT create a trail itself.** It only flips the setting — it removes the `strategy_options.trails` key from settings (restoring the default "enabled" state). That's all it does.

**Auto-creation happens later**, on the next `TurnStart` event (i.e., when an agent session starts a new turn). The flow is:

1. Agent hook fires `TurnStart` → `handleLifecycleTurnStart()` (`lifecycle.go:112`)
2. At the end, it calls `autoCreateTrailOnTurnStart()` (`lifecycle.go:148`)
3. That function checks: trails disabled? On default branch? Already has a trail?
4. If none of those apply, it calls `AutoCreateTrail()` which creates one with `in_progress` status

**So for existing branches:** yes, it works — but only when the next agent turn starts on that branch. If you run `entire trail enable` on a branch that already exists but has no trail, the trail will be auto-created the next time you send a prompt to your agent on that branch. It won't be created immediately by the `enable` command itself.

There's no "backfill" — branches that existed while trails were disabled won't get trails until someone starts an agent session on them.

+# Trails Implementation
+
+## Overview
+
+Implement a branch-centric work tracking system called "Trails" that replaces PR-based task tracking. Trails use pure git primitives (branches, commits) rather than GitHub-specific features (PRs/Issues).
+
+**Key decisions:**
+- Store trail metadata in `entire/trails` branch (similar to checkpoints)
+- One trail per branch - trail tracks the full lifecycle of work on that branch
+- Link to checkpoints via branch name matching (`trail.branch === checkpoint.branch`)
+- Support discussion/comments stored alongside trail metadata
+- Sync trails to database for fast querying (same pattern as checkpoints)
+- No dependency on GitHub PRs - PR info is optional/supplementary
+
+## Concepts
+
+### Trail Lifecycle
+
+```
+draft → open → in_progress → in_review → done → closed
+  │                              │           │
+  │   work happening             │  merged   │  abandoned
+  └──────────────────────────────┴───────────┴──────────
+```
+
+### Relationship Model
+
+```
+Trail (1) ←──branch──→ (many) Checkpoints
+   │                         │
+   └── "why/what"            └── "how/when"
+       (human intent)            (machine snapshots)
+```
+
+- **Trail**: Human-defined work item tracking purpose and status
+- **Checkpoint**: Machine-generated snapshot of work at a commit
+- **Link**: `trail.branch === checkpoint.branch` (no explicit foreign key needed)
+

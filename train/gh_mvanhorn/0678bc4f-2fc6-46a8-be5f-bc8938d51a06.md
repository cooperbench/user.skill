> AGENT

The sentinel is a mechanism to wait for Claude Code to finish writing its transcript file before reading it. When Claude Code runs hooks (like the `stop` hook), it writes a `hook_progress` entry to the transcript JSONL file. The sentinel logic looks for a line containing `"hooks claude-code stop"` in the transcript file — that entry signals "Claude Code has flushed all pending writes to this transcript, it's safe to read now." The flow is: 1. Claude Code finishes a turn → fires the `stop` hook → your CLI hook runs 2. Your CLI wants to read the transcript (to extract files touched, check for new content, etc.) 3. So `waitForTranscriptFlush` polls the last 4KB of the transcript every 50ms for up to **3 seconds**, looking for that `hook_progress` entry with a matching timestamp 5. If found → safe to read.

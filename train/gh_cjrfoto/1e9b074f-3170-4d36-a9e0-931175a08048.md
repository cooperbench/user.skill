Based on the official Claude Code documentation, here's how Claude Code licensing works in relation to Claude Pro:

## Claude Code Licensing

**Claude Code requires a paid subscription** — it is not included with free Claude.ai accounts. Here's the breakdown:

### What Plans Include Claude Code Access:

Claude Code is available to users with:
- **Claude Pro** subscription
- **Claude Max** subscription  
- **Claude Team** accounts
- **Claude Enterprise** accounts
- **Anthropic Console** accounts (for API-based access)

**The free Claude.ai plan does NOT include Claude Code access.**

### How It Works With Claude Pro:

Yes, Claude Code is **connected to your Claude Pro subscription**. When you use Claude Code (whether through the terminal, VS Code extension, Desktop app, or web), it uses your Claude Pro credentials and subscription. Your usage counts against your Claude Pro limits.

### Third-Party Alternatives:

You can also use Claude Code with third-party API providers if you prefer:
- **Amazon Bedrock**
- **Google Vertex AI**
- **Microsoft Foundry**

These require their own credentials and billing arrangements, separate from Claude Pro.

### Getting Started:

1. Ensure you have an active Claude Pro (or higher) subscription at [claude.com/pricing](https://claude.com/pricing)
2. Install Claude Code from https://claude.ai/install.sh (or use your preferred method)
3. Run `claude` in your terminal
4. Log in when prompted — you'll be directed to authenticate with your Claude account

The authentication connects Claude Code to your existing Claude subscription, and all your usage flows through that account.

For more details, see the official documentation at:
- [Claude Code overview](https://code.claude.com/docs/en/overview.md)
- [Claude Code setup and authentication](https://code.claude.com/docs/en/setup.md#authenticate)

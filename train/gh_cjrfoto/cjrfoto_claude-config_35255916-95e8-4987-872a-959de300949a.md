> AGENT

You have two interfaces to **Claude Code** open simultaneously:

1. **VS Code Extension panel** (right side) — the GUI panel with the Claude logo. This is the graphical interface built into VS Code. You interact via the chat panel.

2. **Claude Code CLI in the terminal** (bottom) — you ran `claude` in the terminal, which starts the interactive TUI (text-based) version of Claude Code.

**They are the same tool, just different interfaces.** Both connect to the same Claude model (Sonnet 4.6) and both can read/edit your files.

**Which to use:** Stick with the VS Code extension panel (right side) — it's more convenient since it's integrated with your editor. You can close the terminal `claude` session by typing `/exit` or pressing `Ctrl+C`.

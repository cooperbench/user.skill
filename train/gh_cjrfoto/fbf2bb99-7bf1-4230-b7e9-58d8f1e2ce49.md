**Claude Console** (console.anthropic.com) is Anthropic's web dashboard for developers. It's where you:

- **Get API keys** to use Claude programmatically
- **Monitor usage** — token counts, costs, rate limits
- **Test prompts** in a Workbench playground
- **Manage billing** and set spend limits
- **Create Organizations** and invite team members
- **View logs** of API calls (in some tiers)

It's the control panel for building with the Claude API — not for chatting with Claude directly (that's claude.ai).

**You'd use it if you're:**
- Building an app that calls Claude via API
- Checking how much you've spent
- Getting your `ANTHROPIC_API_KEY`

## Channels vs Remote Control

### **Remote Control** — Drive your session from afar
Remote Control lets you **continue a Claude Code session running on your machine from your phone, tablet, or another computer**. Think of it as remote access.

- **What you're doing**: Continuing work that's already in progress on your Mac or PC
- **How it works**: You start a session on your machine (`claude remote-control`), then open it in your browser at claude.ai/code or the Claude mobile app to keep working
- **Example**: Start coding at your desk, then switch to your phone and keep steering the conversation while sitting on the couch
- **Key feature**: Your local files, MCP servers, and tools all stay available — nothing moves to the cloud

### **Channels** — Push events into a session
Channels let you **send messages and alerts into a running Claude Code session from external platforms** like Telegram, Discord, or iMessage. Think of it as one-way communication coming IN.

- **What you're doing**: Having Claude react to events while you're away
- **How it works**: You enable a channel plugin (like Telegram), then external messages or webhooks push into your session
- **Example**: Your CI pipeline fails, a webhook pushes that event into Claude, and Claude automatically investigates the bug and suggests a fix
- **Key feature**: Claude can reply back through the same channel, creating a chat bridge from your phone to your local session

Based on the Claude Code documentation, **Telegram channel configuration is not done via settings.json**. Instead, it uses a plugin-based approach. Here's how it actually works:

**Telegram Channel Setup (Not settings.json):**

The Telegram bot token is configured via the `/telegram:configure` command, which saves it to:
```
~/.claude/channels/telegram/.env
```

Or you can set it directly as an environment variable:
```bash
TELEGRAM_BOT_TOKEN=your_token_here
```

**There is no JSON snippet for settings.json** because channels are configured separately as plugins, not through the main settings file.

**To use Telegram with Claude Code:**

1. Install the plugin:
   ```
   /plugin install telegram@claude-plugins-official
   ```

2. Configure the token:
   ```
   /telegram:configure <token>
   ```

3. Restart Claude Code with the channel enabled:
   ```bash
   claude --channels plugin:telegram@claude-plugins-official
   ```

4. Pair your account via Telegram bot

**For Enterprise/Team Organizations:**

If you need to control channels via managed settings, the format is:
```json
{
  "channelsEnabled": true,
  "allowedChannelPlugins": [
    { "marketplace": "claude-plugins-official", "plugin": "telegram" }
  ]
}
```

This is set by organization admins in the Claude Code Admin console, not in individual settings.json files.

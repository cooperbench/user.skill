Good question — to be clear: **all three are Google Fonts**, loaded the exact same way (`next/font/google`, self-hosted at build). So "Silkscreen/VT323 instead" just means *which typeface* to pick, not replacing the Google Fonts approach. How they differ visually: - **Pixelify Sans** (current) — a pixel font with slightly rounded, open letterforms. Good x-height, so it stays readable down to the ~10px HUD sizes. Reads as "pixel/blocky" without being hard to parse. - **Silkscreen** — a true tiny bitmap font, very square and condensed; the most "retro pixel" of the three, but it muddies below ~12px and leans uppercase, so small labels (durability lines, controls list) get harder to read. - **VT323** — a monospace CRT/terminal font. Looks like old DOS text — retro, but reads more "computer terminal" than "Minecraft." One thing worth knowing: **the actual Minecraft typeface is *not* on Google Fonts.** If you want the literal Minecraft look, the closest open-source clone is **Monocraft**, which would mean self-hosting a font file via `next/font/local` instead of `next/font/google` (still self-hosted/no runtime fetch, just a committed `.woff2` rather than a build-time download). That's the most authentic option but adds an actual font file to the repo.

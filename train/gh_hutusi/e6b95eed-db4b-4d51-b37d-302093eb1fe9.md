Current order:
```
AuthorCard → Tags → Backlinks → ShareBar → Comments → ExternalLinks → PostNavigation → RelatedPosts
```

Better order by reading intent:
```
Tags → ShareBar → Comments → ExternalLinks → Backlinks → AuthorCard → PostNavigation → RelatedPosts
```

Rationale:
- **ShareBar before Comments**: readers should be prompted to share before they leave; right now it's buried after Backlinks.
- **ExternalLinks near Comments**: HN/V2EX links are external comment threads — they belong beside the native comment section.

h.level === 3 ? 'pl-6' : 'pl-3'

Any h4 (or deeper) gets the same indent as h2. If content has nested headings (h2 → h3 → h4), the TOC indentation breaks visually. Should be `(h.level - 2) * 12px` or equivalent.

If the lockfile doesn't pin these transitive packages at the top level, Bun on the CI runner may hoist them differently or not make them directly importable — resulting in "Cannot find package".

The fix is to add them explicitly to `package.json` as direct dependencies, which makes the intent clear and guarantees they're available regardless of how the lockfile resolves transitive deps.

---

**UX issues:**

4. **Hero stat chips link to anchor hashes** (`#featured-posts`, `#recent-flows`, etc.) — if a section renders empty and returns `null`, the anchor doesn't exist and the click goes nowhere. They should link to the actual page URLs (`/posts`, `/flows`, `/series`, `/books`) as a reliable fallback.

5. **RecentNotesSection doesn't show note titles** — `RecentNoteItem` only carries `date` and `excerpt`. Flow notes have a `title` field that's available but stripped out at `page.tsx:96-100`. Notes are only distinguishable by date, which is confusing when several are close together.

6. **Timeline visual bug in RecentNotesSection** — the `border-l-2` line continues past the last dot because only `pb-0` is applied to the last item. The line visually overshoots.

**Minor:**

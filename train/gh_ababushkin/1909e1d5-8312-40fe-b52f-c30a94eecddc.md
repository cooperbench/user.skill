Hook output protocol** Claude Code reads stdout from any hook script and — if it's valid JSON with a `message` field — injects it as a system message into the session context. The `priority: "IMPORTANT"` flag makes Claude treat it with high weight. **4. Result** Claude sees GOVERNANCE.md as if it were part of the system prompt. You can see it firing right now in this session — the `SessionStart:startup hook success` banner at the top of every conversation is Claude Code reporting what the hook emitted. The rules files (`rules/code-review.md`, `rules/linear-workflow.md`) are *not* injected upfront — GOVERNANCE.md just references them by path. All the actual content and logic lives in the rules markdown files. The hook just bootstraps awareness of them at session start.

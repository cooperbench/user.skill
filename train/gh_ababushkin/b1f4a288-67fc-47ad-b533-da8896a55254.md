**Halt-on-Not-Done Logic:**

**Context checked:** Spec requires CLI command + auto-trigger on Done + clear error on missing entry. All three covered.

---

### Correctness

- `log.entries[-1]` in orchestrator: safe — `append_entry()` unconditionally appends before we read it. If `append_entry()` raised, we'd never reach the grade-draft block.  
- `_find_most_recent_entry`: reverse-sorted files then reversed entries within each file correctly yields the latest-run, latest-entry for the issue.  
- Overwrite: `write_text` replaces without checking. `mkdir(exist_ok=True)` handles pre-existing directory. Test confirms single `status: draft` and single `## KR check` on second write.  
- Null fields: `entry.get("cost_usd")` returns `None` for pre-spawn halt entries → renders `"—"`. Test covers sparse entries.  
- CLI: `grade-draft` with no identifier → `remaining == ["grade-draft"]` (len 1) → falls to unknown-invocation → exits 2. Test covers this.  

### Readability / Simplicity

- `grade_draft.py` mirrors `grade.py` shape: `grades_dir()`, `run()`, internal helpers. Consistent.  
- `_render` is straightforward list-of-lines join. The final `""` element produces a trailing newline, consistent with POSIX convention.  
- Test helpers `_entry()` and `_write_run_log()` match the style of `test_grade_per_cycle.py`.  

**Nit:** `grade_draft` is eagerly imported at module level in `cli.py`, while `status` is lazily imported inside its dispatch branch. Minor inconsistency; no functional impact since `grade_draft` carries no heavy imports.

### Architecture

- Module boundary clean: `grade_draft` imports `runlog` (lightweight), never imports `orchestrator` (would be circular).  
- Non-fatal auto-trigger: `except Exception` wraps the orchestrator call. `KeyboardInterrupt` inherits `BaseException`, not `Exception`, so it propagates correctly.  
- `grades_dir()` resolved on each call (not module-import time), matching `runlog.runs_dir()` contract so tests can redirect via `HOME`.  

### Security

- `grades_dir() / f"{issue_identifier}.md"`: path traversal only possible if identifier contained `../`. Linear identifiers are validated upstream (`TEAM-NNN` format) and this is a single-operator local tool. Not a concern.  
- No secrets written to grade files (states, durations, costs, token counts only).  

### Performance

- `_find_most_recent_entry` reads all run-log files on manual invocation. Cycle scale is ≤15 issues × a handful of runs — negligible.  
- Auto-trigger writes one small file after an already-completed network + disk round-trip. No concern.

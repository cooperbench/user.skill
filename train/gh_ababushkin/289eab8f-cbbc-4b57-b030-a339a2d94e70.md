Two ways: **Auto (recommended):** iTerm2 → Settings → General → Preferences → "Load preferences from custom folder" = `~/src/dotfiles` + check "Save changes to folder when iTerm2 quits". Every quit writes `com.googlecode.iterm2.plist` back to repo. Just `git diff` + commit. **Manual:** Same panel, uncheck auto-save. Click "Save Current Settings to Folder" button when you want snapshot. Or CLI: `defaults export com.googlecode.iterm2 ~/src/dotfiles/com.googlecode.iterm2.plist`. Install script sets `PrefsCustomFolder=~/src/dotfiles` + `LoadPrefsFromCustomFolder=true` via `defaults write` before first launch. iTerm2 picks up plist from repo on boot. Proceed?

# Plan: Add aider to dotfiles installation

## Context

aider is an AI pair-programming CLI tool. The user wants it installed as part of `install-core.sh` so any fresh machine setup includes it. aider has a Python dependency and several install methods with different isolation tradeoffs.

## Install method: curl one-liner (recommended by aider docs)

```bash
curl -LsSf https://aider.chat/install.sh | sh
```

**Why this over pipx:**
- Officially recommended by aider
- Auto-manages Python (installs 3.12 in an isolated env via uv if needed) — no Python version pinning required
- Fully isolated — won't conflict with mise-managed runtimes or pipx/poetry
- Mirrors the existing Claude Code install pattern in `install-core.sh` (also a curl script)
- pipx is limited to Python 3.9–3.12 and would require a Python runtime to be present

**Why not brew:** aider docs explicitly say system package managers often install with incorrect dependencies.

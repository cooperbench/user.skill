## Bugs to fix

**1. B3 background sampling is contaminated by the subject.**
B3 samples 10% strips on all four frame edges. In a *correctly framed* photo (head 70–80%, shoulders visible) those strips cut through hair, ears, and shirt — so the "background" stats measure the subject, not the wall. Measured on the AusPost photo:

```
full 4-edge border (current B3):  L* 87.4   variance 1453   ← FAILs uniformity (>400)
top strip only (real background): L* 95.0   variance   70
top corners only:                 L* 95.7   variance    4   ← flawless white
```

Lowering `background_l_min` to 75 (done in <issue id="51f1859a-7c30-4f2f-812e-c07b4f9add6d">ABA-250</issue>) fixed the brightness fail but not uniformity. The uniformity check effectively only passes on loosely-framed (non-compliant) photos.
**Fix:** sample background only where it is background — use the detected face box to exclude the head's horizontal column; sample top-corners / above-crown.

**2. B1 sharpness threshold is not resolution-aware.**
`SHARPNESS_THRESHOLD = 100.0` (Laplacian variance). The AusPost photo is tack-sharp but scores 44 at 1056×1358 → false "blurry". Laplacian variance scales with resolution and edge content; a clean lower-res photo of smooth skin on a plain background scores low even when perfectly focused.
**Fix:** normalise by resolution (or measure on a fixed-size face ROI) and recalibrate so a known-sharp photo passes.

**3. Visa aspect rejects the standard photo.**
The `visa` profile hardcodes `aspect_ratio = 3/4` (0.750) ±0.02, which FAILs a standard 35:45 (0.778) photo. Passport and citizenship are the *same physical photo*. <issue id="51f1859a-7c30-4f2f-812e-c07b4f9add6d">ABA-250</issue> widened the `passport` aspect to a range but left `visa` at 3:4.
**Fix:** verify against the Home Affairs source whether the digital upload truly requires 3:4 or accepts the standard ratio; correct accordingly (a range, or rely on `--fix` to resize).

382	# ---------------------------------------------------------------------------
383	# Tier C — face geometry (OpenCV Haar cascades, bundled, fully offline)
384	# ---------------------------------------------------------------------------
385	
386	# Detection is run on a downscaled copy so runtime and minNeighbors behaviour
387	# stay consistent regardless of the source resolution. All reported quantities
388	# are fractions of the frame, so they are unaffected by the downscale.
389	DETECT_MAX_DIM = 1000
390	
391	# Ignore face boxes smaller than this fraction of the shorter frame side — keeps
392	# the cascade from latching onto background clutter as a tiny "face".
393	FACE_MIN_FRAC = 0.10
394	
395	# The face centre may sit within ±this fraction of the frame width from the middle.
396	CENTRE_TOLERANCE = 0.10
397	
398	# The Haar frontal-face box spans roughly the forehead to the chin, which is
399	# shorter than the full crown-to-chin head height the specs measure. This factor
400	# converts detected face-box height to an estimated head height. Calibrated by
401	# cropping a reference portrait to a known 75%-of-frame head and measuring the
402	# resulting Haar box at ~58% of frame → 0.75 / 0.58 ≈ 1.30. Derived from a single
403	# reference face; crown position varies with hairstyle, so re-validate against
404	# more portraits if outputs frame the head too high or low.
405	HEAD_FACE_RATIO = 1.30

408	def detect_face_and_eyes(image_path: Path) -> dict | None:
409	    """Run the frontal-face and eye cascades once on an image.
410	
411	    Returns the geometric facts the per-profile checks need, or None if the
412	    image could not be read. The face box height and centre are measured against
413	    the detected-face bounding box (brow-to-chin), which understates the full
414	    crown-to-chin head height; the head band is the target after cropping, so a
415	    raw, uncropped portrait is expected to fall short of it here.
416	    """
417	    import cv2
418	
419	    img = cv2.imread(str(image_path))
420	    if img is None:
421	        return None
422	
423	    h, w = img.shape[:2]
424	    scale = DETECT_MAX_DIM / max(h, w)
425	    work = cv2.resize(img, (round(w * scale), round(h * scale))) if scale < 1 else img
426	    gray_plain = cv2.cvtColor(work, cv2.COLOR_BGR2GRAY)
427	    # Histogram equalisation makes frontal-face detection robust to lighting, but
428	    # it suppresses the eye cascade — so faces use the equalised image, eyes the plain one.
429	    gray = cv2.equalizeHist(gray_plain)
430	    wh, ww = gray.shape[:2]
431	
432	    face_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_frontalface_default.xml")
433	    min_side = int(min(ww, wh) * FACE_MIN_FRAC)
434	    faces = face_cascade.detectMultiScale(
435	        gray, scaleFactor=1.1, minNeighbors=5, minSize=(min_side, min_side)
436	    )
437	    faces = sorted(faces, key=lambda f: f[2] * f[3], reverse=True)
438	
439	    facts: dict = {"n_faces": len(faces)}
440	    if not faces:
441	        return facts
442	
443	    fx, fy, fw, fh = faces[0]
444	    facts["height_frac"] = fh / wh
445	    facts["centre_x_frac"] = (fx + fw / 2) / ww
446	    facts["face_box_frac"] = (fx / ww, fy / wh, fw / ww, fh / wh)
447	
448	    # Eyes are expected in the upper half of an upright frontal face; restricting
449	    # the search there rejects nostril/mouth false positives and confirms orientation.
450	    eye_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_eye.xml")
451	    roi = gray_plain[fy:fy + fh // 2, fx:fx + fw]
452	    eyes = eye_cascade.detectMultiScale(roi, scaleFactor=1.1, minNeighbors=5)
453	    facts["n_eyes_upper"] = len(eyes)
454	    return facts

457	def append_face_geometry(result: CheckResult, facts: dict | None, profile: dict) -> None:
458	    """Append the four Tier C face-geometry findings to a profile's result."""
459	    if facts is None:
460	        result.fail("C1 could not read image for face detection")
461	        return
462	
463	    n = facts["n_faces"]
464	    if n == 0:
465	        result.fail("C1 no frontal face detected — not a portrait (document scan, or face too small/turned)")
466	        return
467	    if n > 1:
468	        result.fail(f"C1 {n} faces detected — a passport photo must contain exactly one")
469	        return
470	    result.ok("C1 exactly one frontal face detected")
471	
472	    hf = facts["height_frac"]  # Haar face-box (brow-to-chin) as fraction of frame
473	    estimated_head_frac = hf * HEAD_FACE_RATIO  # crown-to-chin estimate
474	    lo, hi = profile["head_height_min_frac"], profile["head_height_max_frac"]
475	    if lo <= estimated_head_frac <= hi:
476	        result.ok(f"C2 estimated head height {estimated_head_frac:.0%} of frame (target {lo:.0%}–{hi:.0%})")
477	    else:
478	        result.fail(
479	            f"C2 estimated head height {estimated_head_frac:.0%} of frame, "
480	            f"outside target {lo:.0%}–{hi:.0%} — crop/scale needed"
481	        )
482	
483	    cx = facts["centre_x_frac"]
484	    offset = abs(cx - 0.5)
485	    if offset <= CENTRE_TOLERANCE:
486	        result.ok(f"C3 face horizontally centred (centre at {cx:.0%} of width)")
487	    else:
488	        result.fail(f"C3 face off-centre (centre at {cx:.0%} of width, must be 50% ±{CENTRE_TOLERANCE:.0%})")
489	
490	    eyes = facts["n_eyes_upper"]
491	    if eyes >= 2:
492	        result.ok(f"C4 {eyes} eyes detected in upper half of face")
493	    elif eyes == 1:
494	        result.warn("C4 only one eye detected in upper half of face — head may be tilted or partly obscured")
495	    else:
496	        result.fail("C4 no eyes detected in upper half of face — face may be obscured, tilted, or a false detection")

508	def crop_to_profile(image_path: Path, profile: dict, face_facts: dict, out_path: Path) -> bool:
509	    """Crop and scale source image to profile fix dimensions with head in the target band.
510	
511	    Returns True on success. The crop centres the face horizontally and places the
512	    estimated crown with balanced top/bottom margins. Regions outside the source
513	    image are padded with white.
514	    """
515	    import cv2
516	    import numpy as np
517	
518	    if "face_box_frac" not in face_facts:
519	        return False
520	
521	    img = cv2.imread(str(image_path))
522	    if img is None:
523	        return False
524	
525	    src_h, src_w = img.shape[:2]
526	    xf, yf, wf, hf = face_facts["face_box_frac"]
527	
528	    # Face box in source pixels
529	    fx = xf * src_w
530	    fy = yf * src_h
531	    fw = wf * src_w
532	    fh = hf * src_h
533	
534	    # Estimated head bounds using the calibration factor
535	    crown_y = fy - (HEAD_FACE_RATIO - 1.0) * fh   # crown above the face-box top
536	    chin_y = fy + fh                                 # chin at the face-box bottom
537	    head_h_src = chin_y - crown_y                    # = fh * HEAD_FACE_RATIO
538	    face_cx = fx + fw / 2.0
539	
540	    # Target: head at the centre of the 70–80% band
541	    head_frac = (profile["head_height_min_frac"] + profile["head_height_max_frac"]) / 2.0
542	    out_w = profile["fix_width_px"]
543	    out_h = profile["fix_height_px"]
544	
545	    # Crop region in source pixels: scale so head_h_src maps to head_frac * out_h
546	    # crop_h / out_h = head_h_src / (head_frac * out_h)  →  crop_h = head_h_src / head_frac
547	    crop_h = head_h_src / head_frac
548	    crop_w = crop_h * out_w / out_h  # maintain output aspect ratio
549	
550	    # Balanced vertical margin: crown at (1 - head_frac) / 2 from top of crop
551	    top_margin = (1.0 - head_frac) / 2.0 * crop_h
552	    crop_y1 = crown_y - top_margin
553	    crop_x1 = face_cx - crop_w / 2.0
554	
555	    # Convert to integer pixel coordinates
556	    cx1 = int(round(crop_x1))
557	    cy1 = int(round(crop_y1))
558	    cw = int(round(crop_w))
559	    ch = int(round(crop_h))
560	
561	    # White canvas; copy the source region into the correct position
562	    canvas = np.full((ch, cw, 3), 255, dtype=np.uint8)
563	    sx1 = max(0, cx1)
564	    sy1 = max(0, cy1)
565	    sx2 = min(src_w, cx1 + cw)
566	    sy2 = min(src_h, cy1 + ch)
567	    if sx2 > sx1 and sy2 > sy1:
568	        dx1 = sx1 - cx1
569	        dy1 = sy1 - cy1
570	        canvas[dy1:dy1 + (sy2 - sy1), dx1:dx1 + (sx2 - sx1)] = img[sy1:sy2, sx1:sx2]
571	
572	    out_img = cv2.resize(canvas, (out_w, out_h), interpolation=cv2.INTER_LANCZOS4)
573	
574	    out_path.parent.mkdir(parents=True, exist_ok=True)
575	    ext = out_path.suffix.lower()
576	    if ext in (".jpg", ".jpeg"):
577	        cv2.imwrite(str(out_path), out_img, [cv2.IMWRITE_JPEG_QUALITY, 95])
578	    else:
579	        cv2.imwrite(str(out_path), out_img)
580	    return True

# All sessions for one project

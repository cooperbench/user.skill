* Visa / citizenship — [https://immi.homeaffairs.gov.au/citizenship/photo-requirements-for-citizenship-applications](<https://immi.homeaffairs.gov.au/citizenship/photo-requirements-for-citizenship-applications>)

## Known issues found during verification (seed list — confirm + resolve each)

1. **No automated tests.** Validation has no backstop. Add a suite with sample fixtures (a compliant photo, a document scan that must FAIL C1, an off-spec photo) and per-rule PASS/FAIL assertions. Pin `pytest` in `requirements.txt`.
2. **Passport background too strict.** Code requires white (`background_l_min` 90); the official rule is "plain white **or light** background that contrasts with your face." May FAIL a valid light-grey-background passport photo. Also: the `passport` profile never checks face/background **contrast** (only `visa` does), though the office requires it.
3. **Passport aspect tolerance misses 40:50.** Code uses 0.778 (35:45) ±0.02 → 0.758–0.798. Official photo size is a **range** (35–40 mm × 45–50 mm), so 0.80 (40:50) is valid but currently FAILs. Widen the band to 0.778–0.80.
4. **No print-resolution warning.** The passport pixel floor (413×531 px @ 300 DPI) is a tool choice — the official spec states **no DPI/pixel rule** (it's mm on glossy paper). Decide whether to WARN below 600 DPI (827×1063 px) for print quality.
5. **PNG accepted for visa.** Code accepts JPEG **and PNG**; Home Affairs asks for **JPEG**. A PNG the tool passes may be rejected by the portal. Decide: WARN on PNG for `visa`.
6. **C2 head-height calibration.** C2 measures the Haar face box (brow→chin), which understates full chin-to-crown head height, so raw portraits read low against the 70–80% band. Needs a calibration factor (tracked alongside <issue id="889f0e5d-8c24-4062-907c-8324af430b99">ABA-246</issue>).
7. **Passport file-size band (50 KB–2 MB) has no official basis** — it's a sanity band for a printed photo. Acceptable, but confirm + document as a tool choice.

352	# Detection is run on a downscaled copy so runtime and minNeighbors behaviour
353	# stay consistent regardless of the source resolution. All reported quantities

358	# the cascade from latching onto background clutter as a tiny "face".
359	FACE_MIN_FRAC = 0.10

361	# The face centre may sit within ±this fraction of the frame width from the middle.
362	CENTRE_TOLERANCE = 0.10
363	
364	# The Haar frontal-face box spans roughly the forehead to the chin, which is
365	# shorter than the full crown-to-chin head height the specs measure. This factor
366	# converts detected face-box height to an estimated head height. Calibrated by
367	# cropping a reference portrait to a known 75%-of-frame head and measuring the
368	# resulting Haar box at ~58% of frame → 0.75 / 0.58 ≈ 1.30. Derived from a single
369	# reference face; crown position varies with hairstyle, so re-validate against
370	# more portraits if outputs frame the head too high or low.

374	def detect_face_and_eyes(image_path: Path) -> dict | None:
375	    """Run the frontal-face and eye cascades once on an image.
376	
377	    Returns the geometric facts the per-profile checks need, or None if the
378	    image could not be read. The face box height and centre are measured against
379	    the detected-face bounding box (brow-to-chin), which understates the full
380	    crown-to-chin head height; the head band is the target after cropping, so a
381	    raw, uncropped portrait is expected to fall short of it here.
382	    """
383	    import cv2
384	
385	    img = cv2.imread(str(image_path))
386	    if img is None:
387	        return None
388	
389	    h, w = img.shape[:2]
390	    scale = DETECT_MAX_DIM / max(h, w)
391	    work = cv2.resize(img, (round(w * scale), round(h * scale))) if scale < 1 else img
392	    gray_plain = cv2.cvtColor(work, cv2.COLOR_BGR2GRAY)
393	    # Histogram equalisation makes frontal-face detection robust to lighting, but
394	    # it suppresses the eye cascade — so faces use the equalised image, eyes the plain one.
395	    gray = cv2.equalizeHist(gray_plain)
396	    wh, ww = gray.shape[:2]
397	
398	    face_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_frontalface_default.xml")
399	    min_side = int(min(ww, wh) * FACE_MIN_FRAC)
400	    faces = face_cascade.detectMultiScale(
401	        gray, scaleFactor=1.1, minNeighbors=5, minSize=(min_side, min_side)
402	    )
403	    faces = sorted(faces, key=lambda f: f[2] * f[3], reverse=True)
404	
405	    facts: dict = {"n_faces": len(faces)}
406	    if not faces:
407	        return facts
408	
409	    fx, fy, fw, fh = faces[0]
410	    facts["height_frac"] = fh / wh
411	    facts["centre_x_frac"] = (fx + fw / 2) / ww
412	    facts["face_box_frac"] = (fx / ww, fy / wh, fw / ww, fh / wh)
413	
414	    # Eyes are expected in the upper half of an upright frontal face; restricting
415	    # the search there rejects nostril/mouth false positives and confirms orientation.
416	    eye_cascade = cv2.CascadeClassifier(cv2.data.haarcascades + "haarcascade_eye.xml")
417	    roi = gray_plain[fy:fy + fh // 2, fx:fx + fw]
418	    eyes = eye_cascade.detectMultiScale(roi, scaleFactor=1.1, minNeighbors=5)
419	    facts["n_eyes_upper"] = len(eyes)
420	    return facts

423	def append_face_geometry(result: CheckResult, facts: dict | None, profile: dict) -> None:
424	    """Append the four Tier C face-geometry findings to a profile's result."""

435	        return

474	def crop_to_profile(image_path: Path, profile: dict, face_facts: dict, out_path: Path) -> bool:
475	    """Crop and scale source image to profile fix dimensions with head in the target band.
476	
477	    Returns True on success. The crop centres the face horizontally and places the
478	    estimated crown with balanced top/bottom margins. Regions outside the source
479	    image are padded with white.
480	    """
481	    import cv2
482	    import numpy as np
483	
484	    if "face_box_frac" not in face_facts:
485	        return False
486	
487	    img = cv2.imread(str(image_path))
488	    if img is None:
489	        return False
490	
491	    src_h, src_w = img.shape[:2]
492	    xf, yf, wf, hf = face_facts["face_box_frac"]
493	
494	    # Face box in source pixels
495	    fx = xf * src_w
496	    fy = yf * src_h
497	    fw = wf * src_w
498	    fh = hf * src_h
499	
500	    # Estimated head bounds using the calibration factor
501	    crown_y = fy - (HEAD_FACE_RATIO - 1.0) * fh   # crown above the face-box top
502	    chin_y = fy + fh                                 # chin at the face-box bottom
503	    head_h_src = chin_y - crown_y                    # = fh * HEAD_FACE_RATIO
504	    face_cx = fx + fw / 2.0
505	
506	    # Target: head at the centre of the 70–80% band
507	    head_frac = (profile["head_height_min_frac"] + profile["head_height_max_frac"]) / 2.0
508	    out_w = profile["fix_width_px"]
509	    out_h = profile["fix_height_px"]
510	
511	    # Crop region in source pixels: scale so head_h_src maps to head_frac * out_h
512	    # crop_h / out_h = head_h_src / (head_frac * out_h)  →  crop_h = head_h_src / head_frac
513	    crop_h = head_h_src / head_frac
514	    crop_w = crop_h * out_w / out_h  # maintain output aspect ratio
515	
516	    # Balanced vertical margin: crown at (1 - head_frac) / 2 from top of crop
517	    top_margin = (1.0 - head_frac) / 2.0 * crop_h
518	    crop_y1 = crown_y - top_margin
519	    crop_x1 = face_cx - crop_w / 2.0
520	
521	    # Convert to integer pixel coordinates
522	    cx1 = int(round(crop_x1))
523	    cy1 = int(round(crop_y1))
524	    cw = int(round(crop_w))
525	    ch = int(round(crop_h))
526	
527	    # White canvas; copy the source region into the correct position
528	    canvas = np.full((ch, cw, 3), 255, dtype=np.uint8)
529	    sx1 = max(0, cx1)
530	    sy1 = max(0, cy1)
531	    sx2 = min(src_w, cx1 + cw)
532	    sy2 = min(src_h, cy1 + ch)
533	    if sx2 > sx1 and sy2 > sy1:
534	        dx1 = sx1 - cx1
535	        dy1 = sy1 - cy1
536	        canvas[dy1:dy1 + (sy2 - sy1), dx1:dx1 + (sx2 - sx1)] = img[sy1:sy2, sx1:sx2]
537	
538	    out_img = cv2.resize(canvas, (out_w, out_h), interpolation=cv2.INTER_LANCZOS4)
539	
540	    out_path.parent.mkdir(parents=True, exist_ok=True)
541	    ext = out_path.suffix.lower()
542	    if ext in (".jpg", ".jpeg"):
543	        cv2.imwrite(str(out_path), out_img, [cv2.IMWRITE_JPEG_QUALITY, 95])
544	    else:
545	        cv2.imwrite(str(out_path), out_img)
546	    return True

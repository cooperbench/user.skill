> DEVELOPER

actually before that how do is there a meta key i can use to open dual right now already?

> AGENT

Not built into Dual yet, but you can set it up right now with a tmux keybinding. Add this to your `~/.tmux.conf`: ```bash # Prefix + D to open Dual picker bind-key D display-popup -E -w 60% -h 60% "dual" ``` `display-popup -E` runs Dual in an overlay popup — when you select a workspace, it switches client and the popup disappears. Clean. Or if you want it without the prefix key (e.g. just `Meta+d`): ```bash bind-key -n M-d display-popup -E -w 60% -h 60% "dual" ``` After editing, reload with `tmux source-file ~/.tmux.conf`. The "meta-key workspace switching" item in the backlog (not yet ticketed) would bake this into Dual itself — auto-installing the keybinding via `dual init` or similar. But the manual tmux config works today.

> DEVELOPER

isnt that meta + d the detach meta?

> AGENT

Good catch on being cautious, but `M-d` (Meta+d) isn't tmux detach — that's `Prefix + d` (`Ctrl+b d`). However, `M-d` *is* "delete word" in bash/zsh readline, so it would conflict there. Better options: ```bash # Meta+space — clean, rarely conflicts bind-key -n M-Space display-popup -E -w 60% -h 60% "dual" # Meta+w — "workspace" mnemonic bind-key -n M-w display-popup -E -w 60% -h 60% "dual" # F12 — dedicated function key bind-key -n F12 display-popup -E -w 60% -h 60% "dual" ``` `M-Space` is probably the safest — it's easy to hit and rarely bound to anything.

> DEVELOPER

are you sure thats the correct way? should we unbind first?

> AGENT

`bind-key` in tmux overwrites any existing binding for that key — no need to `unbind-key` first. But worth checking if anything's already on that key: ```bash tmux list-keys | grep M-Space ``` If it's clean, just add the bind. `M-Space` has no default tmux binding, so you should be good: ```bash bind-key -n M-Space display-popup -E -w 60% -h 60% "dual" ```

> DEVELOPER

wait. so what is meta in tmux? i was talk about prefix

> AGENT

`Meta` = `Alt` (or `Option` on Mac). So `M-Space` = `Alt+Space`. `Prefix` = `Ctrl+b` (then release, then press the key). Two different things: - `bind-key -n M-Space ...` → press `Alt+Space` directly, no prefix needed - `bind-key Space ...` → press `Ctrl+b`, then `Space` If you want it on prefix: ```bash bind-key Space display-popup -E -w 60% -h 60% "dual" ``` That's `Ctrl+b Space`. Default binding for `Prefix + Space` is `next-layout`, so you'd be overriding that. If you don't use it, no problem. Otherwise pick another key like: ```bash bind-key w display-popup -E -w 60% -h 60% "dual" ``` `Prefix + w` defaults to `choose-tree` — but Dual's TUI is basically replacing that anyway.

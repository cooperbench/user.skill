Containers are created **without `-p` port publishing** (`container.rs:195-234`). Each container sits on Docker's bridge network with its own private IP (172.17.0.x). Two containers can both bind port 3000 internally without conflict because they have separate network namespaces.

### Layer 3: Reverse Proxy (`dual proxy`)
A separate `dual proxy` command must be running to route browser traffic. It binds to host ports and routes requests based on subdomain: `repo-branch.localhost:3000` -> `172.17.0.x:3000`.

## Analysis: Proxy Data Plane — Token Acquisition, Fetch, and Retry Logic

### Overview

`proxy.ts` is a tRPC mutation handler that acts as an authenticated API proxy. It acquires a token, builds a URL and headers, fires a `fetch`, and conditionally retries once on a 401. Token acquisition is delegated to two helpers in `token-helpers.ts`. The GitHub provider's token path goes through `getInstallationToken`, which calls the GitHub App installations API and extracts the bearer token from the JSON response.

**Request-scoped correlation ID in `proxy.execute`.**

Right now, even with all these new log lines, when 50 installations hit the proxy concurrently, the logs interleave into an unreadable wall. const requestId = crypto.randomUUID();

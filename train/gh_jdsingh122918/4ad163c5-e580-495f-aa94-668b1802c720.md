## 11. KEY ARCHITECTURAL INSIGHTS

### Separation of Concerns
- **Rust backend** handles orchestration, state, git, processes
- **React frontend** handles UI layout, drag-and-drop, real-time updates
- **WebSocket** decouples them (backend broadcasts, frontend subscribes)

### Optimism & Reactivity
- Frontend uses optimistic updates (move issue, then call API)
- Rolls back on error
- WebSocket messages make state eventually consistent

### Real-time Coordination
- Broadcast channel (256-slot buffer) in backend
- Each client's WebSocket handler receives all events
- Frontend selectively handles relevant events (e.g., only handles `run_id` match)

### Testing
- `FactoryDb::new_in_memory()` for unit tests
- MSW (Mock Service Worker) for API mocking in frontend tests
- Vitest for React component tests

### 10. Key Architectural Patterns

1. **State Management:**
   - React hooks (useState, useEffect, useCallback, useRef)
   - Context for WebSocket (Provider pattern)
   - Custom hooks compose domain logic
   - Refs for optimistic rollback, mounted checks, debouncing

2. **Data Flow:**
   - App root subscribes to all WebSocket messages
   - useBoard updates board state incrementally
   - useAgentTeam updates team/events/merge/verification
   - Components receive sliced data (issue, run, team, events)

3. **Async Patterns:**
   - All API calls return Promises
   - Error states captured in local state
   - Optimistic updates (moveIssue) with fallback
   - Loading states for async operations

4. **Drag & Drop:**
   - @dnd-kit/core + sortable + utilities
   - PointerSensor with 8px activation constraint
   - closestCorners collision detection
   - Manual target finding (no built-in sorting)

5. **Form Patterns:**
   - Controlled inputs with useState
   - Double-click to edit (title, description)
   - Keyboard shortcuts (Enter, Escape, Ctrl+Enter)
   - Blur/key handlers with `Ref` flags to prevent double-save

6. **WebSocket Integration:**
   - Pub/sub subscriber pattern (Set of callbacks)
   - Each hook registers listener with useWsSubscribe
   - Messages dispatched to all subscribers
   - Type-safe union type (WsMessage) for all events

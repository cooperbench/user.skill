**However** — the `cargo-target` volume is a Docker named volume, not a bind mount. This means `cargo watch` inside the container uses its own target dir. You should see `forge-dev-1` logging a recompilation in your terminal where `start.sh dev` is running. Look for a `Compiling forge ...` line followed by `Starting Forge Factory server`.

The currently running pipeline won't get the fix — it's already in-flight. The fix will apply to the **next** pipeline run after the backend finishes recompiling.

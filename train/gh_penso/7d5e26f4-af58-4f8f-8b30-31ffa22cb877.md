## Root Cause

The issue manifests in **two flows**:

1. **Single-model save flow** (`providers.js:824`): After the user selects a model and saves credentials, `testModel()` is called. If it times out, `showError()` fires and the model is **not saved**. This is the primary blocker.

2. **Multi-model selector** (`providers.js:1123`): The probe is informational — models CAN still be selected — but a timeout shows as "Unsupported" which is misleading.

The timeouts are:
- `models.test` RPC: **10 seconds** (`crates/chat/src/lib.rs:2231`)
- Provider validation probe: **10 seconds** (`crates/provider-setup/src/lib.rs:2496`)

For local LLM servers (llama.cpp, Ollama with large models, etc.), the model must be loaded into memory before any tokens stream. Loading + prompt processing easily exceeds 10 seconds, causing the timeout even though the model works fine (the user's logs confirm the LLM finishes processing).

## Fix Plan

### 1. Increase backend timeouts (Rust)

- **`crates/chat/src/lib.rs:2231`** — `models.test` timeout: 10s → 30s
- **`crates/provider-setup/src/lib.rs:2496`** — `VALIDATION_PROBE_TIMEOUT_SECS`: 10 → 30

### 2. Frontend: don't block model save on timeout (JS)

- **`crates/web/src/assets/js/providers.js:~824`** — Treat timeout the same as `modelServiceUnavailable`: save the model with a console warning instead of blocking
- **`crates/web/src/assets/js/providers.js:~1226`** — Show "Timeout" badge (not "Unsupported") when probe times out, with a tooltip explaining the model may still work

### 3. Distinguish timeout from unsupported in `provider-validation.js`

- Add `isTimeoutError()` helper to detect timeout errors
- Export it for use in `providers.js`

### 4. Regression test

- **`crates/chat/src/lib.rs`** (or a new integration test) — Test that `models.test` with a provider that delays response for 15 seconds still succeeds within the new 30s timeout
- **`crates/provider-setup/src/lib.rs`** — Test that validation probe handles slow model responses correctly

### 5. E2E test

- **`crates/web/ui/e2e/specs/`** — Test that a model with a slow probe response still gets saved successfully (mock the RPC to return timeout, verify the model is saved with warning)

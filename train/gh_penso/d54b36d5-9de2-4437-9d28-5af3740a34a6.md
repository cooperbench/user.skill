Yes — **`mime_guess`** is the go-to crate. Usage:

```rust
mime_guess::from_ext("pdf").first_raw()  // Some("application/pdf")
```

It returns `Option<&'static str>` via `.first_raw()`, which is a drop-in replacement for your `mime_from_extension` signature.

Both `mime_from_extension` and `extension_for_mime` can be replaced:
- `mime_from_extension(ext)` → `mime_guess::from_ext(ext).first_raw()`
- `extension_for_mime(mime)` → `mime_guess::get_mime_extensions_str(mime).and_then(|exts| exts.first())`

The `extension_for_mime` reverse direction is slightly less clean since `mime_guess` returns a slice of possible extensions, but it works. You could also keep the reverse mapping manual if you want control over preferred extensions (e.g. "jpg" vs "jpeg").

One caveat: `mime_guess` won't know `"text"` or `"log"` as extensions for `text/plain`, and `"ppm"` may not be in its database. You could handle those few edge cases with a fallback. Want me to make the change?

<a href="#"><img alt="P1" src="https://greptile-static-assets.s3.amazonaws.com/badges/p1.svg?v=7" align="top"></a> **Serving `text/html` inline enables stored XSS**

`text/html` is included in the `inline` disposition list, which tells the browser to render the file directly from the same application origin. Since the LLM can generate and save arbitrary HTML files via `send_document` (`.html` is in the supported extensions), this creates a stored XSS path:

1. An adversarial prompt injection tricks the LLM into generating an HTML file with malicious `<script>` content.
2. `send_document` saves it to the session media directory.
3. A user clicks "Open" in the document card — their browser renders the HTML on the app's own origin.
4. The injected script runs with full access to `localStorage`, cookies, and the session API.

`text/csv` and `text/markdown` are less risky because browsers don't execute them, but `text/html` is the primary XSS attack surface. Consider removing it from the inline list so HTML files always trigger a download:

```suggestion
            "application/pdf" | "text/plain" | "text/csv" | "text/markdown"
```

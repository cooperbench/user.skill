Is the shims only for tests or moltis as well?

> AGENT

Shims are **only for tests**. The moltis app doesn't use them at all. The app loads `dist/main.js` (the Vite bundle) which has everything self-contained — all modules are bundled together with their imports resolved internally. The shim files in `js/state.js`, `js/helpers.js`, etc. are never loaded by the app. The shims exist because the e2e tests do `await import("js/state.js")` to inspect and mock internal app state (WebSocket connections, chat sequence counters, etc.). With the old native ES modules, those files existed as real standalone modules. With Vite bundling, they don't — so the shims bridge the gap by proxying to `window.__moltis_modules` which the app populates at startup. If you eventually migrate the e2e tests to use `window.__moltis_stores` / `window.__moltis_state` directly (via `page.evaluate`) instead of dynamically importing individual modules, the shims can be deleted entirely.

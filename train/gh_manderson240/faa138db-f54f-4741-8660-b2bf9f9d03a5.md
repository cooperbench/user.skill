`★ Insight ─────────────────────────────────────`
**`| None = None` field pattern trap**: Using `None` as the default for collection fields (vs `field(default_factory=list)`) means callers must handle `None` explicitly — `len(field)` fails on `None`. This is a common pattern in "optional" dataclass fields, but it means all consumers need `or []` guards. The alternative — always defaulting to empty lists — is safer but can't distinguish "not set" from "empty".

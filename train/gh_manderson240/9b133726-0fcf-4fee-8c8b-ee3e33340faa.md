### Key Architecture Decisions

1. **File-Based Task Queue**: Uses markdown files in git-tracked vault, not a database. Survives across Claude sessions naturally.

2. **Two-Layer Async Model**:
   - **Layer 1** (this codebase): Compound cycles, skill refinement loops, and journey tracking
   - **Layer 2** (vault): Teleport task queue for delegation to remote agents

3. **Session Tracking Integration**: `track_session()` creates a node in SurrealDB that captures:
   - Agent ID + goals
   - Model used + phase
   - Execution context for later queries by retrospection engine

4. **Agent Specialization**: Each agent (.claude/agents/*.md) is autonomous with:
   - Explicit tool allowlists (what it can read/execute)
   - Explicit tool denylists (what it cannot do)
   - Model choice optimization (haiku for refinement, sonnet for planning)

5. **Non-Blocking Observability**: JourneyTracker, MetricsCollector, DegradationDetector all have try/except wrappers—failures don't crash execution, just log warnings.

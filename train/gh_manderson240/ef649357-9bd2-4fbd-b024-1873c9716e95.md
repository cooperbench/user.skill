## PDF Content Summary (Source Document - 29 Pages)

### Chapter 1: Fundamentals (pp. 4-6)
- **Skill = folder**: `SKILL.md` (required) + optional `scripts/`, `references/`, `assets/`
- **Progressive Disclosure**: 3 levels - YAML frontmatter (always in system prompt), SKILL.md body (loaded on trigger), linked files (on demand)
- **Composability**: Skills coexist; don't assume exclusivity
- **Portability**: Works across Claude.ai, Claude Code, API
- **MCP + Skills**: MCP = connectivity (tools), Skills = knowledge (workflows). "Kitchen analogy" - MCP is the kitchen, skills are the recipes

### Chapter 2: Planning and Design (pp. 7-13)
- **Start with use cases**: 2-3 concrete use cases before coding
- **3 skill categories**: (1) Document & Asset Creation, (2) Workflow Automation, (3) MCP Enhancement
- **Success criteria**: Quantitative (90% trigger rate, X tool calls, 0 API failures) + Qualitative (no user prompting, consistent results)
- **File structure**: `SKILL.md` must be exact case. Folder naming: kebab-case only. No README.md inside skill folder
- **YAML frontmatter fields**: `name` (kebab-case, required), `description` (required, <1024 chars, must include WHAT + WHEN), `license`, `compatibility`, `metadata`
- **Description formula**: `[What it does] + [When to use it] + [Key capabilities]`
- **Security**: No XML angle brackets in frontmatter. No "claude" or "anthropic" in name
- **Instructions best practices**: Be specific/actionable, include error handling, reference bundled resources clearly, use progressive disclosure

### Chapter 3: Testing and Iteration (pp. 14-17)
- **3 testing approaches**: Manual (Claude.ai), Scripted (Claude Code), Programmatic (Skills API)
- **3 test areas**: Triggering tests (loads at right time), Functional tests (correct output), Performance comparison (vs baseline)
- **skill-creator tool**: Built into Claude.ai + Claude Code. Generates, reviews, suggests improvements
- **Iteration signals**: Undertriggering (add detail to description) vs Overtriggering (add negative triggers, be more specific)

### Chapter 4: Distribution and Sharing (pp. 18-20)
- **Individual**: Download folder → zip → upload via Settings > Capabilities > Skills (or Claude Code skills directory)
- **Organization**: Workspace-wide deployment (shipped Dec 2025), automatic updates, centralized management
- **Open standard**: Agent Skills - portable across platforms
- **Skills API**: `/v1/skills` endpoint, `container.skills` parameter in Messages API, version control via Console
- **API vs Claude.ai routing**: End users → Claude.ai/Code; Programmatic/production → API
- **Positioning**: Focus on outcomes not features; highlight MCP + skills story

### Chapter 5: Patterns and Troubleshooting (pp. 21-27)
- **Problem-first vs Tool-first**: Two design approaches depending on user context
- **5 Patterns**:
  1. Sequential Workflow Orchestration (multi-step, explicit ordering, rollback)
  2. Multi-MCP Coordination (cross-service, phase separation, data passing)
  3. Iterative Refinement (quality loops, validation scripts, stop criteria)
  4. Context-aware Tool Selection (decision trees, fallback options, transparency)
  5. Domain-specific Intelligence (embedded expertise, compliance-before-action, audit trails)
- **Troubleshooting**: Upload errors (SKILL.md naming), invalid frontmatter (YAML formatting), trigger issues (description quality), MCP connection issues, instructions not followed (verbose/buried/ambiguous), large context issues (optimize SKILL.md size, reduce enabled skills)
- **Advanced technique**: Bundle validation scripts for deterministic checks rather than relying on language instructions

### Chapter 6: Resources and References (pp. 28-29)
- Official docs: Best Practices Guide, Skills Documentation, API Reference, MCP Documentation
- Blog posts: Introducing Agent Skills, Engineering Blog, Skills Explained, How to Create Skills, Building Skills for Claude Code, Improving Frontend Design
- Public skills repo: `anthropic/skills` on GitHub
- skill-creator: Built-in tool for generating, reviewing, and validating skills
- Support: Claude Developers Discord, GitHub Issues at `anthropic/skills/issues`

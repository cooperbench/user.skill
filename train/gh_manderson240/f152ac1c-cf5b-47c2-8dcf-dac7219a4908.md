## Context

Cohezion accumulates rich execution experience (phi_score, 12D FLUME trajectories, coherence
metrics) via JourneyTracker but never uses it to update model weights. Four training pipelines
exist in `flume/` but all generate bash scripts and stop — none execute training. Meanwhile
cloud API costs accumulate on Claude Code / Gemini CLI every session.

The goal is a closed **Cohezion Autonomous Learning Loop (CALL)**: Cohezion's own runtime
experiences become the training signal, AgentJet provides the RL loop, Unsloth provides the
fast fine-tuning backend, and improved local models route away from cloud APIs for familiar
tasks. The Ryzen AI MAX+ 395 with 128GB unified memory is uniquely capable for this — MoE
models like nemotron-3-super (120B total / 12B active) fit entirely in unified memory.

**Critical constraints driving the design:**
- OOM prevention: 128GB is shared CPU+GPU; training + inference models loaded simultaneously
  = crash. Must unload inference models before any training job.
- Context window management: KV cache grows quadratically with context. A 128K context uses
  16x more memory than 32K. Ollama settings + context compression must be first-class.
- AMD training gap: Unsloth Studio AMD training is "coming soon" — Phase 1 uses existing
  llama.cpp/llamafactory path. Unsloth slots in as a drop-in when AMD support ships.

## Context Window Optimization Strategy

Key Ollama environment variables to set/expose as Cohezion config:

```bash
# In .env or cohezion config:
OLLAMA_FLASH_ATTENTION=1       # 50% KV cache reduction — enable always
OLLAMA_KV_CACHE_TYPE=q8_0     # Quantized KV cache (further memory reduction)
OLLAMA_NUM_PARALLEL=1          # During training: 1 parallel request max
OLLAMA_MAX_LOADED_MODELS=2     # During training: max 2 models (reduce from 4)
```

Per-model context window sizing rules (to prevent KV cache OOM):

| Scenario | num_ctx | Rationale |
|----------|---------|-----------|
| Routing models (0.8B-2B) | 32768 | Fast, small KV cache |
| Execution models (9B-30B) | 16384 | Balance quality vs memory |
| Deep reasoning (70B+) | 8192 | Prevent OOM at large sizes |
| During QLoRA training | 2048 | Training doesn't need long context |
| Fine-tuned domain models | 8192 | Adequate for specialized tasks |

The `ContextHarness` in `cohezion/reliability/context_harness.py` already does prompt pruning
targeting phi3:mini. Extend it to use per-model `ModelContextProfile` instead of hardcoded target.

## OOM Prevention Protocol (Non-Negotiable)

Before ANY training job, `AgentJetTrainer._safety_check()` must:

1. Call `OllamaContextManager.get_available_memory_gb()`
2. Estimate training memory: `model_params_gb × 3.0` (weights + gradients + optimizer)
3. If `available < required × 1.2` (20% headroom): raise `OOMRiskError`, abort
4. Call `OllamaContextManager.unload_all_for_training()`:
   - `POST http://localhost:11434/api/generate` with `keep_alive: 0` for each model
   - Wait for confirmation (poll `/api/ps` until empty)
5. After training: call `reload_inference_models()` in finally block

`DegradationDetector` already monitors `memory_pressure_threshold: 0.80` — wire it to
trigger model eviction before training starts.

## Platform Resource Manager (Cross-Session)

**The problem**: Multiple Claude Code sessions, Gemini CLI sessions, background scripts, and
training jobs all compete for 128GB unified memory with no coordination. Each session's
`model_pool_manager.py` is a singleton that sees only its own allocations. A training job
can OOM the machine while a separate session is serving inference.

**The solution**: A lightweight persistent resource daemon that acts as the platform's
memory arbiter — any session must check in before loading models or starting training.

### Architecture

```
┌─────────────────────────────────────────────────────┐
│           RESOURCE DAEMON (persistent)              │
│  Polls Ollama /api/ps every 30s                     │
│  Tracks: loaded_models, reserved_gb, training_locks │
│  Backend: SurrealDB (already running at ws://8000)  │
│  API: HTTP :8765 (lightweight, always-on)           │
└───────────┬────────────────────────┬────────────────┘
            │ reads                  │ reads/writes
  ┌─────────▼──────┐       ┌────────▼────────────┐
  │ Claude Code    │       │ Training Job         │
  │ Session A      │       │ (AgentJetTrainer)    │
  │ ResourceClient │       │ ResourceClient       │
  └────────────────┘       └─────────────────────┘
            │
  ┌─────────▼──────┐
  │ Claude Code    │
  │ Session B      │
  │ ResourceClient │
  └────────────────┘
```

### New Component: src/cohezion/platform/resource_manager.py

```python
class ResourceDaemon:
    """Persistent platform resource arbiter.

    Runs as background process between sessions.
    Polls Ollama /api/ps for ground-truth model state.
    Manages training locks to prevent concurrent training OOM.

    Start: uv run python -m cohezion.platform.resource_manager
    Or via systemd: cohezion-resources.service
    """
    POLL_INTERVAL_S = 30         # Ollama /api/ps poll frequency
    PORT = 8765                  # Local HTTP API port
    TRAINING_LOCK_TTL_S = 7200   # Max training job reservation = 2 hours

    async def poll_ollama_state(self) -> OllamaState:
        """Query /api/ps for actual loaded models + memory usage."""
        ...

    async def get_available_memory_gb(self) -> float:
        """Total unified memory - Ollama usage - OS overhead - 10GB safety buffer."""
        ...

    async def request_training_lock(
        self, session_id: str, model: str, required_gb: float
    ) -> TrainingLock | None:
        """Exclusive lock for training. Returns None if insufficient memory.
        Locks are stored in SurrealDB with TTL for crash recovery.
        """
        ...

    async def release_training_lock(self, lock_id: str) -> None: ...

    async def register_session(self, session_id: str) -> None:
        """Track active sessions for cleanup on death."""
        ...

    async def cleanup_dead_sessions(self) -> None:
        """Release locks from sessions that died without cleanup."""
        ...


class ResourceClient:
    """Lightweight client for any session to consult the ResourceDaemon.

    Falls back gracefully if daemon not running (single-session mode).
    All sessions MUST use this before loading large models or training.
    """
    DAEMON_URL = "http://localhost:8765"

    async def check_memory(self) -> PlatformMemoryState:
        """Get current memory state across all sessions."""
        ...

    async def acquire_training_lock(
        self, model: str, required_gb: float, timeout_s: float = 30.0
    ) -> TrainingLock | None:
        """Request exclusive training access. Blocks until available or timeout."""
        ...

    async def can_load_model(self, model_name: str, size_gb: float) -> bool:
        """Check if loading a model is safe given all sessions' current usage."""
        ...

    def is_daemon_running(self) -> bool:
        """Silent check — False = fall back to local-only mode."""
        ...


@dataclass
class PlatformMemoryState:
    total_gb: float              # 128 for Ryzen AI MAX+ 395
    ollama_used_gb: float        # From /api/ps (all sessions combined)
    system_reserved_gb: float    # OS + non-Ollama processes
    training_reserved_gb: float  # Active training lock reservations
    available_gb: float          # total - ollama_used - system_reserved - training_reserved
    safety_buffer_gb: float = 10.0  # Never let available drop below this
    loaded_models: list[str]     # All models currently loaded across ALL sessions


@dataclass
class TrainingLock:
    lock_id: str
    session_id: str
    model: str
    reserved_gb: float
    acquired_at: float
    expires_at: float            # TTL for crash recovery
```

## Gemini Embedding 2 — Orchestration Anchor

Gemini Embedding 2 (March 10, 2026) is Google's first natively multimodal embedding model:
maps text, images, video, audio, and documents into ONE unified embedding space.

This upgrades Cohezion's orchestration from keyword matching → semantic concept matching.

### Why It Matters

`SemanticCache` already has a plug-and-play `EmbeddingModel` interface. The current
`FlumeVAEEmbeddingModel` uses a 256D SHA-256 hash projection — not truly semantic. Gemini
Embedding 2 slots directly into the same interface as a higher-quality tier.

### Three Uses (in priority order)

**1. Vault Indexing (offline, one-time cost)**
Embed every vault note, decision, pattern, and PRIME skill using Gemini Embedding 2.
Store vectors locally in SurrealDB. Never pay again for the same content.
This makes `vault_find_relevant_context()` orders of magnitude more accurate.

**2. FLUME VAE Distillation (calibration, not runtime)**
Use Gemini Embedding 2 vectors as teacher signal to train the FLUME VAE.
The VAE learns to approximate Gemini's embedding quality locally.
After calibration: near-cloud quality at zero API cost per runtime query.
This is knowledge distillation for embeddings — same principle as DistilBERT vs BERT.

**3. Cross-Modal Orchestration (when cloud available)**
Task descriptions, code snippets, trajectory data, and skill definitions all embedded
into the same space. SmartRouter semantic matching across modalities, not just text.

### New Component: src/cohezion/agentjet/embeddings.py

```python
class GeminiEmbeddingModel(EmbeddingModel):
    """Cloud Gemini Embedding 2 — uses Gemini API, caches locally.

    Never embeds the same content twice. Stores in SurrealDB with content hash key.
    Falls back to FlumeVAEEmbeddingModel when cloud unavailable.
    """
    def __init__(self, cache_backend: SurrealClient, fallback: EmbeddingModel): ...
    async def encode(self, text: str) -> EmbeddingResult:
        key = sha256(text)
        if cached := await self.cache_backend.get(key): return cached
        result = await self._call_gemini_api(text)
        await self.cache_backend.store(key, result)
        return result

class EmbeddingDistiller:
    """Distills Gemini Embedding 2 quality into local FLUME VAE.

    Generates Gemini embeddings for vault corpus, then fine-tunes FLUME VAE
    to minimize distance to Gemini vectors. Result: local embeddings that
    approximate cloud quality without runtime API calls.
    """
    def distill(self, vault_corpus: list[str], epochs: int = 10) -> Path: ...
    # Outputs calibrated FLUME VAE checkpoint
```

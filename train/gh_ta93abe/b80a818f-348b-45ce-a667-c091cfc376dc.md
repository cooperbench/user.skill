podman対応しているの？

> AGENT

公式ドキュメントでは **「Docker compatible CLI tool」** として Docker Desktop と Colima のみ言及。Podman の記載はありません。 Wrangler は内部で `docker` CLI を呼び出しているので、Podman を使うには: ```bash # podman を docker コマンドとしてエイリアス # macOS (Homebrew) brew install podman podman machine init podman machine start # docker CLI 互換にする sudo ln -s $(which podman) /usr/local/bin/docker # または alias docker=podman ``` ただし **公式サポート外** なので、動く保証はありません。Colima の方が安全です: ```bash brew install colima docker colima start ``` Colima は Docker CLI 互換の軽量ランタイムで、公式ドキュメントにも記載されています。README は現状「Docker Desktop または Colima」としているので、このままで良いと思います。

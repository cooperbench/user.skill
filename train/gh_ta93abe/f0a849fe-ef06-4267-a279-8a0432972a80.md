`★ Insight ─────────────────────────────────────`
**エラーの意味**: `state:modified+` セレクターは「本番の manifest.json と比較して変更されたモデル」を選びます。しかし、比較対象の manifest（production artifact）がまだ存在しません。dbt-jobs の `deferral: main` は GitHub Actions の artifact から manifest を取得しますが、まだ一度も `deploy` や `merge` が実行されていないため、artifact がアップロードされていない状態です。
`─────────────────────────────────────────────────`

**解決策**: まず `dbt Deploy` ワークフローを手動実行して、本番の manifest.json artifact を生成する必要があります。

DuckDB 固有の部分は以下の3箇所です： **1. `generate_series()` + `unnest()` (3行目)** ```sql unnest(generate_series(date '2024-01-01', date '2024-12-31', interval '1 day'))::date ``` Snowflake にはこれらの関数がありません。Snowflake では `GENERATOR()` + `DATEADD()` を使います。 **2. `strftime()` (24-27行目)** ```sql strftime(date_day, '%Y-%m') ``` DuckDB の書式関数。Snowflake では `TO_CHAR()` を使います。 **3. `extract(dow from ...)` (21, 30, 31行目)** ```sql extract(dow from date_day) ``` DuckDB の `dow` は日曜=0、土曜=6。Snowflake では `DAYOFWEEK` で、デフォルトの曜日番号体系が異なります。

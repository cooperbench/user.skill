> AGENT

J-Quants（株価）+ EDINET（決算）を組み合わせると、こんな分析ができます：

### ファンダメンタル分析
- **PER / PBR / ROE** などの指標算出（決算データ + 時価総額）
- **割安株スクリーニング**（財務指標 × 株価水準）
- **業績トレンド分析**（売上・利益の四半期推移）

### イベント分析
- **決算発表前後の株価変動**（決算サプライズの影響測定）
- **業績予想修正と株価の相関**
- **セクター別の決算反応パターン**

### 比較分析
- **同業他社比較**（セクター内でのバリュエーション位置づけ）
- **財務健全性ランキング**（自己資本比率、キャッシュフロー等）

### 定量スクリーニング
- **グロース株 / バリュー株の分類**
- **増収増益が続く銘柄の抽出**
- **配当利回り × 財務安定性のフィルタリング**

### 時系列分析
- **業績と株価の乖離検出**（ファンダメンタルズ対比で割安/割高）
- **季節性パターン**（決算月ごとの傾向）

## mf-dashboard の構成まとめ

### アーキテクチャ

```
GitHub Actions (cron: 毎日2回)
  → Playwright で MoneyForward Me をスクレイピング
  → SQLite (data/moneyforward.db) に保存
  → DB ファイルを git commit & push
  → Cloudflare Pages (Next.js Static Export) でダッシュボード表示
```

### モノレポ構成 (pnpm + Turborepo)

| パッケージ | 役割 |
|-----------|------|
| `apps/crawler` | Playwright で MF をスクレイピング |
| `apps/web` | Next.js ダッシュボード（Static Export → Cloudflare Pages） |
| `apps/mcp` | MCP サーバー（AI連携） |
| `apps/simulator` | 複利シミュレーター（モンテカルロ法） |
| `packages/db` | Drizzle ORM + SQLite スキーマ・リポジトリ |
| `packages/analytics` | 財務分析・LLM インサイト生成 |
| `packages/meta` | カテゴリ定義・URL定数 |

### DB スキーマ (Drizzle + SQLite)

主要テーブル:
- **groups** / **group_accounts** - グループ管理
- **accounts** / **account_statuses** - 金融機関アカウント
- **holdings** / **holding_values** - 銘柄・評価額（日次スナップショット）
- **transactions** - 収支明細（income/expense/transfer）
- **asset_history** / **asset_history_categories** - 資産推移
- **spending_targets** - 予算カテゴリ（固定費/変動費）
- **analytics_reports** - LLM分析レポート

### 取得データ

| スクレイパー | 取得内容 |
|-------------|---------|
| asset-summary | 総資産・前日比・前月比 |
| asset-items | 資産カテゴリ別内訳 |
| asset-history | 資産推移（グラフ用） |
| cash-flow | 月次収支・明細 |
| portfolio | 保有銘柄・評価損益 |
| liabilities | 負債一覧 |
| registered-accounts | 連携金融機関ステータス |
| spending-targets | 予算設定 |

### 参考になるポイント

- **Playwright でのスクレイピング**: MF にはAPIがないのでスクレイピングで対応
- **SQLite + git**: DB ファイルをリポジトリに直接コミットするシンプルな運用
- **Drizzle ORM**: 型安全なスキーマ定義・マイグレーション
- **日次スナップショット**: `daily_snapshots` + `holding_values` で時系列追跡
- **LLM 分析**: `packages/analytics` で OpenAI を使った財務インサイト生成
